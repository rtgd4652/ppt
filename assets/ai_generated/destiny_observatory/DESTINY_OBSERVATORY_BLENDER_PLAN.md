# 《命运观测塔》Blender 建模方案

> 用途：交给“美术与模型线”作为命运观测塔巨构的建模任务书。  
> 目标：先完成低模可用版本，再追加发光材质、环体旋转动画和 LOD，最终接入 Stellaris 巨构模型。

## 1. 设计定位

命运观测塔不是普通空间站，而是一座“把命运星盘立体化”的神圣未来科技巨构。

核心视觉关键词：

- 命运观测：环形星盘、透镜、棱镜、观测阵列。
- 神圣未来科技：银白金属、冰蓝水晶、金色太阳冠冕。
- 塔罗牌“太阳”：顶部日轮、白昼感、纯净强光。
- 低模可读：远距离看得出“中央圣塔 + 命运环 + 底部锚定尖塔”。

## 2. 总体轮廓

建议使用垂直构图，整体从上到下分为五层：

1. 顶部太阳冠冕  
   金色/银白发光日轮，作为最高识别点。

2. 中央观测主塔  
   竖向主结构，承载水晶核心和主观测装置。

3. 三层命运环  
   围绕主塔旋转，像星盘、轨道仪和命运演算环。

4. 径向支臂与观测模块  
   连接外环，挂载透镜、棱镜、小型观测塔。

5. 底部锚定尖塔  
   形成“悬浮圣塔”的重心，也用于放置能量收束材质。

## 3. 推荐建模阶段

### 阶段 A：低模 Blockout

目标：先做出游戏中能识别的完整轮廓，不追求细节。

建议对象命名：

- `DO_Main_Spire`：中央主塔。
- `DO_Solar_Crown`：顶部太阳冠。
- `DO_Ring_Inner`：内层命运环。
- `DO_Ring_Middle`：中层命运环。
- `DO_Ring_Outer`：外层命运环。
- `DO_Crystal_Core`：中央冰蓝水晶核心。
- `DO_Radial_Arm_A/B/C/D`：四向径向支臂。
- `DO_Lens_Module_*`：外环观测透镜模块。
- `DO_Bottom_Anchor`：底部锚定尖塔。
- `DO_Dock_Platform_*`：外围建造/停泊平台。

建议建模方法：

- 主塔：用立方体、倒角立方体、锥体堆叠。
- 环体：用 Torus 或曲线 Bevel Depth，低分段即可。
- 支臂：用长方体加倒角，避免圆柱过多。
- 水晶：用低分段八面体/锥体组合，保持透明棱面。
- 透镜模块：用短圆柱 + 环形边框 + 小水晶。
- 底部尖塔：用锥体或四棱锥，强调垂直收束。

低模阶段预算：

- LOD0 目标：15k–25k tris。
- 单个环体分段：48–72 段即可。
- 小型重复模块尽量用实例/镜像，不要逐个高细节建模。

### 阶段 B：结构精修

目标：让近景截图也能看出层次，但仍保持性能友好。

重点追加：

- 主塔表面分层装甲板。
- 环体内外双层边框。
- 支臂连接处的银白节点。
- 外环均匀分布 8–12 个观测透镜。
- 顶部太阳冠可做成双环：外金环 + 内冰蓝发光环。
- 底部锚定尖塔加入 3–4 片向下收束的翼片。

注意：

- 不要把每个面都切很多小线。
- 远距离可见的大块轮廓优先于近距离碎细节。
- 与“命运之主”舰船保持同一色系：深蓝主面、银白边、冰蓝发光线。

## 4. 材质方案

建议材质命名：

- `MAT_DO_Navy_Panel`：深蓝主装甲。
- `MAT_DO_Silver_Edge`：银白边框/切面。
- `MAT_DO_Ice_Crystal`：冰蓝透明水晶。
- `MAT_DO_Blue_Emission`：蓝色发光线路。
- `MAT_DO_Gold_Solar`：顶部太阳冠金色发光。
- `MAT_DO_Black_Seam`：黑色阴影缝隙。

材质表现：

- 深蓝主装甲：低粗糙度、轻微金属感。
- 银白边框：高金属度，作为结构识别线。
- 冰蓝水晶：透明或半透明，带自发光。
- 蓝色线路：用 emissive 材质，贴在环体和主塔表面。
- 金色太阳冠：少量使用，避免把整体变成金色空间站。

Stellaris 内实际效果提醒：

- 游戏内过强红光/过亮自发光容易糊成一片。
- 建议蓝光为主，金光只作为顶部冠冕和核心点缀。
- 贴图阶段可先使用纯色材质测试，再做 DDS。

## 5. 动画方案

先做最简单、最稳的循环动画。

建议动画对象：

1. `DO_Ring_Inner`
   - Z 轴慢速顺时针旋转。
   - 一圈 20–30 秒。

2. `DO_Ring_Middle`
   - Z 轴逆时针旋转。
   - 一圈 35–45 秒。

3. `DO_Ring_Outer`
   - 极慢旋转。
   - 一圈 60 秒以上。

4. `DO_Solar_Crown`
   - 可做轻微呼吸光，不一定旋转。

5. `DO_Crystal_Core`
   - 可做轻微缩放或发光强弱变化。

动画原则：

- 不做复杂机械展开，先保证循环稳定。
- 环体旋转速度必须慢，避免远景闪烁。
- 不要让支臂与环体穿帮；若支臂固定，则旋转环体应与支臂分层。

## 6. LOD 方案

### LOD0：近景版本

用途：玩家拉近查看巨构。

预算：

- 15k–25k tris。
- 保留完整环体、透镜、支臂、主塔分层。

### LOD1：中距离版本

用途：普通星系视角。

预算：

- 7k–12k tris。
- 保留三层环和中央塔。
- 删除大部分小透镜，仅保留代表性模块。

### LOD2：远距离版本

用途：星系远景。

预算：

- 2k–5k tris。
- 环体降分段。
- 小平台合并为简单块。
- 发光线减少为几条主线。

### LOD3：极远距离版本

用途：战略缩放下的轮廓。

预算：

- 500–1500 tris。
- 只保留“中央塔 + 外环 + 底部尖塔”的剪影。
- 可以完全删除小模块。

## 7. Blender 操作建议

推荐工作流：

1. 新建集合：
   - `DO_LOD0`
   - `DO_LOD1`
   - `DO_LOD2`
   - `DO_LOD3`
   - `DO_Animation_Rigs`
   - `DO_Locators`

2. 先只做 `DO_LOD0`。

3. 使用 Mirror / Array / Empty 旋转复制：
   - 四向支臂。
   - 八到十二个观测透镜。
   - 环体外围重复小模块。

4. 低模确认后再应用修改器。

5. 生成 LOD：
   - 从 LOD0 复制。
   - 删除小件。
   - 合并平台。
   - 降低环体分段。

6. 添加命名空物体/定位点：
   - `locator_center`
   - `locator_ring_inner`
   - `locator_ring_middle`
   - `locator_ring_outer`
   - `locator_core_glow`
   - `locator_top_crown`

## 8. 尺寸与比例建议

以中央主塔高度为 1 个单位基准：

- 主塔高度：1.0
- 顶部太阳冠直径：0.65–0.9
- 内环直径：1.2
- 中环直径：1.8
- 外环直径：2.4–3.0
- 底部锚定尖塔高度：0.35–0.55
- 外围平台长度：0.35–0.7

整体比例：

- 从正面看：像“竖立的圣塔”。
- 从俯视看：像“多层命运星盘”。
- 从侧面看：能看出环体前后层级。

## 10. 第一轮验收标准

第一轮只验收低模和基础材质：

- 巨构远看能识别为“高塔 + 环形星盘”。
- 正面、侧面、俯视都不塌形。
- 环体没有明显穿插主塔。
- 蓝色/金色发光不过曝。
- LOD0 面数不超过 25k tris。
- LOD2 仍能看出命运观测塔轮廓。
- 导入游戏后不会出现红色材质、全黑材质、比例过大或比例过小。

## 11. 后续可选强化

在第一版稳定后再考虑：

- 环体缓慢旋转动画。
- 核心水晶呼吸光。
- 顶部太阳冠微弱脉冲。
- 外围观测透镜悬浮小件。
- 少量星尘粒子或蓝色能量线。
- 建造阶段模型：框架态、半成品态、完成态。

## 12. 美术与模型线当前任务

请美术与模型线优先执行：

1. 根据本方案制作 `destiny_observatory_blockout.blend`。
2. 只做低模结构，不急着画复杂贴图。
3. 使用纯色材质区分：
   - 深蓝主装甲。
   - 银白边框。
   - 冰蓝水晶。
   - 金色太阳冠。
4. 完成后导出截图：
   - 近景三-quarter 视角。
   - 正视图。
   - 侧视图。
   - 俯视图。
5. 回传面数统计和是否存在明显穿模。

第一目标不是“最终漂亮”，而是“结构正确、能进游戏、能远距离识别”。
