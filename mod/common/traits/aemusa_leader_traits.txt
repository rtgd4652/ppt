# 赛斯专属特质：依据原作“辅助型神官”与神器“羽蛇神杖”映射为随等级成长的殖民地治疗和安抚能力。
leader_trait_seth_official = {
    cost = 0 # 专属特质不占用特质点。
    initial = no # 不在常规领袖生成界面中出现。
    randomized = no # 不允许其他领袖随机获得。
    leader_class = { official } # 赛斯当前作为行政官接入白夜馆。

    triggered_planet_modifier = {
        potential = { always = yes }
        pop_happiness = 0.01 # 每级领袖等级使管辖行星人口幸福度 +1%，对应赛斯作为辅助型神官的安抚能力。
        planet_amenities_add = 1 # 每级领袖等级使管辖行星舒适度 +1，对应治疗、祝福和避难点支援。
        planet_stability_add = 1 # 每级领袖等级使管辖行星稳定度 +1，表现沦陷区救援后恢复秩序的能力。
        mult = trigger:has_total_skill # 按领袖总等级放大上述管辖行星效果。
    }

    triggered_councilor_modifier = {
        potential = { exists = owner }
        country_unity_produces_mult = 0.01 # 每级领袖等级使任职议会时全国凝聚力产出 +1%，对应神官身份与圣星教会纽带。
        country_edict_fund_add = 5 # 每级领袖等级使任职议会时法令经费 +5，表现白夜馆和中央庭的临时支援调度。
        mult = trigger:has_total_skill # 按领袖总等级放大上述议会效果。
    }
}
