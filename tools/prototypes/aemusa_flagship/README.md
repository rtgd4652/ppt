# 爱缪莎旗舰隔离原型

本目录用于验证爱缪莎终局旗舰的技术可行性，不是正式 Mod 内容，也不会被 `mod/` 自动加载。

## 验证目标

- 自定义旗舰可进入舰船设计器并由玩家调整设计。
- 舰体具备反应堆、超光速引擎、推进器、传感器、作战电脑与两个光环核心槽。
- 开发事件只允许同一帝国拥有一个有效旗舰实例。
- 旗舰被真正摧毁后，可在首都星系重新生成独立编队。
- 国家局势只显示生命周期状态，不负责生成舰船。
- 故障注入与审计入口能够暴露重复实例、缺失实例和恢复失败。

## 目录边界

- `mod_skeleton/`：可手工组装为独立临时 Mod 的源码。
- `scripts/`：离线检查与组装工具，不写入正式 `mod/`。
- `reports/`：人工测试记录模板。
- `build/`、`test_output/`：本地产物，已由 `.gitignore` 排除。

## 当前明确限制

1. 当前使用原版战列舰舰艏实体作为占位模型，只验证脚本和界面，不代表任何美术决定。
2. 摧毁后恢复当前只保证使用一个仍存在的该舰种设计；当玩家保存多个同舰种设计时，脚本无法承诺恢复“最后一次安装”的精确设计。该行为必须实机验证。
3. 独立编队通过每次生成新舰队实现。引擎没有可验证的通用 `can_merge = no` 字段，因此原型不宣称已经禁止玩家手动合并。
4. 部署锁定、危机国家局势和故障注入仅用于技术验证，不是 1.0 数值或叙事实现。

## 手工安装

运行 `scripts/build_prototype.ps1` 后，将 `build/AemusaFlagshipPrototype/` 与生成的 `build/aemusa_flagship_prototype.mod` 复制到 Stellaris 用户 Mod 目录，再单独启用“爱缪莎旗舰技术原型”。测试时不要同时启用正式项目 Mod。

## 开发事件

在控制台依次使用：

```text
event aemusa_fp.1
event aemusa_fp.10
event aemusa_fp.20
```

- `.1`：启用原型并建立测试旗舰。
- `.10`：执行生命周期审计并显示结果。
- `.20`：故障注入菜单。

详细步骤见 `BUILD_AND_TEST.md`。
