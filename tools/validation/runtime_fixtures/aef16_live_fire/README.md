# 旗舰 16T 实弹对照

本夹具作为单独的测试 Mod，在独立资料目录的新银河里与开发版同时启用。游戏版本为 Cygnus 4.5.3。开局通过正式效果 `aemusa_ms_flagship_ensure_present` 生成旗舰，在一个空置 G 型星系布置一对一试场；G 型条件不可用时查找 F 型。靶舰使用原版 `NAME_Black_Earl`，仅给靶舰叠加八层 `talon_power` 以延长受击观察时间。

就绪窗口允许继续待命，或在五个游戏日后交战。保留放行前的日期档，同一份档可以在修改主炮后重放。夹具根据原生交战、摧毁和胜负回调记日志，交战开始后读取最多45个游戏日的生命、防护读数。日志前缀为 `AEF16|`。开火与命中以真实战斗画面、战斗面板和靶舰读数为据。

11月8日这份战前档位于独立测试目录下的 `save games/_987386394/2200.01.01.sav`。首次实机确认舰艏12T、舰尾4T。首轮使用25°射界，记录到旗舰伤害为零。
