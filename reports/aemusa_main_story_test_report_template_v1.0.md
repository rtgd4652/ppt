## 2. 通过标准

- `通过`：预期结果、唯一结算、状态审计和日志证据全部满足。
- `有条件通过`：主要路径成立，但存在不影响权威状态的表现问题；必须登记问题。
- `失败`：状态错误、重复结算、越级、信息泄露、不可恢复中断或关键脚本错误。
- `阻塞`：环境或未实现依赖导致无法执行；不得写成通过。
- `未测试`：尚未执行。

“窗口出现”“文字能读”或“游戏没有崩溃”不能单独作为通过结论。

- 未决定；
- 暂缓；
- 玩家拒绝；
- 授权待回应；
- 爱缪莎拒绝；
