# 爱缪莎旗舰隔离原型第八轮测试

## 测试目标

- 验证部署状态能够禁止主动移动、超空间航行、跃迁和撤退。
- 验证部署状态不会禁止旗舰在原地对进入射程的敌舰自卫开火。
- 验证解除部署后，移动、超空间航行和跃迁能力能够恢复。
- 验证部署与解除过程不破坏唯一旗舰身份、独立编队和国家账本。

## 测试前提

- 当前国家恰有一艘 `aemusa_fp_flagship` 专属舰种。
- `event aemusa_fp.10` 审计显示唯一旗舰与账本一致。
- 旗舰位于可安全接触测试敌舰的星系。

## 测试步骤

1. 执行 `event aemusa_fp.20`，选择“模拟部署锁定”。
2. 尝试下达普通移动、跨星系航行和跃迁命令。
3. 让敌对舰船进入旗舰武器射程，观察旗舰是否原地开火。
4. 若进入战斗，检查是否能够主动撤退。
5. 再次执行 `event aemusa_fp.20`，选择“解除部署锁定”。
6. 再次尝试普通移动、跨星系航行和跃迁。
7. 执行 `event aemusa_fp.10`，复核唯一身份和国家账本。
8. 检查最新 `error.log` 中是否出现原型相关错误。

## 预期结果

- 部署时不能主动移动、跨星系航行、跃迁或撤退。
- 部署时仍能原地自卫并正常使用武器与光环。
- 解除部署后航行能力全部恢复。
- 全流程只存在一艘合法旗舰，审计保持账本一致。

## 实测结果

- 旧实现部署后舰船可见性：失败；`set_disabled = yes` 使旗舰从正常舰队视图消失，等待一个月也不会自行恢复。
- 故障性质：已确认不是摧毁与延迟重构事务，因此禁止补发第二艘舰。
- 安全救援：已新增 `event aemusa_fp.12`，只解除旧版禁用状态，不生成舰船。
- 救援实测：通过；旧存档中的原舰成功恢复，未生成第二艘旗舰。
- 静态修正实机结果：舰船保持可见，但仍可移动、超空间航行和跃迁，不能单独承担部署锁定。
- 当前候选实现：保留静态修正作为位移保险，并在部署期间启动单国单舰的每日监视器，持续清除旗舰移动、跃迁及舰队行动命令。
- 首次监视器复测发现：原舰仍可见且可接受玩家命令，但 `.10` 使用 `owned_ship` 后误报缺失；已将审计、唯一性、部署监视和重构前检查统一改为 `controlled_ship`。
- `controlled_ship` 修订后复测：通过；`.10` 已正确显示唯一旗舰，未生成重复实例。
- 部署后普通移动：新实现待测试。
- 部署后超空间航行：待测试。
- 部署后跃迁：待测试。
- 部署后主动撤退：待测试。
- 部署后原地自卫：待测试。
- 解除部署后能力恢复：待测试。
- 最终唯一性审计：待测试。
- `error.log`：待测试。

## 判定边界

- 已证实 `set_disabled = yes` 会隐藏或禁用舰船；该实现已判定失败并从部署入口移除。
- 若部署期间下达移动、超空间航行或跃迁命令后，舰船仍能完成离场，则每日监视器方案不满足设计目标。
- 每日监视器只在部署 flag 存在时运行，解除部署后应在下一次事件回调中自动停止。
- 本轮只验证引擎行为，不调整正式数值、模型、武器或剧情。
