# 本地参考图片缓存

本目录用于保存视觉研究所需的本地图片副本，不属于正式 Mod 资产库。

- 除本说明文件外，本目录内容均由 `.gitignore` 排除。
- 可以保存原作截图、网络参考图和其他来源待核验素材。
- 未明确拥有再分发权限的图片不得强制加入 Git。
- 每个本地素材仍应在 `docs/art/reference_library/REFERENCE_MANIFEST.csv` 中登记来源、用途和权利状态。
- 素材转为正式资产前，必须经过原创重绘／重新建模、权利审核、美术审核与游戏规格适配，并登记到 `docs/art/ASSET_REGISTRY.csv`。

建议本地子目录：

```text
art/reference_library/
├── original_game/
├── stellaris/
├── external/
└── downloads/
```
