# Curated 确认知识层

`knowledge/curated/` 是人工审核后的知识层。它与自动采集层分离，避免下一次 Wiki 同步覆盖人工结论。

## 层级边界

- `sources/`：每个来源的身份、使用范围与局限。
- `videos/`：视频目录和人工可读索引。
- `glossary/`：核心术语的确认事实与来源。
- `reviews/`：人工审核队列。
- `decisions/`：项目编辑决定；它们不是原作事实。

## 事实审核规则

正式事实必须同时满足：

1. 有来源 ID。
2. 有可回到原页面或视频分集的链接。
3. 视频事实有起止时间码。
4. 使用原创摘要，不复制长篇台词。
5. 人工状态为“已确认”。

审核状态统一为：`未开始`、`审核中`、`已确认`、`需要特殊补充`、`不采用 / 排除`。

`mod_ready` 中的转化建议、职业建议和机制映射不是原作事实，不能直接迁入本目录。
