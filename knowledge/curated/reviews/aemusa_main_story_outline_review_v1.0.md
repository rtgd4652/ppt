## 1. 审核目的

本文逐项记录爱缪莎 1.0 主线章节总纲的人工审核结果。

审核完成前：

- 不把总纲状态改为 `approved_for_implementation_design`。
- 不编写事件、危机、局势、特殊项目或机制代码。
- 不创建专属终局天灾的正式身份、国家、舰队或数值。
- 不设计命运主宰的具体游戏效果。
- 不以旧舰船、旧巨构或现有脚本反向决定主线。

## 2. 审核状态

| 状态 | 含义 |
| --- | --- |
| `pending` | 尚未进行人工裁定 |
| `approved` | 按当前内容批准 |
| `approved_with_revision` | 方向批准，但必须完成记录中的文字修订 |
| `rejected` | 当前方案不采用，必须重新提出 |
| `deferred` | 当前保持开放，并记录在决定前禁止写死的边界 |

只有用户的明确回复可以把审核项从 `pending` 改为其他状态。助手的分析、建议和静态检查不能代替人工批准。

从 `AMR-012` 起，每一项在获得用户批准并完成记录保存后，必须在同一轮回复中直接展示下一项审核卡，直到本轮审核结束或用户要求暂停。

## 4. 逐项审核记录

### AMR-001：“序幕 + 六幕”结构及章节数量

**当前状态：**`approved`

**审核范围：**

- 一个序幕。
- 六个正式幕。
- 序章加第一至第十六章。
- 第三幕的原版天灾模块不另占固定编号；具体采用何种选择与发生规则由后续审核项决定。

**本项不审核：**

- 失落帝国战争与原版天灾阶段的固定先后。
- 原版天灾候选的选择与发生规则。
- 专属终局天灾身份与表现。
- 埃索林和里见茜是否登场。
- 结局分支和具体能力。

**结构摘要：**

1. 序幕：未翻开的牌。
2. 第一幕：文明进入因果。
3. 第二幕：旧日权威的战争。
4. 第三幕：四种终局。
5. 第四幕：终局异常调查。
6. 第五幕：未命名的专属终局天灾。
7. 第六幕：与你谈论未来。

**审核建议：**`approved_with_revision`

建议保留该结构，同时在总纲中统一写成：

> 序幕 + 六幕；序章 + 十六个编号章节；第三幕的原版天灾模块不另占固定编号，具体选择与发生规则另审。

这样可以避免把原版天灾候选路线误算成额外固定章节，也避免把“序幕”误算为六幕之一。

**人工决定：**批准“序幕 + 六幕”总体结构；结构计数统一为“序章 + 十六个编号章节”，第三幕的原版天灾模块不另占固定编号。其选择与发生规则以后续 `AMR-003` 决定为准。

**决定日期：**2026-07-25。

**所需修订：**在主线总纲总体结构处补充统一计数说明。

### AMR-002：失落帝国战争是否固定在原版天灾之前

**当前状态：**`approved`

**审核范围：**

- 第二幕是否固定为失落帝国觉醒与战争。
- 第三幕的原版天灾阶段是否只能在第二幕完成后开始。
- 这一顺序是否作为爱缪莎从观测参与进入危机尺度压力测试的叙事阶梯。

**本项不审核：**

- 具体是哪一种失落帝国。
- 失落帝国的要求、宣战理由和战争目标。
- 天堂之战是否并入本路线。
- 原版天灾候选的选择与发生规则。
- 游戏触发条件、存档兼容和后备生成方式。

**方案 A：固定在原版天灾阶段之前。**

- 优点：先用古老文明对年轻文明的政治压迫检验自主选择，再进入灭绝级危机，压力升级清楚。
- 优点：爱缪莎可以先学习把观测纳入外交、战争与公共制度，再在原版天灾中进行银河尺度压力测试。
- 风险：后续实现必须处理失落帝国已被提前消灭、天堂之战以及塞塔娜原版入口兼容。
- 边界：爱缪莎和神器科学只能影响失落帝国如何评估人类，不能成为觉醒或宣战的唯一原因。

**方案 B：只要求发生，不固定在原版天灾之前。**

- 优点：更容易尊重不同存档和《群星》沙盒中的实际发生顺序。
- 风险：第二幕到第三幕的叙事递进会变得不稳定，部分章节必须能够延后或回插。
- 风险：爱缪莎的阶段成长需要额外重排，避免已经经历终局天灾后再回到较低强度的政治压力。

**审核建议：**`approved`

建议采用方案 A，将失落帝国战争固定在原版天灾阶段之前。这里固定的是本主线的叙事门槛，不预设具体失落帝国类型，也不允许用“命运阻挠”覆盖其原有政治和意识形态动机。

**人工决定：**采用方案 A。失落帝国战争固定在原版天灾阶段之前；该阶段后来由 `AMR-003` 修订为玩家四选一且每局只发生一次。

**决定日期：**2026-07-25。

**所需修订：**将主线总纲中的该顺序从待审建议改为已批准结构；保留失落帝国原有政治动机以及后续实现兼容问题。

### AMR-003：四种原版天灾候选的选择与发生规则

**当前状态：**`approved_with_revision`

**审核范围：**

- 索林原虫、异次元入侵者、肃正协议与塞塔娜是否作为四个候选模块。
- 玩家是否在进入天灾阶段时主动选择其中一种。
- 一局游戏中有多少个原版天灾进入爱缪莎主线。
- 原版天灾结束后何时进入下一阶段。

**本项不审核：**

- 四个候选模块各自承担的具体主题。
- 每种天灾的事件接入和触发方式。
- 天灾失败、银河被其他势力拯救或玩家未取得最后一击时的机制。
- 玩家选择后的具体提示、反悔边界和存档状态。

**人工决定：**

- 四种原版终局天灾作为互斥候选模块。
- 玩家在进入天灾阶段时自行选择一种。
- 每局主线只出现被选择的一种原版天灾，并且只发生一次。
- 战胜或完成该天灾路线后，主线进入终局异常调查阶段。
- 爱缪莎从这一原版天灾阶段开始尝试主动干涉命运。

**决定日期：**2026-07-25。

**所需修订：**

- 删除“四种天灾全部发生”“按完成数量推进”和“四灾共同复盘”结构。
- 将第三幕改为“四种候选终局”，每局只接入一个候选模块。
- 将第七章改为选定天灾后的共同收束章节。
- 在 `AMR-005` 审核中重新校准成长阶段：天灾之前以观测、建议和现实行动为主；主动命运干涉从天灾阶段开始。
- 同步叙事约束、角色状态和项目编辑决定。

### AMR-004：四个原版天灾候选模块的主题命题

**当前状态：**`approved`

**审核范围：**

玩家虽然每局只选择一种原版天灾，但四种候选路线都需要拥有独立且符合原版的主题：

| 候选天灾 | 当前主题命题 | 爱缪莎在该路线面对的问题 |
| --- | --- | --- |
| 索林原虫 | 生存算术与具体生命的价值 | 预测可以优化救援，但能否因此放弃低概率生存者？ |
| 异次元入侵者 | 未知规则与模型失效 | 当既有观测无法解释敌人时，是否仍能承认未知并行动？ |
| 肃正协议 | 预防性灭绝与不可纠错判断 | 是否能以尚未发生的极端风险为由取消所有人的未来？ |
| 塞塔娜 | 消除痛苦与消除主体 | 通过抹除意识来终结痛苦，是否仍能称为拯救？ |

**共同边界：**

- 四条路线在剧情长度和主线资格上等价，但不要求敌军数值完全相同。
- 每条路线保留原版身份、动机和基本叙事结构。
- 被选择的天灾不是专属终局天灾的部下、前身或召唤条件。
- 四条路线都必须能承载爱缪莎第一次主动干涉命运，而不能依赖其他三条路线提供前置认识。
- 完成任意一条路线都可以进入第七章和下一阶段。

**审核建议：**`approved`

建议保留上述四个主题。它们分别检验生命价值、认识边界、预防性统治和强制救赎，能够在只选择一种天灾的情况下形成不同的主线体验。

**人工决定：**批准当前四条候选路线的主题命题与共同边界。

**决定日期：**2026-07-25。

**所需修订：**

- 在主线总纲中将四条候选路线标记为 `AMR-004` 已批准主题。
- 四条路线后续可以补充场景、角色职责和实现方式，但不得改变本项锁定的核心命题；如需改变，必须重新开启人工审核。

### AMR-005：爱缪莎五阶段成长结构

**当前状态：**`approved_with_revision`

**审核范围：**

- 爱缪莎从开局有限观测到终局命运主宰的五阶段顺序。
- 每个阶段对应的章节范围和叙事职责。
- `AMR-003` 已批准的“主动命运干涉从玩家选择的原版天灾开始”如何进入成长结构。
- “文明共同选择”应当在首次主动干涉之前还是之后形成。

**本项不审核：**

- 各阶段对应的 trait、等级、资源、变量或数值。
- 主动干涉的具体事件效果和命运主宰最终能力上限。
- 30 级的精确触发条件。
- 失败、暂停、拒绝转变和多结局机制。

**方案 A：先学会参与文明选择，再开始主动干涉。**

| 阶段 | 建议章节 | 核心变化 |
| --- | --- | --- |
| 1. 有限观测者 | 序章 | 承认预言边界，不把未知当作答案 |
| 2. 银河因果取样者 | 第一至第三章 | 以观测、建议和普通现实行动参与决策，接受模型被现实修正 |
| 3. 文明共同选择的参与者 | 第四至第六章 | 在失落帝国战争中理解制度、社会、舰队和个人共同承担未来 |
| 4. 承担代价的局部干涉者 | 玩家选择的原版天灾至专属终局天灾 | 第一次主动干涉命运；确认范围、条件、次生代价与共同授权 |
| 5. 命运主宰 | 第十四至第十六章与尾声 | 在危机、真相边界和玩家沟通后，自愿承担更大尺度责任 |

优点：

- 严格符合 `AMR-003`：天灾前不发生主动命运干涉。
- 爱缪莎先理解制度与共同责任，再获得更危险的干涉能力，降低“先有力量、后补伦理”的突兀感。
- 失落帝国篇和原版天灾篇各自拥有明确且不重复的成长职责。

需要注意：

- 第三阶段表示参与文明共同选择，不代表她已经可以替文明决定未来。
- 第四阶段从一种被选择的原版天灾开始，并延续至专属终局天灾；不能把一次成功写成无限改写能力。
- 第五阶段必须经过爱缪莎自主同意，不能由玩家按钮或 30 级自动完成。

**方案 B：保留旧顺序“局部干涉 → 文明共同选择”。**

- 必须把失落帝国篇中的共同协作解释为尚未形成的前置认识，并让第四阶段直到原版天灾才正式开始。
- 风险是章节文本会反复区分“已经参与共同选择”和“尚未进入文明共同选择阶段”，容易造成概念混乱。

**方案 C：合并局部干涉与文明共同选择。**

- 可以减少阶段术语，但需要另造一个第五阶段填补命运主宰之前的位置。
- 风险是削弱“个人能力必须受文明共同选择约束”这一主线核心。

**审核建议：**`approved_with_revision`

建议采用方案 A，并据此重排总纲与《1.0 叙事约束》中的五阶段顺序。该方案只重排叙事成长，不提前批准任何能力或机制。

**人工决定：**批准方案 A；经 `AMR-014` 后续时间点修订，五阶段顺序固定为“有限观测者 → 银河因果取样者 → 文明共同选择的参与者 → 承担代价的局部干涉者 → 终局真相与授权抉择”。“命运主宰”是第五阶段结束后的最终身份。

**决定日期：**2026-07-25。

**所需修订：**

- 重排主线总纲中的成长流程图、阶段表和幕结构对应关系。
- 将失落帝国篇明确为“文明共同选择的参与者”阶段。
- 将玩家选择的原版天灾明确为“承担代价的局部干涉者”起点。
- 同步《1.0 叙事约束》、项目状态、角色状态和项目编辑决定。
- 保持 30 级、玩家按钮和旧版实现不能提前解锁主动干涉或命运主宰。

### AMR-006：安托涅瓦、晏华、玩家与爱缪莎的职责

**当前状态：**`approved_with_revision`

**审核范围：**

- 四个核心参与方在爱缪莎主线中的权力、责任和叙事职责。
- 安托涅瓦的中央庭核心领袖定位是否得到保留。
- 晏华和爱缪莎是否保持不同方向的辅助定位。

### AMR-007：埃索林作为后期见证者／顾问的叙事功能

**当前状态：**`approved`

**审核范围：**

- 埃索林是否作为爱缪莎 1.0 主线后期的重要角色登场。
- 她在主线中承担的是“边界见证者”“有限顾问”还是更强的解释者职责。
- 她如何帮助区分世界维护、文明治理与命运干涉。
- 她在原版天灾之后、专属终局天灾之前及其展开期间可以提供何种帮助。
- 她的存在是否仍能保留爱缪莎、指挥使／玩家与中央庭的行动主体地位。

**现有事实与项目边界：**

- 项目已人工确认：埃索林是塞拉菲姆的老师；塞拉菲姆放弃神位后，埃索林承担世界管理职责。
- “承担世界管理职责”不等于全知、全能、完整继承神位或拥有中央庭与人类文明的统治权。
- 世界维护与命运干涉是不同的责任领域；“世界之主”与爱缪莎终局的“命运主宰”不是同一身份。
- 埃索林在 Stellaris 开局时代的具体状态、管理职责的性质、知识范围和接触方式仍未定稿。
- 以上边界分别由项目编辑决定、宇宙论、事实矩阵和灾后时间线约束；本项不能越过这些上游资料直接关闭开放谜团。

**本项不审核：**

- 埃索林在 Stellaris 开局时是否仍是、已经是或不再是当前世界管理者。
- 她承担的是继承、托管、协作还是其他形式的世界管理职责。
- 她如何与中央庭和指挥使建立联系，以及具体以何种形象、地点或通讯形式登场。
- 她能确认多少箱庭、塞拉菲姆、世界之主、玩家层和终局异常的具体事实。
- 她与里见茜是否同场，以及里见茜在本主线中的身份阶段。
- 具体对白、事件脚本、任务步骤、奖励、机制和战斗功能。

**方案 A：后期重要的边界见证者／有限顾问（推荐）**

- 埃索林在玩家选择并战胜一次原版天灾、终局异常开始显现后进入主线后期。
- 她在第九章“边界的见证者”承担第一次完整叙事职责，并可在专属天灾与终局真相阶段继续提供有限证言。
- 她只依据自身能够被后续来源和人工审核支持的经历，说明世界维护与命运干涉并非同一种职责。
- 她可以提出工作假说、风险警告、观察边界与停止条件，但必须区分“亲历事实”“当前推断”和“仍未知内容”。
- 她提醒爱缪莎：能够触及未来规则，不等于拥有所有生命、所有选择或整个文明。
- 她能够识别爱缪莎正在接近一种不同于世界之主的责任位置，但不能替爱缪莎定义“命运主宰”，也不能宣布其必然完成转变。
- 她不直接解决专属天灾；世界维护层的知识或能力不能替代玩家文明的科研、外交、制度和舰队行动。

**方案 A 的明确禁止项：**

- 不把埃索林写成幕后黑手、专属天灾制造者或所有危机的共同源头。
- 不把埃索林写成全知讲解员，用一段对白解释黑门、箱庭、轮回、玩家和银河命运的统一真相。
- 不让埃索林向中央庭下令、取代安托涅瓦的国家领导职责，或以世界管理权限否决文明制度。
- 不让埃索林取代晏华完成现实证据审查，取代指挥使／玩家作出路线选择，或取代爱缪莎承担成长与终局决定。
- 不因她曾承担世界管理职责，就默认她能随意改写世界、复活生命、消除天灾或支配自由意志。
- 不在 `AMR-008`、`AMR-012` 和后续来源校订前写死她的当前身份、权限规模与完整知识。

**方案 B：仅保留一次性证言或资料锚点**

- 埃索林不成为后期持续参与者，只通过一次通讯、档案或证言帮助建立“世界维护不等于命运干涉”的概念。
- 优点是对尚未完成的身份与时间线依赖较少。
- 代价是无法兑现“埃索林作为第一条大型主线后期重要角色”的既有项目构想，也会削弱第九章与后续终局章节之间的人物连续性。

**方案 C：世界真相解释者或终局解决者（不建议）**

- 该方案会提前关闭箱庭、世界之主、玩家层和命运规则等开放谜团，削弱爱缪莎与玩家文明的主体性，并与现有宇宙论硬边界冲突。

**审核建议：**批准方案 A。

方案 A 最符合埃索林“后期重要角色”的既有方向，同时把她的作用限制在边界辨析、有限证言与风险提醒。它既能让世界管理体系与命运主宰主线发生有意义的接触，又不会把埃索林写成全知神明或终局解题工具。

**人工决定：**批准方案 A：

- 将埃索林锁定为爱缪莎 1.0 主线后期的重要“边界见证者／有限顾问”。

- 她可以提供有限证言、工作假说、风险警告和责任边界说明，但不得成为全知解释者或终局解决者。
- 她必须帮助明确“世界维护不等于命运干涉”“世界之主不等于命运主宰”。
- 方案 A 的全部明确禁止项同时生效。

**决定日期：**2026-07-26。

**所需修订：**

#### A1. 最低身份

  - 对方自称“埃索林”。

  - 埃索林是塞拉菲姆的老师。
  - 塞拉菲姆曾是世界之主。
  - 塞拉菲姆后来放弃神位、失去相关记忆并成为神器使里见茜。
  - 埃索林与世界管理职责的真实关系。

- 每次回应都必须保留通信受限、信息不完整或只能说明责任边界的条件。
- 是否在未来版本安排实体会面、常驻关系或更完整身份揭示，必须另行审核。

**方案 B：现在锁定“现任世界管理者”并安排实体会面**

- 明确埃索林在 Stellaris 后期仍是当前世界管理者，并让她亲自进入中央庭或人类控制空间。
- 优点是角色登场直接、戏剧性强，也便于展示完整视觉。
- 代价是必须立即确定她的时间线、所在地、权限、进入银河的方式和对人类政治的边界；这些内容目前缺少足够校订，会把多个开放谜团提前变成既成事实。

**方案 C：只通过档案、记录或代理出现**

### AMR-010：专属终局天灾在总纲中只保留功能占位

**当前状态：**`approved`

**审核范围：**

- 当前章节总纲是否只锁定专属终局天灾的叙事职责，而不提前确定其正式身份与表现。

- 该阶段解锁爱缪莎的专属舰船和专属巨构。
- 在之后对抗本 Mod 专属终局天灾的过程中，爱缪莎必须发挥不可或缺的作用。

**本项对用户补充的最低解释：**

- “变得更加强大”首先表示她完成第一次主动命运干涉后进入更高能力阶段；具体 trait、数值、技能和表现不在本项确定。

- “不可或缺”表示专属终局天灾的完整成功路线必须依赖爱缪莎经共同授权实施的命运干涉，不能把她降为旁观者或普通加成来源。
- “不可或缺”不表示爱缪莎可以单独获胜。文明的外交、科研、制度、舰队、盟友和现实行动同样不可替代。
- 完成原版天灾与解锁两项资产不自动授予“命运主宰”身份。

**本项不审核：**

- 专属终局天灾的名称、身份、来源、动机、阵营、视觉和具体机制。
- 专属终局天灾是否具有意识，是否认识爱缪莎或玩家。
- 专属舰船和巨构的正式名称、造型、功能、数值与制作方案。

- 战胜专属天灾后允许揭示的宇宙真相层级。
- “命运是否具有独立意志”。

**方案 A：批准经用户补充后的功能占位（推荐）**

- 总纲保留专属终局天灾的身份与表现空位。

  2. 爱缪莎专属舰船与专属巨构在此时解锁。

**方案 B：在总纲中立即确定专属天灾的最低身份**

**方案 C：立即完成专属天灾、舰船和巨构的整体设计**

- 专属终局天灾的身份、动机、主体性和宇宙论来源尚未确定。

**本项不审核：**

- “命运”是否拥有独立人格、意志或目的；该问题由 `AMR-013` 审核。
- 命运主宰的具体能力和最低边界；该问题由 `AMR-014` 审核。
- 专属终局天灾的正式身份、来源、视觉、机制和数值。
- 玩家在现实世界中的生理身份、姓名或现实经历。
- 箱庭、银河、黑门、神器、世界之主、世界重构和命运规则的完整统一理论。
- 具体对白、事件脚本、镜头、奖励与 UI 表现。

**方案 A：分层揭示，确认连续关系但保留本体论（推荐）**

1. **文明可验证层**
   - 中央庭能够确认：文明选择、集体行动与爱缪莎的观测／有限干涉，会对未来分布和现实代价产生可测量的影响。
   - 专属终局天灾暴露了真实存在的世界边界或命运规则异常，但其完整来源仍未被解释。
   - 世界维护、未来观测和命运干涉是不同职责，任何一方都不能被简单等同。

2. **爱缪莎与指挥使／玩家的终局互认层**
   - 爱缪莎确认：无尽七日轮回中的指挥使与《群星》时代的玩家，是同一位跨越不同世界状态、持续作出选择并承担结果的存在。
   - 这一连续关系足以支撑她与玩家的最终沟通，以及她自主选择成为命运主宰。
   - 1.0 不解释这种连续关系究竟属于外部操作者、灵魂延续、世界重构保留、观察者效应或其他机制。

3. **角色知情层**
   - 该玩家层真相首先只由爱缪莎与指挥使／玩家直接确认。
   - 安托涅瓦、晏华和中央庭可以验证爱缪莎已经跨越新的认知边界及其现实后果，但不会自动获得完整的玩家层认知。
   - 埃索林可以证明部分世界边界和维护规则，却不能凭个人证言完成整个本体论解释。
   - 是否、何时以及以何种形式向中央庭公开更深层真相，留给后续剧情决定。

4. **继续开放层**
   - 指挥使—玩家连续关系的精确机制。
   - 七日轮回终止和世界重构的完整因果。
   - 箱庭与《群星》银河的空间和本体层级。
   - 黑门、神器、世界之主、世界重构和命运规则是否具有共同来源。
   - 命运修正规律的起源与完整作用尺度；`AMR-013` 后续已确认命运本身没有独立意志。
   - 专属终局天灾的真实身份与来源。
   - 命运主宰与其他宇宙规律交叉时的具体运用；`AMR-014` 后续已确认其在命运规律领域拥有完整主宰权。

该方案明确：爱缪莎知道的是能够改变她与玩家关系、并支撑终局决定的关键真相，而不是突然获得关于宇宙一切问题的全知。

**方案 B：完整公开玩家层本体**

- 1.0 终局明确说明玩家是世界外部操作者，并解释指挥使、轮回、世界重构与《群星》时代的全部关系。
- 优点是元叙事冲击直接。
- 风险是一次关闭过多开放谜团，削弱中央庭制度、文明行动和后续世界真相主线，也容易把其他人物降格为只受玩家操纵的对象。

**方案 C：只确认因果科学，不确认指挥使—玩家连续关系**

- 终局只确认选择和观测会改变未来分布，不触及玩家层。
- 优点是世界观最保守。
- 风险是直接削弱已经确认的终局设定，无法兑现爱缪莎识别过去与现在玩家连续关系的核心情感回报。

**方案 D：爱缪莎独自获得完整真相，但无法说明**

- 爱缪莎知道所有答案，但其他角色和玩家只能接受她的结论。
- 优点是保持表面神秘。
- 风险是把爱缪莎写成不可验证的全知者，也会让终局沟通失去可理解内容，不建议采用。

**审核建议：**批准方案 A。

方案 A 同时兑现“爱缪莎最终认出过去与现在的玩家”这一已经确认的核心设定，并保留其精确机制和完整宇宙论供后续展开。它允许终局具有明确情感与叙事回报，又不会把命运主宰写成全知神明。

**人工决定：**批准方案 A。

具体边界如下：

- 中央庭只能确认文明选择、集体行动以及爱缪莎的有限观测／干涉对未来分布产生了可测量影响。
- 爱缪莎在最终阶段确认：无尽七日轮回中的指挥使与《群星》时代玩家，是同一位跨越不同世界状态、持续作出选择并承担结果的存在。
- 玩家层真相首先只由爱缪莎与指挥使／玩家直接确认；安托涅瓦、晏华和中央庭不会因此自动获得完整的玩家层认知。
- 埃索林只能提供世界边界与维护规则的有限证据，不能证明完整宇宙本体论。
- 指挥使—玩家连续关系的精确机制、轮回终止与重构因果、箱庭与银河层级、各异常是否同源、命运是否具有意志、专属终局天灾来源和命运主宰能力上限继续保持开放。
- 爱缪莎获得的是足以支撑最终沟通和自主决定的关键真相，不是关于宇宙一切问题的全知。

**决定日期：**2026-07-27。

**批准后需要同步：**

- 建立或更新 1.0 真相揭示矩阵，明确文明可验证层、角色知情层和开放谜团层。
- 同步主线总纲第十四章及终局通讯边界。
- 同步《1.0 叙事约束》、宇宙论、事实／正史／开放谜团矩阵和爱缪莎角色状态档案。
- 登记“爱缪莎知道关键真相不等于理解全部宇宙本体论”的明确约束。
- 将当前审核项推进至 `AMR-013`。

### AMR-013：命运是否具有独立意志

**当前状态：**`approved_with_revision`

**审核范围：**

- 1.0 是否明确回答“宇宙命运”具有独立意识、人格、目的或敌意。
- 爱缪莎开始主动干涉命运后接连出现的阻力，应被描述为客观因果反作用、角色解释，还是有意志主体的行动。
- 专属终局天灾能否被直接等同为“命运意志”。
- 角色、旁白、系统文本、美术与机制分别允许使用何种措辞，避免未经审核就通过表现暗中定论。

**已批准的上游约束：**

- 危机接连发生，不等于已经证明宇宙命运具有独立人格或由同一主体操纵。
- 失落帝国战争具有自身政治与文明动机。
- 四种原版天灾保留原版身份和基本动机，每局由玩家选择一种且只发生一次。
- `AMR-012` 已确认指挥使—玩家连续关系，同时保留专属天灾来源与统一宇宙论开放；命运是否有意志由本项裁定。
- 专属终局天灾的正式身份、动机和主体性必须在独立联合设计中审核。

**本项不审核：**

- 专属终局天灾究竟是什么。
- 命运主宰的具体能力与限制。
- 黑门、神器、箱庭、世界之主和命运是否同源。
- 危机的具体触发器、数值、舰队、视觉和对白。
- 未来版本是否最终回答命运意志问题。

**方案 A：1.0 保持本体开放，只确认存在可观察的命运阻力（推荐）**

- 1.0 可以确认：爱缪莎扩大观测并主动干涉后，会遭遇可重复观察的因果收敛、概率反弹、代价转移或其他“命运阻力”。
- “命运在阻挠我们”“宇宙作出回应”等说法可以作为角色语言或工作假说出现，但不得由全知旁白和系统百科认证为客观人格。
- 失落帝国和原版天灾继续拥有各自原因，不能被改写成命运意志控制的傀儡。
- 专属终局天灾可以提供更强证据并表现出主体性，但在独立设计完成前，不能自动被定义为命运本身、命运化身或命运派出的执行者。
- 终局允许爱缪莎承认自己还无法确定：她面对的是无意识规则、复杂因果、某种高维信息结构，还是具有意志的存在。
- 后续版本只有在新增可追溯证据并完成新的人工审核后，才能关闭该谜团。

**方案 B：1.0 明确命运具有敌对独立意志**

- 将逐级危机和专属终局天灾统一解释为宇宙命运对爱缪莎的主动阻挠。
- 优点是反派清晰、冲突直观。
- 风险是抹去失落帝国与原版天灾自身动机，提前锁死专属天灾身份，并把复杂的命运主题简化为击败一个人格化敌人。

**方案 C：1.0 明确命运没有意志**

- 将全部现象定义为无意识概率、因果和高维信息规律。
- 优点是科学模型明确。
- 风险是同样过早关闭谜团，也会限制专属终局天灾和未来宇宙论设计。

**方案 D：文本保持开放，但美术和机制明确暗示一个人格化命运**

- 对白不作结论，却使用统一面孔、王座、命令语气、阵营标识或“命运化身”机制名称。
- 这种做法会通过表现层事实性地批准方案 B，只留下文字上的表面模糊，不建议采用。

**审核建议：**批准方案 A。

方案 A 允许主线真实呈现“宇宙命运的阻挠”，但把“阻力存在”与“阻力具有独立人格”严格分开。这样既保留爱缪莎成长所需的压力，也保护失落帝国、原版天灾和专属终局天灾各自的叙事主体性。

**人工决定：**批准方案 C 的用户修订版。

正式定义如下：

- 命运没有人格、意识、情绪、目的或敌意。
- 命运是一套运行规律；当个体或集体造成足以脱离既有命运约束的“不和谐”时，规律会产生修正。
- 这种修正可以表现为因果收敛、概率反弹、代价转移、机会关闭或其他可观察的阻力。
- 修正不是某个主体在判断谁有罪，也不是命运主动选择敌人；它是规律对超脱趋势产生的非人格化反馈。
- 爱缪莎遭遇的“命运阻挠”，是她和文明逐步接近、干涉乃至试图超脱既有命运边界后触发的规律修正。
- 失落帝国和原版天灾仍保留自身动机与主体性；命运规律可以改变条件和收敛压力，但不能把它们降格为傀儡。
- 专属终局天灾不得被写成“命运本人”“命运化身”或奉命行动的执行者；它与命运修正规律的具体关系仍须在独立联合设计中确定。

**决定日期：**2026-07-27。

**批准后需要同步：**

- 在宇宙论、事实矩阵、1.0 真相揭示矩阵和叙事约束中登记“阻力可确认、意志保持开放”。
- 同步主线总纲中失落帝国、原版天灾、专属终局天灾和终局对白的措辞边界。
- 为专属终局天灾联合设计增加“不得预设为命运化身”的闸门。
- 将当前审核项推进至 `AMR-014`。

### AMR-014：下一阶段先锁定命运主宰最低能力边界

**当前状态：**`approved_with_revision`

**审核范围：**

- 爱缪莎成为命运主宰后，叙事上至少能够做什么。
- “主宰”如何区别于更强的未来观测，同时不变成全知、全能或免费改写结果。
- 她如何识别、承受和干涉命运的非人格化修正规律。
- 她的能力与玩家选择、中央庭制度、文明行动、神器科学和现实代价之间的关系。
- 哪些能力可以作为 1.0 终局后的稳定身份基线，哪些仍须留待机制与数值设计。

**已批准的上游约束：**

- 命运没有意志，而是修正“不和谐”、阻止个体或集体超脱既有命运约束的运行规律。
- 爱缪莎从有限观测逐步走向主动干涉，并在文明共同参与、危机挑战和终局沟通后自主成为命运主宰。
- 她不能单独替文明获胜，也不能替安托涅瓦、中央庭、指挥使或银河众生决定全部未来。
- 命运主宰不是世界之主、中央庭统治者、宇宙创造者或全知者。
- 玩家按钮不能直接授予该身份。

**本项不审核：**

- 具体 Stellaris 数值、冷却、资源、按钮、科技、部件或事件效果。
- 最终专属舰船、专属巨构和终局立绘的正式设计。
- 命运修正规律的起源与完整宇宙尺度。
- 爱缪莎在 1.0 之后继续成长时可能达到的最高能力。
- 其他神器使、世界之主或专属终局天灾的能力上限。

**方案 A：有限的命运规则接口与可能性守护者（推荐）**

成为命运主宰后，爱缪莎至少能够：

1. **识别修正**
   - 在银河和文明相关范围内识别命运修正正在形成的征兆、压力方向和主要代价路径。
   - 她看到的是有条件的可能性与收敛趋势，不是唯一确定未来。

2. **锚定可能性**
   - 在原本会被命运修正关闭的未来中，暂时保持少量可实现路径开放。
   - 锚定不等于保证成功；文明仍必须通过科研、外交、制度、舰队和具体行动走完路径。

3. **偏转或延缓修正**
   - 在明确对象、范围、条件和责任承担者后，有限地偏转、延缓或重新分配命运修正。
   - 她不能永久删除所有代价，只能为文明争取行动窗口或改变代价落点。

4. **建立因果保护窗口**
   - 在关键行动中暂时保护已经由文明共同选择的方案，使其不会在开始前就被修正规律完全封死。
   - 保护窗口结束后，结果仍取决于现实行动，并可能产生新的修正压力。

5. **与指挥使共同校验**
   - 她可以利用已经确认的指挥使—玩家连续关系，辨认跨世界状态仍然持续的选择与责任。
   - 玩家提供选择和文明行动，爱缪莎提供观测、警告和有限干涉；双方都不能替另一方完成决定。

**最低限制：**

- 不能自由改写过去、撤销已经发生的历史或无条件复活死者。
- 不能保证战争、科研、外交或危机必然成功。
- 不能控制思想、取消自由意志或替其他人作出选择。
- 不能凭个人能力直接消灭舰队、天灾或文明问题。
- 不能同时观察全部未来、全部地点和全部主体。
- 不能永久让整个人类文明脱离一切命运修正。
- 每次干涉必须具有对象、范围、条件、代价和现实执行方。

该方案锁定的是 1.0 终局后的最低稳定能力，不提前决定她未来能够达到的最高上限。

**方案 B：完整支配命运规律**

- 爱缪莎可以自由决定未来、取消代价、改写过去并让文明永久脱离命运修正。
- 优点是“主宰”字面力量极强。
- 风险是立即破坏危机、选择、死亡、制度和文明行动的意义，也与已经批准的非全知、非单独获胜边界冲突。

**方案 C：只提升观测，不允许实际干涉**

- 命运主宰只比原来看到更多未来，不能锚定、偏转、延缓或保护任何路径。
- 优点是最容易控制叙事风险。
- 风险是称号缺少实质变化，也无法兑现主线中“从观测走向主动干涉”的成长。

**方案 D：仅让爱缪莎本人免受命运修正**

- 她可以个人超脱，但无法帮助文明建立任何行动窗口。
- 优点是角色中心明确。
- 风险是把文明主线缩成个人成神，也与她作为中央庭辅助者和文明共同承担者的定位冲突。

**审核建议：**批准方案 A。

方案 A 让“命运主宰”拥有明确而强大的实质：她可以识别修正、锚定可能性、偏转或延缓修正，并为共同选择建立因果保护窗口；但结果仍必须由文明在现实中争取。它既兑现终局成长，也保留后续剧情、游戏挑战和其他角色的意义。

**人工决定：**批准方案 B，并采用用户补充理由：爱缪莎获得玩家授权。

正式边界如下：

- 玩家在终局确认指挥使—玩家连续关系后，可以向爱缪莎授予对命运规律的完整权限。
- 玩家授权是完整主宰权成立的必要条件，但不是强制授神按钮；爱缪莎必须在理解真相、责任与后果后自主接受。
- 授权与自主接受同时成立后，爱缪莎获得命运规律领域的完整主宰权：
  - 可以决定、改写和重新开放未来路径。
  - 可以取消、覆盖或重新编排命运修正。
  - 可以处理由命运规律封闭的过去结果及其延续影响。
  - 可以允许特定个体、集体乃至文明超脱原有命运约束。
- 该完整权限只直接定义“命运规律”领域，不自动等于世界之主权限、中央庭统治权、思想控制、对所有物质规律的全能，或对全部宇宙知识的全知。
- 玩家授权不能抹去爱缪莎的人格和自主性，也不能令玩家代替她承担命运主宰身份。
- 1.0 需要表现获得完整权能之前的选择、牺牲与文明行动；终局后的完整主宰权不能倒写为她在成长过程中早已可以无代价解决所有危机。
- 玩家授权和爱缪莎自主接受发生在第五阶段全部剧情结束后的最终收束点；完整主宰权成立即标志 1.0 主线结束，不参与本主线任何战争、危机、路线修复或解题。

**决定日期：**2026-07-27。

**批准后需要同步：**

- 建立命运主宰能力边界文档，区分最低稳定能力、永久禁止能力和未来待审核上限。
- 同步主线总纲终局、宇宙论、叙事约束、爱缪莎角色状态及项目编辑决定。
- 后续专属舰船、巨构、事件和机制只能在该边界内提出方案。
- 将当前审核项推进至 `AMR-015`。

### AMR-015：路线暂停与修复机制的叙事边界

**当前状态：**`pending`

**审核范围：**

- 玩家是否可以在爱缪莎主线的章节之间暂停推进。
- 错过条件、作出错误判断或暂时无法承担代价后，是否允许通过后续行动修复路线。
- 暂停和修复是否会抹除已经发生的历史、牺牲、关系变化与危机后果。
- 原版天灾选择、专属终局天灾和终局授权等关键节点，哪些可以等待，哪些不能被回滚或重复选择。
- 如何避免长篇主线因一次误点、界面关闭或短期资源不足而永久损坏。

**已批准的上游约束：**

- 危机和成长必须真实发生，不能通过等级、按钮或调试状态直接跳过。
- 玩家每局只选择一种原版天灾；未选择的三种不进入该局主线。
- 爱缪莎在终局经玩家授权并自主接受后获得命运领域完整主宰权，但该权能不能倒写消除成长过程。
- 完整主宰权只在第五阶段全部剧情结束后的最后收束点成立，本项讨论的暂停与修复全部发生在授权之前。
- 主线需要保留选择、牺牲、文明行动和后果承担的意义。

**本项不审核：**

- 哪些具体事件会失败。
- 失败惩罚、资源数值、冷却时间和 UI。
- 永久失败、玩家拒绝授权和爱缪莎拒绝接受的最终出口；该内容由 `AMR-016` 审核。
- 多种成功结局语气；该内容由 `AMR-017` 审核。
- 游戏内“暂停时间”功能。

**方案 A：章节间可暂停，错误可修复，但历史不可擦除（推荐）**

- 主线在重大阶段之间允许无限期暂停，不因玩家处理战争、经济、外交或其他内容而自动失败。
- 已开始的即时危机仍按自身规则运行；“路线暂停”不冻结原版战争、天灾或银河时间。
- 因资源不足、调查遗漏、关系受损、判断失误或暂时拒绝承担代价而中断时，可以通过后续特殊项目、沟通、补偿、证据收集或文明行动重新取得推进资格。
- 修复建立新的历史状态，不回滚旧事件：
  - 已发生的损失仍然发生。
  - 已公开的信息不能假装从未公开。
  - 角色记得玩家此前的决定。
  - 修复后的对白、信任和代价可以与一次成功路线不同。
- 玩家选定一种原版天灾后不能更换为另一种，也不能重复完成多种候选来叠加成长。
- 专属终局天灾开始前可以等待准备；一旦正式开始，其暂停和失败边界由天灾联合设计决定，不能用普通章节暂停绕过。
- 终局玩家授权和爱缪莎自主接受必须在实际终局沟通中确认，不能由自动修复代替。

**方案 B：全程不可暂停，关键错误永久关闭路线**

- 主线按阶段持续推进，错过窗口或作出错误选择即永久失败。
- 优点是紧迫感强。
- 风险是大型 Mod 中容易因玩家忙于其他银河事务、界面误操作或机制不透明而失去整条 1.0 核心主线。

**方案 C：所有节点都可回滚并重新选择**

- 玩家可以重置章节、改选原版天灾、撤销牺牲并恢复到最佳结果。
- 优点是最宽容。
- 风险是让历史、责任和命运主题失去意义，也容易造成重复奖励、状态冲突和存档问题。

**方案 D：路线永不失败并自动修复**

- 无论玩家如何选择，系统最终都会把路线恢复到完整成功状态。
- 优点是确保所有玩家看到终局。
- 风险是选择只剩表面差异，爱缪莎和文明不再需要真正承担任何后果。

**审核建议：**批准方案 A。

方案 A 把“可继续游玩”与“后果真实存在”分开：玩家不会因一次操作失去大型主线，但修复是新的行动和责任，而不是读档式擦除历史。它也能显著降低长期 Stellaris 战役中的任务丢失与状态锁死风险。

**人工决定：**等待审核。

**决定日期：**待定。

**批准后需要同步：**

- 同步主线总纲的章节状态、原版天灾选择锁、专属终局天灾准备阶段与终局通讯边界。
- 在叙事约束中登记“章节可暂停、历史不可擦除、关键选择不可重选”。
- 为后续事件设计建立最低状态模型：`active`、`paused`、`repairable`、`resumed` 与不可回滚关键选择。
- 将当前审核项推进至 `AMR-016`。
