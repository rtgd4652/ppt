# 4. 一致性结论

## 4.1 世界与文明

- 七日轮回已经结束，人类重新进入连续历史。
- 黑门灾难既是文明创伤，也是制度、科学与神器研究转型的历史起点。
- 中央庭是灾后人类文明治理核心，安托涅瓦是核心领袖；中央庭仍是制度而非个人政权。
- 人类在 Stellaris 开局时只是年轻星际文明，不能因神器独有性被写成银河天选霸主。

## 4.2 神器与宇宙论

- 神器是人类独有、可研究但尚未被完全理解的异常现象，不是魔法、灵能或普通量产技术。
- 黑门、异界、箱庭、世界之主与命运规则已经形成足以约束 1.0 的分层框架。
- 命运没有人格意志；修正是规律对不协调状态产生的非人格化收敛反馈。
- 世界更替、指挥使跨世界连续和世界之主权限本质仍属开放谜团，不阻塞后续设计。

## 4.3 角色与组织

- 十名锁定神器使均已具备当前背景设计层所需的原作资料、转化摘要、标准档案、状态档案和最低时间连续性。
- 八名拥有个人支线来源的角色已经完成整名角色人工审核；相关结论已进入证据链，但不会自动变成职业、trait 或玩法效果。
- 安托涅瓦和安没有个人支线，不以缺少独立页面判定资料不完整。
- 白夜馆仍只是神器使招募、联络、档案和管理入口，不进入中央庭政治、银河外交或主线因果。

## 4.4 爱缪莎 1.0 主线

- 主线保持“文明影响扩大 → 失落帝国战争 → 玩家选择的一种原版天灾 → 专属终局天灾 → 最终沟通与授权”的既定顺序。
- 爱缪莎在危机期间尚未获得完整授权；她只能逐步从观测走向有限干涉。
- 战胜专属危机后，她才确认当前世界与旧轮回世界不是同一世界，并确认指挥使／玩家跨世界连续。
- 主线最后，玩家明确授权且爱缪莎自主接受后，她才成为命运主宰；该身份不等于世界之主、宇宙全知或中央庭统治权。

# 5. 非阻塞开放项

以下内容继续保持开放，不得为了进入下一阶段而自行补写：

1. 七日轮回、世界重构与世界更替的完整本体机制。
2. 指挥使／玩家跨世界连续的具体原理。
3. 世界之主完整权限来源，以及埃索林和塞拉菲姆历史链的未公开部分。
4. 中央庭精确宪制名称、部门全表、选举和继任程序。
5. 灾后至星际时代的精确公历年份及十名角色寿命机制。
6. 专属危机、旗舰和巨构的正式名称、最终美术、数值与实现方案。
7. 尚未完成的原作视觉锚点、中央庭材质校准和黑门／异界正式视觉对照。

# 6. 下一阶段边界

若本终审获得人工批准，则只允许进入：

1. 十名神器使领袖职业与“每人一个核心机制”的逐人审核。
2. 爱缪莎主线事件、危机与机制的实现设计文档。
3. 与已批准叙事职责一致的专属旗舰、巨构和终局表现重新设计。
4. 后续美术锚点与可实现性审核。

本批准仍不直接授权：

- 编写正式事件或危机脚本；
- 确定未经审核的数值、舰船槽位或巨构效果；
- 扩大 1.0 十人名单；
- 启动第二条大型个人主线；
- 用旧“命运观测塔”或旧 Stage 9 舰船反向决定正式方案。
