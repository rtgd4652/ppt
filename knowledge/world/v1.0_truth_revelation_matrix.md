# 爱缪莎 1.0 主线真相揭示矩阵

> 文档性质：`mod_design_decision`
>
> 状态：`approved`
>
> 依据：`AMR-012` 方案 A
>
> 决定日期：2026-07-27

## 1. 用途

本文限定爱缪莎 1.0 主线终局能够揭示的真相层级。它不负责解释完整宇宙本体论，也不替代事实矩阵、宇宙论或后续专属终局天灾设计。

## 2. 真相分层

| 层级 | 可以确认 | 主要知情者 | 1.0 禁止越界 |
| --- | --- | --- | --- |
| 文明可验证层 | 文明选择、集体行动和爱缪莎的有限观测／干涉会改变未来分布与现实代价；专属终局天灾涉及真实的世界边界或命运规则异常 | 中央庭、安托涅瓦、晏华、科研体系、玩家文明 | 不得据此断言所有危机同源、命运具有人格或中央庭掌握完整宇宙规律 |
| 终局互认层 | 无尽七日轮回中的指挥使与《群星》时代玩家，是同一位跨越不同世界状态、持续作出选择并承担结果的存在 | 爱缪莎、指挥使／玩家 | 不解释外部操作者、灵魂延续、重构保留、观察者效应或其他具体机制 |
| 角色知情层 | 爱缪莎已经跨越新的认知边界；埃索林可提供部分世界边界与维护规则证据 | 安托涅瓦、晏华、中央庭、埃索林分别在自身证据范围内 | 不让中央庭自动获得玩家层认知；不让埃索林成为全知说明者 |
| 开放谜团层 | 只登记问题，不给出唯一答案 | 作者与后续设计审核 | 不得通过临时对白、机制说明或美术暗示擅自关闭 |

## 3. 必须继续开放的谜团

- 指挥使—玩家连续关系的精确机制。
- 七日轮回终止和世界重构的完整因果。
- 箱庭与《群星》银河的空间和本体层级。
- 黑门、神器、世界之主、世界重构和命运规则是否具有共同来源。
- 命运修正规律的起源、完整作用尺度，以及“不和谐”与具体修正之间的机制。命运没有独立意志已经是项目正史，不再属于开放谜团。
- 专属终局天灾的真实身份与来源。
- 命运主宰在后续版本中的具体运用和游戏实现。1.0 已确认：经玩家授权并由爱缪莎自主接受后，她在命运规律领域拥有完整主宰权。

## 4. 角色边界

- 爱缪莎知道的是足以改变她与玩家关系、支撑最终沟通和自主决定的关键真相。
- 她不会因此成为世界之主、宇宙创造者、中央庭统治者或全知者。
- 安托涅瓦继续承担国家领导与文明责任。
- 晏华继续负责现实证据、判断与风险审查。
- 埃索林只能在有限知识与身份边界内提供证言。
- 是否以及何时向中央庭公开更深层玩家真相，留给后续剧情审核。
