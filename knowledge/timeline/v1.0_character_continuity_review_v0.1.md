# 1.0 十名神器使时间连续性审核草案

## 1. 文档用途

本文审核十名锁定角色从七日轮回结束到 Stellaris 开局之间的**最低连续性**。它不为角色补写新经历，不确定精确年龄、官职、任期或事件，只回答：现有资料是否足以让该角色在 1.0 开局时代继续作为同一位历史人物存在。

- [1.0 神器使锁定名册](../characters/character_roster_v1.0.md)

状态含义：

| 状态 | 含义 |
| --- | --- |
| `可闭合` | 现有资料足以建立最低连续性；具体职务仍可开放 |
| `草案待审` | 已有可用草案，但关键事实或项目解释尚未人工批准 |
| `开放` | 项目有意不确定，不妨碍角色存在，但不能被写成既定经历 |

## 2. 阶段压缩规则

为避免虚构逐年履历，本文把详细时间线压缩为五段：

| 审核阶段 | 对应时间线 | 只审核的内容 |
| --- | --- | --- |
| 轮回结束 | T0 | 角色是否以同一人格／身份进入连续历史 |
| 灾后重建 | T1–T2 | 原有经验如何安全连接救援、生活与科研恢复 |
| 制度与全球整合 | T3–T6 | 角色如何处于中央庭及文明制度中，而非取代制度 |
| 星际准备 | T7–T8 | 角色主题能否连接星际准备；不编造具体工程功绩 |
| Stellaris 开局 | T9 | 角色在 1.0 可被招募时的最低身份与知情边界 |

## 4. 角色知情边界

### 4.1 共同边界

- 十人都不能因为经历过轮回而自动知道轮回、箱庭、世界重构和不同世界状态的完整机制。
- 角色对原作事件的亲历、记忆保留程度与公开档案可见范围可以不同；未经来源或项目决定确认时保持开放。
- Stellaris 开局的全世界把旧轮回时期与当前时代的指挥使视为同一人，但并不知道两个阶段属于不同世界。
- 爱缪莎只在 1.0 专属危机胜利后首先确认世界差异，并在主线最终沟通后才成为命运主宰。

### 4.2 丽的专门边界

- 独立角色采集链已建立，但自动采集事实与标准档案草案仍待人工审核，不能据此补写完整角色史。
- “黄金姬”只作为称号使用，“黄金伞”只作为已确认机构语境使用。
- 独立资料支持宝伞・毗沙门天慧伞、敛聚财富、商业经营、社会安置关切与机甲投资等内容；人工批准前仍标记为待核事实。
- 中央城区剧情支持“实验室、黑核研究、直接交涉”三项行为事实，但不支持据此确定其正式研究职责或与赛斯的私人关系。
- 人工校订完成前，不确定其 T0 至 T9 的具体职责、职业或能力演化。

### 4.3 里见茜与塞拉菲姆历史边界

- 里见茜不在 1.0 十人名单，已有资料只作为历史与未来储备。
- 塞拉菲姆仅存在于过去历史层；1.0 不展开当前剧情或身份链揭示。

## 5. 当前可批准结论

1. 安托涅瓦、爱缪莎、晏华、安、赛斯、幽桐、拉比、格蕾莎八人的最低连续性可以闭合。
2. 八人的连续性只证明“能够合理存在于 T9”，不批准具体官职、事件、职业、trait 或玩法效果。
3. 雯梓已有足以建立连续性草案的资料，但需要人工校订角色事实并批准东方古街至星际时代的最低连接。
4. 丽的名单席位与独立资料链已建立，已经可以提出最低连续性草案；封闭连续性仍须人工校订并批准角色档案。
5. 精确年份、年龄、任期、制度职位和逐阶段个人履历继续保持开放，不阻塞背景总纲。
