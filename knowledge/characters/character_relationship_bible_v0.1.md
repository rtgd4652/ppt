# 《神器使》Stellaris Mod 核心人物关系圣经 v0.1

> 本文档用于统一《神器使》Stellaris Mod 中核心神器使、中央庭历史人物与文明象征之间的关系定位。
>
> 本文只整理人物关系和叙事定位，不新增游戏机制、不编写事件脚本、不设计数值或剧情任务。除已确认的 Mod 历史定位外，不补写原作中未确认的私人关系、对白或事件。

## 1. 安托涅瓦 × 晏华

### 主题：领袖与战略辅助

在中央庭体系中，安托涅瓦是毫无疑问的核心领袖。她代表守护、庇护与希望，并承担带领灾后文明继续前进的重要责任。

晏华是安托涅瓦的重要辅助者。他并不与安托涅瓦构成平级的权力中心，也不以个人取代中央庭制度；他的作用是以秩序、判断、战略与理性支持安托涅瓦和中央庭的长期选择。

两人的关系可概括为：

- 安托涅瓦负责守护文明、凝聚希望，并承担带领文明前进的责任。
- 晏华负责分析局势、识别风险、整理信息，并协助形成理性而可承担的战略规划。
- 安托涅瓦为文明保留生存空间与未来；晏华帮助文明在有限信息中判断应当走向何处。

这是一种领袖与战略辅助者的互补，而不是由两位角色共同统治中央庭的关系。中央庭始终是文明制度；安托涅瓦的领导力与晏华的辅助判断，均服务于制度、社会与人类共同的未来。

## 2. 安托涅瓦 × 爱缪莎

### 主题：领袖与未来辅助

安托涅瓦作为中央庭领袖，承担守护文明、保护生命与维系希望的责任。她的领导并非意味着能够独自解答所有未知，而是意味着在灾难之后仍愿意为人类保留走向未来的空间。

爱缪莎是安托涅瓦的重要辅助者。她以塔罗、计算、概率与可能性观测相关的经验，为中央庭理解未知、辨识未来方向提供参考。她并不决定文明命运，也不取代安托涅瓦的责任与中央庭的公共决策。

两人的关系可概括为：

- 安托涅瓦负责守护文明、承担责任，并让人类拥有继续前进的条件。
- 爱缪莎负责观察未来可能性、提示风险与机会，为文明提供方向参考。
- 安托涅瓦关注“如何保护走向未来的人”；爱缪莎关注“未来有哪些可能”。

爱缪莎的观察不是绝对预言。她所提供的是有限、需要被验证的可能性视角；安托涅瓦则在这些信息之外，承担保护具体生命与作出公共选择的领导责任。

## 3. 晏华 × 爱缪莎

### 主题：现实判断与未来观测的互补

晏华与爱缪莎是两种不同的信息处理方式的代表，但二者并不构成独立于安托涅瓦之外的另一核心。

- 晏华偏重当前现实的分析：已有信息、可见风险、资源条件、制度边界与战略后果。
- 爱缪莎偏重未来趋势与可能性的观测：概率、未知方向、尚未发生的风险与选择空间。
- 二者共同辅助安托涅瓦，使中央庭既不会只困于眼前事实，也不会把尚未验证的未来当作唯一答案。

这种互补要求保持明确边界：晏华不是永远正确的现实计算器，爱缪莎也不是全知的命运预言者。两人的判断都必须接受事实、研究、制度与人类共同责任的检验。

## 4. 核心人物结构总结

中央庭的核心人物结构是：**安托涅瓦为领袖，晏华与爱缪莎为重要辅助者。**

安托涅瓦位于关系结构的中心。她以守护、庇护和希望代表灾后文明最重要的领导责任；晏华与爱缪莎从不同方向为她和中央庭提供支持。

```text
                 安托涅瓦
        （中央庭领袖 / 守护 / 希望）
                  /   \
                 /     \
                /       \
        晏华                 爱缪莎
（判断 / 战略 / 秩序）   （未来 / 可能性 / 观测）
```

这不是三位角色平级分担中央庭权力的三角结构，而是以安托涅瓦为领导核心、由两位重要辅助者提供不同专业视角的关系框架。

## 5. 与中央庭的关系

中央庭是灾后人类文明的治理制度与公共协调体系，不是任何单一个人的私有组织。

- 安托涅瓦：作为核心领袖，承担守护文明、凝聚希望和带领人类走向未来的重要责任。
- 晏华：作为重要辅助者，帮助中央庭进行分析、决策与规划，使制度能够在复杂局势中维持理性与秩序。
- 爱缪莎：作为重要辅助者，帮助中央庭理解未知、观察未来可能性，并为长期方向提供有限但独特的参考。

三人的关系不是个人统治，而是个体经验与文明制度共同推动发展。中央庭的有效性来自制度、研究体系、公共责任与社会协作；核心神器使的意义，在于让这些结构在灾后与星际时代具备更深的经验、判断与希望。

## 6. 第一代星际中央庭核心神器使群体定位

安托涅瓦、晏华与爱缪莎可被视为 Mod 中第一代星际中央庭核心神器使关系框架的起点。

他们不是：

- 超越文明的神明。
- 取代中央庭制度的统治阶层。
- 依靠个人能力维持一切的救世主。
- 脱离社会与历史背景的特殊单位。

他们是经历黑门灾难、见证七日轮回结束，并帮助人类将灾难经验带入银河时代的重要历史人物：

- 安托涅瓦以领导、守护与希望成为中心。
- 晏华以战略、判断与秩序提供支撑。
- 爱缪莎以未来、可能性与观测提供支撑。

后续可在不改变这一层级结构的前提下，逐步补充更多神器使与中央庭历史人物。所有扩展都应保持开放性，不以具体剧情事件或固定对话提前锁死人物关系。
