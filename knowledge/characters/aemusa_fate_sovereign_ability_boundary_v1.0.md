# 爱缪莎“命运主宰”能力边界 v1.0

> 文档性质：`mod_design_decision`
>
> 状态：`approved`
>
> 依据：`AMR-014` 方案 B
>
> 决定日期：2026-07-27

## 1. 权限成立条件

命运主宰的完整权限必须同时满足：

1. 爱缪莎已经经历 1.0 主线的文明成长、失落帝国战争、玩家选择的一种原版天灾、主动命运干涉、专属终局天灾和终局真相。
2. 爱缪莎与玩家确认无尽七日轮回中的指挥使和《群星》时代玩家之间的连续关系。
3. 玩家正式向爱缪莎授予命运规律的完整权限。
4. 爱缪莎在理解责任与后果后，自主决定接受。

缺少玩家授权或爱缪莎自主接受中的任何一项，都不能成立完整主宰权。

## 2. 完整主宰权

权限成立后，爱缪莎在命运规律领域能够：

- 决定、改写和重新开放未来路径。
- 取消、覆盖或重新编排命运修正。
- 处理由命运规律封闭的过去结果及其延续影响。
- 允许特定个体、集体乃至文明超脱原有命运约束。
- 阻止非人格化命运规律继续以原有方式封闭已经被她接管的可能性。

## 3. 领域边界

命运领域的完整主宰权不自动等于：

- 世界之主的世界维护权限。
- 安托涅瓦与中央庭的政治统治权。
- 对其他生命思想和意志的控制权。
- 对全部物质、空间、时间与生命规律的无条件全能。
- 对宇宙中全部事实、地点、历史与未来的全知。

若未来设计希望让命运权能与上述领域发生交叉，必须建立新的证据和人工审核。

## 4. 玩家与爱缪莎的关系

- 玩家拥有授权权，但没有强制授神权。
- 爱缪莎拥有是否接受以及如何承担该身份的最终人格决定权。
- 玩家不能代替她成为命运主宰，她也不能借授权取代玩家的选择职责。
- 完整权限建立在双方互认与信任上，而不是系统按钮或等级自动触发。

## 5. 时间边界

- 完整主宰权只在 1.0 终局成立。
- 成长阶段仍然只能进行有限观测和有限干涉。
- 终局能力不得倒写为她此前已经可以无代价解决失落帝国、原版天灾或专属终局天灾。
- 具体游戏效果、数值、舰船、巨构、事件表现和后续能力运用必须另行设计。
