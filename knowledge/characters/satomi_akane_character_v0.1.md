# 里见茜角色档案 v0.1

> 本文档依据 `character_design_template_v0.1.md` 编写，参考里见茜 Clean 资料、Mod Ready 摘要及项目已有世界观决定。
>
> 本文是待人工审核草案，不包含代码、技能数值、trait、事件流程或飞升设计。Wiki 角色页只用于里见茜当前身份资料；“塞拉菲姆后来成为里见茜”的连续性来自项目人工确认，不冒充角色页原文。

## 1. 基础信息

### 姓名

- 正式名称：里见茜。
- 常用名称 / 别名：当前身份不使用“塞拉菲姆”作为日常别名。
- 待人工确认信息：进入 Stellaris 开局时代前的具体身份转换时间，以及公开档案是否记录其异常来源。

### 原作身份

- 所属背景 / 组织经历：得到中央庭与古研所支持，在古研所从事危险的黑门研究工作。
- 在原作中的主要身份：A级、灵属性、射手、物理攻击；具有“特定物品具现化”能力。
- 与其他角色或事件的已知关联：安托涅瓦与零曾关照她的生活；同伴评价中还出现高山雅、源千雪。她幼年曾在孤儿院生活，后被身份不明的资助者领养。

### 神器

- 神器名称：记录・生命蓝图。
- 神器相关象征：记录、生命结构、解析、具现化与不完整权限。
- 已知表现：能够具现化枪械、克赛特号与相关攻击装置；角色页同时明确，她“并非真正意义上的神器使”，而是在实验中意外获得了不完整的神器能力，类似现象未再重复。

### 原作定位

- 角色在原作叙事中的核心位置：里见茜是具有异常能力的黑门研究者，也是把天赋、技术能力和获得过的善意继续用于帮助他人的个体。
- 性格、经历或选择的关键特征：聪慧、独立、动手能力强、长期过度工作；珍视孤儿院经历，也愿意把自己得到的帮助传递给其他人。
- 不应被简化或误读的部分：她不是全知研究者、万能工程师或已经恢复神之记忆的隐秘神明；其不完整神器能力也不能被写成对世界规则的完整控制。

## 2. MOD 历史定位

### 在灾后文明中的身份

- 轮回结束后保留的历史身份：以里见茜当前人格、记忆和社会关系继续生活的异常能力者与研究人员。
- 与中央庭、神器研究或灾后社会的关系：她可以作为黑门研究、异常物质解析和工程具现化的特殊案例；中央庭与研究体系负责制度、伦理和安全边界，不能把她当作可无限调用的实验工具。
- 在星际时代可能承担的公开身份：适合成为参与异常分析、工程验证与黑门研究的科学人员。该方向仍待人工批准，不等于已确定领袖职业。

### 对人类文明的意义

- 该角色所代表的灾后经验、价值或问题：科学研究必须同时面对未知、风险、个人代价与公共责任。
- 对神器使群体或普通人类社会的象征意义：异常能力者仍有普通生活、劳动保障与社会关系；获得帮助的人也可以成为继续帮助他人的一员。
- 角色作为个体与文明整体之间的边界：她能提供独特经验与技术，却不能单独解释黑门、神器、箱庭或世界之主体系。

## 3. 身份连续性与知情边界

### 项目人工确认的身份链

- 项目已人工确认：塞拉菲姆曾是七日之都世界的世界之主；后来放弃神位、进入箱庭并失去相关记忆，以里见茜身份生活。
- 该连续性属于 `project_interpretation / human_confirmed` 与 `mod_design_decision / project_defined`，不是本次采集的里见茜角色页所直接证明的事实。
- 1.0 名单只按里见茜计一人；塞拉菲姆阶段不是另一名可招募角色，也不是里见茜的普通换装。

### 当前身份边界

- 里见茜不自动保留塞拉菲姆阶段的世界之主权限、完整记忆、知识或视觉符号。
- 中央庭在故事初期不知道塞拉菲姆曾是世界之主，也不知道她后来成为里见茜。
- 里见茜本人不得被预设为知晓箱庭、轮回、世界重构与宇宙真相的全部答案。
- 她不参与爱缪莎 1.0 主线的行动、通讯、证言或终局解决；未来其他剧情可以在证据充分时逐步揭示身份关系。

## 4. 神器设定

### 神器性质

- 与人类记忆、神话、器物或概念的关联：生命蓝图表现为对生命实相、信息记录与结构的异常映射，但角色页中的宏大描述不能直接当作已被科学证实的宇宙理论。
- 已知能力边界的世界观描述：当前可确认的是有限的解析与特定物品具现化表现；“览阅世界之理”之类神器故事文本应作为象征与研究线索，而非里见茜已经全知全能的证据。
- 与黑门、异常现实或其他未知之间的已知联系：她从事黑门研究，且异常能力来自一次未能重复的实验；两者的精确因果仍未确认。

### 与神器使关系

- 共鸣 / 契约的已知表现：角色页明确其并非通常意义上的神器使，而是拥有不完整神器能力的特殊个体。
- 对角色经历、性格与选择的影响：能力与研究工作共同强化了她对解析、工程和异常现象的关注，但没有取消其普通人的生活需求与责任。
- 角色对神器的理解与使用态度：现有资料支持她以技术与研究方式使用能力，不支持将其描述为宗教式崇拜或神力复苏。

### 当前认知程度

- 已被人类科学体系观测或确认的部分：能力可以表现为特定物品具现化；异常获得过程曾发生，但未能重复。
- 仍属假说、争议或未知的部分：特殊体质的来源、不完整能力与真正神器共鸣的关系、实验和黑门之间是否存在因果、其与塞拉菲姆旧身份之间是否存在无意识联系。
- 待人工确认：项目在玩法层是否继续将她归入“神器使”招募类别，以及设定文本如何解释原作“并非真正意义上的神器使”与 1.0 名单名称之间的差异。

## 5. Stellaris 定位

### 领袖类型

- 推荐领袖职业：科学家方向候选，尚未批准。
- 推荐理由：黑门研究经历、解析能力、学术背景与工程实践能够支持异常研究和技术验证的叙事定位。
- 该定位体现的角色核心，而非单纯强度：在不完整信息和不可重复现象面前坚持记录、实验、验证与风险意识。

### 文明作用

- 对文明的主要贡献方向：黑门异常分析、具现化现象记录、工程验证与研究安全经验。
- 与中央庭、神器研究、黑门研究或社会支持体系的关系：她属于制度与团队中的研究者，不是凌驾于研究体系之上的答案提供者。
- 适合代表的人类文明主题：把无法完全理解的异常纳入可审查、可记录且受伦理约束的科学过程。

### 未来发展方向

- 后续可拓展的角色主题：实验获得能力的来源、资助者身份、被遮蔽的旧记忆，以及研究者如何面对与自身有关的未知。
- 可与星际时代相连接的世界观问题：异星黑门是否呈现相同规律；具现化能否在不同物理环境中稳定；异常能力研究如何保护研究对象。
- 暂不进入当前档案的内容：具体职业、trait、数值、解锁条件、身份揭示事件与塞拉菲姆记忆恢复方案。

## 6. 剧情定位

### 已发生历史

- 原作中可引用的经历：孤儿院成长、神秘资助、卓越学业、广泛兼职经历、选择进入古研所从事黑门研究，以及一次不可重复实验带来的不完整神器能力。
- 轮回结束后对角色产生的长期影响：项目只能安全确认她以里见茜当前身份进入连续历史；身份转换的具体时点仍待审核。
- 与当前 Mod 时间线一致的历史结论：Stellaris 开局时她不能以塞拉菲姆世界之主身份公开行动，也不能拥有完整旧记忆与权限。

### 可探索内容

- 适合未来延展的主题：研究伦理、身份与记忆、被帮助者对社会的回馈、不可重复实验的证据，以及普通人格如何面对曾经的世界级身份。
- 可以从个人经历连接到文明历史的角度：通过她的研究工作表现灾后人类如何把黑门风险转化为长期科学体系，同时保护研究人员与异常能力者。
- 需要保留的情感与伦理重点：里见茜首先是具有自身生活、关系和选择的人，不能被旧身份覆盖或仅作为揭谜工具使用。

### 未解释部分

- 原作保留的谜团：神秘资助者与其助理、不可重复实验、特殊体质，以及生命蓝图能力的真实来源。
- 项目保留的谜团：塞拉菲姆如何放弃神位、为何失去记忆、里见茜保留了多少无意识痕迹、埃索林何时以及如何揭示身份链。
- 不应在当前版本仓促定论的内容：世界之主权限机制、记忆恢复程度、身份揭示的完整剧情顺序，以及她与爱缪莎主线终局的关系。

## 7. 美术与表现规范

### 外貌特征

- 当前 Clean 与 Mod Ready 文本不足以确认发型、发色、瞳色、服装和配饰的完整视觉锚点。
- 正式立绘制作前必须单独核验里见茜原作基础立绘、觉醒立绘、神器表现与角色固有色。
- 不得使用塞拉菲姆风格页替代里见茜本人视觉锚点，也不得为了表现身份连续性直接覆盖世界之主服饰或神性光效。

### 核心象征

- 可安全使用的叙事象征：记录、蓝图、解析、具现化、监控与研究环境。
- 待视觉核验后才能使用的元素：具体个人色、发型轮廓、服装剪影、武器外形和神器图案。

### 视觉主题

- 氛围方向：理性研究、工程实践、疲惫但可靠、日常生活与异常现象并存。
- 星际时代转化原则：可加入受控实验界面、结构蓝图与异常分析环境，但不能机械化、神化或让研究设备覆盖人物识别。
- 立绘、头像、通讯图与图标的一致性：待原作视觉锚点完成后再正式批准；当前不得凭文本自行生成最终视觉规范。
