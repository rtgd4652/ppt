# 《神器使》Stellaris Mod 1.0 神器使锁定名册

> 文档性质：`mod_design_decision` / `project_defined`
>
> 适用版本：1.0 正式版
>
> 决策依据：[`ED-009`](../curated/decisions/project_editorial_decisions_v0.1.md)

## 1. 名单结论

1.0 正式版的最低神器使阵容锁定为十人：

1. 安托涅瓦。
2. 爱缪莎。
3. 晏华。
4. 安。
5. 赛斯。
6. 幽桐。
7. 拉比。
8. 格蕾莎。
9. 雯梓。
10. 里见茜。

这十人是 1.0 的不可替换基线。后续可以通过独立范围决定增加角色，但不能用新角色替换其中未完成的成员，也不能把联动角色算入这十个原作神器使名额。

## 2. 分组与版本作用

| 分组 | 角色 | 1.0 作用 |
| --- | --- | --- |
| 中央庭核心人物 | 安托涅瓦、爱缪莎、晏华 | 安托涅瓦承担文明领导主题；晏华提供现实战略辅助；爱缪莎提供未来观测辅助并承担 1.0 主线 |
| 首批文明成员 | 安、赛斯、幽桐、拉比、格蕾莎 | 扩展时间、救援、远程支援、伦理判断与生命研究等文明侧面 |
| 地区与世界规则接入 | 雯梓、里见茜 | 补足东方古街与世界规则相关人物，但不得在资料不足时自行补完 |

分组只用于安排开发与叙事职责，不代表角色等级、政治地位或游戏强度。

## 4. 身份与计数边界

### 4.1 安

角色正式名是“安”。知识库、脚本、本地化和美术登记均应使用这一正式名；“神器安”只能在自然语言中用于消除歧义。

### 4.2 里见茜与塞拉菲姆

塞拉菲姆放弃神位、进入箱庭并失去相关记忆后，以神器使里见茜的身份生活。两者是同一人物的不同身份阶段，但不能被当作普通换装、立绘切换或两名独立招募角色。

1.0 只招募神器使身份里见茜。塞拉菲姆世界之主阶段：

- 不单独计入十人。
- 不直接进入白夜馆招募池。
- 不自动保留到里见茜身上的神位权限、完整记忆或视觉符号。

`AMR-009` 已确定里见茜不参与爱缪莎 1.0 主线。该决定只限制她在这条主线中的出场、通讯与行动，不影响她作为锁定第十名神器使、白夜馆接入目标和独立角色实装对象的地位。其他人物可以在主线中通过调查和证据逐步确认其身份关系，但不得借此让她恢复塞拉菲姆阶段的完整记忆。

### 4.3 司篁

司篁已确认是神器使并拥有专门主线，但当前决定是暂不进入 1.0 十人基线。她保留为后续版本候选，不能被写成“不是神器使”，也不能在资料不足时被雯梓或其他角色的视觉与设定替代。

### 4.4 埃索林

埃索林是塞拉菲姆的老师，并在后续承担世界管理职责。`AMR-007` 已批准她作为爱缪莎 1.0 主线后期的“边界见证者／有限顾问”，`AMR-008` 已批准由她本人通过受限边界通讯实时参与；她不是全知说明者或终局解决者。以上身份链是作者层资料，中央庭初次接触时只知道对方自称“埃索林”，并不知道她与塞拉菲姆、世界之主和里见茜的关系。`AMR-009` 已确定里见茜本人不参与该主线。埃索林当前不是神器使，不占用神器使名额；当前世界管理状态、完整权限、知识上限与身份揭示顺序仍待后续审核。

### 4.5 联动角色

冈部伦太郎虽是跨作品联动来客，但可以按照神器使身份与规则进行设计。他当前不占用本次锁定的十个名额；若后续要加入 1.0，必须另行明确是作为第十一名追加，还是通过新的人工决定调整名单，不能无声改变计数。

## 5. 1.0 共通完成条件

每名锁定角色在 1.0 发布前至少需要：

- 有可回溯的原作资料或人工确认依据。
- 有 Mod Ready 转化摘要。
- 有标准角色档案，明确历史、神器、叙事与美术边界。
- 有白夜馆招募、联络和档案入口。
- 有唯一招募保护。
- 有明确且经过审核的 Stellaris 领袖职业。
- 有一个可验证的角色核心机制或专属特质。
- 有符合角色身份阶段的立绘和本地化。
- 完成新开局、读档、重复招募与错误日志测试。

爱缪莎还必须完成 [`1.0 叙事约束文档`](../../docs/design/v1.0_narrative_constraints.md) 规定的“命运主宰”主线。其他九人不要求在 1.0 拥有同等规模的个人主线。

## 6. 维护规则

1. 名单变化必须新增项目编辑决定，不能只修改本表。
2. 角色事实以来源、clean 资料和人工校订为准；状态档案只记录进度和边界。
3. 角色状态变化时，同时更新对应 `status/*_status_v1.0.md` 和本页总表。
4. “计划接入”不能写成“已经实装”；“身份链已确认”不能写成“完整资料已完成”。
5. 雯梓和里见茜的资料缺口必须通过后续采集与人工审核补齐，不得为追赶进度而自行创作原作事实。
