# 拉比 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 已知核心要素：怪兽・阿米特；分辨善恶；约束、伦理判断与压制。
- 当前游戏定位：指挥官。

## 2. 当前证据链

- [Clean 资料](../拉比.md)
- [Mod Ready 摘要](../../mod_ready/characters/拉比.mod.md)
- [标准角色档案](../rabi_character_v0.1.md)

标准角色档案已经建立，并明确拉比与阿米特是具有监护与共生性质的关系，“分辨善恶”不能替代公共司法。当前仍缺少独立关系档案与正式视觉锚点。

## 3. 1.0 叙事定位

- 拉比的“分辨善恶”应被写成角色面对判断与后果的主题，不能变成系统对所有文明和个体的绝对道德裁决。
- 阿米特不应被泛化为中央庭司法、外交或政治合法性的来源。
- 1.0 不要求完整个人事件链，但需要避免把角色只写成登陆战数值单位。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：已实现。
- 独特领袖、指挥官职业、专属特质与唯一引用：已实现。
- 角色专属肖像：未完成。
- 1.0 候选版完整回归：尚未完成。

## 5. 美术状态

尚无正式角色视觉规范。必须核验原作外貌、阿米特、服装与个人颜色；不得用通用怪兽、审判天平或宗教惩罚符号自行替代。

## 6. 1.0 完成条件

- 完成标准角色档案与视觉锚点。
- 补齐正式角色肖像。
- 复核指挥官职业和一个核心机制。
- 通过招募唯一性、职业、特质、读档、肖像、本地化和 `error.log` 测试。

## 7. 当前阻塞项

- 美术锚点缺失。
- 指挥官职业及未成年人参与文明级军事行动的边界仍待人工复核。
- 当前“可玩”不等于 1.0 回归验证通过。
