# 拉比 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 已知核心要素：怪兽・阿米特；分辨善恶；约束、伦理判断与压制。
- 当前游戏定位：指挥官。

标准角色档案已经建立，并明确拉比与阿米特是具有监护与共生性质的关系，“分辨善恶”不能替代公共司法。二者的共同人物锚点、拉比人物外貌与固有色、阿米特实体锚点和独立视觉规范均已完成人工审核。

- [领袖职业与核心机制设计](../../../docs/design/characters/rabi_leader_core_design_v1.0.md)：RBR-001～RBR-009 已整体批准，锁定“指挥官单职业＋阿米特的守则”。

## 3. 1.0 叙事定位

- 拉比的“分辨善恶”应被写成角色面对判断与后果的主题，不能变成系统对所有文明和个体的绝对道德裁决。
- 阿米特不应被泛化为中央庭司法、外交或政治合法性的来源。
- 1.0 不要求完整个人事件链，但需要避免把角色只写成登陆战数值单位。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：已实现。
- 独特领袖、指挥官职业、专属特质与唯一引用：已实现。
- 角色专属肖像：未完成。
- 1.0 候选版完整回归：尚未完成。

## 5. 美术状态

- `「地精」拉比` 已批准为 1.0 基础形态主锚点，拉比与阿米特必须作为共同识别整体；觉醒立绘与设计稿已批准为辅助锚点。
- 拉比的灰褐短碎发、上翘发梢、琥珀金眼睛、月牙发饰、少年体态与恶作剧表情已经通过 `CVA-005` 人工审核。
- 基础固有色锁定为暖黄橙外套、深灰黑边缘、灰绿针织内层、深色短裤、白袜、深灰黑鞋和白色毛球；拉比必须从阿米特的深色甲壳中清晰分离。
- 基础构图允许拉比坐在阿米特背部、身侧或保护范围内，但禁止缰绳、鞍具、驾驶舱和操纵坐骑关系。
- `企鹅少年` 已归类为皮肤／活动形态，不得反向改写基础形态。
- 阿米特的四足厚重轮廓、深炭黑／砂岩灰／象牙灰硬质结构、琥珀能量，以及双方共同、失能分离、吞噬、震击和恢复阶段已经通过 `AFA-006` 人工审核。
- 正式表现不得用通用怪兽、审判天平、宗教惩罚、血腥处刑或成熟军阀形象自行替代。

## 6. 1.0 完成条件

- 完成标准角色档案与视觉锚点。
- 补齐正式角色肖像。
- 已复核并批准指挥官职业和一个核心机制。
- 通过招募唯一性、职业、特质、读档、肖像、本地化和 `error.log` 测试。

## 7. 当前阻塞项

- 双方在非战斗场景中的落座／站位、休息动作和视线联系仍待补充证据；正式资产仍需技术色板采样和共同头像验证。
- 指挥官职业及未成年人参与文明级军事行动的边界已完成设计审核，仍待游戏实现与回归测试。
- “阿米特的守则”已获人工批准；正式数值、事件脚本和最终美术仍须另行审核。
- 当前“可玩”不等于 1.0 回归验证通过。
