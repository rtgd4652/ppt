# 安托涅瓦 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 核心定位：中央庭核心领袖；守护、庇护与希望的代表。
- 版本职责：作为中央庭文明叙事中心进入白夜馆，不与爱缪莎争夺 1.0 个人主线主角位置。

## 3. 1.0 叙事定位

- 安托涅瓦负责带领文明前进，并把守护生命转化为制度方向。
- 她是核心领袖，但不是君主、神明、中央庭所有者或唯一决策者。
- 晏华与爱缪莎分别提供战略判断和未来观测辅助，不能被写成与她平级的三角权力中心。
- 她的方舟与空间经验不等于掌握箱庭全貌或能够无条件拯救所有人。

## 5. 美术状态

已有角色视觉规范和部分原作锚点。后续正式资产仍需按安托涅瓦外貌、方舟、蓝白银体系与空间庇护主题校验，不能套用爱缪莎的星月、卡牌或命运语言。

## 6. 1.0 完成条件

- 完成白夜馆招募、通讯和档案。

- 完成唯一招募、读档与死亡状态处理。
- 完成正式立绘、本地化和专项测试。
- 确认所有文本均保持“制度化核心领袖”边界。
