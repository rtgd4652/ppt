# 雯梓 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 地区关系：东方古街。
- 当前项目资料中可回溯到雯梓的剧情发言、对话头像和“棋圣”角色图标，但尚未完成独立角色采集。

## 2. 当前证据链

现有间接入口包括：

- [`避世的方舟／第一天`](../../story/pages/避世的方舟_剧情_第一天.md)
- [`牺牲的意义／最终日`](../../story/pages/牺牲的意义_剧情_最终日.md)
- 其他角色图片索引中登记的雯梓对话头像与角色图标。

这些材料只能证明角色出现与部分地区语境，不能代替雯梓自己的 raw、clean、图片索引、Mod Ready 摘要和标准角色档案。

## 3. 1.0 叙事定位

- 雯梓用于补足东方古街在统一人类文明与星际时代中的人物视角。
- 具体神器、能力、政治职责、领袖职业与个人主题必须等待角色页采集和人工审核。
- 不得仅根据“东方古街”“棋圣”或现有一句同伴评价推导完整人格、能力或国家地位。
- 她进入 1.0 名单不意味着东方古街成为独立银河国家，也不改变中央庭作为统一文明治理核心的正史。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：未开始。
- 独特领袖、职业、核心特质与唯一招募：未开始。
- 立绘、本地化与测试：未开始。

## 5. 美术状态

尚无经过审核的独立原作视觉锚点或角色风格页。正式制作前必须完成角色基础立绘、神器、个人配色、服装和东方古街语境的分层核验，不能把地区公共建筑语言直接当作雯梓的个人符号。

## 6. 1.0 完成条件

- 完成 raw、clean、图片索引三件套采集。
- 完成 Mod Ready 摘要和标准角色档案。
- 建立原作视觉锚点与角色风格边界。
- 批准领袖职业与一个核心机制。
- 完成白夜馆接入、唯一招募、本地化、立绘和专项测试。

## 7. 当前阻塞项

- 独立角色来源尚未采集。
- 神器、能力、职业和视觉方向均不得在来源补齐前定案。
