# 丽 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：第十名已锁定。
- 正式姓名：丽。
- 已确认机构语境：黄金伞。
- 已确认称号：现有剧情页面使用“黄金姬”。
- 已确认出场语境：中央城区讨伐及相关主线片段。

“丽（黄金伞）”用于项目名册消除歧义；“黄金姬”是称号，“黄金伞的丽”是自然语言关系描述，二者均不替代角色姓名。

当前资料支持其神器为宝伞・毗沙门天慧伞，能力摘要为敛聚财富，并记录商业经营、鉴赏、教育与就业关切、机甲投资等个人经历。现有证据仍不足以确定其正式职务、灾后制度身份、与赛斯的私人关系或 Stellaris 职业。

## 3. 1.0 叙事定位

- 作为中央城区与黄金伞相关的神器使人物进入 1.0 名单。
- 可确认她具备独立判断、直接交涉和研究黑核的行为表现；这些行为仍不能直接映射为 Stellaris 职业或核心机制。
- 她可以连接灾后经济恢复、社会安置、工业投资与资源组织，但具体文明职责必须等待人工审核，不能让私人财富替代中央庭制度。
- 她不因补位而自动进入爱缪莎大型主线的关键节点。
