# 赛斯 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 已知核心要素：权杖・羽蛇神杖；实现微小愿望；救援与支持。
- 当前游戏实现：行政官；正式批准定位为行政官／指挥官双职业，指挥官形态尚未实现。

中央城区地区证据补充确认：赛斯受安排在中央公园接应指挥使，参与异常调查，并在丽的黑核回收链中提供她偏好蜂蜜甜食的实用情报。该证据只支持任务协作与信息支援，不证明两人存在未经来源确认的私人关系。

## 3. 1.0 叙事定位

- 赛斯应体现救援、恢复、日常愿望与人与制度之间的支持关系。
- 圣星教会背景不能把神器研究写成宗教，也不能把赛斯写成神授权威。
- “微小愿望”不应扩张为无代价、无限制的许愿能力。
- 1.0 不要求赛斯拥有大型个人主线。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：已实现。
- 独特领袖、行政官职业、专属特质与唯一引用：已实现。
- 职业与核心机制复核：行政官／指挥官双职业与“愿望履责”已获人工批准；当前可玩实现暂不改动，等待可行性设计。
- 角色专属肖像：未完成；当前仍依赖物种表现。
- 1.0 候选版完整回归：尚未完成。

## 5. 美术状态

- `「神官」赛斯` 已批准为 1.0 基础形态主锚点；`赛斯-觉醒.jpg` 与 `赛斯觉醒设计1.jpg` 已批准为觉醒形态辅助锚点。
- 暖棕中长碎发、后颈发束、青蓝眼睛、基础形态黑色单眼眼罩、高挑修长体态和松弛姿态已经通过 `CVA-003` 人工审核。
- 基础固有色锁定为暖白／冷白服装、深巧克力棕／近黑内层、暖金／黄铜附件、黑色手套与腰封，以及红棕至暗红的神器垂带；觉醒白金羽翼层不得反向改写基础形态。
- `逍遥同尘`、`平安夜小叮当` 已归类为皮肤／活动形态，不得反向改写基础形态。
- 羽蛇神杖的长柄、盘绕羽蛇、展开双翼、深棕／古铜／象牙白材质关系已经通过 `AFA-004` 人工审核。
- 丰收之雨、圣光再临、神之暴风、光之护盾和神之救赎已经建立分层表现规则；不能统一处理为金色圣光或绿色治疗光。
- 正式表现不得用通用宗教金色、中央庭公共色、圣星教会公共视觉或爱缪莎命运语言替代赛斯个人识别。

## 6. 1.0 完成条件

- 完成标准角色档案与视觉锚点。
- 补齐正式角色肖像并校验裁切。
- 已复核并批准双职业和一个核心机制。
- 通过招募唯一性、职业、特质、读档、肖像、本地化和 `error.log` 测试。

## 7. 当前阻塞项

- 羽蛇神杖在全身立绘中的长度、握持、收纳和非施展状态仍待补充证据；正式资产仍需技术色板采样和显示校色。
- 当前“可玩”不等于 1.0 回归验证通过。
- 指挥官形态、双职业切换、愿望履责正式脚本和数值尚未设计与审核。
