# 幽桐 1.0 角色状态档案

- 1.0 十名神器使：已锁定。
- 已知核心要素：神弓・甘狄拔；束缚自身；克制、精准与远程支援。
- 当前游戏定位：指挥官。

标准角色档案已经建立，并明确责任心不能被写成无限自我牺牲许可。当前仍缺少独立关系档案与正式视觉锚点。

P05 结构级证据确认幽桐在港湾区讨伐模块中出现，但现有材料尚未提供足以确认其任务职责、个人战果或与利维坦关系的逐句对白。因此该出场只登记为地区经历证据，不改变现有角色定位。

## 3. 1.0 叙事定位

- 幽桐的核心应表现为自我约束下的精准行动与守护，不是泛用火力增幅器。
- 甘狄拔的角色意义不能被简化为普通舰炮或与其他射手共享的通用图标。
- 1.0 不要求展开完整个人主线，但必须保留其克制与选择边界。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：已实现。
- 独特领袖、指挥官职业、专属特质与唯一引用：已实现。
- 当前内部 ID 使用 `yutong`；旧候选拼写不得重新引入。
- 角色专属肖像：未完成。
- 1.0 候选版完整回归：尚未完成。

## 5. 美术状态

尚无正式角色视觉规范。必须核验原作外貌、神弓、服装、颜色与远程攻击表现，不能只把中央庭舰队武器换色后当作幽桐个人视觉。

## 6. 1.0 完成条件

- 完成标准角色档案与视觉锚点。
- 补齐正式角色肖像。
- 复核指挥官职业和一个核心机制。
- 通过招募唯一性、职业、特质、读档、肖像、本地化和 `error.log` 测试。

## 7. 当前阻塞项

- 美术锚点缺失。
- 当前“可玩”不等于 1.0 回归验证通过。
