P05 结构级证据确认幽桐在港湾区讨伐模块中出现，但现有材料尚未提供足以确认其任务职责、个人战果或与利维坦关系的逐句对白。因此该出场只登记为地区经历证据，不改变现有角色定位。

## 3. 1.0 叙事定位

- 幽桐的核心应表现为自我约束下的精准行动与守护，不是泛用火力增幅器。
- 甘狄拔的角色意义不能被简化为普通舰炮或与其他射手共享的通用图标。
- 1.0 不要求展开完整个人主线，但必须保留其克制与选择边界。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：已实现。
- 独特领袖、指挥官职业、专属特质与唯一引用：已实现。
- 职业与核心机制复核：指挥官单职业与“自定射界”已获人工批准；当前可玩实现暂不改动，等待可行性设计。
- 当前内部 ID 使用 `yutong`；旧候选拼写不得重新引入。
- 角色专属肖像：未完成。
- 1.0 候选版完整回归：尚未完成。

## 5. 美术状态

- `「诛心」幽桐` 已批准为 1.0 基础形态主锚点；`幽桐-觉醒.jpg` 已批准为觉醒形态辅助锚点。
- 金色短发、长斜刘海、琥珀金眼睛、高挑修长体态和克制姿态已经通过 `CVA-004` 人工审核。
- 基础固有色锁定为驼黄／浅焦糖外套、白灰毛领、黑色高领内层与长裤、灰色中间层及少量银饰；觉醒白黑金关系不得反向改写基础形态。
- `协奏舞曲`、`悠久之海`、`白夜辉光` 已归类为皮肤／活动形态，不得反向改写基础形态。
- 甘狄拔的黑／深紫黑、银白反曲弓体、平行金色能量弦，以及普通射击、连续积累、五箭展开、近身后跳与局部箭雨阶段已经通过 `AFA-005` 人工审核。
- 古典音乐限于人物环境、通讯、待机和界面节奏；无原作证据时不转化为音乐攻击。不能只把中央庭舰队武器换色后当作幽桐个人视觉。

## 6. 1.0 完成条件

- 完成标准角色档案与视觉锚点。
- 补齐正式角色肖像。
- 已复核并批准指挥官职业和一个核心机制。
- 通过招募唯一性、职业、特质、读档、肖像、本地化和 `error.log` 测试。

## 7. 当前阻塞项

- 甘狄拔在全身立绘中的长度、握持、收纳和实际拉弦姿态仍待补充证据；正式资产仍需技术色板采样和显示校色。
- 当前“可玩”不等于 1.0 回归验证通过。
- 射界对象、校准、越界援护、正式脚本和数值尚未设计与审核。
