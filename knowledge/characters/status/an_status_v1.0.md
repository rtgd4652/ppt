# 安 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 正式姓名：安。
- 已知核心要素：双剑・时光之刃；时间、回环、成长与选择。

## 2. 当前证据链

- [Clean 资料](../安.md)
- [Mod Ready 摘要](../../mod_ready/characters/安.mod.md)
- [标准角色档案](../an_character_v0.1.md)

标准角色档案已经建立，并明确有限时间回溯不得扩写为世界线、世界重构或七日轮回控制权。当前仍无独立美术规范或完整游戏实现。

## 3. 1.0 叙事定位

- 安应体现生活、成长、时间与玩家选择之间的关系，不只是“时间能力角色”。
- 时光之刃不等于自由改写全部历史，也不能绕过“七日轮回已经结束”的项目开局前提。
- 她不能因接触时间与回环而自动理解世界重构、世界之主或全部世界线。
- 1.0 不要求安拥有与爱缪莎同等规模的大型个人主线。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：未开始。
- 职业与核心机制：待标准档案完成后设计。
- 独特领袖、唯一招募、立绘和本地化：未开始。
- 测试：未开始。

## 5. 美术状态

尚未建立原作视觉锚点与角色风格页。正式制作前必须核验基础立绘、时光之刃、个人颜色和不同剧情状态，不得把爱缪莎的命运视觉或通用时间齿轮直接套用为安的个人设计。

## 6. 1.0 完成条件

- 按统一模板完成标准角色档案。
- 建立原作视觉锚点和风格边界。
- 批准 Stellaris 领袖职业和一个核心机制。
- 完成白夜馆接入、唯一招募、立绘、本地化和专项测试。

## 7. 当前阻塞项

- 视觉锚点缺失。
- 时间能力在 Stellaris 中的叙事与玩法边界尚未批准。
