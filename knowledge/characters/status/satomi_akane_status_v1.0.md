# 里见茜 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 身份连续性：塞拉菲姆放弃神位、进入箱庭并失去相关记忆后的神器使身份。
- 计数规则：只按里见茜计一名神器使；塞拉菲姆世界之主阶段不另占名额。

里见茜独立 Raw、Clean、图片索引和 Mod Ready 摘要已经生成，标准角色档案草案已经建立。角色页只证明里见茜当前身份资料，并明确其“并非真正意义上的神器使”、而是通过不可重复实验获得不完整能力；塞拉菲姆身份连续性仍单独依据项目人工确认，不能冒充角色页事实。以上成果均待人工校订与批准。

## 3. 1.0 叙事定位

- 里见茜必须作为失去神之记忆后的神器使出现，不能直接以世界之主塞拉菲姆状态招募。
- 人物连续性不等于完整继承塞拉菲姆的记忆、权限、服装、配色或神位特效。
- 她不得自动知晓箱庭、轮回、世界重构和宇宙真相的全部答案。
- `AMR-009` 已确定她不参与爱缪莎 1.0 主线：不在该主线中出场、通讯、行动、提供证言或参与终局，也不为说明身份链而恢复完整神之记忆。
- 她的身份关系可以由其他人物通过调查和证据逐步揭示；这种被提及或被确认不等于她本人参与主线。
- 本决定不影响她作为 1.0 锁定神器使、白夜馆接入目标、独立角色实装对象和未来剧情候选的地位。
- 她相对 Stellaris 开局时代的具体时间位置与解锁方式尚未决定。

## 5. 美术状态

里见茜的独立视觉锚点明确延期。塞拉菲姆现有来源和风格页不能替代里见茜的基础立绘、神器、服装和个人色。正式制作前必须完成独立视觉核验。
