# 里见茜 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 身份连续性：塞拉菲姆放弃神位、进入箱庭并失去相关记忆后的神器使身份。
- 计数规则：只按里见茜计一名神器使；塞拉菲姆世界之主阶段不另占名额。

## 2. 当前证据链

- [项目编辑决定 ED-006](../../curated/decisions/project_editorial_decisions_v0.1.md)
- [宇宙论圣经](../../world/cosmology_bible_v0.1.md)
- [里见茜／塞拉菲姆视觉边界](../../../docs/art/characters/SATOMI_AKANE_SERAPHIM_STYLE.md)

目前只有经人工确认的身份链和部分剧情来源入口，尚无里见茜独立 raw、clean、图片索引、Mod Ready 摘要或标准角色档案。

## 3. 1.0 叙事定位

- 里见茜必须作为失去神之记忆后的神器使出现，不能直接以世界之主塞拉菲姆状态招募。
- 人物连续性不等于完整继承塞拉菲姆的记忆、权限、服装、配色或神位特效。
- 她不得自动知晓箱庭、轮回、世界重构和宇宙真相的全部答案。
- 她相对 Stellaris 开局时代的具体时间位置与解锁方式尚未决定。

## 4. 游戏实现状态

- 白夜馆招募、通讯和档案：未开始。
- 身份阶段解锁逻辑：未设计。
- 职业、核心机制、唯一招募、立绘与本地化：未开始。
- 测试：未开始。

## 5. 美术状态

里见茜的独立视觉锚点明确延期。塞拉菲姆现有来源和风格页不能替代里见茜的基础立绘、神器、服装和个人色。正式制作前必须完成独立视觉核验。

## 6. 1.0 完成条件

- 完成独立角色采集三件套、Mod Ready 摘要和标准角色档案。
- 决定她在 T9 开局前已经是神器使，还是通过 1.0 剧情解锁。
- 建立独立视觉锚点和角色风格页。
- 完成白夜馆接入、身份阶段保护、职业、核心机制、立绘、本地化和专项测试。

## 7. 当前阻塞项

- 独立来源、角色档案与视觉锚点缺失。
- 身份转换相对 T9 的时间位置未定。
- 招募条件不能在时间线决定前实现为既定正史。
