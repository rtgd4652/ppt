# 格蕾莎 1.0 角色状态档案

## 1. 名单与身份

- 1.0 十名神器使：已锁定。
- 已知核心要素：神符・安卡；唤起生命的力量；生命、恢复与成长。

## 2. 当前证据链

- [Clean 资料](../格蕾莎.md)
- [Mod Ready 摘要](../../mod_ready/characters/格蕾莎.mod.md)

当前缺少标准角色档案、独立关系档案与正式视觉锚点。

## 3. 1.0 叙事定位

- 格蕾莎应体现生命研究、恢复与对成长的理解，不能被简化为通用治疗单位。
- 安卡与生命力量不等于无条件复活、永生或对生命的完全支配。
- 具体科研、医疗或治理职责必须在标准角色档案和职业审核后确定。

## 4. 游戏实现状态

- 白夜馆：目前只有“资料待整理”性质的占位，不可招募。
- 独特领袖、职业、核心特质与唯一招募：未开始。
- 立绘、本地化与专项测试：未开始。
- 内部英文拼写在旧候选中存在不一致，正式实装前必须先锁定唯一 slug。

## 5. 美术状态

尚无正式角色视觉规范。必须核验原作外貌、安卡、个人配色与生命特效；不得用通用绿色医疗、埃及符号拼贴或全屏治愈光代替角色设计。

## 6. 1.0 完成条件

- 完成标准角色档案与视觉锚点。
- 锁定内部 slug、职业和一个核心机制。
- 将白夜馆占位升级为完整招募、通讯和档案。
- 完成立绘、本地化、唯一招募和专项测试。

## 7. 当前阻塞项

- 标准角色档案、美术锚点和职业决定缺失。
- 现有白夜馆占位不能计为已实装。
