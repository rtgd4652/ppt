# 使用边界

本文依据《赛斯／支线剧情》正文整理剧情结构、人物行为、信仰表达和可用于项目设定的证据，不替代来源三件套。

- 页面正文保留七个标题段落，其中“赛斯在这里吗？”主要承载地图搜索结构。
- 页面包含两类不同选择：可重复寻找正确地点的巡查选择，以及一次性的私信回应选择。
- 赛斯关于神、愿望和神官职责的发言首先属于其个人信仰与职业理解，不能单凭本页认定为项目宇宙客观规律。
- 页面以大量喜剧对白表现赛斯的懒散、好色和逃避工作，同时也以行动表现其保护他人、承担危险的一面；两者都不能被删除。
- 支线发生于黑门和怪物仍直接威胁交界都市的时期，精确周目与主线归属没有注明。

# 2. 神官工作与停职

赛斯在中央庭处理信徒来信，要求指挥使代写回复。剧情通过他提出的不当回答、指挥使实际写下的较稳妥回复，以及赛斯自己伪造求援信等行为，明确表现其逃避文书工作的习惯。随后他在宣讲时忘词并把现场交给指挥使，进一步导致教会以请假、旷工和有损神官形象等理由将其停职。

这些内容说明：

- 赛斯确实具有明显的懒散、投机和不守工作纪律问题。
- 指挥使与赛斯存在长期互相帮助、吐槽和收拾残局的合作关系。
- 喜剧表现不能被改写成赛斯始终严肃、完美或完全符合组织纪律。

# 3. 寻找赛斯的巡查结构

停职通知送达后，指挥使依据赛斯的活动习惯，在中央庭、高校学园、东方古街和中央城区等可能地点寻找他。

- 选择错误巡查点时，只得到“赛斯不在这里”的反馈，可以继续寻找。
- 找到正确地点后，指挥使把信放入赛斯的行李箱，搜索流程结束。
- 该结构属于地点检索，不应整理成多个彼此冲突的剧情世界线。

# 4. 信徒的愿望

赛斯为恢复职位接受教会任务，接待一名自称东方古街花店老板娘的少女。对方声称丈夫重病，唯一药物存放在怪物控制的研究所仓库，希望赛斯亲自取回。

指挥使提出可向中央庭求助，但赛斯认为既然对方直接向自己提出愿望，就应由自己完成。他的接受既包含受到年轻女性恭维后的虚荣，也包含对神官职责的个人理解，不能只保留其中一面。

私信选择只改变赛斯请求帮助时的回应语气，之后都会进入会面和仓库剧情。

# 5. 仓库行动与“潜行”

面对大量怪物，赛斯拒绝常规潜入方案，以引来并正面击破怪物的方式开路。他让没有合适武器的指挥使留在安全处，独自进一步清理仓库，然后才通知指挥使进入。

他在行动前表示：神不会听从所有人的愿望，因此神官需要替向神祈祷的人解决现实问题。这是赛斯对神官职责的个人解释，不是本页对神是否存在、如何行动所作的客观证明。

# 6. 陷阱、愿望与责任

仓库中并不存在所说的药物。自称老板娘的少女现身并承认设下陷阱，希望赛斯死亡。赛斯随后说明自己早已察觉对方身份可疑：东方古街没有她所描述的花店和丈夫，她的举止也与自称身份不符。

赛斯没有简单照字面“实现”死亡愿望，而是要求少女面对愿望成真后的责任，包括自己的死亡、指挥使可能受到伤害，以及中央庭失去指挥使的后果。他提出自己的愿望是让对方为其愿望负责。

这一过程可支持：

- 赛斯能够识别身份和说辞中的异常，但不是预先知道所有细节。
- 他对愿望的理解包含后果、责任以及愿望对许愿者自身的反向影响。
- 他选择进入已经察觉可疑的地点，既有主动处理问题的一面，也包含让同行者置身风险的事实，不能只作英雄化解读。

# 7. 保护、受伤与事后休憩

撤离时，赛斯承担正面战斗，尽力阻挡扑向指挥使和少女的怪物，把两人送回安全区域。他随后独自离开，并在事后否认自己受伤，但其反应显示他是在掩饰伤势。

再次见面时，赛斯说明黑暗愿望可能反过来吞噬许愿者，而在尚能挽回时阻止少女继续走向极端，是他对“拯救”的理解。紧接着，他又因工作未完成而躲避其他神官，保留了支线一贯的性格反差。

# 8. 人物事实与能力边界

## 8.1 可由正文直接支持

- 赛斯缺乏日常工作纪律，常把文书、宣讲和组织任务推给他人。
- 他具有直接、强力的正面战斗能力，能在怪物群中保护同行者撤离。
- 他在危险发生时会优先让指挥使留在安全位置，并尽力保护没有战斗能力的人。
- 他能识别求助者身份与说辞中的破绽，但需要接触现实线索。
- 他把神官职责理解为在现实中帮助人、处理愿望的后果，而不是等待神迹代替行动。
- 他会用玩笑和夸张掩饰严肃判断、压力与伤势。

## 8.2 必须限定的内容

- “任何愿望都能实现”是赛斯的夸张自述，本页并未证明其字面成立。
- “神创造世界”等话语属于赛斯的信仰表达，不直接决定项目宇宙论。
- 识破少女身份来自地区知识和行为观察，不应改写成超自然全知。
- 保护他人和履行职责不消除其逃避工作、冒险和不当言行等缺点。

# 9. MOD 与项目正史使用边界

- 可将“愿望必须承担后果”“以现实行动帮助求助者”作为赛斯的核心人物主题候选。
- 不把赛斯写成宗教权威、神意代言人或能够实现任意愿望的超越者。
- 圣星教会和中央庭仍是不同体系；本页只表现赛斯把部分教会工作带到中央庭，并不证明两个组织合并。
- 如果将本支线纳入灾后历史，应同时保留他的缺点、喜剧气质、实际保护行为与责任观。

# 11. 来源缺口

- 页面没有说明设局少女的姓名、完整动机和之后去向。
- 页面没有说明支线的精确周目、日期和主线结局归属。
- 页面没有客观解释赛斯信仰中的神，也没有证明其神学陈述是宇宙事实。
- 页面没有明确说明赛斯受到的伤势程度及复职的最终行政结果。
