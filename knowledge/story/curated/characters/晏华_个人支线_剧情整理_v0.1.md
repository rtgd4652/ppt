# 使用边界

本文只整理《晏华／支线剧情》中能够由正文支持的剧情结构、人物行为与能力边界，不替代 Raw、Clean 和来源索引。

- 页面由五个主要剧情段落构成，包含两处选择结构。
- 页面开头的角色概述属于 Wiki 整理者的导语，不能单独作为最高等级事实证据。
- “凌驾于一般人类”“人形计算机”“中央庭最强黑客”等表述分别来自角色自述或叙述性评价，必须结合具体行动使用。
- 本支线发生于交界都市仍在重建、中央庭仍承担对抗怪物基础设施建设的时期；精确周目和主线归属未注明。
- 本文不把支线中的个人技术行为自动提升为中央庭长期制度或项目正史中的合法操作规范。

# 2. 中央庭的头脑

晏华与指挥使分别收到以对方名义发送的求援私信，因而共同处理堆积在指挥使办公室的大量文件。正文展示了晏华快速筛分事项、识别无效请求和推进工作的能力，也展示了中央庭日常行政中确实存在大量琐碎信息。

两人核对后确认私信均为伪造。晏华没有把它简单视为玩笑，而是从行为收益和潜在代价出发，判断发送者另有目的。随后他得知自己任职的税务部门发生爆炸；他优先调查伪造信息与爆炸之间的联系，而不是把事件直接归为偶然。

本段可支持：

- 晏华具备高效率的信息分类和行政处理能力。
- 他倾向从动机、收益、成本和时间关联判断行为目的。
- 他会协助指挥使处理事务，但不是中央庭的统治者，也没有取代指挥使或制度本身。

# 3. 来客与职责转移

霍克以城建部门受爆炸影响为由，把东方古街歌舞伎町和中央城区购物中心等建设任务转交中央庭。指挥使接受请求后，艾露比出现，并在受托后调查爆炸现场。

霍克的说辞把“共同参与城市重建”转化成“中央庭替城建部门完成其工作”。本段暂不直接判定霍克所有陈述均为谎言；其职责转移是否合理，要与后续晏华查明的实际受损程度合并判断。

# 4. 矛盾情报与制度边界

晏华指出，中央庭与城建部门虽然都参与城市恢复，但职责不同：中央庭主要建设对抗怪物的基础设施，城建部门负责居民生活和城市常规建设。他查明城建部门实际只受到有限破坏，因此认定霍克利用概念混淆把自身工作转给中央庭。

与此同时，艾露比报告爆炸现场存在幻力痕迹，与晏华早先“现场没有幻力痕迹”的观察冲突。晏华没有因为相信自己的初次判断而忽略新证据，而是把矛盾本身视为必须解释的异常，决定亲自调查并要求带上适合巡查的神器使。

本段可支持：

- 晏华重视组织分工和制度边界，不主张中央庭无限吸收其他部门职责。
- 他的判断可以被新证据重新检验；人物价值在于处理矛盾，而不是永远预先知道答案。
- 谨慎并不等于迟疑：一旦矛盾与怪物风险相关，他会立即组织调查。

# 5. 地下调查与骗局识别

晏华追回霍克在推卸工作期间的工资，并将其作为指挥使完成额外工作的补偿。随后两人在爆炸遗址发现通往地下矿洞的新隧道、怪物与被搬运的税务部门残骸。

表面证据指向“怪物从地下破坏税务部门”。晏华却指出证据过于完整，而且这条隧道在他第一次检查时并不存在。他据此判断，有人在爆炸之后开凿隧道并布置残骸，试图制造怪物袭击的假象。

结合能够面对怪物、能够伪造私信、拥有企业背景、与税务部门存在纠纷以及主动提供怪物证据等条件，他把嫌疑范围收束到艾露比。

选择树只改变指挥使是否立即看穿骗局：

- 选择认同表面结论时，晏华指出骗局的缺陷。
- 选择否定表面结论时，晏华确认指挥使的判断。
- 两条分支随后汇合，不产生不同案件结局。

# 6. 诱饵、路线控制与抓捕

晏华发布关于税务电子账本的公告，以艾露比可能关心的目标为诱饵，并与指挥使在办公室等待。艾露比现身后，晏华说明推理链条，随后由指挥使追捕。

追捕期间，晏华通过监控、门禁和路线信息限制艾露比的逃跑路线。艾露比也能短暂破解门禁，说明双方的技术对抗并非单向、无条件控制；最终晏华通过持续修正路线，让指挥使赶在她逃离前完成拦截。

本段可支持：

- 晏华的技术能力与战略判断相互配合：技术是执行工具，推理与诱导才构成完整方案。
- 他擅长把指挥使及现场条件纳入行动规划，而不是只依靠个人战斗力解决问题。
- 艾露比能够突破部分控制，表明晏华不是全知、全能或不可对抗的系统支配者。

# 7. 能力与人物事实候选

## 7.1 可由剧情直接支持

- 快速处理、筛分和判断大量行政信息。
- 依据动机、成本、证据完整度和时间变化识别欺骗。
- 面对矛盾证据时重新调查，而不是维护最初判断。
- 理解中央庭与一般行政部门之间的职责边界。
- 能使用信息系统、论坛公告、监控和门禁组织抓捕。
- 会保护指挥使，在危险区域要求其跟在自己身后，并在追捕时提供安全路线。

## 7.2 需要限定的表述

- “高于一般人类水平的认知观测”可保存为晏华对自身能力的表述，不写成客观全知。
- “中央庭最强黑客”来自叙述性评价；本页能确认其技术水平很高，但不足以建立跨时期、无条件的绝对排名。
- 转移霍克工资的行为是剧情事实，不自动证明这是中央庭的常规合法程序。
- 对艾露比的惩罚性语言带有喜剧和角色互动色彩，不应直接扩写为中央庭正式司法制度。

# 8. MOD 与项目正史使用边界

- 可以把本支线作为晏华“现实分析、责任边界、战略规划、信息系统应用”的人物证据。
- 不能据此把荷鲁斯之眼写成全知、预言或自动给出正确答案的能力。
- 不能把晏华写成中央庭统治者；他在本页承担的是重要辅助者、分析者和执行规划者角色。
- 不能把一次支线中的网络权限扩大成对所有文明系统的永久绝对控制。
- 支线的案件细节可以进入角色历史材料，但是否进入灾后至星际时代的连续正史仍需单独审核。
