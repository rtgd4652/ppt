# 使用边界

本文依据《拉比／支线剧情》正文整理事件结构、成长线、阿米特关系和神器现象边界，不替代来源三件套。

- 页面正文由五个主要剧情段落构成，包含两处一次性选择。
- 页面开头的任务摘要可以辅助确认流程，但其中“奇迹”“永远的谜团”等措辞不是机制结论。
- 拉比是儿童，且明确提到在贫民窟中挣扎求生；其偷窃行为必须同时放在社会经历与个人责任中理解，既不美化也不污名化。
- 阿米特被人物称为怪兽、魔兽、宠物和神器。本文保留这些不同视角，不在单一支线中强行统一其本体分类。
- 拉比在近距离爆炸中幸存、黑雾出现及阿米特消散后重现均为可观察现象，但具体机制仍需神器资料与世界观文档交叉验证。
- 精确周目、日期和主线结局归属没有在页面中说明。

# 2. 绑架救援与偷窃冲突

高校学园发生人质绑架。拉比骑乘阿米特正面冲入体育馆，突破绑匪火力并解救学生。事件结束后，学生发现钱包、糖果和玩偶等物品被拉比拿走。

阿米特阻止拉比离开，迫使他归还物品并向学生道歉。拉比承认知道偷窃不对，同时表达自己对其他孩子从小生活幸福、自己却在贫民窟求生的不平。获救学生仍把他视为英雄，并把玩偶送给他。

两项指挥使选择的措辞不同，但都进入拉比解释贫困经历的共同剧情，不形成不同结果。

# 3. 地下实验室与任务边界

中央庭调查绑匪武器来源，锁定地下实验室。拉比通过欺骗保安、偷取身份芯片和撬锁进入资料区，协助指挥使取得军火研究资料。

必须区分两类行为：

- 取得研究资料属于中央庭针对危险军火来源的调查目标。
- 拉比另行拿走怪物雕像作为送给阿米特的礼物，是任务之外的个人偷窃。

阿米特拒绝赃物并将雕像打碎。拉比把这种管教理解为歧视自己的贫民窟出身，情绪失控后用碎块攻击、辱骂阿米特，并要求它离开。无论指挥使选择劝阿米特还是劝拉比，冲突都会发生并进入共同剧情。

# 4. 拉比与阿米特的相遇

指挥使在东方古街找到离家出走的拉比。拉比讲述：自己曾在偷窃时遇到黑洞与怪物，随后黑雾中出现阿米特；阿米特驱赶其他怪物，从此照顾他，为他准备食物、要求规律生活，并建造了他第一次能够在床上睡觉的小屋。

该段能够支持阿米特承担保护者、照料者和道德约束者角色，也说明拉比虽然口头嫌弃，实际把阿米特视为家庭与归宿。它不能单独解释黑雾来源、阿米特本体或二者建立神器联系的完整机制。

# 5. 三木博士与真正实验室

三木博士说明先前实验室和资料是诱饵，随后绑架拉比并以他引诱阿米特进入真正实验室。实验室关押异世界怪兽，用于军火研究；博士试图捕获和解剖阿米特。

实验失控后，泰坦吞噬三木博士并攻击拉比。阿米特挣脱束缚、保护拉比和指挥使，并在爆炸中替众人承受冲击。重伤后的阿米特再次迎战泰坦，最终身体化为黑雾消散。

拉比在悲痛和愤怒中抱起炸弹冲向泰坦并引爆，击败泰坦后重伤昏迷。正文显示爆炸近距离发生，也在页面摘要中提到拉比身边似有黑雾，但没有给出其幸存的确定机制。

# 6. 消散、恢复与重聚

拉比醒来后认为阿米特已经死亡，并为离家出走和辱骂它感到后悔。指挥使依据中央庭档案说明，存在魔兽受伤后消失、又随着神器使身体恢复而重新出现的案例。

结尾中，黑雾进入病房并重新形成阿米特。阿米特替熟睡的拉比盖好被子，确认它已经回归。

这一段可以确认：

- 本次消散并非阿米特的永久死亡。
- 阿米特状态与拉比身体恢复之间至少存在人物档案所记录的关联。
- 具体是重构、召回、再显现还是其他机制，本页没有给出技术解释。

# 7. 人物成长与关系边界

## 7.1 拉比

- 具有勇气、战斗能力、潜入技巧和很强的临场行动力。
- 因贫困经历形成对资源和公平的强烈敏感，也以偷窃作为长期生存与反抗方式。
- 知道偷窃不对，却会以对象是坏人或社会不公为自己辩护。
- 在失去阿米特的冲击下承认自己的任性与伤害，产生明确悔意。
- 页面摘要称其后来帮助城市居民并成为“怪物骑士”；这可作为支线结局状态，但若纳入项目连续正史仍需时间线审核。

## 7.2 阿米特

- 不只是坐骑或武器，也是拉比的保护者、照料者和道德约束者。
- 主动要求拉比归还赃物、道歉并纠正生活习惯。
- 即使受到拉比辱骂和攻击，仍在其被绑架后实施救援并保护众人。
- 不应被简化为没有意志的装备，也不应仅凭本页写成人类意义上的普通宠物。

# 8. MOD 与项目正史使用边界

- 可把拉比的核心成长概括为：从以偷窃和反抗保护自己，转向理解责任、信任与主动保护他人。
- 不能把贫民窟出身等同于犯罪倾向，也不能因其成长而删除真实偷窃与伤害阿米特的行为。
- 不能把中央庭调查资料与拉比个人顺手偷窃混为同一种合法行为。
- 不能仅凭本页确定阿米特属于黑门生物、神器投影或其他单一本体类别。
- 不能把近距离爆炸幸存直接解释为不死、命运保护或已经掌握的神器技术。
- 指挥使是任务搭档、劝导者、搜寻者与救援参与者；本支线不锁定恋爱关系。
