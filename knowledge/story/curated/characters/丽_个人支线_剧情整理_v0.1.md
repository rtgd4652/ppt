# 使用边界

本文依据《丽／支线剧情》正文整理慈善重建、契约观念、旧城区收容、孤儿院援助、受助者资料危机与丽的家庭经历，不替代来源三件套。

- 页面包含明确的攻略失败文本，不能把所有选项视为仅改变一句回应后自动汇合。
- “正确选项／错误选项”的开头摘要是攻略结构说明，不是故事内人物对白。
- “拒绝执行清场”分支同时出现强烈拒绝文本和共同推进文本，现有页面结构不足以完全确定实际游戏中的接续方式，需保留验证项。
- 丽对旧城区居民、贫困者、犯罪者与商业行为的评价属于人物立场；不能直接提升为中央庭或项目的制度价值判断。
- 本页能确认其家庭富裕、母亲曾长期参与慈善并在落魄后遭受逼迫，不支持“皇室血统”设定。
- 精确周目、日期、主线路线归属与本支线是否进入项目连续正史保持开放。

# 2. 慈善、重建与商业方法

丽通过募捐、资产收购、店铺修复、收容所、就业岗位和物资发放介入旧城区重建。她要求核查捐助人与受助人身份，并记录捐款用途，避免重复申领或欺诈。

原先居住在待修店铺中的无家可归者并非被简单驱逐。丽为愿意工作和重新生活的人提供收容与就业渠道，并记住不同受助者的健康和家庭需求。她把受助者称为“廉价劳动力”，又坚持用债权人与投资回报的语言解释自己的行动；结合她拒绝亲自发放物资、否认关心受助者等连续表现，这主要是丽用商业措辞掩饰关心的傲娇表达，而不是她援助这些人的唯一动机。

因此：

- 丽的援助兼具慈善、投资、就业和秩序管理，不是无条件施舍。
- 该方案确实提供容身之处、物资和工作机会；“廉价劳动力”首先作为丽的傲娇和嘴硬措辞保存，不把它直接解释成项目的真实援助目的。
- 丽强调财务记录、身份审核和资金去向，反映其风险控制能力。
- 本页只展示一次旧城区项目，不能直接推导为中央庭普遍福利制度或完整经济模型。

# 3. 契约观念及其伦理边界

丽反复要求他人阅读合同，认为即使存在信任或求助关系，也必须理解条款并承担选择后果。企业主逐页审阅贷款文件、指出三项无法接受的条款后，丽同意删除并重新出具合同，这体现了协商可以改变交易条件。

与此同时，丽给指挥使的合同加入“协助甲方执行任何事项”等异常宽泛条款，并利用指挥使因信任而未阅读全文的行为要求其继续协助。结合两人的连续对话，这份合同主要表现丽面对指挥使时的毒舌、嘴硬、傲娇，以及希望在相处中维持优势地位；不能脱离人物关系，单独解释成正式商业剥削或中央庭制度。

因此：

- “契约精神”是丽的重要人物主题；与指挥使的合同同时承担人物互动和喜剧表达功能，不能只按严肃商业合同理解。
- 企业主的协商展示了相对完整的审阅与修改过程；指挥使的合同则展示了信息理解不足和权力不对等。
- 这些行为体现她既重视契约，又会对亲近对象毒舌、嘴硬并争取主导地位的角色矛盾，不应被写成中央庭标准契约制度。
- 合同确实构成剧情中的行动约束，但其叙事重点是丽与指挥使的相处方式；后续转化时应保留傲娇互动，避免把丽写成单纯压迫合作者的资本方。

# 4. 孤儿院、儿童与教育观

丽把一部分物资以一至两元的象征价格“出售”，另一部分作为无价礼物赠送，用支付行为向儿童说明劳动、购买和责任。她还承诺支付儿童到十八岁的教育费用，并把没有法律约束力的儿童合同称为“约定”。

本段可确认：

- 丽长期为孤儿院提供物资和教育支持，并对儿童表现出明显关心。
- 她区分商品、礼物和教育约定，知道与儿童订立的合同不具正常契约约束力。
- 她用商业语言包装善意，不代表儿童实际上承担可强制执行的债务。
- 本页没有证明其援助模式适用于所有儿童福利项目，也不能把象征收费直接写成普遍政策。

# 5. 企业主事件与风险判断

一名轻纺企业主因旧城区拆迁、补偿款未到位和黑门事件导致的新厂停摆陷入困境。在他受谣言影响、以“自爆”威胁求助后，丽先制止危险，再听取经营情况。

丽指出企业原本仅能维持收支平衡，经营者确实存在风险预估不足，但认为这不是全部责任。她愿意提供两千万贷款，并允许企业主审阅和修改部分苛刻条款。

该事件表明：

- 丽会区分经营漏洞、外部灾难和个人责任，不把失败简单等同于道德缺陷。
- 她愿意向存在恢复可能的企业提供资金，但援助仍以条件、审查和谈判为基础。
- 企业主在孤儿院外制造威胁是危险行为，后续获得贷款不能消除该责任。
- 丽承认自己故意加入几项近乎无法达成的条件以降低对方心理预期；这属于谈判操控手段，不应包装为中立合同范式。

# 6. 家庭经历与慈善边界

丽自述母亲出身富裕家庭、热衷慈善并帮助许多人；家庭落魄后，部分受助者反而逼迫母亲继续捐款。五岁的丽目睹父亲保护母亲，由此形成严格审核受助人、拒绝威胁和反对把他人财富视为理所当然的立场。

这一经历解释了她对慈善欺诈、道德绑架和勒索的强烈反应，但必须注意：

- 家庭富裕可以确认，不等于具有皇室、王族或贵族血统。
- 该回忆解释其价值观来源，不使她对所有贫困者的苛刻评价自动正确。
- 她明确认为金钱本身没有错，并可帮助真正陷入危险的人；她反对的是胁迫、欺诈和拒绝承担选择后果。

# 7. 名单危机、能力与行动边界

犯罪团伙盗取包含受助者详细信息的内部名单，企图出售资料。丽因担忧隐私泄露和技术破解，假意接受一亿交易以争取时间，并要求指挥使若同行就自行寻找不被发现的方法。

最终行动中，丽预先屏蔽工厂附近电讯号，并使用小型镭射炮驱赶高处敌人。指挥使借隐身帽秘密同行，在横梁落下时救她，并通过制造声音或主动现身吸引敌人注意；两个选项随后汇合到丽制服团伙、取回资料的结果。

可确认：

- 丽具备商业调查、信息保护、通信封锁、战术准备和直接战斗能力。
- 莱奥斯是其重要机械伙伴和行动支援者，承担运输、保护和文件递送等工作。
- 隐身帽由指挥使另行取得，不是丽或黄金伞的常规装备。
- 本页不能据此把丽写成能够任意控制金融系统、通信网络或全部城市基础设施的人。

# 8. 人物事实与项目使用边界

- 丽的核心不是“富有而善良的大小姐”单一反差，而是以商业、契约、审查和投资方式处理公共援助的复杂人物。
- 她能够关心受助者并提供实质帮助，也习惯以刻薄商业语言掩饰善意；面对指挥使时尤其会借合同、毒舌和嘴硬维持优势地位。
- 她区分需要援助、愿意重新生活的人与持续实施盗窃、诈骗和勒索的人，但其分类方法并非无争议。
- 她与黄金伞存在明确的公司和担保关系；本页不足以定义黄金伞的完整产权、组织层级和政治地位。
- 指挥使是捐助者、被合同约束的合伙人、调查协助者和战斗支援者；本支线不锁定恋爱关系。
- 不使用已经被项目否决的“皇室血统”描述，也不从豪车、财富或“大小姐”称谓推导王族身份。

- 页面没有给出“拒绝执行清场”选项在实际游戏中的完整接续结果。

- 页面没有说明隐身帽来源任务的完整过程和技术性质。
- 页面没有说明支线的精确周目、日期和主线结局归属。
