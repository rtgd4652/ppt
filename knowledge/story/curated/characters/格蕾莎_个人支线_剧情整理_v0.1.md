# 使用边界

本文依据《格蕾莎／支线剧情》正文整理事件结构、军医经历、医疗能力、战争创伤与医疗伦理边界，不替代来源三件套。

- 页面以多个三级标题和私信过渡构成完整支线，可归纳为五个主要阶段。
- 页面解析出六处选择，均为一次性回应并回到共同剧情，不形成不同结局。
- 格蕾莎自述过去是二十五岁的军医；伽梨耶称其当前身体约十二岁。本文区分生理外观、既有记忆和社会身份，不把她简单写成普通儿童或外表不变的成年人。
- 伽梨耶关于格蕾莎心理状态的描述是重要旁证，但不能替代专业诊断；正文能够确认战争记忆、负罪感和持续警戒。
- 幻力毒素试药、血液采样、暴力威胁等内容即使以喜剧方式呈现，也属于必须保存的伦理问题。
- 精确周目、日期、原国家和主线归属没有在页面中完整说明。

# 2. 诊所、身份与持续警戒

格蕾莎的旧城区诊所位于地下室，周围布置监控、红外设备和可能存在的陷阱。指挥使未经回应进入后，她将其当成敌人，以擒拿、枪械和绳套控制，确认身份后才同意前往孤儿院。

保育员说明，黑门事件后格蕾莎曾遍体鳞伤地出现在中央庭，身份和来历无法核实；大约一个月后，她通过医疗资格考试并取得历史最高分，随后因媒体追逐搬到旧城区开设诊所。

本段可支持：

- 格蕾莎拥有经过考试确认的医疗专业能力。
- 她维持高度警戒和军事化防护习惯。
- 对指挥使的暴力控制与威胁是剧情事实，不能因其医生身份或外表幼小而删除。

# 3. 孤儿院病例与诊断修正

格蕾莎第一次检查时将儿童病情判断为流感，并提醒儿童免疫力尚未成熟，需要持续观察。儿童短暂好转后集体昏迷，她再次检查并表面宣称无法确定病因，随后带指挥使到高处监视孤儿院。

格蕾莎说明，自己察觉儿童身上存在幻力，怀疑附近怪物正在吸取生命力，因此故意演出失败以让怪物放松警惕。她能识别异常类别，却不知道怪物具体藏身何处。直到监视中发现一名“儿童”形体扭曲，才确认怪物伪装在孩子之中。

她远距离射击削弱怪物，随后赶到现场消灭目标。儿童仍未苏醒，格蕾莎据残留幻力修正判断，确认怪物注入了麻痹意识的特殊幻力毒素，需要另外研制解药。

因此：

- 格蕾莎能力很强，但并非首次观察就掌握全部真相。
- 她会依据新现象修正诊断，并区分病因解除与残留毒素治疗。
- 她以儿童作诱饵实施监视、未经明确同意采血等做法存在伦理争议，不能直接作为中央庭标准医疗程序。

# 4. 军医经历与身体变化

伽梨耶展示格蕾莎珍藏的旧名片，上面记录她曾任“特级医疗工程兵、医疗四番队队长”，照片则是成年女性形态。格蕾莎随后亲自讲述：

- 她出生并成长于长期战争中的国家。
- 她选择成为医生，希望守护共同作战的人。
- 在一次被包围的战役中，她目睹战友死亡，自己也可能死亡或失去意识。
- 再次醒来时，她已经出现在交界都市，身体回到童年，并成为神器使。
- 她通过网络调查过去，逐渐接受现状，决定继续在新城市帮助需要帮助的人。

“也许因为黑门力量变小”来自伽梨耶的概括；格蕾莎自己也不清楚转变过程。因此，身体幼化、跨地域或跨世界抵达及神器使化之间的因果仍未确定。

# 5. 战争创伤与“昔日的彩虹”

格蕾莎把无法救回战友视为个人失败，并在儿童尚未苏醒时再次产生“没能保护他们”的挫败感。她保持诊所戒备、担心敌人突然出现，并以饮酒缓解压力。正文能够确认持续警戒、负罪感和痛苦回忆，但不在本文给出具体医学诊断。

试药后，指挥使进入疑似格蕾莎战场记忆的场景。格蕾莎尝试用神器力量向已毁城市降下生命药雨，但废墟和尸体没有改变。她由此明确：逝者不能归来，死者不能复生，即使在记忆中也无法改写已经发生的死亡。

她最终选择不再以遗忘作为目标，而是背负过去继续前行，在交界都市履行医生职责。彩虹成为记住死者和继续行动的象征，不代表战争结局被逆转。

该场景究竟是共享记忆、幻觉、梦境还是药物作用，正文和指挥使均未确认，必须保持开放。

# 6. 医疗能力与伦理边界

## 6.1 能力事实

- 格蕾莎能进行常规诊疗、血液检查、异常病例识别和药剂研发。
- 她能识别幻力毒素并研制对应解药。
- 她能制作调节、恢复指挥使生命力的药剂。
- 她具备军用观察、枪械射击、擒拿和战场判断能力。
- 她明确否认医生能够起死回生，神器也未能改变既成死亡。

## 6.2 伦理问题

格蕾莎在没有获得知情同意的情况下，先让指挥使服用幻力毒素，再注射解药和生命力调节药剂。她也承认此前已经进行动物实验，但这不能替代人体试验同意。

因此：

- 试验成功和药物有效不消除强制试药的伦理问题。
- 该行为不能成为中央庭医学规范或神器研究标准流程。
- 后续项目若表现其成长，应区分高超医疗能力与需要被约束的实验习惯。

# 7. 人物事实与项目使用边界

- 格蕾莎的核心不是“外表幼小的天才医生”单一标签，而是拥有成年军医经历、幼化身体、战争记忆和新生活责任的复杂个体。
- 她的暴躁、暴力和控制欲与持续警戒相关，但创伤背景不能免除其对他人造成伤害的责任。
- 她在孤儿院事件中既展现专业判断和责任感，也使用了风险较高、缺少沟通的处理方式。
- 她的未来方向是守护交界都市居民、继续行医并背负过去，而不是复活旧世界死者或重写战争。
- 指挥使是助手、试验对象、记忆见证者和未来同行者；本支线不锁定恋爱关系。
- 不能仅凭本页确定她来自另一个世界、同一世界的外国，或被黑门转移的准确宇宙学路径。
