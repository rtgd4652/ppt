# 使用边界

本文只对《避世的方舟》第一天已采集的 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 来源索引登记三棵不可重复的状态树，不是玩家对话选择：顶层为“剧情战胜利／失败”，两种结果下各自再判断“集齐全部黑核／未集齐全部黑核”。
- 三棵树均为 `repeatable: false`、`has_shared_continuation: false`。五处区域突袭正文在胜利与失败大分支中各收录一次；即使文字重复，自动结构也没有把它们登记成共同续段。
- “未集齐全部黑核”两个 Tab 都没有独有正文。空白只表示当前页面没有收录额外段落，不等于该状态没有后果。
- 区域突袭是取得空间道标后的独立玩法模块，页面排列不等于单轮游玩中必然按东方古街、中央城区、海湾侧城、旧城区、港湾区的顺序全部完成。
- 页面链接同时列出《深蓝之星》《黑暗中的身影》《终结（避世的方舟）》三个最终日，但来源索引没有把每个链接直接绑定到某一状态组合。结局条件需要与三页最终日正文交叉推定并保留人工核验。
- 希罗、安托涅瓦、奥露西娅关于黑门、新世界、活骸与倒计时的说法按说话者保存；本页没有独立验证其中每一项机制。

# 1. 巨大黑门开始降临

指挥使与安托涅瓦整夜带领神器使破坏黑门。指挥使持续提供幻力并准备净化黑核，安托涅瓦注意到其同时支持多名神器使的能力已经增强。

战术终端随后发现近处幻力浓度异常、大型结界展开。安托涅瓦判断新的黑门压力异常，提议借方舟接近。两人在观光塔附近见到希罗；天空裂隙吸入周围物体并缓慢扩张。

希罗把裂隙称为异界的一部分，宣称它会持续扩大、吞噬世界，使众人抵达“门”后并见证新世界。安托涅瓦反驳：

- 其所谓新世界并不存在；
- 巨大黑门只会毁灭当前世界；
- 普通活骸也无法在该环境中存活；
- 希罗的行为可能与零有关。

希罗在听到零后情绪剧烈变化，并展示已经成为新式活骸、仍能说话的奥露西娅。

# 2. 奥露西娅与“新式活骸”

奥露西娅自称意志仍在，并把活骸状态描述为强大与“永恒”，认为自己能一直陪伴希罗。希罗则说为得到新式活骸产生了大量“废料”，但已在巨大黑门降临前完成。

本页直接呈现：

- 奥露西娅以活骸形态说话和战斗；
- 希罗把她称为成功的“新作品”；
- 希罗承认此前存在大量失败或被其视为废料的对象。

下列内容仍属角色主张：

- 奥露西娅的“永恒”是她对自身状态的理解，本页没有展示无限存续；
- 希罗没有公开炼制过程、样本数量或意志保留条件；
- 安托涅瓦称巨大黑门会连活骸一同毁灭，是她对终局风险的判断。

# 3. 对希罗的剧情战与状态树

希罗身边有四名活骸化神器使巡逻守卫。安托涅瓦认为正面同时击败四人很困难，但希罗作为指挥使本身缺少战斗能力，可以绕开守卫直接攻击他。

```text
对希罗的剧情战
├─ 胜利
│  ├─ 集齐全部黑核 → 庆贺全区域讨伐完成
│  └─ 未集齐全部黑核 → 当前 Tab 无独有正文
└─ 失败
   ├─ 集齐全部黑核 → 同样收录庆贺正文
   └─ 未集齐全部黑核 → 当前 Tab 无独有正文
```

该树只表示来源页面保存的父子状态。它不能单独回答突袭模块发生在主战前还是主战后，也不能证明“主战失败＋最终集齐黑核”一定能进入与胜利相同的最终日。

## 3.1 剧情战胜利

希罗被逼入劣势后仍声称：

- 已成为活骸者不会恢复；
- 已开启的巨大黑门不会关闭；
- 距离完全毁灭只剩一天；
- 倒计时所指时间由自己规定。

指挥使追问希罗是否也看得到倒计时。希罗从“也”字意识到指挥使早已见过它，继而说“她”放弃了自己，自己最后也被“她”利用。

希罗取出一个陌生漆黑物件并消失，宣称自己不会死。随后指挥使一方击败其余活骸、回收希罗手上的黑门之核，页面称希罗势力从交界都市完全消失。

胜利并没有解决巨大黑门：它仍继续向城市压下。指挥使与安托涅瓦准备以黑核和神器使战力迎接最终战。

页面最后转到地下废弃铁道。一个仍标为“？？？”的存在察觉不到希罗气息、怀疑希罗已经死亡，并挣脱束缚离开。虽然 raw 资源图标为后续身份提供候选线索，正文未实名；当前不把说话者直接写成零或零的某一人格。

## 3.2 剧情战失败

希罗夺走指挥使一方全部黑门之核，要求安托涅瓦不要行动，随后从她胸口挖出结晶，使其退出当前战斗。希罗表示会留下指挥使的生命，因为将其视为同类，并希望其看到自己的愿望实现。

本分支直接确认安托涅瓦受到致命程度未明的重创、黑核被夺走、希罗仍能继续行动。页面没有在该段明确写出安托涅瓦死亡，也没有交代指挥使如何脱离现场。

失败段之后，来源再次收录五处突袭和黑核完成状态。由于自动转换没有展示这些模块相对主战的真实时序，不能按 Markdown 排列写成“希罗夺走所有黑核后，指挥使必然又逐区夺回”。

# 4. 五处区域突袭模块

五处模块的共同框架是：指挥使取得空间道标，安托涅瓦利用方舟协助突袭，完成战斗后收复区域并得到当地黑门之核。

| 区域 | 页面中的守方／阻拦者 | 完成后的直接结果 |
| --- | --- | --- |
| 东方古街 | 雯梓幻象；关卡还列出钟函谷与雯梓 | 收复东方古街，得到当地黑门之核。 |
| 中央城区 | 莱奥斯与丽；丽要求指挥使证明中央庭不是弱者 | 收复中央城区，得到当地黑门之核。 |
| 海湾侧城 | 阿岚 | 收复海湾侧城，得到当地黑门之核。 |
| 旧城区 | 艾露比 | 收复旧城区，得到当地黑门之核。 |
| 港湾区 | 濑由衣；关卡敌方图标另列普通怪物 | 收复港湾区，得到当地黑门之核。 |

这些模块不能被无条件写成固定时间线：

- 第二天只解锁了通过情报定位空间道标、用方舟突袭的总体功能；
- 第一天下的五个区域模块分别依赖对应道标与实际行动；
- 页面没有给出每一处的强制先后、是否能在同一轮全部完成，或中途失败后的开放关系；
- 主战胜负两边都有重复正文，说明 Markdown 排列更像页面条件内容汇总，而非单一连续镜头记录。

# 5. “集齐全部黑核／未集齐”状态

## 5.1 集齐全部黑核

页面出现全城黑门讨伐完成的庆贺公告。爱缪莎祝贺全区域解放，晏华认可成果但提醒不要松懈，安托涅瓦则请指挥使先享受庆祝。

该文本直接支持“全区域黑门讨伐完成”状态。它没有在本页明说总黑核数；最终日《黑暗中的身影》另以“全部 8 颗”为完整阈值，需要在结构文档中标为跨页证据。

## 5.2 未集齐全部黑核

胜利与失败父节点下的该 Tab 都是空白。可确认的是系统保留了这一状态；不可确认的是：

- 缺少多少颗；
- 是否仍可继续补收；
- 该状态直接对应哪一个最终日；
- 主战失败是否会覆盖或改变此状态。

# 7. 本日在路线结构中的作用

1. 希罗让巨大黑门开始降临，并展示保留语言与意志表现的新式活骸。
2. 指挥使与安托涅瓦迎击希罗；主战胜负决定希罗和安托涅瓦在最终日前的关键状态。

4. 全黑核／未全黑核构成另一条独立资源状态轴。
5. 三个最终日由“希罗是否被阻止、安托涅瓦是否仍能行动、黑核是否集齐”等状态共同区分，但精确游戏判定仍需实机核验。

# 8. 角色补充（限本页）

## 安托涅瓦

- 恢复后与指挥使共同连续作战，并用方舟承担接近巨大黑门和区域突袭。
- 认为希罗的目标是毁灭而非创造新世界，并把其情绪与零联系起来。
- 在主战失败状态下被希罗强行取出胸口结晶，之后状态未由本页明确交代。

## 希罗

- 公开以“抵达门后新世界”为巨大黑门计划辩护。
- 承认制造新式活骸产生大量被其称为废料的失败对象。
- 在胜利分支暴露自己知道倒计时、认识设置倒计时的“她”，并认为自己也被利用。
- 其消失方式、漆黑物件和“不死”说法均未在本页解释。

## 奥露西娅

- 以仍能说话的新式活骸形态出现，自称保有意志和更强力量。
- 把永恒陪伴希罗视为目标；本页没有证明她对自身风险和最终结局有完整认知。

## 指挥使

- 能同时为多名神器使提供幻力，并准备净化黑核。
- 从希罗对“也”的反应中确认倒计时不是只有自己看到或知道，但设置者身份仍未知。
- 主战与资源状态共同影响最终日前的可用条件。

## 地下未知者

- 只在胜利分支结尾出现，能感知希罗气息并解除束缚。
- 正文不实名；不得用资源图标或最终日信息倒填成已经公开身份。
