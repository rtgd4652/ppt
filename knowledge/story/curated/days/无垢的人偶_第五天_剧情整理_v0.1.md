# 使用边界

本文整理《无垢的人偶》第五天的 Wiki 正文。该页包含中央庭分裂主线和安的“同为异类”条件支线。

- 页面只有一棵 Tab 选择树：“拒绝希罗／跟随希罗”，不可重复、无嵌套。
- 本页“跟随希罗”不是成功加入：正文明确显示“无法反驳安托涅瓦，不能跟随希罗”。成功跟随后的其他路线内容不得并入本页。
- 两个选项最终都汇入安托涅瓦与希罗阵营交战、希罗离开、安托涅瓦病倒的共同续段。
- 希罗和奥露西娅关于净化黑核、神器使死亡、指挥使寿命与世界融合的说明均有明确说话者；本页没有独立实验记录完成验证。
- “同为异类”标注安好感度达到 80，是条件支线，不应写成每次主线第五天必然发生。
- P09／P10 视频仅作补充，不覆盖 Wiki 正文或选择结果。

# 1. 未知少女的梦

指挥使梦见白色房间中一名背对自己哭泣的少女。少女不断重复“没有时间了”，但指挥使无法接近，也不知道其身份。

本页只确认警告内容与指挥使的梦中感受。不能据后续轮回信息直接指定少女身份，也不能把“没有时间”解释成已经确认的具体倒计时机制。

# 2. 赛哈姆记录公开与七人众会议

安托涅瓦把恢复出的战斗影像交给指挥使，影像显示希罗强行使赛哈姆活骸化。她认为希罗刻意覆盖记录，且类似事件可能再次发生，因此召集中央庭七人众讨论对策。

页面直接呈现：

- 会议开始时，安托涅瓦、奥露西娅、罗纳克、爱缪莎、晏华和芙罗拉在场；
- 晏华指出，希罗作为中央庭创建者的威望不能由一条录像立即消除；
- 希罗带达尔维拉突然出现，达尔维拉袭击安托涅瓦；
- 会场中的神器使站位逐渐形成两边阵营，希罗称自己早已安排会在关键时刻站在自己一方的人。

正文没有在此逐一列出每名神器使最终所属阵营。除达尔维拉的直接行动和人物明确发言外，不应仅凭站位或后续路线把所有人提前归队。

# 3. 希罗提出的世界融合理由

希罗宣称自己找到黑门之核的新用途，主张不应继续净化，而应让异世界与现实世界融合。他给出的理由包括：

- 神器使需要生命力与幻力保持平衡；
- 黑门之核被全部清除、两个世界完全剥离后，神器使会因失去幻力而全员活骸化；
- 保留并利用黑核，可以创造神器使能够生存的世界。

奥露西娅进一步声称：

- 指挥使每次净化黑核都会消耗生命力；
- 神器使之所以宽容，是因为知道指挥使最终会为世界死去。

希罗确认她的说法，并邀请指挥使离开“充满欺骗的中央庭”。

上述是希罗阵营在会议上提供的解释。安托涅瓦随后表达即使牺牲自己也要让世界恢复原样，但这不等于她逐条验证了希罗的机制论证；后续世界观整理仍需用其他页面和组织资料交叉核对。

# 4. 唯一选择树：拒绝或尝试跟随希罗

## 4.1 拒绝希罗

指挥使承认希罗的说法有一定道理，但拒绝与“能轻易牺牲同伴”的人合作。希罗以中央庭没有告知净化代价反问，并把安托涅瓦愿意为目标牺牲自己及他人的态度称作与自己同类。

该选项直接保留在中央庭一方。

## 4.2 跟随希罗

指挥使考虑新道路，但随即想到：

- 不知道有多少神器使会跟随自己；
- 可能无法离开中央庭；
- 若无人愿意追随，独自加入希罗没有意义。

页面随后明确给出“无法反驳安托涅瓦，不能跟随希罗”。因此这是一次被当前状态阻止的尝试，不是加入成功。页面没有公开触发成功所需的完整好感、人数或其他隐藏阈值，不能自行补写。

## 4.3 共同续段

两个选项都进入以下共同节点：

1. 安托涅瓦拒绝希罗，并准备以神器使力量阻止其计划；
2. 双方发生战斗，安托涅瓦因使用力量超过安全界限而出现活骸化迹象；
3. 希罗宣布中央庭是留给安托涅瓦的最后礼物，双方自此为敌，并准备夺取更多黑核；
4. 安托涅瓦阻止指挥使追击，随后被送入地下治疗设施；
5. 晏华判断其活骸化进程只能缓解，中央庭局势从此改变。

自动清洗把战斗段放在“跟随希罗”之后，不代表它只属于该选项。

# 5. 中央庭分裂后的直接状态

本日结束时可以确认：

- 希罗与中央庭公开分裂，并带走一部分神器使；
- 中央庭人手与信用受到冲击；
- 安托涅瓦仍活着，但因过度使用力量出现活骸化，需住院并暂时不能使用方舟；
- 晏华接手大量事务，并要求继续寻找治疗可能；
- 指挥使承诺寻找让安托涅瓦恢复的方法。

“活骸化不可逆”在本段仍是晏华对当前知识的总结，不应写成跨所有后续剧情都不可被修正的绝对定理。

# 6. 安的“同为异类”条件支线

## 6.1 触发条件

页面标注：

- 安好感度达到 80；
- 东方古街出现怪物通告；
- 巡查东方古街。

该事件承接第六天为尘鱼拍照的支线。如果前置支线未发生，页面没有提供另一版正文；因此其连续触发条件仍需实机确认。

## 6.2 芙罗拉、尘鱼与袭击

安和指挥使发现芙罗拉正追杀此前获得照片的尘鱼。安依据上次接触保护它，并主张“生为怪物并非自愿”；芙罗拉则认为怪物即使短暂表现出理性，也仍可能恢复攻击本能，并指出神器使公开保护怪物会损害民众信任。

尘鱼随后突然袭击安，以紫黑光球腐蚀其腰腹。芙罗拉将它击杀，并把袭击解释为友好伪装后的本性恢复。页面直接确认的是袭击与死亡；“始终伪装”或“本性恢复”是芙罗拉的解释，本页没有展示尘鱼的内在原因。

## 6.3 安的机械身体暴露

安受伤处没有血肉，而是报废机械零件、皮肤胶材、粉色液体和短路火花。她拒绝指挥使接近，捡起损坏相机和尘鱼留下的照片后逃走。

这段直接确认安的身体至少包含机械结构，但本日尚未说明：

- 谁制造了安；
- 她的全部身体构成；
- 制造目的；
- 她是否会像尘鱼一样失控。

最后一项只是安与指挥使随后产生的不安，不能从身体材料直接推导。

# 7. 角色与组织信息（限本页）

## 指挥使

- 面对希罗的生存论证时，仍以赛哈姆被牺牲为拒绝合作的理由。
- 尝试跟随希罗的选项会被当前状态阻止；页面呈现其考虑神器使是否愿意追随。
- 在安的支线中亲眼看到其机械身体，但尚不知道完整来历。

## 安托涅瓦

- 主导恢复记录公开和七人众会议。
- 愿意以自身为代价阻止希罗，但战斗使活骸化风险转为现实。
- 对“世界恢复原样”的坚持是其价值立场，不自动验证具体世界机制。

## 希罗

- 主动分裂中央庭，并承认早在七人众形成时就布置己方人员。
- 以神器使生存和世界融合为公开理由招揽指挥使。
- 对净化黑核后果、神器使幻力平衡和融合正确性的陈述仍属其主张。

## 安

- 在条件支线中把尘鱼视作可能与人类共处的异类。
- 遭袭后机械身体暴露，并因恐惧而逃离。
- 她是否早已知道全部制造真相，本页没有说明。

## 芙罗拉

- 以保护民众及维持中央庭信任为由坚持消灭尘鱼。
- 对尘鱼袭击的“本性”解释不能替代机制证据。

# 8. 本页在路线结构中的作用

第五天是《无垢的人偶》的首个明确路线门槛：

```text
希罗邀请离开中央庭
├─ 拒绝希罗
│  └─ 留在中央庭 → 共同战斗
└─ 尝试跟随希罗
   └─ 当前状态无法反驳安托涅瓦，跟随失败 → 共同战斗

共同结果：希罗公开分裂；安托涅瓦受伤并开始活骸化；中央庭进入危机
```

本页能够确认《无垢的人偶》继续的是“拒绝／未能成功跟随”的状态，不能从这里反推出另一条路线的全部成功条件。
