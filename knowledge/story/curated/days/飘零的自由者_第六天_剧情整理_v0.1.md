# 使用边界

本页正文较短，只收录“学园的战斗”支线和每日补给记录。页面没有选择树，也没有说明该支线是否为进入后续结局的强制条件。

# 1. 当日状态

手账确认指挥使已经拒绝安托涅瓦的邀请，以自由人身份独自在交界都市生活。当日目标仍是认识更多朋友，但本页没有呈现新神器使正式加入队伍。

# 2. 学园附近的战斗

指挥使来到学园附近时，当地正在发生激烈战斗，地面留有怪物尸骸。一块巨石在爆炸中飞向指挥使，一名红色身影出现并连续开枪将其击碎；随后页面确认该人物为赛哈姆。

赛哈姆的行动可分为三层：

1. 立即消除飞石威胁。
2. 告知此处是交战区，要求指挥使转移到安全区域。
3. 拒绝指挥使参与战斗，称这是“我们的问题”，要求不要干扰其工作。

她仍询问指挥使能否自行行动，并在确认后要求其尽快离开，随后奔赴下一个战斗区域。

# 3. 叙事意义与事实边界

- 本段直接表现赛哈姆正在履行中央庭的城市防卫职责。
- 她既主动保护指挥使，也拒绝其介入中央庭的战斗事务。
- 指挥使因“与你无关”而感到被排除在外，这强化了自由人路线与中央庭组织成员之间的距离。
- 页面没有说明赛哈姆是否知道安托涅瓦保留了指挥使的战斗与信息权限。
- 因此不能把她的拒绝进一步解释成否定指挥使能力、私人敌意，或中央庭已经正式撤销指挥使权限。
