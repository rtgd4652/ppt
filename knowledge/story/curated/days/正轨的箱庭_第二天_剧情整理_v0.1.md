# 使用边界

本文只整理第二天已采集的 Wiki 正文，用于后续人工审核、角色档案与主线时间线工作。它不替代 raw 或 clean 来源文本，不把角色在极端处境下的判断、梦境／白色空间中的话语或尚未解释的称呼直接写成确定世界观事实。

- “我不想伤害安托涅瓦”与“帮助安托涅瓦解脱”是一次性玩家选择；来源索引明确标为没有已确认的共同后续。两项各自包含一段相似的白色病房与晏华救回场景，但不得因此把它们自动合并为同一次流程。
- “扫荡击败安和达尔维拉”之后，raw 层仅保留“剧情战胜利／剧情战失败”两个界面标签和一段后续文本，没有保存可验证的分项正文。本文不为这两个战斗结果补写差异。
- “海湾侧城黑核情报”列出了第三天的两个前置状态，但当前采集输出没有可靠保留失守文本与哪一项状态逐项对应的结构。因此保留状态和失守结果，不自行补写映射。
- “改版前／改版后”是 Wiki 版本对照，不是游戏内选择。

# 1. 当日开场：病房危机与外部进攻

第二天开始于指挥使在安托涅瓦病房旁醒来。页面再次呈现一个白色世界与身份未明少女的发言；她询问指挥使是否仍未找到自身意义。该段为叙事异常线索，当前页面没有解释该空间、少女或其话语的性质。

现实中的安托涅瓦活骸化进一步恶化。中央庭同时遭到外部闯入者攻击；晏华判断，对方选择此时进攻，是想利用活骸出现与外部攻势内外夹击、摧毁中央庭。他要求指挥使留在病房观察安托涅瓦，并在她真正成为活骸前作出决定。

安托涅瓦醒来时已失明，活骸化进程接近临界。页面将她此前希望在彻底活骸化前自我毁灭的意愿作为本次选择的直接背景。

# 2. 面对安托涅瓦的互斥选择

## 2.1 我不想伤害安托涅瓦

指挥使拒绝亲手终结安托涅瓦。安托涅瓦随即自行作出选择，留下希望指挥使“改变这一切”的遗言后死亡；页面以她的心脏留在托盘上呈现这一结果。

此后，指挥使因无法理解自己、安托涅瓦与牺牲的意义而前往中央庭门口。达尔维拉与安出现在那里；安认为指挥使已只剩迷茫、已不是自己所认识的人，并对其发动攻击。页面随后转入白色病房场景：身份不明的“安（？）”与先前白色世界中的少女短暂出现，少女明确否定“死亡即可离开”的想法，并要求指挥使回去。

指挥使之后被晏华等人救回。晏华在这条分支中说明，达尔维拉趁此夺走了中央庭的黑核；当指挥使要求神器使停止战斗、即使活骸化也先求生时，晏华接受命令但表示是否实际执行仍需斟酌，并拒绝以安托涅瓦之死为由立刻转入回避战略。

这一条分支的重点是：指挥使没有亲手处置安托涅瓦，安托涅瓦自行死亡；随后指挥使在迷茫中与安发生冲突，并在被救回后提出停止战斗的命令。它不能与另一选择中的“亲手破坏核心”和后续追击态度拼接。

## 2.2 帮助安托涅瓦解脱

指挥使在活骸化临界突破时破坏安托涅瓦的核心。页面将随后诞生的活骸怪物描述为因失去核心支撑而在出现时即死亡；指挥使由此直面同伴死亡，并将自己的状态理解为不再逃避。

之后，指挥使在中央庭门口见到达尔维拉与安，并主动走到晏华身边。安对指挥使的眼神表现出短暂的熟悉感；达尔维拉则表示他们是为“收割那个眼神”而来。页面接着给出“扫荡击败安和达尔维拉”的战斗节点，以及“剧情战胜利／剧情战失败”两个界面标签，但目前采集文本没有分别保存两种战斗结果的后续内容。

现有正文随后写道，安带着达尔维拉撤离；指挥使要求晏华派人追踪，并明确表示自己不会再犹豫，要正面面对安与希罗。该段应仅作为来源当前保留的后续文本记录，不能据此推断两个战斗标签必然得到相同结果。

这一分支同样随后出现白色病房与少女的打断，并由晏华救回；晏华也在这里说明中央庭黑核被达尔维拉夺走，且在指挥使提出停止战斗后保留对命令实际执行的斟酌。虽然相关文本与前一分支高度相似，但它们被来源分别放入两个选择体中，当前仍按互斥分支保留。

# 3. 本页的牺牲与选择议题

第二天把第三天病房中的价值冲突推进到临界状态：

- 安托涅瓦曾表达希望在成为活骸前自我毁灭；
- 指挥使可以拒绝伤害她，或主动破坏她的核心；
- 两条选择各自使指挥使形成截然不同的当下反应：一条进入迷茫、要求停止战斗，另一条转向不再犹豫、追击安与达尔维拉。

页面没有把任何一项选择直接标为唯一正确答案。它也没有在本页说明白色病房、少女介入或“死亡不能离开”的完整机制；这些只能作为后续核对的叙事线索。

# 4. 海湾侧城黑核情报：第三天前置状态

本节先列出：

- 第三天未处理希罗动向；
- 第三天已处理希罗动向。

其后文本描写阿岚力量耗尽时遇到达尔维拉，达尔维拉夺走黑核并留下“虚假的世界”相关说法，结尾标记海湾侧城被希罗占领、黑核在本周目内无法再回收。

当前 raw 与 clean 层同时保留了两个状态标签和失守文本，却未保留可可靠确定“失守文本对应哪一项第三天状态”的结构。因此这里仅记录：第三天的希罗动向处理是第二天海湾侧城内容的前置条件，且页面存在海湾侧城失守、黑核永久丢失的结果叙述。阿岚与达尔维拉的对话也应保留为当时人物的发言，尤其“虚假的世界”一语尚未在本页获得解释。

## 安托涅瓦

- 活骸化恶化至临界，并在醒来时已失明。
- 她此前希望在彻底活骸化前自我毁灭的意愿，构成指挥使选择的直接前提。
- 在“不想伤害”分支中由她自行结束生命；在“帮助解脱”分支中，指挥使破坏其核心。

## 晏华

- 判断外部进攻试图利用活骸危机摧毁中央庭，并安排指挥使留守病房。
- 在两条已采集分支中都作为救回指挥使的人出现，并说明中央庭黑核被达尔维拉夺走。

- 两人都出现在中央庭门口的冲突中，但在两条分支中的直接行动不同。

## 身份未明少女／白色病房

- 白色世界与白色病房在本页多次出现。
