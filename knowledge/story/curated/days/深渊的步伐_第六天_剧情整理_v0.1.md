# 1. 未知少女、安的照料与高校学园行动

指挥使在醒来前听到未知少女说“新的棋盘已经开始”，并期待其作出选择、努力挣扎。该段直接呈现了梦中发言，但没有解释少女身份、“棋盘”的含义或她如何观察轮回。

醒来后，安以女仆身份整理房间、准备早餐和便当，并催促指挥使前往高校学园协助希罗寻找黑核。随后生活区遭受袭击，赛哈姆以失控状态向指挥使发动攻击；安、罗纳克和希罗先后介入，罗纳克最终将赛哈姆压制。

这部分是本日进入活骸议题前的共同事件，不受后续是否隐瞒希罗行为的玩家选择影响。

# 2. 赛哈姆事件与活骸问题

赛哈姆被压制后，身体落下紫黑色结晶。希罗把她的状态称为“活骸”，并给出自己的解释：神器使体内存在幻力，幻力过高或过低都可能使神器使暴走。

安则说明中央庭目前采用的处理原则：活骸化一旦开始便不能恢复，在彻底丧失神志和继续恶化前将活骸消灭。她也回顾，早期净化和时间回溯等尝试没有解除活骸化，只延长痛苦或短暂恢复表象。

应分层记录：

- 赛哈姆袭击、被压制以及身体出现结晶，是页面直接呈现的事件。
- “幻力过高或过低导致暴走”是希罗在当时给出的机制解释。
- “目前不可恢复”及中央庭既有处置方式，是安对已知经验和制度的说明。
- 后续恢复的战斗记录直接呈现希罗强行夺取赛哈姆幻力结晶并导致其成为活骸；这与希罗起初将事件说成自然失控形成冲突。

# 4. 研究所共同续段与记录恢复

在“去见希罗吧”的路径中，希罗和安以镇静、时间束缚等方式暂时限制赛哈姆。希罗表示赛哈姆状态不乐观，并把解除活骸限制描述为接近“死者复生”的研究。

希罗随后提出：

- 神器使至少应被理解为英雄或超人，而不只是战斗兵器。
- 成为神器使会带来身体和精神上的提升，是一种更好的“进化”。
- 活骸化使这种进化仍不完整，但未来可能摆脱限制。
- 黑门不仅是危机，也可能是可以利用的机会。

这些都是希罗当时的研究立场和价值主张，本页没有独立验证其科学正确性。

赛哈姆很快进一步恶化。与此同时，安托涅瓦在中央庭检查战斗报告，发现记录被二次覆盖；她借方舟碎片向未署名对象询问并获得备份地址，最终恢复出希罗强行夺取赛哈姆幻力结晶的影像。这段恢复结果由叙事直接呈现，是本日对希罗最初说法的重要反证。

# 5. 安托涅瓦与希罗的研究所对峙

安托涅瓦进入研究所后，质问希罗隐瞒活骸研究、使用遗体和主动制造赛哈姆活骸的行为。双方冲突集中于研究伦理、组织权力和“前进”的代价：

- 希罗称活骸遗体是重要研究资料，研究将有益于神器使乃至人类，并称自己已与各国领导达成共识。
- 安托涅瓦把这种做法视为对死者的侮辱。
- 希罗以指挥使身份强调自己对神器使的统御地位，并要求安托涅瓦退出。
- 安托涅瓦在当时没有公开完整对峙内容，只让指挥使等待她之后的重要联络。

“已与各国领导达成共识”及“神器使只是被统御者”是希罗的主张；正文直接确认的是他用这些理由要求安托涅瓦离开，而不是各国协议或其权力解释已经被独立证实。
