# 使用边界

本文只整理“深渊的步伐／剧情／第一天”的已采集正文。第一天含有两场彼此独立的关键战斗，并在第二场胜利后继续按黑核状态和希罗生死分流；不得把两个“剧情战失败”合并。

- 第一场战斗发生在指挥使携带零的结晶逃离地下后，对手是希罗阵营的活骸化神器使。
- 第二场战斗发生在第一场胜利、结晶已交给雷切尔并重新追踪希罗之后，地点再次回到海底研究所。
- 第一场失败对应“结晶被夺、安托涅瓦无法恢复”；第二场失败对应“已完成前段救援，但追捕希罗失败”。两者均让希罗存活并进入“零的故事”，但中间结果不同。
- 只有第二场胜利后才检查“全黑核／未全黑核”，并决定是否可以放过希罗。
- Clean 页面把多处共同续段挂在最后一个选项下；本文按事件因果重新抽出，不改写 Raw 或 Clean。

# 1. 地下重逢：活骸零与零的结晶

指挥使因担心安托涅瓦无法获救，再次进入研究所地下。与前一日不同，此时占据身体的是具有明显威胁性的活骸人格。活骸零承认自己并非零，并称零从活骸化一刻起便已死亡，希罗始终没能把零的意识从它体内分离。

指挥使讲述外界近况后，活骸零因安托涅瓦将死而兴奋，并提出让指挥使杀死希罗、解除自身拘束。此时零短暂夺回表达能力，交出剩余半块幻力结晶，说明它能够治疗安托涅瓦且不会因此杀死活骸身体，请求指挥使同时帮助希罗和安托涅瓦。

“你也一起逃／我会回来救你”只改变指挥使对零的回应。两项都汇入取得结晶并逃离地下的共同续段；不能把后续撞见希罗写成第二项独占内容。

# 2. 逃离方式与晏华救援

指挥使在出口撞见希罗。玩家可以立刻冲撞逃跑并通过终端发出警告，也可以当场尝试通知神器使、被希罗击落终端。两种做法随后都进入被活骸化神器使截住、晏华带援军破顶进入的共同节点。

两项选择表现的是求援方式，不改变晏华已经持续观察指挥使并决定接触的事实。真正影响路线的是紧接着的第一场战斗结果。

# 3. 第一场战斗：能否带出结晶

## 3.1 第一场胜利

希罗阵营的活骸化神器使被击败。希罗尚未被控制，奥露西娅以缎带带走他；晏华则带指挥使乘潜艇逃出研究所。

回到中央庭后，晏华说明自己一直观察指挥使，并因其此前在旧城区阻止希罗而判断仍可接触。指挥使把零的结晶交给雷切尔，雷切尔据此开始治疗安托涅瓦。随后晏华要求尽快找到希罗，避免黑核再次落入其手。

这条胜利线保住了结晶与安托涅瓦的治疗机会，但没有抓住希罗，因此还必须继续第二场追捕。

## 3.2 第一场失败

第一场失败对应 Clean 页面后列出的第二段“剧情战失败”：希罗夺走零的结晶并追问指挥使对零做了什么，晏华只能救出指挥使。回到中央庭后，安托涅瓦已经无法恢复，病房外最终迎来预料中的绝望。

随后巨大黑门开始形成。希罗仍然存活，指挥使也没有再进入追捕成功后的黑核与处决判断；该状态直接通往“零的故事”最终日的“希罗存活”版本。

# 4. 胜利后的追踪与第二场战斗

第一场胜利后，晏华启用中央庭情报系统。希罗散布大量假消息，筛除后只剩中央城区线索；丽和指挥使清理废墟，发现通往水边的秘密入口和希罗预置潜艇，从而判断他已返回海底研究所。

第二场战斗发生在重新找到希罗之后，不是第一场战斗的重复标题。

## 4.1 第二场失败

第二场失败对应 Clean 页面先列出的第一段“剧情战失败”：指挥使未能在研究所击败希罗，晏华带其撤离。此时前一阶段已把结晶交给雷切尔，文本没有出现结晶被夺或安托涅瓦无法恢复的段落。

希罗存活，黑雾吞没天空，晏华判断融合正在开始，并为次日进入观光塔附近的巨大黑门作准备。该状态同样通往“零的故事”最终日的“希罗存活”版本。

## 4.2 第二场胜利

希罗拔出一支只装一颗子弹的手枪威胁指挥使。晏华击飞手枪，指挥使取得武器并反过来瞄准希罗。希罗此时承认：

- 他确实能看到倒计时；
- 即使不融合，当前因果崩坏的世界也会走向终结；
- 停留在循环中不会改变结局。

这些是希罗为自身行动提供的解释。后续禁闭室对话中，他又明确把最终目的表述为“毁掉这个世界”，并称活骸、神器使都只是手段；因此不能把他此前公开的“拯救或融合世界”继续当作完整真实目的。

# 5. 第二场胜利后的黑核条件

## 5.1 全黑核：可以放过或射杀希罗

### 放过希罗

希罗被带回中央庭禁闭，研究所仪器交给雷切尔，并帮助稳定安托涅瓦。之后页面提供三组对话入口：先与晏华交谈或直接探望希罗、询问最终目的或地下活骸零、以及以殴打或不理会回应希罗。

这些短选项后的共有结论应单独保存：

- 希罗承认自己想毁掉世界，并把神器使和活骸当作实现目标的手段；
- 希罗认为世界是到终点后回到原点的环，想亲自验证终末之后；
- 晏华拒绝陪同这种验证，并感谢指挥使没有让神器使参加实验；
- 雷切尔说明“新式活骸”只是身体异化先于精神崩坏的短暂状态，真正活骸化后仍会失去神智；
- 中央庭准备更谨慎地研究活骸化，并暂不贸然移动地下活骸零。

该路径保留了希罗手枪中的唯一子弹，并进入“神的棋盘”最终日。

### 射杀希罗

指挥使开枪杀死希罗。拘束装置随设置者死亡而解除，零的意识短暂寻找希罗，活骸人格随后夺取并吞下用于救治安托涅瓦的结晶，冲出研究所并在天空形成巨大黑门。

希罗死亡，次日进入“零的故事”最终日的“希罗死亡”版本。

## 5.2 未全黑核：希罗被射杀

在未集齐全部黑核状态下，页面提供“射击／没有理由犹豫”两个表达；两者均导向射杀希罗、活骸零夺取结晶并形成巨大黑门的共同结果。该状态没有“放过希罗”入口，因此同样进入“零的故事（希罗死亡）”。

# 7. 角色材料（限本页）

## 晏华

- 即使指挥使此前离开中央庭，仍持续观察其行动并依据实际选择判断是否重新接触。
- 两次关键战斗中均承担救援与撤退组织；第一场胜利后恢复情报追踪，第二场胜利时击落希罗手枪。
- 在放过希罗路径中，拒绝以毁灭世界验证循环，并推动对活骸化进行更谨慎研究。

## 安托涅瓦

- 是否得到零的结晶直接影响其能否接受雷切尔治疗。
- 第一场失败线明确失去恢复机会；第一场胜利后则保留稳定和苏醒可能。

## 零与活骸零

- 零主动交出最后半块结晶，希望救安托涅瓦和希罗。
- 活骸零主张杀死希罗以获得自由；希罗死后又夺走结晶、制造巨大黑门。
- 两者意愿相反，后续不得合写为“零夺走结晶”。

## 希罗

- 从否认看到倒计时转为承认知情，并公开追求世界终结与循环验证。
- 生死不是单纯角色状态，而是决定“神的棋盘”和“零的故事”最终日前置构成的关键变量。
