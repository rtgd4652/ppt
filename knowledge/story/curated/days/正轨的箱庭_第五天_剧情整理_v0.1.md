# 1. 当日开场：赛哈姆记录与会议召集

第五天开场承接赛哈姆事件。安托涅瓦向指挥使展示复原后的战斗记录；页面呈现的影像使指挥使得出“希罗强行让赛哈姆成为活骸”的判断。安托涅瓦因此认为，希罗对神器使已构成危险，并召集中央庭七人众中的在场成员讨论对策。

会议场景明确出现安托涅瓦、奥露西娅、罗纳克、爱缪莎、晏华、芙罗拉与指挥使。安托涅瓦提出以指挥使替代希罗的位置并将希罗监禁的设想；晏华则指出，希罗作为中央庭创始者的威望不会仅凭一段影像就消失。

# 2. 希罗现身与阵营冲突

希罗主动进入会议，并带来被称为“黑暗之子”的达尔维拉。页面随后呈现会议室内的站位分化；希罗表示自己已为这一刻准备了支持者，晏华指出希罗早已在七人众形成时布置能够站到自己一边的人，而爱缪莎没有接受希罗的拉拢。

希罗在此提出两类重要主张，均应按“希罗阵营在当时提出的解释”保存：

- 若黑门之核全部被净化、异世界与现实世界完全剥离，神器使将无法获得幻力并可能走向活骸化。
- 因此他希望利用黑门之核促成异世界与现实世界融合，创造能够使神器使继续存活的世界。

奥露西娅进一步称，净化黑门之核会逐渐消耗指挥使的生命力，并将其与神器使、指挥使的最终死亡相连。本页没有独立完成这些说法的真实性、条件或适用范围验证；后续引用必须保留说话者与本页冲突语境。

# 3. 面对希罗的选择与来源边界

## 3.1 拒绝希罗

指挥使拒绝与希罗合作，并将理由指向希罗牺牲同伴的行为。该选项卡中，希罗继续以黑门之核、神器使生存与指挥使生命代价质问安托涅瓦和指挥使；安托涅瓦则表示若是为了让世界恢复原样，可以承担牺牲。

该分支在来源文本中止于安托涅瓦与希罗围绕“目的、牺牲与是否同类”的争执，未在本选项卡中直接呈现之后的战斗与分裂结果。

## 3.2 跟随希罗

指挥使一度考虑跟随希罗，但页面明确给出“无法反驳安托涅瓦，不能跟随希罗”的结果。该选项卡随后继续呈现安托涅瓦与希罗的冲突、战斗条件及安托涅瓦的高强度战斗。

在此分支文本中：

- 希罗宣布中央庭将成为留给安托涅瓦的最后礼物，并表示双方此后为敌。
- 希罗表示会在城市中夺取更多黑门之核、让黑门扩展。
- 安托涅瓦因过度消耗而倒下，晏华安排其进入治疗设施。
- 晏华在该分支中将活骸化称为当前已知不可逆的事实，并说明可做的是缓解及继续寻找办法。

这些事件在当前 HTML 结构中属于“跟随希罗”选项卡下的后续文本。除非以后有其他页面或人工确认说明其为共同节点，不应自动写成“拒绝希罗”同样经历了完整相同的战斗后果。

# 4. 中央庭分裂的本页材料

第五天让“赛哈姆事件”从个人处置问题扩大为中央庭内部冲突：

- 安托涅瓦试图以已恢复的记录促成对希罗的限制。
- 希罗以长期准备的支持者和对黑门之核的不同利用方向回应。
- 晏华以分析与预判的立场指出希罗的威望和预先布局。
- 爱缪莎在会议文本中被明确描述为未接受希罗的拉拢。

本页可用于记录“中央庭内部发生公开的路线冲突”和“安托涅瓦、晏华、爱缪莎在该冲突中的不同位置”，但不应只凭本页列出完整的阵营名单、人数或所有成员去向。

# 6. 角色与组织信息（限本页）

## 安托涅瓦

- 以复原战斗记录为依据，主张将希罗的危险性告知其他核心成员。
- 尝试通过碎片空间限制希罗，并在冲突中强调力量应用于守护重要之物。
- 在“跟随希罗”选项卡的后续中因消耗过度进入治疗状态。

## 晏华

- 在会议中指出希罗的创始者威望和预先布局，使安托涅瓦的初始方案难以直接实现。
- 在后续治疗段落中给出本页关于活骸化不可逆、只能缓解并继续寻找办法的说明。

## 爱缪莎

- 作为会议中的七人众在场成员出现。
- 晏华指出希罗曾尝试拉拢她，而她没有答应；该信息只说明本页冲突时的立场线索。

## 希罗

- 对黑门之核、神器使存续和异世界融合提出与中央庭不同的路线主张。
- 通过达尔维拉及已有支持者改变会议中的力量对比。
- 其关于生命力、幻力与黑门之核的说法需保留为角色主张，等待跨页面证据核对。
