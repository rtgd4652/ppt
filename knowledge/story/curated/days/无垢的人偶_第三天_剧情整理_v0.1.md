# 使用边界

本文整理《无垢的人偶》第三天 Wiki 正文。页面由安的命令与反抗主线、三棵连续选择树、中央庭审问以及区域信任事件组成。

- 来源索引共有三棵玩家选择树，全部不可重复。
- 第一棵“愤怒／悲伤”和第二棵“发誓／我……”都是深度 0 的连续节点；第二棵不是“悲伤”独占。
- 第三棵才是真正的嵌套树：仅在第二棵选择“我……”后出现，提供“发誓／但是我……”。
- “追上去”以单一推进项出现，不是 Tab 选择树，页面也未收录“留下照顾安托涅瓦”的独立正文。
- 三次巡查中央庭与高校开发是条件事件序列，不是可重复问答菜单。
- 未知梦中少女、蝙蝠魔偶的说话者及其真实身份均未公开。
- P09／P10 视频只作补充，不覆盖 Wiki 正文。

# 1. 未知少女的警告与安的秘密任务

梦中少女继续警告“已经没有时间”，但本页没有说明倒计时对象或少女身份。

与此同时，安在希罗据点汇报刺杀安托涅瓦失败。希罗表示安托涅瓦退场符合计划，并质疑安为何对命令动摇；他声称自己没有给安设置过“怀疑”的指令，要求她再去执行任务。

安离开后，一只蝙蝠状黑色魔偶以少女声音与希罗交谈。对话呈现：

- 魔偶知道安即将踏入陷阱；
- 希罗反问此前战斗记录是否也是魔偶交给安托涅瓦；
- 魔偶没有直接否认，并把搅动局势视为消遣；
- 双方都知道希罗对外公开目的并非全部真相。

“魔偶就是记录提供者”是希罗的指认及对方语境上的承接，页面没有给出独立署名或技术记录；整理时应保留这一证据形式。

# 2. 安试图刺杀安托涅瓦

安进入中央庭特殊病房。她认为：

- 安托涅瓦醒来后会要求指挥使继续净化黑核；
- 指挥使可能接受牺牲；
- 没有指挥使和同伴的世界即使恢复也失去意义；
- 自己只想与大家永远在一起。

她因此对病床上的安托涅瓦召唤武器。指挥使及时制止，安逃离。页面随后只提供“追上去”作为推进项。

这些动机由安当场表达，但她同时受希罗命令。不能把刺杀简化为纯粹程序执行，也不能反过来断言完全出于自主感情；本页正是在呈现两种驱动力冲突。

# 3. 追逐、回收与达尔维拉战

指挥使在雨中追上安。安承认：

- 自己从一开始就听从希罗；
- 接近、讨好和跟随指挥使原本都是命令；
- 希罗要求她在指挥使与安托涅瓦之间选择，她选择除掉安托涅瓦；
- 任务失败后，她预期自己将被“回收”。

达尔维拉随后出现，确认任务是处理安的反抗反应，并引用希罗对安“想哭却无法拒绝”的评价。指挥使介入并击败达尔维拉。战后安惊讶于自己作为“人偶”竟然能够反抗。

页面直接确认达尔维拉被派来面对面回收；安关于体内可能存在远程病毒或控制程序的说法仍是她的担忧，而非本页检测结果。

# 4. 三棵选择树与共同去向

## 4.1 第一棵：愤怒或悲伤

| 选项 | 独有表达 |
| --- | --- |
| 愤怒 | 指挥使斥责安用“人偶”与重启次数否定自己，表示犯错、道歉、弥补正是人的经历，并承诺帮助她走回来。 |
| 悲伤 | 指挥使质问安为何不愿相信自己，也反对她把自身努力全部推给既定程序，强调不会抛弃她。 |

两项都确认安对指挥使重要，并汇入安要求指挥使发誓的下一节点。Clean 将“你发誓？”放在“悲伤”段末，但来源索引把第二棵树标为深度 0；不能把誓言树误写成只对“悲伤”开放。

## 4.2 第二棵：是否立即发誓

| 选项 | 结果 |
| --- | --- |
| 发誓 | 指挥使立即承诺；安以“笨死了的主人”回应，随后讨论希罗可能的控制手段。 |
| 我…… | 指挥使迟疑，安先认为无法承诺；进入嵌套的第二次选择。 |

## 4.3 第三棵：迟疑后的二次选择

该树父节点为“我……”：

| 选项 | 独有内容 |
| --- | --- |
| 发誓 | 指挥使最终作出同样承诺，安作出与立即发誓线相同的回应。 |
| 但是我…… | 安收回追问，不再要求为难的承诺。 |

无论立即发誓、迟疑后发誓还是继续迟疑，页面都进入共同续段：安担心希罗知道其失控后会启动隐藏程序；指挥使推断，既然希罗必须派达尔维拉面对面回收，就说明至少没有能直接让安自行返回的远程手段。两人随后一起回中央庭。

该推断是指挥使基于现象作出的判断，不等同于已经完成安身体的安全检查。

# 5. 晏华审问与证据边界

晏华把安视为潜在安全风险，询问她与希罗的关系。安回答：

- 不知道创造者是谁；
- 自有意识起就被设定为听从希罗，过去无法反抗；
- 现在出现了比希罗命令更想做的事；
- 今天以前的思维、所见所闻都已交给希罗，今天尚未汇报；
- 不知道希罗下一步计划和当前所在；
- 知道中央庭周边、海底研究所、旧城区和港湾区等据点。

这些是安的自述。晏华把变化概括为“希罗命令的脑内优先级被压低”，这是其分析，并没有解释具体技术原理。

晏华不允许安探望安托涅瓦，并表示中央庭无法信任二人；但他同时提供恢复信任的路径：处理各区域问题、证明与希罗决裂。主目标由此变为“获得中央庭的信任”。

# 6. 中央庭信任事件：本日两组

## 6.1 巡查中央庭（三次连续事件）

### 第一次：突如其来的骚动

雷切尔在城市地下寻找只会短暂存在于黑门附近的矿物，并因怪物和自制爆炸装置陷入危险。安主动提出护卫；雷切尔向晏华报告时隐瞒了晏华要求等待增援的真实意见。

### 第二次：地下坑洞再开发

一群实验员样人物也在地下布置探测装置。雷切尔追踪时踩中陷阱，安把指挥使和雷切尔抛出爆炸范围；晏华赶到并将受伤的雷切尔送医。页面后来由安把这些人称作希罗方科学家，但没有在初遇时展示正式身份文件。

### 第三次：宝贵的矿石

安和指挥使再次找到实验员及矿石稳定装置。对方不受安的时间暂停影响，并用爆炸撤走。安为保存遗留矿石碎片，尝试把通常只能维持数秒的时间暂停延长十余分钟；在指挥使供能下把矿石带回中央庭。

晏华接收材料，页面显示“中央庭信任度＋20”。雷切尔把安冒活骸化风险提供帮助视为心意证明；晏华仍没有口头承认完全信任。

三次事件是固定顺序的一次性任务链，不是同一巡查可无限重复刷取信任。

## 6.2 巡查高校学园

安因没有学校记忆而重视学园环境，提出重建。页面要求通过开发把高校学园提升至等级 4；达成后增加中央庭信任度 20。

该事件依赖建设状态，不含玩家 Tab，也没有说明重复提升能再次增加信任。

# 7. 本日信任状态

第三天正文明确提供：

| 来源 | 页面增量 |
| --- | ---: |
| 中央庭地下矿石任务链 | +20 |
| 高校学园开发至等级 4 | +20 |
| 本日合计 | +40 |

后续是否必须完成全部事件、信任初始值和满值阈值，应结合第二天与第一天状态页判断，不能只凭本页推导。

# 8. 角色材料（限本页）

## 安

- 在程序命令、对同伴的依恋和自主选择之间发生直接冲突。
- 亲口承认长期向希罗提交所见所闻，也承认刺杀安托涅瓦。
- 能反抗面对面回收，但仍担忧潜在远程控制。
- 为恢复中央庭信任承担高风险任务，并把保护指挥使与帮助组织置于自身安全之前。

## 指挥使

- 选择追赶安，并在回收战中介入。
- 三种誓言路径都不会抛下安，但承诺措辞和即时态度不同。
- 用“必须面对面回收”推断远程控制受限；该判断待技术核验。

## 晏华

- 优先把安当作情报泄露和控制风险处理，不允许其接触安托涅瓦。
- 同时提供以实际行动恢复信任的条件，并最终接收矿石成果。
- 其尖锐态度与行动上的救援、接收材料并存，不能简化为单纯敌意或已经原谅。

## 希罗

- 直接命令安再次刺杀安托涅瓦，并安排达尔维拉执行回收。
- 声称安的怀疑不在原有指令中，表现出对其变化的观察。
- 与未知魔偶共享部分计划，但真实最终目的仍未在本页公开。

## 未知魔偶

- 以蝙蝠状魔偶出现，声音如少女。
- 知道安的陷阱、希罗的隐瞒与记录泄露问题，并以他人不幸取乐。
- 身份、能力来源和与方舟碎片回复者是否同一，均未由本页确认。

# 9. 本页在路线结构中的作用

```text
安受命刺杀安托涅瓦
↓ 指挥使阻止并追赶
达尔维拉执行回收
↓ 战斗胜利
愤怒／悲伤
↓
立即发誓 ───────────────┐
我…… → 发誓／但是我…… ├─ 共同返回中央庭
                         ↓
晏华审问 → 以区域任务恢复信任
                         ├─ 中央庭矿石链 +20
                         └─ 高校学园开发 +20
```

本日完成了安从“执行希罗命令”到“第一次明确反抗”的转折，但没有证明其所有控制风险已经解除。
