# 使用边界

本文只整理已采集的 Wiki 正文，不覆盖 Raw 或 Clean，不从后续结局反写未知人影的身份，也不把页面为了展示男女版本而设置的 Tab 全部当成玩家可见的剧情选择。

页面 Clean 中四次出现“领取补给”，主要源于未知人影的男女表现版本和两种问句组合分别复制了同一段共同续文。它们不是第七天连续领取四次补给。

# 1. 路线入口：是否加入中央庭

第七天开场沿用共同起点。安托涅瓦邀请失忆的指挥使加入中央庭：

| 第一层选择 | 结果 |
| --- | --- |
| 我要加入中央庭 | 《飘零的自由者》进线失败，回到《正轨的箱庭》。 |
| 我需要考虑一下 | 指挥使以失忆和事发突然为由暂不加入；安托涅瓦接受，并保留其指挥使权限。 |

“我需要考虑一下”之后，页面先提供两种即时反应：

- “为什么要对我这么好……”
- “这都可以？”

两者都得到“因为你是我们的希望”的核心回应。Clean 把中央庭面临威胁、指挥使不可或缺以及再次邀请加入中央庭的共同续段完整挂在第二项之后；整理层暂按两项回答后的共同续段处理，等待人工确认。

随后进入第二次路线选择：

| 第二次路线选择 | 结果 |
| --- | --- |
| 我要加入中央庭 | 《飘零的自由者》进线失败，回到《正轨的箱庭》。 |
| 我还是当个自由人吧 | 正式进入《飘零的自由者》。 |

# 2. 安托涅瓦对自由选择的处理

指挥使坚持当自由人后，安托涅瓦：

- 接受选择，并允许指挥使以后改变想法；
- 要求指挥使住进中央庭空置且持续维护的宿舍；
- 表示有问题可以随时联系；
- 对指挥使的道歉以“当一个自由人，也挺好的”回应。

叙述者感觉她的话里“有一丝羡慕”，这是指挥使当时的主观感受，不应直接写成安托涅瓦已明确承认羡慕自由生活。

# 3. 空白短信与记忆空间

安托涅瓦离开后，战术终端收到一封空白短信。指挥使触碰后被白光包围，并在白色空间中见到看不清面容、却莫名熟悉的人影。

来源同时保存“她……”和“他……”两个版本，并分别使用女性／男性黑影头像和代词。结合页面结构，它们更适合暂记为表现状态版本，而不是指挥使可以任意决定未知人影性别的剧情选择。未知人影身份在本日仍保持为“？？？”。

随后真正影响开场回答的问句有两项：

| 问句 | 独有开场回答 |
| --- | --- |
| 你是谁？ | 人影称自己也是被困在时空迷城中的迷途者。 |
| 这是哪里？ | 人影称这里是保存这座城市记忆的地方。 |

两项之后汇入共同续段：人影表示自己等待已久，指挥使是第一个来到这里的人；这里保存城市的记忆，也可能保存指挥使失去的过去。

# 4. 未知人影提出的交换

人影以帮助指挥使找回失落记忆作为交换，提出两层愿望：

1. 指挥使去认识神器使、与他们成为伙伴；当他们成为指挥使的朋友时，也被人影视为自己的朋友。
2. 指挥使与伙伴一起帮助城市中需要帮助的人，实现更多人的愿望。

指挥使接受后，人影承诺会继续提供帮助。随后空间被黑暗吞没，指挥使从宿舍床上醒来；战术终端中的神秘信息仍在，但无法再次开启。

本日只能确认人影声称能够接触城市与指挥使的记忆，不能据此确认其真实身份、权限来源或说法完全可靠。

# 5. 雷切尔与自由行动规则

指挥使醒来后进入自由行动阶段。雷切尔认可其不加入中央庭的选择，并介绍仍处于测试中的“区域传送”：

- 可以跨越空间距离前往目标区域；
- 可以避开幻力屏障，对黑门区域中的怪物发动突袭；
- 传送到一个区域后，必须击败怪物并破坏黑门，才能继续传送至下一区域；
- 雷切尔以玩笑口吻提到测试设备存在把使用者“大卸八块”的概率。

这些内容是本路线的行动机制和雷切尔对测试机的说明。不能仅凭该页面把区域传送提升为中央庭已经成熟普及、绝对安全的常规技术。

本日目标更新为：与神器使成为朋友，一起实现人们的愿望。

# 7. 可确认的人物与世界信息

## 安托涅瓦

- 即使指挥使拒绝加入中央庭，她仍保留其必要权限并提供住处。
- 她尊重指挥使暂不加入的决定，同时保留未来重新加入的入口。
- 她把指挥使称为城市对抗威胁所需的“希望”。

## 指挥使

- 拒绝加入中央庭的主要理由是失忆、局势突然及希望先找回记忆。
- 虽未加入组织，仍保有指挥战斗、信息处理、巡查和战斗相关权限。
- 接受未知人影的交换后，开始以建立伙伴关系和实现居民愿望为路线目标。

## 未知人影

- 位于或表现为城市记忆保存空间中的未知存在。
- 自称同样是“迷途者”，并表示等待了很久。
- 希望通过指挥使间接结识神器使并帮助居民实现愿望。
- 身份、真实性、能力边界和与指挥使的熟悉感来源均未在本日揭示。

## 雷切尔

- 为不加入中央庭的指挥使提供区域传送测试技术。
- 该装置服务于路线自由行动，但仍有测试性质和行动限制。

# 8. 人工批准记录

- [x] `FRD-7-002`：两种即时反应共享“因为你是我们的希望”及再次邀请的续段，不把完整续文只挂在“这都可以？”下。
- [x] `FRD-7-003`：第二次选择“加入中央庭”仍退出；“还是当个自由人”才是正式进线路径。
- [x] `FRD-7-004`：“她／他”按未知人影的女性／男性表现状态记录，不判定为玩家主动选择其性别。
- [x] `FRD-7-005`：“你是谁／这是哪里”仅改变人影的第一句自我说明，之后汇入同一交换与愿望续段。
