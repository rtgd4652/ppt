# 使用边界

本文只对《深渊的步伐》第五天已采集的 Wiki 正文作结构化整理，不替代 raw 或 clean 来源文本。人物回忆、政治解释和关于黑门之核的机制说法，必须与页面直接发生的事件分层保存。

- “跟随希罗／拒绝希罗”是当日的主路线选择；页面明确标注“拒绝希罗”回归《正轨的箱庭》。本页后续长篇内容只属于“跟随希罗”路径。
- “我不会下手／假装要下手”是“跟随希罗”下的嵌套选择。自动清洗结果把共同离场续段挂在后一个选项下；本文将两项的独有回应与之后的共同事件分开。
- 海湾侧城、旧城区与港湾区的讨伐故事是可分别进入的区域行动模块，不应机械拼成单次游戏内必然按此顺序全部发生的线性上午。
- 奥露西娅、罗纳克和芙罗拉讲述的早期经历，以“角色回忆及其戏剧化重现”登记；其中对希罗内心、零的死亡和个人动机的判断不自动视为全知叙述。
- 梦中哭泣少女仍无正文署名，不能依据后续页面或资源名在本日提前确认身份。

# 1. 梦境、赛哈姆记录与七人众会议

第五天以未知少女在白色空间中哭泣并反复说“没有时间了”的梦境开场。指挥使无法接近她，醒来后也不知道其身份。

安托涅瓦随后召集指挥使，展示从前一日战术终端中恢复的影像。页面直接呈现的影像内容是希罗强行夺取赛哈姆的幻力结晶，使赛哈姆成为活骸。安托涅瓦认为希罗可能再次对神器使构成危险，因此召集中央庭七人众讨论对策。

会议中明确出现：

- 安托涅瓦；
- 奥露西娅；
- 罗纳克；
- 爱缪莎；
- 晏华；
- 芙罗拉；
- 指挥使与安。

安托涅瓦提出由新任指挥使替代希罗的位置，并把希罗监禁在碎片空间。晏华指出，希罗作为中央庭创建者拥有难以用一段影像立即消除的威望，因此安托涅瓦的方案并不容易实施。

# 2. 希罗现身与中央庭公开分裂

希罗主动进入会议，达尔维拉尝试袭击安托涅瓦。希罗将达尔维拉介绍为从未公开出现的七人众末位“黑暗之子”。随后在场神器使的站位发生变化，形成两个阵营。

本页对阵营位置提供了以下直接材料：

- 晏华指出希罗从七人众形成之初便准备了会在关键时刻支持自己的人。
- 晏华称希罗没有试图拉拢自己，曾试图拉拢爱缪莎；爱缪莎明确表示没有答应。
- 跟随希罗离开后，达尔维拉负责新据点和后续调查，奥露西娅、罗纳克、芙罗拉分别出现在希罗阵营控制或讨伐区域。
- 安托涅瓦、晏华和爱缪莎在冲突及后续页面中处于阻止希罗的一方。

这些材料足以确认中央庭在本日发生公开分裂，但七人众各成员在所有阶段的完整政治关系仍应结合后续页面整理，不能把“早已准备支持者”简化为所有人自始至终完全知晓希罗全部计划。

# 3. 希罗阵营提出的路线理由

希罗在会议中公开提出：

- 神器使需要维持幻力与生命力平衡。
- 若黑门之核全部被净化，异世界与现实世界完全剥离，神器使将因无法继续获得幻力而全员活骸化。
- 他希望利用黑门之核使异世界与现实世界融合，为神器使创造可以存活的世界。

奥露西娅进一步称，净化黑门之核会消耗指挥使生命力，黑门彻底消失时也将是指挥使死亡之时。希罗随后认可这一说法，并邀请指挥使离开“充满欺骗的中央庭”。

这些内容决定了指挥使面临选择时所获得的信息，但在本页仍属于希罗和奥露西娅的解释。页面没有以独立实验、旁白或其他阵营证据验证“全员活骸”“指挥使必死”和世界融合的完整因果；后续引用必须保留说话者。

# 4. 路线选择与共同续段

## 4.1 是否跟随希罗

| 选项 | 页面范围与路线意义 |
| --- | --- |
| 跟随希罗 | 指挥使握住希罗的手，安托涅瓦放弃继续劝说并转为武力阻止；进入《深渊的步伐》的中央庭分裂、离场与海底研究所据点内容。 |
| 拒绝希罗 | 页面只标记“回到主线正轨的箱庭”，不包含本页长篇分裂后续。 |

两项互斥。“跟随希罗”不是对希罗所有论述的客观认证，只能说明指挥使在当时根据所获信息作出阵营选择。

## 4.2 是否对安托涅瓦下手

该选择只出现在“跟随希罗”之后：

| 选项 | 独有内容 |
| --- | --- |
| 我不会下手的 | 希罗称指挥使是好人，并接受不由其下手。 |
| 那就假装要下手吧…… | 晏华从受伤状态举枪警告，若指挥使真的下手，他不介意同归于尽；希罗称赞晏华。 |

两项之后都进入同一离场续段。晏华举枪只属于“假装要下手”的独有内容，不能写入拒绝下手分支；达尔维拉取出方盒、希罗阵营离开中央庭、安追随指挥使和新据点建立则属于选择后的共同结果。

# 5. 跟随希罗后的共同结果

达尔维拉的恶魔从安托涅瓦身上取出方盒，并报告“黑核回收完毕”；希罗将其称为分手后不再需要的“定情信物”。页面直接呈现这组行动和称呼，但没有在本段解释方盒、安托涅瓦、方舟及黑核之间的完整机制关系，不应自行补全。

指挥使与希罗阵营离开中央庭后，安主动追上并请求继续跟随指挥使。她一方面承认对不起安托涅瓦，另一方面强调自己选择追随指挥使，并用“达成目的的方法可以不同，只要结果正确”解释自己的决定。

达尔维拉宣布新据点已经整修完成，路线据点转移至海底研究所。页面同时给出当时的区域阵营状态：

- 中央庭、高校学园属于中央庭阵营，暂时无法前往；
- 东方古街、中央城区属于希罗阵营，可以建设；
- 海湾侧城、旧城区、港湾区仍需讨伐。

达尔维拉随后要求指挥使通过后续区域行动了解希罗，并警告中央庭会进行阻挠。这是本日从政治分裂转入区域讨伐与人物回忆的结构节点。

# 6. 三条区域讨伐与希罗早期经历

三条区域线都以“指挥使询问希罗是怎样的人”为共同目的，但由不同人物讲述，不可相互替代，也不应假定同一周目必然在第五天依次完整经历全部九段战斗。

## 6.1 海湾侧城：奥露西娅的“回忆之花”

奥露西娅回忆黑门事件发生不久后，希罗带着名为零的少女进入城市：

1. 希罗与零救助逃离避难所的男人，之后仍前往调查避难所。
2. 零从路上数名男子身上的血迹判断现场可能另有受害者；两人继续前进。
3. 他们在避难所见到奥露西娅。奥露西娅因对背叛和爱意的扭曲执着攻击他人，败北后被希罗以糖果和谈话接近，最终提出跟随希罗。

奥露西娅将自己的加入描述为被希罗的魅力和难以捉摸的内心吸引。指挥使可以回应“不认为她随便”或认为“还有更重要的原因”；两项先产生简短态度差异，随后共同进入奥露西娅对希罗和零的进一步观察。

奥露西娅称希罗看待零的眼神“像宠物”，并直接告诉指挥使零后来死了。前者是她的个人观察，后者是她在本页给出的信息；零如何死亡、她口中的“涅瓦”是谁以及希罗与零的真实关系，均没有在本段展开。

## 6.2 旧城区：罗纳克的“追忆之铁壁”

罗纳克把自己支持希罗解释为一场为了族人的交易，并回忆三次关键接触：

1. 他为保护迁入交界都市的族人独自断后，希罗和零介入抵挡怪物并首次提出招募。
2. 族人暂住地下通道时再次遭到怪物袭击，希罗和零帮助战斗、治疗与安葬死者。
3. 希罗取得可供罗纳克族人生产、生活和防御的土地，并表示无论罗纳克是否加入都会赠予；罗纳克仍以战斗检验希罗，之后接受土地并加入。

罗纳克明确说自己最初认为希罗理智、狡猾，可能为达目的不择手段；但他也认为接受已经发生的恩惠就必须支付代价，即使被世人唾骂也承担自己的选择。

因此，本页可以确认罗纳克以族人安置和既成恩惠解释支持行为，不能把他的选择简单概括为对希罗全部理念的无条件认同。

## 6.3 港湾区：芙罗拉的“静谧之声”

芙罗拉称自己能从心跳中感知困惑、猜疑或恶意，并把希罗的心声描述为“像赤子一样纯粹”。她随后回忆：未婚夫去世后，自己一心求死，反复进入怪物密集区域；希罗和零跟随并保护她。

希罗告诉芙罗拉，普通怪物难以杀死已经成为神器使的她，并在听到她质问世界不公后提出：如果世界没有道理，就毁掉世界；他也把自己描述为因失去最重要之人而想向世界复仇。芙罗拉因此同意协助。

这里需要区分：

- 芙罗拉丧失未婚夫、寻死、与希罗相遇及加入，是她的回忆内容。
- “希罗心声纯粹”是芙罗拉基于自身能力作出的判断。
- “毁掉世界”“向世界复仇”是希罗在回忆中的明确主张。
- 心声纯粹不等于行为正确，也不等于芙罗拉能够验证希罗计划的全部后果。

# 7. 角色材料与证据层级（限本页）

## 安托涅瓦

- 依据恢复记录召集会议，试图限制希罗并保护其他神器使。
- 在指挥使选择希罗后转而武力阻止；冲突中受伤并被达尔维拉取走方盒。
- 本页没有从她的视角完整解释分裂后的身体状态和方盒性质。

## 晏华

- 预判希罗威望和早期布局，指出安托涅瓦方案的现实困难。
- 明确说自己不在希罗拉拢目标之中，并指出爱缪莎拒绝过拉拢。
- 仅在“假装下手”分支举枪警告指挥使。

## 爱缪莎

- 在会议中拒绝希罗阵营的拉拢。
- 本页材料可支持其当时站在阻止希罗的一方，但不能据此替她补写完整政治理由。

## 安

- 在中央庭冲突后选择跟随指挥使，而不是被希罗直接列入预先布置的七人众支持者。
- 她对结果与道路的说明是对个人决定的解释，不是本页已经验证的普遍伦理原则。

## 希罗

- 公开提出世界融合和神器使存续路线，并依靠预先准备的支持者完成分裂。
- 对奥露西娅、罗纳克和芙罗拉采取不同的接近与招募方式；这些早期行为主要通过三人的回忆呈现。
- 对黑门之核、神器使灭亡和指挥使生命代价的解释需要后续独立证据核对。

## 零

- 在三条早期回忆中作为希罗身边的少女出现，具有感知黑门、战斗和治疗能力。
- 奥露西娅称她后来死亡，但本页没有交代死亡经过。
- 零提到“涅瓦还在家里等着”，本页没有完整说明称呼对象，不应自行补写。

# 8. 本页在主线资料中的作用

第五天完成了《深渊的步伐》的正式阵营转折：赛哈姆事件成为公开分裂的导火索，希罗以神器使存续和指挥使牺牲为理由招揽指挥使，指挥使选择离开中央庭，海底研究所成为新据点。

三条区域回忆则把“为什么有人支持希罗”拆成不同个人经历：

- 奥露西娅：吸引、欲望与难以捉摸的关系；
- 罗纳克：族人生存、恩惠与承担交易代价；
- 芙罗拉：失去、复仇与希罗心声的纯粹性。

这些原因互不相同，不能被统一缩写为“七人众认同世界融合”，也不能用回忆中的善举直接抵消当下赛哈姆实验的伦理问题。
