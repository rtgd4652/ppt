# 使用边界

本文只整理第三天已采集的 Wiki 正文，供后续人工审核、角色档案与主线时间线使用。它不替代 raw 或 clean 来源文本，不把角色的自述、威胁、推测或隐瞒自动升级为无条件成立的世界观结论。

- “追上去”与“留下来照顾安托涅瓦”是一次性玩家选择，来源索引明确标为没有已确认的共同后续；两条内容不得拼写成同一次经历。
- “海湾侧城黑核情报”的“处理／不处理”是另一项独立资源选择；“改版前／改版后”仅为 Wiki 版本对照。
- “旧城区黑核情报”先列出第四天的两个前置状态，但当前采集输出没有可靠保留其后的失守文本与哪一项状态逐项对应的结构。因此保留条件和失守结果，不自行补写映射。

# 1. 当日背景：分裂后的中央庭与希罗据点

第三天以中央庭分裂后的维持压力为开场。指挥使将自己定位为在安托涅瓦恢复前、为稳定中央庭而四处奔走的执行者；同一段叙述还呈现中央庭人员变少、有人离开希罗阵营但更多人投入希罗阵营的局面。这些内容可用于记录分裂后的组织压力，但不足以单独推导完整的人员规模或所有阵营归属。

与此同时，页面将镜头转向希罗的一个据点：安未能完成此前任务后返回。希罗谈及安托涅瓦可能醒来并公开事情的风险，称安托涅瓦的“退场”原本就在自己的计划中；安表示自己开始无法理解其中的原因，却仍答应再次行动。

这一段还出现一名身份未明、蝙蝠形态的黑色魔偶。它与希罗谈及战斗记录、安托涅瓦、安和“真正目的”等话题。魔偶称其他人并不了解希罗的真正目的，但本页没有揭示该目的的具体内容，也不足以确认魔偶身份、立场或其与希罗合作的全部条件。

# 2. 特殊病房事件：安与安托涅瓦

指挥使进入特殊病房后，页面直接呈现安托涅瓦的活骸化已发展到中途，黑色纹路遍布身体。安在病床旁说明自己的选择：她无法接受“牺牲自己以恢复世界”的逻辑，也不愿意接受没有指挥使与其他同伴的未来。

随后，安对安托涅瓦召唤武器；指挥使赶到后，安没有回答质问便逃离。该病房冲突发生在玩家作出“追上去／留下来照顾安托涅瓦”选择之前，是两条分支的共同前提。它展示了安在希罗命令、个人感情和对牺牲逻辑的抵触之间的冲突，但不能仅凭本页将她的全部动机归结为单一原因。

# 3. 面对安离开的互斥选择

## 3.1 追上去：安的自述与离开

指挥使在雨中追上安。安在该分支中自述：自己从一开始便听从希罗的命令，接近与陪伴指挥使也是任务的一部分；希罗要求她在指挥使与安托涅瓦之间作出选择，而她选择了安托涅瓦。

安还表示自己任务失败后也会消失，并要求指挥使回到安托涅瓦身边。她最后否认自己对指挥使和安托涅瓦的感情后离开，指挥使则反省自己或许未能及早了解她的异常。

这一段应保存为“安在追上去分支中作出的自述与离开”，而不是直接扩展为安所有行为的最终、无疑义解释。

## 3.2 留下来照顾安托涅瓦：牺牲议题的说明

指挥使选择留在病房后，安托涅瓦听到了安先前的话，并坦言自己仍决定以指挥使的生命净化黑门之核。她在本分支中提出以下说明：

- 若指挥使持续净化黑门之核，终有一天会耗尽生命力；
- 黑门关闭后，神器使也会逐个死去；
- 若只能在世界中的众多人和交界都市仅存的神器使之间选择，她会选择前者。

安托涅瓦将这种取舍与希罗的做法相比较，并承认自己也会以数量衡量生命。指挥使则反驳她并非无情；之后，安托涅瓦说明中央庭隐瞒这些信息，是出于担心指挥使离开，而非要强行把指挥使当作净化工具，并要求指挥使依照自己的意愿选择。

这组关于生命力、黑门关闭和神器使命运的内容只明确出现在“留下来照顾安托涅瓦”分支中。它可以作为安托涅瓦在该条件下提供的重要解释，但不能自动视为“追上去”分支中已经得到的同一段信息，也不应脱离后续证据直接判定全部机制细节。

页面在分支文本之后以界面文字标记“安已经离开了你”。由于来源选择树未确认共享后续，当前整理不把这条标记强行归入任一选择的共同结局；需要游戏实测或原始页面结构进一步确认其适用范围。

# 4. 区域黑核情报与条件边界

## 4.1 旧城区黑核情报：第四天前置状态

本节先列出：

- 第四天未处理希罗动向；
- 第四天已处理希罗动向。

其后文本描写希罗在旧城区与艾露比交涉黑门之核，并在薇拉出现后发生冲突；结尾标记旧城区被希罗占领，黑核在本周目内无法再回收。

当前 raw 与 clean 层同时保留了两个状态标签和失守剧情，却未保留能可靠确认“该失守剧情对应哪一项第四天状态”的结构。因此这里只记录为：第四天的希罗动向处理会作为第三天旧城区内容的前置条件，且页面存在旧城区失守、黑核永久丢失的叙述；具体映射待人工确认。

## 4.2 海湾侧城黑核情报：本日独立选择

页面明确提示希罗将在下一日入侵海湾侧城并夺取黑核。玩家可作出的独立选择及页面直接结果如下：

| 选项 | 页面明确呈现的结果 |
| --- | --- |
| 不处理 | 下一日希罗将夺取海湾侧城黑核。 |
| 花费情报 60 处理 | 成功阻止希罗夺取海湾侧城黑核。 |

这不是病房选择的后续，也不是旧城区前置状态的同义表达。后续引用必须单独保留是否投入情报资源这一条件。

# 5. 角色与组织信息（限本页）

## 安

- 在病房冲突前表现出对希罗命令与自身感情之间的动摇。
- 对“以牺牲恢复世界”的路线明确表达无法理解和抗拒。
- 在“追上去”分支中说明自己听命于希罗，并在任务失败后离开；这仍是该分支内的自述。

## 安托涅瓦

- 以活骸化中途、接受特殊病房治疗的状态出现。
- 在“留下来照顾安托涅瓦”分支中说明自己会把多数人的生存置于神器使存续之前。
- 强调中央庭不能强制指挥使成为净化黑核的工具，并把最终选择权交还给指挥使。

## 希罗

- 在据点中对安托涅瓦醒来与公开事件表现出明确担忧，并试图继续推动安执行任务。
- 其与身份未明魔偶的对话表明，他对中央庭未被完全摧毁的现状并不满意，但将其视为仍可接受的挑战。
- 本页不揭示其“真正目的”的具体内容。

## 晏华与中央庭

- 晏华在补给版本对照中出现，未在本日主线分支中获得新的独立剧情段落。
- 中央庭在本页被描写为分裂后人员稀少、需要由指挥使与仍在岗成员维系的组织；这是一段当日环境叙述，不等同于完整组织史。
