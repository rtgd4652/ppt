# 使用边界

第一天来源页只保存末日前的环境描述、自由行动框架和三个最终日导航入口。导航链接证明路线存在三种结局，但没有公开它们的完整解锁公式。

# 1. 末日前的城市状态

页面描述天空转阴、天气怪异，城市中弥漫恐惧与不安。指挥使仍相信即使如此也存在希望，并以“还有明天”鼓励自己，随后进入最后一次自由行动。

这些文字可以确认末日前夕的公共氛围和指挥使的希望态度，但没有说明天气异常的具体物理原因，也不能单独证明居民已经知道世界将在当天结束。

# 2. 三个最终日入口

来源页列出三条结局导航：

| 结局 | 当前可确认的结构意义 |
| --- | --- |
| 终结 | 独自面对末日与轮回重启的收束。 |
| 两个人的城市 | 与本周目已经攻略的神器使共同度过最后一天。 |
| 记忆的种子 | 濯樱祭愿望链完成后，围绕记忆种子形成的收束。 |

其中“两个人的城市”的候选索引结构已经人工确认；但第一天页面没有提供三个结局所需的好感度、神器使数量、愿望完成数量或其他隐藏阈值。因此不得根据导航顺序自行补写数值条件。

# 3. 页面结构

```text
第一天开始
├─ 天空、天气与城市情绪出现异常
├─ 指挥使仍保持希望
├─ 最后一次自由行动
├─ 领取补给／记录每日报告
└─ 根据本周目状态进入一个最终日
   ├─ 终结
   ├─ 两个人的城市
   └─ 记忆的种子
```

三条最终日是互斥收束，而不是第一天之后依次发生的三个章节。

# 4. 时间与叙事边界

- “还有明天”是指挥使在末日前夕的希望表达，不代表本轮世界必然正常进入下一日。
- 页面没有明说指挥使当时已经掌握七日轮回真相。
- 页面只提供结局入口，不说明玩家是否在第一天直接进行可见选择，或由系统依据本周目状态自动判定。
- 结局正文、候选神器使范围和濯樱祭愿望链分别由对应页面独立保存。
