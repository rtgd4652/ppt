# 使用边界

本文只整理“被抛下的人／剧情／第一天”的已采集正文，不替代 Raw 或 Clean，也不把希罗对异界、神器来源、死者复活或世界融合的假说直接提升为世界观定论。

- 当日正文在结尾才按“黑核、活骸等要求”分流；此前安失控、希罗解释巨大黑门与前往异界的计划均为共同前提。
- 来源只写“黑核、活骸等要求达成／要求未达成”，没有列出黑核数量、活骸人数、具体角色、区域完成度或其他阈值；本文不自行补数值。
- 条件达成进入“被抛下的人”最终日；未达成进入来源称作“终结”的特殊失败段落，当前采集对应“深渊的步伐／剧情／特殊灭世3”。
- 希罗把安的失控解释为城市幻力浓度不均，并提出以现实与异界融合解决问题；这是其研究判断和行动理由，不是已经验证的因果关系。

## 路线分流复核

```text
共同剧情：安在新式活骸化后失控
→ 希罗提出“幻力浓度常规化”
→ 以指挥使力量开启巨大黑门
→ 宣称可从异界寻找复活类神器
→ 要求更多神器使完成活骸化
   ↓
黑核、活骸等要求达成 → 被抛下的人／最终日
要求未达成 → 特殊灭世 3（来源界面称“终结”）
```

这里是状态检查，不是玩家在对话框中主动选择“达成／未达成”。“等”字明确提示可能还有页面未列出的条件，不能缩减为单一黑核或活骸要求。

# 1. 安的状态恶化

第一天城市中的黑门和怪物活动显著增强。指挥使准备与安外出清理怪物，却发现她不在房间；罗纳克最初只称其活骸化状态出现问题，后来带指挥使进入标有警告的隔离房间。

安的肢体已经布满结晶，衣物被刺破，四肢扭曲。研究员认为这种变化理论上不应发生，并承认此前研究存在重大漏洞；研究所原本试图隐瞒安已经“没救”的判断。

安仍能短暂回应。她称实验其实成功、自己或许只是特殊个例，并要求指挥使不要怀疑此前选择，要继续走认为正确的道路。她的说法具有安慰和支持意味，不能用来否定现场研究员对实验漏洞的观察。

# 2. 希罗的解释与“幻力浓度常规化”

指挥使质问希罗为何隐瞒。希罗承认没有预料到已经达成活骸化的神器使仍会陷入狂乱，并把原因归于城市空气中的幻力浓度不平衡。

为此，他重新启动“幻力浓度常规化”计划：让巨大黑门吞噬城市乃至世界，使现实世界与异界融合，使幻力成为空气中的常规物质。希罗认为这种平衡“最有可能”避免安的情况，同时也承认仍存在其他可能性。

因此，本页能确认的是希罗提出并实施该方案，而不是方案一定能够稳定新式活骸。安的状态已经直接证明此前关于“不再衰弱、不再死亡”的承诺并不可靠。

# 3. 开启巨大黑门与异界计划

希罗带指挥使登上观光塔，展示云层中长期存在、等待降临时机的裂缝。他取出一颗黑核，让指挥使像向神器使供能一样把力量延伸至裂缝；黑暗随后包裹城市，现实与异界之间的链接被建立。

希罗把这一入口称作经数据观测“迄今最稳定的黑门”，并称其最终可以让两个世界同步。他进一步提出：既然神器随着异界出现而出现，异界或许是神器的宝库，也可能存在让死者复活的神器；与其等待新神器使诞生，不如主动进入异界寻找。

这些说法应按证据层级分开：

- 页面直接呈现巨大黑门被开启、链接开始形成。
- “异界是神器宝库”“存在复活神器”是希罗基于现象作出的推测。
- “世界融合可解决失控”是尚未验证的计划目标。
- 指挥使同意进入异界调查，但这不等同于认可希罗全部理论已经为真。

希罗最后强调入口幻力浓度过高，只有已经活骸化的神器使适合进入，并继续劝指挥使转化更多同伴。

# 4. 结局条件与失败边界

## 4.1 要求达成

页面仅标记“黑核、活骸等要求达成”，随后进入“被抛下的人”最终日。当前资料可以确认黑核收集和神器使活骸化属于条件组成部分，但不能确认：

- 需要多少黑核；
- 需要多少名或哪些神器使活骸化；
- 是否还需要特定区域、角色或行动条件；
- “等”所包含的其他判定。

## 4.2 要求未达成

页面标记“要求未达成”后进入来源称作“终结”的段落，当前页面体系对应特殊灭世 3。该失败不是最终日战斗失败，而是在进入异界之前，指挥使没有满足希罗要求而遭其清算。

# 5. 角色材料（限本页）

## 安

- 在第三天看似成功的新式活骸化后出现身体扭曲和精神状态风险。
- 即使处于严重恶化中，仍试图让指挥使不要因她而否定自己的道路。
- 她自称“特殊个例”只是当下自我解释，不能据此证明其他活骸必然安全。

## 希罗

- 承认新式活骸研究存在未预料到的失控问题，却没有暂停转化，反而扩大方案至世界融合。
- 把避免死亡、复活死者和进入异界作为继续前进的吸引力。
- 其计划要求黑核、指挥使供能及已活骸化神器使，但完整门槛没有在本页公开。

## 罗纳克与研究员

- 罗纳克违背隐瞒安排，让指挥使看到安的真实状态。
- 研究员明确承认理论预期与实际结果冲突，说明研究所内部并非所有人都认为实验已经完成。

## 指挥使

- 在安失控后质疑此前道路，却仍因复活可能与进入异界的目标选择继续调查。
- 其继续前进发生在信息不完整和沉没成本不断增加的情境中，为最终日“不愿回头”的态度埋下前提。

# 6. 本页可用于后续核对的线索

- 新式活骸肉体异化与意识崩坏之间可能存在时间差，第三天的短期稳定不能预测第一天状态。
- 希罗的计划从个体实验扩大到现实世界与异界融合，风险尺度发生根本变化。
- 巨大黑门、黑核、指挥使供能与异界入口的关系在本页被同时呈现，但其底层机制仍主要由希罗解释。
- 指挥使接受继续进入异界，既包含寻找答案，也包含对已付出牺牲难以回头的心理压力。
