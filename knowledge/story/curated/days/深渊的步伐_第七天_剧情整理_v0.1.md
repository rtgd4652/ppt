# 使用边界

本文只对《深渊的步伐》第七天已采集的 Wiki 正文进行结构化整理，用于后续人工审核、角色档案与主线时间线工作。它不替代 raw 或 clean 来源文本，不补写页面没有给出的动机、因果或跨轮回结论。

- 本页没有互斥剧情 Tab，也没有可重复询问菜单。
- 私信中的“我也觉得你的名字挺耳熟的……”是推进对话的单一回应，不构成会改变后续内容的选择树。
- 希罗关于中央庭建立、安托涅瓦意图、个人崇拜和神器使未来的说明，均先记录为希罗在初次会面时提出的叙述或主张；本页没有提供独立证据完成验证。
- 梦境少女、轮回观察者或“棋盘”等线索尚未在本页出现；不得把后续页面身份反写进本日正文。

# 1. 希罗的首次主动联络

希罗通过私信主动联系新任指挥使，自称是中央庭的另一名指挥使。他表示中央庭寻找新的指挥使已经很久，并两次提到对指挥使及其名字有莫名的熟悉感，随后邀请其前往中央庭面谈。

页面直接呈现的事实是：

- 希罗知道新任指挥使已经出现，并主动发起联络。
- 指挥使也觉得希罗的名字耳熟，但正文没有解释这种熟悉感的来源。
- 指挥使把希罗理解为中央庭中的“前辈”并前往中央庭。

“熟悉感”在本页只是双向的主观感受，不应据此直接确认两人过去已经见过、保留了轮回记忆或存在其他确定关系。

# 2. 中央庭会面与见面礼

指挥使抵达中央庭后，希罗亲自迎接并再次强调两人之间可能存在“奇妙的缘分”。他以草莓糖果作为见面礼，并以较为亲近、随意的方式展开谈话。

这一段为后续路线建立了两类角色材料：

- 希罗善于主动缩短人际距离，并以糖果作为建立联系的媒介。
- 指挥使对希罗的第一印象带有戒备，内心将其形容为“有点可疑的自来熟大叔”。

这两点分别是人物行为和指挥使的即时感受；不等于本页已经证明希罗的真实动机是善意或欺骗。

# 3. 希罗关于指挥使、神器使与中央庭的说明

希罗以“指挥使为何会被视为救世主”为问题，引导指挥使讨论指挥使与神器使之间的权力关系。他指出神器使拥有远强于指挥使的力量，并提出：如果只考虑供能需求，神器使理论上也可能反过来控制指挥使。

随后，希罗给出自己对中央庭早期历史的叙述：

- 他称自己在黑门事件初期和中央庭建立阶段积累了过高威望，“救世主”称号带来沉重的个人崇拜。
- 他称安托涅瓦认为个人崇拜会阻碍对抗异界，因此推动多名神器使组成中央庭核心组，并寻找、培养新的指挥使。
- 他将这一安排解释为：让公众理解拯救并非希罗一人的功劳，而是指挥使与神器使共同努力的结果。
- 他又称新任指挥使替代了自己承担的大量事务，使他能够集中进行更重要的研究。

以上内容是本页首次出现的中央庭权力与历史解释，但说话者只有希罗。后续世界观整理时，应与安托涅瓦、晏华、其他七人众和组织资料交叉验证，不能把希罗对安托涅瓦意图的判断直接写成安托涅瓦本人已确认的动机。

# 4. “自己的队伍”与合作门槛

希罗表示自己正在进行一项用于对抗异界、已进入后期关键阶段的研究，并邀请指挥使在满足条件后加入。

他提出的条件不是单纯接受中央庭任务派遣，而是建立一支在危机时愿意站在指挥使身边、能够称为朋友的神器使队伍。希罗以“亲密过半”和“至少五人”作为口头类比，并警告如果没有这样的队伍，指挥使将无法承担“接下来的后果”。

本页可以确认：

- 希罗把个人信任和愿意追随的关系视为合作前置条件。
- 他已经预期后续行动可能带来严重后果，但没有在本日说明这些后果的具体内容。
- “过半”“五人”是希罗在对话中给出的具体门槛表达；是否同时属于实际游戏条件，应在路线条件或实机记录中另行核对。

# 5. 角色与组织信息（限本页）

## 希罗

- 主动接近新任指挥使，并以熟悉感、糖果和较亲近的谈话方式建立关系。
- 将自己描述为黑门危机早期和中央庭建立阶段具有极高威望的指挥使。
- 对中央庭分散个人权力的历史提出自己的解释，同时口头认可安托涅瓦减少个人崇拜的判断。
- 正在推进一项未公开具体内容的重要研究，并要求指挥使先建立真正愿意追随自己的队伍。

## 指挥使

- 刚成为中央庭指挥使，对能否胜任仍有不安。
- 对希罗产生耳熟感，并在好奇与戒备并存的状态下接受会面。
- 已理解自己在中央庭中的基本工作职责，但尚不了解希罗所说的“接下来的后果”。

## 安托涅瓦（由希罗叙述）

- 本页没有与安托涅瓦直接对话。
- 关于她降低希罗权力、组建核心组、寻找新指挥使及其动机的内容，都来自希罗的叙述，必须保留这一证据层级。

# 6. 本页在路线结构中的作用

第七天没有正式分流，而是完成《深渊的步伐》的前置铺垫：

1. 希罗主动把新任指挥使纳入自己的观察与联络范围。
2. 个人崇拜、指挥使权力、神器使力量和中央庭核心组被第一次放进同一场谈话中。

这些内容只能说明路线正在建立希罗与指挥使的接触，不等于指挥使已经选择加入希罗，也不等于希罗在本日已经公开研究目标。
