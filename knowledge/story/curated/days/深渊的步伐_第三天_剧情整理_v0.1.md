# 使用边界

本文只整理“深渊的步伐／剧情／第三天”的已采集正文，不替代 Raw 或 Clean，也不把希罗、达尔维拉对实验结果的判断直接提升为已经证实的世界观机制。

- 安提出参加活骸化实验之前的内容，是两项决定的共同前提。
- “阻止安／让安去”是改变路线走向的互斥选择；前者进入“神的棋盘／零的故事”共通分支，后者转入“被抛下的人”分支。
- “稍微有点顾虑／他比我们想的复杂很多”和随后两项关于时间的问法，只改变当下表达；询问倒计时、希罗的回应和中央庭讨伐命令属于共同续段。
- “新式活骸不会死亡”是希罗、达尔维拉在实验当下的主张。后续页面明确揭示其精神仍会失控，不能将“成功”写成永久解决活骸化。
- 本页末尾的路线标签是 Wiki 导航标记，不是角色在场景中说出的台词。

## 选择树结构复核

```text

├─ 阻止安 → “神的棋盘／零的故事”共通分支
│  ├─ 稍微有点顾虑
│  └─ 他比我们想的复杂很多

└─ 让安去 → “被抛下的人”分支
   ↓ 安接受实验 → 暂时保持清醒 → 开启活骸化功能 → 命令讨伐中央庭
```

# 1. 共同前提：安主动提出参加实验

指挥使没有按照希罗的期待让自己的神器使准备活骸化。希罗以“不承担风险却期待研究成果”为由施压，安则主动站到两人之间，提出由自己参加实验。

安把决定解释为：指挥使既然把希望与未来押在希罗的研究上，同行者也不能只等待他人的成果。指挥使反驳，加入希罗原本就是为了让神器使活下去，若她们先在实验中死亡，所谓成功便失去意义。安坚持自己会活下来，并要求指挥使相信她。

这一冲突不是单纯的“是否相信安”。它同时涉及指挥使是否继续服从希罗、是否接受以同伴承担研究风险，以及是否把实验结果置于保护个体之前。

# 2. 阻止安：进入“神的棋盘／零的故事”共通分支

指挥使用行动挡住安。希罗表现出杀意，却随即恢复笑容，表示实验进度只能放慢，并把安留下照顾指挥使。

安质问指挥使为何已经选择追随希罗，却又在关键时刻反对。随后出现两项表达选择：

| 选项 | 独立内容 |
| --- | --- |
| 稍微有点顾虑 | 指挥使说明自己在与其他神器使交流后开始重新审视希罗。 |
| 他比我们想的复杂很多 | 指挥使强调不同人看到的希罗并不相同，似乎无人完全了解他。 |

两项均导向安承认指挥使有所改变，并提到希罗为实验设定了必须赶上的日期。此处开始是共同续段，不属于第二项独占内容。

## 2.1 倒计时询问与希罗的回避

指挥使可以从“时间有何特殊意义”或直接联想到倒计时切入；两种问法随后共同指向希罗。指挥使说明自己从加入中央庭开始就看到由七递减的数字，希罗则声称自己看不到，并建议以后检查大脑和视觉系统。

希罗把“在某一天前完成实验”解释为人为设定研究期限，用“死线是第一生产力”淡化其特殊意义。到第一天他才承认自己能够看到倒计时，因此本日回答应记录为希罗当时的否认与搪塞，而不是“希罗确实不知道”。

## 2.2 本分支当日结果

希罗判断中央庭因失去指挥使供能且强力成员外出而防守薄弱，命令指挥使讨伐中央庭、夺取黑核。手账明确记录指挥使没有把神器使交给希罗，研究因此延期，而自己并不后悔。

这条路线随后进入第二天的地下零事件，并在第一天根据两场战斗、黑核状态和希罗生死继续分流。

# 3. 让安去：转入“被抛下的人”分支

指挥使同意后，安跟随希罗进入实验区。达尔维拉展示手上的紫色结晶，并称样本实验已经能够避免神器使在过程中死亡；他同时提醒，指挥使真正要面对的是实验后形态是否能够接受。

实验期间舱室压力越过危险线，研究所持续震动。数值回落后，安醒来并保持清醒，身体出现紫黑纹路，自述身体轻盈且不觉疲惫。希罗把结果称为“完美的进化”，宣称安已经不会衰弱或死亡；安则希望其他神器使也接受转化，从而免于死亡并继续相伴。

页面随后开启“活骸化”功能，并警告转化会影响结局走向。该提示和路线标签共同表明本选择进入“被抛下的人”方向；但实验只证明安在本日短时间内保持清醒，第一天的后续失控推翻了“已经永久安全”的理解。

# 4. 两条路线均出现的中央庭讨伐与黑核回收

两条选择都保留希罗进攻中央庭的命令，并出现高校学园、中央庭两处黑核内容：

- 高校学园：达尔维拉拒绝进入学校，指挥使回收黑核。
- 中央庭：达尔维拉提醒中央庭仍可能反攻，并把晏华称为不可轻视的“神之头脑”；黑核没有被隐藏，使他怀疑晏华另有计划。

相同的区域文本不意味着两条路线之后仍完全共通。真正的路线分流发生在是否让安参加实验，后续应分别读取“深渊的步伐”第二天与“被抛下的人”分支页面。

# 5. 角色材料（限本页）

## 安

- 主动提出承担实验风险，把追随指挥使理解为共同承担其选择的后果。
- 被阻止时质问指挥使的立场变化，但最终接受保护决定。
- 被允许实验时，把短暂保持清醒和身体强化理解为能够永远同行的希望；该希望后来被证明并不可靠。

## 希罗

- 以研究收益和风险承担为理由向指挥使施压。
- 对倒计时作出自己看不到的回答，却在第一天承认早已知道倒计时和终结。
- 将中央庭的暂时弱势视作夺取黑核的机会。

## 达尔维拉

- 以自身结晶化痕迹说明实验方法，并强调实验后形态的代价。
- 对中央庭仍保持警惕，尤其关注晏华的行动。

# 6. 本页可用于后续核对的线索
