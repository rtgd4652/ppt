# 使用边界

本文只对《避世的方舟》第三天已采集的 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 页面索引登记四棵不可重复的玩家选择树，深度依次为 0、1、2；没有任何一棵登记共同续段。
- 顶层“追上去／留下来照顾安托涅瓦”互斥。“追上去”的 Tab 在 raw 与 clean 中均无正文，不能把空白解释成“什么也没发生”。
- 页面文章链接中出现《正轨的箱庭／第二天》，但来源索引没有把该链接绑定到“追上去”。将其视为转线目标是合理候选，不是本页结构数据已直接确认的事实。
- “是啊／你怎么知道的”分别带有一份内容近乎相同的雷切尔任务子树。本文可以归纳重复内容，但仍保留两个不同父节点。
- 两个“不巡查中央庭”分支不完全等价：前者只有催促私信，后者在相似催促之后明确标注进线失败。
- 安托涅瓦关于净化者死亡、黑门关闭后神器使死亡的说明，雷切尔关于不死结晶的说明，均按说话者保存；不因角色表示确信就自动升级为跨路线绝对规律。

# 1. 梦中警告与安的失踪

指挥使再次在梦中听见少女警告“已经没有时间了”，醒来后发现安不在身边。页面没有确认少女身份，也没有解释她所说的时间限制由谁设定。

与此同时，叙事转到希罗的据点。安向希罗报告任务失败；希罗说安托涅瓦可能醒来，要求安再次行动，并声称：

- 安托涅瓦“退场”原本在其计划中；
- 安不该怀疑，因为他不记得给她设置过怀疑指令；
- 安已经因短暂相处而动摇。

安离开后，希罗与一只发出少女声音的黑色魔偶交谈。魔偶称希罗明知是陷阱仍让安回去；希罗反过来指出，此前交给安托涅瓦的战斗记录也是魔偶所为。魔偶还说安、安托涅瓦等人都不知道希罗真正目的。

该魔偶在清洗正文中始终标为“？？？”。本页可确认它与希罗合作、曾提供战斗记录，并知道安的处境；不能仅凭声音、形态或后续路线提前指定其真实身份。

# 2. 安试图袭击安托涅瓦

安进入中央庭特殊病房，见到活骸化已进行到一半、黑色纹路遍布身体的安托涅瓦。她对昏迷中的安托涅瓦说明自己的选择：

- 她无法理解为了恢复世界而牺牲指挥使；
- 她认为安托涅瓦醒来后会继续让指挥使净化黑核，而指挥使也会接受；
- 她只想与指挥使和大家永远在一起；
- 因此准备阻止会破坏这一切的人。

安召出武器指向安托涅瓦，指挥使及时喝止。安没有解释，立即逃走，触发顶层选择。

这里可确认安在希罗要求下再次接近安托涅瓦，并主动召出武器；页面没有呈现实际伤害已经发生。她关于安托涅瓦与指挥使未来选择的说法，是她据已知信息作出的判断。

## 3.1 “追上去”

本选项在 raw 和 clean 中均没有独有正文。页面文章链接包含《正轨的箱庭／剧情／第二天》，而《避世的方舟》第三天的正文又正好发生安逃离事件，因此“追上去后转入该页”是需要实机验证的结构候选。

当前校订不把候选链接写成确定转线，也不把空 Tab 写成进线失败、自动返回或无事发生。

## 3.2 “留下来照顾安托涅瓦”

安托涅瓦醒来后表示自己听到了安的话，并承认希罗所说的部分内容在其理解中属实：

- 指挥使继续净化黑门之核，终会耗尽生命力而死；
- 黑门关闭后，神器使也会逐一死亡；
- 若不净化，黑门无法关闭，世界不能恢复正常；
- 若必须在世界上千万人与当地几十名神器使之间权衡，她会选择前者。

她由此怀疑自己与希罗同样只按数量衡量生命，并重复希罗对自己“不会爱人也不爱自己”的贬斥。指挥使则引用三次方舟所见的历史切片，说明自己知道她旅行的愿望、开车与奔跑能力、灾难中的组织行动以及对孤独的恐惧，否定其自我评价。

指挥使承诺不会放弃或离开；安托涅瓦表示相信，并请求让自己能够“回去”。手账随后登记病情恶化与治疗努力。

必须保留两层边界：

- 关于净化代价和神器使结局，是安托涅瓦在此时给出的明确判断，较此前希罗、奥露西娅的主张形成同向证词，但页面仍没有展示完整实验或所有例外。
- 指挥使对安托涅瓦人格的总结来自方舟历史切片和自身理解，不是对其全部动机的唯一解释。

# 4. 雷切尔私信与不死结晶研究

雷切尔主动私信，称已听说指挥使取得“不死结晶”，要求立刻带给自己。

## 4.1 回答“是啊”

雷切尔直接表现出兴奋并要求指挥使到中央庭。手账认为结晶可能救治安托涅瓦，随后出现“巡查／不巡查中央庭”子树。

### 巡查中央庭

雷切尔确认样本是不死结晶，并将其解释为“曾拥有起死回生之力的神器使变成活骸后的心脏”。她起初说不能拯救安托涅瓦，随即说明是在开玩笑，真正结论要等分析。

她提出两项准备：

- 研究综合科技值约需 210 以上；
- 为治疗准备急救中心和先进医疗设备。

手账据此登记雷切尔已经开始研究，并把科技值 210 与建设急救中心列为接下来的目标。

这些数值是雷切尔按设备和研究员评分估算后给出的玩法要求；页面没有展示研究完成后的成功率，也没有证明不死结晶本身足以独立治愈安托涅瓦。

### 不巡查中央庭

雷切尔连续发私信催促。该分支在当前 clean 页没有“进线失败”文字，也没有后续实验室正文。不能因另一父节点的相似分支会失败，就把此处分支自动改写成相同结果。

## 4.2 回答“你怎么知道的”

雷切尔回避消息来源，又提到不死结晶属于“被中央庭所封存的资料”，随后称自己说漏嘴，继续催促指挥使前往。

该回答补充了她可能接触过封存资料，但没有说明是谁把当前结晶消息告诉她，也没有展示她对全部零档案拥有完整权限。

### 巡查中央庭

页面重复收录与“是啊→巡查中央庭”相同的实验室正文：确认样本、解释其来源、提出综合科技值 210 和建设急救中心、开始研究。

本文归纳相同内容，不把两个父节点合成一棵树。

### 不巡查中央庭

雷切尔先催促“快点”，指挥使以沉默回应，随后收到连续催促。页面在此明确标注进线失败。

该失败标记只属于“你怎么知道的→不巡查中央庭”这一已登记父子路径；当前证据不足以向旁边的“不巡查”分支扩张。

# 5. 本日在路线结构中的作用

1. 希罗再次命令安处理安托涅瓦，安的个人愿望与被设定的指令出现正面冲突。
2. 未知魔偶被确认与希罗合作，并曾把战斗记录交给安托涅瓦。
3. 顶层选择将“追上安”与“留在安托涅瓦身边”分开；前者的页面去向仍待核，后者继续治疗路线。
4. 安托涅瓦亲口承认净化黑核在其理解中的生命代价，并接受指挥使不会放弃她的承诺。
5. 不死结晶被交给雷切尔研究；路线目标转化为科技值约 210、建设急救中心并等待分析结果。

# 6. 角色补充（限本页）

## 安

- 向希罗承认任务失败，因是否应袭击安托涅瓦而动摇。
- 认为失去指挥使与大家的世界即使恢复也没有意义。
- 试图以武器阻止安托涅瓦继续牺牲指挥使，但被发现后逃离，没有在本页完成攻击。
- 希罗关于“指令”和“设置”的说法暗示他对安有特殊控制或制造关系；具体机制仍需其他来源确认。

## 安托涅瓦

- 即使活骸化恶化，仍坚持以多数普通人的生存为优先。
- 因这种权衡而自责，甚至接受希罗对其缺乏人性的评价。
- 在指挥使表明不会放弃后选择相信，并愿意接受治疗尝试。

## 指挥使

- 能以方舟中所见历史切片回应安托涅瓦，但这些内容只证明其掌握那些片段。
- 选择是否追赶安；留守后还需通过两层私信／巡查选择推进研究。
- 手账把不死结晶、科技值和急救中心视为希望，不代表治疗已完成。

## 雷切尔

- 知道不死结晶消息，并接触过中央庭封存资料，但信息来源未公开。
- 将结晶解释为活骸化后保留起死回生力量的神器使心脏。
- 给出研究和医疗设施要求，却明确需要先分析样本，尚未承诺一定成功。

## 希罗与未知魔偶

- 希罗承认把安托涅瓦退场纳入计划，并期待安再次行动。
- 未知魔偶曾提供战斗记录，也知道希罗尚未完全摧毁中央庭。
- 两者互相取笑并共享部分情报，但本页没有公开合作起点、契约或魔偶真实身份。
