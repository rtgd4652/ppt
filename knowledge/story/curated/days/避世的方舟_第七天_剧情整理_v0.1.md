# 使用边界

本文只对《避世的方舟》第七天已采集的 Wiki 正文进行结构化人工校订，用于后续路线对照、角色档案与证据提取。它不替代 raw 或 clean 来源，不把版本差异、支线任务和失败转线拼接成同一次必然经历。

- 开场的系统文字直接呈现“神器使死亡”“挑战完成”“残余率提升”和世界重构；页面没有指明死亡者、上一轮完整经过或“残余率”的本质。
- “我要加入中央庭／我需要考虑一下”是一次性主线选择，不是可反复询问菜单。“考虑一下”内部还包含两层嵌套选择。
- 直接加入中央庭后存在“改版前／改版后”的版本对照；这不是玩家选择，也不能把两版情节同时写进同一次经历。
- “调查幽灵”与三项“回到过去最想做的事”都是支线模块。其出现条件、巡查次数和实际游玩顺序，本页没有完整给出。
- 页面登记的六棵选择树均为 `repeatable: false`；正文没有可重复询问菜单。

# 1. 世界重构与失忆后的再次苏醒

页面先显示系统记录：

- “神器使”生命值过低并确认死亡；
- 本次挑战记录为完成；
- 搜寻幸存者时检测到残余率提升；
- 实时数据被删除，新系统时间设为七天；
- 系统警告残余率会影响后续运行，并开始世界重构。

随后，指挥使在安与安托涅瓦身边醒来。其头部受伤、记忆缺失，却因无法解释的悲伤而流泪。战术终端中保留着对神器使的评价与了解，但指挥使本人无法回忆这些内容。

本页能确认的是“新一轮七天已经启动”和“指挥使存在情感及资料残留”；不能仅凭这一页断言残余率等于完整记忆、上一轮具体结局已经被谁记住，或系统由何者控制。

# 2. 中央庭、黑门与净化黑核

安带指挥使观察城市并进行基础说明。她称：

- 黑门会随机出现在城市中，并释放怪物和黑雾；
- 消灭怪物、破坏黑门和保护人类是中央庭成员的工作；
- 中央庭是人类对抗异世界的主基地；
- 希罗建立中央庭，在指挥使出现前是唯一的指挥使，并曾集结神器使解救城市。

这些历史说明来自安在当时的讲述，应保留说话者层级。

中央庭附近突发黑门后，指挥使触碰怪物尸体中央出现的黑色晶体，使其由黑转白。雷切尔将其解释为指挥使能够净化“核”，并称自己的理论得到验证。安托涅瓦则把击败怪物、破坏黑门、净化核和帮助更多人概括为中央庭正在做的事情。

页面直接呈现了黑核被净化；“特定神器使或指挥使都可能净化核”是雷切尔对其理论的陈述，仍需用其他来源核对适用范围。

# 3. 是否加入中央庭的主选择树

## 3.1 第一层选择

| 选项 | 独有结果 | 路线状态 |
| --- | --- | --- |
| 我要加入中央庭 | 安托涅瓦道谢，带指挥使前往一直有人保养的房间，并留下建设与神器使交往资料。 | 保持本路线；随后进入版本对照。 |
| 我需要考虑一下 | 指挥使以失忆和希望先找回记忆为由暂不加入；安托涅瓦仍保留其指挥、信息处理、巡查与战斗权限。 | 进入两组嵌套选择。 |

该选择不可重复。安托涅瓦允许指挥使暂时不加入，只说明她在当时给予行动权限，不等于中央庭所有权限制度已经由本页完整定义。

## 3.2 “我要加入中央庭”后的版本对照

| 版本 | 页面内容 |
| --- | --- |
| 改版前 | 指挥使受神秘声音引导进入白夜馆，认出霞；霞称其正逐渐找回“真正的记忆”，自己会旁观其重新开始七天并追寻所选结局。 |
| 改版后 | 指挥使决定先观察可做之事，并准备有空时去中央庭找安托涅瓦。 |

两版互为来源版本，不是先后事件。改版前关于“被遗忘的记忆”“之前的约定”和重新开始七天的解释均来自霞；本页没有独立展示约定内容，也没有完成对霞身份和能力的验证。

## 3.3 “我需要考虑一下”后的态度选择

第一组嵌套选项为“为什么要对我这么好……”与“这都可以？”。两项得到同一核心回应：安托涅瓦称指挥使是城市面对威胁时不可或缺的希望，并再次邀请其加入中央庭。

这组不是可循环问答；页面没有“返回菜单”或退出项。

第二组嵌套选项决定最终路线：

| 选项 | 结果 |
| --- | --- |
| 我要加入中央庭 | 回到加入中央庭的房间段，并接入改版前所保留的白夜馆、霞和重新开始七天内容。 |
| 我还是当个自由人吧 | 页面明确标注进线失败，并转入《飘零的自由者》。 |

因此“先考虑”并不必然退出本路线；只有最终坚持自由人选择才明确转线。

# 4. 安托涅瓦的档案工作与身体情况

## 4.1 “中央庭的女王”

指挥使深夜进入档案室，见到安托涅瓦独自处理从各地汇聚、由系统分类的信息。安托涅瓦请其协助回复市民邮件；三小时后，她准备夜宵茶点并解释回复信件能够帮助理解城市正在发生的事情。

页面可直接支持：

- 安托涅瓦承担大量信息与文书工作；
- 她能借助方舟或空间能力在档案区移动；
- 她把市民来信视为理解城市现实的一种渠道。

“全部由她一个人处理”的范围以当时档案室对话为限，不应外推为中央庭没有其他行政人员。

## 4.2 “中央庭的女王2”

面对市民关于她一直坐着的提问，安托涅瓦主动说明：自己刚成为神器使时曾在战斗中受伤，醒来后胸口以下失去知觉；此后依靠“方舟”移动，并已经逐渐习惯。

这是安托涅瓦本人对身体情况的直接陈述，也是方舟作为移动与庇护载体的角色材料。该支线没有说明受伤战斗的全部经过，需与第四天关于零的资料交叉核对。

# 5. “调查幽灵”与跨世界线方舟

安在深夜档案室见到漂浮女性，以为出现幽灵。选择“去调查一下吧。”后，指挥使与安在中央庭遇到另一条世界线的安托涅瓦；选择“现在可能没有时间调查这种事……”则由安独自前往，页面明确标注进线失败。

成功分支中的另一世界线安托涅瓦称：

- 自己不是这个世界的安托涅瓦；
- 诺亚方舟能够连接不同空间与次元；
- 少量信息可以通过方舟渗透传递；
- 身体跨越次元需要消耗方舟本身能量；
- 她因收到本世界安托涅瓦的求助而来协助夜班。

她交出等人大小的“方舟”传送装置设计图，使城市内可建立方舟装置。没有方舟加护的指挥使必须依靠装置，停留时间有限且会自动返回。

以上机制说明来自该安托涅瓦本人。她所说“历史不会因一个人的力量而改变”“帮助也只是挣扎”属于角色判断，不能在未交叉验证前提升为全宇宙绝对规则。

# 6. 方舟测试：回到过去最想做的事

装置启动后，指挥使被送往某个过去时间点，并在三项一次性选项中选择行动：

| 选项 | 页面结果 |
| --- | --- |
| 去买张彩票试试吧 | 彩票很快遗失，指挥使把它理解为历史难以改变的表现。 |
| 上网看看消息 | 发布“预言消息”被系统以可能违反法规政策为由拦截，传送在再次尝试时结束。 |
| 去找旧友 | 指挥使想寻找少年时期的珈儿或泰丝拉，却因在学校门口探看而被路人误解，随后时间结束。 |

三项互斥且不可重复。它们展示的是一次方舟测试中的失败或荒诞结果，不足以单独证明所有过去绝对不可改变；“无法改变的历史”在彩票分支中首先是指挥使的即时理解。

# 7. 本日在路线结构中的作用

1. 系统重构和残余率提示为多周目、记忆残留及世界循环提供直接文本入口。
2. 指挥使重新认识中央庭、黑门、黑核及自身净化能力。
3. 加入中央庭的选择构成《避世的方舟》入口；坚持自由人会明确转线。
4. 两个“中央庭的女王”支线补充安托涅瓦的行政职责、身体损伤和方舟移动方式。
5. “调查幽灵”建立方舟可连接世界线及过去时点的路线机制，并解锁后续寻找历史切片的行动。

# 8. 角色补充（限本页）

## 安托涅瓦

- 主动接纳失忆的指挥使，并在其犹豫时仍保留行动权限。
- 将对抗黑门理解为通过长期累积帮助更多人。
- 承担高密度档案和市民信息工作。
- 亲口说明胸口以下失去知觉、依靠方舟移动。
- 另一世界线的同位体提供跨次元方舟装置，但其历史观只能记为角色主张。

## 指挥使

- 失去明确记忆，却保留难以解释的悲伤与战术终端资料。
- 能将黑色的核净化为白色。
- 是否立即加入中央庭由玩家选择；暂缓加入并不立即失去权限。

## 安

- 负责向失忆的指挥使说明城市、黑门和中央庭。
- 在“调查幽灵”中表现出害怕、好奇和研究欲并存的一面。
