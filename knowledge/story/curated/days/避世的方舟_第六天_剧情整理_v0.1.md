# 使用边界

本文只对《避世的方舟》第六天 Wiki 正文进行结构化人工校订，不替代 raw 或 clean 来源。页面包含一组状态条件和五组玩家选择，其中“去见希罗”下还有一组嵌套选择；六棵树均标记为不可重复。

- 开场神秘声音称“新的棋盘已经开始”，但本页没有确认说话者身份，也没有解释“棋盘”的机制。
- “已解放／未解放高校学园”是进入页面前的区域状态，不是玩家在当前对话中的选择。
- 当前来源把赛哈姆事件的完整正文放在“未解放高校学园”条件内；不能擅自补到已解放状态。
- “答应希罗”“隐瞒实情”和“去见希罗”长分支末尾分别出现进线失败标记。它们可作为失败路径材料，但不能与成功进入《避世的方舟》的后续拼成同一条线。
- 页面自动结构没有标记共同续段；本文只在正文位置明确回到公共叙事时说明汇合，不把互斥独有回应互相复制。

# 1. 开场：神秘观察者与安的日常照料

指挥使朦胧间听见未知者称“新的棋盘已经开始”，期待其选择并要求其努力挣扎。醒来后，安强行接管早餐、清扫和出门准备，以女仆身份照顾指挥使。

这一段同时提供两类材料：

- 神秘观察者正在关注新一轮选择，但身份和目的未在本页确认。
- 安把照顾“主人”落实为具体生活劳动，而非只承担战斗职责。

# 2. 高校学园状态条件

| 条件 | 页面独有内容 | 结构边界 |
| --- | --- | --- |
| 已解放高校学园 | 安说明昨日讨伐后仍有遗留问题，希罗发消息邀请指挥使前往搜寻线索。 | 该选项卡到提示处结束。 |
| 未解放高校学园 | 高校学园黑门尚未破坏；希罗开始搜寻黑核并请指挥使协助。安交出爱心便当，随后触发赛哈姆袭击。 | 后续赛哈姆、活骸与选择树均位于此状态文本中。 |

两种状态互斥且不可重复。当前页面不足以证明赛哈姆冲突在“已解放”状态也必然发生。

# 3. 赛哈姆袭击与“活骸”说明

在未解放状态下，失去正常交流能力的赛哈姆将指挥使视为敌人。罗纳克、希罗与安共同介入，罗纳克将其重创压制。赛哈姆身上掉落紫黑色结晶。

希罗随后说明：

- 神器使体内存在幻力；
- 幻力过高或过低都可能导致暴走，成为“活骸”；
- 赛哈姆的活骸化刚开始；
- 他希望将赛哈姆隐藏并研究治疗方式。

安补充中央庭当前认知：活骸化开始后不能恢复；完全失控会造成巨大伤亡，因此既定处理是在丧失神志、进一步恶化前将其消灭。

此处必须分层：

- 赛哈姆袭击、结晶化和被压制是页面直接事件。
- 活骸成因与不可逆性分别由希罗和安解释，需与后续研究资料交叉验证。
- 希罗称安托涅瓦是“极力主张立刻消灭活骸的人”，只是希罗对她立场的转述。

# 4. 是否替希罗隐瞒赛哈姆

两项不可重复，也没有共同续段。答应隐瞒的短分支不能与拒绝后的安之对话、中央庭汇报和研究所事件拼接。

# 5. 对活骸化的价值判断

拒绝希罗后，安担心自己若成为活骸是否仍会有人挽救。她称中央庭最初尝试过净化和时间回溯，但净化只延长痛苦，回溯解除后会恢复原状，安托涅瓦因此才制定处置规则。

玩家随后作一次不可重复的态度选择：

| 选项 | 指挥使表达 | 安的回应 |
| --- | --- | --- |
| 一定会有解决的办法 | 不会伤害同伴，只能继续寻找治疗。 | 将其称为与希罗一致的理想主义。 |
| 尊重当事人的想法 | 无解时尊重当事人意愿；只要对方想活，就会尽全力救助。 | 质疑其“大话”，并谈到是否向安托涅瓦隐瞒。 |

页面在两项之后回到前往中央庭、考虑是否汇报赛哈姆的共同段。两种态度不是事实判断，也没有在本页被裁定高下。

# 6. 是否向安托涅瓦说明实情

## 6.1 说出活骸化

指挥使向安托涅瓦说明希罗与赛哈姆之事，并要求听她亲口解释。安托涅瓦确认处置规则存在，回忆第一个活骸在城市破坏、造成两名讨伐者死亡和一人失去双腿，最终仍能听见内部哭喊；该活骸后来自我毁灭。

她允许指挥使尝试希罗的方法，但提出边界：若赛哈姆完全活骸化并开始无差别袭击，希望指挥使不要阻止她处置。指挥使接受，并表示相信希望不是错误。

安托涅瓦关于首个活骸的历史属于当事管理者叙述，可信度高于希罗转述她的立场，但仍应保留来源身份并与第四天零的资料核对。

## 6.2 隐瞒实情

指挥使只提交高校调查，不提赛哈姆。安托涅瓦察觉报告不完整，却允许其按自己的判断行动。指挥使转而用“每天都会给别人带来死亡的诅咒”作假设询问；安托涅瓦称会先寻找解除方法，若最终无法避免伤害他人，就会在伤害发生前自我了断。

本分支随后标注进线失败。她的回答是对假设问题的个人伦理立场，不等于已发生的自杀决定，也不能直接证明她掌握赛哈姆完整情况。

## 7.1 研究所中的“英雄／兵器”

希罗称赛哈姆只能暂时被镇静，并询问神器使是英雄还是战斗兵器：

| 嵌套选项 | 独有回应 |
| --- | --- |
| 是英雄 | 希罗表示认同。 |
| 是兵器 | 希罗称此想法比自己更激进。 |

两项之后均进入希罗的共同论述：他将成为神器使描述为身体与精神的提升和人类“进化”，认为活骸化使神器使尚不完整；又把黑门同时视作危机与机遇。以上都是希罗的思想与研究立场，不是页面已经验证的科学结论。

# 8. 被覆盖的记录与安托涅瓦、希罗对峙

赛哈姆迅速恶化后，希罗把指挥使挡在实验室外。与此同时，安托涅瓦在中央庭检查战斗报告，发现影像被切开、版本号多一位，并通过一小片方舟碎片向未知联系人询问，得到战术终端后门备份地址。

恢复影像直接显示：希罗强行夺取赛哈姆的幻力结晶，导致其成为活骸。安托涅瓦以方舟进入研究所，并与希罗对峙。

希罗承认研究未向外公开，强调活骸遗体的资料价值，并称已与各国领导达成共识。他主张“前进”必须铺路，又以指挥使对神器使的统御关系要求安托涅瓦离开。安托涅瓦则斥责其侮辱死者。

可确认与待核边界：

- 强行夺取结晶的影像是本页恢复记录中的直接事件。
- “与各国领导达成共识”仅是希罗自述，未见外部确认。
- 方舟碎片联系人身份未公开；不得提前指定为另一世界线安托涅瓦或其他角色。
- 安托涅瓦称指挥使与安没有听到后续谈话；页面作为叙事文本展示了对话，但角色在世界内实际获知范围应按该句保留。

研究所分支最后明确标注进线失败。

# 9. 不前往研究所时的七人众资料

“不想和希罗扯上关系”分支给出私密资料，称中央庭由希罗建立，并由七名神器使作为主要管理人员：

- 安托涅瓦：管理神器使与能力者并负责文书；
- 奥露西娅、罗纳克、芙罗拉：资料分别概括其前线相关职责；
- 晏华：城市内务；
- 爱缪莎：预言师；
- 达尔维拉：不公开的“黑暗之子”，负责暗杀与破坏，受希罗直接指挥。

这份文本是路线内“私密资料文件”，不是本页现场事件；职责措辞及组织权力结构需与其他时期资料交叉验证，尤其不能据此把希罗对达尔维拉的直接指挥自动延伸至所有时间。

# 10. 本日在路线结构中的作用

1. 神秘观察者以“棋盘”和“挣扎”标记新一轮选择。
2. 赛哈姆事件建立活骸化的表征、中央庭处置伦理和希罗研究路线。
3. 选择树连续筛选路线：答应隐瞒、隐瞒安托涅瓦或进入研究所均被页面标为失败路径。
4. 恢复记录首次把希罗从“试图救治”转为“主动制造活骸”的直接证据。
5. 安托涅瓦与希罗的冲突从政策分歧进入研究伦理与权力关系对峙。
