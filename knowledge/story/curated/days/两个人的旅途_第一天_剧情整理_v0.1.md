# 使用边界

本文整理《两个人的旅途》第一天 Wiki 正文。该页是《无垢的人偶》第二天后的结局前置页之一。

- 页面只有一棵“请求放过安／强烈抗议”玩家选择树，不可重复、无嵌套。
- “请求放过安”保留《两个人的旅途》方向；“强烈抗议”由页面明确跳转《永恒的终焉》。
- 指挥使在两项下都处于中央庭地下监禁状态；选择改变的是与晏华的交涉及后续路线，不是能否立即离开。
- 战术终端残余镜头直接显示安与安托涅瓦战斗；“杀死安托涅瓦的就是安”是晏华据此作出的结论，镜头描述本身只写到战斗与力竭。
- P09 视频仅作补充，不覆盖 Wiki 正文。

# 1. 希罗与巨大黑门

页面先呈现希罗站在观光塔高台观察天空裂缝。浓烈黑雾在裂缝内涌动，细小物件及黑色方块被吸入，裂缝缓慢扩大。希罗表示对这个黑门满意，并称时间很快就要到了。

本页直接确认希罗正在观察并期待黑门扩大，但没有解释黑色方块的具体身份、巨大黑门完整启动机制或“时间”所指的精确倒计时。

# 2. 指挥使被中央庭监禁

指挥使在中央庭地下醒来，身体活动伴随金属碰撞声。晏华说明房间沿用会议室特殊墙壁设计，能够“保护”其中事物；叙事把实际状态理解为监禁。

晏华表示：

- 安尚未被关押，但爱缪莎正在前往处理；
- 即使指挥使和安完成了大量恢复信任的行动，他仍无法信任安；
- 希罗正在寻找指挥使，地下房间被其视为安全隔离；
- 城市上空已经出现巨大黑门，中央庭正尝试处理。

因此“中央庭信任度恢复”与“晏华对安的安全判断”不是同一个变量：即使前者达标，本页仍可因新证据进入监禁。

# 3. 安托涅瓦终端的残余镜头

晏华展示从安托涅瓦战术终端找到的剩余影像。页面描述扭曲空间、剑光、破碎光片，以及安与安托涅瓦在狭窄通道交战并分开。

晏华据此称：

- 影像是安托涅瓦与“安”战斗并最终力竭的画面；
- 杀死安托涅瓦的就是“安”；
- 指挥使无法确认追上的安、每日见到的安是否始终是同一个；
- 连安自己也可能不知道是否仍被操控。

证据边界应保持：

- 战斗影像和来源终端由本页叙事呈现；
- “杀死”与“是否同一个安”是晏华对残余材料的判断与质疑；
- 页面没有展示完整死亡过程，也没有在此确认存在多个安、复制体或替换机制。

# 4. 唯一选择树

## 4.1 请求放过安

指挥使接受自己留在地下，交换条件是中央庭放过安，并威胁若不答应便设法制造动静。晏华接受交涉。

页面随后明确“行动受到限制，无法离开中央庭”。该选项保留等待安救援、进入《两个人的旅途》最终日的前置。

## 4.2 强烈抗议

本页没有展开抗议对白，只明确标注“进入主线永恒的终焉”。具体抗议回应见《永恒的终焉》第一天对应状态，不应从该页反向补写到本页来源正文。

## 4.3 共同状态与互斥结果

| 选项 | 即时状态 | 后续路线 |
| --- | --- | --- |
| 请求放过安 | 与晏华交涉成立；指挥使继续被限制 | 两个人的旅途 |
| 强烈抗议 | 本页不展开对话；监禁前置不变 | 永恒的终焉 |

手账记录巨大黑门出现、指挥使被困、虽不再期待获得信任却仍希望有人救援。它位于 Tab 之后，描述页面级共同处境，不应只挂在“强烈抗议”名下。

# 5. 角色材料（限本页）

## 指挥使

- 即使看到残余战斗影像，仍坚持自己认识的安善良，并要求时间调查。
- 在《两个人的旅途》入口选择以自身受限换取安的安全。
- 无法参与巨大黑门处理，只能等待外部救援。

## 晏华

- 承认二人为中央庭做了很多，却把安的身份连续性与控制风险置于信任成果之上。
- 以保护指挥使、避免希罗找到为由实施监禁。
- 在“请求放过安”下接受交涉，但页面没有给出“放过”的具体执行边界。

## 安

- 本页没有直接出场。
- 关于她是否杀死安托涅瓦、是否始终为同一主体、是否仍受操控，都通过影像和晏华判断出现，不能当作安本人已确认事实。

## 希罗

- 正在观光塔观察巨大黑门，并被晏华认为在寻找指挥使。
- 本页没有展示他如何定位指挥使或为何需要其本人。

# 6. 本页在路线结构中的作用

```text
前置：第二天后进入第一天，指挥使被中央庭监禁
↓
晏华展示安与安托涅瓦战斗残片
├─ 请求放过安
│  └─ 以继续受限换取安的安全 → 《两个人的旅途》
└─ 强烈抗议
   └─ 页面明确跳转 → 《永恒的终焉》
```

路线分歧发生在回应监禁的方式，而不是对影像真伪作出最终司法判定。
