# 使用边界

本文对《避世的方舟》第五天已采集 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 白色空间中哭泣的少女只被页面称为“少女”；不得依据后续路线提前写成塞拉菲姆或其他确定身份。
- “拒绝希罗／跟随希罗”是一次性主线选择。“跟随希罗”在当前条件下被系统阻止，随后与拒绝分支汇入同一冲突续段。
- 三次“巡查方舟所在地”是相互独立、依次编号的历史切片任务，不是同一场连续穿越；页面没有把它们登记为可重复询问菜单。
- 第一次方舟中的“拜托你了／你有驾照吗”不可重复；前项没有独有正文，后项多出驾照问答，随后共同进入搭车与武器店段。
- 希罗关于黑核、幻力与未来灭亡的说法，和奥露西娅关于净化消耗生命的说法，均先保留为人物阵营在会议中的主张。

# 1. 白色空间的少女与当日危机

指挥使梦见白色房间中的少女背对自己哭泣，反复说“没有时间了”。指挥使无法接近，也不知道她是谁。梦醒后，安催促其前往中央庭处理昨日赛哈姆事件。

安托涅瓦展示恢复后的战斗影像：希罗强行夺走赛哈姆的幻力结晶，使赛哈姆成为活骸。她认为希罗不惜篡改记录掩盖此事，已经对神器使构成现实危险，因此召集原中央庭七人众商议。

# 2. 七人众会议与阵营分裂

会议室中出现安托涅瓦、奥露西娅、罗纳克、爱缪莎、晏华和芙罗拉。页面称这是公开的六名七人众；希罗随后带达尔维拉现身，将其称为末位“黑暗之子”。

安托涅瓦提出用新任指挥使替代希罗的位置，并将希罗监禁在准备好的碎片空间。晏华指出希罗作为中央庭创建者拥有无法被一段录像迅速抹去的威望。希罗进入后，原七人众的站位分成两边；晏华判断这种支持关系可能在七人众确立之初就已形成。

页面直接呈现：

- 达尔维拉试图偷袭安托涅瓦；
- 七人众在现场分成支持希罗与支持安托涅瓦的阵营；
- 晏华与爱缪莎没有接受希罗的拉拢；
- 希罗公开宣布与安托涅瓦及中央庭现有路线决裂。

“从最开始已经决定”“尝试拉拢爱缪莎”等细节分别来自晏华和希罗阵营谈话，后续仍可与其他人物资料交叉核对。

# 3. 希罗的黑核主张与生命代价说法

希罗提出如下论证：

1. 神器使依靠生命力与幻力平衡而存活；
2. 黑门之核若被全部净化，异世界与现实完全剥离；
3. 神器使将因失去幻力来源而全员活骸化；
4. 因此应利用黑核推动异世界与现实融合，为神器使创造可生存世界。

奥露西娅补充称，净化黑核会一点点消耗指挥使的生命，神器使之所以宽容，是知道指挥使最终会为世界死去。希罗认可这一说法，并邀请指挥使离开中央庭、创造“英雄的世界”。

这些说法在本页推动政治分裂，但页面没有展示独立实验、医学记录或最终结果。后续知识库应分别标注为“希罗的理论”和“奥露西娅的告知”，不能直接当作已完全证实的世界规律。

# 4. “拒绝／跟随希罗”选择树

| 选项 | 独有内容 | 汇合情况 |
| --- | --- | --- |
| 拒绝希罗 | 指挥使认为其论证有一定道理，但拒绝与轻易牺牲同伴者合作。希罗转而指责中央庭隐瞒净化代价，并称安托涅瓦与自己都愿为目标牺牲一切。 | 进入共同战斗续段。 |
| 跟随希罗 | 指挥使短暂考虑另一条道路，但因没有愿意跟随自己的神器使、无法反驳安托涅瓦，系统提示不能跟随希罗。 | 选择未真正生效，进入共同战斗续段。 |

两项不可重复。“跟随希罗”不是本页成功加入希罗阵营的路线，不应写成指挥使实际叛离中央庭。

# 5. 会议战斗、安托涅瓦活骸化与希罗离去

共同续段中，安托涅瓦拒绝以怪物形态苟活，强调力量应用于守护重要事物，并以方舟投入战斗。任务要求击败敌人并保证她存活。

希罗指出她的消耗已越过安全界限、继续下去会活骸化；安托涅瓦表示自己曾为保护他人失去下半身知觉，如今也愿继续押上身体。希罗最终撤离，宣布中央庭是留给她的最后礼物，双方从此成为敌人；他还称会夺取更多核、让黑门遍布城市。

安托涅瓦因幻力使用过度倒下，血管出现紫色光点。晏华将她送往治疗设施并宣布局势改变，随后说明：

- 情况比预想稍好；
- 休养可使活骸化进程变慢；
- 按当前认知，活骸化不可逆，只能缓解。

“不可逆”是晏华基于当时中央庭知识给出的说明，应记录为当前认知，而非跨所有路线永不可能被修正的绝对结论。

# 6. 第一次方舟：灾难前的学生安托涅瓦

指挥使通过方舟到达黑门尚未降临的郊区，被年轻的安托涅瓦邀请搭车。

## 6.1 驾照选择

| 选项 | 独有回应 | 共同续段 |
| --- | --- | --- |
| 拜托你了 | 页面无独有正文。 | 进入驾车进城。 |
| 你有驾照吗？ | 安托涅瓦称上周刚取得驾照。 | 进入驾车进城。 |

两项不可重复，前项空白不等于剧情缺失；按页面位置，两者均接入后续。

年轻的安托涅瓦归还替武器店送货的旧车。对话显示她靠打工承担生活费和学费，计划攒钱参观各国图书馆孤本。她试图替无处可去的指挥使寻找住处，甚至考虑再打一份工。

指挥使没有向她透露未来，既担心改变过去令未来的安托涅瓦消失，也不忍破坏其普通生活，只留下“以后一定还会再见”的约定。

这一切是方舟中的历史切片；页面没有证明该过去能被永久改变，也没有证明每次进入的是同一条连续时间线。

# 7. 第二次方舟：黑门初现与神器使诞生

第二次落点是黑门危机中的学校。尚未成为神器使的安托涅瓦组织幸存学生：

- 调整前后门防御与撤退路线；
- 依据怪物行为安排诱导；
- 在防线破坏后留守掩护他人；
- 即使可以独自逃走，也坚持不丢下任何人。

她直言自己并非圣母，而是害怕孤独；与其独自存活，更希望他人好好活着。她走向被怪物袭击的超市时，周围空间破碎，一名新神器使由此诞生。

指挥使由此把安托涅瓦后来的自我牺牲与“害怕一个人、希望他人活下去”联系起来。这是指挥使的角色解释，不等于页面已经证明她所有行动只有这一种动机。

# 8. 第三次方舟：建设中的中央庭与零

第三次落点是刚建成的中央庭。安托涅瓦以管理员身份接待指挥使，将其带到临时资料室，并与一名被称为“零”、头有异样角的小女孩相遇。

页面直接呈现零与安托涅瓦关系亲近，零要收集战斗资料并愿意陪她寻找物品。指挥使尚未说明要找什么，方舟空间即剧烈波动，将其强制送回；指挥使感觉“方舟非常抗拒遇见她”。

边界：

- “零”之名和两人亲近是直接事件。
- “方舟抗拒零”是指挥使对异常波动的理解。
- 零的种族、神器、本质及空间为何崩解，本页没有确认。

# 9. 本日在路线结构中的作用

1. 恢复影像把希罗制造赛哈姆活骸化固定为会议冲突的直接证据。
2. 七人众正式分裂，希罗与安托涅瓦从内部矛盾转为敌对。
3. 希罗提出“保存神器使必须保留／利用黑门”的路线理论。
4. 安托涅瓦过度使用幻力后进入活骸化进程，形成路线救治目标。
5. 三次方舟分别展示她的灾难前生活、黑门危机中的人格选择、早期中央庭及与零的关系，但仍未取得治疗方法。
