# 使用边界

本文只整理“被抛下的人／剧情／第二天”的已采集正文，不替代 Raw 或 Clean，也不把角色对活骸、幻力或救治可能性的判断自动提升为完整机制结论。

- “拒绝他／答应他”是指挥使对无家可归者求助的态度选择，不会形成两条不同的后续路线。
- 自动清洗把到达中央庭后的共同续段挂在“答应他”下；人工整理时，应把两项各自的即时回应与共同前往中央庭的后续分开。
- 安托涅瓦在本页表现为几乎完全活骸化，并在结尾“完全失去生命特征”；本文只记录本页呈现，不据此补写跨路线的永久状态。
- 达尔维拉将死者称作“报废样本”和“残骸”，这属于其角色立场与研究所用语，不应成为本文的中性叙述标准。

## 选择树结构复核

```text
无家可归者请求前往中央庭寻找安托涅瓦
├─ 拒绝他 → 对方以临死前可能失控相威胁 → 指挥使被迫同意
└─ 答应他 → 指挥使主动同意，并安排实验服伪装
   ↓ 共同续段
潜入中央庭 → 无家可归者在高幻力环境中恶化
→ 见到已严重活骸化的安托涅瓦
→ 无家可归者绝望失控，被安托涅瓦终结
→ 安托涅瓦随后失去生命特征
→ 安与达尔维拉赶到，达尔维拉回收两具“残骸”
```

来源没有把“拒绝”保留为成功拒绝：对方的威胁使指挥使最终仍答应带路。两项差异在于同意的过程和是否明确出现伪装准备，而非是否抵达中央庭。

# 1. 失控的试验参与者

第三天参与实验的无家可归者逃进指挥使所在房间。他的右半身已经黑化、结晶并腐朽，精神也从此前的主动参与转为恐惧、颓然与接近疯狂。他承认自己临近死亡后突然不想死，并把最后希望寄托在安托涅瓦的神器使身份上。

他要求指挥使带自己去中央庭，认为既然变化由希罗造成，安托涅瓦或许能以“超能力”救治。这个期待来自绝境中的个人推测，不代表中央庭或安托涅瓦实际拥有相应救治手段。

# 2. 态度选择与共同续段

## 2.1 拒绝他

指挥使最初摇头拒绝。无家可归者以自己将死、什么都可能做出来相威胁，最终迫使指挥使答应带他前往。指挥使同时意识到安托涅瓦连自身状态也无法解决，对救治结果并不抱有确定信心。

## 2.2 答应他

指挥使直接同意，同时提醒这里仍是希罗控制的研究所。两人从实验室换衣柜中取得实验服，用乔装方式尝试避开研究所人员。

## 2.3 共同续段

无论同意源于主动选择还是威胁，指挥使最终都带无家可归者抵达中央庭。页面后续的中央庭事件属于两项汇合内容，不应误记为“答应他”独占。

# 3. 中央庭：两种活骸化结果相遇

进入中央庭的瞬间，无家可归者因当地极高的幻力浓度迅速恶化。页面描述普通神器使也难以独自在这种环境中停留，而半活骸化的普通人更无法承受；这是当日现场观察，不足以独立确定全城幻力浓度的固定数值或长期分布。

大厅中央出现严重活骸化的安托涅瓦：身体与从地下伸出的结晶肢体连为一体，眼睛在指挥使到来后短暂恢复清明。无家可归者看到连安托涅瓦也无法保持原状，因最后希望破灭而进一步失控。

安托涅瓦以结晶肢体刺穿无家可归者心脏，并向其道歉。随后她又向指挥使道歉，心脏大小的结晶从身体外脱落，结晶肢体垂下，页面明确写作“完全失去了生命特征”，周围幻力开始消散。

这一场面把第三天宣称“成功”的新式活骸与传统失控活骸并置：普通试验者没有获得稳定结果，安托涅瓦也未因神器使身份自动免于崩坏。它反驳了“活骸化已经完全安全”的乐观判断，但仍不提供所有失控原因的完整实验结论。

# 4. 安与达尔维拉赶到

安依据终端定位找到指挥使，达尔维拉则称自己来追捕走失的实验成员。他把无家可归者和安托涅瓦都称作需要回收的“残骸”，并宣布希罗的实验最后阶段已经完成。

达尔维拉还警告第二天之后异界将有“大动作”，要求尽量在此之前让神器使完成活骸化，并称希罗正在进行最关键的准备。本页没有揭示该准备的全部内容；第一天才会进一步说明巨大黑门与进入异界的计划。

# 5. 角色材料（限本页）

## 无家可归者

- 从主动参加实验转为在濒死状态下逃亡和求救，证明此前“自愿”不等于已知晓或接受全部后果。
- 把安托涅瓦视为最后救治希望；希望破灭后迅速陷入绝望与失控。
- 其死亡由本页直接呈现，但具体实验过程和失控原因没有完整记录。

## 安托涅瓦

- 严重活骸化后仍因指挥使到来短暂恢复清明。
- 在无家可归者失控时以致命方式结束其痛苦，并两次道歉。
- 本页以“失去生命特征”结束她的场景；永久生死与其他路线状态仍需由后续材料交叉确认。

## 安

- 通过终端定位寻找指挥使，表现出转化后仍保有对其安危的关心。
- 本页没有直接表现她失控，但第一天会揭示状态恶化，故不能把此刻行动当作长期稳定证明。

## 达尔维拉

- 继续以样本和残骸语言处理参与者，对个体死亡缺少同理表达。
- 宣布实验已进入最后阶段，并推动更多神器使在异界行动前完成活骸化。

# 6. 本页可用于后续核对的线索

- 无家可归者的结果与第三天“新式活骸成功”形成直接反差，说明普通人与神器使的转化过程不能混为一谈。
- 中央庭高幻力环境同时加速无家可归者崩坏，也与安托涅瓦的严重异化共存。
- 安托涅瓦在高度异化后仍保留短暂识别、悲悯与道歉，说明肉体异化程度不能简单等同于意识完全消失。
- 达尔维拉所称“最后阶段完成”与随后的安失控之间存在明显矛盾，适合作为希罗研究可靠性的后续核对点。
