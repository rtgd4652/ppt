# 使用边界

本文只对《避世的方舟》第四天已采集的 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 本页有一棵三选一的玩家选择树；仅“带着安托涅瓦一起跑”之下嵌套一棵“剧情战胜利／失败”状态树。两棵树均为 `repeatable: false`，且索引均未登记共同续段。
- “先跑”“带着安托涅瓦一起跑”“与活骸战斗”是互斥行动，不是同一场战斗的先后步骤。
- “带着安托涅瓦一起跑”后发生战斗，但胜败属于战斗状态，不是第二次玩家对话选择。
- “剧情战失败”与“与活骸战斗”的正文高度相似；它们仍有不同父节点，不因文本重复而合并。
- “先跑”、嵌套战斗失败和“与活骸战斗”都出现方舟耗尽与进线失败，但各分支此前发生的事件不同。
- 晏华关于零的历史说明来自隐藏档案及其解读；“假如零还活着就能救安托涅瓦”在本页先是晏华的条件判断和指挥使的希望，不是已经发生的治疗结果。

# 1. 分裂后的中央庭与安托涅瓦的病情

希罗通过早间新闻宣布离开中央庭只是“战略改变”，会建立独立组织，同时仍以夺回安全世界为公开目标。晏华则向指挥使说明，分裂已经带来三项直接压力：

- 希罗带走许多神器使；
- 中央庭在城市中的信用下降；
- 中央庭行动受限且人手严重不足。

晏华要求指挥使与安通过委托了解市民立场并争取外部支援。安提议分头行动，指挥使负责西侧、安负责东侧。

安托涅瓦随后坐轮椅出现。她说明自己暂时不能使用武器和方舟，但仍会处理文书并提供支援。面对指挥使对活骸化治疗线索的询问，她认为除非出现“奇迹”，否则大概没有办法；指挥使承诺去寻找奇迹，她答应等待。

这里可确认的是安托涅瓦已经清醒、暂不能使用神话武器与方舟、活骸化仍需治疗。她对“若非奇迹便无办法”的回答是基于当时认知的判断，不等于页面已经证明所有治疗途径均不存在。

# 2. 关于零的隐藏档案

指挥使巡查中央庭，在数据库中搜索“零”却没有找到公开登记。晏华通过隐藏路径调出文件，并说明：

- “零”不是名字，而是编号；
- 她是最初跟随希罗的神器使之一，也是第一个成为活骸的神器使；
- 事件发生在中央庭刚建立不久、众人尚未充分认识活骸危害的时期；
- 她平时多数承担治疗角色，活骸化后主要显露毁灭能力；
- 讨伐造成严重损失，安托涅瓦也在当时重伤；
- 活骸化的零取出带有不死能力的结晶治疗安托涅瓦；
- 零最终自我毁灭，此后无人再见到她，也没有留下尸体；
- 从资料特征看，她的身体被某种异形生灵寄宿，自身即为武器，兼有创生与毁灭性质。

以上主要是晏华对隐藏资料的转述。页面没有展示原档案全文、零自我毁灭的现场，也没有独立确认“尸体未留下”意味着她仍然存活。

晏华说“如果她还活着，安托涅瓦或许还有一线希望”；指挥使据此把零视为治疗关键。这里的语气是“或许”，不能提前改写为零或不死结晶一定可以完成治疗。

# 3. 最后一次方舟：抵达零活骸化的历史切片

指挥使启动方舟后，先听见两段断裂通讯：前方防线受损严重，一名未知者判断无法继续战斗；另一名未知者称敌人太强。清洗页没有确认两名说话者身份。

指挥使抵达一座被巨大力量破坏、黑雾浓重的城市，遇到仍能认出自己的安托涅瓦。活骸随即击碎她的防护罩。安托涅瓦要求指挥使立刻逃走，页面由此进入三选一分支。

该落点与第四天档案所述“零活骸化、安托涅瓦重伤”相呼应，但它是方舟抵达的历史切片。页面没有证明指挥使第一次访问过去时就已改变原历史，也没有解释方舟为何恰好到达此时。

# 4. 顶层选择树

```text
最后一次方舟：活骸击破安托涅瓦的防护
├─ 先跑
│  └─ 见证活骸取出结晶治疗安托涅瓦 → 后续搜索失败 → 进线失败
├─ 带着安托涅瓦一起跑
│  ├─ 剧情战胜利 → 得到“不死结晶” → 返回现在
│  └─ 剧情战失败 → 安托涅瓦受创并送走指挥使 → 后续搜索失败 → 进线失败
└─ 与活骸战斗
   └─ 安托涅瓦受创并送走指挥使 → 后续搜索失败 → 进线失败
```

三个顶层选项和两种战斗状态均不可重复。来源索引没有为任何一层登记共同续段。

## 4.1 选择“先跑”

指挥使依言逃离，却因跌入裂缝扭伤脚踝，无法返回战场。再次到达现场时，指挥使看见活骸向重伤的安托涅瓦爬去，一边以未知身份台词道歉、请求她不要死，一边从心口挖出淡蓝色结晶并掰碎，撒在她身上。

结晶融入后，安托涅瓦的断肢接回、出血停止，结晶也随之消失。指挥使被方舟带走，此后多次寻找同一时空，直到方舟力量耗尽仍未再次抵达。页面标注进线失败。

本分支直接展示的是“活骸以结晶治疗安托涅瓦”。结合晏华档案，可以把该活骸列为零的强候选；但清洗正文在这段台词处仍用“？？”，说话者标注不宜擅自改成已由零的某个人格实名发言。

## 4.2 选择“带着安托涅瓦一起跑”

指挥使拉住安托涅瓦撤退，并向她透露自己来自别的时空、要寻找零的治疗线索，也希望避免她被重伤。安托涅瓦称自己与希罗的联系被临时斩断、幻力不足，请来自别处的指挥使为她供能，两人随后迎战活骸。

安托涅瓦在战前说明：眼前的神器是零；其变化从结晶化开始，继而结晶消失、四肢崩裂，最终失去神志并无差别攻击敌我。这里是历史切片中的安托涅瓦对眼前变化的观察和命名过程。

### 剧情战胜利

两人击败活骸。安托涅瓦认为零一直因无法救下死者而痛苦，将取得的一小块结晶交给指挥使，用于治疗其“最重要的人”。页面明确登记得到“不死结晶”。

方舟裂隙随即出现，指挥使只来得及承诺一定会救她。众人离开后，希罗出现在战场残骸上，对零表示“你做到了”，又追问为何偏偏是安托涅瓦做到了。

此分支没有“进线失败”标记，是本页唯一取得不死结晶并正常返回的顶层路径。页面仍未直接展示结晶在现代治疗中的最终效果。

### 剧情战失败

安托涅瓦为保护指挥使被活骸利爪贯穿，随后以方舟碎片包裹并送走指挥使。指挥使之后数次搜索该时空，直到方舟耗尽也未再抵达。页面标注进线失败。

“安托涅瓦说自己不会死”是她在送走指挥使时的安抚；本分支没有提供其此后的生死结论。

## 4.3 选择“与活骸战斗”

本分支直接进入与嵌套战斗失败几乎相同的段落：安托涅瓦为保护指挥使被贯穿，以方舟碎片将其送走；此后反复搜索失败，方舟耗尽，页面标注进线失败。

文本重复不代表两项在结构上相同：

- “与活骸战斗”是顶层玩家选择；
- “剧情战失败”是先选择带安托涅瓦撤离、说明来历并获得其协作后产生的战斗状态。

# 5. 本日在路线结构中的作用

1. 分裂后的中央庭进入信用、人力和区域控制危机。
2. 安托涅瓦虽已清醒，却因活骸化暂时失去方舟和战斗能力，治疗成为路线目标。
3. 晏华的隐藏档案把零、首个活骸事件、安托涅瓦旧伤和不死结晶连接起来。
4. 最后一次方舟将指挥使送到零活骸化的历史切片。
5. 只有“带着安托涅瓦一起跑＋剧情战胜利”取得不死结晶；其余三条已写明的失败路径均失去继续寻找该时空的机会。

# 6. 角色补充（限本页）

## 安托涅瓦

- 在不能使用方舟和武器时仍继续处理中央庭文书。
- 对自身治疗前景悲观，但接受指挥使寻找“奇迹”的承诺。
- 历史切片中的她即使幻力不足，仍坚持阻止失控的零。
- 战斗胜利时主动把结晶交给指挥使；失败时则优先将指挥使送离危险。

## 晏华

- 在中央庭人力不足时承担协调、委托和外部支援工作。
- 知道零的隐藏档案路径，并据资料把零与首个活骸、安托涅瓦重伤及不死结晶联系起来。
- 关于零本质的说明是基于档案特征的定性，不能替代零本人或独立研究结论。

## 零

- 隐藏档案称其为编号、早期神器使和首个活骸。
- 档案称其兼具治疗与毁灭能力，并曾用不死结晶治疗安托涅瓦。
- 历史切片中，安托涅瓦明确把眼前活骸称为零。
- 活骸段的碎片化道歉台词、零的主人格与里人格关系，本页没有完成说明。

## 指挥使

- 把寻找零及不死结晶作为救治安托涅瓦的关键尝试。
- 顶层行动与战斗胜败共同决定是否取得结晶。
- 失败分支中即使反复搜索，也因方舟能量耗尽而失去继续行动的机会。

## 希罗

- 只在胜利分支收尾处出现，对零及安托涅瓦的结果作出反应。
- 其“你做到了”没有在本页完整说明预设任务的内容，不能据此补写他对全部事件的直接控制过程。
