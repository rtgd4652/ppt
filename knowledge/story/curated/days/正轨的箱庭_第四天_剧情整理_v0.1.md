# 使用边界

本文只对第四天已采集的 Wiki 正文作结构化整理，用于后续人工审核、角色档案与主线时间线工作。它不替代 raw 或 clean 来源文本，也不把角色在新闻、会议或私下对话中的说法直接升级为无条件成立的世界观事实。

- 本页“旧城区黑核情报”中的“处理／不处理”是一次性资源选择；“改版前／改版后”只是 Wiki 的版本对照，不是游戏内抉择。
- “港湾区黑核情报”列出了两个来自第五天的前置状态，但目前采集到的页面结构没有可靠地把其后的港湾失守文本逐项绑定到其中一个状态。因此本文保留状态与结果，不自行补写对应关系。
- 本页出现的行动后果、人物身体状况与政治判断，均限定在第四天正文的叙事语境中；跨日或跨路线结论需要额外来源核对。

# 1. 当日开场：中央庭分裂后的公开局面

页面以中央庭高层发生严重分歧为当日背景：希罗已从中央庭分裂出去，安托涅瓦在试图阻止他的过程中受伤。

随后，电视新闻以采访形式呈现希罗的公开说法。希罗将离开中央庭称为战略改变，表示中央庭仍会活动，而自己会建立独立组织系统；他同时将“夺回安全的世界”描述为双方的共同目标。这一段应记录为希罗面向公众提出的路线解释，而不是对分裂性质的独立裁定。

晏华则从中央庭内部的工作视角说明当下局势：分裂虽未在表面完全撕破，但已限制中央庭行动；希罗带走许多神器使，中央庭在城市中的信用快速下降。晏华还转述希罗曾公开提出以激进方式让所有人成为神器使的方向；该内容在本页中属于晏华对局势的概括，需要在后续页面继续核对其完整条件与实际实施情况。

# 2. 中央庭的维持与城市行动

在人手紧缺的情况下，晏华将当日的工作重点放在两件相互关联的事务上：

- 通过城市委托了解市民的具体立场；
- 争取外部支援，以维持中央庭继续运转。

安将这一安排概括为“赚好评”，并提出与指挥使分头行动。页面随后把指挥使的日常职责落到区域巡视、城市事务与黑核收集上。这里可作为“中央庭分裂后仍试图依靠城市委托、公共支持与前线行动维持秩序”的本页材料，但不能据此补全中央庭所有行政制度。

# 3. 安托涅瓦的伤势与持续支援

安托涅瓦已经苏醒，但晏华说明她暂时不能使用神话武器。她以轮椅代步，并向指挥使与安表示，身体状况不会阻止自己继续完成文书与支援工作。

本页将她的状态通过三个层次呈现：

- 页面开场直接交代：她在阻止希罗时受伤。
- 晏华说明：为防止风险，她暂时不能使用神话武器。
- 安托涅瓦自身说明：失去方舟的使用条件后，她第一次切身体会到一般人的身体限制；即使如此，她仍会尽力提供支援。

当指挥使询问她的活骸化是否有线索时，安托涅瓦给出的是个人判断：除非发生奇迹，否则她认为目前没有办法。指挥使因此表示会去寻找“奇迹”，安托涅瓦接受这份约定。此处应记录为角色面对未知病变时的自我认知与关系表达，而不能在本页之外直接推出活骸化的最终规则或必然结局。

# 4. 黑核情报与状态边界

## 4.1 港湾区黑核情报：第五天前置状态

“港湾区黑核情报”在正文中先后列出：

- 第五天未处理希罗动向；
- 第五天已处理希罗动向。

紧随其后的文本描写希罗在港湾区取走黑核、潜艇浮出海面，并以“港湾区已被希罗占领，黑核本周目内无法再回收”收束。

当前 raw 与 clean 输出保留了两个状态标签和这段失守文本，却没有保留足以可靠判断“失守文本究竟对应哪一个第五天状态”的 HTML 结构。为避免把前置条件反写，当前整理只记录：本页存在第五天处理结果影响第四天港湾区的条件性内容；港湾区失守与黑核永久丢失的具体触发映射须以原页面结构、游戏实测或人工确认补齐。

## 4.2 旧城区黑核情报：当日独立选择

“希罗动向／旧城区黑核情报”明确提示：情报显示希罗将在下一日入侵旧城区并夺取黑核。页面的玩家选择及直接结果如下：

| 选项 | 页面明确呈现的结果 |
| --- | --- |
| 不处理 | 下一日希罗将夺取旧城区黑核。 |
| 花费情报 60 处理 | 成功阻止希罗夺取旧城区黑核。 |

这是与港湾区前置状态分开的单次处理选择。后续时间线、区域资料或资源逻辑引用时，都应保留是否花费情报处理这一条件。

# 5. 角色与组织信息（限本页）

## 安托涅瓦

- 在中央庭分裂后仍承担文书、联络与支援工作。
- 伤后暂时不能使用神话武器，以轮椅行动。
- 对自身活骸化的解决前景保持悲观，但没有放弃与指挥使之间继续寻找办法的约定。

## 晏华

- 以分析与协调者的立场评估分裂后的人手、信用和行动限制。
- 将城市委托、公众支持与中央庭维持工作纳入当日任务安排。
- 提供安托涅瓦暂不能使用神话武器的状态说明。

## 安

- 注意到晏华的疲惫与安托涅瓦伤势带来的现实压力。
- 提出分头行动，并与指挥使共同离开中央庭执行城市巡视与黑核收集工作。

## 希罗

- 以公开采访说明自己离开中央庭及建立独立组织系统的立场。
- 在港湾区相关条件性文本中出现为夺取黑核的一方。
- 对其“让所有人成为神器使”等方向，本页只能保留为晏华转述的局势信息。

# 6. 本页在主线资料中的作用

第四天将第五天冲突后的影响落到中央庭的日常存续上：公共信用受损、人手不足、安托涅瓦受伤、城市支持和黑核控制都成为同一轮回内互相影响的压力来源。

同时，本页为后续整理留下两类需要保持条件边界的材料：

- 希罗动向会受到前一日情报处理状态影响；

因此，后续不能将“中央庭分裂”“港湾区失守”“旧城区黑核被夺”连写为不带条件的单一固定时间线。
