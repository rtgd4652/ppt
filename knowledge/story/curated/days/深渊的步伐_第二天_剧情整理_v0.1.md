# 使用边界

本文只整理“深渊的步伐／剧情／第二天”的已采集正文。本页承接第三天阻止安参加实验的分支，是“神的棋盘／零的故事”的共通日页；不应与“被抛下的人／剧情／第二天”混读。

- “大大方方地告诉她／稍微有点不安”只改变指挥使如何向零交代来历；零讲述希罗、活骸化和世界融合的长段内容是共同续段。
- 零与“活骸零”共享同一身体但具有不同意识和愿望，本文严格分开书写。
- 零关于希罗早年经历、中央庭建立、黑核与世界融合的说明属于她当时掌握的信息；希罗真正想毁灭世界的目的直到第一天才由其本人明确。
- “新式活骸实验完成”是希罗的宣告；本页没有证明其永久安全。


# 1. 梦境与地下通道

指挥使因没有交出实验对象而辗转难眠。神秘少女再次出现在梦中，表示指挥使尚未想起她，因此还不到揭示身份的时候。指挥使醒来后发现希罗在非工作时间携带黑核进入平时封闭的地下通道，遂不带战术终端跟踪。

地下洞窟充满黑雾、紫黑结晶和能够孕育黑门的异常环境。希罗将黑核放入围绕巨大活骸的拘束装置，使结晶继续生长并完全包裹其身体；确认装置后离开。

本段只确认希罗使用黑核维持或强化拘束状态，不能仅凭场景推导装置完整原理。

# 2. 零与活骸零：同一身体中的两个意识

希罗离开后，指挥使接近活骸。此时出现的温和意识自称“零”，称自己曾是中央庭神器使，变成活骸后只剩非常虚弱的一点意识；当“她”苏醒，零就会失去控制并最终消失。

零说明希罗把两者关在地下，是为了避免活骸人格外出伤人，并曾承诺在创造“理想世界”后让她离开。这里的“她”指占据身体主导地位的活骸人格，不能把其言行归到零名下。

# 3. 两项交代方式与共同续段

| 选项 | 独立内容 |
| --- | --- |
| 大大方方地告诉她吧 | 指挥使主动讲述希罗、中央庭分裂、实验和自己来到地下的经过；零称赞两人努力，并担心受伤的安托涅瓦。 |
| 稍微有点不安，但她感觉并不危险 | 零根据指挥使知道自己、没有神器使特征且跟踪希罗等线索，推断其身份和来意，并主动提出说明希罗。 |

来源页面把后续长段挂在第二项下，但从内容关系看，两条表达均汇入零对希罗与自身历史的讲述；不能把完整背景误写成只有“不安”选项才能得知。

# 4. 零的历史叙述与证据边界

零在共同续段中给出以下叙述：

- 希罗在黑门出现前就主张异世界存在，并长期为此准备；
- 黑门事件后，希罗迅速组织中央庭、寻找神器使并参与压制各地黑门；
- 零负责治疗时最早发现无法治愈的伤，为给研究提供样本而主动让自己活骸化；
- 活骸化后，另一个意识占据身体，希罗及时将二者拘束并从样本中获取数据；
- 黑核打通两个世界，是希罗收集黑核进行研究的关键对象。

这些内容可作为零的经历和她对希罗的理解，但其中涉及中央庭形成史、希罗动机和异界机制的部分仍应与其他页面交叉核对，不能直接扩写为无条件世界观定论。

# 5. 世界融合警告

当指挥使询问希罗所说的“两个世界融合”是否会形成新世界时，零明确回答：强行把两个千疮百孔的世界拼在一起，只会令两者共同毁灭。她认为希罗不应犯下这种错误，请指挥使提醒并帮助他，同时建议在必要时带走周围黑核。

随后结晶碎裂，零警告活骸人格即将苏醒并催促指挥使离开。指挥使在出口处听见活骸零询问是否有人来过，零选择隐瞒。

这是本路线第一次直接否定希罗“融合会创造理想世界”的说法，但仍是零基于自身知识作出的说明。第一天希罗的行动表明，他可能早已知道毁灭风险并有意追求终结。

# 6. 希罗宣布实验完成

指挥使回到地面后遇见希罗。希罗宣布奥露西娅等实验者已经完成“新式活骸”实验，并准备让他们次日进攻中央庭；他还判断安托涅瓦的伤势会使其在次日进入失去神智的活骸状态。

指挥使因已得知融合风险而不再相信实验能够拯救世界，但为了避免自己的神器使面对强化敌人时毫无准备，仍跟随希罗了解转化方法。页面由此开启“活骸化”功能，并再次提醒该功能会改变结局走向。

# 7. 角色材料（限本页）

## 零

- 以虚弱而清醒的意识存在于活骸身体中，主动保护外界免受另一意识伤害。
- 把自己成为样本理解为警告与帮助他人的选择。
- 仍然信任希罗能够拯救世界，发现融合会毁灭双方后首先希望纠正而非消灭他。

## 活骸零

- 本页只在苏醒前后的短句中出现，却已被明确为压制零、占据身体的另一个主体。
- 其完整目标尚未在本日揭示，不能把零的善意或警告归给它。

## 希罗

- 使用黑核维持地下拘束，并向零之外的人隐瞒该空间。
- 公开推进新式活骸和对中央庭的攻击，却未向指挥使说明融合会共同毁灭。

## 安托涅瓦

- 本页未直接出现；其伤势和活骸化风险分别由零关切、希罗判断，均需按说话者引用。

# 8. 本页可用于后续核对的线索

- 零与活骸零不是“人格情绪变化”，而是立场相反的两个意识主体。
- 零关于黑门前研究、中央庭早期和自愿成为样本的叙述，是补充希罗与零关系的重要第一人称材料。
- 融合会毁灭两个世界的警告，是第一天质问希罗和最终战选择的直接前提。
- 希罗仍宣称实验与进攻成功，说明其公开拯救理由和真实目的之间存在断裂。
