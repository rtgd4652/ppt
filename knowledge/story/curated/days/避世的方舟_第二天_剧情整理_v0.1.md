# 使用边界

本文只对《避世的方舟》第二天已采集的 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 来源索引只登记一个“第2天”正文段，`choice_trees: 0`；本页没有玩家选项、状态 Tab 或可重复菜单。
- 页面从“已用急救中心治疗”直接进入安托涅瓦恢复后的对话，没有复述不死结晶研究过程、科技值判定或具体治疗操作。
- 安托涅瓦关于神器使、活骸化及希罗宣传的公开发言均保留说话者层级；公开演说并不自动等于所有机制已经由独立资料验证。
- “突袭”是本日解锁的区域进攻玩法。空间道标、情报系统和忽略区域距离是页面直接给出的行动规则，但具体区域结果在第一天的独立模块中出现。

# 1. 急救中心后的苏醒

指挥使守在已经接受急救中心治疗的安托涅瓦身边，因疲劳睡着。安托涅瓦醒来后称身体状况很好，并以半开玩笑的方式引导指挥使说出“没有她会很想念”。

页面随后明确显示“安托涅瓦恢复了健康”。她准备重新活动并投入接下来的战斗，指挥使认为两人可以一起阻止希罗和黑门。

当前来源可以确认：

- 安托涅瓦在第二天醒来并被页面判定恢复健康；
- 指挥使此前持续守候且极度疲劳；
- 两人的信任与亲密程度进一步加深。

当前来源不能单独确认：

- 不死结晶、科技值 210、急救中心三者各自承担了哪一步治疗作用；
- 结晶是否被消耗、如何使用，或治疗是否存在其他隐藏条件；
- “恢复健康”是否意味着此前身体旧伤也全部消失。后续最终日反而继续把其下肢旧伤视为长期状态，因此不能把本页措辞扩大为所有身体损伤均已治愈。

# 2. 中央庭正式发布会

安托涅瓦随后举行正式发布会，说明中央庭分裂、后续人力安排，并回应希罗发布的宣传。

她首先指出，希罗离开中央庭已经三天；期间怪物和黑门没有减少，各区域伤亡率仍在上升。她承认希罗宣传中的一部分具有现实基础：普通人确有成为神器使的可能，因为现有神器使过去也曾是普通人。

接着，她补充希罗没有公开的风险：

- 神器使身体已被异界异变，介于人类与怪物之间；
- 体内力量失控时可能成为失去理智的活骸；
- 神器使之间早有约定，一旦有人进入这种状态，由其他人将其消灭。

安托涅瓦承诺中央庭会继续破坏黑门、清剿怪物，同时呼吁普通人不要因追求力量加入她所称“注定灭亡的队伍”。

# 3. 演说的证据边界

发布会直接证明安托涅瓦选择向公众披露活骸风险，并以减少新神器使为政策目标。下列内容仍需按层级使用：

- “普通人也能成为神器使”是安托涅瓦对现象的承认，不代表任何普通人在相同条件下都能成功转化。
- “神器使介于人类和怪物之间”是她在公开演说中的概括，不能据此替代生理结构或幻力研究资料。
- “所有神器使都有可能变成怪物”强调共同风险，不等于每人必然在本轮发生活骸化。
- “一旦失控由其他人消灭”是她所述的内部约定和处置规则；规则存在不代表每次执行都没有争议或例外。
- “注定灭亡的队伍”表达她对神器使前景的悲观判断，与第三天有关黑门关闭后神器使死亡的说明相呼应，但本页没有再给机制证明。

# 4. 路线目标转为回收黑门之核

发布会后，指挥使认为听众已经开始动摇。安托涅瓦判断这还不够，并宣布中央庭主要目标变更为回收黑门之核。

行动方法分为两部分：

1. 安托涅瓦利用方舟开启通往希罗占领区的传送通道；
2. 指挥使利用情报系统取得各区域的空间标记点信息。

系统随后提示解锁“区域突袭”：

- 通过情报开启区域突袭；
- 突袭可忽略区域距离；
- 可直接攻击希罗占领区并收复失地。

这里的“忽略区域距离”属于玩法与行动条件，不应外推为方舟在任何地点、任何时间都能无条件传送。第一天各区域突袭的实际模块还需要分别满足对应空间道标和战斗结果。

# 5. 本日在路线结构中的作用

1. 安托涅瓦从第四、三天的活骸化危机中恢复，重新承担公开领导与战斗规划。
2. 她将中央庭与希罗的分歧公开化，并向市民披露成为神器使和活骸化的风险。
3. 中央庭从维持组织与治疗安托涅瓦，转入主动回收黑核和收复占领区。
4. 方舟、空间道标和情报系统共同构成第一天区域突袭的前置行动框架。
5. 本页没有新选择树；结局差异尚未在此产生。

# 6. 角色补充（限本页）

## 安托涅瓦

- 在急救中心治疗后醒来，并被页面直接判定恢复健康。
- 以轻松、亲近的方式要求指挥使承认对自己的个人感情。
- 通过正式发布会承担组织危机沟通，公开活骸风险和内部处置约定。
- 不接受希罗把力量转化宣传成单纯“进化”，并试图阻止更多普通人进入高风险转化。
- 重新使用方舟规划突袭通道，但本页没有直接展示她已恢复到第五天战斗前的全部状态。

## 指挥使

- 为救治安托涅瓦持续行动和守候，停下后才显露明显疲劳。
- 在安托涅瓦追问下承认会因失去她而想念。
- 接受通过情报系统寻找空间道标、配合方舟突袭的任务。

## 希罗

- 本页没有现场出现，其立场通过此前宣传与安托涅瓦的回应呈现。
- “频繁接触黑雾会产生进化”“普通人可以成为神器使”是发布会概括的希罗宣传内容；不得补成希罗在本页亲口给出的完整研究论证。
