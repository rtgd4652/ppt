# 使用边界

本文只整理“被抛下的人／剧情／第三天”的已采集正文，不替代 Raw 或 Clean，也不把希罗、达尔维拉等角色对实验结果的解释直接提升为已经证实的世界观机制。

- 本页首先按第四天的行动状态分成两条路线；“第四天未让普通人参加实验、未推完港湾区”同时包含行动与区域进度两个条件，不能简化成单一选择。
- 每条状态路线内各有一次态度选择。自动清洗把选择后的共同续段挂在最后一个选项下，人工整理时应将共同续段抽出。
- “新式活骸”在当日实验结束时仍保持清醒并获得强化，但后续页面证明这种状态仍可能失控；不得把本页的“成功”写成已经永久解决活骸化。
- 页面没有给出“活骸化”结局要求的完整数量或阈值，不得由本页的功能提示反推具体数值。

## 选择树结构复核

```text
第四天让普通人参加实验
├─ 是有点累了
└─ 其实不怎么累，继续等着
   ↓ 共同续段：实验警报 → 新式活骸暂时成功 → 开启活骸化功能 → 计划讨伐中央庭

第四天未让普通人参加实验、未推完港湾区
├─ 既然你这样要求了……
└─ 一定要好好地回来
   ↓ 共同续段：安主动参加 → 实验警报 → 安暂时保持清醒 → 开启活骸化功能 → 计划讨伐中央庭
```

两组选择均主要表达指挥使当下的态度。来源在各选项后只分别保留短回应，而警报、实验结果、功能开启与中央庭讨伐命令构成该状态路线后续；不得把这些共同内容误写成最后一个态度选项的独占结果。

# 1. 第一条状态路线：第四天让普通人参加实验

指挥使回顾自己按照希罗的要求，在旧城区找到并让一名普通人参加实验。希罗称指挥使找到了合适的神器使，又称达尔维拉带来了普通对照组；页面对样本称呼存在混杂，当前整理不据此重建完整样本名单。

研究所内聚集着不同动机的研究人员：有人心怀目的，有人沉迷研究，也有人单纯追随希罗。希罗询问指挥使是否疲惫，形成“先休息／继续等候”的态度选择。

## 1.1 态度选择与共同续段

| 选项 | 独立回应 |
| --- | --- |
| 是有点累了 | 希罗表示会让人带指挥使回房间。 |
| 其实不怎么累，继续等着 | 希罗同意继续观察，并提醒不要勉强。 |

随后实验警报响起。舱室压力越过临界值，希罗仍命令研究员继续；装置最终炸裂，结晶和黑雾泄出。数值恢复后，一名仍保持外形、意识与智力的神器使从黑雾中走出，指挥使称其为安。希罗把这一状态称为“新式活骸”，并宣称其躯体固定、不会疲惫、衰弱或死亡。

“不会死亡”等结论是希罗在成功当下的主张。页面只直接证明实验对象此刻保持清醒、身体出现紫黑结晶且检测数值符合其预期；后续失控风险仍然存在。

# 2. 第二条状态路线：未让普通人参加实验且未推完港湾区

这一状态路线同时要求第四天没有让普通人参加实验，并保留“未推完港湾区”的区域进度。指挥使没有为希罗准备神器使样本，理由是活骸化仍有危险；希罗则指责其既不愿承担风险又期待研究成果。

安主动提出参加实验。她把这一决定解释为：既然指挥使把未来寄托在希罗的研究上，己方也应承担代价。指挥使担心实验会让本想保护的人先行死亡，安则要求其相信自己。

## 2.1 态度选择与共同续段

| 选项 | 独立回应 |
| --- | --- |
| 既然你这样要求了…… | 安回答“我明白了，就这么决定了”。 |
| 一定要好好地回来 | 安同样回答“我明白了，就这么决定了”。 |

两项只改变指挥使表达同意时的语气。安随后共同向希罗请求参加实验，不是第二项独占内容。

达尔维拉展示手上活骸化结晶，并称前一日实验已经能避免神器使在过程中死亡；他把方法描述为以指挥使的力量重新梳理暴走能量，同时警告指挥使真正需要面对的是实验后形态能否被接受。这仍是达尔维拉的说明，不等同于风险已被完整排除。

实验过程中压力异常、研究所震动并触发警报。数值回落后，安仍保持意识，身体出现紫黑纹路，自述身体轻盈且不会疲惫。希罗将结果称为“完美的进化”，安则希望其他神器使也能借此避免活骸化、黑门关闭与死亡，并与指挥使继续生活。

# 3. 两条路线的共同结果与后续方向

两条状态路线都在页面中导向以下结果：

- “活骸化”功能被开启；满足游戏条件的神器使可以在海底研究所接受转化。
- 页面提示活骸化会显著增强战斗力，也可能影响结局走向。
- 希罗判断中央庭因失去指挥使供能、强力成员外出而防御薄弱，命令指挥使讨伐中央庭并夺取黑核。

这里的“功能开启”和“路线要求”应分开记录。功能说明没有列出通往“被抛下的人”结局所需的具体活骸人数、黑核数量或其他隐藏条件。

# 4. 区域黑核回收

## 4.1 高校学园

指挥使与达尔维拉找到高校学园黑核。达尔维拉明确表示自己不喜欢学校，随后离开；页面确认该黑核被回收。

## 4.2 中央庭

达尔维拉提醒中央庭仍有反攻能力，并以“神之头脑”称呼晏华，认为其不可轻视。羊角恶魔影子把装有黑核的盒子交到达尔维拉手中；他对中央庭没有进一步隐藏黑核感到疑惑。页面确认取得黑核，但没有解释晏华的具体计划。

# 5. 角色材料（限本页）

## 安

- 在第二条状态路线中主动承担实验，并把自己的选择与指挥使希望所有神器使活下去的目标联系起来。
- 实验结束时保持自我意识并表现出乐观，但这只是当日状态，不应覆盖第一天出现的后续失控。
- 第一条状态路线中，屏幕内实验对象被指挥使称为安；页面对前置样本叙述存在混杂，仍需与实机画面核对。

## 希罗

- 把研究者、普通人和神器使都当作实验样本，并在设备超出临界值时坚持继续。
- 将暂时稳定的新式活骸解释为“不再死亡”的成功，并立刻把成果用于攻打中央庭。
- 其关于实验安全、独立个体和永生的判断均属于当日研究者主张，后续页面会对这些判断形成反证。

## 达尔维拉

- 在第二条状态路线中承担实验现场操作与解释工作，对风险和肉体变化保持冷漠态度。
- 在黑核回收段落中表现出对晏华及中央庭反攻能力的警惕。

# 6. 本页可用于后续核对的线索

- “新式活骸”显示肉体异化可以暂时先于精神崩坏，但不能据此认定精神问题已经被解决。
- 指挥使是否主动提供普通人、是否让安参加实验，以及区域推进状态，共同影响第三天可见内容。
- 希罗把研究成功、神器使存续和进攻中央庭连续起来，体现其科研目标与阵营战争并未分离。
- 中央庭黑核没有被进一步隐藏，可能是战略选择，也可能只是页面未提供过程；不得自行定论。
