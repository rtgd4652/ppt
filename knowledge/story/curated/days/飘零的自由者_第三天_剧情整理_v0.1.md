# 使用边界

第三天来源页只保存当日手账、自由行动提示和领取补给，没有独立支线正文或选择树。来源缺少正文不等于正史中“这一天什么都没有发生”。

# 1. 页面可确认内容

- 新的一天开始，指挥使继续探索城市。
- 路线状态仍以“自由的生活，应该怎样选择”为主题。
- 玩家进入自由行动，可以自行决定当天行动。
- 中央庭智能系统仍能验证身份并记录每日报告。

# 2. 与濯樱祭愿望链的关系

《记忆的种子/剧情/主线剧情》另行保存按已结识神器使数量推进的居民愿望内容。它们可能在自由行动期间发生，但本页没有把某一段愿望固定标注为第三天事件。

因此整理时：

- 不把第一至第五段愿望机械分配到第六至第二天；
- 不根据常见攻略顺序，把某名神器使或某个居民事件固定写进第三天；
- 愿望链继续作为进度触发内容独立整理，直到获得明确日期证据。

# 3. 页面结构

```text
第三天开始
├─ 手账：继续探索城市
├─ 自由行动提示
└─ 领取补给／记录每日报告
```
