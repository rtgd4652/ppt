# 使用边界

P05 不是单一的东方古街剧情，而是从高校学园开始、在第二次讨伐选择东方古街后，继续串联研究所、海湾侧城、旧城区与港湾区的长篇地区流程。本文依据完整低清视频、每三十秒接触表、转场高密度接触表和原分辨率关键帧，完成地区结构级人工校订。

- 本文确认地区顺序、中央庭交接、区域完成界面和可辨识角色。
- 没有逐句核验的对白不补写为完整台词。
- 中央庭房间、城市地图和公共调查事件单列为交接／公共过场，不强塞进前后某一地区。
- P06 是第二次讨伐选择中央城区的替代分支；P07 是各地区讨伐后的黑核回收集合。
- 临时视频、关键帧和接触表保存在 `temp/story_video/`，受 Git 忽略，不是公开仓库资产。

# 2. 高校学园与第二次讨伐前置

## 2.1 高校学园

P05 开头并不是东方古街。它先保存高校学园的地区流程：

- 中央庭进行任务说明后，队伍进入高校学园环境；
- 安、珈儿等角色参与高校区域行动；
- 视频包含校园、教室、战斗和区域异常画面；
- 约 `14:10`，安明确表示黑门影响已经消失，并提议返回中央庭。

高校学园正文在 Wiki 中已有较完整结构，P05 在此主要提供演出顺序和视频时间锚点。

## 2.2 第二次讨伐选择

返回中央庭后，安托涅瓦与晏华说明下一阶段任务。城市地图和中央庭对话把流程带入第二次地区选择。P05 采用东方古街路线，P06 采用中央城区路线；二者只是中段选择差异，不改变主线走向或结局。

# 3. 东方古街独有段

约 `17:50` 起，画面正式进入东方古街：

- 东方古街庭院、灯笼、樱树与街道构成稳定场景锚点；
- 雯梓与钟函谷在当地流程中出现；
- 达尔维拉也进入后段行动；
- 地区战斗和区域完成界面在约 `30:00` 前后结束独有段。

当前可确认该段属于东方古街，但雯梓、钟函谷与达尔维拉的全部对白、行动分工和因果链仍需逐句转录。

# 4. 东方古街之后的公共过场

约 `30:00–36:50` 不是另一个已经确认的地区讨伐正文，而是中央庭汇报、夜间公园调查、达尔维拉相关行动和下一地区准备的混合过场。

这一段必须保持独立，原因是：

- 场景先回到中央庭；
- 随后出现夜间公园及城市行动；
- 约 `36:50` 后才稳定进入研究设施；
- 现有画面不足以把整段归入东方古街或研究所。

# 5. 研究所

约 `36:50–52:30` 的环境、人物和完成节点共同指向研究所流程：

- 场景稳定为实验室、研究设备与紫色异常设施；
- 雷切尔相关实验环境和羽弥相关节点出现；
- 队伍处理设施内的异常与敌对目标；
- 约 `52:30` 返回城市地图，随后进入中央庭交接。

研究所段的神器实验、异常来源和人物分歧仍需用逐句对白补齐，不根据设备外观自行定义实验目的。

# 6. 海湾侧城

约 `54:30–67:00` 的流程从新的地区任务开始，包含：

- 商业／酒吧环境；
- 地下车库与车辆设施；
- 米菈相关接触；
- 阿岚在地下车库相关场景明确出现；
- 多轮异常目标与战斗；
- 后段返回中央庭和城市地图。

这组角色与环境和 Wiki 黑核回收页中的海湾侧城人物链相互支持，因此地区结构可以确认；但角色动机和完整事件结果仍需逐句校订。

# 7. 旧城区

约 `69:40–82:40` 的流程以轨道、仓储、工业设施和艾露比相关行动为主要锚点。约 `82:40` 出现旧城区完成界面，提供了明确的地区终点证据。

当前可确认：

- 艾露比参与旧城区行动；
- 地区包含轨道／仓储设施与多轮战斗；
- 流程完成后返回中央庭和城市管理界面。

不能仅依据装束或战斗画面补写艾露比的计划、队伍损失或具体敌人来源。

# 8. 港湾区

旧城区完成后，约 `83:00` 起进入最后一段地区流程。港湾区段包含：

- 工厂、仓库与通信通道；
- 幽桐在工厂通信相关对白中出现；
- 艾露比继续参与部分行动；
- 濑由衣在后段登场；
- 对白和画面出现利维坦；
- 战斗转入夕阳港口、货船和船舶甲板；
- 约 `98:40` 返回区域地图，随后进入庆祝与城市管理收束。

旧记录曾把末段笼统写成“海湾区／港湾候选”。本次审核按区域完成顺序和明确的旧城区结束界面，将 `约 83:00` 之后整理为港湾区流程；画面中地图的“海湾区”文本仍作为界面命名差异保留，不自动等同于海湾侧城。

# 9. 与 P06、P07 的关系

- P05 包含高校学园、选择东方古街后的独有流程以及后续多地区讨伐。
- P06 是选择中央城区时替换第二次讨伐中段的短分支；其约 `19:50–20:00` 后进入东方古街相关共同后续。
- P07 不延续 P05／P06 的战斗，而是把各地区完成后的黑核回收片段集中保存。
