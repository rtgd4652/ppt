# 1. 地区定位

高校学园是《正轨的箱庭》中第一个完整展开的解放地区，也是 Wiki 唯一保存了完整讨伐正文的地区。剧情以救援两名新觉醒神器使为起点，集中表现黑门对空间、时间与人格的侵蚀，以及指挥使第一次面对“能否把人从活骸化边缘带回来”的分支结果。

# 2. 讨伐剧情

中央庭从幻力纸鹤中取得求救信息，确认珈儿与泰丝拉被困在高校学园。安托涅瓦决定提前实施解放计划，并可引荐爱缪莎为行动占卜。

指挥使与安进入被黑雾覆盖的校园，找到珈儿与泰丝拉，得知西比尔为保护学生而深入黑雾。珈儿拒绝放弃老师，在经历防守战、幻力冲击与中央庭治疗后继续参与救援。队伍循灵猫留下的线索找到已经失控的西比尔，并尝试建立精神联系。

最终结果由是否获得爱缪莎占卜分为两条互斥路线：

- 已获得占卜：塔罗牌为指挥使提供方向，指挥使稳定西比尔，使其恢复人的形态；队伍随后击败黑门守卫“鬼哭”。
- 未获得占卜：精神联系失败，西比尔彻底失去人的状态；珈儿最终亲手阻止老师，西比尔死亡，黑门消散。

两条路线都以高校学园脱离黑雾影响收束，但西比尔的命运不能合并成一项固定历史。

# 3. 黑核回收

地区解放后，晏华提醒指挥使仍需巡查并净化黑核。珈儿把黑门与黑核的关系比作鸡与蛋；玩家回应会令珈儿好感度 `+5` 或 `-5`，但两项最终都会找到、净化并回收高校学园黑核。

P07 确认该模块位于 `00:00–00:44`，人物为珈儿；视频实际点击的好感度回答尚未捕获。

# 4. 关键角色

- 安托涅瓦：解读求救、调配行动、治疗并指导新觉醒神器使。
- 爱缪莎：以有限次数的占卜提供方向，不直接替代指挥使行动。
- 珈儿：坚持救援西比尔，其成长与老师的互斥结局构成本区核心。
- 安、泰丝拉、西比尔：分别承担前线协助、被困新人和危机中心人物的位置。

# 5. 选择与状态边界

- 是否接受爱缪莎引荐。
- 首次占卜、金币不足、既有占卜等状态。
- 一周目／多周目差异对白。
- 是否获得占卜决定西比尔生还或死亡。
- 黑核回收时对珈儿的回答只改变反馈与好感度。
