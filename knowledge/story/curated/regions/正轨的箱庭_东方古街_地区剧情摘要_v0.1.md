# 1. 地区定位

东方古街是第二次讨伐时可由指挥使优先选择的地区。其叙事核心不是单纯清除怪物，而是中央庭如何面对拥有本地历史、秩序与自治诉求的原住民。Wiki 缺失本区完整讨伐对白，当前只能以地区选择正文和 P05 视频结构确认上层流程。

# 2. 讨伐剧情

安托涅瓦说明东方古街的解放准备已经持续一段时间，但当地原住民的立场使计划受到阻碍。若玩家选择东方古街，P05 在约 `17:50–30:00` 显示当地庭院、街道、雯梓、钟函谷、达尔维拉、地区战斗和完成界面。

目前可以确认：

- 指挥使亲自负责东方古街的第二次讨伐路线。
- 雯梓与钟函谷均参与当地流程。
- 达尔维拉进入该段后期行动。
- 地区讨伐完成后，流程返回中央庭并进入公共调查过场。

人物分工、战斗目标和达尔维拉行动因果尚未获得逐句证据，不能在摘要中补写。

若第二次讨伐选择中央城区，P06 约 `20:00` 后仍进入安、钟函谷与东方古街相关的共同后续。这说明“优先选择哪个地区”会改变中段路线，但不代表另一地区从故事中完全消失。

# 3. 黑核回收

黑核回收根据此前首先解放的地区进入两条互斥状态路线：

- 首先解放东方古街：雯梓仍在当地。她要求先讨论东方古街与中央庭的未来，强调原住民、独立和尊重；随后说明五行阵因黑核获得真实力量，但继续依赖黑核属于不可持续的保护。
- 首先解放中央城区：雯梓已经不在，钟函谷承担当地责任。他同样要求先完成关于原住民和地区未来的洽谈，再带领指挥使净化黑核。

P07 `01:00–02:35` 明确播放雯梓路线，不是钟函谷路线。两条路线共享“先洽谈、后处理五行阵与黑核”的结构，但不能拼成连续会面。

# 4. 关键角色与主题

- 雯梓：强调地区历史、原住民立场、独立与尊重。
- 钟函谷：在另一状态路线中承担东方古街保护和洽谈职责。
- 安托涅瓦：把地区选择交给指挥使，并尝试协调另一地区的行动。
- 达尔维拉：在讨伐后段出现，但完整目的仍待逐句校订。

本区可稳定提炼的主题是“文明治理必须处理地方历史与共同安全之间的张力”，而不是把东方古街简单写成拒绝统一的敌对势力。

# 5. 选择与状态边界

- 第二次讨伐选择东方古街或中央城区是一次互斥选择，不是可重复询问菜单。
- 雯梓／钟函谷回收路线由此前地区状态决定，不是回收页面里的自由角色选择。
- P07 只证明实际播放了雯梓路线，不抹除钟函谷路线的原作有效性。

# 6. 尚存缺口

- P05 东方古街独有段的逐句对白。
- 达尔维拉、雯梓与钟函谷在讨伐中的具体行动因果。
- P05 与 P06 进入东方古街共同后续的精确对白汇合点。
