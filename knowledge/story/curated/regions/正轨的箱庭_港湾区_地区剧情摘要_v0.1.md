# 1. 地区定位

港湾区是七区讨伐流程的后段地区，以工厂、仓库、通信设施、货船和近海战斗形成环境特征。Wiki 缺失完整讨伐对白；P05 提供结构证据，Wiki 与 P07 则确认以深海潜艇进入利维坦巢穴的黑核回收路线。

# 2. 讨伐剧情

P05 约 `83:00–98:40` 显示工厂、仓库和通信环境，幽桐、艾露比、濑由衣、利维坦相关画面，以及日落港口或货船附近的战斗，最后返回地图。

现阶段只能确认这些人物和对象在港湾区模块中出现，不能确定幽桐、艾露比和濑由衣各自承担的任务，也不能把利维坦、货船战斗和地区解放之间的完整因果写成事实。画面中出现“海湾区”字样的界面命名差异继续保留。

# 3. 黑核回收

黑核位于深海利维坦巢穴。指挥使巡查研究所后，雷切尔提供三份残余工程图：深海潜艇、电气拘束装置和急速风箱。只有建设深海潜艇才能继续本区回收。

濑由衣坚持同行。两人乘潜艇进入深海并完成黑核净化，没有遭遇预想中的巨大怪物。P07 `10:15–10:49` 确认雷切尔与深海潜艇建设，`10:50–11:24` 确认同行人物为濑由衣。

# 4. 关键角色与主题

- 雷切尔：提供三种工程方案及进入深海所需的技术路径。
- 濑由衣：主动要求同行并参与深海回收。
- 幽桐、艾露比：在讨伐视频中出现，具体职责仍待对白校订。
- 利维坦：与港湾区异常和深海巢穴相关，但完整关系仍不能从现有证据扩写。

本区主题是“以工程准备进入人类难以抵达的异常空间”，体现普通技术与神器异常处理之间的协作。

# 5. 选择与状态边界

- 三份工程图是候选方案，但推进回收所需的是深海潜艇。
- 潜艇建设属于前置条件，不应误写成三个方案都被实际制造。
- P07 确认濑由衣同行；其他讨伐人物不因此自动进入回收事件。

# 6. 尚存缺口

- P05 港湾区讨伐的逐句对白。
- 幽桐、艾露比、濑由衣、利维坦和货船战斗之间的完整因果。
- “港湾区／海湾区”界面命名差异的版本来源。
