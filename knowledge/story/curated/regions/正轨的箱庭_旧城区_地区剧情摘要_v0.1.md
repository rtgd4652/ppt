# 1. 地区定位

旧城区以轨道、仓储、工业设施和长期积累的混乱空间为主要环境特征。Wiki 缺失完整讨伐对白；P05 确认艾露比参与当地流程，P07 与 Wiki 则完整保留了两种黑核回收方案。

# 2. 讨伐剧情

P05 约 `69:40–82:40` 显示轨道、仓库和工业环境，艾露比、多段战斗以及旧城区完成界面。

目前可以确认该段是旧城区独立讨伐模块，艾露比在其中出现；但敌对目标的来源、艾露比的具体委托和各场战斗之间的因果尚未逐句校订，不能通过画面补写。

# 3. 黑核回收

黑核位于混乱的图书馆中。艾露比提出以十万金币帮助清理，由此形成两条互斥方案：

- 支付十万金币：艾露比立即完成清理，指挥使当场净化并回收黑核。
- 拒绝支付：指挥使向晏华求助，等待至次日由中央庭完成清理，再进入回收。

P07 `08:50–10:04` 只出现艾露比并直接完成清理，且没有进入晏华延时段，因此实际播放的是十万金币即时方案。另一方案仍是有效原作分支，不能删除。

# 4. 关键角色与主题

- 艾露比：以明确报酬提供快速解决方案，表现其交易式行动逻辑。
- 晏华：在拒绝付款路线中提供制度化但需要等待的中央庭方案。

本区回收剧情形成“付出资源换取即时效率”与“依靠公共组织等待处理”之间的对照。

# 5. 选择与状态边界

- 支付与拒绝是一次互斥选择。
- 晏华只属于拒绝支付后的延时路线，不能与艾露比即时方案写成同一过程。
- P07 证明的是一次实际播放路线，不代表另一分支无效。

# 6. 尚存缺口

- P05 旧城区讨伐的逐句对白。
- 艾露比在讨伐阶段的任务目的与敌对目标来源。
