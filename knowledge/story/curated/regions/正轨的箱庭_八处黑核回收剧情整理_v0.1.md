# 1. 证据边界

本档案按 Wiki 原始正文整理八处黑核的取得、前置条件和选择树。P07 视频不再承担缺失台词的补写，只用于核对实际播放顺序、人物造型、场景和时间码。

- 页面明确写出的选择、状态条件和回收结果可以进入本档案。
- 页面没有说明的动机、路线共通性和后续影响不得补写。
- 东方古街的雯梓／钟函谷内容是互斥状态路线，不是连续发生的两场事件。
- 中央庭黑核为周目初始取得；独立回收页从高校学园开始。

# 3. 高校学园

晏华说明中央庭属于例外，后续区域均需要在解放后额外巡查并净化黑核。珈儿把黑门与黑核的关系比作鸡与蛋：

- 选择“很有趣的比喻……”：顺利找到黑核，珈儿好感度 `+5`。
- 选择“……”：珈儿认为自己说错了话，随后仍找到黑核，好感度 `-5`。

两项最终都回收高校学园黑核，差异仅在对话与好感结果。

# 4. 东方古街

## 4.1 首先解放东方古街

雯梓仍在东方古街。她要求指挥使先讨论中央庭与东方古街的未来，强调原住民、独立和尊重。洽谈完成后，她说明五行阵原本只有象征意义，黑核出现后才获得足以抵御黑门的实际力量；继续依赖它是“饮鸩止渴”。随后她带领指挥使净化黑核。

## 4.2 首先解放中央城区

雯梓已经不在，钟函谷承担保护东方古街的责任。他要求先讨论原住民与东方古街的未来，并希望这里能够独立、自由地发展。完成洽谈后，钟函谷带领指挥使净化黑核。

两条路线共享“先洽谈、后回收”的结构，但人物状态和对白不能混写。

# 5. 中央城区

黑核位于丽的实验室。指挥使没有礼物时被丽直接拒绝。赛斯通过一组玩笑式选择树提供关键情报：丽喜欢甜食，尤其是蜂蜜，白夜馆有限量甜品。

取得蜂蜜蛋糕后再次拜访，丽接受蛋糕，并说明黑核对她已经没有用途。她把交出黑核称作对蛋糕的回礼，同时否认这是承认研究失败。随后完成中央城区黑核回收。

# 6. 研究所

羽弥带指挥使前往存放黑核的实验室，但研究所系统损坏，防护门无法开启。页面要求把研究所开发至二级，再次巡查后系统恢复。

进入实验室后，羽弥说明她的父亲曾使用她、达格等人的血以及黑核相关材料进行实验，并提到鬼生。选择树分为：

- 直接评价“真是人渣！”：羽弥反感，离开现场；随后回收黑核，羽弥好感度 `-5`。
- 询问羽弥自己的想法：进入“这是否是爱”的第二层回应，最终由指挥使承诺陪她寻找答案，并准备净化黑核。

本段记录羽弥的主观理解，不把她的说法自动升级为对实验全过程的客观结论。

# 7. 海湾侧城

黑核位于只有阿岚熟悉的幻境深处。流程为：

1. 确认“可爱的女孩子”传闻。
2. 在东方古街找到阿岚，完成“阿岚的心事”。
3. 在海湾侧城建设购物中心。
4. 再次巡查海湾侧城。

阿岚谈到他人把自己当作女孩子、过去由姐姐为他穿女装以及自身的困惑。两组选择分别回应他的穿着与如何看待外界目光。完成心事与购物中心后，阿岚带指挥使进入幻境深处，表示自己不会再被虚幻迷惑，随后净化并回收黑核。

# 8. 旧城区

黑核仍在因战斗而混乱的图书馆中。艾露比提出以十万金币为报酬代为清理：

- 支付十万金币：艾露比与手下立即工作，随后回收黑核。
- 拒绝支付：指挥使前往中央庭向晏华求助；晏华派人清理，但需要等待到下一天，再巡查旧城区才能回收。

两条方式在成本和时间上不同，最终均汇合至旧城区黑核回收。

# 9. 港湾区

黑核位于深海中的利维丽坦巢穴。未建设潜艇时无法抵达。指挥使巡查研究所，雷切尔提供三张残留工程图：

- 深海潜艇；
- 强电流拘束装置；
- 急速风箱。

页面允许查看／取得三项，但回收所需的是深海潜艇。建设完成后，濑由衣坚持同行；一行人抵达巢穴并顺利净化黑核，没有遇到她期待的巨大怪物。

# 10. 对角色资料的补充价值

- 丽：重视研究成果，也会接受符合个人偏好的礼物；交出黑核时仍维护自己的判断与自尊。
- 赛斯：以玩笑缓和交流，但能够提供有效的人际情报。
- 羽弥：对父亲、需要与爱的理解受到实验经历深刻影响。
- 阿岚：其服装选择、自我认同和幻境经历不能被简单等同。
- 艾露比：以金钱和交易处理事务，但确实能够快速组织人手完成工作。
- 雷切尔：专注研究与资料恢复，对工程图的具体用途兴趣较低。
- 濑由衣：面对未知环境表现出强烈的好奇与战斗兴趣。
