# 使用边界

本文只整理灰机 Wiki 已公开的高校学园与东方古街黑核回收文本，并严格保留页面中的状态分支和嵌套选择。P07 视频只用于补充演出、画面和时间码，不覆盖本文正文。

- 高校学园与东方古街是两个独立回收模块。
- 东方古街的交涉者取决于第二次讨伐首先解放的地区。
- 同一组选择拥有相同回答时，仍保留它们是不同玩家选项的事实。
- 页面没有证明这些选择可以返回或反复询问，因此不标记为可重复菜单。

# 1. 高校学园黑核回收

## 1.1 私信前置

高校学园解放并救出珈儿和泰丝拉后，晏华提醒指挥使：该地区的黑核尚未净化，仍是潜在危险，必须额外巡查高校学园寻找并净化黑核。

私信提供两个回应：

```text
晏华要求巡查高校学园、净化黑核
├─ “净化黑核还需要额外的巡查？”
└─ “明白！”
    ↓
共同回答：中央庭属于意外；后续地区均需在解放后额外巡查、寻找并净化黑核
```

两个选项汇合到同一回答，但不能因此删除其中一个选项。

## 1.2 巡查与角色对话

巡查任务名为“黑门残余”。剧情明确说明：

- 黑门影响已经清除，但仍需找到黑核并净化。
- 珈儿因黑核引发学园灾祸而对其产生兴趣。
- 指挥使转述雷切尔的说明：黑核是黑门产生的源泉；若不净化，黑门可能再次诞生。
- 珈儿以“鸡和蛋”作比喻。

随后出现一次性回应：

```text
珈儿提出“鸡和蛋”的比喻
├─ “很有趣的比喻……”
│  ├─ 珈儿肯定自己的判断
│  ├─ 发现黑核并净化
│  └─ 珈儿好感度 +5
└─ “……”
   ├─ 珈儿因指挥使沉默而不安
   ├─ 指挥使转移话题并发现黑核
   ├─ 净化黑核
   └─ 珈儿好感度 -5
```

两条分支都会完成高校学园黑核回收，但角色反馈与好感度结果不同。

# 2. 东方古街黑核回收的上层状态

东方古街回收剧情存在两个互斥状态：

```text
第二次讨伐的首先解放地区
├─ 首先解放东方古街
│  └─ 雯梓仍在，由雯梓负责交涉和引导回收
└─ 首先解放中央城区
   └─ 雯梓已经不在，由钟函谷承担交涉和引导回收
```

这里不是玩家在黑核回收页面重新自由选择雯梓或钟函谷，而是此前地区选择造成的状态分支。

# 3. 雯梓路线：首先解放东方古街

## 3.1 私信与阻断条件

晏华要求尽快净化东方古街黑核，并说明雯梓应当知道黑核位置。直接巡查“五行阵禁锢之物”时，雯梓拒绝立即带路，要求指挥使先到棋馆与她认真交谈。

因此流程为：

```text
巡查“五行阵禁锢之物”
↓
未完成“与雯梓的洽谈”时受到阻断
↓
完成“与雯梓的洽谈”
↓
再次巡查“五行阵禁锢之物”并回收黑核
```

## 3.2 与雯梓的洽谈

雯梓说明，她希望讨论中央庭与东方古街的未来，并确认指挥使对“原住民”的理解。

第一组选项为“传统？”“固执？”“不太知道……”。三者汇合到同一说明：原住民是城市最初的居民；随着城市发展，旧建筑、知识、物品和人逐渐被视为过时之物，但他们认为这些内容不可磨灭、不可遗忘。

第二组选项为“或许我们可以改变大家的想法”与“……”。两者汇合到同一立场：雯梓无意改变所有人的想法，只希望保住土地，获得独立与尊重。指挥使答应在处理东方古街事务时考虑这些要求，雯梓随后同意暂时协助指挥使。

## 3.3 五行阵与黑核

完成洽谈后，雯梓说明：

- 五行阵的根本实际是黑核。
- 黑核出现前，五行阵只有象征意义。
- 黑核出现后，五行阵真正运转，成为足以抵御黑门的强大结界。
- 东方古街因此迟迟不愿破坏它，这是一种“饮鸩止渴”的选择。

指挥使可以回应“嗯，多多少少猜到了”或“真的吗……”，两者汇合到相同的后续说明。雯梓感谢指挥使帮助东方古街走出囚笼、看到真正的希望，并提及这或许也是达尔维拉希望看到的结果。随后完成东方古街黑核回收。

# 4. 钟函谷路线：首先解放中央城区

## 4.1 私信与阻断条件

晏华要求净化东方古街黑核，并说明在当前状态下，恐怕只有钟函谷知道黑核位置。直接巡查“五行阵禁锢之物”时，钟函谷以雯梓不在、自己必须承担保护东方古街的责任为由，要求先与指挥使讨论未来问题。

流程与雯梓路线结构相同，但前置任务改为“与钟函谷的洽谈”。

## 4.2 与钟函谷的洽谈

钟函谷要求指挥使理解东方古街与原住民，否则重建工作必然遇到阻碍。

第一组选项仍为“传统？”“固执？”“不太知道……”，并汇合到相同说明。钟函谷强调：雯梓希望保护旧有事物却不被理解，因此他们以强势、固执的外在阻挡不怀好意者。

第二组选项为“或许我们可以改变大家的想法”与“……”，并汇合到同一请求：在失去雯梓后，他们已很难继续要求什么；钟函谷希望指挥使承诺，让东方古街独立且自由地发展。

指挥使答应后询问钟函谷是否也是神器使。钟函谷没有立即加入，而是表示指挥使目前还不足以驾驭自己，待缘分到来时自然会来到指挥使身边。

## 4.3 完成回收

完成洽谈后，钟函谷认为黑核继续存在可能重新引发黑门，因此带领指挥使前往净化并完成东方古街黑核回收。该路线原文没有重复雯梓路线中关于五行阵历史机制的完整解释。

# 5. 可确认的角色与世界背景事实

- 黑门消散后，黑核仍可能再次产生黑门，因此地区解放不等于黑核回收完成。
- 中央庭要求指挥使在地区解放后额外巡查并净化黑核。
- 东方古街原住民重视历史建筑、知识、物品、土地、独立与尊重。
- 五行阵在黑核出现后获得实际力量，但依赖危险黑核维持保护属于不可持续状态。
- 雯梓路线与钟函谷路线反映此前地区选择造成的不同人物状态，不可合并成同一时间线中的连续会面。
