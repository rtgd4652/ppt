# 1. 地区定位

研究所承接人类对神器、幻力与异常现象的研究，也是科研伦理和个体经历交汇最明显的地区之一。Wiki 没有保存本区完整讨伐对白；现阶段只能用 P05 确认研究设施中的行动结构，用 Wiki 回收正文确认羽弥相关剧情。

# 2. 讨伐剧情

P05 约 `36:50–52:30` 显示队伍进入实验室与研究设施环境，经过研究设备、紫色异常区域、雷切尔所在的实验环境、羽弥相关节点、敌对目标和地区完成界面。

现有视频结构可以确认研究所是一段独立的地区讨伐流程，也可以确认雷切尔与羽弥出现在该地区叙事中；但设备用途、实验目的、紫色异常来源和战斗因果没有逐句文本支持，不能从画面自行补写。

# 3. 黑核回收

回收前需要修复并开发研究所，使系统重新启动保护门。羽弥带指挥使进入保存黑核的实验室，并谈到父亲、达格、血液及与黑核有关的研究材料。她对自己的经历和“爱”的含义仍存在困惑。

对话包含两层回应：

- 直接斥责利用羽弥的人，会使羽弥不愿继续交谈并离开。
- 先询问羽弥自身的想法，会进入关于“爱”的第二层讨论；指挥使可以承诺陪她寻找答案。

不同回应改变人物反馈与好感，但都通向黑核净化和回收。P07 `05:15–06:14` 确认人物为羽弥，具体两层回答未全部被关键帧捕获。

# 4. 关键角色与主题

- 雷切尔：作为研究相关人物出现在讨伐设施中，具体实验职责待对白校订。
- 羽弥：以自身经历呈现研究、利用、亲情与自我理解之间的冲突。

本区稳定主题是“科学研究必须面对被研究者的主体性”，而不是把神器研究简单写成善或恶。

# 5. 选择与状态边界

- 修复和开发研究所属于黑核回收前置条件，不是讨伐对白中的自由选择。
- 羽弥对话包含嵌套回应；不同回答不能拼成同一次连续发言。
- P07 只确认人物和模块时间，不足以确定实际采用了哪组回应。

# 6. 尚存缺口

- P05 研究所讨伐的逐句对白。
- 雷切尔实验、紫色异常和敌对目标之间的完整因果。
- P07 实际采用的羽弥两层回答。
