# 无垢的人偶：分支与结局结构 v0.1

> 状态：来源结构人工校订。本文统一《无垢的人偶》的十一张 Wiki 来源页、跨日状态、安的条件支线、中央庭信任闸门及两个正式结局／一个特殊灭世入口。它不替代各页 Raw、Clean 或逐页整理。

## 1. 文档范围与来源边界

本路线由以下十一张来源页构成：

- 六个基础日页：`无垢的人偶/剧情/第七天` 至 `第二天`；
- 两个第一天分支页：`两个人的旅途/剧情/第一天`、`永恒的终焉/剧情/第一天`；
- 两个正式最终日：`两个人的旅途/剧情/最终日`、`永恒的终焉/剧情/最终日`；
- 一个条件失败页：`无垢的人偶/剧情/特殊灭世1`。

本文以 Raw／Clean、`indexes/story_pages` 和 `huiji_story_text_manifest` 为正文与结构依据。P09／P10 视频只可补充画面、配音、战斗顺序或实机条件核验，不覆盖 Wiki 正文。

角色陈述统一保留说话者：

- 希罗关于黑核、神器使幻力和世界融合的说法，不自动成为无条件世界观定论；
- 晏华关于安杀死安托涅瓦、主体是否唯一的判断，不等于完整死亡过程已经呈现；
- 安关于自身人格从程序中自发形成的说明，是她的自我理解；
- 梦中少女、高处观察者和无署名收束声音在身份确认前不合并。

## 2. 页面阅读模型：两组重复收录

Wiki 为便于按结局阅读，存在两组内容重叠，不能按文件顺序机械串联。

### 2.1 两套第一天不是连续两次选择

`永恒的终焉/第一天` 是完整状态入口：

1. 先检查中央庭信任度已满／未满；
2. 已满时出现“请求放过安／强烈抗议”；
3. 未满时直接进入特殊灭世 1。

`两个人的旅途/第一天` 重复收录了“信任已满”后的监禁对话和同一棵“请求／抗议”选择，用于单独阅读旅途方向。实际结构不是先在一个页面选一次、再到另一页面重复选一次。

### 2.2 两个最终日不是连续六次确认

`永恒的终焉/最终日` 是结局状态入口：

1. 先检查是否满足《两个人的旅途》条件；
2. 未满足时无玩家选择，自动留下；
3. 满足时出现三次连续“离开／留下”确认；
4. 任一“留下”进入永恒收束，三次均离开则跳旅途结局。

`两个人的旅途/最终日` 重复收录这三次确认，并在三次均离开后继续展示投影对质、逃亡、中央庭战斗和最终战胜负。

因此真实决策序列是三次确认，不是先在永恒页选三次、再在旅途页再选三次。

## 4. 第七至第五天：路线建立与首个门槛

### 4.1 第七天的重构与残余

系统文字确认神器使死亡记录、残余率、实时数据删除、七天重设和世界重构。指挥使醒来后失忆，却在见到安时无原因落泪。

该页建立轮回残余线索，但没有确认前一轮死者、操作者或记忆保留机制。

### 4.2 第六天的选择不等于正式结局分流

第六天有八棵来源 Tab，混合了：

- 高校学园已／未解放状态；
- 是否隐瞒赛哈姆；
- 活骸价值态度；
- 是否告诉安托涅瓦；
- 是否前往希罗研究所；
- “英雄／兵器”嵌套回应；
- 尘鱼拍照态度；
- 改版前后文本。

其中“去见希罗／不再接触”决定本页是否出现研究所长段，但来源没有把它标为《两个人的旅途》《永恒的终焉》分流。改版前后也不是玩家选择。

### 4.3 第五天的希罗路线门槛

《无垢的人偶》第五天只保留两类继续状态：

- 明确拒绝希罗；
- 尝试跟随，但当前状态下“无法反驳安托涅瓦，不能跟随希罗”。

两个选项都进入中央庭与希罗阵营的共同战斗。成功跟随希罗的内容不在本页，不能把被阻止的尝试写成加入成功，也不能凭本页补出成功条件。

## 5. 安的条件支线链

安的个人线按页面公开数值逐步推进：

| 日页 | 条件／事件 | 直接结果 |
| --- | --- | --- |
| 第七天 | 线索 1—3；线索 3 标注好感 20 | 成人仪式、取得相机、开始记录人生 |
| 第六天 | 好感 50，巡查中央城区 | 为有智慧的尘鱼拍照 |
| 第五天 | 好感 80，巡查东方古街 | 尘鱼袭击，安的机械身体暴露 |
| 第四天 | 好感 100，尽快巡查中央城区 | 安承认自己是人偶，不知创造者与目的 |

这些是条件事件，不是每名玩家必经的主线共通段。页面未公开：

- 好感如何从一个阈值增长到下一阈值；
- 是否必须严格完成全部前置事件；
- “尽快找到安”的具体行动期限；
- 好感 100 是否就是最终日“满足《两个人的旅途》条件”的全部或部分条件。

因此只能确认该链与旅途主题高度相关，不能把完整结局公式写死。

## 6. 第三、第二天：中央庭信任系统

### 6.1 第三天公开增量

| 任务 | 增量 |
| --- | ---: |
| 中央庭地下矿石任务链 | +20 |
| 高校学园开发至等级 4 | +20 |
| 小计 | +40 |

### 6.2 第二天公开增量

| 任务 | 增量 |
| --- | ---: |
| 东方古街外来种族登记链 | +20 |
| 中央城区购物中心 | +20 |
| 研究所歌舞伎町 | +20 |
| 小计 | +60 |

两日公开增量相加为 100。第一天确实检查“中央庭信任度已满／未满”，但来源没有公开初始值、满值阈值、遗漏任务或额外加减项。因此结构上记录“公开任务总计 100”，不直接宣称隐藏公式必为从 0 累积到 100。

### 6.3 信任度与晏华个人判断不同

即使信任度已满，晏华仍因安托涅瓦终端残余镜头对安的主体连续性与控制风险保持怀疑，并监禁指挥使。数值资格只决定是否进入正式最终日选择，不代表组织内所有人已经完全相信安。

## 7. 第一天：正式结局资格闸门

### 7.1 信任度未满

`永恒的终焉/第一天` 直接进入“终结”，来源索引链接到特殊灭世 1。指挥使没有获得正式结局选择资格。

### 7.2 信任度已满

出现一次性选择：

| 选项 | 页面可确认的结果 |
| --- | --- |
| 请求放过安 | 指挥使接受监禁换取晏华放过安；《两个人的旅途》第一天把它作为旅途方向 |
| 强烈抗议 | 晏华只作有限承诺，指挥使继续监禁；旅途第一天明确标注转《永恒的终焉》 |

“请求放过安”是可见的旅途相关选择，但最终日另有“是否满足《两个人的旅途》条件”状态树。来源没有明说该条件是否只由请求决定，还是还包括安好感支线等前置，因此完整公式继续留待实机。

## 8. 最终日三次确认

满足旅途条件后，玩家需要在三轮压力下连续决定：

1. 安第一次邀请离开；
2. 安托涅瓦投影以神器使供能与救世责任劝阻；
3. 投影再以安托涅瓦之死、安的人工智能身份和可能背叛施压。

每一轮都可选择留下；任一“留在中央庭”立即进入永恒收束。只有三次都选择离开，才进入旅途逃亡。

三轮选项不可重复、不能在同一周目并行查看。第三轮在《永恒的终焉》来源索引中顺序反转为“留下／离开”，但逻辑不变。

## 9. 三类结局

### 9.1 特殊灭世 1：信任不足

触发：第一天中央庭信任度未满。

指挥使无论否认或怀疑残余镜头，都被关在地下供能。最终日中央庭成为废墟，指挥使逃出并在另一囚禁室发现安的尸体。

页面直接确认安死亡，但没有给出死因、死亡时间、看守者或晏华等人的下落。高处未知幼小身影和结尾无署名声音都谈到“下次”，身份不能自行合并。

### 9.2 永恒的终焉：留下与自我消耗

进入方式：

- 未满足旅途条件时自动留下；
- 满足条件但在三次确认中任一次选择留下。

安接受指挥使决定，在门外作为剑与盾抵挡怪物；指挥使留在地下为神器使供能，忍受持续心脏疼痛并沉入黑暗。

页面没有展示中央庭最终获胜，也没有明确安、指挥使或世界的终态。不能把“沉入黑暗”擅自等同已确认死亡。

### 9.3 两个人的旅途：连续三次离开

三次坚持离开后，安与安托涅瓦投影就人格、程序与自主意志对质；安破坏摄像头使投影消失。二人打通地下通路，与晏华、爱缪莎交战，随后面对“神灭鬼生”。

战斗状态：

| 状态 | 收束 |
| --- | --- |
| 胜利 | 星空与世界在周围崩解，两人的实际旅程短暂完成，“缺失的拼图”补上一块，并约定终有一天再见 |
| 失败 | 希罗取得散落黑核，以未知力量拘束二人；巨大黑门释放怪物，已无人阻止 |

胜利页没有明确说明二人死亡、幸存或进入何种重构状态；只能写作完成共同选择与短暂旅途。

## 10. 状态与选择分类规则

本路线统一按以下层级保存：

1. **跨日前置状态**：高校学园是否解放、中央庭信任度、是否满足旅途条件；
2. **条件支线状态**：安好感 20／50／80／100、建设等级、及时巡查；
3. **玩家路线选择**：拒绝／尝试跟随希罗、请求／抗议、离开／留下；
4. **局部态度选择**：活骸价值观、是否拍照、对安身份的回应；
5. **剧情战状态**：旅途最终战胜利／失败；
6. **来源版本**：改版前／改版后，不计入剧情分支；
7. **页面导航**：两个第一天与两个最终日的重复收录，不当作额外游戏选择。

本路线来源没有可重复询问菜单。所有 Tab 索引的 `repeatable` 均为 `false`。

## 11. 共同续段校订规则

Clean 自动排版常把共同文字放在最后一个选项下。本路线已人工抽出的主要共同续段包括：

- 第七天“买／不买”都取得相机；
- 第六天高校状态都进入袭击，多个态度选项都回主线，“英雄／兵器”后共享希罗长篇说明，拍照同意与否都实际拍照；
- 第五天拒绝／跟随失败后共享中央庭战斗；
- 第三天三种誓言路径都返回中央庭；
- 两套第一天的请求／抗议都继续监禁；
- 特殊灭世 1 的否认／怀疑都继续拘禁与供能；
- 永恒最终日三个不同深度的“留下”进入同类收束。

“共同结果相同”不等于选项文本可合并；独有回应和证据条件仍逐项保存。

## 12. 角色叙事线索

### 安

- 从模仿人类仪式、使用相机记录人生，逐步公开机械身体与未知制造目的；
- 从执行希罗命令到第一次反抗回收，再到主动营救指挥使；
- 最终把人格理解为从原有程序中自发形成并由经历学习构成；
- 自主意志由她的自述和行动共同表现，但技术机制仍待核。

### 指挥使

- 从重构后失忆、对安无来源落泪，逐步选择在组织信任与保护安之间行动；
- 能否完成公开信任任务决定第一天是否进入特殊灭世；
- 正式最终日的核心选择是继续作为供能来源，还是连续三次与安离开。

### 晏华

- 既提供恢复信任的行动路径，又在安托涅瓦死亡后坚持安全隔离；
- 把数值信任、安的控制风险与指挥使供能价值分开处理；
- 对安主体连续性的质疑仍是风险判断，页面没有证明复制体存在。

### 安托涅瓦

- 第五天因战斗开始活骸化，第四天仍工作，第三天遭安刺杀未遂；
- 第二天其死亡由晏华报告为避免活骸身体被夺而自毁；
- 最终日出现的形象依赖摄像头／投影设施，不能当作本人复活。

### 希罗

- 以神器使生存和世界融合公开招揽指挥使；
- 对安具有命令与回收权，但是否为制造者仍未由安确认；
- 旅途失败时取得黑核并使世界轨迹无法改变。
