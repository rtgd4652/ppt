# 使用边界

本页按 Wiki 的“攻略成功第一个至第五个神器使后”结构整理愿望链。攻略人数是页面显示的进度门槛；具体好感、建设和地区开放条件仍以游戏实际规则为准。

# 1. 第一阶段：端木教授与图书馆

页面把本阶段标记为“攻略成功第一个神器使后”。未知人影通过战术终端送来端木教授的求助信，并确认指挥使已经结识第一名朋友。男女表现版本的语气不同，但都要求指挥使与神器使一起帮助端木教授。

高校学园旧图书馆在黑门灾害中严重损坏。菲尼克为指挥使带路并介绍端木教授与濯樱祭；乌鹭承诺协助公共图书馆工程；新馆完成后，西比尔用驾驭纸张的能力修复严重损坏的书籍。三人的作用不同，不合并写成共同参与同一施工步骤。

濯樱祭是当地延续千年以上、已经停办二十年的传统祭典。参与者结伴赏樱，把洗净的落花埋回树下，以“落花归土”表达归来与团圆。该含义来自菲尼克的民俗介绍，不等于祭典能够让死者复生。

端木教授在妻子去世后因触景伤情，以开会为由拒绝陪女儿参加当时最后一次濯樱祭，并以“明年”不断延期承诺。祭典停办后，他仍年复一年重复同一承诺；后来他攒够举办祭典的钱，女儿却在中央城区黑门袭击中遇难。他希望恢复祭典，不是页面确认其相信能够让妻女真正复生，而是希望完成无法兑现的家庭约定，使自己不再永远停留在悔恨中。

战术终端在端木教授讲述时产生白光，指挥使看见其过往记忆；端木教授、西比尔等人没有表现出同时看见。随后未知人影把现象解释为战术终端的“记忆集成系统”或隐藏技能，可通过记忆频率同调实现传送、共享。现象本身由叙事直接呈现，但系统原理只来自未知人影说明，当前不能提升为已被中央庭验证的成熟技术。

“答应”与“拒绝”是表面选择：拒绝时未知人影提醒指挥使帮助居民实现愿望，指挥使最终仍答应，因此两项汇入共同任务。该选择改变即时心理和端木教授的回应措辞，不形成两条结局路线。

# 2. 第二阶段：春原的梦与失落记忆

页面把本阶段标记为“攻略成功第二个神器使后”。端木教授因濯樱祭已经停办二十年、旧资料又受黑门灾害破坏，请指挥使前往其发源地东方古街补充记录；与此同时，临近婚期的春原因反复梦见樱花林与一名女孩而秘密求助。春原爱自己的未婚妻，但希望在婚礼前确认梦境真相，不能把这段调查写成他准备放弃婚约或追寻旧恋。

钟函谷判断梦境可能来自被遗忘的记忆，并建议利用旧物唤回线索。春原童年受到家庭严格管束，只有每年濯樱祭时能够自由外出。他们进入受黑门事件影响而封锁的春原旧宅，在照片和钟函谷所给指南针的帮助下找到藏在暗格里的故事笔记。战术终端随即发生记忆同调，呈现春原幼年与女孩杏在濯樱祭相识、相约每年重逢并讲故事的经历；祭典停办后，杏不再出现，春原也逐渐遗忘了这段记忆。

春原坚持寻找杏。“你真的想要找到她吗／过去了这么多年，真的还能找得到吗”只改变春原当下回答：前者强调必须找到，后者承认困难但仍要寻找答案；两项随后汇入同一调查。伽梨耶带众人找到杏的家，杏的母亲说明杏自幼患有原因未明的嗜睡怪病，清醒时间越来越短，如今已多年没有醒来。杏曾把春原在祭典讲过的故事记录下来，也曾用各种方法保持清醒，只为赴约。

春原在病床边继续讲故事。杏出现细微反应，记忆同调中也表达自己会在永远盛开的梦中等待，但现实中的杏最终仍未醒来；页面明确写出“奇迹没有发生”。春原随后将开始与未婚妻的婚姻和新旅程，同时帮助端木教授取得东方古街的濯樱祭旧资料。未知人影提出祭典顺利举办后杏“说不定”会醒来，只能保留为角色希望，不能提升为确定后续事实。

# 3. 第三阶段：小布与洛可

页面把本阶段标记为“攻略成功第三个神器使后”。十一岁的小布秘密求助，希望把宠物犬洛可从怪物外形恢复原状。洛可原本每天在公园等待小布放学；公园因黑门事件封锁后失踪，后来以怪物形态回到小布身边。故事没有确认怪物洛可是由黑门直接转化而来，也一度保留“它是否真是原来的洛可”的疑问，因此不能擅自补写其变化机制。

妮维与刻耳柏洛斯发现洛可后，洛可逃回尚未清除黑门的封锁公园，小布随即追入。赛斯留在外部维持秩序，指挥使与妮维进入救援；洛可引导他们避开怪物、找到被围困的小布，并在撤离时独自留下阻挡追兵。洛可重伤返回后，身体化为黑雾，战术终端发生记忆同调，呈现它与小布从相遇、相伴到公园外重逢的经历。记忆结束后，洛可恢复小狗原貌，但已经没有呼吸，随后被小布安葬。

小布把愿望理解为洛可终于回到自己身边，并询问能否在濯樱祭再次见到洛可。指挥使回答“一定可以”，在语境中是对失去伙伴的孩子给予安慰；之后指挥使又明确指出这种说法只是没有根据的传说。未知人影的总结把重点放在“能否真正见到并不重要，重要的是思念本身”。因此本阶段确认的是归来、告别与安葬，而不是祭典能够让死者复活或让洛可永久留下。

# 4. 第四阶段：鲸太与小叶的咖喱

页面把本阶段标记为“攻略成功第四个神器使后”。为了给濯樱祭寻找厨师与美食，端木教授和指挥使前往受黑门事件影响而萧条的海湾侧城；剧情明确要求先将海湾侧城发展度提升到 4 级，使交通、环境和客流恢复，之后才继续寻找鲸太所说的“这座城市最好的咖喱”。该 4 级开发要求是页面明示条件，与其他未公开的好感或日期条件不同，可以直接记录。

鲸太否定多家知名餐厅的料理，却从流动餐车的味道辨认出小叶与其父亲的传承。小叶的父亲三年前去世；小叶虽然继承咖喱店并获得顾客称赞，却因始终无法达到父亲的味道而逐渐放弃“做出最美味咖喱”的梦想。鲸太拿出一瓶墨绿色粉末，声称那是小叶父亲提过、自己走遍许多国家才找到的秘诀香料；结尾小叶明确说明它其实只是葱末。因此这不是具有特殊力量的稀有材料，而是鲸太促使小叶重新尝试的契机。

鲸太向指挥使透露自己身患重病、所剩时间不多，拒绝在医院度过最后时光，决定继续随船出海。他想在离开前再吃一次二十多年前记忆中的咖喱。小叶重新料理后，鲸太安静地一盘接一盘吃下，战术终端发生记忆同调：童年时的鲸太是遭受欺凌、靠偷食维生的孤儿，一名咖喱店主给他食物并肯定其环游世界的梦想。鲸太后来成为水手、走遍世界；这顿咖喱承载的是店主当年的善意和鼓励，而不仅是可复制的配方。

鲸太乘船离开，文本没有继续展示他的病情或确认其死亡。小叶由此重新找回作为厨师的初心，并答应参加濯樱祭。未知人影的男女表现版本都肯定小叶的咖喱会受欢迎，女性版本多一句想品尝的感叹；这属于表现差异，不构成不同结局。

# 5. 第五阶段：巴里、萝拉与樱花林

页面把本阶段标记为“攻略成功第五个神器使后”。濯樱祭准备基本完成后，端木教授担心停办二十年的祭典已被年轻人遗忘，也担心持续发生的黑门事件使居民没有心情参加，因此希望恢复旧城区樱花公园这一标志性场地。园丁巴里同时来信求助：他照料三十多年的樱花林突然大片枯萎，而他和妻子萝拉将在当年退休后离开城市，希望离开前使樱花重新开放。

萝拉已经失明，巴里不愿让期待最后一次花期的妻子伤心，谎称当年樱花开得比往年更好。“很漂亮／哪里有樱花”两个回答都接入同一文本，没有形成不同反应或后续路线。巴里最初不知道枯萎原因；在旧城区建造黑门监测站后，才确认废弃地下铁深处存在强烈黑门反应，中心正位于樱花林下方。由于位置很深，该黑门此前未被发现，也没有对居民安全造成直接影响，却是樱花枯萎的明确原因。

艾露比凭借对旧城区地下环境的熟悉带领清理隧道怪物和黑门。清除完成后黑雾散去，枯树在居民面前重新恢复生机并开花，这是现实中直接发生的结果，不只是记忆幻象。随后战术终端发生记忆同调：巴里与萝拉在濯樱祭相识；祭典停办后巴里仍照料荒废的花林；火灾曾将花林烧尽，萝拉用积蓄购买树苗，与病后的巴里共同重种。二人后来没有孩子，把樱花林视作共同守护的孩子；萝拉逐年失去视力，却始终陪伴巴里。

记忆还确认萝拉早已知道巴里在隐瞒当年樱花不会开放，也能感到樱花林逐渐衰弱。现实中的樱花恢复后，她通过花瓣、气味和共同记忆说自己“看到了”樱花；文本以“思念化为风景、回忆里的樱花在心里绽放”描述这一体验，不能据此断言她恢复视觉。樱花复苏及公园的集体记忆吸引更多居民关注濯樱祭，使五阶段筹备完成。未知人影男女表现版本内容相同，不构成分支。

# 6. 五段共同结构

```text
收到居民求助
→ 与神器使共同调查和行动
→ 发现愿望背后的未完成记忆
→ 战术终端发生记忆同调
→ 帮助当事人完成约定或重新理解愿望
→ 为濯樱祭增加资料、参与者、食物或场地
```

五段故事的共同点不是“所有失去都被逆转”，而是让角色在末日前重新面对记忆，把未完成的约定转化为能够被他人共同承载的行动。
