# 使用边界

本文只根据已经保存的 Wiki Raw、Clean 与来源索引整理《飘零的自由者》的路线骨架。用户已人工确认：本路线由指挥使在开局拒绝加入中央庭进入；《两个人的城市》的字母章节只是可共同度过最后一天的神器使名单索引，不是连续剧情。Clean 页面保存 21 个字母索引标题；连同“最终日”总标题可计为 22 个同级标题。

- Raw 与 Clean 保留网页完整内容，不因项目当前角色名单而删减原作资料。
- 本文只在《两个人的城市》摘要中筛选项目 1.0 已锁定神器使。
- 安和安托涅瓦属于没有个人支线的特殊角色，不纳入该结局的当前可选摘要。
- “白夜馆中的那一位”是原作结局对白中的信息，不得自动等同于本 Mod 的白夜馆功能入口，也不得在来源未确认时补写身份。
- 三个最终日的精确数值门槛与优先级尚未由 Wiki 页面完整公开，不能凭结局内容反推隐藏公式。

# 1. 路线入口

```text
第七天：安托涅瓦邀请指挥使加入中央庭
├─ 立即加入中央庭
│  └─ 进线失败，回到《正轨的箱庭》
└─ 表示需要考虑
   ├─ 最终加入中央庭
   │  └─ 进线失败，回到《正轨的箱庭》
   └─ 坚持“我还是当个自由人吧”
      └─ 正式进入《飘零的自由者》
```

安托涅瓦接受指挥使的决定，仍保留指挥、信息处理、巡查和战斗权限，并要求指挥使住进中央庭空宿舍。她没有因为遭到拒绝而撤销保护或强迫加入。

# 2. 第七天的神秘引导者

指挥使收到空白信息，经战术终端进入保存城市记忆的白色空间。页面根据第七天状态显示“他”或“她”两套文本，两套结构与任务相同，只在称谓和语气上存在差异：

1. 神秘人自称同样困在“时空迷城”中的迷途者。
2. 神秘人声称此处保存城市的所有记忆，并以帮助指挥使找回记忆为交换。
3. 神秘人的愿望是：让指挥使结识神器使、与他们成为伙伴，并共同帮助城市居民实现愿望。
4. 雷切尔随后开放测试中的区域传送，让未加入中央庭的指挥使仍能清除黑门并在城市中行动。

“他／她”不是两个同时存在的人，也不是两条连续会面。它们是同一结构在不同第七天状态下的互斥文本。

# 5. 三个最终日

## 5.1 终结

指挥使独自面对城市毁灭，以“反正一切还会重新开始”的消极态度迎来孤独结局。页面没有选择树，只明确新轮回再次开始。

## 5.2 两个人的城市

指挥使选择与本周目已经攻略的一名神器使共度最后一天。Wiki 以首字母列出全游戏候选名单；这些标题是索引，不是连续剧情章节。

当前项目 1.0 名单中，可从原页名单确认的候选为：

- 爱缪莎
- 晏华
- 赛斯
- 幽桐
- 拉比
- 格蕾莎
- 雯梓
- 丽

安与安托涅瓦没有个人支线，按项目人工确认不读取为本结局当前候选。页面也没有为每名候选保存独立对白，因此摘要只能确认“与所选神器使共度末日”，不能编写八套不存在的结局剧情。

## 5.3 记忆的种子

濯樱祭恢复，五段愿望链中的人物在祭典中重新面对各自的记忆。神秘引导者最终说明自己是另一个世界中同样拒绝加入中央庭、独自寻找真相并孤独迎来终结的“指挥使”。该记忆碎片希望其他世界的自己不要重走同一路径，并称自己在满足苛刻条件后，请求白夜馆中的“那一位”保留了极少量记忆信息。

引导者询问要保存哪段记忆，正文以“答案显而易见”直接进入共同续段，并未展示多个可选回答。与伙伴共同经历的记忆凝结为“记忆的种子”，在新轮回开始、当前记忆被遗忘后仍于某个遥远地方保存并成长。

# 6. 当前最稳妥的结局关系

```text
拒绝加入中央庭
└─ 自由探索城市
   └─ 第一天进入三个互斥最终日之一（完整判定公式未公开）
      ├─ 《终结》：独自迎来毁灭与新轮回
      ├─ 《两个人的城市》：与本周目已攻略的一名神器使共度最后一天
      └─ 《记忆的种子》：完成濯樱祭后，让伙伴记忆凝结为跨轮回保存的种子
```

上图只表示三个结局的叙事内容及互斥关系，不表示完整实机判定公式。《两个人的城市》明确从本周目已攻略神器使中选择一人；《记忆的种子》与五阶段愿望链和濯樱祭相连。攻略次数、好感、建设、区域开放及三个结局的入口优先级仍须实机或攻略条件补证，不能从结局主题反推出《终结》的隐藏条件。

# 7. 角色与世界观材料

## 安托涅瓦

- 尊重指挥使暂不加入中央庭的决定，同时保留其权限和居住保障。
- 第五天仍在承担中央庭例会与城市事务，并表示万不得已时会采取强制措施。
- 页面没有把她写成单纯行政人员；这里只是路线选择使指挥使没有加入她的行动体系。

## 指挥使

- 拒绝加入不是拒绝帮助城市，而是希望先找回记忆并保留自主选择。
- 路线通过结识伙伴和完成普通人的愿望，对照“独自寻找真相”的旧世界自己。
- 结局区别不只在是否阻止末日，也在毁灭来临前是否建立真实联系并留下记忆。

## 神秘引导者

- 最终自称另一个世界的指挥使所留下的记忆碎片。
- 性别文本取决于第七天状态，不应拆成两个实体。
- 关于“白夜馆中的那一位”、记忆保存场所和跨轮回机制仍属于开放谜团。
