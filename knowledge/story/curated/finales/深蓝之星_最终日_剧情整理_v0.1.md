# 使用边界

本文只对《深蓝之星／最终日》已采集的 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 页面索引登记两棵不可重复的树：顶层“战胜活骸零／未战胜活骸零”是战斗状态；仅胜利状态下出现“拯救世界／拯救安托涅瓦”的玩家选择。
- 两棵树均为 `repeatable: false`、`has_shared_continuation: false`。三个结果互斥，不能拼成同一次最终日。
- 页面开场由指挥使直接说明希罗已被阻止、黑核已经集齐；这是本最终日相对《黑暗中的身影》的关键前置差异。
- 梦中少女和最终选择前的“？？？”声音在 clean 正文中均未实名。raw 的对话图标只能作为身份核验线索，不能替代正文证据。
- 叙事称该声音为“神明的声音”，安托涅瓦也称其“神明大人”；这能证明角色和叙述当时如此称呼，不能单凭本页完成其真实身份、权限范围或本体性质的定义。
- 页面标题为《深蓝之星》，但正文没有在“拯救世界”分支内再次显示结局名；把标题精确绑定到该选项需结合导航或实机结算画面确认。

# 1. 倒计时消失与最终日前置

指挥使再次梦见白色房间中的少女。少女不再哭泣，而是反复质问指挥使为何不来救自己。指挥使回答已经找到更重要的东西，醒来后拿战术终端砸向梦中少女所在位置；现实墙上的倒计时随即消失。

安托涅瓦根据希罗此前留下的话判断，倒计时可能是某个人刻意让指挥使看到的提醒，并询问其是否知道对方身份。指挥使承认不知道，只说少女连续出现在梦中。

指挥使随后明确列出本页前置状态：

- 希罗已经被阻止；
- 黑核已经集齐；
- 倒计时已经消失；
- 只要击败眼前怪物、阻止巨大黑门开启，或许可以拯救世界。

这些是指挥使在最终日开始时掌握的状态。倒计时因砸终端而消失的先后关系是直接事件，但页面没有证明物理撞击就是系统机制上的唯一原因，也没有证明倒计时对应的终末已被取消。

# 2. 以全部净化黑核定位最终黑核

安托涅瓦依据雷切尔的理论，认为巨大黑门仍可像普通黑门一样通过拔除核心来断绝根源。由于无法定位其内部全貌，她需要全部已净化黑核提供能量。

她把自己作为能量通路，将净化黑核中的力量汇向巨大黑门，准备显现最后的黑核，并请指挥使提供力量。

这里需区分：

- 安托涅瓦确实执行了以自身为通路的操作；
- “巨大黑门仍只是黑门”是她引用雷切尔理论后的行动判断；
- 已净化黑核被她描述为不再混乱、而是平和温暖的力量；
- 页面没有给出能量换算、通路安全阈值或可替代方法。

# 3. 活骸零出现

清场后，零出现并称自己遵循希罗的愿望：

- 希罗希望零在自己死后完成最后愿望；
- 因此零会阻止安托涅瓦破坏巨大黑门；
- 零要求交出黑核，并准备杀死安托涅瓦与指挥使。

安托涅瓦据此判断，零为了希罗成为活骸，希罗保存其身体并在最后时刻让她完成计划。零则坚持希罗是好人、新世界确实存在，自己的行动是在实现其愿望。

“希罗保存零的身体”是安托涅瓦在对话中的推断，零没有逐项确认保存过程。零亲口确认的是自己因希罗愿望而出现并执行阻止任务。

# 4. 选择树总览

```text
最终战：活骸零
├─ 战胜活骸零
│  └─ 最终黑核显现，未知声音提出二选一
│     ├─ 拯救世界
│     └─ 拯救安托涅瓦
└─ 未战胜活骸零
   └─ 进入伪装成重建未来的梦境，随后识破并崩塌
```

战斗胜负是状态条件，不是玩家可在对话中任意选择的态度。胜利后的两项才是玩家选择；两层均不可重复。

# 5. 战胜活骸零

零倒下后，安托涅瓦也因无力继续支撑方舟而跌坐。净化黑核仍通过她的身体向巨大黑门输送能量，最终显现一颗更大的漆黑核心。

未知声音此时出现，声称：

- 安托涅瓦的身体已经成为通道，能量传送完就会“报废”；
- 净化最终黑核所需生命力必然会让指挥使死亡；
- 若想活下去，应破坏任意一颗黑核，在能量传送结束前停止；
- 黑核可以用于唤醒奇迹，而指挥使必须在拯救世界和拯救安托涅瓦之间选择。

这些是未知声音对代价与选择规则的说明。随后两个分支都按照它提出的框架展开，但本页没有提供独立系统面板、实验数据或其他人物验证“必然死亡”的精确机制。

## 5.1 选择“拯救世界”

安托涅瓦向指挥使道谢。未知声音强烈反对，称即使世界被吞噬，自己也能让指挥使与安托涅瓦共同生活；它无法理解指挥使为何放弃眼前重要的人。

指挥使坚持选择权由对方亲口给予，并说明自己选择世界，是因为安托涅瓦的愿望就是让世界恢复原状。

未知声音最终答应恢复世界，却追问：如果实现安托涅瓦愿望意味着必须消灭她，指挥使是否也会执行。随后“她”的身影消失，新世界开始苏醒。

收束文本呈现：

- 世界恢复原样；
- 所有人获得新的生活；
- 指挥使以牺牲一个人换取世界获救；
- 文本反问这样的世界是否美好、指挥使是否幸福；
- “所有人都得到幸福，只有你无法得到幸福”把牺牲的后果集中到指挥使与被牺牲者。

页面没有明确写出未知声音被击败或死亡，也没有逐一说明列出的“正义的伙伴”等称谓对应谁。后续角色档案不应仅凭称谓列表实名匹配。

## 5.2 选择“拯救安托涅瓦”

未知声音认为该选择毫无新意。安托涅瓦却反驳“不要小看人类”，并用方舟将自己与指挥使隔开。

她感谢指挥使的心意，但拒绝让其停留在毁灭现场，要求其活下去并以后再想办法回来救自己。方舟随后带指挥使离开。

收束文本强调：

- 毁灭已经开始；
- 人类有无穷可能，选择会分裂出更多结果；
- 当前并非最终结局；
- 指挥使应在下一轮继续寻找真相、阻止终结；
- 安托涅瓦希望下一次指挥使仍能记得并呼喊她的名字。

该分支没有展示安托涅瓦在世界毁灭后的确定生死，也没有说明方舟把指挥使送往哪个具体时空。它表达“下一次还能寻找道路”，不等于当前世界已被成功拯救。

# 6. 未战胜活骸零

指挥使突然出现在繁华、重建完成的中央城区。一个外表和说话方式都像安托涅瓦的存在称世界末日早已过去，指挥使治好了自己的双腿，并准备带其参加庆祝会。

指挥使因对方能够步行而识破异常，指出安托涅瓦曾说自己不存在恢复下肢的未来，因此这里不是现实世界。周围景象随即崩塌；该“安托涅瓦”反问一直活在梦中是否不好，随后与幻境一同消失。

本分支可确认：

- 战斗失败后，指挥使经历了一个以理想化安托涅瓦和城市重建为内容的幻境；
- 指挥使主动识破并拒绝梦境；
- 页面没有公开梦境制造者、现实中零与安托涅瓦的最终状态，或幻境崩塌后的下一步。

不能把幻境中的“下肢治愈、世界重建、大家等待”写入现实时间线。

# 7. 本页在路线结构中的作用

1. 全黑核且希罗已被阻止的状态进入本页。
2. 安托涅瓦以自身为通路显现最终黑核，零依希罗遗愿阻止行动。
3. 战胜零后，玩家获得“世界／安托涅瓦”二选一；未战胜则进入并识破梦境。
4. “拯救世界”完成世界恢复；收束文本称“牺牲了一个人”，语境指向安托涅瓦，但没有交代其具体物理状态，并强调指挥使无法得到幸福。
5. “拯救安托涅瓦”没有在当前轮拯救世界，而由安托涅瓦把指挥使送往下一次可能。

# 8. 角色补充（限本页）

## 安托涅瓦

- 主动把身体作为净化黑核的能量通路。
- 面对零仍坚持阻止巨大黑门。
- 接受指挥使选择世界；在另一分支则违背“被拯救后共同留下”的表面结果，优先把指挥使送走。
- 她对“人类可能性”的陈述是路线价值立场，不是具体轮回机制的完整技术说明。

## 指挥使

- 拒绝继续被梦中少女和倒计时支配。
- 在全黑核前提下参与显现最终核心。
- 胜利后能够选择世界或安托涅瓦；失败后仍能识破理想化梦境。

## 零

- 以希罗遗愿为行动理由，阻止黑核净化。
- 对希罗及新世界的信任由其本人表达；页面没有说明是否受到控制、指令或人格切换影响。
- 本页胜利分支只写身体倒下，不能自动推定所有人格和存在形式彻底消灭。

## 梦中少女／未知声音

- 梦中少女指责指挥使没有救她；最终选择前的未知声音了解净化代价并能提出“奇迹”选择。
- 两者在叙事上高度相关，但本页没有用同一实名直接确认二者完全同一。
- 未知声音显示出改变或重构世界、安排两人生活的自述能力；能力上限和陈述真实性仍需其他来源核对。
