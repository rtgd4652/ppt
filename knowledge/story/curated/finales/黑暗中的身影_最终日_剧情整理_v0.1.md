# 使用边界

本文只对《黑暗中的身影／最终日》已采集的 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 来源索引只有一棵不可重复的状态树：“战胜活骸零／未战胜活骸零”。两项为战斗状态，不是玩家态度选择。
- 该树为 `repeatable: false`、`has_shared_continuation: false`。胜利与失败互斥。
- 与《深蓝之星》不同，本页明确说明没有收集到全部 8 颗黑核；战胜零后也没有“拯救世界／拯救安托涅瓦”的第二层选项。
- 安托涅瓦“掏出全部的黑门之核”指拿出当前持有的全部黑核；同段又明确说尚未收齐 8 颗，不能把前一句误读为全城黑核齐备。
- 零在本页自称存在“主人格／里人格”，并由里人格宣称自己才是真正的零、是希罗的资助者和黑门计划构造者。这些重要陈述均为角色自述，页面未提供外部档案验证。
- 最终未知声音在 clean 正文中没有实名。叙事和安托涅瓦称其为神明，但本页不足以独立确定真实身份和能力边界。
- 战斗失败后的重建城市是幻境；不得把其中安托涅瓦能够行走、世界末日结束等内容写入现实时间线。

# 1. 最终日开场：倒计时消失但黑核未集齐

梦中少女再次质问指挥使为何不去救她。指挥使回答自己找到了更重要的东西，醒来后用战术终端砸向墙壁，倒计时消失。

与《深蓝之星》开场不同，指挥使随即看见天空已经完全被巨大黑门遮蔽，并明确承认“黑核没有收集完全”。希罗已经不在；指挥使仍准备在最后时刻与安托涅瓦破坏黑门。

本页直接前置为：

- 希罗不再现场阻挡；
- 安托涅瓦仍能行动并展开方舟；
- 黑核少于完整的 8 颗；
- 巨大黑门已经遮住天空。

倒计时消失没有阻止黑门继续降临，因此不能把倒计时界面消失直接等同于终末危机解除。

# 2. 不完整黑核下的通路操作

安托涅瓦仍采用雷切尔的理论：将巨大黑门视作可通过核心断根的黑门，用现有已净化黑核的能量尝试定位其内部。

她把当前持有的全部黑核取出，以自身为能量通路，同时明确说明：由于没有收集到全部 8 颗黑核，自己暂时没有余力参与战斗。

这一段证明黑核数量会改变最终战条件：

- 全黑核状态下，安托涅瓦至少在零出现前参与清场；
- 本页不完整状态下，她因维持通路而不能参与当前战斗；
- 页面没有说明少了几颗、最低可进入数、或是否每少一颗都产生同等影响。

# 3. 里人格自称“真正的零”

零出现后先以熟悉语气称呼安托涅瓦，并说自己是曾把心脏给她、随后悲惨死去的零。安托涅瓦立即否认，认为眼前存在不是她所认识的零。

随后，零以另一套口吻说明：

- 安托涅瓦也是被其“主人格”欺骗的人；
- 自己是许久未出现的“里人格”，并自称才是真正的零；
- 没有自己，希罗仍会停留在研究毫无进展的粒子撞击；
- 自己是希罗最初的资助者和启蒙者；
- 自己发现并构造了黑门计划；
- 现在要收回“利息”。

本页可以确认同一具活骸零至少表现出互相区分的意识或说话立场，并且里人格提出上述历史主张。不能直接确认：

- “主人格／里人格”是否是医学或系统正式分类；
- 哪一人格在历次零事件中分别承担哪些行动；
- 里人格对希罗与黑门计划历史的自述是否完全准确；
- 它所说“利息”具体指黑核、世界毁灭、身体控制权或其他目标。

# 4. 战斗状态树

```text
不完整黑核状态下迎战活骸零
├─ 战胜活骸零
│  └─ 最终黑核显现，但现有黑核不足以封门
│     → 未知声音只提供中止连接、保全安托涅瓦的“唯一选择”
└─ 未战胜活骸零
   └─ 进入重建城市幻境，指挥使识破后幻境崩塌
```

本页没有第二层玩家选择。不能从《深蓝之星》复制“拯救世界”选项到本页。

# 5. 战胜活骸零

战斗收尾时，零的台词出现明显冲突：

- 一方持续质问为何阻止自己；
- 另一方请求不要伤害安托涅瓦，称自己不想这样做；
- 前者反驳自己正是为了对方，并说因对方拖累，两者都要一起死。

页面把这些台词都标在“零”名下，没有进一步给出每句对应的正式人格标签。可以记录为两个意识立场冲突，不能自行逐句完成主人格／里人格标注。

零倒下后，安托涅瓦也因维持通路而失去支撑方舟的力气。最终黑核显现，未知声音指出：

- 现有黑核数量不足以封住巨大黑门；
- 即使尝试净化最终核心，所需生命力也会让指挥使死亡；
- 若中止连接，至少还可以保住安托涅瓦；
- 它愿意在新世界为两人准备住处，并以“圈养神器使和指挥使”描述结果。

叙事随后写“唯一的选择，也能姑且算是明智的选择”。这说明在本页状态下，玩家没有获得《深蓝之星》中的世界／安托涅瓦二选一。

安托涅瓦仍以“不要小看人类”回应未知声音。未知声音随后以“都已经把黑核毁掉了”为既成事实质问她还能做什么；页面没有展示黑核被毁的具体动作、执行者或时间点，因此只能按未知声音的现场陈述保留。

收束文本强调人类拥有无穷可能，当前不是最终结局，指挥使应在下一次继续寻找真相、阻止终结，并记住安托涅瓦的名字。

需要严格避免跨页补写：

- 本页没有收录《深蓝之星》“拯救安托涅瓦”分支中安托涅瓦扬手隔开双方、明确要求方舟带走指挥使的整段正文；
- 两页片尾文字相似，不代表本页缺失动作可以直接从另一页视为同一次事件补入；
- 本页没有明确交代当前世界、安托涅瓦和指挥使各自的最终物理状态。

# 6. 未战胜活骸零

该分支与《深蓝之星》的战斗失败段文本相同，但仍属于本页独立状态：

- 指挥使突然置身重建完成的中央城区；
- 一个表现为安托涅瓦的存在称末日已经过去，大家正等待庆祝；
- 对方能够行走，并称是指挥使治好了自己；
- 指挥使用安托涅瓦旧伤不可能恢复的既有认知识破幻境；
- 城市与该形象随即崩塌，对方询问永远活在梦里是否不好。

页面没有说明梦境制造者，也没有交代幻境崩塌后现实战场的零、安托涅瓦和指挥使状态。重复文本不能让两个最终日的失败路径在知识结构中丢失各自的黑核前置。

# 7. 与《深蓝之星》的差异矩阵

| 结构项 | 深蓝之星页面 | 黑暗中的身影页面 |
| --- | --- | --- |
| 希罗状态 | 已被阻止 | 已不在现场 |
| 黑核状态 | 已集齐 | 未集齐全部 8 颗 |
| 安托涅瓦能否参与前段行动 | 参与清场及通路 | 明说因黑核不足而无余力参战 |
| 战胜零后 | 出现世界／安托涅瓦二选一 | 没有第二层选择，只剩中止连接方向 |
| 未战胜零 | 重建城市幻境 | 同文本幻境，但继承不完整黑核前置 |

两页的核心差异不是是否遇见零，而是黑核资源是否允许玩家在战胜零后取得拯救世界的选择权。

# 8. 本页在路线结构中的作用

1. 将“未集齐全部 8 颗黑核”落实为最终战资源不足。
2. 展示零的主人格／里人格冲突，以及里人格对黑门计划历史的自述。
3. 战胜零仍无法封闭巨大黑门，玩家没有“拯救世界”选项。
4. 失败则进入并识破美好未来幻境。
5. 两种状态都没有在本页给出当前世界所有角色的完整收束，需要避免擅自补完。

# 9. 角色补充（限本页）

## 安托涅瓦

- 在黑核不足时仍以身体维持定位最终核心的通路。
- 因资源不足无法参与前段战斗，却仍在胜利后反驳未知声音对人类可能性的轻视。
- 她能辨认眼前零并非自己所认识的那一意识状态。

## 指挥使

- 明知黑核不完整仍选择迎战巨大黑门。
- 战胜零后没有取得拯救世界的分支选择权。
- 战败进入幻境时，仍凭对安托涅瓦旧伤的了解识破虚假未来。

## 零的主人格／里人格

- 页面显示双方对是否伤害安托涅瓦存在直接冲突。
- 里人格自称黑门计划发现者、构造者和希罗早期资助者；尚无独立证据。
- 页面没有说明零倒下是否代表两个人格永久消失。

## 未知声音

- 能说明通路、净化生命代价和黑核不足后果，并声称可安排新世界住处。
- “圈养”一词显示其把神器使与指挥使视为可控制对象。
- 身份、是否制造失败幻境、是否与梦中少女同一均待核。
