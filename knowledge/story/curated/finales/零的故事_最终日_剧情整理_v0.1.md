# 使用边界

本文只整理“零的故事／剧情／最终日”的来源正文。页面包含两个互斥的希罗生死前置状态；两者在战斗胜利后共用同一段零的收束文本，但前置敌人和希罗是否在场不同，不能抹平。

- “希罗死亡”对应第一天射杀希罗后的路线。
- “希罗存活”对应第一天任意关键剧情战失败后的路线。
- 两种前置状态均再分为最终战胜利／失败；失败分别进入特殊灭世 2 中对应的零路线段落。
- “少女剖开了自己，将所有的回忆讲述”属于诗性收束，不应直接解释成字面上的自我解剖。

## 选择树结构复核

```text
希罗死亡
├─ 最终战胜利 ─┐
└─ 最终战失败   │
                ├─ 胜利共同收束：零交付最后力量与记忆
希罗存活        │
├─ 最终战胜利 ─┘
└─ 最终战失败
```

失败分支并不共用完全相同的因果：希罗死亡状态下由活骸人格说明其主动推动毁灭；希罗存活状态下则由希罗夺取黑核并完成世界吞没。

# 1. 共同目标：进入巨大黑门

晏华组织中央庭人员前往观光塔，并按雷切尔的分析进入巨大黑门寻找其黑核。净化黑核被视为关闭黑门的行动方案；这是当时中央庭的判断和计划，不应在缺少后续验证时外推为所有异常巨门的普遍规则。

# 2. 希罗死亡状态

希罗已在第一天被射杀。中央庭进入黑门后直接遇到正在寻找更深处目标的活骸零。指挥使尝试唤回零，活骸人格则主动迎战。

该状态没有希罗和四名追随者在最终战场出现。若胜利，进入零的共同收束；若失败，活骸人格说明自己一直利用零残存的可能性驱使希罗推进融合研究，并以整个世界为祭品。

# 3. 希罗存活状态

希罗因第一天战斗结果而存活，并在黑门中带领四名神器使和活骸零拦截中央庭。他否认会因零而放弃计划，并试图夺取最后的黑核。

该状态的最终战规模和敌方构成与“希罗死亡”不同。若胜利，同样进入零的共同收束；若失败，则由希罗取得黑核，巨大黑门与怪物失去阻挡。

# 4. 胜利共同收束：零的最后选择

活骸人格被击败后，零重新取得表达能力。她为造成的麻烦道歉，但明确表示即使重来仍会做出相同选择。零把最后的治疗力量交给指挥使，治愈其伤痛与疲惫，并留下自己的记忆碎片，请求指挥使活下去并记住自己。

诗性结尾把零描述为绘制世界、打开箱子、窥探奥秘并承载灾难的少女。最明确的角色结论是：即使再次经历，她仍会选择打开“箱子”，也仍会选择与指挥使相遇。

# 5. 零与活骸零的主体边界

## 零

- 希望阻止活骸人格和世界毁灭。
- 在身体走向消亡时仍把最后力量用于治疗他人。
- 把“被记住”和“再次相遇”作为最后愿望。

## 活骸零

- 在两个前置状态中都以独立语气行动和战斗。
- 希罗死亡状态的失败文本明确表现其主动把世界当作祭品。
- 其愿望、行动与零的意愿相反，不能笼统合写为“零毁灭世界”。

# 6. 其他角色材料（限本页）

## 晏华

- 组织进入巨大黑门的行动并说明作战目标，承担最终阶段的战略与调度职责。

## 希罗

- 只在“希罗存活”状态出现；继续把零和追随者作为争夺黑核的战力。
- 不能把该状态下的言行写入“希罗死亡”版本。

# 7. 本页可用于后续核对的线索

- 零所说的“箱子”、研究行为和记忆碎片之间的关系。
- 活骸人格是否独立于活骸化普遍机制，或与零的特殊研究经历有关。
- 两个希罗状态为何能进入同一胜利收束，以及它们对后续循环记忆的影响。
