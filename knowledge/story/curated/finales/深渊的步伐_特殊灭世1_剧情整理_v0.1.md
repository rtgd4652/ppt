# 使用边界

本文整理海底研究所在第四天被中央庭占领后触发的特殊失败路线。它跨越第四天至最终日，但不是四个可独立进入的日页，也不是三个正式结局之一。

- “掩护希罗／趁机袭击希罗”是互斥选择。
- 两个选择都会汇合到指挥使被关在中央庭地下、行动受限的结果。
- 晏华对拘禁理由的说明随前置选择不同，不应互相拼接成同一次对话。
- 页面未交代晏华、爱缪莎和希罗离开后究竟发生了什么；不能据“无人回来”断定具体生死。

## 选择树结构复核

```text
研究所被中央庭占领
├─ 掩护希罗 → 中央庭只抓到指挥使 → 地下拘禁
└─ 袭击希罗 → 被希罗击昏后由中央庭找到 → 地下拘禁
   ↓
第 3 天至第 1 天：持续受困
↓
最终日：无人返回，指挥使放弃等待，轮回收束
```

# 1. 第四天：研究所失守

中央庭攻破海底研究所防线，希罗准备携带必要资料撤离。指挥使可以选择留下掩护，也可以趁机袭击希罗。

## 1.1 掩护希罗

希罗把备用潜艇钥匙交给指挥使后离开。指挥使试图阻挡追兵，最终失去意识，并在中央庭地下醒来。晏华质问其为何愿意为希罗牺牲，并表示中央庭会继续追捕希罗。

## 1.2 袭击希罗

希罗发现袭击并击昏指挥使。指挥使同样在中央庭地下醒来，向晏华说明自己原本试图阻止希罗。晏华承认知道这一点，却仍以安全和为神器使持续供能为由限制其行动。

两条分支都表现晏华将指挥使视为战略资源和风险对象，但“是否相信其动机”的对话不同。

# 2. 第三天至第一天：被隔绝的等待

指挥使无法打开地下房间，也没有得到探视。页面逐日缩短信息，只保留持续受困、时间感和外界联系消失。该段不是“什么都没有发生”的模板空白，而是特殊失败线以隔绝感推进的核心。

# 3. 最终日：无人归来

最终日中，指挥使已无法判断经过了多久，只依靠预先准备的食物维持。晏华、爱缪莎和希罗均未回来。指挥使把结局理解为自己没有能力把选择的道路走到底，并请求一切尽快结束。

无署名收束回应“还会继续等待”“很快还会再次见面”，暗示轮回或观察者仍在运行；页面没有说明外界战局、所有人命运或重构的技术过程。

# 4. 角色材料（限本页）

## 晏华

- 在中央庭反攻成功后限制指挥使行动。
- 根据指挥使此前选择给出不同态度，但最终优先考虑安全、供能和追捕希罗。
- 承诺尽快回来，却在页面剩余时间内没有再出现；原因未知。

## 爱缪莎

- 只通过终端催促晏华查看外部情况，此后没有进一步正文。
- “没有回来”不能被直接写成死亡。

## 指挥使

- 无论试图保护还是袭击希罗，都因研究所失守而失去行动权。
- 失败核心并非战场死亡，而是选择、能力与行动机会被彻底切断。
