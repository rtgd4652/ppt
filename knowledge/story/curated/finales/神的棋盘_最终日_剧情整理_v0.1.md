# 使用边界

本文只整理“神的棋盘／剧情／最终日”的已采集正文，不替代 Raw 或 Clean，也不把结局中的角色陈述直接提升为跨路线世界观定论。

- 本结局承接第一天“全黑核、放过希罗”的成功分支；希罗被监禁后失踪，并带走中央庭黑核。
- “想要一起活下去／哪能就这么结束”是态度选择，随后均进入同一场最终战。
- “剧情战胜利／失败”是状态条件，不是玩家主动选择；失败转入特殊灭世 2 的“神的棋盘最终战战败”段落。
- 页面出现“神”“箱庭”“无名神明”等叙事称呼，但未明确解释神秘少女的正式身份、轮回系统或箱庭本质。

## 选择树结构复核

```text
希罗制造巨怪
├─ 想要一起活下去
└─ 哪能就这么结束
   ↓ 共同进入最终战
剧情战胜利 → 神秘少女出现 → 指挥使向其开枪 → 箱庭崩裂
剧情战失败 → 特殊灭世 2／神的棋盘最终战战败
```

两个态度选项的表述不同，但都体现指挥使拒绝接受“只有世界终结”这一答案。不得把其中一项后的共同战斗和结尾误写成该项独占内容。

# 1. 希罗失踪与零的死亡

晏华发现希罗和中央庭黑核同时失踪。指挥使赶往研究所地下后，看到希罗站在零的遗体旁。希罗承认自己杀死了试图获得自由的活骸人格，而零的意识也随之死亡。

希罗回顾自己早年研究异世界时缺乏证明能力，随后在资助者家中发现年幼而聪慧的零，并以“小手段”将她带走。按希罗自己的说法，零帮助建立理论证明，后来又按其安排成为神器使并成为活骸研究样本。

这些内容直接表现希罗长期利用零的能力与信任；但“最爱的只有自己”是本页叙述者对其行为的评价，应与希罗亲口承认的事实分开引用。

# 2. 以黑核和活骸遗体制造巨怪

希罗将黑核塞入活骸遗体，制造出能够吞噬周围存在的巨大怪物。他承认已经错过开启黑门的原定时机，却仍试图寻找毁灭世界的其他方法。

希罗最后一次邀请指挥使共同迎接终末。无论指挥使以“共同活下去”还是“不能就此结束”回应，均拒绝把希罗、世界或自己当成必须放弃的对象。希罗在被怪物吞没前留下“这个世界的神看似强大、实则弱小”的未完成提示。

该提示是希罗的判断与线索，不足以单独证明“神”的本质或弱点。

# 3. 胜利分支：神秘少女与崩裂的箱庭

巨怪被击败后，梦中反复出现的神秘少女坐在巨大黑核上出现，身后巨大黑门继续扩张。她把希罗的经历称作无聊而可悲的故事，并准备让世界进入下一次循环。

指挥使将希罗留下的提示指向眼前少女，举枪射出最后一颗子弹。页面随后以“无名的神明伸手触碰停滞在半空中的子弹”“骤然崩裂的箱庭”收束，并让少女承认人类给出的答案已经接近能够在下一次杀死她。

本页没有确认指挥使已经杀死神秘少女：子弹被停在半空，箱庭发生崩裂，少女仍保有说话与判断。摘要不得把“接近能够杀死”改写成“已经弑神成功”。

# 4. 失败分支

最终战失败时，页面跳转至特殊灭世 2。对应段落只描述指挥使在最后关头败北，巨怪张口吞噬世界；神秘少女、开枪和箱庭崩裂不属于失败线。

# 5. 角色材料（限本页）

## 希罗

- 亲口承认带走并利用年幼的零，将她视为推动异界理论与活骸研究的关键工具。
- 在零死亡后没有停止，而是立刻把其遗体和黑核用于新的毁灭方案。
- 对指挥使仍保留片刻复杂回应，但最终继续选择世界终结。

## 零

- 本页中的零已死亡，无法再以自身视角陈述；关于她早期经历的主要信息来自希罗。
- 希罗的叙述可以证明其利用关系，却不能代替零自己的感受与选择。

## 指挥使

- 拒绝接受“只有一方活下去”或“世界必然终结”的二选一。
- 把希罗留下的线索转化为对轮回控制者的直接反抗。

## 神秘少女

- 与此前梦境中的少女被指挥使识别为同一存在。
- 页面使用“神”“无名的神明”等称呼，但仍未给出可独立核验的正式身份。

# 6. 本页可用于后续核对的线索

- 希罗与零在黑门出现前的研究历史，以及零如何成为神器使和活骸样本。
- 神秘少女、巨大黑核、箱庭与循环重启之间的关系。
- “神看似强大、实则弱小”究竟是希罗的推测、既有研究结论还是轮回经验。
- 箱庭崩裂是否改变后续轮回结构，需由其他路线或后续剧情确认。
