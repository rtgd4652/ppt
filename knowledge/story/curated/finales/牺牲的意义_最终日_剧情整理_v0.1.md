# 使用边界

本文只整理“牺牲的意义／剧情／最终日”的已采集 Wiki 正文。它是第一天页面列出的三个最终日入口之一；三个最终日页面现已完成采集与分支结构核对，但本文仍不把它与“已收集全部黑核”等入口条件做未经验证的逐项绑定。

- “剧情战胜利／剧情战失败”是页面明确保留的状态分支，二者分别记录；不能把胜利分支中的战斗、同伴发言或后续牺牲写入失败分支。
- 已通过本页原始 HTML 复核：页面实际包含四组逐层嵌套的“剧情战胜利／剧情战失败”Tab。每一层的“剧情战胜利”才会进入下一场战斗节点；任一层选择“剧情战失败”都会进入该层对应的失败收束文本。
- 胜利分支包含大量以角色名为标题的临战／活骸化语音。页面没有说明这些角色在同一周目、同一战场必然同时存在；应将其视为按已拥有或已参战角色呈现的条件性文本库，而非固定全员出场名单。
- 四个失败分支均显示同一段希罗收束文本。该文本在 raw 层多次出现不是模板噪声，而是四个独立嵌套战斗节点各自的失败面板；不得将其删除、合并为胜利后的共同剧情，或解释为同一时间线重复发生。
- 页面混合叙事正文与“疲劳值、活骸化、集火击杀”等战斗 UI 提示；二者均保留为来源材料，但不能在未核对玩法语境前把全部 UI 数值与提示机械化为世界观定律。

## 选择树结构复核

本页的状态树为严格的胜利链，而不是单一“胜利／失败”节点：

击败怪物首领、关闭黑门

↓ 剧情战胜利

挑战四方之王

↓ 剧情战胜利

黑门卷入后的未命名剧情战节点

↓ 剧情战胜利

“不停战斗”剧情战节点

任一节点的“剧情战失败”均进入页面所列的希罗失败收束。清洗版 Markdown 与来源索引已保留四层父子关系，不能再把后续三层误当作第一层胜利正文。

# 1. 最终战前：观光塔与巨大黑门

本页以指挥使在多次经历中逐渐把世界视为比自身生命更重要之物为开场。晏华带领其乘直升机抵达观光塔附近；由于黑门引力，飞行器无法升得过高。观光塔顶部已聚集大量异界怪物，黑门仅打开一小道缝隙便不断召来怪物。

指挥使决定设置黑门之核以阻止黑门继续开启，并请求神器使在此期间护卫；爱缪莎负责提醒其选择参战的神器使、将其带入战场，并叮嘱指挥使小心。此处是最终战的共同开场，尚未进入“胜利／失败”分支。

# 2. 剧情战胜利：希罗、活骸与观光塔决战

在“剧情战胜利”分支中，指挥使关闭黑门并击败怪物首领后，希罗现身。他身边有四名全身被紫黑结晶覆盖的神器使；页面随后由奥露西娅、达尔维拉、罗纳克与芙罗拉各自说明其站在希罗一方的理由，包括对永恒、力量、族人存续或旧世界毁灭的期待。

希罗称这些人成为活骸是自愿接受的试验，并以“让指挥使交出黑门之核、在新世界获得永生”作为条件试图动摇其余神器使。该段关于“自愿”“永生”“无限增强”的内容，需保留为希罗及其阵营在战场上的主张，而不是在本页之外直接视为已验证机制。

指挥使拒绝；页面在“挑战四方之王”节点后叙述四名活骸被打倒。与此同时，指挥使身上已净化的黑门之核受到黑雾侵染，剩余时间进一步缩短。珈儿率先站出来，以“守护比生命更重要之物”为理由拒绝希罗的诱导，其余人随之继续战斗。

黑门随后接触观光塔平台并产生巨大吸力，将在场者卷入。指挥使短暂听见身份未明的呼唤后醒来；珈儿表示黑门已被消灭，城市与天空恢复，但仍有怪物残余。这是胜利分支的阶段性结果，不等于所有代价已经消失。

# 3. 胜利后的代价：活骸化与长期结局叙述

黑门被消灭后，珈儿首先出现活骸化迹象，并请求指挥使在自己失去意识、可能伤害重要之人前终结自己。指挥使答应会面对这一请求，并承诺尽力活到最后。

页面随后切入“持续战斗—疲劳值下降—活骸化—集火击杀”的战斗提示与大量角色发言。就当前来源可确认的叙事功能而言，这一段表达的是：在胜利后的持续消耗中，神器使仍陆续走向活骸化，指挥使被迫继续面对同伴的失控与死亡。它不应被简化为“消灭黑门即无代价的圆满胜利”。

在长篇角色语音后，页面给出一个长期后果叙述：神器使陆续成为活骸，人们无法逐一消灭它们而设立围城自保；昔日中央庭成为黑门事件纪念馆，指挥使成为唯一见证过这段历史的人。叙事者将这一未来称为充满牺牲与疑问的结果，而没有给出“这是否正确”的确定答案。

# 4. 奇迹、遗忘与重新启程的线索

胜利分支的长期后果之后，来源出现身份未明的声音，提出若想得到奇迹，就要献上三类代价：与伙伴的羁绊、度过的七天时光、以及对神明的绝对谦卑。该声音称足够代价会带来奇迹，并提到再次启程与再次遗忘。

这段内容与主线中的七日循环、失败与重启主题高度相关，但本页没有完整解释：

- 发声者是谁；
- 三类代价如何实际发生；
- “奇迹”是否已被触发；
- 重新启程与世界重构之间的完整因果。

因此应保存为最终日明确提出的机制性线索，等待第七天、初始失败记录、其余最终日与人工确认材料共同核对，而不单凭本页定义整个循环系统。

# 5. 剧情战失败：四层节点共用的收束文本

本页的四个嵌套战斗节点均各自提供“剧情战失败”面板；这些面板的正文相同：希罗拾起散落的黑门之核，称世界轨迹无法改变，并以力量拘束指挥使前往天空。指挥使看到巨大黑色大门及持续涌出的怪物，页面以“今天到这里”“很快还会见面”收束。

它不包含其所在层级之后的胜利内容：例如四方之王战、珈儿请求、角色活骸化语音或长期纪念馆叙述均不能被写入失败线。同一收束文本的重复来自多层失败面板，不表示所有战斗状态已经完全汇合。

# 6. 角色材料（限本页）

## 爱缪莎

- 在最终战共同开场中协助指挥使选择参战的神器使并进入战场。
- 她的直接表现是提醒、护卫安排与关切，而不是代替指挥使决定黑门之核的处置。
- 页面角色语音库还收录她面对最终离别的发言；该发言的出现条件应与可用／参战角色状态一同保留。

## 晏华

- 负责观光塔行动的抵达与战场判断，指出必须尽快消灭不断召来怪物的黑门。
- 其在本页的作用是将指挥使和神器使组织到明确的战斗目标上，不替代指挥使设置黑门之核的决定。

## 珈儿

- 在希罗试图以永生动摇众人后首先明确拒绝，并将守护置于生命之上。
- 黑门消灭后最先请求指挥使在自己活骸化后终结自己，是胜利后“牺牲仍未结束”主题的直接承载者。

## 希罗与四名活骸神器使

- 希罗把黑门、活骸与新世界描述为通向永生或力量的道路。
- 奥露西娅、达尔维拉、罗纳克、芙罗拉分别以自己的理由回应这条道路；这些是本场冲突中的角色立场，不是对黑门后果的独立科学验证。
- 失败分支中，希罗取得黑门之核并向指挥使展示无法阻止的黑色大门。
