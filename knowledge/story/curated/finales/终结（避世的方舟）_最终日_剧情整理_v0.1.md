# 使用边界

本文只对《终结（避世的方舟）／最终日》已采集的 Wiki 正文作结构化人工校订，不替代 raw 或 clean 来源。

- 来源索引只登记一个“最终日”正文段，`choice_trees: 0`；本页没有玩家选择树、嵌套状态树或可重复菜单。
- raw／clean 中的“最终战失败”是战斗结果标记，不是供玩家主动选择的对话选项。
- 页面只收录最终战失败后的正文，没有成功分支。不能凭“打败希罗就可以阻止黑门”的战前台词自行补写成功结局。
- 希罗说巨大黑门已开始降临、“祭品”已献上、黑核是唯一钥匙；这些是希罗对计划的说明。本页没有公开祭品身份、献祭过程或黑核作用的独立验证。
- 安托涅瓦没有在本页出现。结合第一天主战失败后她被取出结晶，可形成入口候选，但不能把“本页未出现”单独当成死亡证明。

# 1. 太阳不再升起

最终日开始时，太阳没有升起。希罗突然出现，解释是巨大黑门遮住太阳，并表明自己是来夺取指挥使持有的黑门之核。

希罗称：

- 巨大黑门的降临已经开始；
- 祭品已按预料献上；
- 唯一能阻止降临的钥匙是黑门之核；
- 为防意外，他必须取得指挥使手中的黑核。

指挥使拒绝交出。希罗原本也没有期待其自愿让出，要求召唤神器使并以战斗决定黑核归属。

这一开场与另两个最终日有明显差异：

- 《深蓝之星》和《黑暗中的身影》中，希罗已经被阻止或不在现场；
- 本页中希罗仍能主动现身、召集同伴并直接争夺黑核；
- 安托涅瓦没有与指挥使共同展开方舟或显现最终黑核。

# 2. 最终战前的对峙

希罗欢迎其“朋友们”到场，并说自己的夙愿得以完成也多亏指挥使。指挥使拒绝继续争论，认为希罗不会放弃理想，只能直接击败他并破坏黑门。

希罗则认可指挥使在短时间内成长，又直言更想在此杀死对方。

可确认的是双方已经没有协商空间并进入最终战；不可确认的是：

- 希罗所称“朋友们”具体名单；
- 指挥使此前哪项行动构成完成夙愿的关键；
- 希罗是否仍把指挥使视作第一天所称的“同类”，以及该词的机制含义。

# 3. 最终战失败

来源只保存失败结果。希罗称世界轨迹已经无法改变，捡起散落在地的黑门之核，并邀请指挥使一起到天空观看。

指挥使被希罗以未说明的力量束缚并带到空中，看见：

- 巨大的黑色门；
- 从门中持续涌出的怪物；
- 已经没有人能够阻止它们。

页面在此结束。它可以支持“当前轮阻止巨大黑门的行动失败”，但不能自行补写：

- 世界被吞噬的完整过程和时间；
- 指挥使、希罗、安托涅瓦及其他神器使的最终生死；
- 黑门之后是否存在希罗期待的新世界；
- 轮回何时、由谁重新启动。

# 4. 与第一天状态的入口关系

第一天剧情战失败时，希罗夺走黑核并从安托涅瓦胸口取出结晶，同时留下指挥使性命；本最终日又表现为希罗仍在、安托涅瓦缺席、指挥使持有一批黑核并再次与其决战。

因此，当前最佳支持关系是：

```text
第一天未能彻底阻止希罗／安托涅瓦失去行动能力
→ 最终日由希罗再次争夺黑核
→ 最终战失败
→ 巨大黑门无人阻止
```

但来源索引没有把《终结》链接绑定到第一天“剧情战失败”对象，也没有解释第一天被夺走的黑核与最终日重新由指挥使持有之间的实际时序。该入口应标为待核候选，不能作为已确认公式。
