# 使用边界

本文整理《永恒的终焉》最终日 Wiki 正文。

- 第一棵是状态树：“未满足／满足《两个人的旅途》条件”，不是玩家选择。
- 只有满足条件时，才出现三棵连续嵌套的“和安离开／留在中央庭”选择树。
- 任一层选择“留在中央庭”都进入同一类《永恒的终焉》收束；连续三次选择离开才跳转《两个人的旅途》正式结局页。
- 三次选择是一次性的深度 1、2、3 节点，不是可返回、可重复查看的菜单。
- 未满足条件时没有玩家 Tab，指挥使直接决定留下。
- 结尾只写指挥使忍受心脏疼痛并“沉入黑暗”，没有明说安、指挥使或其他人的最终生死。
- P10 视频只作补充，不覆盖 Wiki 正文。

# 1. 第一层：是否满足《两个人的旅途》条件

## 1.1 未满足条件

安说明自己也被关在类似地下房间，手脚因强行挣脱机关而流血；她逃出后立刻来救指挥使。她提出两种价值方向：

- 一起离开城市和混乱世界；
- 留在地下继续为神器使提供生命力，尝试阻止世界毁灭。

但该状态没有实际玩家 Tab。指挥使直接选择留下，理由是不能在其他人仍战斗时抛下一切。

安接受决定，表示会在门外陪伴、作为剑与盾阻止怪物接近。她关门后，指挥使独自留在房间。

## 1.2 满足条件

安的进入方式不同：

- 爱缪莎原本依晏华计划应抓捕安；
- 据安转述，爱缪莎认可二人一直为中央庭工作；
- 爱缪莎因此提供进入地下的方法。

安没有以流血逃脱的状态出现，而是把救援视为此前努力终于被认可。随后第一棵玩家选择出现。

两种状态互斥，不能合写成“爱缪莎提供方法后安又从牢房流血逃出”。

# 2. 满足条件后的三次选择

## 2.1 第一次确认

| 选项 | 结果 |
| --- | --- |
| 和安离开城市 | 安托涅瓦形象出现，以神器使需要供能、救世责任劝阻；进入第二次确认。 |
| 留在中央庭 | 指挥使道歉并留下；进入《永恒的终焉》留守收束。 |

## 2.2 第二次确认

仅在第一次选择离开后出现：

| 选项 | 结果 |
| --- | --- |
| 和安离开城市 | 安表示不愿勉强，投影进一步以安托涅瓦死亡施压；进入第三次确认。 |
| 留在中央庭 | 指挥使留下；进入同一类留守收束。 |

## 2.3 第三次确认

仅在前两次均选择离开后出现。来源索引中的选项顺序为“留在中央庭／和安离开城市”：

| 选项 | 结果 |
| --- | --- |
| 留在中央庭 | 指挥使留下；进入同一类留守收束。 |
| 和安离开城市 | 页面明确“进入结局两个人的旅途”。 |

因此结构为：

```text
满足《两个人的旅途》条件
└─ 第一次
   ├─ 留下 → 永恒的终焉
   └─ 离开
      └─ 第二次
         ├─ 留下 → 永恒的终焉
         └─ 离开
            └─ 第三次
               ├─ 留下 → 永恒的终焉
               └─ 离开 → 两个人的旅途
```

Clean 把三个“留下”长段按嵌套关闭顺序连续列出，不能误读成同一节点有三个“留下”选项。

# 3. 留在中央庭的共同收束

三个玩家选择层级中的任意“留在中央庭”，以及“未满足条件”状态，都会进入内容近似的留守收束：

1. 指挥使认为自己不能在其他人战斗时逃走；
2. 安尊重其选择，表示会在门外作为剑与盾保护；
3. 走廊传来怪物嘶吼，安独自守在门外；
4. 指挥使相信只有留在这里为神器使供能、击败希罗和黑门，灾难后才有机会与安及中央庭重新解释；
5. 在持续心脏疼痛中，指挥使祈求安再等一等，最终沉入黑暗。

“灾难结束后可以解释”是指挥使当时的希望，页面没有确认灾难真的结束或解释机会到来。

满足条件状态下三处“留下”正文高度重复。它们是三个不同深度的互斥入口，结果相同，不应压成“可重复点击留下”。

# 4. 安托涅瓦形象的证据边界

当玩家选择离开时，安托涅瓦形象会出现并施压：

- 自称可被当作中央庭里的一缕孤魂；
- 指责指挥使抛下正在战斗的神器使；
- 称自己的死亡由安导致；
- 质疑指挥使是否应相信安。

在《两个人的旅途》页面中，安将其称为虚拟投影并通过破坏摄像头使之消失。本页没有公开投影制造者或数据来源。因此这里只能记录为“安托涅瓦形象／投影”，不能视为本人复活或灵魂发言。

# 5. 条件与路线矩阵

| 前置状态 | 最终日行为 | 结果 |
| --- | --- | --- |
| 未满足《两个人的旅途》条件 | 无 Tab，自动留下 | 永恒的终焉 |
| 满足条件 | 第一次留下 | 永恒的终焉 |
| 满足条件＋第一次离开 | 第二次留下 | 永恒的终焉 |
| 满足条件＋前两次离开 | 第三次留下 | 永恒的终焉 |
| 满足条件＋连续三次离开 | 跳转旅途结局页 | 两个人的旅途 |

页面未公开“满足条件”的完整公式。中央庭信任已满、第一天“请求放过安”等是可见相关状态，但是否还需要其他条件，应维持待实机确认。

# 6. 四棵树结构总表

| 树 | 类型 | 深度／父节点 | 可重复 | 作用 |
| --- | --- | --- | --- | --- |
| 未满足／满足旅途条件 | state_condition | 深度 0 | 否 | 决定是否有离开选择 |
| 第一次离开／留下 | player choice | 深度 1；父项“满足” | 否 | 留下收束或继续确认 |
| 第二次离开／留下 | player choice | 深度 2；父项第一次离开 | 否 | 留下收束或继续确认 |
| 第三次留下／离开 | player choice | 深度 3；父项第二次离开 | 否 | 留下收束或跳转旅途 |

本页没有剧情战胜负树；《两个人的旅途》的最终战只在跳转后的独立最终日页面出现。

# 7. 角色材料（限本页）

## 安

- 无论前置状态如何，都主动到地下寻找指挥使。
- 未满足条件时靠受伤强行逃脱；满足条件时由爱缪莎提供入口。
- 即使希望共同逃离，也尊重指挥使留下，并独自在门外承担防卫。
- “你是我最喜欢的人”是她在接受与自身愿望相反选择后仍保留的明确表达。

## 指挥使

- 未满足条件时没有离开选择，直接把救世与神器使供能置于个人逃亡之前。
- 满足条件后有三次改变决定的机会；任何一次留下都会进入同样的自我消耗。
- 最后“沉入黑暗”是页面明确收束，生死及下一轮过程仍未展开。

## 爱缪莎

- 只在“满足旅途条件”版本中由安转述为提供地下入口。
- 未满足版本没有该协助，安被关押并自行逃脱。
- 其判断依据与后续是否参与战斗，需结合旅途最终日交叉核对。

## 晏华与中央庭

- 本页不直接出现晏华对话，但地下房间持续限制并抽取指挥使力量。
- “继续供能能否真正阻止黑门”没有在本页得到结果验证。

# 8. 结局主题与事实边界

《永恒的终焉》的页面结局不是一场明确胜负的战斗，而是指挥使一次次选择留下，把自身作为中央庭供能来源。安则接受并在门外守卫。

可以确认的是：

- 二人没有共同离开城市；
- 指挥使持续承受心脏疼痛并失去意识；
- 安最后在门外对抗怪物；
- 页面没有展示希罗、巨大黑门、中央庭战线或世界最终状态。

因此不能把结局补写为中央庭成功获胜，也不能在没有后续证据时确定安或指挥使死亡。
