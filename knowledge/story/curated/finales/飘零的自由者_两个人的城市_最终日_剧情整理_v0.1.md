# 使用边界

用户已人工确认：页面中的 A、B、C 等标题只是候选神器使名单的首字母索引，不是连续剧情章节；结局允许指挥使从本周目已经攻略的神器使中选择一人，共度最后一天。当前 Clean 页面实际保存 21 个字母索引标题；连同“最终日”总标题可计为 22 个同级标题，因此不得笼统写成“22 个字母分类”。

Raw 与 Clean 必须保留原页完整名单。本文件为了服务当前 Mod，只列项目 1.0 十人名单与原页名单的有效交集。

# 1. 结局结构

七天过去后，天空呈现异样色彩，恐惧在城市蔓延。指挥使确认自己仍拥有朋友，可以回到他们身边，并从候选名单中选择一名本周目已经攻略的神器使共度最后时光。选择谁不会改变本页保存的公共结局正文：

- 与所选神器使一起度过最后一天；
- 末日在共同陪伴中成为美好回忆；
- 两人在遗忘前一起观看末日景象。

页面没有保存每名角色的独立对白、行动或差异结算，不能根据个人支线自行补写。结局仍以末日和遗忘为前提，没有确认两人阻止毁灭、逃离轮回或保留记忆。

# 3. 叙事意义

《终结》强调孤独与放弃，《两个人的城市》则确认：即使本轮世界仍将在末日中结束，指挥使已经通过个人支线与至少一名神器使建立了真实联系。结局价值在于“共同经历”，而不是把所选角色提升为唯一正史伴侣。

# 4. 禁止误读

- 不把字母索引及“最终日”总标题写成 22 段连续剧情。
- 不把原页全角色列表自动加入 Mod 的白夜馆名单。
- 不为八名当前候选编造 Wiki 没有收录的独立对白。
- 不把安和安托涅瓦缺少个人支线解释成她们与指挥使没有关系。
- 不从本页推断唯一官配或项目正史最终伴侣。
