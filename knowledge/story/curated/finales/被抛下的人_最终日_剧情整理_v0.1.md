# 使用边界

本文只整理“被抛下的人／剧情／最终日”的已采集正文，不替代 Raw 或 Clean，也不把希罗、晏华关于门后异界的判断自动提升为完整世界观定论。

- 本结局承接第一天“黑核、活骸等要求达成”的状态分支；来源没有公开完整阈值，本文不补写具体数量。
- “就算在这里动摇也没有意义了／已经坚定的目标一定要走到底才行”是态度选择，两项随后汇入同一段拒绝回头、与中央庭战斗的剧情。
- “剧情战胜利／剧情战战败”是结果条件，不是玩家主动选择。战败进入特殊灭世 2 的对应段落。
- 胜利段写作中央庭来者被“打倒”，没有逐人确认死亡；不得将其概括成晏华、爱缪莎等人已经死亡。
- 最后评价“牺牲者／前行者／坚守者”没有署名；在可靠来源确认前，不指认具体说话者。

## 选择树结构复核

```text
中央庭追入黑门并夺走一颗黑核
├─ 就算在这里动摇也没有意义了
└─ 已经坚定的目标一定要走到底才行
   ↓ 共同续段：指挥使称已无路可退 → 说服失败 → 与中央庭战斗
剧情战胜利 → 希罗集齐装置所需黑核 → 活骸受希罗后门控制 → 指挥使遭背弃并被践踏
剧情战战败 → 特殊灭世 2／被抛下的人最终战战败
```

两个态度选项只改变指挥使对动摇与坚持的措辞。来源为两项保留相同的“很想相信，但已经太晚”回应；后续“已经没有办法回头”、晏华宣告战斗及最终战均为共同续段。

# 1. 黑门内部与八槽装置

指挥使、希罗与罗纳克进入巨大黑门深处。周围是黑暗、星空与不断湮灭的星体，脚下没有传统道路。三人在一面看不到顶部的高墙前发现未知装置；希罗观察到装置具有八个豁口，认为可嵌入八颗黑核并打开墙后的门。

“八个豁口”是最终日现场明确视觉信息，但不能反向等同为第一天所有隐藏结局条件的完整列表。第一天仍只公开“黑核、活骸等要求”。

# 2. 中央庭追击与异界风险争议

晏华、爱缪莎等中央庭成员追到黑门内部。罗纳克挡住晏华射击，爱缪莎趁机夺走希罗正准备放入装置的黑核，并要求指挥使承诺净化现有黑核，否则便通过战斗夺回。

晏华主张当前所在空间并非真正异界，真正异界在高墙之后；若以黑核启动装置，让弱小的现实世界直接接触门后世界，现实会被碾压粉碎。指挥使则怀疑这是中央庭为要求其消耗生命净化黑核而编造的理由。

这里存在两套互相冲突的解释：

- 希罗把门后描述为神器宝库和可能的复活希望；
- 晏华把开门描述为足以毁灭现实世界的接触风险。

最终日用行动结果呈现希罗的操控和背叛，却没有完整展示高墙后的异界，因此不能仅凭本页解决全部异界本质争议。

# 3. 态度选择与共同战斗

## 3.1 两项态度

| 选项 | 页面呈现的态度 |
| --- | --- |
| 就算在这里动摇也没有意义了 | 指挥使承认想相信晏华，却认为选择已经造成太多活骸，回头太晚。 |
| 已经坚定的目标一定要走到底才行 | 指挥使同样承认想相信晏华，却以既定目标与此前牺牲为继续前进的理由。 |

两项都汇入同一判断：为了不让此前牺牲失去意义，指挥使认定自己只能前进。晏华据此结束说服，并表示中央庭除非全部被击败，否则不会退让。

这一选择主要呈现指挥使如何为继续道路赋予意义，不会改变接下来的战斗对象或结局结构。

# 4. 最终战结果

## 4.1 剧情战胜利

指挥使一方击倒中央庭追击者。希罗从他们身上取回黑核，宣称距离最终目标只差献上最后的“灵魂”以打开门。

随后，指挥使遭到自己亲手转化为活骸的神器使攻击。希罗承认自己在活骸化过程中加入了“小彩蛋”；活骸对指挥使没有回应或怜悯，只朝希罗和装置方向前进，并把倒地的指挥使当作障碍践踏。

因此，结局中的“被抛下”不是页面预先公开的游戏条件，而是最终呈现的关系结果：指挥使以让同伴存续为理由推动转化，最终却因希罗预设的控制后门被这些同伴舍弃。摘要不应把活骸的行为简化成他们自愿背叛，也不应断言其原本人格已经彻底消失；页面只证明此刻没有回应并受希罗设计影响。

结尾的无署名文字称这一结果是“不甚理想”的未来可能性，并询问“牺牲者”“前行者”“坚守者”各是谁。它保留对指挥使选择和其他未走道路的反思，但没有解释说话者身份。

## 4.2 剧情战战败

战败时不发生希罗取回黑核、活骸背弃和无署名评价，而是转入特殊灭世 2 的“被抛下的人最终战战败”段落。该失败边界必须与第一天要求未达成的特殊灭世 3 分开：

- 特殊灭世 3：进入最终日前未满足希罗要求；
- 特殊灭世 2 对应段：已进入最终日，但败给中央庭追击者。

# 5. 角色材料（限本页）

## 指挥使

- 面对晏华警告时仍受既有牺牲和“不能让付出失去意义”的心理推动。
- 击倒中央庭后并未获得希罗承诺的共同未来，反而成为其计划中可被舍弃的最后障碍。
- 本页结局呈现的是选择的后果，不足以把其所有动机简化成单纯服从希罗。

## 希罗

- 对黑门内部装置并不完全了解，却愿意用黑核试开高墙后的门。
- 在最终阶段公开活骸化过程中预埋的控制后门，证明此前“独立个体”的承诺具有欺骗性。
- 所称最后的“灵魂”没有在本页得到完整机制解释，不应自行定义。

## 晏华

- 追入高幻力黑门，试图以异界接触风险说服指挥使回头。
- 说服失败后把阻止开门置于自身安全之上，选择与指挥使一方战斗。
- 战胜分支只确认其被击倒，未确认死亡。

## 爱缪莎

- 以机动方式从装置前夺走关键黑核，并把是否净化黑核设为最后交涉条件。
- 她直接接触黑核的风险被指挥使指出，但本页没有给出具体伤害结果。
