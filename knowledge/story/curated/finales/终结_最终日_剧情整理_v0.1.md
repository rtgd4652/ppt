# 使用边界

本文只整理“终结／剧情／最终日”的已采集 Wiki 正文。它是第一天页面列出的三个最终日入口之一；虽然页面形态与“黑核收集数不足”的失败式收束相符，但在第一天原始 HTML 或游戏实测确认入口绑定前，不将其写成某一具体黑核数量条件的确定结果。

- 经原始 HTML 复核，本页没有页面级玩家选择或“剧情战胜利／失败”Tab。它在“四方之王”战斗节点后只保留一段失败式收束文本；不能补写未呈现的胜利路径。
- 希罗关于活骸自愿、保有自我意识、巨大黑门与祭品的说法，均保留为希罗的战场主张。
- 黑影少女、黑门、黑色大门和“今天结束”的结尾与其他页面的循环线索相关，但本页不独立解释时间重置或世界重构机制。

# 1. 黑雾覆盖下的最后抵抗

最终日开场时，太阳已无法穿透天空黑雾，城市陷入黑暗并发生震颤。一名身份未明的幼小黑影在高处注视坍塌中的世界，认为指挥使似乎没有翻盘机会，却又询问最后是否会出现不同的结果。页面没有揭示其身份或观察世界的立场。

珈儿报告巨大黑门仍在从城市中心向外围扩张。她与指挥使判断黑雾最浓处位于天空，因此前往观光塔顶层攻击空中的黑门；她希望神器使承担前线，指挥使留在后方，但指挥使预期希罗会在塔顶等待。

# 2. 观光塔对峙与四方之王

观光塔顶层确实有希罗及四名已经成为活骸的原神器使。希罗要求指挥使交出黑门之核，称打开最终、最大的黑门是自己一直以来的夙愿。

面对指挥使对活骸化的质问，希罗声称这些人是自愿的，并称“新式活骸”能够保持自我意识；他还表示巨大黑门已经降临，祭品已如预料般献上。这些是希罗为其路线提出的说明，不等于页面已验证其真实性、适用范围或代价。

希罗给出的战场条件是：指挥使可召唤自己的神器使，若打败他便能用全部黑门之核阻止黑门降落；否则便只能看着城市被吞噬。页面随后出现“扫荡击败四方之王”的战斗节点。

# 3. 页面实际保留的收束

在战斗节点之后，本页没有提供独立的胜利正文，而是直接呈现希罗的失败式收束：他称世界轨迹无法改变，拾起散落的黑门之核，并以莫名力量拘束指挥使飞向天空。

指挥使在空中看见巨大的黑色大门和不断涌出的怪物，页面明确写道已经没有人能够阻止它们。随后以“今天到这里”“很快还会见面”结束。

因此，本页目前能确证的是一条“巨大黑门未被阻止、希罗获得黑门之核、世界进入无法阻止的怪物涌出状态”的终局文本。它不能被扩展为所有最终日共同结局，也不能因战斗节点存在而假定另有未采集到的成功结局。

# 4. 角色与叙事材料（限本页）

## 珈儿

- 在黑门急剧扩张时提供观光塔攻击方案，并优先考虑指挥使留在后方。
- 她的判断体现了前线神器使与指挥使在最后防御中的分工，但本页没有展开之后的具体战斗过程。

## 希罗

- 把最终巨大黑门的开启称为长期夙愿。
- 再次以“自愿的新式活骸”“保有自我意识”“祭品已献上”为其行动辩护。
- 在本页唯一保留的战后文本中取得黑门之核，并带指挥使观看无法阻止的黑色大门。

## 身份未明黑影

- 在城市崩塌景象前对指挥使发出带有旁观性质的评价。
- 没有名字、能力、所属或目的的正文说明；图片资源名称不能替代剧情中的身份确认。

# 5. 与其他最终日的对照边界

“终结”与“牺牲的意义”“箱庭风景”都使用观光塔、黑门、希罗与四方之王等共同元素，但各页面的结构并不相同：

- “牺牲的意义”有明确的剧情战胜利／失败状态分支和大量后续语音材料；
- “箱庭风景”有明确的剧情战胜利／失败状态分支，并在胜利分支给出箱庭窥探叙事；
- “终结”没有状态 Tab，只保留失败式收束。

因此，现阶段只能把三页作为独立最终日来源保存。黑核收集数量与三页的精确入口映射、它们是否代表互斥结局、以及各自的触发条件，必须在原页面结构或游戏实测确认后再写入总时间线。
