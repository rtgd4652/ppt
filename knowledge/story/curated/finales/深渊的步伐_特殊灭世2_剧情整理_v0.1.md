# 使用边界

本页汇总三个正式最终日的战败收束，但它们是彼此独立的失败结果，不是一段连续发生的剧情。

- “神的棋盘最终战战败”“零的故事最终战战败”“被抛下的人最终战战败”是三个独立入口。
- 只有“零的故事”内部再按希罗死亡／存活分为两个状态。
- 各失败段落的责任主体和毁灭方式不同，不能合并成通用“世界毁灭”摘要后丢失差异。

## 选择树结构复核

```text
神的棋盘战败 → 巨怪吞噬世界

零的故事战败
├─ 希罗死亡 → 活骸人格完成以世界为祭品的计划
└─ 希罗存活 → 希罗夺取黑核，黑门与怪物失去阻挡

被抛下的人战败 → 活骸逐一消失，指挥使停止抵抗
```

# 1. 神的棋盘最终战战败

指挥使在最后关头被击倒，只能看着由黑核和活骸遗体形成的巨怪张开能够吞噬世界的巨口。该段没有神秘少女、射击或箱庭崩裂；那些内容只属于胜利分支。

# 2. 零的故事最终战战败

## 2.1 希罗死亡状态

活骸人格明确表示世界融合与毁灭并非研究意外，而是其主动推动的目标。她利用零仍可能恢复的希望，迫使希罗持续研究，并把整个世界作为祭品。指挥使的意识被活骸零吞没，世界随之消失。

该陈述来自活骸人格，应记录为其亲口说明的计划；它不能被错误归到零的意愿上。

## 2.2 希罗存活状态

希罗取得散落的黑核，以力量拘束指挥使并带其升向天空。巨大黑门与不断涌出的怪物已无人能够阻止，页面以“今天到这里”“很快还会见面”收束。

该状态没有活骸人格关于祭品计划的说明，不能把两个失败版本混写。

# 3. 被抛下的人最终战战败

指挥使看到活骸同伴逐一消失，反而感到轻松，并停止继续使用他们战斗。希罗催促其继续，但指挥使已不再认为这条道路能保存任何人。

结尾追问其停步究竟源于无法对昔日同伴下手，还是终于意识到不应寄希望于活骸。页面把这一停步称为“明智又狡猾”，没有给出唯一答案。

# 4. 三种失败的叙事差异

| 路线 | 直接失败对象 | 毁灭／收束方式 | 核心边界 |
| --- | --- | --- | --- |
| 神的棋盘 | 希罗制造的巨怪 | 巨怪吞噬世界 | 不出现神秘少女与弑神反抗 |
| 零的故事（希罗死亡） | 活骸零 | 活骸人格完成祭品计划 | 不代表零的意愿 |
| 零的故事（希罗存活） | 希罗阵营 | 希罗取得黑核，黑门失控 | 不包含活骸人格的完整自述 |
| 被抛下的人 | 中央庭追击战与活骸消耗 | 指挥使停止抵抗 | 结论保持开放，不代替角色判断 |

# 5. 本页可用于后续核对的线索

- 活骸人格利用零与希罗研究关系的时间起点。
- “今天到这里／很快还会见面”在不同失败结局中的说话者与轮回含义。
- 被抛下的人失败时活骸消失的具体机制，以及是否与希罗控制后门相同。
