# 使用边界

本文只整理“箱庭风景／剧情／最终日”的已采集 Wiki 正文。它是第一天页面列出的三个最终日入口之一；三个最终日页面现已完成采集与分支结构核对，但本文不把它与任何黑核收集数量条件作未经验证的逐项绑定。

- “剧情战胜利／剧情战失败”是页面明确保留的状态分支。胜利分支中出现的四方之王战、神灭鬼生战、箱庭／窥探者叙事和平台崩裂，均不应写入失败分支。
- 已通过本页原始 HTML 复核：页面实际包含两组嵌套的“剧情战胜利／剧情战失败”Tab。击败四方之王的胜利分支才会进入“神灭鬼生”战斗节点；任一层失败都会进入该层对应的失败收束文本。
- 爱缪莎关于塔罗、希罗关于世界融合与异界、奥露西娅关于活骸躯体的陈述，都须保留为当时角色的说明或立场；本页没有独立完成全部真实性验证。
- 两个失败分支显示同一段希罗收束文本。该文本在 raw 层重复出现不是模板噪声，而是两个独立嵌套战斗节点各自的失败面板；不得删除、合并为胜利后的共同剧情，或解释为同一时间线重复发生。
- “箱庭”“窥探者”“无名神明”等表述在本页以叙事景象与无署名话语出现；不得在单页层面把它们直接定性为已经完全解释的世界本质。

# 1. 最终战前：城市、爱缪莎与观光塔

中央庭准备的直升机载着指挥使和神器使前往与黑门相接的观光塔。页面交代大部分市民已经撤离城市，并把巨大黑门的降临描述为可能吞没交界都市乃至整颗地球的危机。

飞行途中，爱缪莎俯瞰城市，并在被问及能否以塔罗占卜未来时表示，自己不会对这种大事件进行占卜。她给出的原因是：每一次看到的未来都相同——希望与绝望交织，“没有人死去、也没有人活着”。她没有进一步解释该预见的含义；指挥使将其联想到活骸化，爱缪莎没有明确确认。

抵达观光塔后，指挥使计划利用仅存黑核的力量进行逆转处理。希罗现身并要求交出黑核，称两个世界的融合已经开始；他宣称黑门中的事物会被保存，问题只在于多出怪物，而神器使可以处理它们。这一说法是希罗对世界融合后果的解释，不是本页已独立证实的事实。

# 2. 希罗、活骸与四方之王战

希罗让奥露西娅以结晶与黑雾缠身的活骸姿态出现。奥露西娅把该躯体称为可在黑雾中自由行动、不会成为怪物的“完美身躯”，并要求指挥使交出黑核；晏华则警告若活骸化属实，其力量会非常强大。

指挥使选择暂时借用黑核的力量应对。页面在“击败四方之王”后进入“剧情战胜利／失败”状态分支。此处可确认希罗阵营将活骸化、黑门和世界融合视为其路线的一部分，但本页没有足够材料逐项证明他们的承诺能够兑现。

# 3. 剧情战胜利：黑门深处与箱庭景象

在“剧情战胜利”分支中，指挥使击倒活骸敌人，但已经净化的黑门之核逐一被黑雾侵染。希罗再次以永生、摆脱旧活骸命运为条件要求交出黑核；珈儿同样率先以守护比生命更重要为由拒绝。

黑门触及观光塔平台并将众人卷入。指挥使在黑门内部见到更强大的异界怪物，页面以“神灭鬼生”作为战斗节点。希罗将异界描述为混乱与噩梦之地，同时又称黑雾深处有如宝石般的未来；这同样是希罗的叙事与诱导，而不是本页的客观说明。

战斗与平台崩裂中，希罗表示自己另有准备，并以所谓灵魂、指挥使等条件去接触一扇“门”。随后白光覆盖周边，门缓慢开启，地面失色透明，页面以“世界的存在正在被夺走”呈现危机。

在仅存意识中，指挥使看到仿佛有人从“箱庭”外向内窥探的画面。无署名叙事将此世界比作舞台上的剧目，称在愿望实现、世界幸福前，“她”不会认同；窥探者随后合上盖子，将这段可能性封存，并出现“无名的神明紧抱唯一的箱庭、对未来期待”的描述。

这段是本页关于“箱庭”概念最直接的材料。它证明页面以世界被观看、剧本可能性被封存的意象呈现终局危机，但尚不足以独立回答窥探者、她、无名神明与循环系统的真实身份和因果关系。

# 4. 剧情战失败：两层节点共用的收束文本

本页的两个嵌套战斗节点均各自提供“剧情战失败”面板；这些面板的正文相同：希罗拾起黑门之核，称世界轨迹无法改变，并以力量拘束指挥使前往天空。指挥使看到巨大黑门与不断涌出的怪物，页面以“今天到这里”“很快还会见面”收束。

它不包含其所在层级之后的胜利内容：例如箱庭窥探、世界可能性封存或神灭鬼生战均不能被写入失败线。同一收束文本的重复来自两个不同层级的失败面板，不表示两条战斗状态已经完全汇合。

# 5. 角色材料（限本页）

## 爱缪莎

- 在前往观光塔的途中以塔罗与城市俯瞰的场景出现。
- 她拒绝对大事件做具体占卜，并以“希望与绝望交织、没有人死去也没有人活着”的方式描述反复出现的未来图景。
- 她没有在本页中给出完整预言解释，角色档案引用时应保留这种不确定与回避直接断言的态度。

## 希罗

- 公开提出两界融合已经开始，并以交出黑核、活骸躯体和新世界为条件诱导指挥使。
- 在胜利分支中将异界解释为同时具有混乱、怪物与“未来”的地方，并以此继续说服指挥使。
- 他在平台崩裂时启动备用计划，直接触及本页的“门／箱庭”异常景象，但其计划与目的尚未被本页完整说明。

## 晏华与珈儿

- 晏华在对峙时警告活骸敌人的危险性，承担战场理性判断角色。
- 珈儿在希罗再次试图动摇众人时主动站出，强调守护与人之存在的价值高于仅仅活着。

## 奥露西娅

- 以活骸化姿态出现，并将这种状态解释为可在黑雾中自由行动的完美躯体。
- 该解释是她与希罗阵营的立场，不能脱离战斗语境写成活骸化的已验证常规结论。
