## 证据使用边界

- Raw 层保存页面自动转换文本，不承担清洗后的可读性。
- Clean 层保存机械清洗正文和选择树，不自动给出人物结论。
- 项目角色档案只能引用经过人工确认的事实；攻略条件、数值门槛和操作步骤不能直接转化为世界观设定。
- 选择树必须保留选项与回答之间的对应关系，不能把不同分支连续拼接为同一段经历。
