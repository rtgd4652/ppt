# 《神器使》Mod 材质与表面规范 v0.1

> 本文规定从概念图到《群星》实际资产的材质关系。参考图只用于分析；正式模型与贴图必须由项目制作或具有明确授权，并登记到 `ASSET_REGISTRY.csv`。

## 1. 材质设计目标

材质必须同时回答三个问题：

1. 这是什么材料或视觉近似物？
2. 它为什么出现在这里，如何连接、维护或承受环境？
3. 在《群星》的实际镜头距离和材质通道中，它是否仍然可读？

本项目不以“越亮、越透明、越像水晶”代表越高级。高级感来自材料分工清楚、尺度可信、表面状态受控，以及普通工程与规则异常之间的对比。

## 2. Stellaris 实现前提

现有舰船流程使用 diffuse、normal、specular 及独立发光/粒子表现，不能假设现代 PBR 渲染器中的完整金属度、粗糙度、透射、真实折射或次表面散射均可用。

因此概念阶段就要把材质拆分为：

- **Diffuse / Base color**：大色块、明暗层次和材料类别的第一判断。
- **Normal**：中小尺度接缝、板件高度、压纹与表面方向，不承担主轮廓。
- **Specular**：区分陶瓷、涂层金属、裸露金属和玻璃边界。
- **Emissive / 粒子**：状态、能量路径、短时异常与动作反馈；不得补救失败的结构设计。

透明、半透明和多层叠加成本高且容易发生排序问题，应优先使用实体边框、假折射、局部高光与稀疏粒子表达。

## 3. 中央庭公共材质体系

### 3.1 深色陶瓷／复合装甲

用途：舰体主面、空间设施外壳、危险研究区和大型设备保护层。

- 低至中等反射，不是纯黑吸光平板。
- 通过大板分区、轻微方向纹理和受力边建立层次。
- 边角只保留有限磨损；不把所有资产做成久经战争的废墟。
- 深色大面必须由雾银结构边、适度高光或少量功能灯与宇宙背景分离。

### 3.2 涂层金属

用途：承重骨架、桥接梁、接口、散热与活动结构。

- 主体为蓝灰、石墨灰或暖灰涂层。
- 裸露金属只出现在滑轨、转轴、锁扣、接口和维修边。
- 拉丝方向服从加工与受力，不在每个面随机旋转。
- 银白切边用于说明结构分区，不用于把整艘舰船镶成珠宝。

### 3.3 雾银结构件

用途：关键承力边、环体骨架、公共 UI 边框和高辨识节点。

- 反射清楚但不过镜面。
- 面积小于主装甲，承担轮廓划分与尺度提示。
- 与冷青状态光相邻时仍应保持实体材质感。

### 3.4 强化玻璃与聚合物

用途：观察窗、实验隔离、公共空间和信息表面。

- 必须有厚度感、固定件、边框或夹层。
- 玻璃内部应能读出空间、设备或柔和反射，避免黑洞般无内容的窗口。
- 大面积透明墙只用于安全、维护和性能允许的场景；远景优先转为深色反射面。

### 3.5 人类生活材料

用途：医院、居住、白夜馆系统界面、博物天枢与公共服务设施。

- 允许少量暖色织物、磨砂聚合物、木质视觉近似、纸张与生活磨损。
- 这些材质提醒玩家中央庭服务于普通人，不是无人化军政机器。
- 生活材料不进入舰船外装甲或高危规则核心。

## 4. 神器科技材质体系

神器设备必须保留三种材料层：

### 4.1 工程承载层

- 陶瓷装甲、绝缘复合物、金属框、暗色接缝和强化玻璃。
- 负责供能、隔离、观测、散热、维护和紧急断开。
- 在常态下占视觉主体的约 60%–75%。

### 4.2 观测与接口层

- 半透明薄膜、偏振表面、微刻度金属、低亮度数据面和窄导光槽。
- 负责把不可直接理解的现象转为可测量状态。
- 颜色和亮度服从功能，不能自动使用紫色或金色。

### 4.3 规则核心层

- 材质由具体神器决定，可能是器物、牌、书、光场、空间缺口或无法定性的表面。
- 体量通常最小，视觉焦点最强。
- 人类只能标准化外围接口，不能把完整规则核心表现为普通流水线产品。
- 不得用“透明水晶 + 内部发光”统一代替所有神器。

### 4.4 异常材料的面积边界

常规神器设施中，半透明、纯能量、相位错位或不可解释材料的总视觉权重宜控制在约四分之一以内。唯一巨构、觉醒或终局状态可以暂时提高，但需要通过实体框架和短时特效维持层级。

## 5. 表面状态系统

同一材质族至少区分以下状态：

| 状态 | 表面表现 | 发光表现 | 使用范围 |
| --- | --- | --- | --- |
| 新建/校准 | 接缝清楚、轻微加工痕迹 | 低亮状态点 | 新设施、正式展示 |
| 日常运行 | 少量接触、维修和热痕 | 稳定导向线 | 大部分公共资产 |
| 警戒 | 局部隔离标记、关闭面板 | 琥珀/暗红节律信号 | 灾害与战斗准备 |
| 受损 | 边缘剥落、熏痕、补片、局部失光 | 不连续或故障闪烁 | 剧情、战损模型 |
| 激活/共鸣 | 规则核心与接口对比增强 | 受控呼吸、逐段点亮 | 神器技能与高级设施 |
| 终局/过载 | 局部材料响应异常，结构仍可读 | 短时高亮、相位错位 | 唯一资产的峰值状态 |

灾后文明不等于永久废墟。维修补片、覆盖标签和局部磨损用于表达连续重建，不允许统一覆盖尘土、锈蚀和裂纹滤镜。

## 6. 颜色、反射与发光的关系

- 主材料色承担 70% 以上的常态识别，不能依赖发光才看见资产。
- 高反射边只用于切分大面、强调接口和说明厚度。
- 功能发光必须对应导航、供能、状态、扫描、隔离或规则共鸣。
- 普通中央庭能源以低亮冷青/天蓝为主；人居空间使用局部暖琥珀。
- 警报红不得与角色玫红混用；前者节律短促、位置功能化，后者只属于爱缪莎等明确个人签名。
- 终局冷白、玫红或金色峰值必须快速回落，不持续吞没模型和贴图。

完整颜色角色见 [COLOR_SYSTEM.md](COLOR_SYSTEM.md)。

## 7. 角色与专题材质

### 7.1 爱缪莎

- 角色：黑色缎面、暗紫织物、深玫红礼装层、透明薄纱、少量金属金边、漆面卡牌。
- 星海设备：中央庭深色陶瓷与雾银骨架为底，加入半透明投影面、细金边和局部玫红发光。
- 卡牌保持器物厚度与牌面方向，不做成舰体板材。
- 终局外层可以是非实体星轨或偏振薄膜，承重主体仍为实体材料。
- 禁止全舰玫红发光、纯金白陶瓷神船和大量塔罗牌贴花。

### 7.2 安托涅瓦

- 方舟路线倾向雾银、暖灰白、低饱和蓝与柔和半透明边界。
- 材料关系强调包覆、缓冲、隔离、生命支持与可进入空间。
- 蓝白银是星海时代的专业转译层，不应被误标为未核验的原作服装事实。
- 不使用满屏冰晶或无实体边界的圣光替代空间保护。

### 7.3 旧世界回声

- 使用氧化、褪色印刷、纸张、旧塑料、修补金属、生活触摸和覆盖标记。
- 每件遗物应有自身材料史，不套统一棕黄做旧滤镜。
- 博物天枢展柜和记录系统使用中央庭当代材料，与旧物形成时间对比。
- 记忆失真通过局部重影、色偏或显示故障表现，不破坏遗物的可辨认性。

### 7.4 黑门与异界

- 异常优先改变材料响应：反射方向错位、边缘不连续、局部相变或纹理尺度突变。
- 保留一部分正常材料作为比较锚点，才能读出规则被破坏。
- 不以紫色结晶覆盖一切，也不把异常固定为湿润有机物或黑色烟雾。
- 异界材质的具体方案仍需后续经原作视觉锚点审核。

## 8. 舰船材质规范

### 8.1 普通舰船

- 大面使用中央庭深色陶瓷/涂层金属，次结构用雾银与蓝灰。
- 功能分区由材质、法线和少量状态灯共同表达。
- 推进、散热、武器和维护区域应有不同表面逻辑，但保持同一制造家族。
- 不为每个装甲面增加独立高亮边，不使用随机贴花制造“复杂度”。

### 8.2 神器使专属舰

- 60%–75% 保留中央庭材料底座。
- 个人材质集中于核心、翼缘、投射器、舰桥/规则接口和少量识别节点。
- 模型负责主轮廓和厚度，贴图负责表面节奏，粒子负责短时能力。
- 个人符号不得烘焙成覆盖全舰的重复纹样。

### 8.3 命运之主

- 当前没有批准的专属材质方案；未来命运之主将从零重新设计。
- 旧 Stage 9 的深蓝主面、冷白环、暖红发光和现有分区只属于待改作其他舰船的遗留模型。
- 新设计仍须保留实体材料层级，且角色个人色不能替代装甲、结构、推进和维护逻辑。
- 卡牌、星轨、概率分支等若被采用，只能承担有限贴图或短时粒子，不预设为主装甲材质。
- 新方案必须先完成灰模和色块测试，再建立独立材质校准；不得从旧模型直接抽取色板。

## 9. 建筑、区划与巨构材质

### 9.1 建筑与区划

- 基础设施显示可替换面板、混凝土/复合基座、交通面和维护接口。
- 居住、医疗和公共服务可提高暖色内饰与人类材料比例。
- 工业区的磨损集中在运输、热源和接触区域，不平均撒在全图。
- 神器研究设施只在核心和隔离区增加异常材料。

### 9.2 方舟类巨构

- 外层为耐候结构与防护壳体，内层展示生命支持、透明观察和柔和人居材料。
- 空间异常通过边界、深度和内部容量关系表达，不使用冰晶宫殿作为默认方案。

### 9.3 命运类巨构

- 新命运类巨构仍须以中央庭可建造的实体工程为底座，但具体配色、环体、星轨和判定节点均需重新论证。
- 命运观测塔旧“太阳冠/神圣未来科技”方案已经废弃，只作为历史记录保留。
- 新命运观测塔不得从旧方案复制塔体、环体、太阳冠、配色或材质比例；应在未来单独建立全新材质板。

### 9.4 异界稳定类巨构

- 正常工程材料与异常响应区域并置，突出“稳定器正在约束不兼容规则”。
- 材料变化沿隔离边界和能量路径发生，不在整座巨构均匀铺色。

### 9.5 博物天枢

- 当代展陈使用低反射金属、耐久玻璃、档案纸色、清晰标签与柔和照明。
- 展品保持自身时代材料，不统一改造成发光遗珍。
- 空间应兼具公共访问、研究、保存和记忆的气质。

## 10. UI 与图标的材质错觉

图标不需要模拟完整真实材质，但必须保持同一套“表面语法”：

- 公共框架：深蓝灰底、雾银边、冷青状态光。
- 科技与组件：一个实体器物轮廓 + 一个材料焦点 + 少量能量线。
- 遗珍：清楚器物材质与年代差异，不统一加金框和宝石光。
- 飞升：可以提高对比和异常材质比例，但仍保留单一主焦点。
- 区划：以大功能色块和结构材料为主，不画成缩小的复杂场景截图。

在 64 px、32 px 和 16 px 下分别检查；如果材料只能靠微小划痕或纹理识别，应改用更清楚的明暗、边缘和色块关系。

## 11. 纹理尺度与性能

- 纹理分辨率、mipmap 和 DDS 压缩会吞掉高频划痕、微字和细线，先按目标镜头测试再增加细节。
- 一级材质分区使用 diffuse/specular 保留；二级面板使用 normal；三级微纹理只在近景资产中保留。
- 透明层、体积光和高频闪烁均需提供远景降级或关闭方案。
- 同一舰船家族优先复用材质族与贴图逻辑，不为不可见差异增加独立大贴图。
- 发光贴图必须保留暗态外观，不能让关灯后出现无意义的纯黑槽。

## 12. 来源、授权与正式资产登记

- 外部照片、商业纹理库、供应商样本、其他游戏贴图和产品扫描不得直接复制。
- `unknown`、`source_uncertain` 和 `external_reference_only` 只允许作为本地参考，不可自动进入 Git 或正式资源。
- 正式贴图必须为项目原创重绘、程序生成、项目自摄、明确许可素材，或由授权来源改制。
- 从参考中抽取“深色陶瓷大面 + 雾银承力边 + 小比例导光节点”等抽象规律时，仍需保留参考链。
- 任何进入 `mod/gfx`、`textures` 或 `models` 的正式资产都要在 `ASSET_REGISTRY.csv` 记录原创/重绘/重建模、来源审核与允许用途。

## 13. 材质审核矩阵

每个新资产至少进行以下检查：

| 检查距离/状态 | 必须确认 |
| --- | --- |
| 概念近景 | 材料分工、连接、厚度、来源和状态逻辑 |
| 游戏常用镜头 | 大色块、结构边、功能区和主发光仍可读 |
| 战略缩放 | 主体不与背景融为一体，发光不糊轮廓 |
| 暗态 | 关闭发光后仍是完整资产 |
| 激活态 | 能量焦点明确，不覆盖全部材料 |
| 受损态 | 损伤集中于受力/热/碰撞位置，不是统一噪声 |
| LOD/Mipmap | 微细节消失后仍保持材料家族与类别识别 |
