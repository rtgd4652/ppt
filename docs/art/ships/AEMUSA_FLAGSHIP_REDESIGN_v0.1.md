## 主体方向：分岔主脊

采用四条有厚度的主承力路径。它们从舰艉动力／工程区分开，在不同高度绕过纵贯中部的开放空间，再向舰首汇合。连续装甲、承载接口、供能体量和维护通路共同组成超级旗舰；中央控制空间是整艘舰的主要结构关系。

远景需要读到三层大形：收束的舰首、分岔且错层的中段、厚重推进／工程舰艉。放大体量同时增加深度、遮挡层次和开放空间。概念里的少量普通小舰仅说明尺度，不作为新增舰种或严格比例。实际长度、碰撞半径和公里数尚未决定。

第一张[整舰概念](../../../art/concepts/aemusa_flagship_redesign_20261104/flagship_concept_v01.png)已用内置image_gen生成，未上传原作图或旧模型图。图中四组正面发射阵面各有四处开口，中央有四片受框架约束的观测面；这些造型用于候选评审，不是正式建模蓝图。

## 本机接口核对与真实缺口

只读查看本机原版文件，未修改它们：

1. `common/section_templates/titan.txt`的`TITANIC_01`使用`invisible_titanic_fixed`和`xl_gun_01`。挂点含`xl`只是名字，槽类型仍需读取模板。
2. `common/component_slot_templates/00_component_slots_fixed.txt`将该模板定义为`size = titanic`、`component = weapon`、`is_fixed = yes`。
3. `common/component_templates/00_weapons_extra_large.txt`中`PERDITION_BEAM_TITAN`为`titanic`武器，并要求`ship_uses_titan_components = yes`。
4. `common/scripted_triggers/07_scripted_triggers_ships.txt`中的该条件是原生舰种白名单，不包含`aemusa_reality_flagship`。

因此后续实现要同时完成16个T位和本舰可用的T级组件；建议新增本Mod自己的T级组件并限制为本舰使用，沿原生装备／目标选择系统实现，不全局覆盖原版舰种白名单。具体武器表现与数值另定，当前没有写入新组件或运行区段。

后续一次代表检查只需确认16个实际T位可装备、对应发射位置和正常目标选择，以及不丢失原唯一舰身份。现在的概念／数据检查不表示16T已在引擎运行。

## 评审与下一步

本张首稿已经表现了四组火力、开放主空间和更强体量关系；近景维护细节偏密、舰首仍是明显楔形，需在灰模阶段检验哪些结构真正支撑远景识别。画面后部冷青矩形是推进端候选，不算额外T槽。还没有宣称与所有原版／其他Mod完成了视觉避撞。

先收敛整舰形象、体量和命运结构，再以新的轮廓做简洁灰模及16个发射位置。原生导出和保存经验可以复用，v08旧舰壳、旧Stage9、旧塔不能成为新舰造型底稿。基线枢纽／公共中庭级和1.0之后的天体舰另属各自范围。

本轮未操作游戏／用户Blender场景，未恢复旧舰实机测试，未修改槽位、数值、运行资源或存档。
