# 晏华角色视觉规范 v0.3

> 状态：**角色、神器器物、人物外貌与原作固有色已批准**。`「神之头脑」晏华` 是 1.0 基础形态主锚点；基础人物配色、神器眼、服装层级与觉醒边界已通过 CVA-001 方案 A 审核。
>
> 本页定义晏华个人视觉层，不定义中央庭公共风格。参考图用于识别与分析，不自动获得公开再分发或进入正式资产库的权利。

## 1. 证据与形态边界

- 基础形态主锚点：`「神之头脑」晏华` 的 Illustration Cut 与 Portrait。
- 觉醒形态辅助锚点：`「觉醒・神之头脑」晏华` 与 `晏华-觉醒.jpg`。
- 觉醒设计稿只用于核对服装结构和增量；标记为废稿的图片不得充当最终形态事实。
- `掌控者`、`黑鹫`、`缓慢时针` 均属于皮肤／活动形态，只能辅助判断跨服装识别、姿态和构图。
- `晏华 荷鲁斯之眼 Artifact Icon.png` 已通过 `AFA-002` 人工审核，作为神器主锚点；`幻识`、`精确瞄准`、`贯通射击`、`广域狙击`等图标作为能力阶段辅助证据。

## 2. 核心识别

- 人物本体必须以批准的基础形态为准，保留面部、发型、体态、服装轮廓和原作固有色关系。
- 气质关键词是冷静、克制、理性、专注、可靠与承担判断责任的压力。
- 他的核心不是“无所不知”，而是在有限信息下发现隐藏结构、识别风险并作出可承担的判断。
- 荷鲁斯之眼是人物能力与叙事象征，不能把晏华整体改造成埃及神祇、机械观察器或人工智能。

## 3. 色彩规则

- 基础人物暗色为深蓝黑与墨海军蓝，用于头发、马甲、长裤和纵向轮廓。
- 基础暖色为驼金、麦黄与棕褐，用于长外套、皮革腰带和腿带；象牙白与浅灰白用于翻领、内衬和白手套。
- 浅天蓝用于衬衫和冰蓝眼睛，低饱和橄榄绿只用于小面积领带；不得扩大为人物主色。
- 神器眼使用黑色外轮廓、暖金／橙金结构和青蓝瞳孔；金色不得扩散到整件外套、枪械或背景。
- 长枪采用枪铁灰、银灰与石墨黑，保持现代、可维护的工程结构。
- 星际时代环境层可使用低饱和深蓝、灰白、克制冷金和少量数据青，但不得覆盖人物原作固有色。
- 冷金只用于关键判断、目标确认或荷鲁斯之眼相关焦点；数据青用于普通信息层，二者不得同时铺满人物。
- 禁止以高饱和霓虹、整身紫色水晶或纯金神光替代基础配色。

### 3.1 CVA-001 外貌与服装固有结构

- 晏华为身材高挑修长、长腿窄腰、肩背挺拔的成年男性，不制作成厚重肌肉型军人。
- 面部狭长、棱角清楚，眉眼锐利；表情保持冷静、克制与专注。
- 深蓝黑头发向后梳起，形成锐利而略微凌乱的发束；神器眼一侧保留较长弧形侧发，不得改成整齐短发或普通背头。
- 双眼主体为冰蓝／青蓝。神器侧保留贴合眼眶的不对称黑金眼形纹路，不能改成眼罩、机械义眼或伤疤。
- 基础服装固定为驼金／麦黄色长外套、象牙白宽翻领、浅灰白内衬、浅天蓝衬衫、深海军蓝双排扣马甲、低饱和橄榄绿领带、深海军蓝长裤、棕褐皮革束带、白手套和黑色正装皮鞋。
- 人物本体的星海升级只进入分析终端、武器维护接口、战略星图和少量通讯附件，不得用中央庭统一制服、动力装甲或义体替换原作服装。

### 3.2 神器眼与觉醒增量

- 神器眼纹路只覆盖局部眼周；未启动时保持低亮度，启动时暖金轮廓亮起，信息焦点仍为青蓝。
- 觉醒形态可使用更深蓝黑长衣、白翻领、青蓝内层、灰裤、黑手套、局部灰色工程护具及少量金色怀表附件。
- 觉醒形态的蓝黑、青色和护具不得反向覆盖基础形态的驼金长外套、白手套和棕色束带。

## 4. 形状与符号

- 推荐形状：收束的观察框、分层信息面、清晰基准线、目标标记、有限的光暗切面和可追溯的分析路径。
- 荷鲁斯之眼符号应是少量、明确的能力焦点，不得扩展为全屏巨眼、常驻神眼穹顶或泛埃及纹样。
- 战略界面应表现“信息被整理”，避免杂乱数据雨、不可读字符墙和纯装饰全息噪声。
- 个人符号不得与爱缪莎的星轨、塔罗牌和命运分叉混用。

## 5. 材质与光效

- 人物服装材质服从原作锚点；星海升级只在通讯设备、分析终端和少量附件上加入中央庭工程材质。
- 环境投影以半透明信息层、星图和克制边缘光为主，人物面部必须保持清晰。
- 能力启动可使用局部聚焦、目标轮廓增强和短暂光暗分层；结束后应迅速回落。
- 禁止常驻过曝眼光、全屏神圣光柱、机械义眼扫描线覆盖面部或无法解释的魔法阵。

### 5.1 荷鲁斯之眼器物规范（AFA-002）

- 神器核心是“眼睛・荷鲁斯之眼”，负责观察、隐藏信息识别、弱点分析与有限信息下的判断。
- 图标中的长枪属于战斗载体和远程精确攻击工具，不得把神器本质直接等同为一把普通狙击枪。
- 规则层使用暖金／橙金的眼形、扫描轨迹和激活轮廓，并以青蓝瞳孔表现被识别的信息焦点。
- 工具层使用黑／深石墨枪体、灰白装甲面和清晰工程分区；枪械必须保持可维护结构，而非神话法器。
- 能力阶段依次表现为观测、分析、锁定、贯通和广域狙击：先识别隐藏信息，再筛选弱点、建立单一射线、沿确认路径贯通目标，最后有限扩大射击影响范围。
- 广域狙击仍是经过分析的远程攻击，不得变成无差别爆炸或无限射程清场。
- 荷鲁斯之眼不是全知之眼、预言、思想读取或自动正确的判断器；它提供信息优势，最终判断仍由晏华承担。

## 6. 星海时代转译

- 立绘环境可加入战略分析终端、银河星图、异常观测图层和中央庭决策空间。
- 人物升级主要发生在工具与信息环境，不以替换肉身、义体化或装甲化表现。
- 科技与设施转译采用“中央庭工程底座 + 信息观测层 + 荷鲁斯之眼有限签名”，不能把所有中央庭情报资产都变成晏华个人资产。
- 舰船或大型资产若使用晏华个人层，应强调传感、识别、目标判断和信息收束，而不是将舰体制作成眼睛或埃及神殿。

## 7. 形态层级

### 基础形态

- 以 `神之头脑` 为唯一主锚点。
- 星际元素只能作为环境和工具层，不改变人物基础服装与辨识结构。

### 觉醒形态

- 以 `觉醒・神之头脑` 和最终觉醒立绘为辅助锚点。
- 表现观察与判断能力的强化，但不得写成全知、预言或神权。

### 皮肤／活动形态

- `掌控者`、`黑鹫`、`缓慢时针` 用于跨服装识别和气质研究。
- 皮肤专属配色、服饰和场景不得自动进入基础形态或中央庭公共视觉。

## 8. 禁止方向

- 全知神明、预言者或永远正确的超级决策者。
- AI 化、机械人化、赛博义体主导或以机械义眼取代神器使本体。
- 泛埃及神殿、金字塔、满屏荷鲁斯眼与神权仪式。
- 巨大全息眼睛常驻背景，或让信息层遮挡人物面部和肢体。
- 直接复制爱缪莎的命运星轨、塔罗牌、月相与概率分叉。
- 将皮肤／活动服装误认作基础形态。
- 把长枪当作神器全部本质，进而将晏华限制为纯战斗角色。
- 全域监控、思想读取、无限射程、预知未来或用眼形标志覆盖中央庭全部设施。

## 9. 适用范围

- 晏华基础、觉醒、皮肤和未来剧情特殊立绘审核。
- 白夜馆头像、通讯、档案、招募图和角色专属界面。
- 态势研判、异常观测、战略判断相关图标与表现。
- 未来可能出现的晏华专属设施、舰船签名层和剧情视觉。
- 不适用于中央庭通用情报系统、所有科学家资产或其他神器使个人视觉。
