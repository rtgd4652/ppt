# 雯梓角色视觉规范 v0.3

> 状态：**人物、神器与固有色锚点均已批准**。`「棋圣」雯梓` 已确认为 1.0 基础形态主锚点；`王者之弈` 的器物、棋局投影、能力层级和星海转译边界已通过 AFA-008 方案 A 审核；人物外貌、基础固有色及觉醒形态边界已通过 CVA-007 方案 A 审核。
>
> 本页定义雯梓个人视觉层，不定义东方古街全部公共视觉或中央庭公共风格。参考图用于识别与分析，不自动获得公开再分发或进入正式资产库的权利。

## 1. 证据与形态边界

- 基础形态主锚点：`「棋圣」雯梓` 的 Illustration Cut 与 Portrait。
- 觉醒形态辅助锚点：`雯梓-觉醒.jpg`、`雯梓觉醒设计.jpg`及最终觉醒文件。
- `阴阳鱼`、`鎏金夜宴` 均属于皮肤／活动形态，只能辅助跨服装识别、姿态和构图。
- `雯梓 王者之弈 Artifact Icon.png` 是神器器物主锚点；基础器物为一黑一白、彼此成对的实体棋具，能力启动时才投影局部棋盘与棋子。

## 2. 核心识别

- 人物本体以批准的 `棋圣` 基础形态为准：极长而浓密的橙红色长发、灰紫色眼睛、修长成熟的女性体态，以及深藏蓝／黑紫、象牙白、低饱和青绿构成的现代东方幻想服装。
- 发色必须保持橙红主体、朱红阴影与暖金橙高光的层次，不能误改为粉发、纯红发或金发。
- 服装保留象牙白／浅米色上装、深藏蓝／近黑紫主体、胸前青绿玉色纹样、暗红／橙红内衬和少量暖金节点；黑色丝袜与深色短靴维持现代行动感。
- 气质应体现直率、侠气、可靠、包容、传统与现代共存，以及长期承担地方共同体责任的压力。
- 王者之弈对应布局、攻守、进退和每一步背后的现实代价，不代表预知全部未来或把他人当作可任意牺牲的棋子。
- 东方古街是人物历史与生活环境，不等于雯梓本人、中央庭或所有神器科技都必须仿古。

## 3. 色彩规则

- 头发主色为橙红，阴影进入朱红／深橙红，高光使用暖金橙；橙红长发是雯梓最强的人物色彩识别。
- 瞳色为灰紫／淡紫灰，不使用发光神眼、预知瞳或高饱和紫色。
- 服装主色为深藏蓝、黑紫和深梅色，辅助色为象牙白、浅米色与低饱和青绿；暗红、橙红和少量暖金只用于内衬、腰带、边缘与节点强调。
- 黑白棋子用于攻守和位置关系，但不能把人物、服装、舰船和 UI 全部压缩成黑白棋盘。
- 星际环境层可加入低饱和规划界面、中央庭工程色和东方古街文化材料色，但必须保持三者层级清楚。
- 禁止借用爱缪莎的玫红金色命运星轨，把棋局误写成命运演算。

## 4. AFA-008 王者之弈神器锚点

### 4.1 器物本体

- 神器本体采用一黑一白、彼此成对的圆润棋具／棋子收纳器，以及可从中分离的黑白棋子。
- 黑侧以墨黑、深梅色和暗紫反光为主；白侧以象牙白、浅灰紫和珍珠白为主。
- 器物表面的紫色纹样属于原作材质识别，不得简化为廉价纯黑、纯白塑料。
- 棋子可以有限悬浮，但不得形成环绕人物的永久棋雨。

### 4.2 棋盘与能力层级

- 棋盘不是永久实体装备。能力启动时只在目标附近生成有限坐标网格、落点和局部投影，结束后迅速清理。
- 网格线应细、清楚、数量克制；通过落点次序、黑白位置和推进方向表达布局与秩序。
- `黑之攻势`：黑子沿清晰方向推进或落下，强调主动压迫与阵位改变。
- `白之守御`：白子组成局部屏障或推移线，强调保护、缓冲和重新分配空间。
- `黑子领域`：先标记有限区域，再分批落下黑子；不得变成覆盖全屏的棋雨。
- `白子领域`：五枚白子依次推进，在终点形成短暂月牙形碰撞面或屏障。
- `恋子棋`：黑白棋子共同运动或有限环绕，形成有边界的保护结构。
- `双魂`：以棋魂积累表现攻守状态循环，不解释为善恶二元、人格分裂或泛化阴阳术。

### 4.3 色彩、光效与动画

- 神器公共能量只使用浅紫和暖白；行动提示可少量使用朱红、橙红或暖金描边。
- 不使用爱缪莎的玫红金色命运轨迹，也不把棋子改成塔罗牌、概率分叉或预言符号。
- 标准动画顺序为：准备局部网格／落点 → 棋子落位或推进 → 局部效果生效 → 黑白攻守转换清楚可辨 → 快速消散清理。
- 棋子不代表可牺牲的人口，棋局不代表银河全知模拟、命运计算器或绝对胜利保证。

## 5. 形状与符号

- 推荐形状：有限经纬网格、黑白棋子、局部落点、攻守转换、共同体空间和协商边界。
- 棋盘与棋子只能作为神器、决策和局部空间布局语言，不能覆盖全身服装、建筑表面、舰船装甲和整个界面。
- 东方古街元素应来自真实生活空间、文化传承和现代延续，避免泛化飞檐、宫殿、牌楼和武侠门派拼贴。
- 不使用爱缪莎命运分叉、安托涅瓦方舟空间或晏华全息观测作为雯梓个人符号。

## 6. 材质与光效

- 服装、配饰和棋具材质服从原作锚点，星海升级主要进入规划设备、共同体终端与中央庭接口。
- 能力启动可出现有限棋盘、落点与经纬结构；攻势和守势必须通过位置、节奏与局部颜色差异表达。
- 棋子出现和消失应保持清楚、克制，不能形成满屏棋雨或将人物困在巨大棋盘中。
- 地方文化材质必须与现代灾后设施并存，不能把场景制作成脱离时代的古代宫殿。

## 7. 星海时代转译

- 环境可加入殖民规划、地区协商、居民安置、文化档案和共同体公共空间。
- 人物升级应体现地方经验进入统一文明决策，而不是成为独立银河统治者或与中央庭对立的地方君主。
- 科技转译围绕局部布局、攻守转换、共同体保护、文化延续和负责任的资源调度。
- 舰船或设施若使用雯梓个人层，应强调局部阵位与保护网络，不能制作成棋盘舰、东方宫殿舰或宇宙全局模拟器。
- 可转译为殖民地局部规划、舰队阵位、保护网络、居民安置和资源协调界面；不得把人物、人口或舰船直接表现成可抛弃棋子。

## 8. 形态层级

### 基础形态

- 以 `棋圣` 为唯一主锚点。
- 保留东方古街生活环境与人物责任，但星海升级只进入环境和工具层。

### 觉醒形态

- 以最终觉醒立绘和批准设计稿为辅助锚点。
- 可以强化橙红长发、白色主体、深红内衬、黑色轮廓、折扇、云纹、花纹、暖金结构与棋局轨迹。
- 觉醒形态可提高东方古街文化表达与领袖仪式感，但不得反向覆盖基础形态的深藏蓝、青绿和现代行动服特征，也不能获得命运控制、全局预知或无限护盾的暗示。

### 皮肤／活动形态

- `阴阳鱼`、`鎏金夜宴`只用于跨服装识别、姿态和活动氛围研究。
- 皮肤专属服装、阴阳符号、金色宴会材质和场景不得自动进入基础形态。

## 9. 禁止方向

- 全身棋盘纹、满屏棋子、棋盘舰、棋盘建筑或整套 UI 棋盘化。
- 泛东方宫殿、古代门派领袖、历史人物复刻或以仿古覆盖现代灾后文明。
- 独立地方统治者、东方古街独立银河国家或个人代替居民和制度。
- 宇宙全局模拟器、命运棋局、预知一切或把文明成员当作棋子。
- 与爱缪莎命运星轨、塔罗牌和概率分叉混用。
- 黑白等同善恶、双魂等同人格分裂，或用 `阴阳鱼` 皮肤符号反向定义基础形态。
- 将黑方固定为唯一攻击、白方固定为纯被动防御，而不表现可转换、可协商的攻守关系。
- 将皮肤／活动形态误认作基础形态。
- 把橙红长发改成粉发、纯红发或金发，把灰紫瞳改成发光的预知神眼。
- 用觉醒形态的白、红、金完全替代基础形态的深藏蓝、青绿和现代行动服层级。
- 将雯梓表现成古代皇后、宫廷棋圣、东方神女或以权谋操纵他人的幕后棋手。

## 10. 适用范围

- 雯梓基础、觉醒、皮肤和未来剧情特殊立绘审核。
- 白夜馆头像、通讯、档案、招募图和角色专属界面。
- 经纬共局、地区协商、攻守转换、共同体保护与文化延续相关表现。
- 未来雯梓专属设施、舰船签名层和剧情视觉。
- 不适用于东方古街全部公共资产、中央庭全部规划系统或其他神器使个人视觉。
