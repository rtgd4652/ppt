# 里见茜视觉延期与塞拉菲姆身份连续性边界 v0.2

> 状态：**人物关系已确认，里见茜原作视觉锚点延期**。
>
> 塞拉菲姆放弃神位、进入箱庭并失去神之记忆后，以神器使“里见茜”的身份生活。待确认的是两个状态之间的视觉继承关系，不是她们是否为同一人物。

## 1. 当前边界

- 塞拉菲姆的原作视觉锚点独立记录在 [`SERAPHIM_STYLE.md`](SERAPHIM_STYLE.md)。
- 里见茜的基础立绘、神器、服装、个人色与特效将在相关剧情完成梳理后另行登记。
- 在里见茜锚点建立前，不能把塞拉菲姆的神位状态直接换装、缩小光效或降低饱和度后当作里见茜。
- 也不能把里见茜后来的外貌、服装和神器反向解释成塞拉菲姆全部历史状态的固有元素。

- 面部、发型、发色、瞳色和体态中，哪些与塞拉菲姆保持连续？

- “相似”是人物连续性证据，还是仅由画师风格、剧情光线或服装状态造成？
