## 3. 不可改变元素

- 金色超长单马尾形成的长弧线与远距离人物剪影。
- 红瞳、纤细体态及从容、轻盈、华丽、带游戏感的少女气质。
- 黑、深玫红/酒红、暗紫与少量金色构成的个人色彩关系。
- 月牙、星点、命运轨迹与塔罗牌之间的组合关系。
- 卡牌是可数、可翻转、可沿轨迹运行的能力媒介，不是铺满一切表面的装饰纹样。
- “观察可能性并保留选择”的人格表达；不得改成冷漠、绝对全知或要求他人服从的神祇。

特定皮肤中的竖琴、骰子、花束、帽子、花饰或服装结构不自动属于常驻识别核心。

## 4. 主要颜色与用途

| 色彩 | 角色/服装 | 舰船与设备 | UI / 特效 |
| --- | --- | --- | --- |
| 黑与暗紫 | 礼装阴影、稳定轮廓、牌面底色 | 个人模块、深色陶瓷分区 | 深层界面、未激活牌面 |
| 深玫红/酒红 | 礼装节奏与人物识别 | 只用于少量节点、轨迹槽和专属模块 | 因果干涉、选择确认、短时峰值 |
| 金发与暖金 | 发型是最强识别；金边只作局部 | 极少量导边、观测刻度或关键节点 | 星点、牌缘、重要结果节点 |
| 暖白/月白 | 皮肤、透明纱和明暗平衡 | 雾银结构、投影薄膜 | 月光、稳定读数、轮廓分离 |
| 冷蓝/星际蓝 | 只作环境与星海阶段补充 | 来自中央庭工程底座 | 观测、星图与稳定状态 |

- 基础形态不能被纯金白覆盖。
- 高饱和玫红仅用于短轨迹、牌面激活或攻击峰值，不作为整幅画、整艘舰或全部 UI 的主色。

## 5. 形状与符号

- 人物首要剪影由超长单马尾的大弧线、纤细躯干和轻盈不对称礼装构成。
- 月牙用于局部切口、护边或负形；星星用于离散焦点，不能铺成均匀墙纸。
- 命运轨迹是细、定向、存在概率分叉且不完全闭合的弧线。
- 卡牌必须保持数量、正反面和运动方向可读；可手持、翻转、环绕或沿轨迹展开。
- 星盘与观测线只作背景支撑，必须给脸、手势、视线和人物轮廓留出干净负形。

## 6. 材质倾向

- 人物：黑色缎面、暗紫织物、深玫红礼装层、透明薄纱、少量金属金边。
- 卡牌：深色硬质或漆面牌体、细金边、大符号；小尺寸时主动简化牌面细节。
- 星际转译：深色陶瓷、雾银结构、半透明投影面、细金边与局部玫红发光。
- 终局外层可使用非实体星轨或薄膜投影；人物、舰体和承重结构仍须保持实体材质可读。

## 7. 特效语言

- 基础状态：稀疏金色星点、短玫红轨迹、牌缘亮线与柔和月光。
- 卡牌激活顺序：定位 → 翻面 → 符号亮起 → 轨迹连接；避免所有牌同时爆亮。
- 观测表现细、慢、冷静；因果干涉才允许轨迹突然改道、折返或局部玫红增强。
- 终局阶段将实体与投影明确分层：人物/舰体保持可读，星轨、月环和概率分支悬浮在外层。
- 峰值可短暂使用冷白主光加玫红/金色边缘，随后必须回落，不能长时间过曝。

### 7.1 卡牌・塔罗牌器物规范（AFA-001）

- 神器由多张可分离、悬浮、翻转、展开与收束的实体矩形卡牌组成，不是单张牌、书籍、棋盘或固定魔法阵。
- 牌体使用深酒红／黑紫主体，玫红／洋红边框与能量层，暖金月牙和中心细长标记，以及少量淡粉／白色高光。
- 粉色圆形背景属于图标中的能力光效，不属于牌体的永久实体材质。
- 现有证据只支持抽象几何、月牙、放射线与细长金色标记，不能据此认定现实世界某套标准塔罗牌面、完整七十八张牌或固定大阿卡纳体系。
- 静止状态使用少量分离悬浮卡牌；决策状态让卡牌围绕月牙聚集和展开；切牌状态沿倾斜轨迹高速交错并形成短暂切割光面；观测状态以卡牌、月牙和有限轨迹形成可读演算关系。
- 任一阶段都必须保持实体牌轮廓、数量层级和运动方向可读，不能被玫红光团或满屏牌阵吞没。
- 命运主宰终局可增加卡牌数量、观测层与轨迹复杂度，但不得反向修改基础神器结构，也不得将塔罗牌扩展为中央庭公共标志。

## 8. 舰船转译方式

- 先使用中央庭可维护的实体舰体、推进区、装甲和模块，再叠加爱缪莎个人层。
- 月牙转译为翼缘、负形或投射框；命运轨迹转译为粒子投影和目标连线；有限卡牌转译为短时运算界面。
- 实体模型负责船体、环体骨架与大型模块；贴图负责低频分区、细金边和能量线路；粒子负责星轨、概率分叉、锁定和开火。
- 唯一旗舰可把个人层提高到约 25%–35%，但不得以卡牌拼装舰壳，不得牺牲《群星》战略缩放下的方向和剪影。
- 未来爱缪莎专属旗舰必须从零重设；旧 Stage 9 只保留为建模、LOD 和导出技术样本，不得复用其剪影后换色冒充新方案。

## 9. 科技转译方式

- 普通命运科研设施建议：约 70% 中央庭公共结构、20% 命运专业结构、10% 爱缪莎个人符号。
- 设备采用“工程外框—悬浮观测层—规则核心”三层；卡牌或月星只能出现在规则核心和少量专用模块。
- 技术主题是概率观测、演算、校准与有限干涉，不是批量复制完整神器或建造塔罗宗教设施。
- 图标优先表现一个清晰器物/功能轮廓和一处概率分叉、牌面或月相异常，不用细密牌阵填满画面。

## 10. 禁止方向

- 纯金白太阳神、机械神、无情神谕者或失去少女气质的终局形态。
- 把整个中央庭文明或全部神器科技改成塔罗、星月与玫红主题。
- 大量卡牌覆盖人物、舰体装甲、炮塔、建筑立面或普通 UI。
- 满屏高饱和玫红、巨大魔法阵和长时间过曝。
- 将特定皮肤的道具混合进全部形态。
- 改变发色、瞳色、基本体态或气质到无法辨认。
- 用“预知”表达绝对全知、必然正确或对文明的个人统治。
- 把牌面擅自补成现实标准塔罗、固定七十八张体系或未经原作确认的具体大阿卡纳图案。

## 11. 适用范围

- 爱缪莎基础、觉醒、皮肤、主线特殊与终局立绘审核。
- 头像、通讯、档案、招募图和角色专属 UI。
- 命运科技、特质、遗珍、飞升和组件图标。
- 命运观测、抽牌、概率演算、因果干涉与开火特效。
- 未来从零重设的命运之主、命运观测塔及其他爱缪莎唯一资产的个人签名层。
- 不适用于中央庭通用舰船、普通建筑或其他神器使资产。
