# 1. 文档目的

本文把 1.0 十名神器使的原作图片索引、标准角色档案、现有角色风格页和待核验事项统一到一个审核入口。

本文只完成：

- 识别现有原作视觉证据；
- 指定基础形态、觉醒形态和神器的候选锚点；
- 记录已有的角色识别与禁止误读边界；
- 标记仍需人工确认的外貌、固有色、服装和形态关系；
- 为后续逐人建立正式风格页提供审核顺序。

本文不授权：

- 下载或提交版权状态不明的图片；
- 生成正式立绘、头像、图标或舰船；
- 把候选图片直接复制到 `mod/gfx`；
- 根据角色名字、能力文字或二手印象臆造外貌；
- 修改游戏代码或制作技术原型。

# 2. 证据规则

## 2.1 证据层级

| 等级 | 含义 | 可用于 |
|---|---|---|
| A | 已登记来源、形态与用途，并完成人工视觉核验 | 正式角色风格页与资产审核 |
| B | Wiki 文件页与图片索引可追溯，但基础／皮肤／觉醒关系或具体视觉事实尚未人工核验 | 候选锚点和审核准备 |
| C | 本地候选图或项目过程图，来源、形态或权利状态不完整 | 辅助观察，不得固定原作事实 |
| D | 文字主题、剧情象征或能力描述 | 只能限定叙事含义，不能推导外貌和固有色 |

## 2.2 形态分层

- **基础形态主锚点**：决定面部、发型、基础服装、体态、核心配色和神器常态关系。
- **觉醒形态辅助锚点**：决定觉醒后的增量，不得反向覆盖基础形态。
- **皮肤／活动形态参考**：只证明角色在换装后如何维持识别，不得当作基础形态。
- **神器器物锚点**：决定神器本体、持握／环绕关系和能力媒介，不代表全部技能特效。
- **剧情 CG／技能特效**：只用于场景、动作和效果生命周期，不能单独决定服装背面或常态颜色。

## 2.3 权利边界

十人的图片索引来自灰机 Wiki 文件记录，属于原作参考证据。除非另有明确授权：

- `copyright_or_license_status` 统一按 `official_game_reference` 或 `external_reference_only` 管理；
- `allowed_usage` 仅为视觉分析、核验和原创转译；
- 不自动下载，不自动加入 Git，不直接作为 Mod 正式资产分发；
- 正式资产必须原创重绘、重新建模或只提取抽象视觉规律，并另行进入 `ASSET_REGISTRY.csv`。

**剩余工作：**
