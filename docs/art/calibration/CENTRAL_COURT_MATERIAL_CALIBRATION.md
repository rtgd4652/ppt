# 中央庭公共材质校准板 v0.1

> 状态：项目自制的美术校准基线。
>
> 用途：统一中央庭公共舰船、建筑、区划、科研设施、UI 与通用图标的颜色和材质判断。
>
> 重要边界：本文件及配套 SVG **不是游戏正式资产**，不得直接复制到 `mod/gfx`、贴图或模型中。正式资产仍需按目标尺寸、Stellaris 材质通道和 `ASSET_REGISTRY.csv` 流程重新制作与审核。

## 1. 依据与定位

本校准板只汇总以下既有结论，不引入新的文明配色或角色符号：

- [`../ART_BIBLE.md`](../ART_BIBLE.md)：中央庭公共视觉以理性、秩序、重建、精密和可维护工程为核心。
- [`../COLOR_SYSTEM.md`](../COLOR_SYSTEM.md)：公共色值、面积关系和状态色边界。
- [`../MATERIAL_GUIDE.md`](../MATERIAL_GUIDE.md)：陶瓷装甲、涂层金属、雾银结构、强化玻璃、人居材料和神器接口的职责。
- [`../reference_library/moodboards/CENTRAL_COURT.md`](../reference_library/moodboards/CENTRAL_COURT.md)：公共资产的跨类型一致性与禁止方向。

中央庭公共层应先让人读出“可靠、可维护、能够长期应对异常的人类公共工程”，再在局部显露神器科学。角色个人色、神器使符号和剧情状态不得反向覆盖这套公共底座。

| 人居／注意 | 暖琥珀 | `#D39A55` | 门厅、生活区、维护与注意状态 | 2%–5% |

| 危险 | 危险暗红 | `#9E4651` | 损伤、污染和不可逆风险 | 常态小于 3% |

### 使用规则

1. 主色承担实体质量，辅助色说明受力、接口和可进入空间。
2. 冷青和天蓝首先是功能状态，不是装饰性霓虹。
3. 暖琥珀用于表明“这里有人生活、维护或通行”，不等于黄金神圣化。
4. 橙红和暗红必须依靠位置、节律和图标共同传递风险，不能持续覆盖整座设施。
5. 公共资产禁用大面积玫红、纯金、高饱和紫和无材质纯白；这些颜色不能靠换色方式伪装成中央庭风格。

## 3. 六类公共材质样本

### 3.1 深色陶瓷／复合装甲

- **职责**：主舰体、外墙、防护壳体和大型设备外罩。
- **颜色**：以 `#182630` 为主，用 `#304651` 分区；雾银只切分关键受力边。
- **表面**：低至中等反射，有大板层次和轻微方向纹理，不做纯黑吸光板。
- **通道提示**：Diffuse 负责大色块；Normal 负责有限接缝和板高；Specular 保持低至中等；Emissive 只出现在功能节点。
- **磨损**：仅在边角、维护口和高频接触区出现轻微使用痕迹，不做全舰锈蚀。

### 3.2 涂层金属

- **职责**：承重骨架、桥接梁、接口、散热和活动结构。
- **颜色**：石墨蓝灰或暖灰涂层，裸露金属只出现在滑轨、转轴、锁扣和维修边。
- **表面**：中等反射；拉丝方向必须服从加工和受力方向。
- **结构要求**：应看出连接、紧固和可更换性，不能成为无功能的银色装饰条。

### 3.3 雾银结构件

- **职责**：关键承力边、环体骨架、公共 UI 边框和高辨识节点。
- **颜色**：以 `#9BA8AE` 为主体，受光面可接近 `#D6D9D5`，但不得成为全镜面白银。
- **表面**：反射清楚但克制；面积始终小于主装甲。
- **阅读目标**：用于划分轮廓、说明厚度和提供尺度，不沿每条接缝平均描边。

### 3.4 强化玻璃与半透明聚合物

- **职责**：观察窗、实验隔离、公共空间和信息表面。
- **颜色**：深蓝灰基底上使用低饱和冷青／天蓝响应，透明区域不得依赖高亮白边才能辨认。
- **结构要求**：必须有厚度、夹层、固定件或实体边框；不允许无支撑的大面积透明承重件。
- **实现限制**：优先使用实体边框、假折射和局部高光；谨慎使用多层透明，以控制排序和过度绘制。

### 3.5 生活暖材质

- **职责**：门厅、医疗、居住、休息、公共服务和可进入空间。
- **颜色**：暖灰白为实体底色，暖琥珀只作为内照明和使用焦点；外部公共结构仍保持深蓝灰与雾银。
- **材质**：允许少量木、织物、磨砂聚合物和修补后的混凝土，以证明这是延续旧世界生活的人类文明。
- **边界**：不能把军用资产整体家居化，也不能把人居暖光误作金色宗教辉光。

### 3.6 受控神器接口

- **职责**：承载、观测、隔离并反馈神器规则，不代表神器本体可以量产。
- **三层比例**：工程承载层约 60%–75%；观测／接口层约 15%–25%；规则核心及异常视觉权重通常不超过约四分之一。
- **颜色**：公共工程框架使用深蓝灰与雾银；正常观测使用冷青／天蓝。角色个人色只有在明确归属时才能进入局部规则核心。
- **结构**：实体框架、有限悬浮或错位接口、面积最小但视觉权重最高的规则核心。
- **禁止**：不默认使用紫色水晶、完整魔法阵、全息圆环或无来源圣光；圆环只在确有观测、隔离、对接或稳定功能时出现。

## 4. 状态校准

| 状态 | 主材质变化 | 发光变化 | 不应出现 |
| --- | --- | --- | --- |
| 新建／校准 | 接缝清楚、加工痕迹轻微 | 低亮冷青状态点 | 全表面高亮描边 |
| 正常运行 | 大色块稳定、功能区清楚 | 冷青／天蓝沿明确路径 | 无功能霓虹网格 |
| 维护／长期使用 | 局部替换板、轻微磨损 | 暖琥珀维护点 | 全资产锈蚀和废墟滤镜 |
| 警戒／隔离 | 主材质保持可读 | 橙红短促节律、暗红危险节点 | 整体持续染红 |
| 神器启动 | 工程外框仍占主体 | 接口和核心短时增强 | 实体结构被粒子完全吞没 |
| 过载／终局 | 局部相位或材料异常 | 峰值短时出现后回落 | 永久白热化和满屏特效 |

## 5. 跨资产应用

- **舰船**：深色陶瓷／涂层金属构成主舰体，雾银说明骨架和接口，玻璃及功能灯只占少量焦点。
- **建筑与区划**：保留入口、交通、疏散和公共服务；地面设施可加入修补混凝土、旧砖石和替换式金属板。
- **科研设施**：普通仪器占主体，神器接口只集中在隔离、观测和核心区。
- **UI 与图标**：深蓝灰底、雾银边、冷青正常态、琥珀注意态、暗红危险态；图标只模拟必要的材料错觉。
- **角色专属资产**：本板只提供 60%–75% 的中央庭工程底座，个人颜色、器物和特效必须另查角色风格页。

## 6. 使用前检查

- [ ] 关闭所有发光后，仍能区分主装甲、结构边、玻璃和接口。
- [ ] 主材质色承担至少 70% 的常态识别。
- [ ] 雾银没有沿全部接缝平均描边。
- [ ] 冷青发光对应导航、能源、扫描、隔离或稳定状态。
- [ ] 暖琥珀只出现在人居、维护或注意位置。
- [ ] 警戒色在常态下保持小于约 3% 的注意力占比。
- [ ] 神器异常被实体工程框架约束，未变成通用魔法效果。
- [ ] 近景、游戏常用距离和战略缩放下都保留材料层级。
- [ ] 本校准板没有被直接导入 `mod/gfx` 或冒充正式游戏贴图。

## 7. 版本边界

本版确认的是公共色值、材料职责和状态关系，不冻结：

- 某一舰种的精确贴图密度与三角面预算；
- 角色个人色、神器本体色或剧情特殊状态；
- 不同星球环境下的最终曝光和色温；
- Stellaris 游戏内最终 Specular、Normal、Emissive 参数。

上述内容必须在代表性舰船、建筑、UI 和图标样本中继续做游戏内校色。
