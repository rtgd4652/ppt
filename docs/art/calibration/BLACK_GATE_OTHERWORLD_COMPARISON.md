## 1. 对照目标

本对照组回答五个容易混淆的问题：

1. 黑门本体是什么；
2. 黑雾与环境污染是什么；
3. 异界内部与异界生态可以如何表现；
4. 中央庭的观测、隔离和稳定设备与异常本体有何区别；
5. 《群星》星界间隙只能提供哪些实现方法。

黑门的身份依据来自原作世界观：它是现实世界与另一世界发生融合、两个世界的次元相互撞裂后形成的**黑色空间裂缝**。黑核是产生黑门的能量核心。黑雾、怪物、环境停滞和能量流失是黑门影响现实的结果，不应全部画成“门”本身。

## 2. 五层正式区分

| 层级 | 原作证据边界 | 正式视觉结论 | 禁止误读 |
| --- | --- | --- | --- |
| 黑门入口 | 黑色空间裂缝；大规模状态可撕裂天空、像黑幕向下吞噬 | 以**不连续边界、吞光内部、方向冲突和现实切面**为核心；不强制标准圆形 | 普通虫洞、霓虹圆门、紫色星云旋涡 |
| 黑核 | 产生黑门的能量核心；剧情中可表现为悬浮黑色晶体 | 体量小、密度高、边界明确，是异常的“源点/核心”而不是装饰矿石 | 将所有异界材质统一为紫水晶；把黑核铺满环境 |
| 黑雾与环境响应 | 黑门释放黑雾与怪物；建筑可像被冻结在异空间，空气与环境发生异常 | 低对比黑雾用于遮断连续空间；环境表面出现失焦、错位、能量抽离或局部相变 | 随机烟雾贴片、全屏黑滤镜、只有颜色变化没有环境关系 |
| 异界内部／生态 | 原作确认异世界及其怪物存在，但本轮尚未核准一套可覆盖全部异界的固定生态外形 | 每个区域应建立自己的运动和生存逻辑；共享的是“与现实规则不完全兼容”，不是共享某种器官或颜色 | 全部触手、眼睛、牙齿、紫晶；把一个区域外形扩展为全部异界 |
| 中央庭工程响应 | 观测、隔离、净化与稳定属于人类设备和行动 | 使用可读框架、传感器、隔离层、警示灯与稳定锚；工程结构必须与异常分层 | 把观测站图标的紫色门形当成黑门本体；让异常完全服从机械框架 |

## 3. 状态序列

### 3.1 稳定前兆

- 正常城市结构仍占画面主体；
- 局部空气、反射或透视先发生迟滞；
- 声光反馈应克制，避免在异常出现前就用终局级粒子覆盖场景。

### 3.2 门体形成

- 现实边界被切断，而不是在现实表面贴上一张彩色圆盘；
- 黑门内部可以吞光，边缘可出现少量不自然亮边，但不做连续均匀霓虹描边；
- 门形允许纵向撕裂、天幕式扩展或不闭合轮廓，具体形态必须与场景和剧情状态对应。

### 3.3 黑雾扩散

- 黑雾先影响空间连续性和环境可读性，再影响颜色；
- 建筑、道路、灯光和角色应表现出被隔离、冻结、失焦或抽离能量的响应；
- 黑雾运动不能与普通火焰、蒸汽或宇宙星云完全相同。

### 3.4 异界侵入

- 怪物、局部生态和非现实结构进入城市时，必须保留“城市现实—异常边界—异界对象”三层关系；
- 不允许只画一片奇幻背景，使观众无法判断侵入发生在哪里；
- 不同异界对象可以有不同材质家族，但运动规律和能量关系必须在同一场景内自洽。

### 3.5 稳定／关闭

- 人类工程先建立边界、读数和安全区；
- 异常亮度、黑雾覆盖和错位逐步收束；
- 结束阶段保留短暂残余，例如边缘错位、落尘或低亮读数，不以一次全屏白闪替代过程。

## 4. 与《群星》星界间隙的关系

《群星》星界间隙只用于学习：

- 战略地图和场景镜头中的尺度提示；
- 入口、背景、交互目标和 UI 的分层；
- 粒子生命周期、遮挡、LOD 与性能控制；
- 玩家如何识别“可探索异常”。

它不能决定：

- 黑门的颜色和门形；
- 异界生态的具体外观；
- 黑门与交界都市的历史语义；
- 本项目的角色、符号或神器结构。

尤其禁止把《群星》虚境常见的高饱和紫、闪电云、灵能符文直接套用为黑门默认样式。
