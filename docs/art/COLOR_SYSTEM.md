# 《神器使》Mod 颜色系统 v0.1

> 本文定义跨资产的颜色职责，不把单张图的取色直接升级为全文明标准。
> 中央庭色值已由 [`calibration/CENTRAL_COURT_MATERIAL_CALIBRATION.md`](calibration/CENTRAL_COURT_MATERIAL_CALIBRATION.md) 与配套 SVG 建立项目校准基线；角色色在原作锚点未审核前只定义关系、比例与用途，不虚构精确色值。

## 1. 使用原则

1. **颜色先说明归属**：公共结构、功能状态、神器异常、角色签名、剧情状态不得混为一层。
2. **颜色必须有功能**：正常、警戒、危险、可交互、激活和失控应可区分。
3. **不以颜色单独传达信息**：同时使用轮廓、图标、线型、明暗或运动区别状态。
4. **发光面积小于实体面积**：常态下仍能读出材质和结构。
5. **角色签名不反向覆盖文明**：个人颜色只进入专属模块、界面或短时特效。
6. **精确色值需要校色**：在宇宙黑背景、星云、恒星附近、事件 UI 与中文界面中分别测试。

## 2. 中央庭公共色板

### 2.1 核心色

| 色名 | 建议值 | 主要用途 | 禁止用途 |
| --- | --- | --- | --- |
| 深海军蓝 | `#182630` | 舰体大面、建筑骨架、UI 大底 | 不做无高光的纯黑吸光板 |
| 石墨蓝灰 | `#304651` | 次装甲、模块分区、面板 | 不与冷青读数混成同一亮度 |
| 暖灰白 | `#D6D9D5` | 公共内装、医疗／庇护、文字高亮 | 不做全屏圣光或无材质纯白 |
| 雾银 | `#9BA8AE` | 承力边、接口、边框、结构切面 | 不沿所有接缝平均描边 |
| 冷青 | `#69C1CC` | 正常读数、导航、稳定能源线 | 不把全部舰体做成霓虹网格 |
| 低饱和天蓝 | `#79AFC7` | 科研、扫描、辅助信息 | 不与角色蓝色签名混为同一层 |
| 暖琥珀 | `#D39A55` | 人居灯光、维护、注意状态 | 不当作全文明金色装饰 |
| 警戒橙红 | `#D0644D` | 警告、过载、隔离倒计时 | 常态占比不得超过约 3% |
| 危险暗红 | `#9E4651` | 损伤、污染、不可逆风险 | 不持续覆盖整座设施或整艘舰 |

### 2.2 推荐面积关系

- 深海军蓝／石墨蓝灰：45%–60%；
- 暖灰白／雾银：20%–30%；
- 冷青／低饱和天蓝：5%–10%；
- 人居暖琥珀：2%–5%；
- 警戒与危险色：常态小于 3%，危机镜头可临时提高。

该比例适用于公共舰船、建筑和 UI 的整体注意力，不要求每个图标机械照搬。

本表是配色职责；跨材质、状态和通道的完整用法以中央庭公共材质校准板为准。校准板不是正式游戏贴图，最终曝光仍需在《群星》场景中复测。

## 3. 神器科技颜色

神器科技不设单一“神器紫”。其颜色由三层组成：

| 层级 | 颜色来源 | 说明 |
| --- | --- | --- |
| 工程外框 | 中央庭公共色 | 占主要面积，保证可维护与文明连续性 |
| 观测／稳定接口 | 冷青、冰蓝、中性白 | 表示已校准、可观测、受控，不代表神器本体固有色 |
| 规则核心 | 对应神器／角色专属色 | 面积小、识别强，只在有明确对象时启用 |

### 3.1 状态色

- 休眠：低亮蓝灰，核心不持续发光；
- 校准：冷青分段点亮，轨迹逐步闭合；
- 稳定共鸣：中性白核心 + 对应角色签名色；
- 警戒：暖琥珀，工程框先响应；
- 过载：橙红／暗红断续，角色色出现偏色或错位；
- 污染／规则失配：由对象决定，必须同时出现边界、线型或运动异常，不能只换成紫色。

## 4. 核心神器使颜色

### 4.1 爱缪莎

#### 颜色关系

| 颜色 | 角色用途 | 舰船用途 | UI／技能用途 | 限制 |
| --- | --- | --- | --- | --- |
| 黑 | 礼装轮廓、牌面、稳定暗部 | 阴影缝、局部深色实体 | 深色牌面／负形 | 不能吞掉发丝与服装层次 |
| 深玫红／酒红 | 人物识别、服装节奏 | 少量判定节点、专属模块 | 因果改道、选择峰值 | 不覆盖所有武器和推进器 |
| 暗紫 | 礼装次层、神秘感 | 接缝或投影暗层 | 概率背景、非主信息层 | 不等同神器默认色 |
| 暖金 | 金发、牌边、饰件 | 极少关键节点 | 判定点、星点、稀有强调 | 不扩展成纯金神船 |
| 月白／冷白 | 皮肤／透明层平衡 | 主束、环体高光 | 观测线、终局短峰值 | 不持续全屏过曝 |
| 冰蓝／冷青 | 非原作公共层 | 中央庭工程底座、常态能源 | 数据、观测、稳定态 | 不取代玫红与暖金签名 |

#### 比例

- 角色基础形态：黑与暗紫 35%–45%，深玫红／酒红 20%–30%，金发与暖金 15%–25%，暖白／肤色／透明纱 10%–20%；
- 星海资产：公共深蓝灰／银白占实体主体，爱缪莎签名色只占个人层；
- 终局：增加冷白和星际蓝，但必须保留黑／暗紫、玫红、金发红瞳的连续识别。

> 精确角色色值待原作锚点完成来源和显示校准后补充；当前不得从生成图或单一皮肤直接固化 HEX。

### 4.2 安托涅瓦

以下是**星海时代转译关系**，不是对原作固有服装色的替代声明。

| 颜色 | 用途 | 叙事含义 | 限制 |
| --- | --- | --- | --- |
| 低饱和深蓝灰／雾蓝 | 方舟外层、空间深度 | 稳定、克制、可持续庇护 | 具体色相待原作锚点核验 |
| 暖白 | 安全内腔、人物温度 | 生命可以停留的空间 | 不做无菌医院或神圣白光 |
| 冷银 | 门框、锚点、承力边 | 工程边界、可靠锁止 | 不铺满所有边缘 |
| 浅水蓝／冰青 | 稳定空间边界 | 坐标对齐、可通行状态 | 不做冰晶宫殿 |
| 纸张米白／灰金／黄昏琥珀 | 书页、生活舱、被保护者 | 日常、希望、远方 | 只作少量人性温度 |
| 暗红 | 破损边界、疏散警报 | 容量和保护的风险 | 不染红整个方舟空间 |

> 安托涅瓦基础外貌、服装和固有色仍需 `REF-OG-ANTONIVA-001/002` 核验。正式角色立绘不得仅依赖本表确定颜色。

## 5. 专题颜色

### 5.1 旧世界回声

- 基底：煤灰、灰褐、旧纸米白、褪色蓝灰；
- 历史层：氧化铜绿、暗锈红、旧胶片棕、低饱和靛蓝；
- 生活记忆：少量褪色暖黄、旧粉、校服蓝或城市霓虹残色；
- 异常残想：低亮冷白、偏青灰或局部反相色；
- 金色只用于确有来源的金属、标签焦点或对象，不统一包装为宝藏。

### 5.2 黑门与异界

- 主体：近黑、煤灰、深石油蓝绿；
- 边界：病态珠白、冷青灰、低饱和绿蓝；
- 污染：暗锈红、褐红或有具体生态理由的颜色；
- 紫色：仅为受伤、干扰或某一异界层的局部色，不是默认主色；
- 中央庭观测叠层：冷青读数、琥珀警戒、暗红隔离，与现象本体明确分层。

黑门、黑核、黑雾、异界生态与中央庭工程响应不得用同一色板合并。正式边界见 [`calibration/BLACK_GATE_OTHERWORLD_COMPARISON.md`](calibration/BLACK_GATE_OTHERWORLD_COMPARISON.md)。

## 6. 资产类别用色

### 6.1 舰船

- 大面依赖明度和材质分区，不依赖满舰发光；
- 推进、导航、武器和角色签名不能全部使用同一颜色；
- 远景至少保留舰体、推进和一处阵营识别的三层亮度；
- 英雄舰可提高个人色比例，普通舰不得继承终局色效。

### 6.2 建筑与区划

- 城市／区划先按功能和环境区分，再叠加公共色；
- 农业、生活、工业、科研不可只靠滤镜换色；
- 人居暖色集中在入口、窗与活动空间；
- 异常色集中在具体设备，不覆盖整片地表。

### 6.3 UI 与图标

- 背景、主体、状态和边框至少有四级明度；
- 正常／警告／危险同时使用颜色与形状；
- 角色图标保留角色色，但边框与交互态服从公共 UI；
- 发光不超过主体轮廓，缩小后仍能分清主物件。

### 6.4 粒子

- 充能色说明来源，发射色说明武器，命中色说明作用对象；
- 峰值可短暂变白，不能从头到尾纯白；
- 余波降低饱和与亮度，不能留下与常态灯混淆的残光。

## 7. 校色与验收

每组颜色至少在以下条件截图对比：

- 黑色宇宙背景；
- 蓝／紫／金色星云；
- 明亮恒星附近；
- 《群星》100% 与常见 UI 缩放；
- 32、48、64、128 像素图标；
- 色觉缺陷模拟或灰度检查；
- 一支普通舰队与多艘同类资产同时出现。

通过标准：不开 bloom 仍能读出结构；开启 bloom 不吞轮廓；转灰度后仍能区分层级；个人色不会让公共资产误认成另一角色专属资产。
