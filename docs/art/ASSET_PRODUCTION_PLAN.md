更新：2026-09-26。本文登记需求、依赖与下一步，不把尚未制作的资源写成已有资产。实际资产身份、来源和审核继续维护在 [ASSET_REGISTRY.csv](ASSET_REGISTRY.csv)；本表通过资产 ID 关联，不重复维护其来源结论。

## 状态与交付规则

- `已有待验收`：存在已登记资源，仍需来源、规格或游戏表现验收。
- `待盘点`：已明确需求，但尚未逐一验证是否有可复用的独立成品。
- `待制作`：既有文档明确记录缺失，尚未制作正式资源。
- `待专项设计`：职责已确认，具体形式、数量和方案仍待相应审核。
- `遗留待处置`：只针对现有原型兼容，不自动进入 1.0 正式生产。

每项进入制作前记录负责人或工作任务、来源／资产 ID、游戏尺寸与通道规格、制作路径、审核依据和验收报告；没有核验的字段保持待定。进入正式 `mod/` 后才追加或更新实际资产登记。公共校准规则与已批准角色识别锚点继续有效，不因本表重复开启基础设定审核。
