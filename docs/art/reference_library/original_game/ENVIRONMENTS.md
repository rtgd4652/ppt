## 文档用途

本页覆盖剧情 CG、交界都市地区、中央庭/白夜馆/研究所等机构，以及黑门与异界环境。目标是提炼空间组织、地域气质、尺度与光影规律，不直接复刻原作场景图。

## 必收分类

| 子分类 | 建议关注 | 不应推导 |
| --- | --- | --- |
| 剧情 CG | 人物与环境关系、镜头叙事、危机尺度、情绪光影 | 把一次性剧情构图当作日常建筑规范 |
| 交界都市地区 | 城市层级、旧城与新城差异、道路、公共空间、生活痕迹 | 把一个地区的地方符号推广到全城或星际文明 |
| 中央庭 | 危机协调、行政与军事秩序、公共识别 | 把中央庭做成单纯宗教宫殿或纯军事堡垒 |
| 白夜馆 | 访问、档案、记忆与角色交流的舞台 | 把白夜馆误写成中央庭或独立政治势力 |
| 研究所/高校/教会等机构 | 各自功能和组织气质 | 用同一套高塔、徽记和发光覆盖所有机构 |
| 黑门与异界 | 规则不兼容、空间破裂、污染边界、异界生态 | 直接套用通用紫色传送门或《群星》虚境外观 |

## 单张环境参考的分析模板

每个条目至少回答：

- 画面属于日常、灾害、回忆、幻觉还是特定结局？
- 可辨识的建筑类型、交通、植被、地形和城市密度是什么？
- 主光源、辅光源、雾和异常发光分别来自哪里？
- 哪些元素是机构或地区的稳定识别，哪些只是镜头装饰？
- 转译到星际时代时，应保留空间关系、功能逻辑还是材质关系？
- 哪些标识、角色、具体建筑外观或剧情构图不可直接复制？

## 地区转译原则

- 中央城区可提供高密度交通、公共基础设施和中央节点的尺度参考，但不能只保留高楼霓虹。
- 东方古街、旧城区等地区应保留生活性、历史层积和非均质街区，不应变成统一“东方古风”贴皮。
- 海上研究所可学习离岸设施、功能分区和水体关系，不应直接复制其标志性建筑。
- 高校学园可学习公共轴线、院落与教学/研究空间关系，不应把校园符号用于军事设施。
- 中央庭公共风格应从多张机构与地区参考交叉提炼，不能由爱缪莎或任何单一角色的个人视觉决定。

## 黑门与异界

黑门参考应拆成至少四种视觉层：

1. 门体或空间缺口的几何边界。
2. 边界附近的材质、重力、光线或透视异常。
3. 污染、怪物或异界生态的局部响应。
4. 城市、舰船和人员对异常的工程化应对。

可学习的是空间不连续、环境规则冲突与局部危险层级；不可复制的是其他作品的门形、怪物轮廓、纹章与专属色彩方案。登记时必须注明它与 `OTHERWORLD_AND_ASTRAL_RIFTS` Moodboard 的关系，并明确区别于单一紫色烟雾加闪电的虚境模板。

## 剧情状态边界

- 特定结局、梦境、记忆殿堂或被覆盖世界线的画面必须在 `notes` 中标明状态。
- 低饱和、噪点或失真可能属于记忆叙事，不应自动成为所有正式场景的后期滤镜。
- 灾害场景中的破损、警戒灯和撤离设施可用于危机版本，但不能覆盖日常城市版本。
- CG 中为突出角色而夸张的尺度、光源和构图，只能作为 `composition_reference`，不能直接用作关卡或建筑尺寸。

## 从参考到正式资产

环境参考不得自动复制到 `mod/gfx/event_pictures`、行星背景或建筑纹理。正式资产应是项目自制重绘、重新建模或经过明确授权的资源，并在 `ASSET_REGISTRY.csv` 中记录转化方式。若只从原作图提取了道路密度、空间层级或冷暖关系，也要把这种“抽象规律提取”写明。
