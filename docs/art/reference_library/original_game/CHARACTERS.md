# 原作角色视觉参考

## 文档用途

本页规定角色基础立绘、觉醒立绘、皮肤与神器外观参考的收集和分析方法。这里记录的是“视觉依据”，不是可直接进入游戏的资产。所有图片条目必须先进入 `REFERENCE_MANIFEST.csv`；若将参考转化为正式立绘、模型或图标，还要以新的资产身份登记到 `ASSET_REGISTRY.csv`。

## 当前仓库审计

- `assets/official_reference/` 与 `assets/portrait/` 目前只有占位文件，没有形成可审核的原作参考集。
- `mod/gfx/models/portraits/` 已有爱缪莎基础、城市背景、30 级等 PNG/DDS 及裁切版本。这些位于游戏正式资源路径，不能因为“看起来像原作”就反向充当来源、授权或参考登记证据。
- `docs/design/aemusa_main_route_v0.1.md` 明确区分基础形态、30 级觉醒/成神立绘及终局路线；参考登记也必须保留这种状态差异。
- `docs/design/white_night_hall_leaders_v0.1.md` 已整理安托涅瓦、爱缪莎、晏华、赛斯、幽桐、拉比和格蕾莎的神器与能力关键词，可作为选图优先级，但不能代替图片来源。

## 必收分类

| 子分类 | 主要用途 | 登记时必须回答的问题 |
| --- | --- | --- |
| 角色基础立绘 | 锁定日常形态和最低识别线 | 哪些轮廓、发型、面部、服装结构和随身物不可改变？ |
| 角色觉醒立绘 | 区分成长阶段与终局状态 | 哪些变化属于觉醒，哪些仍需保留基础形态识别？ |
| 角色皮肤 | 补充材质、服装和情绪变化 | 哪些元素只属于特定皮肤，不能提升为角色常驻设定？ |
| 神器外观 | 建立神器与能力的形状语言 | 神器本体、能量现象和装饰符号分别是什么？ |
| 角色局部与转面 | 发型、饰件、武器和建模校准 | 是否能支撑侧面、背面或三视图判断，还是只有正面推测？ |

每张参考至少在 `what_to_learn` 与 `what_not_to_copy` 中写清以下四层：

1. 不可改变的角色识别核心。
2. 可以转译到星海时代的抽象规律。
3. 只属于特定皮肤、剧情或觉醒状态的元素。
4. 不能扩展成中央庭或整个文明公共风格的个人符号。

## 爱缪莎锚点

可学习且值得保留：

- 金色超长单马尾形成的纵向动势与远距离识别。
- 黑、玫红、暗紫与少量金色构成的基础配色关系。
- 星星、月牙和命运轨迹，优先作为轮廓、路径或光效，不作为满面贴花。
- 轻盈、华丽、神秘的占卜师气质。
- 卡牌作为命运术式媒介，而不是通用装甲板。

允许进行的星海转译：

- 把月牙和轨迹转为舰体负空间、环形投影或开火路径。
- 把玫红/暗紫用于角色专属强调色、局部能量或 UI 状态色。
- 把卡牌转为短时粒子投影、命运计算界面或战斗技能提示。
- 用高低饱和比例区分基础、觉醒和终局形态，而不是只靠堆叠发光。

不得误读：

- 整个文明都是塔罗牌主题。
- 所有爱缪莎资产都必须覆盖大量卡牌。
- 基础形态等同于纯金白太阳神。
- 所有命运武器都使用满屏高饱和玫红。
- 觉醒后可以删除发型、神态、月牙或命运媒介等人物识别核心。

## 安托涅瓦锚点

参考重点应围绕方舟、空间容纳、保护与冷静的秩序感建立：

- 不可替换核心由经审核的基础与觉醒立绘共同确认，不得只凭二手描述补画。
- 方舟应优先转译为包覆、容纳、折叠空间和安全航道，而不是普通蓝色传送门。
- 蓝、白、银可作为路线主关系，但需要以原作参考确认具体色相和比例。
- 角色个人的方舟符号不得自动扩展为全部民用建筑或全部中央庭舰船。
- 与爱缪莎路线的差异应体现在“保护/容纳”对“观测/干涉”，而不只是蓝色对玫红色。

## 其他角色的最低分析要求

- 晏华：荷鲁斯之眼与弱点识破应转译为观察、瞄准和结构暴露；不得把眼睛图案铺满舰体。
- 赛斯：羽蛇神杖与微小愿望强调稳定、温和支援；不得扩展为泛用宗教金光。
- 幽桐：神弓与自我束缚强调蓄势、张力和精准；不得把所有远程武器都做成弓形。
- 拉比：阿米特与善恶判别强调审视和压制；不得借用现实宗教审判符号替代原作识别。
- 格蕾莎：安卡与生命力强调维持、庇护和有机节律；不得把所有生命技术都统一成绿色水晶。

## 选图与裁切规范

- 每名核心角色优先建立一张 `primary_anchor`，其余基础/觉醒/皮肤图作为 `secondary_reference`。
- 同一张大图的脸部、神器与服装局部可用同一 `source_locator` 建立多个分析条目，但必须注明裁切范围，不得伪装为不同来源。
- 只有单一角度时，在备注中标记“背面/侧面未知”；AI 或建模人员不得把推测写回为原作事实。
- 若图片包含水印、平台 UI 或裁切缺失，保留来源信息，不以清理水印的版本替代来源文件。
- 授权不明的图片可存入本地不跟踪目录进行审核，但不得进入 Git；登记状态保持 `unknown` 或 `external_reference_only`。

## 从参考到正式资产

角色参考可以支持原创重绘、重新建模或抽象规律提取，但不能直接从本页复制进 `mod/gfx`。进入正式资产库前必须说明：是否原创重绘、是否重建三维结构、是否只提取了抽象规律、是否已完成来源与授权审核，并通过角色识别度与小尺寸头像可读性检查。
