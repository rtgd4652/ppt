# 原作神器、技能与战斗特效参考

> 涉及黑门和异界时，先按 [`../../calibration/BLACK_GATE_OTHERWORLD_COMPARISON.md`](../../calibration/BLACK_GATE_OTHERWORLD_COMPARISON.md) 区分入口、黑核、黑雾／环境响应、异界生态和人类工程层，避免把单个剧情特例扩展成统一黑门样式。

## 文档用途

本页用于整理神器显现、技能、战斗、黑门和觉醒演出的关键帧。目标是提炼形状、颜色、时间和空间行为，不复刻原作序列帧或直接抽取特效贴图。

## 当前仓库审计

- 当前 `assets/` 中未发现独立整理的原作技能、神器或黑门特效截图集。
- `mod/gfx/models/ships/destiny_lord/_destiny_lord_entities.asset` 调用了《群星》现有效果作为舰船核心光、环形灯和推进器。这是正式实现依赖，不是原作特效参考。
- `mod/gfx/interface/icons/ship_parts/` 中的武器与部件图标属于正式 UI 资产，不能替代真实的开火、飞行和命中表现参考。

## 必收分类

| 子分类 | 建议帧位 | 主要分析 |
| --- | --- | --- |
| 神器显现 | 出现前、成形、稳定、消散 | 本体与投影边界、召唤路径、持续发光 |
| 普通技能 | 起手、释放、命中、余波 | 读招轮廓、速度、作用范围、反馈强度 |
| 终结/觉醒技能 | 蓄力、展开、峰值、回落 | 层级提升、角色识别保留、镜头依赖 |
| 防御/庇护 | 成形、受击、破裂、恢复 | 表面结构、厚度感、受力反馈 |
| 黑门与异界 | 稳定、扰动、污染扩散、关闭 | 空间不连续、环境响应、危险边界 |
| 状态与治疗 | 施加、持续、结束 | 正负状态辨识、与武器特效区分 |

## 单条参考的分析字段

- 形状：点、线、面、体、环、轨迹、碎片或空间切面。
- 色彩：主色、峰值色、暗部色与背景适配；避免只记录“紫色”“蓝色”。
- 时间：预警、蓄力、峰值、余波各占多长比例。
- 动势：直线、弧线、旋涡、折返、瞬移、扩散或收束。
- 材质错觉：等离子、玻璃、尘埃、液态光、裂隙、投影或实体碎片。
- 角色识别：哪些节奏或符号只属于某名神器使。
- 转译目标：舰炮、光环、建筑循环、事件演出、UI 状态或巨构动画。

## 可学习内容

- 爱缪莎的卡牌更适合作为短时命运媒介、轨迹节点或投影界面；星月与轨迹可以决定运动路径。
- 安托涅瓦的方舟效果应体现容纳、包覆、坐标校准和空间折叠，不应只是换色传送门。
- 神器技术的公共层应表现“普通工程结构承载超常规则核心”，个人特效只在专属资产上加强。
- 黑门应通过边界、透视、光线和环境反应呈现规则不兼容，不靠单一高饱和紫色烟雾完成。

## 不可直接复制

- 原作序列帧、贴图图集、音画同步素材和完整技能动画。
- 其他作品的魔法阵、符文、角色标志或标志性弹道。
- 把终结技的大面积屏幕效果用在普通舰船每次攻击上。
- 把所有神器技术统一成紫色水晶、同一圆环或同一粒子噪声。
- 为了保留二维演出而在三维战场生成大量始终朝向镜头的复杂卡牌面片。

## 《群星》转译与性能边界

- 优先用少量清晰的发射点、主弹道和命中反馈；远景下看不见的内部纹样应删除。
- 将持续高亮尽量放入 emissive 贴图，粒子保留给运动、峰值和环境交互。
- 同一舰队大量并发时，普通武器不得使用终局级粒子数量、长寿命拖尾或大范围屏幕闪光。
- 透明叠层、全屏混合和交叉面片容易产生过度绘制；参考分析必须提出可降级版本。
- 每个效果至少规划“普通远景”“英雄单位近景”两个强度档，巨构循环另设更慢、更低频的档位。
- 关键帧参考不能替代运行测试；正式效果需在黑色宇宙、星云、明亮恒星和大规模战斗中检查可见性。

## 从参考到正式资产

原作视频或截图只进入参考登记。新制作的粒子定义、贴图、动画、定位器与材质必须作为项目原创或明确授权资产重新登记；若只提取了“先收束后展开”“月牙路径”“空间边界错位”等规律，应在资产登记中明确写为抽象视觉规律。
