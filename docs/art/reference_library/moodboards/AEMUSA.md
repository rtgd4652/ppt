# AEMUSA｜爱缪莎视觉锚点

> 状态：v0.1 工作版。本文区分角色识别核心、皮肤/剧情状态和星海时代转译。现有本地图册只能作为待核验候选参考；其文件来源、具体形态名称与授权状态必须在 `REFERENCE_MANIFEST.csv` 中逐项确认。

## 1. 目标描述

锁定爱缪莎在角色立绘、通讯、图标、命运科技和终局资产中的连续识别度，并明确基础形态与命运主宰阶段的差异。她的核心是“以计算和牌局观察可能性、却不向既定命运屈服的人”，不是抽象的塔罗文明或失去人性的科技神。

核心判断：**无论规模扩大到角色、舰船还是巨构，先保留爱缪莎的轻盈、华丽、从容和选择意识，再增加星海尺度。**

## 2. 核心关键词

- 金色超长单马尾
- 红瞳与从容神态
- 黑、玫红、暗紫、金
- 月牙与星点
- 命运轨迹
- 卡牌作为术式媒介
- 计算内的运气
- 轻盈华丽
- 游戏感而非宗教感
- 看见未来但保留选择

## 3. 推荐色彩

### 基础形态

- 黑与暗紫：35%–45%，承担礼装阴影、牌面和稳定轮廓。
- 深玫红/酒红：20%–30%，承担人物识别和动作节奏。
- 金发与暖金：15%–25%，用于最强人物识别，不等同于全身金色装甲。
- 暖白/肤色/透明纱：10%–20%，平衡深色与华丽感。
- 高饱和玫红只用于短轨迹、牌面激活或局部攻击峰值。

### 星海时代与终局形态

- 公共工程载体仍使用中央庭深蓝灰、银白与冰蓝；爱缪莎色作为个人层叠加。
- 终局可增加冷白、星际蓝和低亮度金色，表达尺度与计算展开，但必须保留黑/暗紫、玫红以及她本人的金发红瞳识别。
- 禁止把终局形态洗成纯金白太阳神，也禁止用满屏玫红代替层级。

## 4. 推荐形状

- 人物首要剪影：超长单马尾形成大弧线，纤细躯干与轻盈不对称礼装形成次轮廓。
- 月牙用于局部切口、护边、构图负形；星星用于离散焦点，不铺成均匀纹样。
- 命运轨迹表现为细而有方向的弧线、概率分叉和不完全闭合的环。
- 卡牌应是离散、可数、可读方向的媒介：手持、环绕、翻转或沿轨迹展开，而非装甲贴花海。
- 角色背景可用少量星盘与观测线，但要为人物动作和视线留出干净负形。
- 星海资产可将月牙转译为翼缘/投射框，将轨迹转译为粒子投影，将卡牌转译为有限数量的运算界面。

## 5. 推荐材质

- 角色：黑色缎面、暗紫织物、玫红礼装层、透明薄纱、少量金属金边、漆面卡牌。
- 卡牌：深色硬质牌面、金色细边、清楚的大符号；牌面细节在远景应简化。
- 科技转译：深色陶瓷舰体、雾银结构、半透明投影面、细金边与局部玫红发光。
- 终局外层可以出现“非实体星轨/薄膜投影”，但人物或舰体的主要承重结构必须保持实体材质。
- 乐器、骰子、特定花饰等若来自某一皮肤，只能作为该形态专属材质和道具，不上升为全角色固定语法。

## 6. 推荐光效

- 基础光效由稀疏金色星点、短玫红轨迹、牌缘亮线和柔和月光组成。
- 卡牌激活应有顺序：定位、翻面、符号亮起、轨迹连接；避免所有牌同时爆亮。
- 命运观测偏细、慢、冷静；因果干涉才允许轨迹突然改道、分支折返或局部玫红增强。
- 终局光效应把实体和投影分开：舰体/人物保持可读，星轨、月环和概率分支悬浮在外层。
- 终局峰值可短暂使用冷白主光 + 玫红/金色边缘，但结束后迅速回落，不能持续遮蔽模型。

## 7. 可学习元素

- 从待核验基础/觉醒候选图学习金色超长单马尾、红瞳、黑玫红暗紫金配色、月星牌阵和轻盈构图。
- 从不同服装候选图学习“角色换装后仍能通过发型、姿态、配色节奏被认出”，而不是把每套衣服的道具都混合到一起。
- 从卡牌动态参考学习离散牌面、翻转方向、轨迹层级和手势之间的因果关系。
- 旧 Stage 9 舰体已经退出命运之主设计，只能保留 Blender、LOD、PDX 导出和游戏内尺度经验；不得再从其环体、翼面或现有材质推导爱缪莎专属舰。
- 从《群星》学习角色图标、舰船远景和武器特效的实际可读尺度。

## 8. 禁止元素

- 把整个中央庭文明改成塔罗牌文明，或让所有公共资产覆盖星月牌面。
- 所有爱缪莎资产都堆满大量卡牌，导致角色、舰首和武器功能不清。
- 把基础爱缪莎画成纯金白太阳神，或用圣洁、庄严、无情取代她的游戏感与人性。
- 命运之主采用“塔罗牌装甲化”：把牌面直接拼成舰壳、翼板或炮塔。
- 所有命运武器都使用满屏高饱和玫红、巨大魔法阵和长时间过曝。
- 将某一皮肤的竖琴、骰子、花束、帽子或特定服装固定为所有形态共有元素。
- 成神后改变发色、瞳色、基本体态或气质到无法辨认原人物。
- 将“看见命运”误画成绝对全知、强制服从或压倒他人的神权符号。

## 9. 与中央庭公共风格的关系

- 爱缪莎是中央庭文明中的重要个体，不是公共美术的唯一源头。
- 角色立绘以个人原作识别为主；舰船、建筑和 UI 则必须先保留中央庭工程底座，再叠加爱缪莎签名。
- 普通命运科研设施建议约 70% 公共结构、20% 命运专业结构、10% 爱缪莎个人符号。
- 未来经重新批准的爱缪莎终局唯一资产可以提高个人层到 25%–35%，但推进、装甲、模块和尺度仍须符合人类工程逻辑。
- 她与安托涅瓦的差异：爱缪莎强调概率轨迹、外向展开和华丽干涉；安托涅瓦强调内部容纳、边界保护和克制希望。

## 10. 适用资产范围

- 爱缪莎基础、觉醒、皮肤与终局立绘的审核
- 头像、通讯图、招募图、个人档案与专属 UI
- 塔罗/命运科技、飞升、特质、遗珍和组件图标
- 命运观测、抽牌、因果干涉与开火特效
- 未来从零重设的命运之主唯一舰船
- 未来从零重设的命运观测塔及其他个人路线巨构签名层
- 不适用于中央庭通用舰船、普通民居或其他神器使个人资产
