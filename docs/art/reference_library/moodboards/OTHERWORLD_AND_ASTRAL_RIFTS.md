# OTHERWORLD AND ASTRAL RIFTS｜异界与星界间隙视觉锚点

> 状态：v0.1 基线版。本文用于区分原作黑门/异界、本项目空间异常与《群星》星界间隙的实现参考。引用《群星》时只学习尺度、镜头、UI 和性能方法，不把虚境或具体阵营美术当作本 Mod 最终风格。
>
> 正式对照入口：[`../../calibration/BLACK_GATE_OTHERWORLD_COMPARISON.md`](../../calibration/BLACK_GATE_OTHERWORLD_COMPARISON.md) 与项目自制示意图 [`../../calibration/black_gate_otherworld_comparison.svg`](../../calibration/black_gate_otherworld_comparison.svg)。

## 1. 目标描述

建立黑门、异界生态、星界间隙、空间折叠与规则不兼容的共同视觉语法。异常不应只是“更紫、更亮的传送门”，而应让观众感到现实的连续性、尺度、材质或因果关系出现了无法完全兼容的错误。

核心判断：**中央庭的异常设备是被框定和测量的；真正的异界现象会抵抗框定，让边界、空间和观察本身变得不可靠。**

## 2. 核心关键词

- 黑门
- 规则不兼容
- 空间折叠
- 错误视差
- 尺度失真
- 异界生态
- 污染与侵入
- 负空间
- 不稳定边界
- 可观测但未被驯服

## 3. 推荐色彩

- 主体：近黑、煤灰、深石油蓝绿，制造“不是空白而是深度不可读”的暗部。
- 边界：病态珠白、冷青灰、低饱和绿蓝，表现现实被切开或薄膜受压。
- 污染：暗锈红、褐红或局部失真的生物色，必须有具体生态/损伤理由。
- 紫色：只作为受伤色、干涉色或少量异界层之一，不能成为默认全画面主色。
- 中央庭观测叠层：冷青读数、琥珀警戒、暗红隔离，明确与现象本体分层。
- 异界内部允许局部出现反常高亮色，但面积和持续时间受控，避免变成普通绚丽星云。

## 4. 推荐形状

- 黑门不是标准圆洞：可使用被切断的门框、无法闭合的轮廓、局部厚度不一致和边缘方向冲突。
- 空间折叠通过重复地平线、前后景互换、透视线不相交、同一结构从不可能角度再次出现来表现。
- 异界生态应有自身生长/运动逻辑，可表现为膜、矿物、群落、流体或无法分类的混合体；不要统一为触手。
- 星界间隙强调多层空间尺度：近处碎片、中距边界、远处不可达结构，避免单一平面漩涡。
- 规则冲突可让影子、倒影、粒子流向与实体运动不一致，但每个镜头只突出一至两种错位。
- 与神器科技区分：神器技术通常有完整锚定框和可读核心；异界会穿越、扭曲或使锚定框失效。

## 5. 推荐材质

- 油膜般的薄层干涉、烟尘、湿润矿物、半透明膜、烧蚀边缘、结露玻璃和无材质的负空间。
- 同一表面可在局部呈现互斥属性，如干燥却有水波反射、硬质却缓慢呼吸；使用要克制且可被动画支持。
- 黑门边缘应体现现实材料被拉伸、剥离或失焦，而非贴一圈统一霓虹。
- 异界生物/结构保持材质家族差异，不把所有对象统一做成紫色水晶或黑色烟雾。
- 中央庭隔离装置仍用哑光陶瓷、金属和玻璃，作为可信尺度参照。

## 6. 推荐光效

- 以边缘背光、雾中反射、影子错位、局部反相和非同步闪烁表现不兼容。
- 黑门内部不必总比外部亮；“吞光的深处 + 不自然亮边”通常比彩色旋涡更有辨识度。
- 粒子流可以朝重力、风或镜头运动的反方向漂移，形成细微不安。
- 空间折叠优先使用局部遮罩、视差和有限几何变形，少用全屏色散、抖动和噪点。
- 战斗特效应控制遮挡时间；研究/叙事场景可慢一些，但仍需给玩家稳定观察点。
- 《群星》虚境常见的高饱和紫、粉雷电和云旋只能作为“需要区分的技术参照”，不能直接套用。

## 7. 可学习元素

- 原作黑门与异界参考优先用于决定“门、污染、怪物和城市现实之间”的叙事关系。
- 原作技能/剧情画面可用于学习黑雾、空间侵入和认知扰动的局部表现，但具体图像不能未经资产流程直接使用。
- 从《群星》星界间隙学习场景尺度、镜头层次、探索 UI、交互焦点和运行性能。
- 从不可能空间、光学错位和材料干涉参考学习结构、光影与动态原理，不复制其他作品的标志性场景或生物。
- 从现有黑门观测建筑/图标学习中央庭如何“框定异常”，同时让异常本体在形状和颜色上保持异质。

## 8. 禁止元素

- 直接复制《群星》虚境的高饱和紫色云海、粉色闪电和通用灵能符号。
- 把黑门简化为黑圆洞、普通虫洞、星云漩涡或带紫边的传送门。
- 所有异界生态都长触手、眼睛、牙齿，变成通用克苏鲁装饰。
- 使用神器科技的紫色水晶、规则核心或稳定环，让异界显得已被完全工程化。
- 全屏色差、故障、抖动和噪点持续存在，损害 UI 可读性并引发视觉疲劳。
- 随机碎片与粒子没有流向、尺度和空间层次，只靠数量制造复杂。
- 在普通异常上使用终局危机级光柱和遮屏，失去叙事等级。
- 直接复制外部作品的标志性异界生物、舰船、门形或符号。

## 9. 与中央庭公共风格的关系

- 中央庭通过隔离框、扫描器、警示条、标尺和疏散结构进入画面，为不可理解现象提供人类尺度。
- 观测 UI 保持中央庭冷青/琥珀信息层，但不得给未知现象贴上过于确定的分类和宗教解释。
- 异界应在几何、材质或光线中破坏公共风格的连续性；这种破坏越清楚，越不需要堆高饱和特效。
- 成功稳定后，异常边缘可以逐渐对齐工程框架；失控时则出现穿框、延迟、倒置或尺度错配，形成可读状态变化。
- 其他神器使的个人符号只在他们参与应对时出现，不成为异界本身的固有语言。

## 10. 适用资产范围

- 黑门、黑雾、污染区、异界入口和银河级裂隙
- 星界间隙探索场景、异常现象与特殊项目背景
- 异界生态、怪物环境、空间折叠和规则冲突特效
- 黑门观测、隔离、研究与警戒建筑/组件的异常层
- 考古遗址终段、旧世界线泄漏和危机事件画面
- 相关科技、遗珍、事件、局势和 UI 图标
- 不适用于神器稳定装置常态、普通跃迁门或中央庭公共背景
