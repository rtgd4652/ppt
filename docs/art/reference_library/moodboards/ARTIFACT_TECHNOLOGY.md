# ARTIFACT TECHNOLOGY｜神器科技共同结构语言

> 状态：v0.1 工作版。本文描述的是“普通工程如何安全承载神器现象”，不是把任何参考图直接变成游戏资产。所有 `reference_id` 均须进入 `REFERENCE_MANIFEST.csv` 并核对来源、授权、允许用途和审核状态。

## 1. 目标描述

建立不同神器技术之间可共享、但不会抹去个人差异的结构语法。神器不是批量复制的魔法设备；人类能够标准化的是观测框架、稳定装置、隔离流程和工程接口，而不是神器本体或神器使的个体共鸣。

核心判断：**先看见可信的人类设备，再看见被它测量、约束或引导的异常规则。**

## 2. 核心关键词

- 可观测的未知
- 工程锚定
- 悬浮从属结构
- 规则核心
- 共鸣界面
- 相位错位
- 隔离与冗余
- 不完全可复制
- 有边界的超常
- 个体差异

## 3. 推荐色彩

- 60%–75% 沿用中央庭的深蓝灰、雾银、暖灰白与暗色机械缝。
- 10%–20% 使用冷青、冰蓝或中性白显示“稳定、被观测、可控”。
- 5%–15% 留给具体神器的个人色；同一设备在接入不同神器时可以改变该层，不改变公共底座。
- 警戒状态使用琥珀和暗红；污染/失控状态需有独立、可辨认但不过曝的异常色。
- 紫色不得作为“神器科技”的默认同义词；玫红、金色、蓝白等都应有具体角色或功能理由。

## 4. 推荐形状

- 三层结构：外部工程框架、悬浮/错位的中间层、不可完全解释的规则核心。
- 建议比例：普通机械与承重结构 60%–75%，异常承载/悬浮结构 15%–30%，纯能量或规则核心 5%–10%。
- 外框应具有夹持、测量、隔离、散热和断开结构；即使核心漂浮，也不能像凭空粘在场景里。
- 使用少量不共面的环、偏轴旋转、镜像不闭合、间距微变等方式表现空间错位。
- 悬浮构件应有明确层级：主核心、稳定片、传感器，避免均匀撒满碎片。
- 图标采用“可识别器物/功能轮廓 + 一处异常切口或核心”，不依赖细密魔法纹样。

## 5. 推荐材质

- 工程层：陶瓷装甲、拉丝金属、绝缘复合物、暗色橡胶接缝、强化玻璃。
- 观测层：半透明薄膜、偏振玻璃、微刻度金属、低亮度数据表面。
- 规则核心：按神器个案选择非同质材质，可表现为牌、书、器具、光场、空间缺口或无法定性的表面。
- 异常与工程层之间应有可见过渡：固定环、传感器阵列、屏蔽片或断路间隙。
- 不允许用“紫色水晶”一项材质包办所有神器，也不把水晶等同于高级科技。

## 6. 推荐光效

- 发光必须说明状态：休眠、校准、稳定共鸣、过载、污染或断开。
- 稳定状态使用低频呼吸、逐段点亮和细线闭环；过载时才出现断续、偏色和局部溢出。
- 悬浮关系可用短距离体积光或极细连接线暗示，不要铺满完整魔法阵。
- 规则核心的亮度应高于工程框架，但面积更小；外围设备仍需保持轮廓与材质可读。
- 粒子优先沿既定轨迹移动，表现“被测量的规律”；完全无规则的喷散只用于失控或异界污染。

## 7. 可学习元素

- 从现有神器科技、建筑和组件图标中学习功能分类与小尺寸识别，并识别其中过度统一的部分。
- 命运观测塔旧方案已经废弃，不能再作为神器科技的正向形状样本；其中的 Blender 拆件和 LOD 流程只能作为一般技术历史，不得保留太阳冠、多层环或塔罗结构结论。
- 从现代科学仪器学习标定、遮光、屏蔽、镜架、隔振和维护接口。
- 从粒子与光学参考学习偏振、干涉、扫描、薄膜色散和可控能流。
- 从《群星》学习图标轮廓、特效持续时间、材质发光阈值和战略缩放下的性能边界。

## 8. 禁止元素

- 所有神器设备都是紫色水晶、漂浮碎石或同一套魔法阵。
- 没有普通机械支撑、维护或观测结构，只剩不可解释的“神迹雕塑”。
- 把某位神器使的星月、卡牌、方舟或其他个人符号复制到所有神器资产。
- 将神器直接写成可量产武器，或让公共工厂成排制造完整神器。
- 低级民用设备持续释放终局粒子、空间裂缝和高亮光柱。
- 用宗教祭坛、圣坛和礼拜姿态替代研究与风险管理。
- 细节密度高到游戏内只剩发光噪点，或依靠透明层叠造成严重性能负担。

## 9. 与中央庭公共风格的关系

神器科技是中央庭公共工程中的“受控异常层”，不是另一套覆盖文明的皮肤。

- 外壳、支架、接口、警示与 UI 继续使用中央庭标准。
- 个体神器的形状和颜色只在核心与少量专用模块出现。
- 公共资产强调“可以被多人维护”；神器本体强调“只能由特定关系触发”。
- 失控时可以短暂破坏公共几何秩序，但应通过隔离框、警报与断开装置反衬其异常。

## 10. 适用资产范围

- 神器研究建筑、实验室、观测站、稳定设施与隔离舱
- 神器科技、飞升、特质、遗珍与组件图标
- 舰船上的共鸣核心、专用武器、护盾与传感模块
- 区划中的神器工业、档案、能源与科研设施
- 共鸣、扫描、稳定、过载和失控粒子特效
- 巨构中的规则核心与观测组件
- 不直接规定任何角色立绘的服装或外貌
