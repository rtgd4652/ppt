# ANTONIVA｜安托涅瓦与方舟视觉锚点

> 状态：v0.2，原作基础「神使」、觉醒「觉醒・神使」、诺亚方舟图标和人物设计稿已完成第一轮视觉核验。
>
> 本页只记录可验证的视觉关系和星海转译边界。原作图片保存在 Git 忽略的本地参考目录，不代表项目取得再分发权；文中的 HEX 是项目制作校准值，不是官方色卡。

## 1. 目标描述

建立安托涅瓦在角色立绘、诺亚方舟、空间能力、避难设施与星海时代资产中的共同视觉方向：空间不是炫技，方舟也不是无限逃生按钮；视觉重点是“在有限条件下，为生命和未来留出安全位置”。

核心判断：**安托涅瓦的力量向内形成容纳与保护，爱缪莎的力量向外展开观测与干涉；二者不能只靠换色区分。**

## 2. 已核验的角色识别核心

- 年轻女性，柔和偏窄的脸型与温和、从容的神态；不能改成高位俯视的女神脸或无情系统。
- 头发为深棕至黑棕的超长顺直发，暗部仍保留暖棕高光；不能改成纯黑、蓝黑、短发、卷发或高束发。
- 瞳色为琥珀橙／暖橙金，不是蓝瞳、紫瞳或持续发光的纯金眼。
- 基础服装为现代幻想化的东方层叠宽袖结构；不能简化为普通和服，也不能改成西式礼服、宗教法袍或机械战衣。
- 外层以低饱和薰衣草灰、灰粉和暖白为主，黑紫／炭黑内层提供重量；白色花纹、绳结、流苏与绒球是轻柔细节，不是密集装饰模板。
- 基础构图由人物坐于／依托诺亚方舟形成低重心、被承托和向前移动的关系；亲和不等于幼态，安静不等于虚弱。

## 4. 诺亚方舟识别要素

- 主体是大型、紧凑、近黑的舱体／舟体，不是传统木船、一般宇宙飞船缩略图或宗教圣物。
- 上壳为灰粉至浅紫，并带白色花朵／枝叶纹样，与人物外衣保持连续关系。
- 两侧或后部展开暖金色阶梯状翼片／舟翼，几何感介于折纸与装甲片之间。
- 底部与尾部存在黑紫尖角和深色垂片，用于建立前进方向与视觉重量。
- 周围只有少量淡紫、暖白和暖金悬浮方块，用来表达空间与坐标异常；不能扩展成满屏碎片。
- 方舟叙事是有限容纳、空间移动和保护。原作图标不支持“无限容量”“绝对安全”或全部内部工作原理的断言。

## 5. 推荐形状与材质

- 主要语法是“外壳—缓冲层—安全内腔”：包覆舱、双层壁、门框、空间锚和被保护的负形。
- 方舟意象可转译为龙骨、紧凑舱段、承载平台和有限展开翼，不按字面重画神话木船。
- 人物服装保持柔软织物、绳结、流苏与低反射层次；禁止面板化和机械化。
- 方舟个人层使用近黑舱体、粉紫涂层、暖金结构翼和白色花纹；星海工程底座才可加入中央庭哑光陶瓷、雾银结构肋和强化玻璃。
- 空间折叠使用边缘重合、前后景错位、低频视差和少量坐标方块，不使用通用紫色旋涡和随机碎片。

## 6. 光效与觉醒边界

- 光从被保护空间内部向外溢出，先照亮相邻人物与材料，再出现克制 bloom；不要在人物背后制造常驻神圣光环。
- 稳定边界使用低亮淡紫、冷白或中性空间轮廓；中央庭冷青只属于工程观测和校准层。
- 觉醒形态仍保留深棕长发、琥珀橙瞳、柔和面部与东方层叠服装逻辑。
- 觉醒外层扩大并转向暖白、珍珠白和低饱和虹彩，白色花朵、长披片与黑色内层构成更强的前后景。
- 觉醒的虹彩外层应理解为空间／方舟展开，不是常驻天使翼、婚纱、王座或纯光神体；基础粉紫、深色和暖金关系必须留下连续证据。

## 7. 星海时代转译

- 安托涅瓦专属设施沿用中央庭模块化、可维护、可疏散的工程底座，再用包覆层、生命支持、空间锚和安全内腔表达个人路线。
- 普通避难设施保持 80% 以上公共工程语言；只有方舟核心、个人技能和唯一资产提高灰粉、暖金、花纹抽象与空间错位比例。
- 实体模型负责舱体、保护翼、内腔和锚点；贴图负责压力分区、抽象花纹与路径灯；粒子只负责短时空间错位、坐标方块和内部柔光。
- 专属舰远景先读出被保护核心、稳定前进方向和容纳层，不能只剩白色光环。
- 科技与图标优先使用“外壳包覆安全负形”“黑舱体＋金翼＋淡紫坐标点”等大轮廓，不能用爱缪莎的卡牌、月牙与星轨替代。

## 8. 禁止元素

- 改成黑发蓝瞳、白发金瞳、短发、卷发、高束发或通用女神脸。
- 用蓝白银覆盖深棕、灰粉、薰衣草灰、黑紫和暖金的原作关系。
- 把基础服装改成普通和服、婚纱、宗教法袍、机械战衣或无菌医疗制服。
- 把觉醒虹彩外层写成常驻天使翼、神圣披风或纯白神体。
- 把诺亚方舟画成木船、普通宇宙飞船、无限避难所或纯金圣物。
- 使用通用紫色虫洞、虚境闪电、满屏冰晶或随机碎片代替空间容纳。
- 把安托涅瓦的花纹、灰粉或方舟符号扩展为全部中央庭民用设施和公共舰队的共同装饰。

## 9. 与中央庭公共风格的关系

- 中央庭深蓝灰、雾银与冷青只进入工程底座、维护界面和稳定设备，不能覆盖人物固有色。
- 安托涅瓦个人层把公共框架从“监测与指挥”转向“包裹、隔离、生命支持和可理解的撤离路径”。
- 安全内腔可以加入纸张米白、黄昏琥珀与低亮暖光，保持人类生活感，避免医院式无菌蓝白。
- 与爱缪莎并列时，通过“内向容纳／外向轨迹”“柔和边界／高对比牌阵”“希望暖光／概率星光”形成结构差异，而不是简单蓝色对玫红。

## 10. 适用资产范围

- 安托涅瓦基础、觉醒、皮肤与剧情状态立绘审核
- 诺亚方舟、技能图标、空间门、保护场与收容特效
- “避世的方舟”路线通讯、事件插图与结局画面
- 避难、生命支持、空间收容、撤离设施及可能的唯一舰／巨构
- 不适用于中央庭通用空间门、其他神器使或爱缪莎命运资产
