# ANTONIVA｜安托涅瓦与方舟视觉锚点

> 状态：v0.1 工作版。当前知识库没有足以锁定完整外貌字段的已核验原图，因此本文不自行补写发色、瞳色或具体服装。预留的原作参考 ID 必须在 `REFERENCE_MANIFEST.csv` 中补齐来源、形态、授权与审核状态后，才能成为角色外观锚点。

## 1. 目标描述

建立安托涅瓦在角色、方舟、空间能力、避难设施与星际转译中的共同方向：空间不是炫技，方舟也不是无限逃生按钮；视觉重点是“在有限条件下，为生命和未来留出安全位置”。

核心判断：**安托涅瓦的力量向内形成容纳与保护，爱缪莎的力量向外展开观测与干涉；二者不能只靠换色区分。**

## 2. 核心关键词

- 方舟
- 空间容纳
- 门扉与阈限
- 保护结构
- 安静坚韧
- 有限庇护
- 书页、地图与旅途
- 灾后希望
- 人类温度
- 蓝白银克制体系

## 3. 推荐色彩

以下是星海时代转译色，不宣称等同于原作角色固有服装色：

- 主体：低饱和深蓝灰、雾蓝，承担空间深度和中央庭工程底座。
- 次体：暖白与冷银，承担方舟外壳、保护框和门扉边缘。
- 安全状态：浅水蓝、冰青，面积克制，用于内部空间和边界稳定。
- 人性温度：少量灰金、纸张米白或黄昏琥珀，用于书页、生活舱和被保护对象。
- 危险状态：暗红只出现在破损边界和疏散警报，不把整个空间染成灾难红。
- 与爱缪莎区分：不以玫红、星光金和高对比黑紫作为主组合，不用卡牌色彩节奏。

## 4. 推荐形状

- 主要语法是“外壳—缓冲层—安全内腔”：嵌套椭圆、护臂、舱门、门框、双层壁和被包裹的负空间。
- 方舟意象可以转译为龙骨、舱段、庇护舱、承载平台和展开式保护翼，不必直画古代木船。
- 空间门应有明确阈限：一侧现实、一层稳定边界、一侧被容纳空间；避免随手画成通用圆形传送门。
- 折叠结构以大面积平滑位移、错位门框和空间嵌套为主，不用大量随机碎片。
- 角色构图优先稳定重心、温和视线和“为他人留出空间”的开放姿态，而非高位俯视。
- 书页、地图、路线和远方地平线可作为辅助几何，但不得取代方舟与角色本体。

## 5. 推荐材质

- 方舟外层：暖白哑光陶瓷、雾银结构肋、蓝灰复合装甲。
- 空间边界：半透明层压玻璃、乳白薄膜、低反射水面感或柔和折射层。
- 安全内腔：织物、纸张、木质扶手、柔软座椅等少量生活材质，提醒其服务于真实生命。
- 门框与锚点：拉丝金属、深色密封条、可见锁止和压力分区。
- 角色服装与神器本体材质必须以后续核验原图为准；本文蓝白银主要约束星际设施和特效。
- 禁止用成片冰晶替代空间，也不把透明材质做成无重量的水晶宫。

## 6. 推荐光效

- 光从安全空间内部向外溢出，强调“里面可以被保护”，而不是从角色背后制造神圣光环。
- 稳定边界使用柔和蓝白轮廓光、低频水纹或极慢视差；门开启时才短暂提高亮度。
- 空间折叠可用边缘重合、前后景错位、视差延迟和局部消隐表现，少用爆炸式能量。
- 疏散/收容过程以连续路径灯、门框逐段点亮和内部暖光作为叙事顺序。
- 防护技能先显示边界和覆盖对象，再显示能量厚度；不要用全屏白闪掩盖保护关系。

## 7. 可学习元素

- 从待收集的原作基础立绘确认不可改变的面部、发型、体态、服饰和方舟表现。
- 从待收集的觉醒立绘确认哪些变化属于剧情状态，哪些仍保持角色识别。
- 从原作技能与剧情 CG 学习空间门的边界、被保护者与安托涅瓦之间的空间关系。
- 从现代避难设施、救生舱和空间站舱段学习有限容量、冗余生命支持和可理解的撤离动线。
- 从书页、地图与旅途图像学习她对日常和远方的向往，但这些只能作为人物温度的辅助层。
- 从《群星》学习护盾、跃迁和空间场在游戏缩放下的持续时间与性能预算，不照搬其阵营颜色。

## 8. 禁止元素

- 把安托涅瓦改成无情的空间系统、机械女神或只会自我牺牲的圣徒。
- 用通用紫色旋涡、闪电圆门或《群星》虚境视觉代替方舟空间。
- 把方舟理解为无限容量、无代价救援或可以容纳整个文明的绝对安全空间。
- 直接复刻宗教木船、洪水壁画或十字式符号，让神话字面压过人物与功能。
- 让蓝白银变成医院无菌感：没有生活材质、黄昏、书页或被保护者。
- 使用爱缪莎的卡牌、星轨、月牙翼和玫红金色节奏来表达安托涅瓦。
- 过度碎片化空间边界，使保护范围、入口与对象无法读懂。
- 在原图核验前自行固定发色、瞳色、面部或服装细节。

## 9. 与中央庭公共风格的关系

- 安托涅瓦设施沿用中央庭模块化、可维护、可疏散的工程底座。
- 她的个人层把公共框架从“监测与指挥”转向“包裹、隔离和生命支持”。
- 蓝白银是方舟路线的专业识别层，不应反过来取代中央庭全文明的深蓝灰、暖白与功能状态色。
- 普通避难设施保持 80% 以上公共工程语言；只有方舟核心、个人技能和唯一资产提高空间错位与柔光比例。
- 与爱缪莎路线并列时，应通过“内向容纳/外向轨迹”“柔和边界/高对比牌阵”“希望暖光/概率星光”形成清楚差异。

## 10. 适用资产范围

- 安托涅瓦基础、觉醒、皮肤与剧情状态立绘审核
- 方舟神器外观、技能图标、保护场与空间门特效
- “避世的方舟”路线通讯、事件插图与结局画面
- 殖民地避难、生命支持、空间收容与撤离设施
- 可能的专属舰船、移动庇护站或空间研究巨构
- 与安托涅瓦相关的 UI、特质、科技和遗珍图标
- 不适用于中央庭通用空间门、其他角色神器或爱缪莎命运资产
