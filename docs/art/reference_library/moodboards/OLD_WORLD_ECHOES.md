# OLD WORLD ECHOES｜旧世界回声视觉锚点

> 状态：v0.1 工作版。本文用于考古、遗珍、博物天枢、旧结局残想与历史档案的共同方向。引用原作剧情画面或现实博物馆参考时，只分析结构、光影和陈列方法；来源与授权必须在 `REFERENCE_MANIFEST.csv` 审核。

## 1. 目标描述

让旧世界内容看起来像“被人保存、修复、误读又重新理解的生活历史”，而不是一堆金色宝物或通用远古外星遗迹。七日轮回结束后，记忆终于可以累积；旧结局和被覆盖世界线应呈现为证据、残响和不完整记录。

核心判断：**最有力量的遗物不一定宏伟；一件有使用痕迹的普通物品，也能证明某条被覆盖的生活曾经存在。**

## 2. 核心关键词

- 低饱和
- 档案感
- 记忆失真
- 历史痕迹
- 生活性遗物
- 世界线覆盖
- 缺页与修复
- 冷静陈列
- 温和哀悼
- 可被重新解释的证据

## 3. 推荐色彩

- 基底：煤灰、灰褐、旧纸米白、褪色蓝灰。
- 历史层：氧化铜绿、暗锈红、旧胶片棕、低饱和靛蓝。
- 档案 UI：近黑、暖灰白、冷青扫描线，强调可读性。
- 生活记忆：极少量褪色暖黄、旧粉、校服蓝或城市霓虹残色，作为“曾经有人生活”的证据。
- 异常残想：低亮冷白、偏青灰或局部反相色，不默认使用紫色灵能光。
- 金色仅用于金属氧化、标签重点或确有来源的对象，不把所有遗珍统一包装成宝藏。

## 4. 推荐形状

- 档案结构：编号标签、抽屉、文件夹、胶片格、地图网格、时间戳和修复拼接线。
- 遗物构图：完整对象 + 缺失部分 + 说明证据，保持对象原本用途可推测。
- 世界线覆盖：重复但略微错位的轮廓、擦除后重写的文字、地图道路不吻合、同一场景不同时间层叠。
- 博物馆陈列：单件焦点、清楚基座、尺度标签和充足负空间，不塞满装饰。
- 考古场景：发掘网格、保护棚、扫描框和普通工具与异常残响并置。
- 图标应优先使用器物轮廓、破损边或档案框，不以幽灵脸和恐怖眼睛作为通用捷径。

## 5. 推荐材质

- 档案纸、热敏纸、照片、胶片、磁带、旧屏幕与受潮书页。
- 磨损塑料、划痕玻璃、氧化黄铜、哑光钢、修补胶和编号织带。
- 城市遗物可保留混凝土粉尘、雨水痕、褪色涂层和日常触碰磨亮处。
- 博物天枢的公共框架使用中央庭雾银、深蓝灰与低反射玻璃，展品材质保持各自历史差异。
- 记忆残想可使用半透明双曝光、扫描噪声和局部相位偏移，但不能让所有材质变成数字故障。

## 6. 推荐光效

- 采用博物馆式斜侧光、低照度柜内光、修复台工作灯和移动扫描光。
- 生活记忆可以短暂出现柔和暖光，与冷静档案环境形成对比。
- 世界线残想通过局部亮度不同步、影子迟滞、一次性双曝光和边缘擦除出现。
- 异常光只照亮与证据相关的局部，不把整座遗址变成发光神殿。
- UI 动效应慢而清楚：加载档案、对齐碎片、显示缺失、标注不确定性；避免持续闪屏和难以阅读的故障字。

## 7. 可学习元素

- 从原作剧情 CG 和交界都市地区画面学习城市生活、机构空间、人物关系与灾难前后反差。
- 从现有记忆殿堂、遗珍工坊、遗珍档案等项目图标学习当前视觉连续性，同时审核是否过亮或过度奇幻。
- 从考古现场参考学习证据记录、分层、比例尺、保护和“不确定结论”的视觉表达。
- 从博物馆陈列学习单件焦点、标签系统、玻璃反射控制和观众动线。
- 从《群星》考古与遗珍 UI 学习章节推进、奖励层级和小图标尺度，不复制具体遗址或阵营造型。

## 8. 禁止元素

- 所有旧世界遗物都是纯金宝箱、皇冠、圣杯或发光神器。
- 用通用远古外星神殿替代交界都市的生活历史和七日轮回痕迹。
- 画面过度干净、对称、宏伟，像刚建成的纪念堂而没有时间与使用痕迹。
- 为制造“高级感”把所有记忆染成高饱和蓝紫或持续全息故障。
- 将旧结局只做成恐怖鬼影，忽略其中的人、选择、日常和情感差异。
- 展品堆满屏幕、标签不可读、缩小后只剩碎屑。
- 直接把原作 CG 当作可进入游戏的正式贴图；必须经过来源、授权和资产流程。
- 用当前中央庭的新式标识覆盖旧物原标签，导致年代层次消失。

## 9. 与中央庭公共风格的关系

- 中央庭承担保存、标注、修复和公开解释历史的外层框架；展品本体不被强行改造成中央庭风格。
- 档案 UI 沿用中央庭清晰层级与状态色，但必须增加“缺失、来源不确定、世界线冲突”等历史专用标记。
- 博物天枢可以是先进公共设施，内部却应保留旧城市材料、生活物与不完美证据的异质感。
- 旧世界回声的低饱和和使用痕迹，为中央庭的“连续重建”提供历史根基，而不是把文明永远困在废墟审美里。

## 10. 适用资产范围

- 考古遗址章节图、事件背景、发掘场景和档案 UI
- 遗珍、旧物、黑核/神器残片与生活性纪念物图标
- 博物天枢、记忆殿堂、遗珍档案等建筑或巨构
- 旧结局残想、被覆盖世界线和轮回记录特效
- 城市废墟、修复区、纪念空间和博物馆陈列
- 角色回忆中的物件、照片、书信、地图和日常空间
- 不适用于中央庭当前通用舰队或所有现代城市资产
