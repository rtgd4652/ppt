# CENTRAL COURT｜中央庭公共视觉基线

> 状态：v0.1 工作版。本文只提炼视觉判断，不授予任何图片再分发或转为正式资产的权利。文末所有 `reference_id` 均须在 `REFERENCE_MANIFEST.csv` 中登记并完成来源、授权与审核状态核对。
>
> 设定依据：`knowledge/world/lore_bible_v0.1.md`、`knowledge/organizations/organization_bible_v0.1.md`、现有地区界面与图标、现有舰船和建筑实现。中央庭公共风格是文明级底座，不等于任何一名神器使的个人风格。

## 1. 目标描述

建立整个文明公共资产的共同底色：这是一个从黑门灾难中成长出来、重视预警、救援、科研、协作与长期重建的人类星际文明。画面应先让人读出“可靠、可维护、随时准备应对异常的公共工程”，再在局部显露神器科学带来的超常结构。

核心判断：**中央庭不是神殿，也不是纯军事帝国；它是带着灾害记忆走向星海的综合治理与工程体系。**

## 2. 核心关键词

- 灾后韧性
- 公共秩序
- 克制警戒
- 模块化维护
- 科研与救援并置
- 人类尺度
- 可验证的异常管理
- 连续重建
- 清晰信息层级
- 希望，但不粉饰创伤

## 3. 推荐色彩

以下色值用于跨资产校准，不是强制逐像素套用：

| 功能 | 建议色域 | 建议占比 | 用法 |
| --- | --- | ---: | --- |
| 主结构 | 深海军蓝、石墨蓝灰 `#182630` / `#304651` | 45%–60% | 舰体、建筑骨架、UI 大底 |
| 次结构 | 暖灰白、雾银 `#D6D9D5` / `#9BA8AE` | 20%–30% | 装甲分区、边框、公共空间 |
| 科研/正常状态 | 冷青、低饱和天蓝 `#69C1CC` / `#79AFC7` | 5%–10% | 读数、能量线、导航标记 |
| 人居温度 | 暖琥珀 `#D39A55` | 2%–6% | 门厅、生活区、可进入空间 |
| 警报 | 橙红、暗红 `#D0644D` / `#9E4651` | 小于 3% | 只用于危险、隔离和损伤 |

- 公共资产不得以玫红、纯金或高饱和紫作为大面积文明主色。
- 个人神器色只能作为挂载模块、识别灯、局部纹章或技能状态色，不得反向覆盖中央庭底色。
- 地面设施允许加入混凝土、旧城市砖石和植被色，以保留“从交界都市生长出来”的历史连续性。

## 4. 推荐形状

- 以清楚的承重骨架、桥接梁、分层装甲、可更换模块和可到达维护面构成基础形状。
- 长方体、梯形、钝角楔形和带小倒角的矩形用于普通工程；避免所有结构都变成尖塔或环阵。
- 重要公共节点可使用“中枢体 + 四向/六向支臂 + 外围防护框”，表达协调而非崇拜。
- 避难、隔离与研究设施应让门、闸、缓冲区、观察窗和撤离路径可被看懂。
- 舰船优先保证舰首方向、推进端、模块区和武器区在游戏缩放下可区分。
- UI 与图标采用大轮廓、少层级和明确负形；细节只用于二级阅读。
- 圆环只用于观测、隔离、对接或神器稳定装置，不能成为所有资产的默认装饰。

## 5. 推荐材质

正式跨资产校准入口：[`../../calibration/CENTRAL_COURT_MATERIAL_CALIBRATION.md`](../../calibration/CENTRAL_COURT_MATERIAL_CALIBRATION.md) 与 [`../../calibration/central_court_material_calibration.svg`](../../calibration/central_court_material_calibration.svg)。两者是项目自制校准参考，不是可直接导入游戏的正式贴图。

- 大面积：低至中等反射的深色陶瓷装甲、涂层金属、耐候复合板。
- 边缘与连接：拉丝银灰金属、暗色结构钢、可见紧固和维护接缝。
- 可进入空间：强化玻璃、半透明聚合物、暖色内饰光、少量木质或织物触感。
- 地面建筑：修复后的混凝土、旧砖石、替换式金属补片，允许保留有限使用痕迹。
- 神器研究区：普通仪器与超常界面并置，超常材料不超过视觉主体的约四分之一。
- 避免全镜面、全水晶或毫无磨损的“展柜宇宙飞船”质感。

## 6. 推荐光效

- 公共光源首先承担导航、状态和安全功能：连续导向线、舱门边灯、设备状态点、疏散照明。
- 正常状态以低亮度冷青为主；人居区以局部暖光提示“这里有人生活”。
- 警戒状态使用节律清晰的琥珀/红色段落，不让整座设施持续闪烁。
- 神器设备可有缓慢呼吸或相位错位，但应被工程框架约束，不能像无来源的神圣辉光。
- 战略缩放下只保留少数主发光线和识别点，避免发光把轮廓糊成一团。

## 7. 可学习元素

- 从现有交界都市地区画面学习“现代城区、旧街区、研究设施、港区”如何在同一城市系统中保持差异。
- 从灾害指挥中心参考中学习信息层级、跨部门协作界面、冗余通信和清楚的人员动线。
- 从现代空间站与工业设施学习模块连接、维护面、散热、对接与尺度提示。
- 从《群星》学习远景剪影、模块分区、图标轮廓和受性能约束的发光密度。
- 从现有项目图标学习哪些色彩和形状已形成连续性，同时把早期过亮、过神圣或过度个人化的部分标记为待修订，而不是自动奉为规范。

## 8. 禁止元素

- 纯金白、无处不在的太阳冠或宗教尖塔组成的泛神圣文明。
- 把爱缪莎的塔罗、星月或其他神器使的个人符号作为公共资产统一纹样。
- 只把《群星》默认人类舰船换色，不建立本项目的灾害治理与神器研究特征。
- 普通民居、仓库、道路和运输船使用终局级环阵、空间裂隙或满屏粒子。
- 每个面都切碎、远景只剩噪声、没有清楚主轮廓的设计。
- 看不出入口、维护、推进、承重或使用者尺度的“概念雕塑”。
- 把中央庭画成冷酷地消耗神器使的军政机器，抹去公共保障、救援和普通人的生活。

## 9. 与中央庭公共风格的关系

本文即公共基线。其他 Moodboard 应采用“公共底座 + 专业系统 + 个人签名”的三级关系：

- 60%–75%：中央庭工程、材质、信息与维护逻辑。
- 15%–30%：资产功能所需的专业语言，如方舟收容、命运观测、黑门隔离。
- 5%–15%：角色或神器的个人颜色、符号和异常光效。

终局唯一资产可以提高个人层比例，但仍须保留可识别的舰体、接口、尺度与人类工程痕迹。

## 10. 适用资产范围

- 文明通用舰船、空间站、防御平台和运输设施
- 中央庭总部、殖民地行政、科研、医院、避难与灾害指挥建筑
- 普通区划、道路、公共标识与城市夜景
- 文明级 UI、面板框架、状态色、公共图标和字体氛围
- 通用装甲、舱室、工程组件与材质库
- 神器研究设备的普通机械底座
- 不适用于直接替代角色立绘、个人神器或异界现象本体
