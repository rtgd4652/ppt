# 《群星》粒子与战斗特效实现参考

## 文档用途

本页学习《群星》光束、弹体、炮口、命中、推进器、舰船灯光、光环和巨构循环特效的技术尺度。原版效果只能作为表现与性能参考，不能直接认定为本 Mod 的原创视觉语言。

## 当前仓库审计

- 旧 Stage 9 舰体当前运行时复用 `ai_01_blue_large_station_core_effect`、`ship_light_blue_effect` 与 `generic_big_*_exhaust_circle_*` 等游戏现有效果；这些效果仅记录现状，不再构成未来命运之主粒子方案。
- 这种复用说明项目已有低成本运行基线，但这些效果名称及视觉属于《群星》实现依赖，不是本项目参考图片或自有粒子资产。
- `mod/gfx/interface/icons/ship_parts/` 已覆盖多种武器/部件图标，但图标不能证明实战弹道、开火点和命中反馈已经完成。
- 审计范围内没有独立的原版光束、弹体、命中或星界粒子截图/录屏索引。

## 可学习内容

- 炮口、弹道和命中三段应在色彩、宽度或时间上保持因果连贯。
- 普通武器的效果寿命短、主体明确；泰坦/巨像级效果可以增加蓄力与环境反馈。
- 持续灯光和推进器通过少量稳定节点建立舰体方向，不能代替材质本身的可读性。
- 大规模战斗中应优先保留命中位置、攻击方向和武器类型，装饰粒子可以降级。
- 星界/裂隙效果可通过折射、错位、非欧几里得轨迹和环境色偏表达，而不必全部变成紫色云雾。

## 本项目转译

- 中央庭普通武器：工程化、短反馈、有限色彩，避免满屏魔法阵。
- 神器武器：在普通发射/命中结构上增加规则核心、轨迹偏折或一次清晰的异常行为。
- 爱缪莎：星轨可决定弹道或目标连线；卡牌只在蓄力、锁定或因果改写瞬间出现。
- 安托涅瓦：空间开口、包覆与安全转移为主，不与爱缪莎共享同一星轨/卡牌粒子。
- 黑门与异界：强调边界规则冲突、空间切面和局部环境响应，与虚境紫色保持区别。

## 不可直接复制

- 原版效果的纹理、完整粒子定义、专属颜色序列和标志性弹道。
- 用现成原版粒子作为“本项目已完成美术设计”的证据。
- 普通攻击持续生成全屏法阵、多层卡牌、长寿命星尘或大范围屏幕闪光。
- 所有神器效果都使用同一紫色水晶碎片或同一圆环爆炸。
- 把角色终局演出直接缩小后批量用于普通舰队。

## 性能与降级规则

- 同屏按舰队规模测试，不以单舰预览判断性能。
- 每个效果记录发射频率、最大并发、寿命、透明叠层、拖尾长度和灯光数量。
- 先减少不可读的小粒子，再缩短寿命，再简化透明层；保留主体弹道与命中反馈。
- 持续发光优先由材质承担；粒子负责运动、状态切换和峰值。
- 英雄舰、普通舰、巨构和星界场景使用不同预算，不能共享一个最高规格模板。
- 在明亮恒星、暗空、星云和大规模爆炸背景下分别验证，避免过曝或完全消失。

## 登记建议

静态截图应与录屏时间码或多关键帧成组登记，并注明对象、武器类型、舰队规模、游戏速度和缩放。`visual_role` 通常使用 `effect_reference` 或 `technical_reference`；如只用于说明性能上限，应在备注中明确。

## 参考层与正式资产边界

截图、录屏和原版粒子名称只属于参考层或运行依赖说明，不是可复制的正式素材。项目新建的粒子定义、纹理、材质、定位器与动画在被 `mod/gfx` 使用前，必须作为正式资产重新登记并完成来源、授权与性能审核。
