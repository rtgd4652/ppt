# 《群星》考古与博物馆实现参考

## 文档用途

本页学习《群星》考古遗址、章节推进、遗物发现、特殊项目与展陈界面的视觉叙事方式。它服务于旧世界遗迹、神器残片、七日循环档案、交界都市遗址与“博物天枢”等方向。

## 当前仓库审计

- `docs/design/mod_design_master.md` 已把旧世界遗迹、神器残片、七日循环档案和交界都市遗址列为考古规划，但没有形成专门的视觉参考集。
- 正式图标目录已有记忆殿堂、遗珍工坊、遗珍档案馆与相关科技图标；这些是项目实现，不是《群星》考古参考。
- 当前审计未发现原版考古遗址界面、发掘章节、遗珍近景或博物馆陈列截图。

## 必收参考组

- 考古遗址发现、未发掘、进行中、章节完成与最终发现状态。
- 遗址事件图中遗迹尺度、研究人员/舰船与环境的关系。
- 章节 UI 的标题、进度、难度、文本与关键物件构图。
- 遗珍、档案、日用品、残片、设备与大型遗迹的不同陈列方式。
- 博物馆展柜、标签、灯光、动线和“研究对象”状态。
- 记忆失真、时间覆盖与多世界线痕迹的表现方式。

## 可学习内容

- 用一件明确物件、一个现场痕迹或一段空间关系支撑每个章节，而不是只换文字。
- 发掘推进通过清理、拼合、解码、复原或重建改变画面信息层级。
- 遗珍图标强调轮廓和材质，事件图补充尺度、来源环境和情绪。
- 低饱和、档案编号、局部磨损和生活性遗物可以建立旧世界可信度。
- 展陈要区分“证物”“纪念物”“研究样本”“仍在活动的危险物”。

## 本项目转译

- 旧世界回声优先表现被使用过的物件、维护痕迹、时间覆盖和不完整记录，而不是只做宏伟废墟。
- 七日轮回档案可通过日期冲突、重复磨损、版本覆盖和局部记忆错位表达；不能只依赖 glitch 滤镜。
- 神器残片要保留普通材料与异常规则并存的关系，避免统一做成紫色水晶碎片。
- 博物天枢或档案设施应兼具公共教育、研究和风险隔离，不做单纯战利品陈列室。

## 不可直接复制

- 原版考古事件图、遗址布局、遗珍物件、界面边框和章节构图。
- 其他作品的标志性遗物、文字、徽记、雕像或博物馆展品设计。
- 把所有旧世界内容做成同样的棕灰滤镜、胶片噪点或破损屏幕。
- 为营造历史感而编造原作不存在的机构标识、年代或考古结论。

## UI 与性能限制

- 事件图必须为文本留出安全区；展品主体在被窗口覆盖后仍可辨。
- 同一遗址多章节可复用底图和分层源，通过局部变化表现推进，避免大量近似大图。
- 动态尘埃、扫描线和全屏失真仅作低强度辅助，长文本阅读时不能持续干扰。
- 遗珍/科技图标需在实际小尺寸下与档案、记忆、普通资源图标区分。

## 登记建议

条目应注明遗址阶段、事件 UI 或展品类型，并把“历史情绪”拆成可执行的构图、材质、照明和信息层级。与 `OLD_WORLD_ECHOES` Moodboard 相连的条目要说明其生活性、档案性或世界线覆盖作用。

## 参考层与正式资产边界

原版截图与外部展陈资料只用于分析，不能直接成为事件图、遗珍图标或博物馆资产。正式内容必须原创重绘/重建或具备明确授权，并在 `ASSET_REGISTRY.csv` 中注明是否只提取了叙事构图、档案层级或材质规律。
