# 《群星》星球、区划与建筑实现参考

## 文档用途

本页学习星球界面中建筑/区划图标的语义、远景行星表现和城市功能分层。参考《群星》的信息表达与技术尺寸，不复制其具体阵营建筑。

## 当前仓库审计

- `mod/gfx/interface/icons/districts/` 已有命运公共区、工业、基建、科研、舰队与神器枢纽等正式图标。
- `mod/gfx/interface/icons/buildings/` 已有黑门观测站、命运演算院、记忆殿堂、遗珍工坊/档案馆、相位能源等正式图标。
- 上述文件是项目正式资产，不是《群星》参考图。它们可用于检查当前语义是否重复、缩小后是否可读，但不能作为原版来源。
- 生成脚本目前大量使用圆环、辉光和几何符号；后续参考应帮助区分“建筑功能”“神器层级”“角色专题”，避免所有图标同质化。
- 审计范围内没有独立整理的原版行星、区划或建筑参考截图。

## 必收参考组

- 普通行星、都市星球、环世界/特殊居住地在银河、星系与行星界面中的表现。
- 基础区划、专属区划与受限区划的图标轮廓和状态变化。
- 资源建筑、科研建筑、行政建筑、防御建筑与特殊建筑图标。
- 建成、不可建、锁定、停用、废墟和升级状态。
- 城市灯光、轨道设施、地表纹理与环境异常的尺度关系。

## 可学习内容

- 区划图标用大轮廓表达“土地/网络/生产类型”，建筑图标用主体物表达具体设施。
- 同系列图标共享边框、光源和透视，但以主体剪影区分功能。
- 稀有或终局设施通过少量额外层级体现，不用简单提升全图亮度。
- 行星远景只表达宏观城市密度、地表结构和少量异常节点，建筑级细节留在 UI。

## 不可直接复制

- 原版阵营城市外观、建筑轮廓、区划构图和图标框架。
- 把中央庭建筑统一做成普通人类城市图标换青色。
- 把角色个人神器符号作为所有民用、工业和农业设施的中心主体。
- 在 32–64 像素目标尺寸中堆叠文字、细小窗格、复杂星图或多重卡牌。

## 本项目分类边界

- 中央庭公共设施：治理、救灾、研究和防御优先，使用稳定结构与公共标识。
- 神器技术设施：公共工程结构中嵌入悬浮节点、能量纹路或规则核心，但保持功能可读。
- 角色专属设施：只在确有玩法归属时加入星月、方舟、神弓等个人符号。
- 旧世界/记忆设施：低饱和、档案与生活痕迹，不应与终局神器设施共享满强度辉光。
- 黑门设施：观测、隔离、锚定和应急结构优先，不把黑门本身当作装饰性门洞。

## 性能与实现限制

- 图标必须在实际 UI 尺寸和不同缩放下测试；现有输出涵盖 32、48、58、64、128 像素等尺寸，不能只审 128 像素源图。
- 透明边缘、细线和小光点在 DDS 压缩后容易丢失或产生色边，应使用清晰主体与受控发光。
- 行星表面资产要控制夜光密度、层叠云与透明特效，避免多个修饰同时造成过绘。
- 状态变体优先用 UI 状态层与颜色/遮罩，不为每种状态复制一套大型源图。

## 登记建议

条目应标记目标为行星远景、区划图标、建筑图标或状态表达，并说明主要学习的是轮廓、色彩分级、功能隐喻还是缩放可读性。`what_not_to_copy` 必须指出原版阵营特征和 UI 框架边界。
