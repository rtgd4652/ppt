# 《群星》巨构实现参考

## 文档用途

本页学习巨构在星系尺度下的构图、施工阶段、动画、LOD 与环境关系。它不授权复制原版巨构，也不规定本 Mod 必须采用任何原版阵营风格。

## 当前仓库审计

- `assets/ai_generated/destiny_observatory/DESTINY_OBSERVATORY_BLENDER_PLAN.md` 记录了“中央塔 + 多层环 + 底部锚定尖塔”、低模预算、LOD 与慢速环体动画的旧流程。
- 该方案已经废弃。“神圣未来科技”“太阳冠”、旧环体比例与旧配色均不得作为批准锚点；未来命运观测塔必须从功能、尺度和全新灰模重新设计。
- `mod/common/megastructures/aemusa_fate_observatory.txt` 已有玩法定义，但审计范围内未发现对应的正式巨构模型目录。
- 当前没有独立整理的《群星》巨构截图参考集。

## 必收参考组

- 恒星级、行星轨道级与深空站级巨构的同尺度截图。
- 施工场址、框架、中间阶段和完成阶段。
- 环体、辐条、核心、停泊/维护节点与能源收集结构。
- 星系视角、近景三分之四、正视、侧视和俯视。
- 动画循环、灯光变化、建造特效和损毁/关闭状态。

## 可学习内容

- 用中心体、主环和附属模块建立尺度层级。
- 通过施工阶段逐步增加结构，而不是简单替换贴图颜色。
- 巨构与恒星、行星、轨道、舰船交通的比例关系。
- 低频、慢速、幅度明确的动画如何提示巨构仍在运行。
- 发光核心和工程支撑之间的比例，使超常装置仍具有可维护的实体基础。

## 不可直接复制

- 原版巨构的完整环形比例、支臂数量、表面纹样、施工骨架或专属光效。
- 把“足够大”理解为无差别等比放大或占满整个星系画面。
- 为命运主题在每个面加入塔罗牌、太阳纹章或高亮金边。
- 使用高速多轴旋转、大量半透明面片和高频闪光制造所谓终局感。

## 本项目对齐

- 命运观测类巨构应强调观测、演算、锚定和可读的轨道关系；太阳/金色若使用，只能作为有限焦点。
- 神器科技公共语言应是工程承载体加规则核心：大部分质量可解释为结构与维护设施，少部分表现空间错位或悬浮。
- 旧世界、方舟和黑门专题巨构需要各自的功能轮廓，不能只替换同一座环形塔的颜色。

## 性能与实现限制

- 先完成灰模与 LOD，再做材质和动画；环体分段、重复模块与透镜应可实例化或合并。
- 近景、星系常用视角和战略远景至少准备三级简化；小型停泊台、线路和透镜在远景应删除。
- 循环动画要避免多个巨构同时出现时形成高频视觉噪声；粒子寿命、透明叠层和发光面积都要设上限。
- 施工阶段尽量复用材质与核心结构，避免每阶段生成完整独立的超大贴图集。
- 正式接入前验证遮挡、选择圈、舰船交通、相机裁切和恒星光照。

## 登记建议

每条参考注明对象、阶段、缩放、镜头、主要用途和版本。推荐把同一巨构的不同阶段作为相关条目，分别标为 `technical_reference` 或 `composition_reference`；不能用单张宣传近景代替游戏内尺度证据。

## 参考层与正式资产边界

本页及其登记图片只用于分析原版的尺度与实现方式，不得被游戏脚本或 GFX 直接引用。项目自制的模型、贴图、施工阶段和动画通过审核后，必须另行进入 `ASSET_REGISTRY.csv`；登记时说明是原创重建还是只提取了尺度、构图与 LOD 规律。
