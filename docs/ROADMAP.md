# ROADMAP

## 近期目标：1.0 可玩稳定版

- 启动器可稳定识别本地 Mod。
- 新建国家可见神器使物种、肖像、起源、预设帝国。
- 白夜馆通讯入口可用。
- 爱缪莎与后续领袖召唤、职业切换、立绘切换可用。
- 命运之主可设计、建造、战斗、跃迁与复活。
- 命运观测塔巨构可完整建造并启用政策模式。
- `error.log` 中无本 Mod 的硬错误。

## 中期目标：内容扩展版

- 完成塞斯、幽桐、拉比、冈部伦太郎、格蕾莎等领袖。
- 完善白夜馆阵营与通讯分支。
- 补齐神器使经济、科技、建筑、军备线。
- 制作命运观测塔模型与多阶段建造外观。

## 长期目标：剧情与系统整合版

- 黑门、中央庭、白夜馆、记忆殿堂等势力体系。
- 七日循环事件链。
- 神器使契约、神器觉醒、终末抉择等系统。
- 更多角色专属技能与剧情通讯。
