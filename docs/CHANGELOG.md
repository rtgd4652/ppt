# CHANGELOG

## 0.1.0 - 待发布

### 新增

- 神器使物种、肖像、种族特质、起源、专属星球与预设帝国。
- 白夜馆招募、联络、档案展示与管理入口。
- 爱缪莎、赛斯、幽桐、拉比四名可招募领袖。
- 神器使专属飞升、传统、科技、建筑、岗位和区划。
- 命运观测塔四阶段脚本和政策模式。
- 命运之主舰体、模型、核心组件、双光环、跃迁核心和重构事件。
- Wiki 角色采集、清洗、图片索引和 Mod Ready 摘要工具链。
- 世界观、神器、组织、时间线、剧情与角色关系知识库文档。

### 修复

- 使用国家 flag 防止专属星球重复生成。
- 将两处无效资源键 `trade_value` 修正为 Stellaris 4.4.3 的 `trade`。
- 移除 `aemusa_generated_icons.gfx` 的 UTF-8 BOM，恢复其中已有 sprite 定义的加载。
- 使命运之主复用泰坦名称表，避免自定义舰种无法生成舰名和舰级名。
- 在模型缺少武器 locator 时关闭命运之主武器槽，避免区段加载错误。

### 调整

- 仓库重构为 `mod/`、`knowledge/`、`assets/`、`docs/`、`reports/` 与 `tools/`。
- 白夜馆被明确为功能入口，不属于世界观组织、政治势力或外交实体。
- v0.1.0 冻结为稳定基线，不继续扩展角色、剧情和正式美术。

### 已知问题

- 41 个岗位、修正、trait 与巨构正式图标等待统一美术规范后补齐。
- 命运之主完整武器 locator、武器布局、攻击动画和最终平衡尚未完成。
- 命运观测塔正式三维阶段模型尚未完成。
- 当前候选构建仍需完成游戏内复测，复测通过后才会发布。
