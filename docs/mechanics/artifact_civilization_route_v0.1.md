# 神器文明研究、制度与工程路线 v0.1

更新：2026-10-10。本文记录当前正式脚本的实际入口与用途；后续能力建议单独标记。用户确认文明科技树与爱缪莎飞升专属科技分开；人物组合暂缓，由用户后续决定。

## 当前路线

当前文明科技树为19项：16项共有研究、3项军备研究；另外2项旧工程科技只作遗留兼容。文明研究与军备沿文明条件发展，不要求爱缪莎先到30级；个人命运飞升与主线中的授权、决定仍分别判断。

科技提供设施、岗位、组件和研究资格；传统提供成长与公共制度基础；两项文明飞升提供军备阶段和城市工程资格。前置满足后仍须正常研究，科技层级与研究抽取也受原版规则约束，本表不保证某张科技立即出现。

## 两条独立路线与兼容边界

| 路线 | 发展依据 | 完成后的用途 | 当前实现 |
| --- | --- | --- | --- |
| 神器文明科技树 | 文明身份、科技前置、公共制度、两项文明飞升和工程投入 | 公共产业、军事、城市及舰船／巨构能力；最终Boss后的共通研究奖励也属于此线 | 19项科技与2项公共飞升已有定义，完整工程能力和Boss奖励仍待补齐 |
| 爱缪莎飞升专属科技 | 合法完成主线中的玩家授权、爱缪莎决定与正式转变结算 | 将她转变后的个人能力用于独有舰船、巨构与可能性工程 | 新专属科技尚未定义，不能把旧科技或30级飞升视为已交付 |
| 旧舰／旧塔兼容 | 原有条件、旧科技和旧飞升键 | 保留旧存档内容 | 2项科技单独存放，排除已初始化的新主线路线 |

后续实施遵守以下边界：

- 文明科技树不得读取爱缪莎个人等级、旧个人飞升、正式转变或专属科技作为前置。两种非转变结局仍能完成文明发展并获得最终Boss的共通奖励；新奖励目前未实现。
- 新个人专属科技以`aemusa_ms_country_ending_fate_sovereign_settled`的合法结算为入口；现有结算还保留本人终局身份与授权状态。仅达到30级、选择旧飞升或只取得文明科技都不能代替正式转变。
- 新个人科技独立成文件和前置链，不将普通文明高阶研究接在它之后，也不沿用旧观测塔作为入口。舰体或巨构的通用工程资格可以在建造阶段另行核对，不能让公共研究等待个人转变。
- “塔罗”“命运”等名称本身不决定路线归属。现有塔罗经济、命运经济和命运都市仍是文明共有研究；旧键保持存档身份。

本次拆分的是已有定义的文件与说明，全部研究数值、旧条件、公共飞升和主线资格保持原值。新个人科技的具体能力、数值与正式资产留到对应实现包，不创建空科技卡占位。

共有研究支撑14座有科技条件的建筑；中央庭指挥中心不需要这些科技。建筑既有费用、岗位、维护费与每星球数量限制继续适用，研究完成不自动生成设施或免费岗位。

黑门观测体系和神器锻造目前直接解锁观测站／工坊。现有舰船武器与防御组件的直接前置属于军备研究，不能根据早期注释把它们记到这两项科技下面。

## 中央庭守望：七项制度

| 节点 | 当前效果与用途 |
| --- | --- |
| 采纳：中央庭集结 | 领袖经验获取+20%、法令经费+50；支持现有正常任职成长 |
| 黑门守望 | 陆军伤害+25%、稳定度+5 |
| 七人众协同 | 指挥官与行政官上限各+2、海军容量+100；名称沿用既有键，不新增人物配对 |
| 塔罗档案 | 研究选项+1、科学家初始等级+1 |
| 都市联络网 | 凝聚力+20%、舒适度使用-10% |
| 第七日的约定 | 境内舰船射速+20%、装甲硬化+20% |
| 完成：守望不息 | 法令经费+200、飞升槽+1；满足七日后勤网络的传统条件 |

塔罗档案与传统完成奖励没有脚本科研速度加成。本批移除相应过时说明，并按原版`_delayed`后缀补齐中文传统说明；原有数值不变。

## 飞升与三阶段军备

| 飞升 | 当前显式门槛 | 已有资格与效果 |
| --- | --- | --- |
| 神器共鸣之路 | 神器使主体物种；已有至少2个飞升 | 共鸣军备的文明条件；合金／消费品各+5%、海军容量+10% |
| 神器终解之路 | 已选共鸣之路；已有至少4个飞升 | 终解战争学的文明条件、命运都市决议的文明条件；合金／消费品／凝聚力各+10%、海军容量+20%、舰船射速+15% |

既有个人飞升“爱缪莎：命运主宰”独立管理：要求神器使主体物种、完成传统树、已有至少3个飞升、对应爱缪莎实际基础等级至少30；仍提供既有行政／舰队修正和遗留工程资格。它不是第三项文明飞升，也不授予主线转变身份或新个人专属科技。

两项文明飞升没有脚本中的分学科科研速度加成；终解之路没有单独的武器伤害加成，射速为15%。旧文字中的对应数字已修正。

| 神器终解战争学／T5 | 共鸣军备＋零点能源`tech_zero_point_power`；终解之路 | 后期陆军、武器与组件 |

这些组件与陆军是已有原型，正式舰船组与最终Boss后的新奖励仍待制作；本批没有调整其战斗平衡。

## 城市与新危机设施

命运都市通过原行星决议建造：需要命运都市工程、神器终解之路、标准区划组及`pop_amount >= 25`；帝国只能创建一次。费用为20000矿物、10000合金、10000凝聚力，原决议直接改造行星。该人口字段按现有原版接口记录，未在本批另做UI数量换算或改造测试。

新危机旗舰和现实基线枢纽沿已实现的主线授权、实体与控制权接口开放；它们不由旧命运观测塔科技解锁。枢纽为基址→运行态，运行条件还核对本国所有权与星港控制权。前十章及危机／结局运行证据继续复用。

## 遗留兼容

| 遗留科技／层级 | 前置 | 边界 |
| --- | --- | --- |
| 命运观测塔／T5 | 命运经济矩阵＋原版巨构工程；个人命运飞升 | 新主线路线已初始化时不进入此科技的可见范围；旧键保留 |
| 命运之主舰体工程／T5 | 旧命运观测塔＋原版泰坦；个人命运飞升 | 同一遗留条件，不能充当新旗舰获取入口 |

旧科技沿用原前置，其中观测塔仍读取命运经济矩阵，仅在未初始化新主线的遗留路线中适用。文明科技不反向读取这两项旧科技。它们已迁入独立兼容文件；不能用这条旧连接作为新个人科技路线的设计依据。

科技、传统、飞升采用旧键保持既有存档记录；本次没有新增强制前置或修改章节资格。

## 下一包的明确缺口

当前研究已提供设施与组件，传统和飞升主要提供编制／数值以及少量资格；新危机巨构目前服务主线解析。尚未形成完整的主动文明工程与最终Boss奖励路线，不能据此称1.0体系已经完成。

下一包建议优先给**七日后勤网络接入殖民地应急预案**，让已建成的调度中枢具备一项主动用途。这是未实施的能力建议，具体投入、持续时间与冷却在实施批次确定。

| 设计项 | 首版建议 |
| --- | --- |
| Lore Design | 将公共疏散、民用补给与黑门避护编成可提前准备的制度，体现文明韧性 |
| Player Experience | 对明确殖民地提前投入物资，遭遇轨道轰炸时主动启动有限保护；保护之后需要重新整备 |
| Stellaris Implementation | 复用行星决议、付费投入、局部旗标／限时修正及所有权检查；原版已有`planet_orbital_bombardment_damage`，目前赛斯应急也使用该字段 |
| Technical Difficulty | 中：核对预案准备、一次启动、有效期与重新整备；现有角色与主线任务不写完成事实 |
| Compatibility / Performance Risk | 只管理选定殖民地，不覆盖原版决议、不遍历全银河；与已有赛斯援助的叠加边界须在实现时确定 |

该建议不涉及人物组合，也不绑定新剧情、正式外观或终局奖励。开发期沿用一条新增正常流程、一处关键读档和本次严重失败点检查；不重新穷举十人。
