# 十名神器使玩法指引

当前为1.0开发版。十人已经接入中央庭与白夜馆，各有一项核心机制；人物正式美术、最终数值和发布前整体回归另行交付。最新运行结果见[项目进度](../PROJECT_STATUS.md)。

## 招募与任职

从“联络白夜馆”进入名册或人物通讯。安托涅瓦随中央庭开局接入；旧档从中央庭入口主动接入。其他角色通过各自招募选项加入，已加入的角色改为通讯入口，不会重复生成。

职业切换保留同一人物、等级、已付费用和任务记录，同时解除原任职。切换后请在原版界面重新安排总督、舰队或科研职责。只招募而未安排任务，不会自动获得人物的全部专属效果。经验与30级说明见[成长与职责](leader_growth_and_duty_v1.0.md)。

## 舰队能力

幽桐、拉比及其他人物的舰队任务需要本人实际指挥、玩家拥有并控制的普通军用舰队。专属恒定旗舰承担自己的危机职责，不承载这些普通舰队任务。

幽桐的校准依赖登记星系。离开现场或解除任职会失去校准，需要重新积累。校准完成后，真实交战可以提出一次越界支援；接受后消耗校准，支援持续30日，恢复期180日。拒绝与撤回都有独立等待期。

拉比的出勤约定不等于提前允许反击。真实交战登记实际对手后才提供保护，并由本人单独确认当次有限反击；反击持续30日，恢复期180日。和平期间不会仅凭外交敌对授予效果。

## 任务停滞时

- 先看人物通讯里的状态页，确认当前职业、本人任职、目标控制权和资源是否满足提示。
- 月度任务只累计有效工作：轰炸、控制权丢失、人物离岗或目标失效可能暂停、重置现场准备或终止当前安排。
- 已完成的工作保留结果和最近档案；重复打开窗口不会再发一次收益。冷却结束后才能开始下一项安排。
- 主动撤回保留已投入费用和恢复期。读档不会把人物任务变成新任务，也不会自动重开爱缪莎主线。

尚未逐项实测的应急、风险和替代路径按游玩反馈补测，不增加日常使用的确认步骤。
