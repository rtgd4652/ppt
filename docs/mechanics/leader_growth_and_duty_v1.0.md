# 领袖成长、职责与白夜馆

本说明对应1.0首版机制。本机当前运行版本为4.5.2；全Mod兼容与发布验收另行记录。

## 成长与等级

沿用原版领袖经验系统。任命到殖民地、舰队、科学船、内阁等有效岗位后，按原版规则增长经验；调查、特殊项目与实际战斗也有相应经验。仅加入白夜馆不提供持续任职经验。人物核心任务的工作次数和领袖经验是不同账目，例如安完成时序记录另有原生经验奖励。

现有全局定义将基础与最终等级上限都提高到30级，保留原版经验曲线。该设置同时影响普通领袖和AI领袖，并非爱缪莎专属上限；与其他修改领袖defines的Mod可能冲突，发布前需检查。当前没有另加自动全员升级或无限经验。

爱缪莎达到30级时使用成长肖像，正式转变仍需主线条件、玩家授权和爱缪莎自己的决定。第十四／十五章不足30级时，正常等待页可安排研修：每轮500凝聚力、200能源，180日后补足一级；不足时可继续安排。既有29→30运行证据见[里程碑2报告](../../reports/aemusa_main_story_milestone_2_2026-10-07.md)。

## 转职与任命

从人物通讯中选择允许职业。转职先解除当前任职，再改变同一领袖的职业；随后在原版领袖／岗位界面重新任命。原人物ID、等级、已有经验、任务成本与进度继续保留。职业或现场条件不符合时，工作按该任务规则暂停；转职不会退还物资、提前结算或清除恢复期。爱缪莎重复选择当前职业不会解除任命。

## 中央庭与白夜馆

安托涅瓦承担元首与公共方向，中央庭机构组织治理、研究和防卫，指挥使决定并承担实际行动。新预设使用中央庭公共协调体制；旧档通过明确的制度接入入口迁移，费用与治理变化在确认页说明。

白夜馆承担招募、联络、档案和管理入口，不另设为世界观势力。“任职与成长说明”三页仅展示信息，不启动人物任务、研修或主线选择。联动来客仅保留档案占位，未扩张当前十人实施范围。
