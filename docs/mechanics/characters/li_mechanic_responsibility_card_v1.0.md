# 丽 1.0 责任投资机制责任卡

## 1. 技术目标与硬边界

把“行政官默认／科学家／指挥官可切换＋责任投资”转换成单项目、成本与风险先登记、可审查、可履约并可止损的项目状态机。机制表现组织资源、工程验证、契约协商和失败责任，不实现凭空产出、直接购买科技或胜利、企业接管中央庭、债务劳工、绝对防御或全学科万能研究。

## 2. 作用域与项目目标

- 玩家国家持有唯一责任投资账本。
- 丽领袖保存唯一身份、当前职业和参与资格。
- 同时只允许一个主要项目；第一轮对象限定为事件登记的一个己方殖民地、一支丽所在舰队或一个虚拟工程验证项目。
- 项目启动前必须登记公共／防卫目标、受益对象、前期成本、已知风险和退出条件；缺少任一核心项时不能进入履约。
- 殖民地、舰队和工程项目共享同一账本结构，但履约行动不同，不能并发运行。
- 原型不接管银河市场、贸易系统、企业分部、公共福利或完整科技树。

## 3. 权威账本

国家层记录：项目类型、目标对象、公共／防卫目标、受益对象、登记成本、已付成本、风险类型、审查阶段、协商结果、履约路径、完成进度、风险状态、止损结果、资料保留、冷却和审计记录。

建议阶段：空闲 → 项目登记 → 审查准备 → 条款待确认 → 履约中 → 风险发生／调整待选 → 兑现／止损／失败 → 审计结案 → 冷却。

目标对象只保存参与标记和显示所需临时状态。对象失效、改变所有者或不再符合项目条件时，由国家账本结算；不得把完整投资只保存在星球、舰队、研究站或临时事件目标上。

## 4. 三职业切换与履约路径

- 优先使用同一丽实体切换行政官／科学家／指挥官。
- 切换前安全卸任，保留项目、成本、风险、受益对象、审查结果、履约进度、止损条件和审计记录。
- 行政官状态开放建设、安置、供应链、公共项目与长期组织路径。
- 科学家状态只开放机甲、工业、材料和工程应用相关的可行性验证与原型改进路径，不扩展为全学科研究。
- 指挥官状态开放护送、补给、防护、通信保障与保护性作战路径。
- 职业切换只改变可执行履约手段，不复制投入、清除风险、刷新退出条件或重复结算。
- 当前项目没有新职业可执行路径时保留并暂停，不自动改写项目类型。

## 5. 风险、协商、兑现与止损

- 风险必须在启动前登记或由受控事件明确加入，不能用不透明随机结果替代全部决策。
- 玩家可以在审查阶段缩小项目、修订条款或退出，但已经发生的合理成本必须保留。
- 合同与项目条款必须允许协商和退出；不能通过接受投资取消受益者的拒绝、离开与基本权利。
- 风险发生后只能选择追加承担、调整目标或止损；不能无代价回到项目开始前。
- 止损可以保留已经形成的资料、设施或人员保护成果，但不能返还全部成本或同时领取完整兑现收益。
- 项目兑现必须与最初登记目标相符；不能借工程项目直接购买未批准科技、舰船、领袖、忠诚或命运结果。
- 第一轮原型只验证账本与分支，不支付或奖励正式游戏资源。

## 6. 生命周期与失败回退

- 正常兑现：结算一次有限成果，形成审计记录并进入冷却。
- 主动取消：根据当前阶段结算已付成本；不能重复登记同一项目刷取更优风险。
- 目标失效或所有权改变：停止履约并进入止损／失败结算，不能无成本转移全部进度。
- 丽暂时不可用：账本保留，专属审查与履约暂停；不由其他领袖继承丽的专属路径。
- 丽死亡或解雇：终止人物专属推进，不自动重建；已经存在的公共设施、资料、人员保护和债务责任按结案规则保留。
- 读档：恢复国家阶段后验证丽、职业、项目对象、成本、风险和审计状态；无效引用进入止损清理。
- 重复事件／脉冲：每阶段只收费、推进、触发风险、兑现和审计一次。

## 7. 可行性方案

### 方案 A：国家单项目账本＋对象临时标记＋同一领袖三职业切换（推荐）

国家层持久保存成本、风险、进度与审计，项目对象只负责定位；能稳定处理三职业、目标失效、止损、读档和幂等。

### 方案 B：不同职业各自运行独立投资项目

容易复制投入与收益、绕过风险，并把丽拆成三个互不关联的模板，不符合共享责任账本的批准结论。

### 方案 C：把责任投资做成常驻资源与科研加成

实现简单，但会抹去审查、履约、协商、风险和止损，也容易滑向无条件财富增益，不采用。

## 8. 最小隔离原型

只验证：唯一丽、行政官／科学家／指挥官切换、一个虚拟殖民地项目、一个虚拟舰队项目、一个虚拟工程验证项目、成本与风险登记、条款修订、履约、一次受控风险、兑现或止损、目标失效、受伤／失联／死亡／解雇、存读档和重复触发。原型不消耗或提供正式资源、科技、舰船、人口、建筑或战斗收益。

## 9. 人工审核项

| 编号 | 审核内容 | 当前建议 | 状态 |
| --- | --- | --- | --- |
| LIM-001 | 作用域与并发 | 国家持有唯一责任投资；同时只运行一个事件登记的殖民地、舰队或虚拟工程项目 | 已批准 |
| LIM-002 | 权威状态 | 国家保存目标、受益者、成本、风险、审查、履约、止损、资料和审计；对象只存临时标记 | 已批准 |
| LIM-003 | 三职业切换 | 同一丽切换并共享账本；科学家仅限工程应用；切换不复制投入、清风险或重复结算 | 已批准 |
| LIM-004 | 风险与契约 | 风险预先登记或受控加入；条款可协商退出；投资不取消受益者权利 | 已批准 |
| LIM-005 | 兑现、止损与生命周期 | 兑现对应原目标；止损不全额返还；目标失效必须结算；暂时不可用暂停，死亡／解雇终止 | 已批准 |
| LIM-006 | 原型范围 | 只验证单项目、三职业、登记、审查、风险、兑现／止损、失效、读档与幂等，不加正式收益 | 已批准 |

## 10. 当前建议

LIM-001～LIM-006 已整体人工批准，采用方案 A，允许进入无正式收益的隔离技术原型。原型通过后，项目清单、成本、受益对象表达、风险来源、正式兑现与止损效果、UI 文本和平衡数值仍需逐项单独审核，不能因责任卡获批而自动进入正式实现。
