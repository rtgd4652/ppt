# 幽桐 1.0 自定射界机制责任卡

## 1. 技术目标与硬边界

把“指挥官单职业＋自定射界”转换成单舰队、单目标、可校准且可安全解除的远程支援状态机。机制体现选择保护对象、明确交战边界与一次有限的越界援护，不实现全银河狙击、自动处决、必然命中、无限火力、舰船复活或强制自我牺牲。

## 2. 作用域与目标

- 玩家国家持有唯一射界任务账本。
- 幽桐领袖保存唯一身份、指挥官职业和参与资格。
- 同时只允许一个主要射界任务，并绑定幽桐当前指挥或随行的唯一己方舰队。
- 保护对象第一版限定为该舰队自身或同星系、可见且仍有效的己方舰队；优先威胁必须是同星系可交战目标。
- 航道警戒与复杂敌方单位优先级仅保留为后续扩展，不进入第一轮原型。
- 目标脱离有效范围、改变所有者、被摧毁或失去可见性时，不能继续累积校准。

## 3. 权威账本

国家层记录：幽桐引用、承载舰队、保护对象、优先威胁、交战原则、校准阶段、越界可用状态、恢复阶段、暂停原因和冷却。

建议阶段：空闲 → 目标已登记 → 校准中 → 射界稳定 → 越界请求待确认 → 越界执行 → 恢复中 → 解除／冷却。

领袖、舰队和目标对象只保存参与标记与便于显示的临时状态。舰队重组、目标销毁或所有权变化后，必须由国家账本完成验证与清理，不能仅依靠舰队修正或事件目标维持完整流程。

## 4. 指挥官与舰队归属

- 幽桐保持指挥官单职业，不设计职业切换。
- 射界稳定依赖幽桐与承载舰队的有效关系；更换舰队时必须先安全解除旧射界，再登记新舰队并重新校准。
- 幽桐暂时离开岗位、受伤或失联时，现有记录保留但停止校准和专属支援，不把能力复制给继任指挥官。
- 舰队合并、拆分或船只补充不能复制射界任务、越界次数或完成记录。
- 幽桐重新回到有效岗位后，只能恢复仍然有效的原任务；无效目标必须清理并重新选择。

## 5. 校准与越界援护

- 校准只在承载舰队、保护对象与优先威胁满足同星系、可见性和有效性条件时推进。
- 频繁更换保护对象、威胁或交战原则会中断现有校准，不能通过反复点击刷取完成状态。
- 射界稳定后，只对登记对象和当前任务生效，不扩散到国家全部舰队。
- 越界援护必须由明确紧急条件触发并经一次确认；其用途限定为关键拦截、掩护或集中射击的状态表达。
- 越界执行会消耗当前校准并进入恢复期；恢复期内不能再次越界，也不能通过换舰队、重选目标或重复事件刷新。
- 第一轮原型只验证状态转换，不赋予正式伤害、射程、射速、命中或生存数值。

## 6. 生命周期与失败回退

- 正常解除：清理对象标记，保留一次已完成记录并进入必要冷却。
- 玩家主动取消：立即失去当前校准；不能借取消规避越界恢复期。
- 目标失效：停止推进，清理目标引用；已经进入的恢复期继续有效。
- 承载舰队被毁或不再属于玩家：任务失败并清理舰队引用，不转移校准成果。
- 幽桐暂时不可用：任务暂停并验证对象；恢复后可在目标仍有效时继续。
- 幽桐死亡或解雇：终止人物专属机制，不自动重建角色，也不把射界转交他人。
- 读档：从国家阶段恢复后重新验证幽桐、舰队和目标；无效引用进入清理。
- 重复事件／每日或月度脉冲：每一阶段只结算一次，不重复推进、触发越界或清除冷却。

## 7. 可行性方案

### 方案 A：国家单任务账本＋舰队与目标临时标记（推荐）

国家层保存权威阶段，舰队和目标只承担定位及显示。该方案能承受舰队重组、目标销毁、读档和重复触发，也最符合单射界边界。

### 方案 B：全部状态保存在幽桐当前舰队

实现直观，但舰队合并、拆分、转移和销毁会使状态容易丢失或复制，不采用。

### 方案 C：幽桐常驻提供全局远程火力修正

实现简单，但会失去保护对象、校准、个人边界和有限越界的核心，也容易变成全局数值膨胀，不采用。

## 8. 最小隔离原型

只验证：唯一幽桐、指挥官与承载舰队绑定、一个己方保护对象、一个同星系威胁、校准阶段、一次越界请求与恢复、主动解除、目标失效、舰队合并／拆分／销毁、受伤／失联／死亡／解雇、存读档和重复触发。原型不提供正式战斗修正，不建立航道网络，也不实现自动目标选择。

## 10. 当前建议

YFM-001～YFM-006 已整体人工批准，采用方案 A，允许进入无正式战斗收益的隔离技术原型。原型通过后，交战原则、紧急条件、正式效果、代价、UI 文本与平衡数值仍需逐项单独审核，不能因责任卡获批而自动进入正式实现。
