# 格蕾莎 1.0 生命档案机制责任卡

## 1. 技术目标与硬边界

把“科学家默认／指挥官可切换＋生命档案”转换成单病例、可暂停、可复核并保留伦理记录的医疗状态机。机制表现建档、取证、应急处置、分析与有限治疗方案，不实现复活、永生、万能治疗、批量生命改造、伤亡回滚或无条件人体试验。

## 2. 作用域与病例目标

- 玩家国家持有唯一生命档案账本。
- 格蕾莎领袖保存唯一身份、当前职业与参与资格。
- 同时只允许一份主要病例；第一轮对象限定为事件明确登记的己方殖民地或格蕾莎所在己方舰队。
- 病例来源必须明确其风险类别和作用对象，不把不同物种、环境、污染或战场损伤自动合并为通用结论。
- 没有有效样本、接触条件、研究时间或医疗资源时，不能直接完成分析。
- 原型仅使用虚拟病例验证流程，不接入全银河疾病、人口或战斗损伤扫描。

## 3. 权威账本

国家层记录：病例类型、病例对象、样本来源、证据阶段、风险状态、知情同意或紧急处置依据、已付成本、选择路径、治疗方案状态、审查记录、恢复阶段和冷却。

建议阶段：空闲 → 病例登记 → 接触／取样 → 证据收集中 → 应急处置待选／分析进行中 → 有限方案形成 → 应用／观察 → 结案／失败／冷却。

病例对象只保存参与标记和局部显示状态；对象失效、改变所有者或离开有效范围时，由国家账本完成结算与清理。不得只依赖星球修正、舰队修正或易失效事件目标保存完整档案。

## 4. 双职业切换

- 优先使用同一格蕾莎实体切换科学家／指挥官。
- 切换前安全卸任，保留同一病例、样本、证据、已付成本、伦理记录和恢复状态。
- 科学家状态开放取样、病因分析、方案验证与档案整理路径。
- 指挥官状态开放战场分诊、撤离、隔离和生命支持路径。
- 职业切换只改变当前可执行工作，不复制病例、证据或完成收益，也不能跳过等待与恢复阶段。
- 当前病例没有新职业可执行路径时保留并暂停，不自动改写成另一种病例。

## 5. 应急处置与医疗伦理

- 应急处置只在病例正在造成明确伤害且等待完整分析会扩大风险时开放。
- 应急处置可以稳定仍存对象，但不能自动形成完整研究结论，也不能恢复已经死亡或毁灭的对象。
- 非紧急研究必须保留知情同意和记录；紧急依据只适用于当前危机，不能成为永久取消患者权利的标记。
- 玩家不能通过重复开启病例、切换职业或取消流程绕过同意、重复取样或刷取结论。
- 未经同意的试验必须被记录为失败或违规路径，不作为推荐高收益操作；正式后果仍需另行审核。
- 格蕾莎本人的身体状态与医疗信息不自动成为国家所有的公共实验资源。

## 6. 生命周期与失败回退

- 正常结案：保留有限病例记录，清理对象参与标记并进入必要冷却。
- 主动取消：结算已付成本和已发生医疗后果，不能重新开启以重抽更有利结果。
- 病例对象失效：停止推进并清理引用；已发生死亡、舰毁或殖民地毁灭不回滚。
- 格蕾莎暂时不可用：账本与样本保留，专属分析暂停；已经启动的常规医疗可完成非神器部分。
- 格蕾莎死亡或解雇：停止人物专属推进，不自动重建；文明可以保留已完成的合规档案，但不能继续生成格蕾莎专属结论。
- 读档：恢复国家阶段后验证格蕾莎、职业、病例对象、样本和审查状态；无效引用进入清理。
- 重复事件／脉冲：每阶段只取样、支付、结算和记录一次。

## 7. 可行性方案

### 方案 A：国家单病例账本＋对象临时标记＋同一领袖切换（推荐）

国家层持久保存病例、证据与伦理记录，病例对象只负责定位；能处理职业切换、对象失效和读档，也避免同一病例被复制。

### 方案 B：殖民地和舰队各自维护独立病例

容易产生大量并发项目、弹窗和重复结论，并增加对象销毁后的清理负担，不符合 1.0 单病例边界。

### 方案 C：格蕾莎提供常驻全帝国治疗与寿命修正

实现简单，但会失去诊断、证据、应急取舍和伦理记录，也容易滑向万能治疗，不采用。

## 8. 最小隔离原型

只验证：唯一格蕾莎、科学家／指挥官切换、一个虚拟殖民地病例、一个虚拟舰队病例、取样与证据阶段、应急处置或继续分析的分支、一次合规记录、主动取消、对象失效、受伤／失联／死亡／解雇、存读档和重复触发。原型不提供人口、寿命、舰船修复、资源或正式战斗收益。

## 9. 人工审核项

| 编号 | 审核内容 | 当前建议 | 状态 |
| --- | --- | --- | --- |
| GLM-001 | 作用域与并发 | 国家持有唯一生命档案；同时只处理一个事件登记的己方病例对象 | 已批准 |
| GLM-002 | 权威状态 | 国家保存病例、样本、证据、成本、伦理记录、方案、恢复和冷却；对象只存临时标记 | 已批准 |
| GLM-003 | 职业切换 | 同一格蕾莎切换并共享档案；职业只改变可执行工作，不复制证据或收益 | 已批准 |
| GLM-004 | 应急与伦理 | 应急只稳定现存对象且不自动完成研究；知情同意与违规记录不能被切换或重开绕过 | 已批准 |
| GLM-005 | 生命周期 | 暂时不可用则暂停专属分析；死亡／解雇终止专属推进；对象失效不回滚既成死亡 | 已批准 |
| GLM-006 | 原型范围 | 只验证单病例、双职业、取证、分支、伦理记录、失效、读档与幂等，不加正式收益 | 已批准 |

## 10. 当前建议

GLM-001～GLM-006 已整体人工批准，采用方案 A，允许进入无正式收益的隔离技术原型。原型通过后，病例来源、同意表达、紧急条件、正式治疗效果、代价、违规后果、UI 文本与平衡数值仍需逐项单独审核，不能因责任卡获批而自动进入正式实现。
