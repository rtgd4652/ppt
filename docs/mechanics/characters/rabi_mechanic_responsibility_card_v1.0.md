# 拉比 1.0 阿米特的守则机制责任卡

## 1. 技术目标与硬边界

把“指挥官单职业＋阿米特的守则”转换成单舰队、单保护任务、以可观察敌对行为为依据的保护状态机。机制表现玩家制定任务边界、阿米特保护、拉比有限反击和及时撤离，不建立善恶审判、思想读取、全银河敌意扫描、自动处决、无限吸收伤害或未成年人独立军权。

## 2. 作用域与目标

- 玩家国家持有唯一行动守则账本，并承担任务授权与武力责任。
- 拉比领袖保存唯一身份、指挥官职业和参与资格；阿米特作为拉比机制的一部分记录，不创建可被单独转让的领袖或舰船。
- 同时只允许一份行动守则、一支拉比承载舰队和一个主要保护对象。
- 第一轮保护对象限定为拉比所在舰队自身或同星系、可见且有效的己方舰队。
- 威胁对象必须通过已经发生的攻击、追击或事件确认登记；不能仅凭物种、政体、外交标签或玩家主观选择判定“邪恶”。
- 原型不扫描全银河战斗，也不尝试建立通用司法、犯罪或谍报判断系统。

## 3. 权威账本

国家层记录：拉比引用、承载舰队、保护对象、交战标准、撤离条件、当前威胁对象、威胁确认阶段、阿米特保护状态、有限反击状态、恢复阶段、暂停原因和冷却。

建议阶段：空闲 → 守则待确认 → 保护任务进行中 → 威胁已登记 → 阿米特保护 → 反击待确认 → 有限反击 → 撤离／恢复 → 完成／失败／冷却。

领袖、舰队和保护对象只保存参与标记与显示所需临时状态。目标销毁、舰队重组或所有权改变后，由国家账本验证和清理；不得把完整流程只保存在舰队修正、战斗对象或全局事件目标中。

## 4. 威胁确认合同

- 正式机制只能依据游戏中可以稳定验证的敌对行为或明确事件结果登记威胁。
- 同一时刻只维护一个主要威胁对象；新威胁不能覆盖正在结算的保护或恢复状态。
- 威胁确认只针对当前行动对象，不外推为对敌方国家、物种或人口的永久有罪判定。
- 威胁对象失效、撤退、停止满足任务条件或离开有效范围时，停止继续积累确认，并进入解除或重新评估。
- 第一轮隔离原型使用受控事件登记一次虚拟敌对行为，不尝试直接监听所有战斗细节；战斗触发来源必须在原型通过后另行验证。
- 重复登记同一敌对行为不能重复推进、重复解锁反击或刷新保护状态。

## 5. 阿米特保护与有限反击

- 守则生效时先保护后反击；阿米特保护只能围绕登记的保护对象与现实威胁发生。
- 有限反击必须在威胁达到条件后由玩家请求，并保留拉比确认、拒绝或撤离的叙事接口。
- 反击只消费当前威胁确认并作用于当前任务，不扩散为对整个敌对文明的惩罚。
- 反击完成后必须进入恢复或撤离阶段，不能依靠重复事件、换舰、取消任务或重设守则立即再次触发。
- 阿米特保护不能撤销已发生的舰船损失、无限复活拉比或阿米特，也不能保证战斗胜利。
- 第一轮原型不提供正式减伤、伤害、射速、命中、撤离概率或其他战斗数值。

## 6. 指挥官、舰队与生命周期

- 拉比保持指挥官单职业，不设计职业切换，也不把职业称谓解释为成年军衔或独立战略授权。
- 更换承载舰队必须先安全解除旧守则；新舰队需要重新登记保护对象和撤离条件。
- 舰队合并、拆分或补员不得复制守则、威胁确认、反击次数或恢复状态。
- 拉比受伤、失联或暂时不可用：账本保留并暂停专属推进；阿米特不得被其他领袖继承。
- 拉比死亡或解雇：终止人物专属机制，不自动重建，不把阿米特拆分成独立装备。
- 保护对象或承载舰队失效：按失败或撤离结算，清理引用，不能无成本转移全部进度。
- 读档后从国家阶段恢复并验证拉比、舰队和目标；重复事件与脉冲每阶段只结算一次。

## 7. 可行性方案

### 方案 A：国家单守则账本＋受控威胁登记＋对象临时标记（推荐）

国家层保存完整阶段，受控触发登记可观察威胁，舰队与目标只承担定位和显示。该方案最能限制误判、重复结算和对象失效，也符合一份守则的边界。

### 方案 B：持续扫描所有战斗并自动累计威胁

触发频率、性能、战斗作用域和兼容性风险较高，还容易把局部保护机制扩张为全局审判，不作为第一版方案。

### 方案 C：阿米特提供常驻全舰队减伤与反伤

实现简单，但会失去守则、威胁证据、撤离责任和有限反击的角色核心，不采用。

## 8. 最小隔离原型

只验证：唯一拉比、一份守则、一支承载舰队、一个己方保护对象、一次受控威胁登记、阿米特保护阶段、一次有限反击、撤离／恢复、主动取消、对象失效、舰队合并／拆分／销毁、受伤／失联／死亡／解雇、存读档和重复触发。原型不提供正式战斗收益，不监听全银河战斗，也不实现善恶、司法、犯罪或谍报系统。

## 10. 当前建议

RAM-001～RAM-006 已整体人工批准，采用方案 A，允许进入无正式战斗收益的隔离技术原型。原型通过后，真实战斗触发来源、交战标准、撤离条件、正式效果、代价、UI 文本与平衡数值仍需逐项单独审核，不能因责任卡获批而自动进入正式实现。
