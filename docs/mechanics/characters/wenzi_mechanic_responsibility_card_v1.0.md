# 雯梓 1.0 经纬共局机制责任卡

## 1. 技术目标与硬边界

把“行政官默认／指挥官可切换＋经纬共局”转换成单棋局、单目标、黑白行动共享进度并可明确收官的布局状态机。机制表现共同目标、保护边界、攻守转换与现实代价，不实现全知战略、未来预言、思想控制、全银河棋盘、无限资源或把人口和舰员视为可牺牲棋子。

## 2. 作用域与棋局目标

- 玩家国家持有唯一棋局账本。
- 雯梓领袖保存唯一身份、当前职业和参与资格。
- 同时只允许一局主要布局；第一轮目标限定为事件登记的一个己方殖民地或雯梓所在的一支己方舰队。
- 开局必须登记一个共同目标和一个保护边界；没有这两项时不能开始黑白行动。
- 殖民地棋局与舰队棋局使用同一状态模型，但可执行行动不同，不能同时并行。
- 原型不将整个星系、全部殖民地或全部舰队纳入一局，也不自动寻找所谓最优目标。

## 3. 权威账本

国家层记录：棋局类型、目标对象、共同目标、保护边界、黑子行动记录、白子行动记录、布局阶段、失衡状态、已付成本、已形成成果、收官原因、暂停原因和冷却。

建议阶段：空闲 → 目标登记 → 边界待确认 → 布局进行中 → 稳定／失衡 → 收官待确认 → 完成／失败／冷却。

目标对象只保存参与标记和显示所需临时状态。对象失效、改变所有者或不再满足条件时，由国家账本执行收官或失败清理；不得把完整棋局只保存在星球或舰队修正中。

## 4. 黑白行动与失衡

- 黑子和白子是两类行动方向，不代表善恶、阵营或人格等级。
- 每一步必须与已登记共同目标及保护边界相容；违反保护边界的候选行动不能自动执行。
- 连续偏向同一侧只记录为失衡风险，不直接生成未经审核的正式惩罚或收益。
- 合理衔接黑白行动可以进入稳定阶段，但不能永久叠加为无限产出、防御或伤害。
- 重复点击同一行动、重复事件或月度脉冲不能重复支付、推进或结算。
- 失衡达到边界后必须暂停并要求修正或收官，不能通过职业切换、取消目标或读档刷新记录。

## 5. 双职业切换

- 优先使用同一雯梓实体切换行政官／指挥官。
- 切换前安全卸任，保留共同目标、保护边界、黑白记录、失衡、已付成本和收官状态。
- 行政官状态开放共同体协商、建设、安置、公共服务、修复和文化延续类行动。
- 指挥官状态开放部署、压制、掩护、围挡和撤离通道类行动。
- 职业切换只改变下一步可用行动，不复制棋局、清空失衡或重复结算成果。
- 当前棋局没有新职业可执行行动时保留并暂停，不自动把殖民地棋局改写为舰队棋局或反向转换。

## 6. 自主选择、收官与生命周期

- 保护边界必须允许受影响对象拒绝、离开或改变选择；机制不能把保护转换为永久占有。
- 正常收官：结算有限成果与代价，清理目标标记并进入必要冷却。
- 主动放弃：必须记录放弃原因并结算已付成本，不能借放弃重抽更便宜目标。
- 目标失效或所有权改变：停止推进并执行失败收官；不能把完整进度无成本转移到新对象。
- 雯梓暂时不可用：国家账本保留，棋局暂停；不得由其他领袖继承其专属行动。
- 雯梓死亡或解雇：终止人物专属推进，不自动重建；已经完成的公共工程或现实后果保留。
- 读档：恢复国家阶段后验证雯梓、职业、目标和保护边界；无效引用进入收官清理。

## 7. 可行性方案

### 方案 A：国家单棋局账本＋对象临时标记＋同一领袖切换（推荐）

国家层统一保存共同目标、黑白行动、失衡和收官状态，目标对象只承担定位；可稳定处理职业切换、对象失效、读档和重复触发。

### 方案 B：殖民地与舰队分别维护两套棋局

容易形成并发状态、重复收益和两套清理逻辑，也会削弱“同一角色、同一共局”的统一性，不作为 1.0 方案。

### 方案 C：把黑白行动压缩成可切换的常驻国家加成

实现简单，但会失去共同目标、保护边界、布局过程和收官责任，不采用。

## 8. 最小隔离原型

只验证：唯一雯梓、行政官／指挥官切换、一局虚拟殖民地布局、一局虚拟舰队布局、共同目标与保护边界、黑白行动、稳定与失衡、主动收官、放弃、对象失效、受伤／失联／死亡／解雇、存读档和重复触发。原型不提供正式资源、人口、建筑、舰船或战斗收益。

## 10. 当前建议

WGM-001～WGM-006 已整体人工批准，采用方案 A，允许进入无正式收益的隔离技术原型。原型通过后，共同目标类型、保护边界表达、黑白行动、失衡阈值、正式效果、代价、UI 文本与平衡数值仍需逐项单独审核，不能因责任卡获批而自动进入正式实现。
