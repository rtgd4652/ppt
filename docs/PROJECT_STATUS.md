# PROJECT_STATUS

> 更新时间：2026-07-11
> 当前版本：`0.1.0` 封版候选
> 当前分支：`parallel/v1-integration`
> 详细总控文档：`docs/project/project_status_v0.1.md`

## Completed

- 仓库已拆分为 `mod/`、`knowledge/`、`assets/`、`docs/`、`reports/` 与 `tools/`。
- `mod/` 已成为 Stellaris 唯一加载根目录。
- 神器使物种、肖像、种族特质、起源、专属初始星球与预设帝国已经接入。
- 白夜馆已经作为招募、联络、档案展示与管理的功能入口接入；它不是世界观组织或政治势力。
- v0.1 已接入四名可招募神器使：爱缪莎、赛斯、幽桐、拉比。
- 已建立唯一招募、领袖职业、专属 trait、30 级上限与爱缪莎立绘切换基础。
- 专属飞升、传统、科技、建筑、岗位与区划已经形成第一版可玩闭环。
- 专属星球已使用国家 flag 防止重复生成。
- 命运观测塔四阶段脚本与政策模式已经存在。
- 命运之主舰体、模型、区段、核心组件、双光环、跃迁核心与重构事件已经存在。
- 命运之主当前复用泰坦名称表，避免自定义舰种无法生成舰名或舰级名。
- Wiki 采集已经完成 Raw、Clean、图片索引与 Mod Ready 摘要闭环。
- 七名角色完成批量采集；爱缪莎、安托涅瓦、晏华完成标准角色档案。
- 世界观、神器、组织、时间线、剧情与角色关系圣经已经建立。
- 已完成 v0.1 确定性静态修复：无效 `trade_value` 已改为 `trade`，GFX 脚本 BOM 已移除。
