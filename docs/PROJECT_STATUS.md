## Konwn Issues（Known Issues）

已知问题与风险：

- 领袖与物种肖像显示问题
  - 爱缪莎领袖与物种肖像曾出现只显示腰部或下半身的问题。
  - 需要继续检查 portrait sprite、裁切尺寸、DDS、portrait 配置与 UI 显示区域。

- 命运之主显示名问题
  - 舰船名称或设计界面中可能仍显示内部 key，例如 `destiny_lord_cap`。
  - 需要继续检查本地化 key、ship size、section template、global ship design。

- 命运之主舰船设计 UI
  - 武器与组件数量多，可能超出舰船设计界面边框。
  - 需要继续压缩槽位布局，合理分配 T、X、L、A、光环、护盾、装甲等槽位。

- 命运之主跃迁问题
  - 曾出现舰队无法跃迁，提示缺少跃迁引擎的问题。
  - 需要继续确认专属跃迁组件是否被舰船正确识别。

- 命运之主组件与自动设计
  - 专属组件、反应堆、推进器、作战电脑、光环已经加入，但仍需完整游戏内验证。
  - 自动设计可能仍会出现缺组件、不能保存或设计不合理的问题。

- 科技与建筑解锁
  - 曾出现建筑科技、武器科技未刷出或法令解锁后仍无法建造的问题。
  - 需要继续检查科技权重、前置条件、allow/potential、建筑限制与调试法令。

- 仓库结构迁移后的路径风险
  - 现在实际 Mod 内容位于 `mod/`。
  - 部分旧开发脚本已经更新路径，但后续如果复制旧脚本，仍可能写回旧目录。
  - 启动器、本地测试脚本、导出脚本都应以 `mod/` 为游戏加载根目录。

- 大体积美术资源
  - Blender 文件、DDS、PNG、OBJ、MESH 文件较多，仓库体积会持续增长。
  - 后续可能需要考虑 Git LFS 或发布包与源素材分离。
