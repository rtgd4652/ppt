# README

## 项目介绍

《神器使》Stellaris Mod 是一个以《永远的七日之都》为灵感来源的群星模组项目，核心目标是把“神器使、中央庭、白夜馆、黑门、命运观测、七日循环”等概念转化为 Stellaris 的可玩系统。

当前项目已经包含：

- 神器使物种、种族特质、起源与预设帝国。
- 白夜馆通讯入口与领袖召唤框架。
- 爱缪莎领袖、职业切换、等级成长与立绘切换。
- 专属建筑、区划、岗位、科技、传统与飞升。
- 命运之主终局舰船、专属组件、武器、光环与模型。
- 命运观测塔巨构概念、建模方案与后续开发规划。

仓库根目录用于管理源码、素材、文档和工具；真正给 Stellaris 加载的内容位于 `mod/`。

## 安装方法

本地开发测试时，Stellaris 启动器应指向以下目录：

```text
C:\Users\Admin\Desktop\ppt\simple_leader_edict\mod
```

推荐做法：

1. 在 Stellaris 启动器中创建或编辑本地 Mod。
2. 将 Mod 路径设置为仓库内的 `mod/` 目录。
3. 确认 `mod/descriptor.mod` 能被启动器识别。
4. 启动游戏后，在播放集启用该 Mod。

注意：不要把仓库根目录当作 Mod 根目录加载。仓库根目录包含 `docs/`、`assets/`、`tools/` 等开发资料，游戏只需要读取 `mod/`。

## 依赖

基础依赖：

- Stellaris 4.4.*。
- Windows 本地开发环境。
- Git，用于版本管理和 GitHub 同步。

美术与模型相关依赖：

- Blender，用于舰船和巨构模型制作。
- Blender MCP，用于辅助自动化建模。
- PDX Mesh 导入/导出插件，用于将 Blender 模型导出为群星可读取格式。
- 图片处理工具或 Python Pillow，用于 PNG/DDS 图标与贴图生成。

开发约定：

- 所有 Stellaris 脚本继续添加中文注释。
- 后续 commit 信息统一使用中文。
- `mod/` 内只放游戏运行需要的最终文件。
- `assets/official_reference/` 只放参考资料，不直接进入最终 Mod。

## 开发计划

当前推荐并行开发线：

1. 稳定修复线  
   处理报错、本地化缺失、启动器识别、舰船槽位、组件、跃迁、图标边框等问题。

2. 白夜馆与领袖线  
   负责白夜馆通讯入口、爱缪莎交互、五名新增领袖、职业切换与专属技能。

3. 内容扩展线  
   负责神器使物种、起源、预设帝国、科技、建筑、区划、传统、飞升、巨构政策模式。

4. 美术与模型线  
   负责命运之主模型精修、命运观测塔建模、DDS 贴图、图标、立绘裁切与游戏内显示。

5. 总控/合并线  
   负责路线图、Git 提交、冲突检查、发布包、`error.log` 验收和版本号管理。

每条线应尽量避免同时修改同一个文件。需要跨线修改时，由总控线统一合并。
