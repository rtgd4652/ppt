## 入口与交付

物理T5“高维模型复核”保留A09＋A10前置，科研费24000、权重50。黑门观测站通过原生升级进入“高维观测复核站”；新站`can_build=no`，建造600日，基础成本1800矿物/300合金/300消费品，维护10能源/2消费品。

首版沿用原塔罗分析师4＋2条件原始岗位容量、2稳定与A05当地有效样本比对收益。本包不改岗位定义或全线4.5人口尺度；没有把原始容量声称为实际就业人数。新功能是模型复核，正式岗位尺度和平衡后续统一。

原低级入口看到最终阶段已建/在建时阻止重复新建，旧设施存在资格保留。遗留并存时由活动最终阶段供给岗位和比对，防止一份收益同时来自低/高级。最终阶段同时承接A09对照端和地方应用；升级中的普通站与升级后最终站均有合法供源，已有360日窗口不被清除。

## 模型与事实复核

| 行为 | 费用与条件 |
| --- | --- |
| 启动模型复核 | 正常行星决议一次600能源、300消费品、100稀有水晶 |
| 真实资料 | 本国A09联校档案，以及A10研究和已结算的公共接口记录 |
| 推进 | 活动最终站、本国控制、未受轰炸且原拥有者有效，完成4次有效月度；全国同时一处 |
| 暂停/撤销 | 失效保留工作量，停工不补跑；原拥有者可撤销、不退款；转让/消失由ACS清理未完成状态 |
| 完成 | 本国永久保存`amr_model_reviewed`，为A12提供可读取资格 |
| 后续补录 | 300能源、100消费品；必须已有模型、有效复核站和至少一种尚未纳入的新资料 |

普通模型可在危机前完成。完成时只附带当时已存在的事实，后续新资料可补录；没有新资料时不重复扣费。进度页只读，模型、危机事实与损失档案分别显示。

危机事实来源是原主线“原版危机已经发生”或真实锚点现场基准记录；仅表示背景事实经过对照，不表示反制或胜利已验证。损失来源必须为已初始化专属危机，且锚点损失变量已存在并≥1；该计数由原真实资源损失接口维护。复核只写本包档案，不写主线旗标、计数或历史，不恢复已损失资源。

## 工程与来源

沿用ACS行星月度、原拥有者和清理接口，没有新on_action、定时追踪或银河扫描。新增当地过程修正/变量，以及三个国家完成记录。已完成国家知识不随场地转让或失效撤销；旧库存、联校档案与地方窗口保持各自规则。

先查七都数据库，再读神器/组织/术语源。模型适用条件、观测偏差与证据可审查是Mod工程转译，保留黑门未知；来源审核状态不变，不产生预知能力或个人转变资格。
