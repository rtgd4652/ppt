## 交付与代价

| 节点 | 首版能力 |
| --- | --- |
| B08 共鸣制造质量控制 | 圣炉沿原槽升级为精密合金炉，复用冶金师；低级800、高级1000岗位容量，维护35→50能源。岗位每100单位的配方保持。 |
| B11 分布式配给仓储 | 配给仓允许当地预留一份500矿物＋100合金的工程物资；主动撤回返还80%，重复调用不重复退款。用于本星工程后，180日建筑建造速度＋20%，物资已消耗，不能再撤回。 |
| B13 稀有共鸣定向精炼 | 精炼所升级；600定向精炼师容量。均衡方案每100单位产出三类各3.5；专精主产物6、其余各1.5。切换花200矿物＋300能源，调整90日，期间按原配方各3产出。每100单位维护20矿物＋10能源；不叠加多种专精。 |
| C11 跨殖民地联运 | 每国一处始发端、一处接收端，两地均需换装站与配给仓。100能源把始发端一份已付费物资转给空的接收端，不能复制。两端各一份物资＋1000能源＋300合金可向已有巨构供应，提供360日建造速度＋10%，不能刷新或叠加同一供应。 |
| C12 文明契约共治 | 指挥中心／契约议事厅升级，保留驻防接入。在拥有有效高级设施的当地以500能源＋250凝聚力选择一项公共方案，调整180日后提供收益：工业合金＋10%及岗位矿物维护＋5%；科研三系各＋5%及岗位消费品维护＋5%；民生稳定＋3及舒适度消耗−10%。 |

这是初始数值，不代表自然平衡已验。公共研究总数由52增至57；新增6个行星建筑定义、1种岗位，组件85／陆军5／星港建筑1不变。四座旧建筑保留原科技直建资格，仅接升级、同族互斥供岗与4.5人口容量单位修正；其他旧楼不连带改动。

## 状态与接口

- 所有入口为殖民地决议；即时检查控制权、科技、设施、状态与费用。固定投入由效果逐项实际扣除，避免决议折扣配合固定退款套利。
- 预留物资、联运角色、精炼方向、共治方向均为当地独立状态；国家仅持有已交付的大型工程供应修正。原拥有者使用行星载体索引保存，枚举殖民地时显式回到carrier。
- 转让、失去拥有者或殖民地毁灭时清理本包当地记录且不退款；月度只检查带本包标记的殖民地。占领或设施停用使新运输和方向收益不可用，选择保留，恢复后继续。
- 已经交付的工程物资不因运输端后续停用撤回；当地工程加成仍在殖民地转让时清理。联运是有限端点之间的付费调度，不模拟运输舰或全银河物流。
- 高级指挥中心接续R3c驻防名额和维护；同星低级／高级设施意外并存时，高级优先供岗和方案，不能重复获得驻防或共治收益。
- 精炼与共治均保留均衡／取消入口；取消不返还调整费、不提前清除冷却。玩家提示写清投入、调整期、交付后不可退款及失去殖民地的物资损失。

## 参考及验收边界

本机原版4.5.2是语法依据。参考技能中的建筑／科技／决议样本、现有R1/R2e载体索引和R3c驻防接口，以及原生巨构建造速度、建筑建造速度和岗位条件产出字段。

其他Mod只作模式参考：本机ACOT（1419304439，描述文件声明4.4）中的建筑升级与基础设施组织；舰R（1747099270，声明4.5）中的当地方案修正驱动岗位条件收益。它们不是本Mod运行证据，旧版字段仍需原版核对；不复制其素材、数值体系或整段机制。尚未找到可直接复用的同类两端物资账本，本包独立实现。

源码检查重点是付费物资守恒、重复退款／转运、端点唯一性、转让清理和高级设施供源去重。复用现有严格脚本夹具，只补实际用到的条件；不另建完整游戏模拟器。既有R3d证据不重测。
