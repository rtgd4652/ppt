## 实际恢复与收尾

复用ACS原月度：本地控制、无轰炸、工场/研究有效且原拥有者不变时，每次最多施工一次。当前荒废度至少5才调用`add_planet_devastation = -5`并累计一次有效工作，最多6次。工作达到6，或当前荒废度低于5时收尾；低余量交给原生自然恢复，避免依赖负值截断。

原生自然恢复或其他正常能力可先减轻损伤；若本项目尚未施工时荒废度已低于5，直接记录0次收尾，不伪称已完成六次施工。每轮最多额外减少30点，不保证清零全部损伤。仍达到10时可再付一轮，不自动循环或退款。

收尾保留本轮实际施工次数和空的地方记录`acr_rebuild_done`，供只读进度页查看；它不提供数值收益、国家胜利资格或资源。新一轮会更新记录。建筑废墟仍走原生维修队列；不补人口、重建已摧毁设施、返还锚点已损失资源或改写伤亡/胜利历史。

## 暂停、撤销与归属

占领、轰炸、工场停用/拆除或研究失效时，保留已付款、施工次数及全国占位，不补跑暂停月份。恢复条件后按原工作量继续。原拥有者可在这些失效情况下撤销剩余项目，无退款；已降低的真实荒废度不回滚，其他库存/项目保留。

转让、失去拥有者或毁灭由原ACS清理移除本地过程、收尾记录和工作变量。新拥有者不继承旧投入或收尾资格，已实际改善的行星状态留在行星上。国家公共知识、F03/F04状态、人物机制、C2及旗舰恢复源码未修改。

新增一个手动触发的只读进度页，显示未开始/施工/暂停/收尾；查看不扣费、不恢复、不重发奖励。没有新on_action、月度订阅或全局目标；只有玩家开始时按需核对全国占位，施工复用既有ACS遍历。
