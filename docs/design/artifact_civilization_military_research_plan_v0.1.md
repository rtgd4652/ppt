## 舰船组件分工

| 方向 | 研究入口 | 责任 |
| --- | --- | --- |
| 舰载接口与A槽 | D04／D10／D11 | D04交付新增标准化供能辅助适配器，D10分化战术／支援A槽，D11负责维修回收侧用途；A槽与必需作战电脑分别登记。 |
| 舰载传感 | D05 | 观测型／射控型变体与既有ARTIFACT_SENSOR系列分别映射；A06地表阵列和E06星港接口保留原职责。 |
| 近程与长程武器 | D06／D08 | 武器在射程、追踪、伤害对象、功耗和维护间取舍；S/M/L是同族尺寸，不重复计科技。 |
| 护盾 | D07／D09 | D07偏折护盾、D09分层防御及硬化；与实体装甲的研究入口分开。 |
| 实体装甲 | D15／D09 | D15基础公共符文装甲；复合强化变体要求D15与D09均已研究，不能只研究护盾就得到新装甲族。 |
| 舰用能源 | D16／D13 | 正常公共舰体功率和维护预算；后期承载另依D13及舰型规格，不复用50000功率的旧专属核心。 |
| 亚光速推进 | D17／D13 | 速度、闪避与能耗取舍；各舰体可装尺寸及自动设计须在对应组件包核对。 |
| 超空间航行 | D18／D13 | 航道航行／充能分工，战略跳跃资格另随高阶舰体责任卡验证；与亚光速推进分开。 |
| 作战电脑 | D10 | 按交战距离和平台职责提供电脑变体，并分别核对实际行为；保留旧ARTIFACT_COMBAT_COMPUTER系列。 |
| 高阶场域与承载 | D12／D13／D14 | D12限时脉冲、D13承载与D14付费行星/星港联防均已接源码；原生作用与维护结算待集中试玩，旧光环和个人舰继续独立。 |

D04交付实际A槽适配器，不作为只有前置作用的空研究。反应堆、推进器和FTL是不同组件族；作战电脑和A槽也分别验收。新装甲复合强化读取D15＋D09，不把所有防护继续塞回单一总包。部件尺寸、舰型、能耗和自动设计均在对应包定义，当前不虚构性能或声称已可装配。

高阶公共反应堆、推进器和FTL变体分别要求D13＋D16、D13＋D17、D13＋D18；这些是新组件的组合科技条件，D13研究本身保留原前置。对应旧组件门槛继续保持。

## 陆军发展

| 方向 | 节点 | 玩家用途 |
| --- | --- | --- |
| landing | D01／D19 | 原守备队保留；新增定向登陆队，强调低附带伤害与目标保存。 |
| garrison | D20／D14 | D20提供有限有维护的原生守备军；D14付费联防提升当地守军质量并连接同星轨道接口，不增加原驻防名额或免费创建军队。 |
| siege | D02／D21 | 原共鸣军保留；新增攻坚军，强调耐久与突破，并付出训练、维护及附带伤害代价。 |
| reconstitution | D22 | 接收端消耗一份物资、500能源及200消费品，提供360日当地训练速度+25%和新军经验+50；仍须正常招募，不治疗或复活现有部队。 |
| late | D03／D14 | 原终解军团作为现有T5基线继续保留，不再仅为补数量追加更高数值的重复兵种；公共防务资格不读取个人转变。 |

定向登陆队和攻坚军计划为两类新增侧重兵种；现有三种陆军不删除。驻防使用当地有维护的原生防御军，整补以原生训练和补充效率落地，避免承诺尚未验证的队伍治疗或跨星系瞬间补员。D03已有T5军团保留，因此不再仅为多列一个研究而增加更高数值的重复终局陆军。

## 兼容和制作顺序

先交付新研究和新变体，旧三个科技总包、43个旧公共组件入口、三种旧陆军、旧舰船设计保持。后续若要收敛总包，必须单独落实新档与旧档的迁移方式；在此之前不撤旧能力、不改旧前置，也不批量免费授予新树。个人专属舰、旧舰型限定件和四个光环原型各自登记。
