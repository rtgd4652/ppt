## 玩家得到的能力

一颗殖民地真实完成封存样本分析或材料试制后，趁720日成果仍在，通过“当地公共项目”页面把方法提交给活跃档案设施。方法成为本国永久公共记录；另一颗殖民地不必重新取得原始危险样本或建造原工坊，可在研究园区付费复现。记录不是可交易货币，不赠科技、资源或个人权限。

C10只接受当地现有`artifact_foundation_sample_analysis`／`artifact_foundation_materials_study`成果修正，须本国拥有控制、无轰炸、有活跃记忆档案室或中央庭记忆宫；窗口所属国家仍须一致。每国每种方法仅归档一次，免费提交，不消耗或续期当地成果。旧档现存成果可以提交；已过期且无法辨认来源的历史记录不补算。基础／精密营建、人物任务、危机和个人转变均不是本包来源。

## 复现流程

现有“受控样本分析”和“工坊公共工程”选择页分别增加样本／材料复现；归档入口位于成果有效时的“当地公共项目”页，不增加白夜馆分页。研究说明指明入口与前置。

两种复现均需C10、E05、本国对应公共记录、当地活跃园区或原研究尖塔、拥有与控制一致、无轰炸，以及空闲公共项目名额。每次提交300能源＋150消费品，在效果内再次校验后分别扣除，6次有效月度完成。打开或关闭窗口不收费、不推进。复现和R1四方案共享当地名额，成果有效期内均不能新开或刷新。

样本复现取得原生当地物理岗位研究+10%／720日；材料复现取得工程岗位研究+10%／720日，复用既有成果修正。全国公共记录不消耗，期限届满后可以再次付费。收益没有独立乘区或免费延长期限。

## 状态、失效与兼容

公共记录为两个独立国家flag；不作为后续研究的隐含额外前置，本包不改A12等设计依赖。新增两种模式复用R1月度入口、`arf_r1_owner@this`、进度和付费标记，无新增扫描、计时器、项目货币或回调。源码按既有4.5.2月度colony→carrier切换；不以同号混用行星／殖民地索引。

设施停用、损坏、占领、轰炸或复现研究资格失效时保留已付进度并暂停；园区正常升级后由活跃尖塔接续。转让、毁灭或中止沿既有清理，只清当地项目／成果，投入不返还。旧国已提交的方法仍归旧国，接收星球的新国不获得知识记录；旧窗口不能从新国扣费。已完成的720日成果沿现有R1规则自然计时，不因档案楼或研究园区拆除而重置或退费。

原R1四种付费方案、费用、3／4次月度及720日收益保持；归档不改变它们的账本。C2、人物、主线、遗留个人科技与公开军备均不读写。
