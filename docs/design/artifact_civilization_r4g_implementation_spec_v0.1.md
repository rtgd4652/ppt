# R4g 文明联合防务实施规格 v0.1

2026-10-31，基线`7ef9403`。D14源码及必要检查完成；未运行游戏。完整参数见[结构化规格](artifact_civilization_r4g_implementation_spec_v0.1.json)。

## 玩家获得的能力

“文明联合防务”为社会T5研究，保留D10＋C12前置，科研费24000、权重50。研究后可在已有有效行星驻防的殖民地，通过正常决议部署联防；还需同星系、本国拥有和控制的正常星港及已建成的E06轨道观测接口。接口不要求同时存在远程观测阵列；原观测/预警收益仍按各自条件判定。

| 项目 | 首版实现 |
| --- | --- |
| 一次部署 | 500能源、300合金、200消费品，原生决议一次扣除 |
| 地表收益 | 当地防御军伤害与生命值各+25%；保持原D20两名额，不创建新军队/舰队 |
| 额外维护 | 每个有效联防殖民地每月4能源、1合金；原设施和驻防维护另算 |
| 轨道收益 | 本座星港射速+15%、索敌+10；不扩展到机动舰队或防御平台 |
| 多殖民地 | 每处独立支付和维护；同一星港只获得一份加成 |
| 运行期限 | 登记持续有效，直到主动撤销、原驻防撤销/重部署或殖民地转让/消失清理 |

玩家可随时在本国控制的行星撤销联防，即便研究、设施或接口已失效。撤销不退款，保留原驻防；再次部署需重新投入。行星修正图标显示“已登记”，不把登记本身当作正在提供收益。

## 有效状态与清理

地表收益和联防额外维护使用同一组条件。沿用统筹中心→分部→社区的原驻防优先级，即使遗留存档中多设施共存，也只供给一份收益和维护。建筑在殖民地作用域求值，必须显式回到承载行星，才能正确读取D20原拥有者记录。

占领、驻防设施停用/拆除、轨道接口拆除或星港失控时，联防收益与其额外维护暂停，登记保留；恢复资格后继续。轰炸本身不暂停已运行的防务。暂时失效不改变D20原有名额与维护的规则。

联防复用D20驻防原拥有者，不新增国家目标。`artifact_garrison_clear`清除原驻防时同时移除`ajd_deployed`，因此既有殖民地转让/无主/毁灭回调直接承接。回调投递前，原拥有者与控制条件先阻止新国家接管收益。没有新月度、银河扫描或军队创建循环。

## 来源与实现

先只读查询七都数据库，再读核心术语、组织和神器圣经。中央庭组织公共守护、跨专业协作与资源统筹的定位约束本方案；联防是Mod星际延展，保留来源`under_review`等状态，不复制指挥使个人强化或量产神器。

原生决议费用、`triggered_planet_modifier`与`triggered_station_modifier`承接玩家行为。防御军伤害/生命、舰船射速/索敌字段已对照本机原生文件及生成文档。一个永久修正`ajd_deployed`仅用于登记和显示；实际收益由设施条件提供。D14没有新增建筑、组件、陆军、事件、on_action或月度任务。
