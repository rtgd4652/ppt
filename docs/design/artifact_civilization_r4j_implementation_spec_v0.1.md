汇编要求活跃最终站由本国拥有并控制、无轰炸，以及本国真实完成的A11模型和至少一种C10样本/材料方法。A11研究本身不是模型，C10研究本身也不是方法。方法此前必须从仍有效的当地成果正常归档。

这一步免费、即时完成，不另建月度项目，不占用或清理现有当地名额，不消费或延长资料。国家永久保存`apt_public_engineering_methods`，重复调用无效；汇编站失效或转让不撤销原国家知识，新拥有者不继承。没有额外全国产出修正。

## 当前实际用途

掌握对应场地研究且国家具备公共工程资格后，活跃“工程物资集成场”或“规则锚定试验场”成为C10复现的替代场地。前者仍需B14，后者仍需E08。普通E05研究园区/尖塔的旧路径不要求A12；新工程路径不强制再建E05园区。

通过当地原公共项目页选择已经归档的样本或材料方法，仍付300能源、150消费品，工作6次有效月度。样本完成为当地物理岗位研究+10%，材料为工程岗位研究+10%，各720日；与其他当地公共方案共用名额。只有材料方法时，不能凭汇编获得样本方法，反之亦然。

现场控制、轰炸、设施或研究失效沿原规则暂停并保存进度，恢复后继续，不再次扣费；转让/毁灭清理未完成过程，原国家档案保留。汇编不消耗库存，正常复现也不消费大型工程备料；备料与实验仍各守自身规则。
