# AWP-03 失落帝国战争事实适配与资格判定方案

## 1. 本轮依据与范围

AWP-02 的 AED-T001～T004 已通过，见 [验收报告](../../reports/aemusa_main_story_awp_02_validation_report.md)。用户于 2026-09-27 选择先推进 AWP-03，并批准保守参战与结果资格；随后明确改为“不需要精确回调，只要确定开战和胜利就可以了”。因此本包的必需事实只来自真实宣战和同一场战争的玩家胜利；未证实的外交要求、动机和损失不得写成游戏事实。

原[第四至第六章制作卡](aemusa_main_story_production_matrix_v1.0.md)要求第四章保存失落帝国的具体外交要求；本次用户指令修订了该入口：第四章只能在合格战争真实开始后处理古老权威与中央庭的政治、公共责任，不虚构战前要求或玩家回应。第五章仍是战争主体阶段，第六章仍须保留战后责任与恢复期。主线不得制造战争或胜利。[专项测试计划](../../reports/aemusa_main_story_adapter_test_plan_v1.0.md)继续逐项验证资格和存读档。

## 2. 已核实的 4.5.1 脚本入口

以下来自本机 Stellaris 4.5.1 原版 `F:/steam/steamapps/common/Stellaris/common/on_actions/00_on_actions.txt`，只是脚本声明的作用域，尚未通过本 Mod 的运行测试：

| 回调 | 原版注释中的作用域 | 本包可记录的事实 |
| --- | --- | --- |
| `on_war_beginning`（2595～2621 行） | 每个参战国家执行；`Root` 为国家，`From` 为战争 | 真实开战；同一战争会对多个国家触发，必须限定玩家与唯一写入 |
| `on_entering_war`（2017～2024 行） | 原版注释给出 `This` 为参战国家、`From` 为敌方战争领袖 | 4.5.1 实测原始开战时也触发；不能用它独立认定晚加入，当前适配器已停用此回调 |
| `on_war_won`（3112～3146 行） | `Root` 为胜方战争领袖，`From` 为败方领袖，`FromFrom` 为战争 | 可候选为“玩家以战争领袖身份获胜” |
| `on_war_lost`（3147～3161 行） | `Root` 为败方战争领袖，`From` 为胜方领袖，`FromFrom` 为战争 | 战败事实；不能写入胜利 |
| `on_status_quo`／`on_status_quo_forced`（3163～3199 行） | 包含主攻、防双方及战争作用域 | 维持现状事实；不等于获胜 |
| `on_war_ended`（2623～2646 行） | `Root` 为败方，`From` 为主要胜方；此回调未声明战争作用域 | 结束可作辅助审计，不作为唯一胜利或战争身份来源 |

原版 `common/scripted_triggers/00_scripted_triggers.txt` 分开识别 `fallen_empire` 与 `awakened_fallen_empire`；不能仅凭泛称“失落帝国”推断两者均满足第五章。原版存在战争对象标记的使用例（`set_war_flag`、`has_war_flag`），但本包还需在目标回调中实测标记能否随存档和结束回调正确匹配。

2026-09-27 的[同类模组战争链对照](../../reports/aemusa_main_story_awp_03_war_chain_comparison_2026-09-27.md)进一步核对了原版 `nomads` 和本机已安装的战争事件链：战争对象打标、结果回调核对同一标记是可用模式。其他模组主动创建或强制结束战争的做法不适合本包；特殊战争漏回调只能记作结果未确认，不能借此推定玩家获胜。对照不构成 AWP-03 的运行通过证据。

以下外交来源研究保留作历史与可选旁证，**不再是第四章或战争资格的门槛**。`events/fallen_empire_tasks_events.txt` 的 `fallen_empires_tasks.3` 只覆盖部分要求，不能推广为所有失落帝国的通用入口。

另一组候选位于原版 `events/fallen_empire_events.txt`：`fallen_empires.3` 会按失落帝国自身条件向玩家派发 `.4`～`.8` 要求事件，事件携带 `from = root.owner`（90～181 行）。`fe_demand_made` 与拒绝要求的意见修正也出现在该流程中。它们提供可调查的具体外交来源，但通用 `on_action` 清单未给出“玩家收到任一此类要求”的直接回调；仅看到旗标或敌意不能保证恢复具体发起者。本包不覆盖原版事件，也不以这组记录启动第四章。

现已核对原版 `.4`～`.8` 的拒绝选项会对发起者写 `opinion_refused_fallen_empire_demand`；部分原版任务请求会对发起者写 `opinion_refused_fallen_empire_request` 或 `opinion_accepted_fallen_empire_request`。本包逐月仅从这些修正反查失落帝国和玩家；候选主体唯一时锁定，多个失落帝国同时留下修正时只记录歧义。同一主体若同时有多种修正，来源枚举记为“混合”，不把其中一种冒充唯一回应。**这些修正由多个原版事件共用，不能从修正本身恢复具体事件 ID 或要求正文**；因此它们只是可选旁证，不应进入第四章剧情或被叙述为具体要求。

另有覆盖缺口：原版 `fallen_empires.4`～`.8` 的接受分支调用 `fallen_empire_humiliate_effect` 并清除通用 `fe_demand_made`，没有写入上述三种关系修正；虽然 `opinion_accepted_fallen_empire_demand` 在原版修正表中定义，本机 4.5.1 脚本未见其被调用。`humiliated` 也会来自战争等其他来源，不能据此反推具体发起者或要求。因此可选外交旁证**不能捕获这组一般要求的接受回应**；不得把“未捕获”写成“玩家拒绝”。

## 3. 修订后的资格口径

| 事实或场景 | 处理 | 边界 |
| --- | --- | --- |
| 第四章入口 | 第三章已结算，且已记录合格真实开战 | 从战争现实展开政治判断；不倒填战前要求、玩家回应或对方动机 |
| 合格开战 | `awakened_fallen_empire` 是原始攻击战争领袖、玩家是原始防守战争领袖，且不是代理战争 | `on_war_beginning` 直接识别攻守双方，不依赖此前的外交锁定或第四章结算；主动进攻、盟友参战、普通战争只记旁证 |
| 战争实例 | 开战时给当前战争对象打标，保存攻击者及玩家开战事实 | 结果只能读取同一战争标记；重复回调和其他战争不能代领结果 |
| 结果事实 | 同一战争分别记录玩家领袖胜利、战败与维持现状 | 只有玩家为胜方战争领袖的 `on_war_won` 可开放第六章；`on_war_ended`、停战或敌国消失都不等于胜利 |
| 第六章结算 | 胜利事实、第五章选择、责任与恢复记录分别核验 | 已发生损失不因胜利清除；缺少可证实数据时不编造伤亡数值 |

本次修订只取消精确外交回调前置，不放宽原始攻守领袖和同一战争获胜的限制。真实开战可以先于玩家打开白夜馆；事实适配与叙事结算必须分开。已观察到的一场战争如果战败或维持现状，保持结果历史与当前资格阻断，不将其他战争的胜利拼接到这场战争。

## 4. 实施与证明

1. `aemusa_ms.600`／`.601` 仍可记录部分原版外交回应，供历史旁证或旧存档审计；它们不再决定战争或章节资格，也不能证明要求正文。
2. `aemusa_ms.610` 在战争开始时识别原始攻守战争领袖，给该战争对象打标，并保存觉醒失落帝国攻击者；`.620`～`.622` 只对带标记的同一战争写入胜利、战败或维持现状。外部适配器不直接结算章节。
3. 第四章 AED-04-00～40 从真实开战进入；第五章 AED-05-00～40 记录战时责任优先级并等待同一场战争由玩家获胜；第六章 AED-06-00～90 只在该胜利后记录问责与恢复优先级。玩家选择与战争事实分开记录，剧情按钮不制造战争或结果。战况、伤亡和撤离数字缺少可靠接口，暂保持待核实。
4. 用隔离测试存档与游戏日志执行 FEA-01～06，并复核战争前／中／后读档、重复回调、并发战争、战败及维持现状。控制台注入可检验接口，不能冒充自然发生证据。2026-09-27 已在受控脚本开战中观察到合格开战回调与第四章正常结算；第五章窗口之后的存档缺少状态，结果回调未测，详见[运行记录](../../reports/aemusa_main_story_awp_03_runtime_2026-09-27.md)。

## 5. 用户决定与叙事边界

2026-09-27，用户先批准严格参战和结果资格，随后明确：“不需要精确回调，只要确定开战和胜利就可以了。”因此第四章不再等待失落帝国具体外交要求，开战者身份直接从战争回调锁定。旧设计中的“战前干预／要求已被捕获”“第四章必须先于开战结算”在本包中停止作为门槛；其余真实战争执行、安托涅瓦承担制度责任、爱缪莎不得提供必胜预言、战后恢复期等内容边界继续有效。

第四章可以讨论古老权威发动真实战争后中央庭的证据、风险与公开责任；不能声称玩家此前接受或拒绝某项具体要求，也不能把对方宣战写成命运安排。没有可靠来源的战争目标、伤亡或外交动机只能标为未知，或留给原版界面展示。
