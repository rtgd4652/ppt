2026-10-31文案同步：A10研究名称改为“边界稳定理论”，其提交所得国家记录仍叫“稳定规则接口”；科技键、流程与数值保持原样。见[文案规范](artifact_technology_writing_guide_v0.1.md)。

2026-10-31，源码基线`272dc13`。按已批准R4路线先实现A08／A10／E08，交付实验到公共用途的一段完整能力链；B14及高阶军备留给下一包。源码、定向检查和游戏运行分别记录。

## 玩家流程

研究A08，把异常样本保管库升级为受控边界实验室。在当地决议“受控边界实验”投入600能源、200消费品、100合金，占用现有公共项目名额。依次完成准备2次、实验3次、恢复1次有效月度，三个阶段单独保存工作量。打开窗口不推进，尚未恢复完毕不能取得成果。

实验结束留下720日的当地记录，本身不提供数值加成。研究A10后，在当地项目页提交记录，获得本国永久“稳定规则接口”资格，同时释放当地公共项目名额。A10仍按批准科技前置研究，不以隐藏旗标阻止抽卡；真实实验记录只约束接口的实际使用。每国同时最多一个边界实验，已提交接口后无需重复实验；其他殖民地的原公共项目不受影响。

研究E08、建造公共规则锚定试验场后，本国可在任意有效试验场付费开启360日的当地防护：500能源、100稀有水晶，原生轨道轰炸伤害−20%。须在未受轰炸且自行控制时部署；启动后受到轰炸仍提供防护。设施停用、损坏或失去控制时暂停收益，期限继续流逝；恢复后在剩余期限内继续。无提前续期、叠加或退款。防护不覆盖其他星球、不免疫轰炸，不自动结算危机。

## 状态接口与兼容

实验复用`arf_r1_active`、付费标记、原拥有者目标、公共项目槽及原月度／转让／毁灭入口。新模式`arf_r1_mode_boundary_experiment`；准备、实验、恢复分别存入`arf_r4_preparation`、`arf_r4_experiment`、`arf_r4_recovery`。停用、拆除、占领、轰炸或A08资格失效时保留已付进度；恢复条件后继续。中止、转让或毁灭不退款，记录已完成阶段后清理当地账本，不能从新国扣旧窗口费用。

当地成果为`artifact_foundation_boundary_result`。A10提交效果必须复核旧窗口拥有者、真实结果、原拥有者和有效实验室，写入`artifact_public_rule_interface_record`；该公共知识保留在原国家，转让设施不赠送知识。

试验场激活使用既有`acs_managed`及`acs_owner@this`，定期标记为`acs_rule_anchor_window`。建筑实时检查有效场地、原拥有者、本国接口记录、E08和控制权，**不把轰炸设为运行失效条件**；转让和毁灭由原物资回调清理。没有新月度扫描、独立资源、重复订阅或全银河循环。

不读写爱缪莎个人科技、合法转变、主线现实基线枢纽、锚点解除和Boss结算。此处是公共殖民地试验场；主线巨构与未来军事D12分别保有独立功能。图标沿用已有资源，批量美术仍暂停。
