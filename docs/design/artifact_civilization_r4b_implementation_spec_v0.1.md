## 玩家流程

研究B14，在有配给仓与联运站的接收端建设工程物资集成场。当地必须实存一份普通预留物资；该物资可以由既有联运送达，也可在当地正常预留。

行星决议“集成大型工程备料”消耗这一份实存物资，再扣1500矿物、900合金、500能源，留下无到期时间的工程备料。含原物资成本，材料账面为2000矿物、1000合金；运输费用不计入材料面额。全国同时只保留一份工程备料，普通库存及联运原有限制不变。

备用物资尚未交付时可通过“撤回大型工程备料”收回1600矿物、800合金，不返还能源和运输费用，也不恢复一份普通库存。拆除或停用集成场、撤销接收端不妨碍撤回，但需要原拥有者恢复控制且没有轰炸。先清除备料再退款，重复调用不得再次结算。

占领、轰炸、设施停用或研究资格失效时，备料保留且占位，禁止新增使用；恢复条件后继续可用。行星转让、失去拥有者或毁灭时沿用原回调清除，不退款、不传给新国。没有新增月度订阅、全银河扫描或独立资源。

## 状态与后续消费接口

- `acs_strategic_supply_reserved`：行星永久无收益修正，记录一份真实已付备料；原拥有者沿用`acs_owner@this`，清理沿用`acs_managed`。
- `artifact_civil_supply_strategic_stock`：行星作用域，只认备料与原拥有者；停用仍占位。
- `artifact_civil_supply_strategic_ready`：行星作用域，还须有有效接收端、集成场及研究；用于正式消费者的准入检查。
- `artifact_civil_supply_strategic_consume`：同一行星作用域，复核ready后仅移除一份备料，无奖励或退款。未来消费者必须在同一守卫块内同时确认目标条件、调用消费并启动实际工程；不得把无返回值的调用当作成功凭证。
- 国家查找库存时使用`any_owned_colony = { carrier = { artifact_civil_supply_strategic_stock = yes } }`，动态原拥有者索引必须回到carrier。

库存占位在正式交付后释放；工程自身的在建数量和持续预算由D13／E09分别管理，不由本包提前规定。不同用途共享同一份库存，不能双重交付。旧C11大型工程加速仍消费原来两份普通库存，与新备料相互独立。
