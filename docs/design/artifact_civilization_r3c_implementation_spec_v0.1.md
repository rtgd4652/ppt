## 状态及作用域

方案用行星载体flag和`artifact_garrison_owner@this`动态国家目标保存。效果与条件维护均读取同一套原拥有者、科技、族类、自有控制、活动设施资格；高低两设施共存时分部优先，只计一次。设施停用／损坏／拆除、失去控制或资格时不增加名额、不扣额外维护；恢复资格后保留已付费方案。转让、失去拥有者或殖民地毁灭清除本包方案和动态目标，不退款；新拥有者须重新付费。主动解除随时可用，不以设施存在作为解除前置。

本机4.5.2原版首都建筑使用`planet_defense_armies_add`，防御军`defensive=yes`不能运输离开星球；因此采用引擎维护名额，不脚本循环create_army、不绑定人口对象、不逐军队扫描或免费补突击军。本轮首都已观察到原生9→10→11逐支刷新；其他来源和战斗场景未扩测，不承诺每个战斗瞬间的部队数量或战中复活。设置入口要求自有控制、无轨道轰炸和活动设施；原生资源系统扣决议费及条件建筑维护，无重复手工扣费。
