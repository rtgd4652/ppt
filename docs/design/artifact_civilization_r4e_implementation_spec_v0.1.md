# R4e 公共战略舰体工程

2026-10-31，源码基线`b8c94ee`。本包落实E10：一个公共舰种、炮击／航母两种中段、完整核心适配和正常船厂入口。没有修改个人旗舰及其复活、发放舰船或增加剧情条件。初始参数按本机4.5.2原版对照，4.5.1兼容和正式游戏运行尚未确认。

## 来源与设计范围

写前只读查询七都数据库中的`TERM-ARTIFACT`、`TERM-ARTIFACT-SCIENCE`、`TERM-CENTRAL-COURT`，阅读[核心术语源](../../tools/knowledge/data/core_terms_v0.1.json)、[神器体系](../../knowledge/artifacts/artifact_bible_v0.1.md)第1～2节和[组织体系](../../knowledge/organizations/organization_bible_v0.1.md)的中央庭与科研职责。公共军工是Mod星际延展；可复用的是仪器、工艺与安全工程，不批量制造与特定人共鸣的神器。来源审核状态不变。

沿用[大型物种包参考](artifact_species_pack_mod_reference_2026-10-31.md)，本次又读取舰R的`dreadnought_carrier`和本机原版舰体、区段、核心部件及船厂判断。只借鉴原生设计—建造和资格分层，不复制第三方资产或高数值。在线船舶模组页面读取返回401；具体实现以本机原版4.5.2源码为依据。

## 玩家获得的能力

研究“公共战略舰体工程”（工程T5／28000／权重50，保留E09＋D13前置）后，设计器出现“中庭级战略舰”。本国须已经完成D13承载定型，才能使用配套核心；下单建造还要求一个属于原拥有者、正常运营的E09大型工程营建场，以及擎天堡船厂或完工／修复的巨型船坞。

已有E09和D13的实付成果直接作为资格，不增加新决议、第二轮定型或重复扣备料。每艘仍走正常船厂，以合金和建造时间支付。新舰没有唯一性和免费恢复；受正常海军容量、指挥容量、资源和维护约束。

## 状态、兼容与资产

国家承载定型是持久知识，运营营建场是当前工业条件。后者失控、停用、轰炸或转让时，阻止新建下单；不删除已有舰船、设计或核心资格。恢复运营后重新满足下单条件。原生在建队列、改装在此期间是否继续，待阶段试玩观察，不承诺自动停工。

复用既有E09原拥有者保护和月度清理，无新回调、扫描、状态或数据库变更。不改原版舰型白名单；仅给新舰提供核心，并在本Mod四个既有组件的限制中显式加入新舰。个人唯一舰、旧组件键、已有研究前置保持。

外观使用原版战列舰实体和已存在的炮位定位器，仅作为玩法占位；新舰是独立公共舰种，不能将旧旗舰外观或这份占位当作1.0正式资产。正式造型需按中央庭视觉语言另行定稿。
