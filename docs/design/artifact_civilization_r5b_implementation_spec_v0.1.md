## 失效与归属

中心、控制、联防、研究或本国档案失效时，已备料保留但不能部署，恢复后继续。轰炸期间不能准备新物资；本国仍控制且联防有效时，可以发动已准备反制。原拥有者可在停用/拆除/占领等情况下放弃库存，释放名额但不退款，不清其他库存。

转让、失去拥有者或毁灭由原ACS清理移除尚未部署的地方库存。已发动的舰船干扰、原国家冷却和公共知识各自保留，不转给新拥有者。没有新事件、on_action、变量、全局目标或月度订阅；只有玩家操作时检查本国殖民地/舰队及选定现场。
