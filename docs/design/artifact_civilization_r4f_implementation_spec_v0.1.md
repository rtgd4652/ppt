# R4f 有限场域压制实施规格 v0.1

2026-10-31。基线`f9975d5`，D12源码和必要检查完成；尚未运行。完整参数见[结构化规格](artifact_civilization_r4f_implementation_spec_v0.1.json)。

## 玩家入口与取舍

“有限场域压制”为物理T5研究，保留D03＋A10前置，首版科研费24000、权重50。中庭级另需E10与本国承载定型，安装“边界扰动压制器”A槽后，在普通舰队命令栏手动启动；研究本身不发船。

| 项目 | 首版实现 |
| --- | --- |
| 模块投入 | 250合金、20稀有水晶；功耗150，维护2能源、0.25合金 |
| 每次行动 | 原生一次支付1500能源、25稀有水晶；即时执行 |
| 命中范围 | 发射当时所在的整个星系，敌方控制者的作战舰；不声称有舰旁距离半径 |
| 压制 | 命中舰船射速−15%、亚光速速度−20%，60日 |
| 冷却 | 国家记录180日；舰队原生按钮同为180日，分合舰队和其他中庭级仍受国家记录限制 |
| 排除 | 友方/中立、异星系、隐形、失能、民用/运输、星港与防御平台；已受同类效果者不叠加、不续期 |
| 后续移动 | 已命中舰船离开星系仍保留剩余计时；后来进入的舰船不补算 |

舰队必须由同一个国家拥有和控制。发射舰毁灭、拆分或转编不清除已命中舰船的60日计时；共享冷却仍留在支付国。重复安装只占用额外槽位，不增加次数。首版不自动给AI设计装入模块，也不设置AI自动发动。

## 来源与工程边界

已先查询七都数据库中的神器科学、黑门研究体系、黑门和中央庭，再核对术语JSON及神器/组织圣经。压制脉冲是对风险观测与安全应用的Mod工程转译，不声称原作已有舰载压制、已揭示黑门本质或可量产个人神器。来源审核状态不变，研究不读取爱缪莎个人转变。

本机原生`scripted_actions`说明、圣骑士行动、组件回调和`ambition.250`提供即时舰队行动、成本及按当前星系敌意筛选的参考。原生敌对光环始终覆盖星系，动态添加船用组件缺少可靠接口，因此选用一次本星系脉冲，不实现持续场边界。宿主仍为普通中庭级，使用`slot=0`，不转换成英雄舰。图标沿用现有/原生占位，正式美术后补。

## 状态与代码约定

- `artifact_field_suppression_platform_ready`核对现役宿主、同国拥有/控制、D12及E10定型资格、冷却。当前营建场仅影响E10新建订单，不停用已造舰。
- `artifact_field_suppression_ready`在本星系查找有效敌舰。按钮用显式PREV链找发射舰；完成事件中ROOT为发射舰，敌意使用`is_hostile`，不用外交态度`is_hostile_to`。
- 原生`cost`只扣一次，完成回调不再扣资源，也不把扣费后余额当成前置。通过`on_artifact_field_suppression`调用隐藏舰队事件；回调复核有效资格后登记国家与舰船计时。
- 只有两个新限时修正：国家`afs_recharging`与舰船`afs_suppressed`。无新月度、银河扫描、战斗命中追踪、事件目标或定时重建；旧四光环及个人舰不改。

## 必要检查与下一次试玩

5项新增源码条件/回调检查与5项E10宿主检查通过，静态0错误/0警告。新检查覆盖精确余额、无敌人/无资金不执行、敌我与星系边界、PREV链、共享冷却、旧命中不续期及后来舰船不补算。原生扣费、按钮与日期使用外部夹具，不冒称已在游戏完成。
