## 玩家如何发展

研究塔罗演算后，可以选择发展基准观测、标准件或公共服务。观测路线进一步开放样本分析，制造路线开放材料试制和模块化营建；记忆档案支撑公共记录。科研殖民地可侧重观测与样本，制造殖民地可侧重工坊与民生生产，治理殖民地可选择社区服务与档案。各类不是每颗行星的必建清单。

当地工坊可为这颗殖民地组织施工或材料研究；已经拥有原神器工坊的旧存档也可直接参加，不必重建低级工坊。新内容不要求角色在场、角色等级、人物组合、个人飞升或正式转变。

## 开始暂停与结算

- 项目槽：每颗殖民地一个R1公共项目槽，进行态及收益期内均不能开启另一模式；不占用C2或既有角色工坊槽。
- 开始条件：玩家文明、拥有并实际控制的殖民地、无轰炸、相应科技与至少一座列明现场设施。
- 投入：开始时一次扣费，无逐月追加收费；完成或中止不返还，不发放免费建筑、科技或角色经验。
- 工作推进：每次有效原生月度脉冲推进1步；通常约3或4个月，不宣称固定90或120日。仅处理进行态地点。
- 暂停：同一所有者的现场遭占领、轰炸或失去本模式的全部合格设施时暂停，已付费及工作量保留；同类低级楼升级成合格高级楼不暂停。
- 中止：所有权变化、殖民地消失、文明身份不再符合或玩家主动中止时失败归档，已付费不返还；不得转移给新所有者或首都。
- 完成：最后一步同时复核所有者、控制权、轰炸与设施；先清进行态再添加一项收益，重复进入界面不推进或再结算。
- 收益归属：收益绑定启动时原殖民地；占领不刷新收益期限，失去所有权时移除本包收益；完工后拆楼不重新结算或退款。
- 保存与读档：现场、启动所有者、模式、已付费事实、有效工作步及结算状态随档；载档后等待下一次自然月度脉冲，不补跑历史月份。
- 边界：不增加角色等级、人物组合、个人授权或全局样本资源；不改变C2、旧首都工坊和主线回调。

收益修正自然到期后释放该项目槽。重复打开、关闭入口或保存读档不推进工作，不刷新收益期限。暂停不会退费；失去设施可恢复继续，所有权改变则中止。进度在建造升级期间是否仍有现场，由实际完成的合格建筑判断，不能只看在建队列就算完工。

完成结算仍由启动所有者承担；旧所有者的项目不得在过户后替新国家完成。新所有者可以在自身满足全部研究与现场条件后另付费启动新项目。
