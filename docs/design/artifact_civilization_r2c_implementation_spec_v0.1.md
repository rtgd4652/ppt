地表阵列每阶段使用原生帝国上限1，低级新建另排除本国任何殖民地的已建／在建高级阵列；高级只允许升级，不能另行直建。首版组织一处公共基准站，A09跨殖民地联校实施时再明确网络与限额。它们不增加岗位、科研产出、仓储或第二个项目槽，也不调整其他旧建筑容量。

低级新建排他只放allow，potential仅保留文明资格；升级排队不会撤销正在工作的低级设施存在资格。低级效果持续至原生替换，高级保留1点传感而非再叠一份低级效果。

本国国家修正只来自由本国控制的有效阵列。星港接口可以先建，没有来源时待机并继续付维护。它只取同星系、同一拥有国、未被占领且未停用／损坏的地表阵列；来源恢复时由原生条件重新判断。两个殖民地或两座阵列不会使同一接口重复加成。接口每星港原生限1，仅正常恒星基地，不接轨道环、驿站或舰船殖民地；星港被敌国控制时支援停止。

## 风险与预警的确切含义

本包只以原生传感器可见目标、航道信息与隐形目标作为观测来源。航道探知只扩大航道信息，不等于看见该航道内全部舰队；隐形发现仍受原生探测与目标隐形强度、相关内容是否启用等规则限制。没有创造倒计时、未来舰队或必然战果，也不承诺固定提前几天。

原草案中“提前显示已定义异常风险与准备窗口”的危机脚本部分继续留在F02／F03等对应包，尚未实现；本包交付的是原生感知与判读基础，不能把它登记为完整危机预报。既有主线90天预警、个人事实、C2保护／冷却和R1账本均不读写。
