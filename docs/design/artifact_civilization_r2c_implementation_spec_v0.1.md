## 风险与预警的确切含义

本包只以原生传感器可见目标、航道信息与隐形目标作为观测来源。航道探知只扩大航道信息，不等于看见该航道内全部舰队；隐形发现仍受原生探测与目标隐形强度、相关内容是否启用等规则限制。没有创造倒计时、未来舰队或必然战果，也不承诺固定提前几天。

原草案中“提前显示已定义异常风险与准备窗口”的危机脚本部分继续留在F02／F03等对应包，尚未实现；本包交付的是原生感知与判读基础，不能把它登记为完整危机预报。既有主线90天预警、个人事实、C2保护／冷却和R1账本均不读写。
