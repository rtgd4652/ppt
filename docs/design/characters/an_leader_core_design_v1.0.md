# 安 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定安在 1.0 中的身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。方案经人工批准前，不进入代码实现。

## 2. 证据与约束基线

- 安是拥有复杂自我意识的机械人偶，也是能够实际作战的神器使。
- 她曾受希罗控制，但控制权不等于创造权、改造权或对其人格的所有权。
- 她从模仿人类生活、记录个人经历和理解情感开始，逐渐形成能够反抗命令并承担选择后果的自主意志。
- 神器“双剑・时光之刃”能够造成局部、短时、有限的时间变化，包括加速、减速和短暂回溯。
- 时光之刃只能握住很小一束时间，不能自由重构世界、改写完整历史或控制七日轮回。
- 《无垢的人偶》中的人格连续性、控制风险和“是否仍是同一个安”属于需要被理解和验证的问题，不能简单以机械身体否定其人格。
- 在本 Mod 的连续历史中，安的经历不再随七日重构被完全抹除；她能够真正积累经验并继续成长。

## 3. 固定身份

### 3.1 世界观身份

固定为：**中央庭所属神器使／获得完整人格承认的人工生命个体**。

安既不是供研究和拆解的实验对象，也不是只执行命令的自动兵器。她作为拥有个人经历、社会关系、自主选择和责任能力的个体参与灾后重建与星际探索。

### 3.2 与中央庭及玩家的关系

- 中央庭应以制度确认安的主体身份，同时保留对外部控制、复制和人格连续性风险的技术审计。
- 风险审计针对控制链和系统安全，不等于对安进行永久监禁或否认其人格。
- 玩家作为指挥使见证并支持她的自主成长，但不能替她作出全部选择，也不能成为新的所有者。
- 安能够接受任务、参与治理与作战，也保留拒绝非法控制和伤害他人的权利。

## 4. 领袖职业建议

### 4.1 正式建议

- 对外显示身份：**中央庭时序行动专员**。
- Stellaris 职业：**行政官（Official）／指挥官（Commander）双职业**。
- 行政官状态：参与设施维护、灾害响应、社会服务和人工生命制度实践，把不断积累的生活经验转化为稳定可靠的公共行动。
- 指挥官状态：使用时光之刃进行局部时序干涉，并通过反复观测短时间片修正战术行动。

### 4.2 采用双职业的理由

1. 安在原作中拥有明确的近战、加速、减速和短时回溯能力，指挥官能够承载其实际战斗身份。
2. 她的日常能力、维护习惯、对普通生活的学习和对社会身份的追求同样重要，不能把她压缩成纯战斗单位。
3. 行政官用于表现她作为社会成员参与重建、服务和制度生活，而不是把她安排为实验室中的研究对象。
4. 两个职业共享同一条“记录—学习—修正—成长”链条，不形成两套互不相关的人格。

### 4.3 边界

- 不开放科学家职业；神器研究可以研究她遭遇的现象，但安本人不是可供国家占有的研究样本。
- 不把行政官状态写成普通清洁机器人、廉价劳动力或无限维护设备。
- 不把指挥官状态写成能够反复复活舰队、撤销战争结果或无限回滚存档。
- 职业切换不能清空她的时序记录、成长状态、唯一身份或人物关系。
- 若重建领袖实体会破坏身份连续性，应使用同一实体配合国家层／事件层职业模式。

## 5. 唯一核心机制：时序学习

### 5.1 核心定义

**时序学习**：安以时光之刃记录一个局部事件的短时间片，在遭遇错误、事故或强敌后分析其中的行动差异，并把有限回溯带来的“第二次观察”转化为可持续保留的经验。

机制重点不是把失败从历史中删除，而是让一次有限的重新观察成为真正的成长。已经发生的文明级损失不会被整段撤销，但安可以在明确边界内修正下一次行动，或在致命瞬间争取一次有限的脱离机会。

### 5.2 第一版玩法结构

1. 同一时间只维持一个“时序记录对象”，避免对整个国家或银河建立无限快照。
2. 行政官状态可记录一项正在处理的局部事故、建设难题或公共响应任务；事件发生后形成经验，用于改善同类问题的下一次处理。
3. 指挥官状态可记录一个正在交战的敌方目标或当前战斗阶段；完成观测后形成针对该目标的短期战术适应。
4. 当安本人或其直接负责对象遭遇一次满足条件的严重失败时，可触发有限的紧急回溯表现：避免一次致命结果、强制脱离或保留部分行动成果。具体效果需在机制阶段验证。
5. 紧急回溯会消耗当前时序记录并进入较长恢复期，不能连续触发。
6. 职业切换保留同一份记录与已形成的经验；行政经验和战术经验属于同一个安的连续成长。
7. 对象改变、信息过期或环境发生根本变化后，旧经验只能作为参考，不能永久克制所有同类目标。

### 5.3 叙事意义

- 时间能力提供“重新看一次”的机会，安的人格与学习能力负责理解差异并改变下一次选择。
- 她的成长来自真实经历，而不是预装完成的完美人格。
- 连续历史使这些经验能够长期保留，这正是轮回结束后安在新世界中的重要意义。
- 玩家可以提供机会和信任，但成长的主体始终是安本人。

### 5.4 能力边界

时序学习不能：

- 重启七日轮回、重构世界或读取其他世界线。
- 撤销已经结束的战争、外交决议、人口死亡或星球毁灭。
- 无限复活安、整支舰队或其他领袖。
- 在没有接触和记录的情况下预知敌人全部行动。
- 永久复制任何目标的能力，或对所有同类敌人保持全局克制。
- 取代爱缪莎对未来可能性的观测和命运主线。
- 取代安托涅瓦的跨时间空间方舟、战略传送和大范围庇护。
- 以“安全”为由恢复希罗对安的所有权或强制控制。

## 6. 1.0 实装边界

### 进入 1.0

- 人工生命个体与中央庭神器使身份。
- 行政官／指挥官双职业，并验证切换时唯一身份与时序记录能够稳定保留。
- 一个“选择局部对象—积累记录—形成经验—修正下一次行动”的核心闭环。
- 一次有严格冷却和对象限制的紧急回溯表现；若无法稳定实现，则降级为紧急脱离与经验保留，而不是回滚游戏状态。
- 白夜馆招募、档案与联络。
- 唯一身份、持久化引用、读档、死亡和外部控制边界处理。

### 暂不进入 1.0

- 世界线、存档或整场战争回滚。
- 人工生命公民权的大型国家剧情链。
- 希罗控制系统与安的制造来源最终答案。
- 多目标并行时序记录。
- 大规模复活或无损舰队恢复。
- 独立大型个人主线。

## 7. 与其他核心角色的区分

| 角色 | 主要问题 | 能力方向 | 不能替代的部分 |
| --- | --- | --- | --- |
| 安托涅瓦 | 如何带领并保护文明继续前进 | 方舟时空支配、战略传送、庇护与领导 | 安不能承担国家元首或大范围方舟权能 |
| 晏华 | 如何从现实证据中识别关键矛盾 | 情报验证、态势研判与战略执行 | 安的学习不是国家级情报分析 |
| 爱缪莎 | 未来可能如何展开 | 可能性与命运观测 | 安不能观察完整未来或支配命运 |
| 安 | 个体如何从经历中形成自我并修正行动 | 局部短时记录、有限回溯与持续成长 | 重点是亲历、学习和自主选择 |
