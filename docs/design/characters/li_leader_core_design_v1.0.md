# 丽 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定丽在 1.0 中的固定身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。方案经人工批准前，不修改游戏代码。

## 2. 证据与约束基线

- 丽从贫困经历中建立事业，具备商业经营、鉴赏、投资、风险判断和严格财务记录能力。
- 她长期参与慈善、教育、就业安置和灾后重建，但习惯用借贷、成本和投资回报语言掩饰关心。
- 她重视契约和审阅，能够接受合作者对不合理条款提出修改；与指挥使的宽泛合同主要体现毒舌、嘴硬、傲娇和保持优势地位，不能升格为中央庭标准制度。
- 宝伞・毗沙门天慧伞同时具有守护、财富、武力与智慧的文化象征，已知表现包括格挡、防护、吸收、反击和恢复。
- 丽具备商业调查、信息保护、通信封锁、战术准备和直接战斗能力，并投资战斗／民用机甲研究。
- 私人财富和企业能力不能替代中央庭的公共治理、社会保障和军事制度。
- 财富象征不等于无限创造资源；宝伞也不是绝对防御、贡品换取奇迹或购买命运结果的工具。
- 已删除并禁止“皇室血统”扩写；“黄金姬”是称号，不是神格或政治身份。

## 3. 固定身份

### 3.1 世界观身份

固定为：**中央庭产业与工程研究协作者／黄金伞防护型神器使**。

丽参与灾后产业恢复、社会安置、公共项目投资、机甲研发与星际工程资源组织，也能凭借宝伞和个人装备参与保护性战斗。她既有科研和工程能力，也有组织研究资源并推动成果落地的能力；她不是企业国家统治者、财神化身或以私人资本取代中央庭的权力中心。

### 3.2 与中央庭及玩家的关系

- 中央庭确定公共目标、法律边界和基本保障，丽负责提出可执行的投入、审查和风险控制方案。
- 科研机构负责共同验证理论、实验安全和成果归属；丽可以主持或参与工程研究，但不能用投资关系占有公共知识或跳过共同验证。
- 玩家作为指挥使可以选择优先项目和行动方向，但必须确认成本、受益对象、失败条件和退出方式。
- 丽可以要求账目、合同与责任清晰，也必须接受公共审计、合作者协商和不合理条款修订。
- 私人慈善可以补充紧急援助，不能成为取消公共教育、就业、医疗和社会保障的理由。
- 丽与指挥使之间的毒舌合同保留为人物互动，不转化为中央庭允许无限征用指挥使的正式制度。

## 4. 领袖职业建议

### 4.1 正式建议

- 默认职业：**行政官（Official）**。
- 可切换职业：**科学家（Scientist）**与**指挥官（Commander）**。
- 行政官方向：产业投资、就业安置、公共项目审计、供应链与长期建设。
- 科学家方向：机甲工程、工业技术、原型验证、材料与黑核相关实验的有限研究。
- 指挥官方向：防护编组、战场补给、通信保障、机甲与宝伞保护性作战。
- 三种职业共享同一角色、同一宝伞与同一责任账本，不复制多个丽。

### 4.2 采用行政官／科学家／指挥官三职业的理由

1. 商业组织、公共援助、就业与产业投资构成其最稳定的文明职责，因此行政官适合作为默认职业。
2. 原作资料不仅支持科研投资，也支持黑核实验室、高科技机甲企业、战斗／民用机甲研究和个人工程装备，因此科学家职业具有直接证据基础。
3. 丽的科学家方向偏重机甲、工业与工程应用，不应泛化为所有学科的万能研究者，也不能把团队成果全部归于她个人。
4. 宝伞防护、直接战斗、通信封锁和机甲装备足以支持指挥官职业；所有神器使也必须具有指挥官可用性。
5. 三种职业都围绕“先判断价值并承担成本，再把研究或投入兑现为长期能力”展开，不能拆成行政产钱、科学加科研、军事加伤害的三个模板。

### 4.3 边界

- 不让企业、黄金伞或丽本人接管中央庭、殖民地政府和公共福利制度。
- 不把财富、贸易或资源产出作为无条件常驻增益。
- 不把“偏爱机甲”写成只会投资、不具备科研能力，也不把机甲专长扩张为全学科精通。
- 不把贫困者、失业者和受助者写成可以低价占有的劳动力资源。
- 不把宝伞、机甲与财富符号扩张成整个中央庭文明的公共视觉和技术来源。

## 5. 唯一核心机制：责任投资

### 5.1 核心定义

**责任投资**：玩家与丽选择一个具有明确公共或防卫目标的项目，在行动前登记成本、受益对象、风险和退出条件；丽先投入有限资源并建立审计阶段，随后通过履约进度把一次投入转化为可持续能力。项目失败时必须结算损失、保护受益对象并保留可复核账目，不能无代价重置。

该机制表现丽相信自身判断、重视契约并愿意承担成本的行动方式。财富只是组织资源的手段，核心是“投入是否兑现为真实能力，以及由谁承担失败后果”。

### 5.2 第一版玩法结构

1. 同一时间只维持一项主要责任投资，候选对象可为殖民地重建、就业与公共设施、产业项目，或丽所在舰队的防护与补给任务。
2. 项目启动前登记目标、前期成本、受益对象和一项明确风险；不能只支付资源立即领取永久奖励。
3. 第一阶段为审查与准备：收集账目、供应、需求或敌情信息。玩家可以缩小项目、协商条件，或承担更高风险继续推进。
4. 第二阶段为履约：行政官通过建设、安置和供应链推进；科学家通过可行性验证、原型试验和工程改进推进；指挥官通过补给、防护、通信保障和护送推进。
5. 履约完成后，项目才转化为有限的长期能力或阶段成果；收益必须与最初公共／防卫目标对应。
6. 若风险发生，玩家可选择追加承担、调整目标或止损退出。止损会保留部分资料、设施或人员保护，但不能返还全部成本。
7. 行政官、科学家与指挥官共享同一责任账本；职业切换可以改变履约手段，不能复制投资、清除风险或重复结算。

### 5.3 叙事意义

- 丽的财富不来自神赐或资源复制，而来自判断、组织、工作、风险和长期投入。
- 契约不是压迫他人的万能许可，而是让成本、责任、协商和退出条件可见。
- 慈善、就业和产业建设都要保护受益者人格，不能因为提供援助就获得对其人生的占有权。
- 宝伞的“护持”转化为先承担风险、保护资产与人员，再争取长期能力，而不是绝对防御。

### 5.4 能力边界

责任投资不能：

- 凭空创造能量币、合金、稀有资源、人口、舰船或建筑。
- 用一次付款直接购买科技、胜利、忠诚、领袖或命运结果。
- 保证所有投资成功、消除市场与建设风险或自动得出最优项目。
- 将私人合同置于中央庭法律、公共审计和基本权利之上。
- 强迫受助者成为债务劳工，或以援助为由取消其拒绝和离开权。
- 让宝伞永久无敌、无限吸收伤害、无成本反击或复活损失单位。
- 让丽垄断全部机甲、工业、金融、贸易和社会保障体系。
- 把机甲工程能力扩张成物理、社会、生物等全部学科的万能研究能力。
- 将“黄金姬”解释为神格、皇室血统或银河政治合法性。

## 6. 1.0 实装边界

### 进入 1.0

- 行政官默认职业，科学家与指挥官可切换。
- 一个“选择项目—登记成本与风险—审查准备—履约—兑现或止损”的核心闭环。
- 同时只维持一项主要责任投资。
- 行政、科研与军事履约共享责任账本，职业切换不复制收益。
- 白夜馆招募、通讯、档案、唯一身份和内部 ID `li`。
- 正式数值、项目清单、风险概率和切换成本另行审核。

### 暂不进入 1.0

- 复杂银河市场或企业国家系统。
- 无限财富与资源复制。
- 全产业垄断和大型机甲科技树。
- 黄金伞完整组织制度模拟。
- 大型慈善、家庭或商业剧情线。
- 独立大型个人主线。
