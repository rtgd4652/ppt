# 晏华 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定晏华在 1.0 中的固定身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。方案经人工整体批准前，不进入代码实现。

## 2. 证据与约束基线

- 晏华是安托涅瓦的重要辅助者，负责现实分析、战略判断、秩序与规划。
- 他参与并推动中央庭的发展，但不是中央庭领袖、统治者或独立权力中心。
- 神器“眼睛・荷鲁斯之眼”的原作能力是看穿弱点。
- 荷鲁斯之眼能够帮助他发现隐藏信息与关键矛盾，但不是全知、预言或自动给出正确答案。
- 晏华会根据新证据修正原有判断；他的价值是建立可验证的推理链并承担判断后果。
- 他的技术能力、行政处理能力、情报能力、推理能力和战术规划能力互相配合，不能只缩减为武器命中加成。
- 他仍是能够参与实际冲突的神器使，不能被写成只坐在终端后的抽象顾问。

## 3. 固定身份

### 3.1 世界观身份

固定为：**中央庭战略与情报辅助者／神器使**。

他负责处理中央庭的重要行政事务，把行政记录、外交情报、侦察资料、矛盾证据、敌方行为与公共风险整理成可以讨论和执行的方案，并辅助安托涅瓦与中央庭作出决策。

“首席战略辅助者”是本 Mod 的职能概括，不自动授予他不受监督的情报权、司法权或国家最终决定权。

### 3.2 与安托涅瓦及玩家的关系

- 安托涅瓦负责领导中央庭、确定公共方向并承担国家元首责任。
- 晏华提供现实分析、风险判断、方案比较与行动规划。
- 玩家作为指挥使决定实际行动路线并承担结果。
- 晏华可以指出某个选择的代价与薄弱点，但不能替安托涅瓦或玩家自动作出所有决定。

## 4. 领袖职业建议

### 4.1 正式建议

- 对外显示身份：**中央庭战略与情报顾问**。
- Stellaris 职业：**行政官（Official）／指挥官（Commander）双职业**。
- 行政官状态：通过专属议会／顾问位置表达行政协调、情报汇总和战略分析。
- 指挥官状态：亲自参与舰队行动，把已经验证的态势结论转化为战场反制与精准打击。

### 4.2 采用双职业的理由

1. 晏华长期承担中央庭行政处理、职责协调、信息筛分、风险判断与战略规划工作，行政和情报是其主要职能。
2. 个人支线直接表现了他高效处理大量事务、辨识伪造信息、核对职责边界、组织调查并通过信息系统执行方案的能力。
3. 行政官能够承载议会、治理、外交与情报相关的文明层作用域，表现他持续参与中央庭运作的身份。
4. 原作同时确认他具备射手、物理攻击、看穿弱点与实际战斗能力；指挥官状态用于表现他把研判结果转化为实际战术的能力。
5. 两个职业对应同一条“收集证据—形成判断—执行方案”链条，不是两套互相割裂的人物设定。

### 4.3 边界

- 不开放科学家职业；晏华只在行政官与指挥官之间切换。
- 不把他写成只提供资源、稳定度或行政容量的普通治理领袖。
- 不忽略其神器使战斗能力，也不把战斗表现缩减为固定命中或穿透加成。
- 不因其战略能力而授予全银河情报、永久侦察或绝对系统控制。
- 职业切换不能清空态势研判进度、目标、已验证结论、唯一身份或人物关系状态。
- 如果反复重建领袖实体无法稳定保存状态，应改用同一领袖实体加国家层／事件层职业模式，不能为实现切换牺牲唯一性和存读档稳定。

## 5. 唯一核心机制：态势研判

### 5.1 核心定义

**态势研判**：晏华把中央庭的行政记录、外交情报、侦察资料、异常观测和实际接触整理成证据链，在有限时间内确认一个问题或目标的关键矛盾，并把结论转化为中央庭与指挥使能够执行的应对方案。

机制重点不是直接增加大量资源或伤害，而是“从混乱信息到可判断”：证据不足时只能提出假设；证据充分后才能形成有效的治理、情报或军事对策。

### 5.2 第一版玩法结构

1. 玩家选择一个符合条件的“研判对象”；第一版优先考虑接触中的外部帝国、正在发展的重大危机或明确的文明级风险，不覆盖所有日常事务。
2. 行政记录、外交情报、侦察、异常研究或实际交战为研判提供证据，不同来源可以相互验证或暴露矛盾。
3. 证据达到要求后，晏华形成一项经过验证的“态势结论”。
4. 玩家依据结论选择一种应对方向：改善内部准备、加强情报工作、调整外交方案或针对已确认的军事弱点制定反制。正式选项必须与 Stellaris 可用机制对应。
5. 同一时间只维持一个主要研判对象和一项主要结论，避免变成全银河永久情报与减益网络。
6. 对象发生重大变化、情报遭到欺骗或证据过期后，需要重新验证，体现判断可以被现实修正。
7. 行政官状态更适合积累、核验和整理证据；指挥官状态更适合执行已经形成的军事结论。两种状态共享同一研判记录。

### 5.3 叙事意义

- 荷鲁斯之眼负责帮助晏华发现异常和关键点，但行政资料、情报来源与现实证据共同构成完整结论。
- 晏华负责组织推理和方案，中央庭负责协调资源，玩家负责选择并执行行动。
- 机制允许他犯错、修正和承认未知，不把“看见弱点”写成永远正确。
- 他仍能亲自战斗，但战斗是整个研判闭环的一个执行场景；其强大来自识别关键矛盾并让集体行动准确落点，而不是单纯拥有最高面板输出。

### 5.4 能力边界

态势研判不能：

- 自动揭示全银河、所有隐形单位或全部敌方设计。
- 在没有观测、情报或接触的情况下直接给出正确答案。
- 永久降低所有敌人的全部属性。
- 预测尚未发生的未来，或取代爱缪莎的可能性观测。
- 让晏华获得中央庭最终决策权或不受监督的系统权限。
- 把一次推理成功写成荷鲁斯之眼直接提供完整答案。
- 把敌人简化成永远存在同一个静态弱点的靶子。
- 把中央庭行政和情报体系写成只依赖晏华一人的个人网络。

## 6. 1.0 实装边界

### 进入 1.0

- 中央庭战略顾问与独特神器使身份。
- 行政官／指挥官双职业，并验证切换时唯一身份、国家元数据、领袖引用和研判记录能够稳定保留。
- 一个“选择对象—汇总资料—验证矛盾—形成结论—执行对策”的核心闭环。
- 白夜馆招募、档案与联络。
- 唯一身份、持久化引用、读档和死亡边界处理。

### 暂不进入 1.0

- 全银河情报网络。
- 自动替玩家设计舰队或接管战争。
- 多目标并行解析。
- 独立大型个人主线。
- 荷鲁斯之眼来源与真知本质的最终答案。
- 将一次个人支线中的网络权限制度化为永久国家监控系统。

## 7. 与安托涅瓦和爱缪莎的区分

| 角色 | 主要问题 | 能力方向 | 决策位置 |
| --- | --- | --- | --- |
| 安托涅瓦 | 如何带领并保护文明继续前进 | 方舟时空支配、庇护与领导 | 国家元首与中央庭核心领袖 |
| 晏华 | 在复杂行政与情报中如何识别关键矛盾 | 现实分析、情报验证、治理准备与战略反制 | 战略与情报辅助者，不拥有最终决定权 |
| 爱缪莎 | 未来可能如何展开 | 概率、可能性与命运观测 | 未来辅助者，终局前不能替文明决定未来 |

晏华分析“现在可验证的现实”，爱缪莎观察“未来可能性的变化”；两者共同辅助安托涅瓦，但不能互相替代。
