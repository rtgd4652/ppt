# 格蕾莎 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定格蕾莎在 1.0 中的固定身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。方案经人工批准前，不修改游戏代码。

## 2. 证据与约束基线

- 格蕾莎保留二十五岁军医的经历与成年记忆，当前身体外观约十二岁；不能把她简单写成普通儿童或外表不变的成年人。
- 她拥有正式医疗专业能力，也具备军用观察、枪械射击、擒拿和战场判断能力。
- 她能够诊疗、识别异常病例、研发药剂、解毒和调节生命力，但初次观察并不总能掌握完整病因。
- 神符・安卡象征生命、死亡与延续，能够促进恢复，但不能复活死者、取消死亡或提供永生。
- 格蕾莎曾因战争伤亡产生持续警戒、负罪感和痛苦记忆；她最终选择背负过去继续救人，而不是遗忘或改写死亡。
- 她曾在未取得知情同意的情况下让指挥使试用毒素与解药。这是必须保留并受约束的伦理问题，不能因实验成功而合理化。
- 她珍惜生命但并不厌弃战斗能力；武器对她而言是战场工具，不是个人崇拜主题。

## 3. 固定身份

### 3.1 世界观身份

固定为：**中央庭异常医学专家／灾难医疗与战地生命支持神器使**。

格蕾莎在星际时代负责异常病例、外星环境医学、灾难救治与战地生命支持。她既是医生和研究者，也是能够进入危险区域执行医疗行动的军医；她不是无限复活装置、生物改造工厂或只提供恢复数值的辅助单位。

### 3.2 与中央庭及玩家的关系

- 中央庭为格蕾莎提供临床资料、实验设施、伦理审查和战地医疗资源。
- 玩家作为指挥使可以决定文明行动的优先救治方向，但不能强迫患者或研究对象接受未经同意的试验。
- 格蕾莎拥有诊断和专业建议权；国家政策、战争目标和大规模实验授权仍由制度承担。
- 她可以质疑形式主义和拖延救治的程序，但紧急状态不能成为永久取消知情同意、患者权利和研究记录的借口。
- 她本人特殊的身体状态同样受人格和医疗隐私保护，不能被中央庭占有为实验材料。

## 4. 领袖职业建议

### 4.1 正式建议

- 默认职业：**科学家（Scientist）**。
- 可切换职业：**指挥官（Commander）**。
- 科学家方向：异常医学、病理调查、生命支持与治疗方案研究。
- 指挥官方向：战地医疗、伤员撤离、污染控制和保护性火力支援。
- 两种职业共享同一角色、同一安卡状态与同一病例档案，不复制两个格蕾莎。

### 4.2 采用科学家／指挥官双职业的理由

1. 医生、异常病例研究和药剂研发构成其最稳定的文明职责，因此科学家适合作为默认职业。
2. 军医经历、枪械和战场判断足以支持指挥官职业；所有神器使也必须具有指挥官可用性。
3. 她不以殖民地行政和国家治理为角色核心，1.0 不增加行政官职业。
4. 双职业的差异在工作场景，而不是把科学家写成治疗、指挥官写成纯伤害的两个无关模板。

### 4.3 边界

- 不把生命研究等同于人口批量改造、无限寿命或复活技术。
- 不把医学能力写成无需诊断即可治愈所有物种、疾病、污染和神器异常。
- 不因格蕾莎拥有战斗能力而将她变成狂战士或纯火力指挥官。
- 不将未经同意的人体试验变成玩家可反复获取增益的正确操作。

## 5. 唯一核心机制：生命档案

### 5.1 核心定义

**生命档案**：格蕾莎从真实病例或战场损伤中记录症状、环境、治疗反应和失败结果，逐步建立针对特定风险的临床方案；玩家可以选择立即采取有限的应急救治，或在条件允许时完成分析后采用更稳定的处置方案。

机制强调“先观察和诊断，再形成可复核的治疗证据”。安卡增强生命恢复，但不能跳过病因、医疗资源、伦理边界和死亡的不可逆性。

### 5.2 第一版玩法结构

1. 同一时间只建立一份主要生命档案，来源可为异常、殖民地病理、环境危机或格蕾莎所在舰队承受的明确损伤。
2. 通过观察、研究或有限接触收集病例证据；不同来源不能无条件合并成通用万能疗法。
3. 风险正在造成伤害时，玩家可选择应急处置：立即缓解部分损害并稳定对象，但消耗医疗资源，且不能自动得到完整研究结论。
4. 若保留观察和分析时间，格蕾莎可以形成针对当前风险的治疗方案，为后续救治、恢复或防护提供更稳定效果。
5. 科学家职业侧重收集病例、识别病因和完成方案；指挥官职业侧重战场分诊、撤离、污染隔离和维持生命支持。
6. 两种职业共享档案进度，但切换职业不能复制奖励、重复结算病例或绕过恢复期。
7. 病例结束后，档案保留为文明医疗记录和有限经验；不能永久叠加为对所有生命现象的无限增益。

### 5.3 叙事意义

- 格蕾莎不再被简化为治疗光环，而是以诊断、修正判断和承担医疗后果体现专业能力。
- 安卡代表对生命的支持，不代表胜过死亡；已经发生的死亡仍不可撤销。
- 应急救治与完整研究之间存在真实取舍，但二者都必须留下记录并接受后续审查。
- 格蕾莎的成长不是忘记战争，而是把过去的失败转化为能够保护后来者的知识。

### 5.4 能力边界

生命档案不能：

- 复活死亡领袖、人口、陆军、舰船或被毁灭的文明。
- 撤销已经结算的战争伤亡、行星毁灭或天灾后果。
- 自动治愈全部疾病、毒素、污染、黑门侵蚀或外星生命异常。
- 在没有样本、接触、时间和医疗资源时直接产生完整治疗方案。
- 将一个物种或病例的结论无条件套用到所有生命。
- 赋予无条件永生、无限再生或永久免疫。
- 以紧急处置为理由永久取消知情同意、伦理审查和患者权利。
- 解释格蕾莎身体幼化、跨地域抵达和神器使化的最终因果。

## 6. 1.0 实装边界

### 进入 1.0

- 科学家默认职业与指挥官可切换职业。
- 一个“建立档案—收集证据—应急处置或完成分析—形成有限方案—保留记录”的核心闭环。
- 科学家和指挥官共享同一档案，不复制角色或奖励。
- 明确死亡不可逆、治疗对象权利和实验伦理边界。
- 白夜馆招募、通讯、档案、唯一身份和待锁定的统一内部 slug。
- 正式数值、职业切换成本和触发对象另行审核。

### 暂不进入 1.0

- 复活领袖、人口或舰队。
- 全物种通用医疗数据库。
- 大规模生物改造和永生路线。
- 格蕾莎身体幼化原因的最终解释。
- 完整临床伦理事件链和大型个人主线。

## 7. 与其他角色的区分

| 角色 | 核心机制 | 主要问题 | 与格蕾莎的区别 |
| --- | --- | --- | --- |
| 赛斯 | 愿望履责 | 如何把具体求助转化为现实援助 | 格蕾莎处理可观察病例和医疗证据，不处理一般社会愿望 |
| 拉比 | 阿米特的守则 | 如何辨识现实威胁并进行共生保护 | 格蕾莎依据病理和治疗反应建立方案，不进行善恶或敌意判断 |
| 安 | 时序学习 | 如何从有限时间片与失败中成长 | 格蕾莎不回溯时间，只保留病例记录并改善未来救治 |
| 格蕾莎 | 生命档案 | 如何在危机、证据、救治和伦理之间作出医疗判断 | 以异常医学、战地分诊和有限生命支持构成个人闭环 |
