# 雯梓 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定雯梓在 1.0 中的固定身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。方案经人工批准前，不修改游戏代码。

## 2. 证据与约束基线

- 雯梓继承棋馆并长期承担东方古街的生活、守护和公共责任，是当地主要负责人和对外协商代表。
- 东方古街是具有移民、多元文化、商业生活和历史记忆的共同体，不是只有传统阵法的封闭地区。
- 雯梓推动与中央庭合作，但要求尊重原住民、地方历史与协商边界；这既不是拒绝统一，也不是接受单方面接管。
- 围棋・王者之弈表现黑白棋子、攻守转换、位置、先后、进退和每一步背后的生命代价。
- 雯梓可以放大棋子、布置大型棋阵，实施围困、打击、保护、恢复和局部战场控制。
- 她会主动保护弱者，但苍柯事件说明保护不能替代被保护者的自主选择；她的成长是尊重离开，而不是停止保护。
- 她不能预知全部未来、控制他人思想，也不能把居民、舰员或整个银河当作可任意牺牲的棋子。

## 3. 固定身份

### 3.1 世界观身份

固定为：**东方古街公共代表／中央庭地方协商与布局支援神器使**。

雯梓代表东方古街参与灾后重建、文明整合与星际殖民经验转化。她既承担共同体协商和空间布局，也能以王者之弈参与保护性战斗；她不是独立国家元首、地方割据者或以个人能力替代居民制度的统治者。

### 3.2 与中央庭及玩家的关系

- 中央庭与雯梓之间是统一文明内部的协商、合作与责任分配，不是中央庭对东方古街的单向命令或吞并。
- 玩家作为指挥使可以提出建设、迁移、防卫和行动目标，但必须明确哪些生活、历史与人员不能被当作纯资源牺牲。
- 雯梓可以提供局势布局和攻守方案，也有权要求先听取受影响共同体的意见。
- 居民、学徒和被保护者拥有离开、拒绝或选择其他道路的权利；雯梓的保护欲不能变成占有。
- 东方古街经验可以服务其他殖民地，但不能被复制成所有星球必须采用的唯一文化模板。

## 4. 领袖职业建议

### 4.1 正式建议

- 默认职业：**行政官（Official）**。
- 可切换职业：**指挥官（Commander）**。
- 行政官方向：地方协商、共同体重建、人口安置、文化延续与空间布局。
- 指挥官方向：黑白攻守转换、战场保护、局部围困与撤离通道规划。
- 两种职业共享同一角色、同一王者之弈和同一布局记录，不复制两个雯梓。

### 4.2 采用行政官／指挥官双职业的理由

1. 东方古街负责人、重建合作和公共协商是雯梓区别于一般棋手的核心，因此行政官适合作为默认职业。
2. 原作棋阵、攻守转换与战斗能力足以支持指挥官职业；所有神器使也必须具有指挥官可用性。
3. 科学研究不是其主要文明职责，1.0 不增加科学家职业。
4. 两种职业都围绕“布局时保护具体生活与选择”展开，而不是行政官只加产出、指挥官只加伤害。

### 4.3 边界

- 不把东方古街写成独立银河国家，也不把雯梓写成中央庭之外的国家统治者。
- 不把居民、人口、舰队或角色直接称为可以牺牲的棋子。
- 不将围棋能力扩展为全知战略、未来预言、思想控制或无视距离的银河棋盘。
- 不把地方自治经验写成拒绝中央庭、拒绝现代技术或拒绝所有人口迁移。

## 5. 唯一核心机制：经纬共局

### 5.1 核心定义

**经纬共局**：玩家、雯梓与受影响共同体先确定一个共同目标和一个不可被轻易牺牲的保护边界，再通过有限的黑子行动与白子行动逐步完成布局；黑子用于开拓、突破和主动争取，白子用于守护、修复和保留退路。

棋盘记录的是空间、资源、风险和承诺，不是把居民或舰员降为棋子。只有攻守行动与已确认的共同目标保持一致，布局才会稳定；持续偏向单一方向会产生失衡，需要协商修正或结束当前棋局。

### 5.2 第一版玩法结构

1. 同一时间只维持一局主要布局，候选对象可为一个殖民地、建设区域、雯梓所在舰队或明确防卫任务。
2. 开局前由玩家选择共同目标，并确定一个保护边界，例如维持基本生活、保存地方记忆、保障撤离或保护关键友军。
3. 行政官状态下，黑子行动侧重开拓、建设、人口与资源调度；白子行动侧重公共服务、稳定、修复和文化延续。
4. 指挥官状态下，黑子行动侧重突破、压制和主动部署；白子行动侧重护盾、掩护、围挡和撤离通道。
5. 黑白行动共享同一棋局进度。合理衔接攻守会形成稳定布局；连续只用一侧会提高失衡，不能无限堆叠单一收益。
6. 当目标达成、保护边界被否定或局势已无法维持时，玩家与雯梓必须收官：结算有限成果、承担代价并解除棋局。
7. 职业切换可以改变下一步可用行动，但不能复制进度、重置失衡或重复结算成果。

### 5.3 叙事意义

- 雯梓的棋艺被转化为对位置、先后、攻守和代价的理解，而不是把世界写成她操控的棋盘。
- “共局”强调中央庭、地方共同体和玩家共同确定目标，避免个人保护欲替代他人选择。
- 黑白双方不是善恶，而是主动争取与谨慎守护的两类行动；二者都可能必要，也都可能过度。
- 收官意味着承认现实限制、允许离开并对损失负责，不是强行把所有对象永远留在自己的保护范围内。

### 5.4 能力边界

经纬共局不能：

- 预知全部未来、自动得出最优解或保证任何决策必胜。
- 控制居民、领袖、舰员或敌人的思想与自主选择。
- 把整个银河、全部殖民地或所有舰队同时纳入一局。
- 通过棋子无限创造人口、资源、舰船或建筑。
- 自动吞并地方共同体、取消中央庭制度或建立东方古街独立国家。
- 用保护之名阻止受保护者离开、拒绝或另选道路。
- 自动处决敌方关键单位、封锁全部航道或无视传感器与舰队位置。
- 将黑白棋子解释为绝对善恶、文明阵营或人格等级。

## 6. 1.0 实装边界

### 进入 1.0

- 行政官默认职业与指挥官可切换职业。
- 一个“选择目标与保护边界—黑白行动布局—维持平衡—达成目标或收官”的核心闭环。
- 同时只维持一局主要布局。
- 行政和军事行动共享棋局进度，职业切换不复制收益。
- 白夜馆招募、通讯、档案、唯一身份和内部 ID `wenzi`。
- 正式数值、目标类型、失衡阈值和切换成本另行审核。

### 暂不进入 1.0

- 全银河棋盘与自动最优决策。
- 东方古街独立国家路线。
- 完整地方自治制度模拟。
- 五行阵与黑核技术复原。
- 苍柯及旧人身份的大型个人剧情。
- 独立大型个人主线。

## 7. 与其他角色的区分

| 角色 | 核心机制 | 主要问题 | 与雯梓的区别 |
| --- | --- | --- | --- |
| 晏华 | 态势研判 | 如何从证据确认现实关键矛盾 | 雯梓不建立国家级情报结论，而是在共同目标下安排攻守与保护边界 |
| 幽桐 | 自定射界 | 如何确定个人支援边界并精确执行 | 雯梓处理行政或战场的多步布局，不聚焦单一远程射界 |
| 拉比 | 阿米特的守则 | 如何在现实威胁中进行共生保护 | 雯梓不判断善恶，而是协调共同体目标、空间与攻守代价 |
| 雯梓 | 经纬共局 | 如何在发展、守护与自主选择之间布局 | 以黑白行动、共同目标和收官责任构成个人闭环 |
