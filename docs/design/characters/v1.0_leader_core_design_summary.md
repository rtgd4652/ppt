# 1.0 十名神器使领袖职业与核心机制汇总

## 1. 文档用途

本文汇总十名锁定神器使已经获得人工批准的领袖职业、唯一核心机制和当前实现边界。它是设计总表，不替代各角色专项文件，也不代表正式数值、脚本、美术或测试已经批准。

共同规则：

- 十名神器使都必须能够以指挥官身份参与战斗。
- 每名角色只保留一个人物核心机制；职业切换不得复制机制状态或收益。
- 职业用于承载人物职责，不得把角色压缩成普通数值模板。
- 未完成 Stellaris 4.4.3 可行性验证前，不把叙事设计直接转换成最终脚本。

## 3. 特殊角色说明

### 3.1 安托涅瓦

安托涅瓦是中央庭国家元首、文明核心领袖和强大的神器使。她的行政、研究和战斗职责都不能由单一原版职业完整表达，因此只锁定“指挥官形态必须可用”，底层 class 留给最小技术原型决定。

### 3.2 爱缪莎

爱缪莎的设计由三职业切换、等级成长、命运观测、专属危机和最终授权共同组成。她在开局不是命运主宰；完整命运主宰身份只在第五阶段全部剧情结束、玩家授权且她自主接受之后成立。30 级只是路线资格与表现节点，不自动完成终局转变。

### 3.3 丽

丽的科学家职业以机甲工程、工业技术、材料、原型验证和有限黑核实验为范围。她偏爱机甲，但并非只负责投资；同时不能把其工程能力泛化为全学科万能科研。

## 4. 设计关结论

- 十名神器使的“职业与人物核心”设计关已经完成。
- 下一阶段是机制可行性设计，不是立即批量写入正式数值。
- 每名角色仍须独立完成美术关、实现关和测试关。
- 爱缪莎的大型主线、危机、专属舰与专属巨构继续按已批准专项蓝图推进，不能被普通领袖模板替代。

## 5. 下一阶段建议顺序

2026-10-07执行顺序已按用户确认的四里程碑计划更新：十人与中央庭首版已完成统一收口，下一阶段为里程碑4的正式资产、整体平衡和发布回归。下列设计准备事项保留为依据，不恢复历史逐项穷举门槛；现行范围和运行证据见[项目进度](../../PROJECT_STATUS.md)与[收口记录](../../../reports/milestone3_ten_character_closeout_2026-10-07.md)。

1. 为八名普通规模角色建立最小机制责任卡：作用域、状态保存、职业切换和失败回退。
2. 单独验证安托涅瓦的底层 class 与多职责表现方案。
3. 将爱缪莎现有三职业实现与正式主线状态机做接口审计，不重写已批准主线。
4. 在正式美术风格和角色视觉锚点批准后，再制作立绘与图标。
5. 完成白夜馆、唯一招募、读档和 `error.log` 专项回归后，才把角色标记为 1.0 完成。
