# 幽桐 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定幽桐在 1.0 中的固定身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。方案经人工批准前，不修改当前可玩实现。

## 2. 证据与约束基线

- 幽桐是使用“神弓・甘狄拔”的射手型神器使，具备持续、精准的远程作战能力。
- 甘狄拔能够不停歇地射出箭矢，并向持有者传递“不可堕落”的理想要求，但神器不是绝对道德判定器。
- 幽桐长期以温柔、可靠和近似“圣者”的外在形象压抑厌恶、愤怒、叛逆与自我需求。
- 他会在复杂关系尚未解决时履行救援和照护责任，但责任不等于原谅，也不等于允许他人持续侵害。
- 个人支线最终确认他拒绝继续扮演无条件原谅的圣者，并开始承认自己也是拥有喜怒和边界的普通人。
- 他能依据现场证据识别矛盾，但该能力不等于晏华的国家级情报与态势研判。
- 中央庭不能把他的可靠和自我牺牲倾向当成无限可消耗的军事资源。

## 3. 固定身份

### 3.1 世界观身份

固定为：**中央庭远程支援神器使／精确射击与保护性作战人员**。

幽桐参与危险目标处置、远程掩护和舰队支援。他不是道德圣人、宣传偶像或只负责输出的武器平台；其战斗价值来自清楚选择要保护什么、在何处出手，以及何时拒绝无意义消耗。

### 3.2 与中央庭及玩家的关系

- 中央庭为幽桐提供明确任务目标、交战边界、轮换和心理支持，不能以“可靠”为由无限追加风险。
- 玩家作为指挥使可以选择保护目标和作战原则，但不能要求幽桐以自我毁灭证明责任感。
- 幽桐有权指出目标冲突、拒绝不必要牺牲，并在紧急情况下主动改变既定射界。
- 角色成长表现为主动选择责任与边界，而不是变得冷漠、失去同情心或彻底放弃支援他人。

## 4. 领袖职业建议

### 4.1 正式建议

- 对外显示身份：**中央庭远程支援指挥官**。
- Stellaris 职业：**指挥官（Commander）单职业**。
- 主要职责：远程掩护、航道警戒、优先威胁处置和保护性舰队作战。

### 4.2 采用指挥官单职业的理由

1. 原作射手、物理攻击、神弓和持续射击能力与舰队远程支援具有直接对应关系。
2. 幽桐的核心并非殖民地治理或神器理论研究，不需要为了职业数量而增加行政官或科学家。
3. 指挥官是所有神器使均可使用的共同战斗职业；幽桐以精准、射界和自定边界形成个人差异。
4. 单职业不妨碍通讯、事件和档案表现其音乐、家庭经历、真实人格与非战斗生活。

### 4.3 边界

- 不把幽桐写成只追求最高伤害、射速和射程的火力放大器。
- 不把“不可堕落”写成中央庭要求其绝对服从、永不撤退或永远牺牲的军令。
- 不把远程精准写成自动命中所有目标、无视侦察与射界、或直接识破全部敌方弱点。
- 不因其礼貌和责任感删除腹黑、叛逆、厌恶、拒绝与真实表达。

## 5. 唯一核心机制：自定射界

### 5.1 核心定义

**自定射界**：幽桐与指挥使共同确定一个保护对象、优先威胁和清晰交战边界；他在该边界内维持克制而连续的远程支援，并在真正需要时决定是否打破既定限制进行一次高风险救援。

机制重点不是持续堆叠火力，而是“明确要保护什么，并由本人选择承担到什么程度”。稳定遵守射界带来可靠支援；主动越界可以挽救紧急目标，但必须产生压力、暴露或恢复期，不能成为无限自我牺牲按钮。

### 5.2 第一版玩法结构

1. 同一时间只维持一个主要射界任务，候选对象可为幽桐所在舰队、同星系友军、重要航道或明确的优先敌方目标。
2. 玩家选择保护重点与交战原则，例如保持距离、优先拦截、保护撤离或压制特定威胁；具体选项必须经脚本可行性验证。
3. 舰队在符合射界条件下观察和交战时，逐步完成校准，形成稳定的远程支援状态。
4. 频繁更换目标、脱离观测范围或无视既定原则会中断校准；不能在所有战场同时生效。
5. 当保护对象遭遇明确的紧急威胁时，玩家可请求幽桐“越界援护”。他暂时突破原定限制完成一次关键拦截、掩护或集中射击。
6. 越界援护消耗当前校准并产生恢复期或风险；是否行动必须表现为幽桐的主动确认，而不是强制牺牲。
7. 完成任务后解除射界并重新选择；历史记录可用于档案和成长，但不能永久叠加为无限火力。

### 5.3 叙事意义

- 甘狄拔的约束不再等于外界要求幽桐扮演完美英雄，而成为他自己选择的行动纪律。
- 玩家与中央庭提供明确目标和撤回权，幽桐负责在边界内持续、准确地守护同伴。
- “越界”不是堕落，也不是违抗人格；它表示现实有时需要重新判断规则，但决定必须由承担风险的人参与。
- 机制同时保留他的可靠、精准和责任感，也允许拒绝、疲惫与恢复存在。

### 5.4 能力边界

自定射界不能：

- 在全银河、所有舰队或所有战斗中同时生效。
- 无视传感器、距离、舰队位置和目标可见性。
- 自动摧毁旗舰、巨像、天灾核心或任何指定单位。
- 永久叠加射程、射速、伤害或必中特性。
- 通过越界援护无限复活友军、撤销舰船损失或保证战斗胜利。
- 把幽桐的个人约束变成中央庭鼓励其自我伤害的制度。
- 复制晏华的证据研判、拉比的善恶判断或爱缪莎的未来观测。

## 6. 1.0 实装边界

### 进入 1.0

- 指挥官单职业与中央庭远程支援身份。
- 一个“选择保护对象与交战边界—完成校准—稳定支援—紧急时越界援护”的核心闭环。
- 同时只维持一个主要射界任务。
- 越界援护具有明确消耗、风险或恢复期，且保留幽桐的主动选择。
- 白夜馆现有招募、通讯、档案、唯一身份和内部 ID `yutong`。
- 将当前纯等级火力叠加特质改造为服务核心闭环的方案，正式数值另行审核。

### 暂不进入 1.0

- 全银河多目标狙击网络。
- 自动处决敌方关键单位。
- 大型父子关系剧情复演。
- 无限箭矢对应的无限弹药、无限火力或无冷却攻击。
- 以越界援护为名的无损复活和强制牺牲。
- 独立大型个人主线。

## 7. 与其他角色的区分

| 角色 | 核心机制 | 主要问题 | 与幽桐的区别 |
| --- | --- | --- | --- |
| 晏华 | 态势研判 | 如何从现实证据中确认关键矛盾 | 幽桐不建立情报结论，而是执行明确射界内的支援 |
| 安 | 时序学习 | 如何从短时间片和失败中成长 | 幽桐不回溯时间，而是校准当前目标与边界 |
| 赛斯 | 愿望履责 | 如何把具体求助转化为现实援助 | 幽桐聚焦远程保护与交战纪律，不处理社会愿望系统 |
| 幽桐 | 自定射界 | 如何在责任、精准和个人边界间作出选择 | 通过主动约束与有限越界体现角色核心 |

- 审核日期：2026-08-11。

- 当前状态：`approved_for_mechanic_design`。
