# 拉比 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定拉比在 1.0 中的固定身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。方案经人工批准前，不修改当前可玩实现。

## 2. 证据与约束基线

- 拉比是与“怪兽・阿米特”共同生活和战斗的未成年神器使，二者不是普通的主人、宠物或坐骑关系。
- 阿米特既能战斗，也承担照护、保护和约束职责；与其说拉比单方面控制阿米特，不如说二者形成了具有监护性质的共生关系。
- 拉比因贫困与无人照顾形成强烈生存本能，也曾偷窃、说谎、冲动行事并伤害阿米特；这些事实不能被美化或抹除。
- 拉比能够承认错误、产生悔意，并逐渐从自我保护走向信任、责任和主动保护他人。
- “分辨善恶”是角色和神器的重要象征，但不能替代证据、公共司法、外交程序或中央庭制度。
- 阿米特从黑门黑雾中出现、消散后随拉比恢复而重现，均为已知现象；其本体机制仍是开放谜团。
- 拉比是儿童。中央庭不能让他独立统御文明级军队、决定战争与处决，也不能利用阿米特的保护本能迫使二者无限承担风险。

## 3. 固定身份

### 3.1 世界观身份

固定为：**中央庭特殊行动神器使／与阿米特共同执行保护和威胁压制任务的未成年行动人员**。

拉比与阿米特可以参与救援、护送、危险目标压制和舰队防卫，但必须在中央庭任务授权、成年指挥体系和明确撤离条件下行动。拉比不是法官、处刑者或独立军事统帅；阿米特也不是中央庭用于判定善恶的制度工具。

### 3.2 与中央庭及玩家的关系

- 玩家仍以指挥使身份与拉比沟通，负责明确任务、保护对象、交战限制和撤离条件。
- 中央庭承担未成年人保护、生活保障、教育、医疗和行动监督责任，不能把拉比的战斗能力当成免除这些责任的理由。
- 拉比有权表达不信任、愤怒和拒绝；玩家不能以“英雄”或“坏孩子”的标签替代沟通。
- 阿米特能够对拉比和同伴受到的现实威胁作出保护反应，但不能被授权为独立司法或外交主体。
- 角色成长表现为拉比学习区分冲动、恶意、危险和责任，而不是被改造成完全服从的成人式军人。

## 4. 领袖职业建议

### 4.1 正式建议

- 对外显示身份：**中央庭特殊行动指挥官**。
- Stellaris 职业：**指挥官（Commander）单职业**。
- 主要职责：保护性作战、危险目标压制、救援和有限追击。
- 叙事说明：游戏职业用于承载拉比与阿米特的战斗能力，不等于拉比获得现实制度中的成年军衔或独立战略决策权。

### 4.2 采用指挥官单职业的理由

1. 拉比与阿米特的原作战斗、保护和压制表现可直接转化为舰队行动。
2. 其核心不是国家治理或神器理论研究，不应为了职业数量增加行政官或科学家身份。
3. 指挥官是所有神器使均可使用的共同战斗职业；拉比以共生监护、现实威胁识别和保护反应形成个人差异。
4. 通过任务授权、成年指挥链和撤回权，可以保留可玩职业，同时避免把儿童写成独立掌握文明军权的统帅。

### 4.3 边界

- 不把“分辨善恶”写成自动识别敌国善恶、发现全部间谍或判定所有个体有罪。
- 不让拉比独立决定宣战、灭绝、处刑、永久制裁或文明外交。
- 不把阿米特写成没有人格的舰载兵器、召唤兽或一次性护盾。
- 不以未成年人身份为由删除拉比的行动能力，也不以战斗能力为由取消未成年人保护。

## 5. 唯一核心机制：阿米特的守则

### 5.1 核心定义

**阿米特的守则**：玩家、拉比与阿米特在行动前共同确定保护对象、现实威胁标准和撤离条件；行动中根据敌方已经实施的攻击、追击和伤害累积“威胁确认”，由阿米特优先保护拉比与同伴，再由拉比决定是否进行有限反击。

该机制把“善恶判断”转化为对可观察行为和现实危险的辨识，而不是读取内心或宣布绝对罪恶。它同时表现阿米特的监护、拉比的直觉与成长，以及中央庭必须承担的制度责任。

### 5.2 第一版玩法结构

1. 同一时间只维持一份行动守则，玩家选择一个主要保护对象或任务，例如护送舰队、救援编队、保卫撤离或压制明确威胁。
2. 行动开始前确定有限的交战标准和撤离条件；拉比与阿米特不是无条件留在战场。
3. 敌方对保护对象实施攻击、追击撤退单位或造成持续危险时，逐步形成“威胁确认”；未发生敌对行为的单位不能仅因阵营或标签被自动判恶。
4. 威胁达到条件后，阿米特进入保护状态，优先承担拦截、减伤、掩护或压制功能；具体表现由脚本可行性和数值审核决定。
5. 玩家可以请求拉比进行一次有限反击，消耗当前威胁确认并集中压制已确认目标；该行为不能扩展成对整个国家或种族的惩罚。
6. 当拉比或阿米特承受过高风险、保护对象脱离危险或撤离条件满足时，守则转入恢复或结束，不允许无限保持最高强度。
7. 行动记录可以表现拉比是否遵守约定、是否冲动以及是否主动保护他人，但不能形成永久累加的道德等级或无限战斗增益。

### 5.3 叙事意义

- 阿米特继续承担保护者、照护者和行为约束者，而不是被中央庭拆解成装备。
- 拉比的“善恶感”保留为敏锐但仍会成长的判断，不被神化为永远正确。
- 玩家需要给出可理解的任务与边界，并对使用武力的后果负责，不能把责任推给儿童或神器。
- 拉比的成长不是失去野性和反抗，而是逐渐学会在愤怒之外确认危险、保护他人并承担选择。

### 5.4 能力边界

阿米特的守则不能：

- 读取思想、测量灵魂或证明某个个体绝对善恶。
- 自动发现全部间谍、伪装、犯罪、外交谎言或未来背叛。
- 赋予拉比或阿米特高于中央庭司法、外交和军事制度的裁决权。
- 将单一舰队的敌对行为扩大为对整个物种或文明的有罪判定。
- 自动处决旗舰、领袖、巨像、天灾核心或已撤退单位。
- 无限吸收伤害、无限复活拉比与阿米特、撤销舰船损失或保证胜利。
- 解释阿米特的黑雾本体、黑门来源或消散重现机制。
- 复制幽桐的射界校准、晏华的态势研判或赛斯的愿望履责。

## 6. 1.0 实装边界

### 进入 1.0

- 指挥官单职业与“特殊行动人员而非独立军事统帅”的叙事说明。
- 一个“设定守则—确认现实威胁—阿米特保护—有限反击—撤离或恢复”的核心闭环。
- 同时只维持一份行动守则和一个主要保护任务。
- 玩家、中央庭和成年指挥体系承担任务与武力责任。
- 白夜馆现有招募、通讯、档案、唯一身份和内部 ID `rabi`。
- 将现有纯战斗特质改造为服务共生保护闭环的方案，正式数值另行审核。

### 暂不进入 1.0

- 全银河善恶审判系统。
- 犯罪、谍报和外交忠诚的自动识别。
- 对敌对文明的处刑或永久惩罚机制。
- 阿米特本体、黑雾来源和重现机制的最终解释。
- 大型未成年人伦理事件链。
- 独立大型个人主线。

## 7. 与其他角色的区分

| 角色 | 核心机制 | 主要问题 | 与拉比的区别 |
| --- | --- | --- | --- |
| 幽桐 | 自定射界 | 如何在责任、精准和个人边界间支援 | 拉比不是远程校准，而是阿米特围绕已确认现实威胁进行共生保护 |
| 晏华 | 态势研判 | 如何从现实证据中确认关键矛盾 | 拉比不进行国家级情报分析，只辨识当前行动中的直接危险 |
| 赛斯 | 愿望履责 | 如何把具体求助转化为现实援助 | 拉比不处理社会愿望，而是在危险中保护并学习承担后果 |
| 拉比 | 阿米特的守则 | 如何在愤怒、判断、保护和成长之间行动 | 以共生监护、现实威胁确认和有限反击构成个人闭环 |
