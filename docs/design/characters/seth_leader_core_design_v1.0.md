# 赛斯 1.0 领袖职业与核心机制设计

## 1. 文档目的

本文确定赛斯在 1.0 中的固定身份、职业表达与唯一核心机制，供后续 Stellaris 4.4.3 可行性设计使用。

本文不包含正式数值、事件脚本、图标或最终美术资产。人工整体批准前，不修改当前可玩实现。

## 2. 证据与约束基线

- 赛斯是圣星教会神官，也是与中央庭协作的神器使；两个组织不能因此被合并为同一体系。
- 他表面懒散、逃避文书和组织纪律，不能被改写成始终严肃完美的宗教领袖。
- 他会回应普通人的求助，并在神器无法解决问题时依靠调查、现实行动与社会协作寻找办法。
- 个人支线确认他能够识别求助说辞中的现实破绽，但这来自地区知识和行为观察，不是预知或全知。
- 他具有直接、强力的正面战斗能力，会在危险中保护同行者并掩饰自己的伤势。
- 神器“权杖・羽蛇神杖”与降雨、丰收、治疗和生命支持有关，但不能实现任意愿望。
- “愿望会产生后果，许愿者必须面对责任”是赛斯的重要个人理解，不是宇宙自动执行的因果律。
- 神与教义相关发言属于其个人信仰，不自动成为本 Mod 宇宙论事实。

## 3. 固定身份

### 3.1 世界观身份

固定为：**圣星教会神官／中央庭协作神器使／基层救援与社会支持者**。

赛斯不是教会最高权威，也不是中央庭宗教代表。他在两个体系之间承担实际协作：接触需要帮助的人、辨认真实问题、组织现实资源，并在必要时亲自进入危险区域。

### 3.2 与中央庭、教会及玩家的关系

- 圣星教会为其提供神职与文化背景，中央庭为其公共救援、殖民地协作和危险行动提供制度接口。
- 赛斯不替中央庭制定国教，也不以神意否决公共决策。
- 玩家作为指挥使参与判断求助内容和选择解决路径，但不能把赛斯当成无代价许愿工具。
- 赛斯可以违反日常纪律、逃避文书，却不能在真正需要帮助时毫无理由地抛弃求助者；人物反差必须同时保留。

## 4. 领袖职业建议

### 4.1 正式建议

- 对外显示身份：**中央庭救援联络神官**。
- Stellaris 职业：**行政官（Official）／指挥官（Commander）双职业**。
- 行政官状态：负责殖民地社会支持、灾害救援、生命保障、基层联络和特殊求助处置。
- 指挥官状态：领导救援与护航编队，在灾区撤离、舰队救援和保护性战斗中使用羽蛇神杖支援同伴。

### 4.2 采用行政官／指挥官双职业的理由

1. 赛斯的核心不是指挥舰队，而是在制度与日常生活之间处理具体求助、救援和恢复问题。
2. 羽蛇神杖的治疗、护盾、降雨与丰收表现适合转化为殖民地生命保障和危机响应。
3. 原作确认他能够独自清理怪物、掩护同行者撤离并承担正面战斗，因此指挥官形态可承载救援、护航和保护性作战。
4. 不采用科学家职业，因为神器研究并非其主要身份，其价值也不在理论研究。
5. 指挥官是所有神器使均可进入的共同战斗职业，但赛斯的军事表达仍以救援和支援为核心，不复制晏华的战略研判、安的时序学习或其他角色机制。

### 4.3 边界

- 不把行政官写成只有幸福度、稳定度和舒适度叠加的被动数值包。
- 不因神官身份授予神权国家、强制精神主义或教义统治能力。
- 不把指挥官形态写成传统进攻型舰队统帅；其优势来自救援、护航、防护和危机中的正面承担。
- 不删除懒散、逃班、玩笑和不端正言行，也不让这些缺点否定其关键时刻的责任感。
- 职业切换必须保留同一人物、唯一引用、愿望记录和已承担责任，不能生成互不连续的两个赛斯。

## 5. 唯一核心机制：愿望履责

### 5.1 核心定义

**愿望履责**：赛斯接收一项来自殖民地或群体的具体求助，先调查愿望背后的真实问题和潜在后果，再由玩家选择使用神器、公共制度、物资调度或亲自行动解决问题。

机制的重点不是“点击后愿望实现”，而是把模糊诉求转化为可以承担责任的现实行动。羽蛇神杖只能处理其能力范围内的生命、环境和恢复问题；复杂社会矛盾仍需要制度、资源和人的参与。

### 5.2 第一版玩法结构

1. 同一时间只登记一项主要愿望，来源优先限定为赛斯任职范围内的殖民地、其指挥舰队接到的求救信号或已经发生的明确危机。
2. 愿望首先以不完整诉求出现；玩家可选择调查其真实需求，也可仓促按字面处理。
3. 调查可使用当地信息、中央庭记录、殖民地状况或赛斯的实际接触，揭示愿望的资源需求、风险和责任主体。
4. 查明后提供有限的解决方向：使用羽蛇神杖改善生命／环境条件、调动公共资源、组织社会协作，或由赛斯亲自进入危险区域完成救援。
5. 行政官状态侧重调查、公共资源和长期恢复；指挥官状态侧重护航、撤离、防护与直接救援。两个职业共享同一愿望及责任记录。
6. 正确解决形成“已履行愿望”记录，表现为当地信任、恢复能力或后续危机准备；正式效果待机制阶段确定。
7. 仓促照字面满足、忽略明显风险或长期不处理，可能留下次生问题；不能把失败写成超自然诅咒自动惩罚。
8. 完成、失败或主动放弃后才能登记下一项主要愿望，避免高频弹窗和无限任务堆积。

### 5.3 紧急救援表现

当任职范围发生满足条件的严重灾害时，赛斯可以暂时中断普通愿望，进入一次紧急救援：

- 羽蛇神杖提供有限治疗、生态支持或防护；
- 赛斯本人承担危险区域的行动与撤离掩护；
- 中央庭负责后续资源、医疗和秩序恢复；
- 救援不能让已毁灭的殖民地、已死亡人口或全部舰船无条件复原。

该救援是“愿望履责”的危机形态，不另立第二套核心机制。

### 5.4 叙事意义

- 普通人的小愿望仍然值得星际文明看见，但文明不能依赖神迹代替制度。
- 赛斯的信仰通过实际帮助表达，不要求所有人接受同一宗教解释。
- 他会犯懒、会判断失误，也可能采用冒险办法；可靠来自关键时刻愿意承担后果，而不是人格完美。
- 玩家负责选择国家愿意付出的资源和风险，赛斯负责把抽象愿望带回具体的人与现实。

### 5.5 能力边界

愿望履责不能：

- 无代价生成任意资源、舰队、领袖或星球。
- 实现世界和平、复活死者、改写历史或直接消除全部社会矛盾。
- 把赛斯的个人信仰确认为全银河客观真理。
- 让圣星教会凌驾于中央庭法律、科研与公共制度。
- 自动知道求助者是否说谎，或不经调查获得完整真相。
- 永久免疫灾害、人口损失、生态崩溃或战争伤害。
- 把所有问题都交给羽蛇神杖，否定普通科技、公共资源和社会协作。

## 6. 1.0 实装边界

### 进入 1.0

- 行政官／指挥官双职业与中央庭救援联络神官身份。
- 两种职业共享愿望目标、责任记录、唯一身份与人物关系。
- 一个“接收愿望—调查需求—选择路径—承担结果”的核心闭环。
- 羽蛇神杖、公共资源和亲自行动三类解决语言。
- 低频、单目标的紧急救援表现。
- 白夜馆现有招募、通讯、档案和唯一身份继续保留。
- 将当前纯等级叠加特质改造为服务核心闭环的方案，但正式数值另行审核。

### 暂不进入 1.0

- 全银河愿望系统。
- 圣星教会大型政治或宗教改革线。
- 每个殖民地并行积压的大量随机委托。
- 任意愿望、复活、无损恢复和无限资源。
- 独立大型个人主线。
- 设局少女的后续故事与身份补完。

## 7. 与其他角色的区分

| 角色 | 核心机制 | 主要层级 | 与赛斯的区别 |
| --- | --- | --- | --- |
| 安托涅瓦 | 方舟时空支配 | 文明领导、战略传送与庇护 | 赛斯处理具体求助，不承担国家领导与大范围时空权能 |
| 晏华 | 态势研判 | 国家情报、行政判断与战略执行 | 赛斯调查单项现实需求，不建立国家级情报结论 |
| 安 | 时序学习 | 个体经验、局部回溯与成长 | 赛斯不重试时间，而是承担愿望的现实后果 |
| 赛斯 | 愿望履责 | 基层支持、救援与生命保障 | 强项是把普通诉求转化为可执行援助 |

- 审核日期：2026-08-11。
- 审核方式：SER-001～SER-009 整体人工批准；SER-003 按“所有神器使都可成为指挥官”的公共规则修正后批准。
- 当前状态：`approved_for_mechanic_design`。
- 后续允许：建立双职业切换、愿望目标、责任记录与紧急救援的 Stellaris 可行性方案。
- 后续仍禁止：未经新一轮审核直接写入正式数值、事件脚本或最终美术方案。
