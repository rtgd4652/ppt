## 多源比对

A02黑门观测体系＋A04异常样本封存→A05多源异常比对，物理T2、场操纵、1200科研、110权重。

研究后，同一殖民地有效的黑门观测站和异常样本保管库自动联合比对，使当地岗位物理研究产出+10%、工程研究产出+5%。样本库在别处不能满足资格；任一设施停用、损坏或移除后停止，恢复后重新判断。效果位于原观测站的条件行星修正，两座设施继续支付原建筑与岗位维护，没有额外研究提交或项目槽。

这不是R1付费样本分析的替代提交：不读写其进度、付费标记、成果或期限，也不复制成果；并存时按原生修正规则叠加。旧塔罗经济的额外2单位岗位条件保持独立，原观测站4单位基础岗位、稳定度、费用和维护不变。观测站旧容量单位问题不在本包顺带修正。未来A11复核站需要明确接续这项能力，本包不提前引用不存在的建筑。
