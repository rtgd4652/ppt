## 中庭级传承改型

这是原`artifact_strategic_cruiser`的新增舰首/舰装方案，不新增舰种、唯一舰、免费舰或预设设计。玩家按原设计器、船厂及改装流程投入，原舰体与四种区段仍保留。

传承舰首用原2L武器/4L防护换成1X/3L防护，基础1200合金，较旧舰首多400。炮击构型为1X＋4L；航母构型为1X＋1L＋2H＋2S＋2PD，原舰载机研究保持。两种均7L防护＋2A，较旧方案少一格大型防护，辅助槽仍可与D12等模块取舍。

主炮参数直接写入TXT，`total_fire_time=140`为引擎字段，不直接称140游戏日。主炮/辅助件各注册一个集合，反应堆复用`power_core`。三件均只适配中庭级，旧原版/命运之主/个人旗舰不新增适配；无`upgrades_to`或旧设计自动迁移。

再生使用本机原版字段，受原生时机/条件约束，同类修正相加，不是独立乘区、复活或免费补舰。两个A槽可自行权衡；不修改个人旗舰恢复、D12冷却、角色或剧情事实。

## 原生接口与外观

舰首采用原版`battleship_bow_XL1_entity`、`invisible_extra_large_fixed`和`xl_gun_01`，主炮沿用tachyon_lance特效。原版`has_no_valid_xl_weapon`只枚举原版科技，不能识别本包主炮，因此新区段自动设计权重改读本包资格，不追加原版长矛研究。

这些模型/特效仅供玩法占位，正式中央庭外观及配套表现仍须按资产计划定稿。旧旗舰或本占位不算新正式资产。

E10原擎天堡/完工巨型船坞、原拥有者有效营建场仍决定新建下单。组件能继续选配不等于已确认工业失效时原生改装或队列必然继续，相关行为运行未验。
