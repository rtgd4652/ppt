# R2d 避难组织与城市分区实施规格

2026-10-17，接续R2c `d5b04f0`。状态：**规格已细化，源码和运行未启动**。首包为C09／E04两项公共科技、一座BL05低级演算室，零新岗位；C10／E05留R2e，E07留R2f。当前代码33项公共科技／26个行星建筑定义／1星港建筑不变。

## 玩家得到什么

已有社区服务中心在C09后承担轰炸期的避难组织，帮助维持当地稳定和公共服务。E04让一颗殖民地付费选择科研、生产或民生方向；规划持续到取消，停用设施时暂停收益，原槽升级后接续。选择是当地的公共工程状态，与人物、个人研究、R1项目及C2分别保存。

## 避难组织

C09已研究、当地社区服务中心活跃、本国拥有且控制、公共文明身份符合，并且当前确有轨道轰炸时，提供当地稳定度+5、舒适度需求-10%。轰炸结束或现场失效后收益由条件撤回；无需新增准备按钮、状态或月度任务。

沿用社区设施和原岗位维护。C2继续使用原科技、中枢、正常准备／启动、1000能源＋500消费品、180日25%保护及既有整备期限；本项不读写其标记、费用或保护。

## 城市规划三选一

每次选择正常支付300能源＋100凝聚力。每颗殖民地同时一个方向，选择保存在三个无数值的原生标记修正之一，持续至主动取消或所有权变化。收益由当地活跃演算室／原高级演算院提供。

| 方向 | 当地收益／代价 |
| --- | --- |
| 科研 | 岗位物理、社会和工程研究产出各+5% |
| 生产 | 岗位合金、消费品产出各+5%；岗位矿物维护+5% |
| 民生 | 稳定度+3、舒适度需求-10% |

数值是起始基准，照原生修正规则处理；既有演算院收益保留，不宣称独立乘区。取消决议无费用、无返还、无即时奖励，清除当前方向，再选需要重新付费。三方向各一条选择决议和一条共用取消决议即可，无需新增通讯菜单或项目进度系统。

正常条件为：公共文明、已知E04、拥有控制一致、当地低级或高级演算设施活跃、当前无方向。设施停用、损坏或被占领时仅暂停收益，选择保留；恢复后自动接续，不再扣费。升级时选择不清除，高级接续同一份效果；遗留上下级并存时只由高级提供一次规划收益。

## 保存与所有权

原生建筑／队列和三选一标记保存选择，无新增国家变量、全银河日扫或月度工程账本。所有权改变时由原生on_colony_transfer清除三个本包标记，不退款，不转移给新拥有者；占领但未改变拥有权时继续保留选择并暂停收益。

本机4.5.2的on_colony_transfer注释明确This为colony、From为新拥有国、FromFrom为旧拥有国；原版action.89使用carrier_event清理修正。实现跟随该原生入口，不能用殖民地编号同号读取planet，也不能照搬4.4事件模板。清理事件只处理本包三种标记，不清除R1、C2、人物或主线状态。

## 最小验收

源码检查聚焦三选一、正常扣费／取消不返还、现场失效暂停、升级不丢选择且只计一份，以及转让只清本包状态。费用、前置和本地化需要与规格核账。

游戏只选一颗殖民地正常建演算室、付费选择科研分区并正常升级。在已有升级进度、方向仍有效时保存并实际载回一次，之后完工确认方向接续与单份收益。缺资源直接rr并记录来源，不重跑另外两种方向或历史包。C09若未自然遇到对应轰炸状态，明确留作未验；不为它另造战争，也不把城市规划读档当作避难效果通过。

R2e的成果复现与研究园区先明确公共成果来源和归档，R2f再做有限环境缓冲。陆军和舰船组件按[军备路线](artifact_civilization_military_research_plan_v0.1.md)排R3／R4，当前不混入R2d源码。批量图标继续暂停。
