# R4h 跨殖民地观测联校实施规格 v0.1

2026-10-31，基线`802d436`。A09源码及必要检查完成，未运行游戏。完整字段见[结构化规格](artifact_civilization_r4h_implementation_spec_v0.1.json)。

## 玩家流程

物理T4“跨殖民地观测联校”保留A06＋C03前置，科研费8000、权重65。在已有唯一长基线阵列或相位预警阵列处免费登记基准端；到另一星系的基准观测站/黑门观测站免费登记对照端。每国仅一对、两个指定端点。角色以行星修正显示，重选须先撤销。

两端就绪后，可在任一本国殖民地通过正常决议支付600能源、300消费品、100合金，开始六次有效月度校核。进度页只读，不扣费或推进；项目启动后不追加投入，也不能重入付费。控制/设施/轰炸或研究条件失效时暂停，保留工作量，不补跑停工月份。

完成时，档案永久保留在完成它的国家，清除当前配对和工作量，并弹一次完成通知。档案提供后续A11/A12可读取的资格，同时立即开放地方应用消费者。

## 可重复使用的成果

| 项目 | 首版实现 |
| --- | --- |
| 地方应用 | 在活动普通观测站一次投入300能源、100消费品，持续360日 |
| 现场条件 | 本国控制、原拥有者有效；同星本国正常星港已建E06轨道观测接口 |
| 获得能力 | 普通观测站可作为本地E06基准供源，使该星港获得传感范围+1、超空间探测范围+2 |
| 叠加规则 | 与完整阵列共用原有修正块；同星多个地方端只提供一份支持 |
| 暂停 | 失控、轰炸或观测站失效暂停收益；360日期限继续计算 |
| 结束 | 到期可重新付费；本地转让/消失由原ACS清理移除，国家档案保留 |

已有有效完整阵列或已有应用窗口时，开始应用会被拒绝，避免为同一支持重复投入。A09不发放新的阵列，也不改变唯一限额；原高级阵列的隐形探测仍按原条件判定。档案没有直接的全境传感/科研加成，收益来自真实地方部署。

## 状态与工程接口

新增国家配对/运行/档案三个记录，行星两角色和一个应用窗口；使用按国家索引保存的两个行星目标及一个工作量变量。各端点与地方应用复用`acs_owner@planet`拥有者记录；取消只清理联校角色、端点与工作，不删除物资库存、完成档案或已有地方窗口。

国家月度复用`artifact_civil_supply.1`，新增部分直接查询两处目标。即使两端均不再属于原国家，国家追踪记录仍使清理分支运行；不会因没有自有登记殖民地而卡住。转让/消失或本地角色已被清除时，下次月度撤销未完成联校，不退款。暂时控制变化不等于拥有者变化。

E06基准修正的来源条件增加付费地方端这一替代分支，保持一个修正块，避免多端/完整阵列叠加。没有新on_action订阅、逐日逻辑、全银河扫描或通用新工程框架。

后续A11升级BL02观测站时，须将新阶段接回A09普通观测端/应用窗口资格，避免正常升级令已有校核或付费支持失效。
