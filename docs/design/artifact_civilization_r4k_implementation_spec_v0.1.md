# R4k 星系协同基础设施实施规格 v0.1

2026-10-31，源码基线`13357be`。E11源码和必要检查通过，未操作游戏。字段见[结构化规格](artifact_civilization_r4k_implementation_spec_v0.1.json)。

## 可用能力与正常入口

工程T5“星系协同基础设施”保留E09＋C12前置，科研26000、权重50。首版让B14备料从已有常规联运接收端送到另一星系的施工地，直接接续E09营建或D13试验；没有新建筑或重复工程。

1. 保持原常规接收端及其配给仓、联运站、工程物资集成场有效。B14仍在这里按原费用准备一份真实工程备料：普通库存面额500矿物/100合金，再投入1500矿物/900合金/500能源。
2. 在另一星系有相同三种基础设施的本国施工地，通过正常行星决议免费登记“跨星系工程接收点”。全国同时一处，不占C11常规接收端名额；停用/占领也保留占位。
3. 回到常规接收端，通过“向跨星系施工点交付备料”支付500能源。先验证两端、异星系、库存及余额，再移除始发备料、扣费并立即交付目标。目标条件不依赖刚被移除的源库存；没有目标或费用不足时不扣费、不搬运。
4. 在施工地选择原大型营建/舰体承载决议。备料被实际消费，E09仍是3/4/2有效月度和原后续投入，D13仍为6有效月度；各自研究、设施、国家唯一项目守卫保持。

新端点不能自行准备B14备料，也不能仅凭工程角色接力发运。普通库存不因交付增减；B14全国一份的占位始终跟随实际备料。E11本身不增加巨构并行名额，E09交付场仍按旧规则提供+1。

## 有效性、取消与损失

登记/交付要求本国拥有并控制、无轰炸、设施与研究有效。异星系检查以本国常规接收端为准，同星系其他行星不能代替；其他国家的接收端不影响判定。殖民地枚举返回载体后读取状态，原拥有者沿用ACS。

到货后材料已在当地，不再要求始发站持续在线。施工期间仍要求本地常规接收身份或E11工程接收身份有效；失控、设施停用或身份失效保存已付进度并暂停，恢复后继续，不追补月份、不重复扣费。已运行E09按自己原有运营条件供给容量，可撤回端点；D13完成知识保留原国家。

原拥有者可免费撤销工程端点，即便正被占领或设施已拆除。只清理端点身份，不清库存/工程进度；依赖该身份的在建工程暂停。可以恢复登记继续，未使用的备料也可按B14原规则安全撤回一次，返1600矿物/800合金，运输能源不退。

转让、失去拥有者或毁灭沿ACS清理：端点、当地物资与未完成工程损失，没有新国继承或自动退款。国家知识保留自身归属。

## 接口、来源与运行边界

新增一个当地空状态修正`acs_remote_engineering_receiver`，没有新事件、月度订阅、变量、全局目标或银河扫描。按需查询自有殖民地和目标所在星系；复用原E09/D13的月度及清理。

写前查七都数据库并读中央庭组织与神器研究来源。资源统筹、公共协作与普通工业支撑转译为Mod工程制度；具体运输、收费、端点限制属于设计，不更改来源审核状态。连续巨构视觉原型与正式资产仍暂停。

6项新增、27项相关源码检查及静态通过。覆盖免费唯一登记、异星系与跨国作用域、实付备料一次搬运、原E09/D13实际流程、失败不扣费、暂停恢复、取消/转让/毁灭与一次撤回。原生建造、显示、容量应用和存读档待阶段试玩，不能由夹具代替。阶段试玩仍优先D12，E11可并入必要代表物资链，不单独强制新存读档。

2026-10-31 R4l费用扩展：标准价格保留；有效E12命运都市工业协调在付款时提供营建装配750矿物/1200合金、试运行750能源/225消费品及运输300能源的统筹价。失效恢复标准价，已付不补扣；原物资、名额和工期不变。新条件仅源码检查通过，见[R4l规格](artifact_civilization_r4l_implementation_spec_v0.1.md)。
