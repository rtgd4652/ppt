## 360日应急支援

正常行星决议消耗一份预存备件，提供360日当地支援，不另收费。全国同时一处支援期，暂停期也不能在其他场地刷新。发动需要原拥有者、活跃高阶站、安全控制、F04/E09研究与F02档案；备件已到场后不再依赖原物流设施。

有效高阶站提供当地建筑建造速度修正+25%，原生建筑建造/维修仍走正常队列，不直接修复废墟，不跳过核心工程阶段。它同时成为本地E09已付款阶段的备用物流：配给仓、联运站或B14集成场失效时，只要核心营建场、安全控制及本站仍有效，原月度施工可以继续。

仅准备、装配、试运行中已付款的阶段读取新`artifact_civil_supply_segmented_work_site`，工期仍3/4/2次有效月度、每次只推进一个阶段。新开工/下一阶段付款保留旧接收端与物流条件，等待页不扣费、不自动开下一阶段。进度页使用同一工作资格，备用物流下显示实际工作量，等待页提示恢复常规条件。

完成后的+1巨构容量、E12价位、D13试验与资格保持原规则。C2唯一都市/保护/冷却、旗舰唯一实例与90/75/60日恢复、主线与已结算损失均不改写。

## 失效与清理

失控、轰炸、设施/研究/鉴别档案失效时停止支援，360日时钟继续；恢复后使用剩余时间。到期而原物流仍缺失时，已付工程重新暂停，准确保留当前工作量，无补跑/退款/自动刷新。未使用备件可继续保留，设施恢复后再用。

转让、失去拥有者或毁灭由原ACS清理移除本地备件及窗口。原国家知识和剧情继续保留；已付工程按原转让规则清理。没有新事件、on_action、变量、全局目标或月度订阅，正常决议只按需检查本国名额，施工复用既有月度遍历。
