# AWP-06 专属危机机制方案

## 1. 本次建议

先实现危机底座，并在隔离测试入口完成一个锚点的真实游戏闭环：**预警 → 现场恒定 → 投影战斗与取证 → 弱点解析 → 解除或彻底毁灭 → 归档**。第十一至第十三章的正式剧情入口仍归 AWP-07。

本案把尚未落实的职责、脚本映射、压力限制和轻量测试合并审核，避免继续逐份扩写机制文档。批准范围仅为下述底座和隔离验证；正式舰船、巨构、美术及全银河危机规模不在此次定稿范围。

当前只是提案，未修改 `mod/`、状态登记表或游戏存档，也未把审核状态写成已批准。

| 永久历史 | 每个锚点的结果、真实损失、共享知识在国家账本留存；目标对象只是定位辅助 | 不因对象毁灭、读档或胜利清空损失 |

国家级进度继续使用已登记的 `aemusa_ms_crisis_exclusive_*` 接口，不另造平行进度。新锚点字段在实施时一次性登记；候选目标、旗标和回调都必须携带本锚点身份，防止另一场战斗串入资料。

正式入口仍停在第十章完成页；只有 AWP-07 接入后，玩家才会在正常剧情中进入第十一章。隔离验证可以调用同一底座，但不能补造正式章节完成或终局权限。

单锚点样例只结算该锚点，不写整场专属危机胜利。全局结算接口必须等 AWP-07 提供核心目标处理、停止生成和双钥匙的完整事实后才可调用，不能把样例中的一次解放当作银河危机结束。

## 4. 首个可玩的验证样例

### 宿主与损失

只实现一种容易观察的工程目标：玩家实际控制的非首都星系内，已有普通能源或矿物矿藏的无人天体。这里的宿主是该**资源节点**，天体用于定位。排除殖民地、居住站、考古／异常／特殊剧情目标、稀有与特殊矿藏，以及已处理过的节点。

前兆页先说明异常和未知；确认页再显示目标、时间和可能损失。无合格目标就提示缺口并等待，不凭空生成星球，也不把首都改成教学目标。

若最终彻底毁灭，只移除预先锁定且仍存在的普通矿藏，并记录其真实损失；不清空整颗星球所有矿藏、不摧毁殖民地。若目标先被外部事件改变，重新核对剩余事实，不伪造本危机造成的损失。该节点永久归档，不因后来取得危机胜利而恢复。

这只覆盖“工程与战略目标”中的一例，不冒称人口撤离、通路毁灭或全部宿主类型已经完成。

### 现场行动和两个测试代理

1. **局部恒定代理**：在目标位置发布科研船特殊项目。船必须真实到场完成作业，爱缪莎可用且一次投入实际扣除后，才产生有期限的本地恒定窗口。原型不新增唯一旗舰，也不把爱缪莎改成必须驾驶某种舰船。
2. **投影**：使用独立、无政府、无外交、无普通帝国 AI 的事件势力承载一支测试舰队；使用核实存在的原版常规资源作临时外观，不赋予领袖、人格、宣战台词或最终资产名。该舰队只服务于本锚点，不自动补兵。
3. **现实资料**：现场基线、恒定观测、投影战斗、战后空间勘查分别记录。空间勘查需要实际完成另一项现场项目；清除舰队不能一次填满四类资料。
4. **解析设施代理**：隔离样例把一个现有玩家空间站的可用性接到解析接口。占领／失去控制时停止新增解析，已验证资料保留，恢复后接着累计。代理使用单独目标字段，不冒充正式 `aemusa_ms_megastructure_target`，也不解锁旧塔。空间站控制状态到接口的具体映射须在原型中确认；在此之前只能报告接口模拟结果，不能声称真实巨构占领通过。
5. **解除**：资料和弱点齐备、投影已清除、恒定窗口有效后，先完成现实工程作业；随后独立检查爱缪莎状态并进行未来重开。两项都成立才写解放。设施存在、清怪或点开窗口均不能单独结算。

失去科研船、舰队、解析站或爱缪莎暂不可用时，显示可恢复的缺口；可以替换普通船、恢复设施或等角色恢复后继续，已有资料不重置。危机的公开局部压力仍按当前状态运行。

两个代理只用于验证职责与真实行动的连接，不确定正式恒定载体或巨构的名称、建造机制和外观。

## 5. 暂用参数和压力限制

以下仅为隔离样例的可调参数，批准本案不把它们锁成正式终局平衡。

| 项目 | 首轮值／规则 |
| --- | --- |
| 同时验证的锚点 | 1 个；一支投影舰队，不自动补兵、不链式扩张 |
| 正式形成前预警 | 90 游戏日；可在充分提示后提前开始，读档不重新计时 |
| 现场恒定 | 30 天科研船项目；200 能量、100 矿物；完成后窗口持续 180 天 |
| 窗口补充 | 到场重新完成同一职责作业并支付投入；最多补至 180 天，不叠加为永久有效 |
| 战后空间勘查／现实解除工程 | 各 30 天现场项目，分别记录其实际完成 |
| 弱点解析 | 四类资料齐备后累计 3 次设施可用的月结；不可用月份不增加进度 |
| 失控压力 | 形成后每个无恒定窗口的月结增加 1，达到 12 时彻底毁灭；有效窗口只暂停增加，不清零历史压力 |
| 结算 | 只有“解放”或“彻底毁灭”；各执行一次，之后停止该锚点生成与计时 |

投影的测试舰数与武器仅服务于完成一次真实战斗，实施时从已验证的原版设计选取并在测试记录列明；本案不确定正式难度缩放。多锚点网络和后续危机压力由 AWP-07 接入时另按现有剧情安排，不为样例添加无限生成系统。

## 6. 检测和存档处理

采用“实际作业回报 + 每月一次的活动锚点核对”。不扫描全银河全部舰船，也不追踪最后一击或精确伤害贡献。战斗回调提供事实，月度核对只检查本锚点已生成且仍绑定的投影；撤退、暂时失联或只有保存目标失效均不直接认定清除。

预警起点、恒定窗口、压力和解析进度随存档保存。重开窗口只能显示状态，不重新扣费、延长预警或发放项目。锚点归档后先关闭生成和计时，再清理其临时对象；不会通过清理投影反过来补记胜利。

永久资料与损失写入路线国家。原国家自然败亡时不移交主线；普通锚点失败只保留当地代价，不写全局不可逆失败。旧档仅凭可证实的第十章完成等前置进入准备，不自动取得锚点、解析、战果或最终决定。

## 8. 实施顺序与轻量验收

批准后分两步完成，不一次写第十一至第十三章：

1. **底座**：登记必要的新状态，加入危机／锚点只读条件和唯一写入接口、费用与计时、资料暂停／恢复、双结果与损失账本。正式白夜馆入口保持第十章完成页。
2. **隔离样例**：在新的 AWP-06 工具目录中建立可撤下的入口、现场项目、投影和代理适配；从已完成第十章的测试档分支验证，保护 `2217.01.30.sav` 及更早基线。

必要验证压缩为：一次正常锚点闭环，在处理中保存并载回一次；复用同一前置副本做一次超时损失检查；解析暂停／恢复只检查一次。其他并发、全宿主、全难度和全选择不作本包门槛。工具检查只针对新增不可逆写入和进度保护；已有 52 项与旧游戏证据直接复用，不例行重做。

如果使用控制台或代理输入建立场景，记录其来源；接口模拟不能代替真实舰队、项目完成或设施占领的证据。发现主线卡死才扩大检查。

预期修改位置：`mod/common/scripted_triggers/`、`mod/common/scripted_effects/`、状态 CSV、必要的中文提示；隔离入口及投影配置位于 `tools/prototypes/awp06/`。正式地图资产和第十一至第十三章窗口不在此次交付范围。
