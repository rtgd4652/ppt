# 爱缪莎专属终局天灾联合设计 v1.0

## 1. 文档职责

本文承接已批准的 `AMR-010`、`AMR-011` 与爱缪莎主线总纲，用于在同一处联合审核专属终局天灾的：

1. 身份、来源与动机。
2. 主体性和知识边界。
3. 征兆、展开与信息揭示顺序。
4. 与命运修正规律及其他开放宇宙论问题的证据关系。
5. 视觉、声音、舰队、地图和 UI 表现需求。
6. 爱缪莎、专属舰船、专属巨构、中央庭、盟友与玩家文明的职责。

本文不是机制文档，不包含事件 ID、国家类型、舰队配置、生成逻辑、数值、奖励或 Stellaris 脚本。只有全部联合设计项经人工批准，本文状态改为 `approved_for_mechanic_design` 后，才能进入机制、美术和实现。

## 2. 已锁定的上游约束

- 危机顺序固定为：常规扩张 → 失落帝国战争 → 玩家选择并完成一种原版终局天灾 → 专属终局天灾。
- 原版天灾完成后，爱缪莎进入更强的局部命运干涉阶段，并解锁专属舰船与专属巨构。
- 爱缪莎在完整成功路线中不可替代，但不能独自取胜。
- 文明的科研、制度、外交、盟友、舰队和现实行动同样不可替代。
- 命运没有意志；它是修正“不和谐”、阻止个体或集体超脱既有命运约束的运行规律。
- 专属天灾不能是“命运本人”、命运化身或奉命行动的傀儡。
- 失落帝国和四种原版天灾保留自身动机，不能被追认成专属天灾的棋子。
- 专属天灾不能一次解释黑门、神器、箱庭、世界之主、世界重构和银河命运的全部关系。
- 塔罗、星月和牌面属于爱缪莎个人表达，不自动属于敌方视觉。
- 旧 Stage 9 舰船、旧“命运之主”命名和已废弃命运观测塔不能充当正式方案。
- 完整命运主宰权只在第五阶段全部剧情结束后的最终沟通、玩家授权和爱缪莎自主接受之后成立；它不参与天灾解题。

## 4. JCR-001：专属天灾身份架构

### 4.1 审核问题

专属天灾首先必须回答“它是什么类型的存在”，但当前不确定正式名称、外观、舰队、机制或最终真相。

无论选择哪种方案，都必须满足：

- 它不是命运人格。
- 它不是爱缪莎的黑暗镜像。
- 它不是四种原版天灾的共同幕后黑手。
- 它不是单纯数值更高的普通帝国舰队。
- 它具有足以支撑调查、冲突和终局选择的独立身份。

### 4.2 方案 A：试图转嫁必然终点的遗民文明（推荐）

一个古老文明确认自身的未来已被某种因果约束收敛为不可避免的灭亡。它没有获得命运主宰权，而是发展出一种有限工程：把“已经封闭的终点”转移给其他文明，并以夺取他者仍然开放的未来延长自身。

身份边界：

- 它是具有历史、制度、内部成员和自主选择的文明主体。
- 它利用命运修正规律，但不创造、代表或服从命运规律。
- 它只能转移、压缩或封闭局部可能性，不能自由决定全部未来。
- 它的行为会触发或放大非人格化命运修正，但命运没有向它下令。

与原版天灾的区别：

- 不以吞食与繁殖为目标。
- 不从异次元入侵以获取能量。
- 不执行预防性机械灭绝协议。
- 不以消除痛苦为理由取消主体。
- 核心冲突是“一个文明能否把自己的必然终点强加给所有仍有选择的人”。

优势：

- 能保留敌方主体性、对话、调查与伦理冲突。
- 能直接检验爱缪莎“保留他者选择”而非“选中唯一未来”的成长。
- 允许舰队、设施、边界现象和文明内部证据共同出现，而不把天灾退化为抽象天气。

风险：

- 必须防止把敌方写成已经掌握完整命运权力。
- 必须说明它为什么只能转嫁终点、为什么仍需现实舰队和工程。
- 必须避免把“遗民”处理成索林原虫式逃亡者的重复。

### 4.3 方案 B：无主体的因果坍缩现象

专属天灾是一种在大规模命运干涉后出现的自然规则失稳：可选择未来不断坍缩，星系被锁入单一结果，没有能够对话的中心主体。

优势：

- 最直接体现命运是无意志规律。
- 不会产生“命运派出敌人”的误读。

风险：

- 缺少独立主体、历史和动机，难以满足联合设计对身份与主体性的要求。
- 容易只剩抽象进度条、异常区和规则灾害。
- 舰队与战斗表现可能被迫临时附会。

### 4.4 方案 C：为维持因果稳定而失控的古代维护系统

一个由未知古代文明建立的维护系统，把任何可能超脱既有因果约束的文明识别为不稳定源，并通过舰队和设施执行封闭。

优势：

- 容易形成明确工程结构、舰队和阶段目标。
- 能区分系统程序与命运规律本身。

风险：

- 与肃正协议的远古安全程序和预防性灭绝主题过于接近。
- 容易把最终冲突缩减成关闭更古老、更强的机器。
- 会过早逼近未知前驱者和宇宙维护者设定。

### 4.5 方案 D：遭受未来封闭后向银河迁徙的外部群体

一个来自银河之外或世界边界之外的群体失去自身未来，为寻找仍有开放可能性的区域进入银河，并在迁徙中造成危机。

优势：

- 能保留受害者与加害者并存的复杂性。
- 可提供世界边界证据。

风险：

- 与索林原虫“逃离更大威胁并侵入银河”的结构接近。
- 容易把命运修正规律外化成另一个未露面的猎手。
- 对银河、箱庭和外部空间层级提出过多尚未批准的事实。

### 4.6 当前建议

建议批准方案 A 作为身份架构，并只锁定以下最低事实：

1. 专属天灾是具有主体性的古老遗民文明。
2. 它认为自身必然终点已经无法在现有规则内避免。
3. 它以有限工程把封闭终点转嫁给其他文明，夺取对方仍开放的未来。
4. 它利用并放大命运修正，但不是命运化身，也没有完整命运主宰权。
5. 正式名称、起源地点、文明形态、内部结构、具体动机、视觉与机制继续由后续审核决定。

该方案让专属天灾拥有自身选择和责任，同时把“命运没有意志”保留为硬边界。它也使最终胜利不能只靠击毁舰队：文明必须阻止转嫁工程，爱缪莎则需要在共同授权下重新打开被封闭的局部可能性。

## 5. 当前实现闸门

在 `JCR-001` 获得人工决定前：

- 不为天灾命名。
- 不确定其舰种、国家、地图或 UI 表现。
- 不制作概念图。
- 不编写机制、事件或脚本。
- 不用旧舰船、旧巨构和现有资产填补空位。
