2026-10-17。源码已接入，静态与3项定向条件检查通过；代表正常路径、矿站升级及一次关键读档通过，其他分支与平衡未验。本包补生产路线，保持公共／个人研究分离，人物组合、图标与连续巨构暂停。当前公共28项科技／23个建筑定义，完整目标72项科技／27类46阶段建筑不变。

## 玩家路线

共鸣材料筛选（B07）→精准矿脉测绘（B10）→建设矿脉测绘站。当地须已有普通采矿区，设施占普通城市建筑槽。取得原相位矿脉采掘（B04）后可正常升级为原相位矿脉稳定站；已有高级站不必补研或重建低级站。

B10＋殖民地公共服务（C07）→副产物闭环利用（B12）→建设循环回收处理厂。当地有普通采矿区或有效矿脉／基础制造设施时，回收技师以能源和耗材投入回收矿物与少量合金。回收厂不能以自身作为来源，没有工程退款或无成本结算。

失去全部合格来源后，回收厂停岗，4能源建筑维护继续支付；有效来源恢复后恢复岗位。有效建筑使用has_active_building排除停用或损坏状态，普通采矿区使用has_district。没有新增事件、日扫、库存缓存或全局废料资源。

## 原矿站岗位迁移

本机4.5.2原版b1_jobs为200。当前旧矿站却只提供8单位劳动力容量，若直接衔接新200单位低级站，升级会丢失容量。因此仅将building_artifact_phase_mine的job_artifact_phase_miner_add从8改为800，并增加can_build=yes保留原科技直建。

**这会将当前4.5旧矿站容量扩大100倍，影响实际总产出及岗位维护，不是显示修正。** 原科技、2400矿物／500合金、600日、20能源建筑维护，以及相位矿工每100单位36矿物／3工程和3能源岗位维护保持。旧存档不强制补造低级站、不补科技或发资源，由原生重新分配就业；运行已确认高级站容量800、实际就业652，平衡仍待核对。R1与其他旧建筑的岗位容量另列后续，不在本包顺带修改。

新建普通测绘站要求district_mining；高级站保留原有资格，不追加B10或采矿区门槛。两级均保留resource集合，普通城市区划带未排除它；不改变原高级设施的放置集合。升级排他在allow，不把在建高级站条件放进potential。
