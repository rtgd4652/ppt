## 交付范围

复用原三名人物的唯一旗标、招募与通讯。每人只有一个国家任务账本；独立于爱缪莎章节、方舟和研判。旧人物主动进入通讯或随月度回调接入，不重新创建或改名。新招募记录终身接入事实，离世、解雇后不自动重新招募。

白夜馆 → 对应角色通讯 → “开展本人的专属任务”。首版目标限本国殖民地或角色实际带领的普通军用舰队。友军多目标、全银河搜索、精确最后一击不在本批范围。

## 人物与目标边界

- 赛斯保持圣星教会神官与中央庭协作者身份，不称“白夜馆神官”。行政官／指挥官切换使用原生解除任职与同实体转职；国家任务、进度、消耗和休整不变。指挥官现场路径须本人带队处于目标殖民地星系；行政官可通过白夜馆协调公共支援。
- 请求优先取本人管辖殖民地，再取实际低稳定度或遭轰炸的殖民地，最后取本国可控殖民地的日常服务请求。没有虚构灾难前置或未发生的求救信号。
- 仓促按字面补给花100能源、50消费品，短暂90日舒适度+10；一次月度工作后形成180日稳定度-3的调配失误，占用同一任务名额。补核200能源可清除；退出不退物资，影响按原期限结束。
- 公共执行期间目标正在遭轰炸，进入同队列的有限应急避难：35日轰炸伤害-15%、舒适度+3，暂停公共执行进度。轰炸结束后原计划继续。占领暂停工作，丢失所有权或人物离开结束，不复活殖民地、人口或领袖。
- 幽桐首版的保护对象和作业舰队为同一实际指挥舰队；当前星系构成射界。离开星系、解除指挥或失控，撤去支援并清零校准；仍有效的原任务须返回并重新校准。换目标或原则先退出，不刷新独立恢复期。
- 拉比首版保护实际指挥的舰队。阿米特是共同承担保护的守护者，不建立第二领袖或独立船体。国家指挥安排、初次保护确认和当次反击确认分开记录；拒绝不撤销已有保护约定。
- 幽桐的越界和拉比的威胁登记均使用原版 `on_fleet_combat_joined_attacker/defender` 的真实参战舰队及对手，不用单纯外交敌对或其他战争代替。变更指挥、目标失效或交战结束时清理专属支援；国家恢复期保留。舰队合并、拆分不创建新实例或新使用次数。
