# R2f 行星环境缓冲

2026-10-18，基线`481f53b`。只接E07与BL25一阶段，沿用已批准的公共路线；人物组合、个人研究、批量图标及连续巨构原型保持原边界。源码和运行证据分开记录。

## 能力与边界

文明可在具有危险天气、弱磁场或辐照的殖民地建设环境缓冲站，以持续维护减轻当地部分惩罚。它提供局部安全条件，不清除原始风险、不改行星类型、不增加宜居星球、不自动升级盖亚；也不处理太空风暴、轰炸、天灾、任意事件负面修正或其他Mod的同类环境。

一座设施同时识别当地存在的三种来源，每种最多计算一次。没有白名单来源不能新建；来源消失后对应缓冲自动停止，设施保留并继续原生维护，玩家可以正常停用或拆除。没有新的计时器、月度扫描、决议或永久福利标记。

## 失效、维护与兼容

原生建筑条件修正在来源存在、建筑活跃、所有者实际控制、所有者具备E07及公共神器文明身份时生效。停用、损毁、占领或失去研究／身份资格则停止；恢复条件后自动继续，不重收费、不补过去收益。设施转让后只按新所有者当前资格重新判断，没有国家知识或剧情进度可继承。

维护走原生建筑经济；不再手动扣费。资源赤字按原生短缺系统处理，不承诺资源刚为零时自动关站。轰炸不作为额外环境来源，也不新增减伤；建筑在轰炸中仍活跃且本国控制时可继续原有环境缓冲。

只新增科技、建筑、本地化三个Mod文件，不覆盖原版风险，不新增回调，不修改旧R1/R2路径。4.5.2引擎证据不能冒称完整4.5.1兼容验证。
