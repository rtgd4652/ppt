# 神器文明科技名称、文案与注释规范 v0.1

更新：2026-10-31。适用于公共文明科技及其直接关联的设施、岗位、军备说明。用户要求同时整理名称、文案和注释，并明确提醒使用七都数据库。个人专属研究继续独立。

## 先读来源，再写文案

1. 用[七都数据库](../../knowledge/database/README.md)定位术语、来源和审核状态。SQLite只读查询，数据库只是索引。
2. 打开指向的JSON、Markdown或角色资料，辨明原作事实、项目解释和Mod设计；保留`under_review`等原状态。
3. 查看科技定义及其建筑、部件、岗位、决议消费者，核实玩家真正获得的能力、费用和门槛。
4. 写名称、设定段、应用段和源码注释，在[逐项文案目录](artifact_technology_text_catalog_v0.1.json)登记来源组与实现文件。
5. 做必要的本地化和静态检查。纯文字润色不增加游戏启动、逐窗存档或旧流程复测。

这次初稿先读了实现而遗漏七都来源，用户指出后才补查。下次应从第一步开始；有历史记忆或熟悉角色，不能代替来源核对。缺少依据时缩小表述，不自行补完谜团或修改知识库审核状态。

## 写法与边界

名称优先表达独特对象和技术用途。保留塔罗、七日、交界、中央庭等有来源的语言；避免仅以“接口、协议、公共、终局”充当玩家名称，也不为了通俗而把整棵树写成通用科幻。

卡面采用两段：第一段写工程改变了什么、为何具有这套文明的历史背景；第二段以“应用”说明已有玩法。实际数值尽量由原生效果栏和对应项目提示承担，卡面交代关键门槛与取舍。

源码注释记录作用域、真实消费者、状态与兼容边界，解释为何这样接入。内部编号、测试口径和失效条件不塞进叙事段。科技键、前置、费用、数值、资源名和存档标记保持原样。

| 概念 | 本次采用的写法 |
| --- | --- |
| 神器与制造 | 标准化的是材料、构件、仪器与适用工艺；神器仍与特定人类个体共鸣。工坊和小型文物岗位不等于量产神器 |
| 幻力、黑核与能源 | 保留不同概念。相位供能、共鸣精炼是Mod工程设计，不把幻力或黑核直接定义为能源点及三种稀有资源 |
| 塔罗与公共研究 | 从爱缪莎案例提炼可检验的方法；公共研究不复制预言能力，不增加个人等级或主线转变门槛 |
| 七日与记忆 | 写留存档案、幸存者记述与持续积累；不用“保存每一次轮回”暗示完整记忆已经恢复 |
| 共鸣与终解军备 | 表达公共装备与协作阶段；神器使仍是人类，部队编制不把人写成可量产武器 |
| 规则锚定 | 对特定场地部署有条件、有期限的工程效果，不等于掌握宇宙规则或个人命运主宰权 |
| 白夜馆 | 应用段可以提示玩家从这里进入功能；设定段不让白夜馆充当组织、研究机构或剧情行动者 |

## 完整示例

**塔罗演算**

爱缪莎的塔罗与计算能力为异常研究提供了独特案例。研究者记录牌阵、判断条件与实际结果，尝试提炼可由仪器和实验检验的分析方法。

应用：提高异常现象研究速度，为黑门观测与中央庭调度研究奠定基础。

源码注释：共有计算分支入口；只提供异常研究速度，不检查个人等级。塔罗案例转译为研究方法，不复制爱缪莎预言或主线命运权限。

**记忆档案编目**

七日轮回结束后，保存下来的档案与幸存者的记述终于能够持续积累。编目工作标明来源、分歧和缺页，让后来者知道哪些经验可以依循，哪些仍待查证。

应用：解锁记忆档案室；取得七日后勤网络后可升级为中央庭记忆宫。

源码注释：解锁记忆档案室并衔接高级记忆宫；文案只指留存档案与个人记述，不承诺恢复所有轮回记忆。
