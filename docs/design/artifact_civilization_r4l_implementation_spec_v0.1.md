不新增预算项目、收费步骤或状态。取消工业协调、换为科研/民生、失控、轰炸或设施/研究失效后，国家统筹立即失效。原C12地方收益及额外岗位矿物维护保持自身规则。

## 都市与生命周期边界

原C2都市改造文件未改，国家永久记录`aemod_has_special_planet`及“已有本国命运都市”仍阻止重复改造。E12不改造行星、不写入/清除历史标记、不重置个人或主线冷却。旧档已有都市但缺历史标记可提供真实预算，原C2按实际星球类仍禁止第二颗。

预算读取既有ACS原拥有者。都市转让后原国家失去来源，新拥有者不会继承前任工业协调；原转让清理保持。之后若新国合法重建自己的公共方案，仍受实际研究、场地与旧都市规则约束。

国家资格仅按需枚举自有殖民地并返回载体；没有新事件、月度订阅、变量、旗标、修正或额外全国产出加成。相关提示同时列明标准/统筹价和付款时核定，不伪造固定折扣的锁价承诺。
