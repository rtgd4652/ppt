# R4d 终解舰体承载

2026-10-31，基线 `262b8be`。用户要求继续开发，按既有D13责任表落实承载基础。源码与必要检查通过，游戏运行待阶段试玩；E10公共战略舰体、D12场域及D14联合防务分别后续实现。

## 七都来源与实现参考

写前只读查询七都数据库中的 `TERM-ARTIFACT`、`TERM-ARTIFACT-SCIENCE`、`TERM-CENTRAL-COURT`，并阅读[核心术语源](../../tools/knowledge/data/core_terms_v0.1.json)、[神器体系](../../knowledge/artifacts/artifact_bible_v0.1.md)和[组织体系](../../knowledge/organizations/organization_bible_v0.1.md)。器物共鸣不等于可量产神器；普通工程为研究提供仪器、材料和安全环境。“终解舰体承载”是Mod公共军备阶段的工程设计，不作为原作新增事实，来源的 `under_review`／`project_defined` 状态不变。

实现参考复用[大型物种包](artifact_species_pack_mod_reference_2026-10-31.md)的技术—设施—装备衔接，以及[晨曦减伤](artifact_dawn_ship_survival_mod_reference_2026-10-31.md)和本机原版的原生减伤字段。没有引入瞬间复活、特殊资源或新的战斗扫描。

## 玩家流程与交付

1. 正常研究D13，保留前置D03＋B14。工程T5／宇航技术，24000科研，权重60。
2. 在有效的工程物资集成场，通过行星决议“舰体承载试验”交付一份B14备料。复用原接收端、配给仓和联运站；不增加新建筑或重复收取材料。
3. 完成6次有效月度后，自动归档永久国家记录“舰体承载定型”。只做这一轮联试，不分段追加支付。可通过只读决议查看进度。
4. 在原生设计器选用新件，再正常付费造舰或改装。当前适配护卫舰、雷击舰、驱逐舰、巡洋舰和战列舰；不发放免费舰，不解锁E10舰体或个人能力。

反应堆／推进器／航道引擎分别要求D13＋D16／D17／D18，并同时要求定型记录；缓冲器要求D13＋定型记录。新件显式限制上述常规舰型；后续E10须按其规格另接部件，不能默认继承。原有组件、设计和主线旗舰不变。

## 状态与清理

- `acs_hull_project`与`acs_hull_work`记录当地在建试验及有效月份，全国同时一项。暂停试验仍占位，不能在另一个殖民地重复交付。
- `artifact_civil_supply_can_hull_start`同一守卫块核对D13、场所、全国名额和实付备料；随后调用原消费接口并启动。消费无成功返回值，不以“调用过”作为付款凭证。
- 沿用物资月度入口，占领、轰炸、停用、撤销接收端或研究失效时暂停；进度和已付材料保留，不追补停工月份。
- 未完成前撤销不退款，保留其他普通库存及新备料；转让、失去拥有者或毁灭沿用既有回调／月度补检清理，接收国不继承进度。
- 完成后 `acs_hull_qualified` 是原国家的永久无数值修正，只作为新组件装配资格。设施失效或所在地丢失不撤销已有知识；当地清理不把该资格转送新国。
- 国家定型结果不授予D16／D17／D18，也不提供全国舰船增益。三条分支缺哪项研究，对应新件就仍锁定。
