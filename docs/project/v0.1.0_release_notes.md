# 《神器使》Stellaris Mod v0.1.0 发布说明

> 当前状态：候选稿，游戏内复测通过后转为正式发布说明。

## 版本定位

v0.1.0 是项目的第一个稳定基线，重点是让神器使文明、白夜馆首批角色和第一版专属内容形成可继续扩展的闭环。

## 主要内容

- 神器使物种、肖像、特质、起源、专属星球和预设帝国。
- 白夜馆招募、联络、档案展示与管理入口。
- 爱缪莎、赛斯、幽桐、拉比四名可招募领袖。
- 专属飞升、传统、科技、建筑、岗位和区划。
- 专属星球防重复生成。
- 命运观测塔四阶段脚本和政策模式。
- 命运之主基础舰体、模型、核心组件、双光环、跃迁核心与重构事件。
- 七名角色知识库及世界观基础文档。

## 兼容性

- 目标版本：Stellaris 4.4.3。
- `supported_version`：`4.4.*`。
- 建议新开局并只启用本 Mod 进行首次体验。

## 当前限制

- 命运之主武器槽暂时关闭，等待模型具备正式武器 locator。
- 命运观测塔尚无正式三维阶段模型。
- 41 个正式图标等待统一美术风格后制作。
- 安托涅瓦、晏华和格蕾莎将在后续版本进入游戏。

## 白夜馆说明

白夜馆是神器使招募、联络、档案展示与管理的功能入口。它不是中央庭下属组织、独立势力或银河外交实体。

## 下一版本

v0.2 将围绕中央庭核心人物展开：安托涅瓦作为核心领袖，晏华和爱缪莎分别承担战略判断与未来观测辅助定位。
