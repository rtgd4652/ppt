# v0.1 Release Notes

## 1. 版本定位

v0.1 是《神器使》Stellaris Mod 的第一个可玩版本。

本版本的核心目标是完成「神器使文明基础系统 + 白夜馆招募系统」的可玩闭环。玩家可以以神器使文明进入游戏，通过白夜馆接触首批神器使，并体验基础的领袖、飞升、传统、科技与区划体系。

v0.1 的重点是建立稳定底座，而不是一次性完成全部大型剧情、终局系统和美术资源。

## 2. 已完成系统

### 白夜馆入口法令

已完成游戏内入口。玩家可以通过法令打开白夜馆系统，进入后续通讯、名册和回忆页面。

### 白夜馆主界面

已完成白夜馆统一主界面，用作神器使招募、通讯和后续剧情入口的基础框架。

### 通讯 / 名册 / 回忆分类

已建立三类基础入口：

- 通讯：联系已接入神器使。
- 名册：查看和招募首批神器使。
- 回忆：作为后续回放、剧情记录和人物故事入口。

### 首批神器使招募系统

已完成首批神器使的基础招募流程，包括招募状态识别、重复招募防护和通讯入口。

### 爱缪莎接入

爱缪莎已作为核心角色接入，具备基础招募、通讯、职业方向和 30 级成长节点设计。

### 赛斯接入

赛斯已作为白夜馆成员接入，当前定位为行政官，并具备专属 trait 与基础通讯内容。

### 幽桐接入

幽桐已作为白夜馆成员接入，当前定位为指挥官，并具备专属 trait 与基础通讯内容。

### 拉比接入

拉比已作为白夜馆成员接入，当前定位为指挥官，并具备专属 trait 与基础通讯内容。

### 神器使领袖体系

已完成唯一领袖创建、身份标记、事件目标保存、专属 trait 挂载和白夜馆识别逻辑。

### 神器使等级上限 30

已完成神器使领袖等级上限 30 的基础设定，并保留用于测试的快速升级路径。

### 神器使等级成长 trait

已完成首批神器使专属 trait 的等级成长方向，使领袖成长与文明玩法产生关联。

### 神器使专属飞升

已完成神器使专属飞升的基础框架，包括物种线飞升与爱缪莎个人线入口方向。

### 神器使专属传统

已完成神器使专属传统类别与传统树基础内容。

### 神器使科技线

已完成神器使科技线基础内容，覆盖塔罗演算、黑门观测、中央庭协议、命运都市等方向。

### 神器使专属星球区划

已完成神器使专属星球与区划基础内容，用于承载文明经济、科研、舰队和后续都市系统。

### 角色知识库流水线

## 3. 当前限制

以下内容暂不属于 v0.1：

- 爱缪莎完整成神路线。
- 爱缪莎唯一舰船。
- 爱缪莎专属巨构。
- 爱缪莎五阶段命运飞升。
- 专属考古故事。
- 全神器使剧情。
- 完整银河剧情。

这些内容进入后续版本路线图，不在 v0.1 内继续扩展。

## 4. 已知问题

以下事项当前未完全解决，但不影响 v0.1 的核心游玩闭环：

- 部分自定义图标仍使用原版占位图标。
- 部分岗位、巨构和修正符图标仍未补齐。
- 命运之主舰船武器槽因模型炮位 locator 缺失暂时关闭。
- 命运之主完整战斗、复活、升级和平衡链不纳入 v0.1。
- 命运观测塔巨构保留基础脚本，正式模型、美术和多阶段外观后续补充。
- 白夜馆回忆系统当前为基础入口，完整回忆链和剧情回放后续扩展。
- 角色通讯文本、界面美术和图标风格仍需在后续版本统一。
