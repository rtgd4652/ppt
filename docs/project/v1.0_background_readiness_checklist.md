# 《神器使》Stellaris Mod 1.0 背景准备验收清单

## 1. 文档用途

本文只判断 1.0 的世界观、角色资料和主线叙事基础是否足以进入后续设计，不代表游戏内容已经实现，也不授权编写事件、危机、舰船、巨构或数值脚本。

状态含义：

| 状态 | 含义 |
| --- | --- |
| `完成` | 已有正式文档与可追溯结论，足以约束后续设计 |
| `部分完成` | 主体可用，但存在必须补齐的资料或连续性缺口 |
| `开放` | 项目有意保留未知，不应为了“完成度”自行补写 |
| `未开始` | 尚未形成可审核成果 |

## 2. 总体结论

1.0 的**文明背景、宇宙论边界、爱缪莎主线结构、专属终局天灾叙事职责和命运主宰能力边界已经完成**，可以作为后续设计的正式约束。

当前背景准备尚未完全封闭，剩余两个实际阻塞点是：

1. 雯梓已完成自动采集、Mod Ready 与标准档案草案，但尚未完成人工事实校订和档案批准。
2. 丽已锁定为第十名，但尚未建立独立角色采集、Mod Ready 与标准档案链。

除此之外，部分原作分支入口、精确年代、制度名称和宇宙本体机制属于非阻塞开放项。它们不得被误写为已经确认，但不需要为了开始 1.0 设计而强行填满。

## 4. 已锁定的 1.0 背景结论

以下内容不得在后续设计中反复改写：

1. 七日轮回已经结束，人类重新获得连续历史。
2. 人类没有在灾难中毁灭，而是通过重建、制度和科学进入星际时代。
3. 中央庭是灾后人类文明治理核心；安托涅瓦是核心领袖，但中央庭不是个人政权。
4. 神器是人类独有的现实异常现象；神器科学属于科学体系，但人类尚未理解其本质。
5. 白夜馆只是招募、联络、档案和管理入口，不是世界观组织。
6. 人类在 Stellaris 开局时仍是年轻星际文明，不是银河霸主或天选文明。
7. 命运没有意志；所谓修正是非人格化因果规律的收敛反馈。
8. 失落帝国战争固定发生在玩家选择的原版天灾之前。
9. 玩家从四种原版天灾中选择一种，每局只发生一次；完成后爱缪莎进入更强的主动命运干涉阶段。
10. 专属终局天灾是旧七日轮回中反复兑现的毁灭结果形成的因果吸引子，不是命运人格或外交主体。
11. 战胜专属危机后，爱缪莎才首先确认当前世界与旧轮回世界并非同一世界，并确认指挥使／玩家跨世界连续。
12. 只有在主线第五阶段结束后的最终沟通中，玩家明确授权且爱缪莎自主接受，她才成为命运主宰。

## 6. 非阻塞开放项

下列问题可以留给未来剧情或需要时再设计：

- 七日轮回、世界重构和世界更替的完整本体机制。
- 黑门、异界、神器、箱庭与命运是否共享更深根源。
- 世界之主的完整权限来源和埃索林当前管理状态。
- 指挥使／玩家跨世界连续的精确机制。
- 中央庭精确宪制名称、选举或继任程序及部门全表。
- 灾后重建与星际突破的精确公历年份。
- 专属危机、旗舰和巨构的正式名称、造型、数值与最终游戏表现。

开放项必须继续登记和分层，不得因为它们尚未解答就用角色推测、旧原型或玩法需求反推宇宙事实。

## 7. 后续执行闸门

背景准备的下一顺序固定为：

1. 完成雯梓资料闭环。
2. 完成丽的独立资料与最低时间连续性闭环。
3. 完成十人时间连续性终审。
4. 形成一次背景准备终审记录，把本文状态从 `active` 改为 `background_ready`。
5. 再进入十人职业与单一核心机制审核，以及爱缪莎主线的事件／危机实现设计。

在第 4 步完成前，不扩大新角色名单，不新增第二条大型个人主线，不用隔离技术原型反向决定正式世界观、美术或资产名称。
