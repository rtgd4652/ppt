# v0.1.0 封版说明

> 冻结日期：2026-07-11
> 冻结分支：`parallel/v1-integration`
> 计划标签：`v0.1.0`

## 1. 封版结论

v0.1.0 已进入功能冻结和复测阶段。

从本文件生效起，不再向 v0.1.0 增加角色、剧情、舰船武器槽、巨构模型或正式图标。只允许修复会影响加载、存档、核心功能与本地化识别的问题。

当前代码已完成静态修复，但仍需新开局手动复测。因此本版本现在是“封版候选”，不是已发布版本。

## 2. 冻结范围

### 保留

- 神器使物种、肖像、特质、起源、专属星球和预设帝国。
- 白夜馆功能入口。
- 爱缪莎、赛斯、幽桐、拉比四名领袖。
- 唯一招募、职业、专属 trait 与等级上限 30。
- 第一版飞升、传统、科技、建筑、岗位和区划。
- 专属星球防重复生成逻辑。
- 命运观测塔四阶段脚本与政策模式。
- 命运之主舰体、核心组件、双光环、跃迁核心、模型和重构事件。

### 降级保留

- 命运之主武器槽暂时关闭，直到模型具备正式 locator。
- 命运之主重构设计只强制装配核心、防护、辅助和光环组件。
- 缺失图标保留为已知美术问题，等待统一风格后集中制作。
- 命运观测塔继续使用脚本阶段，正式三维阶段模型延后。

### 不纳入

- 安托涅瓦、晏华、格蕾莎的游戏内实装。
- 完整七日轮回、考古链和主线剧情。
- 爱缪莎完整成神路线。
- 命运之主完整武器系统和最终平衡。
- 命运观测塔正式模型、动画和 LOD。
- 正式图标包与完整美术规范。

## 3. 已完成的封版修复

- 版本号改为 `0.1.0`。
- 两处 `trade_value` 改为 `trade`。
- `aemusa_generated_icons.gfx` 已移除 BOM。
- 命运之主使用泰坦舰名与舰级名作为名称表兼容回退。
- 非本地化脚本基础 BOM 检查通过。
- Stellaris 脚本基础括号检查通过。
- 显式 `texturefile` 路径检查通过。

## 4. 已知非阻断事项

- 15 个岗位图标缺失。
- 15 个岗位修正图标缺失。
- 7 个 trait 图标缺失。
- 4 个命运观测塔 outliner 图标缺失。
- 命运之主没有正式武器 locator。
- 命运观测塔没有正式三维阶段模型。
- 角色与物种肖像裁切需在候选构建中再次目视确认。

## 5. 发布门槛

只有满足以下条件才能合并到 `main` 并创建 `v0.1.0` 标签：

1. `reports/v0.1_manual_test_checklist.md` 的十二项全部完成。
2. 专属星球防重复专项复测完成。
3. 命运之主与命运观测塔专项复测完成。
4. 最新 `error.log` 没有本 Mod 的脚本解析、无效对象、事件崩溃或缺失必需组件错误。
5. 缺失图标仅作为已知美术警告存在，没有引起界面或游戏崩溃。
6. 测试结果已回写 `reports/v0.1_test_report.md`。

## 6. Git 发布流程

1. 在 `parallel/v1-integration` 整理中文提交。
2. 推送封版候选分支供测试使用。
3. 游戏内复测通过后切换到 `main`。
4. 执行快进合并，不创建额外合并提交。
5. 创建带中文说明的附注标签 `v0.1.0`。
6. 推送 `main` 和 `v0.1.0`。

若复测失败，修复仍在集成分支进行，不提前合并或打标签。
