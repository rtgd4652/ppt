# 知识重建工作线 v0.1

> 工作分支：`knowledge/source-rebuild-v0.1`
>
> 运行边界：本工作线不修改 `mod/`，不推进 v0.2 功能开发。

## 目标

为《神器使》Stellaris Mod 建立可追溯的本地知识体系，将自动采集资料、人工确认事实、主线视频目录和 MOD 设计解释明确分层。

## 当前已完成

- 建立 `knowledge/curated/` 人工确认层。
- 建立本地 SQLite 数据库 `knowledge/database/seven_days_knowledge.sqlite`。
- 建立 85 集主线剧情目录的可重建种子数据。
- 导入七名现有角色的灰机 Wiki 来源与 clean 文档索引。
- 建立第 1 至 3 章（P01-P12）的人工摘要审核队列。
- 记录第 12 章《堕天使的挽歌》排除决定。

## 来源规则

1. 灰机 Wiki 用于角色资料、活动资料、基础名词与页面索引。
2. B 站主线剧情合集 `BV17M4y1w7rr` 经人工确认后，用于补足 Wiki 缺失的主线叙事。
3. 翻车线不进入当前正统剧情层；只有未来解释缺口时才作为特殊补充登记。
4. 任何正式事实都需要来源、定位、人工审核状态；视频事实额外需要时间码。

## 后续顺序

1. 为核心术语建立来源卡与审核记录。
2. 分段观看 P01-P12，填写原创摘要、时间码和候选事实。
3. 通过人工审核后，把确认事实写入 curated 术语与剧情条目。
4. 以确认事实为依据，原地重写现有世界观、神器、组织、时间线与剧情圣经。
5. 再回溯审计七名角色，补齐其余四份标准角色档案。

## 明确不做

- 不下载视频、音频、字幕或画面。
- 不复制长篇剧情原文或完整对白。
- 不进行全站 Wiki 同步。
- 不安装自动转写工具；需在首批人工摘要格式稳定后再单独评估。
- 不修改任何 Stellaris 运行脚本、数值或玩法。
