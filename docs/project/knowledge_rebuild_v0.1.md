## 来源规则

1. 灰机 Wiki 用于角色资料、活动资料、基础名词与页面索引。
2. B 站主线剧情合集 `BV17M4y1w7rr` 经人工确认后，用于补足 Wiki 缺失的主线叙事。
3. 翻车线不进入当前正统剧情层；只有未来解释缺口时才作为特殊补充登记。
4. 任何正式事实都需要来源、定位、人工审核状态；视频事实额外需要时间码。
5. 2026-07-15 用户已授权：主线视频审核可直接进行临时内存画面抽样，无须逐段再次征询；仍严格不下载、不保存视频或截图、不提取字幕、不进行 OCR、不转写。
6. P05、P06 经用户人工确认属于第二次讨伐的区域选择分支，不属于主线本体，也不影响主线走向或结局；两集必须全片逐段录入并比较分歧与汇合点。
7. P07 经用户人工确认是每个区域讨伐结束后的黑核回收后续，不是区域选择分支；各区域片段必须按原顺序完整录入。
8. 主线剧情同时是角色资料的重要补充来源。经人工确认的时间码证据可用于补齐角色的行动、关系、立场变化、历史处境与文明定位；路线特有内容必须保留分集、结局编号和时间码，不能覆盖角色的共通档案或 MOD 正史。

## 跨结局甄别规则

1. 同一主线的不同结局共享大量剧情背景、人物状态和场景信息；默认先视为“可能共通”，不把每个结局当作完全独立故事。
2. 每条视频候选事实在跨结局整理时必须标为“共通候选”“分歧候选”或“未分类”；未经比对的内容保持未分类。
3. P02 的 Bad End 结果、角色死亡和失败状态只属于已确认的结局 0 线索，不能反推 P03 或其他结局。
4. 只有同一事实在多个结局中吻合，或由用户明确确认其共通性，才能进入主线共通剧情层。
5. 结局特有内容保留原分集、时间码和结局编号，作为分歧证据，不覆盖角色档案与 MOD 正史。

## 区域流程区分规则

1. P05、P06 独立标记为“区域剧情分支”，分别对应第二次讨伐选择东方古街与中央城区；不得标记成主线章节或结局线。
2. P05、P06 不参与主线走向或结局判定，但完整剧情具有独立知识价值，必须按时间段全部录入，不得只保留差异摘要。
3. P07 独立标记为“区域讨伐后续／黑核回收”，按各区域片段顺序保存，不参与 P05／P06 的选择分支计数。
4. 只有获得人工确认的共通背景事实，才可进入主线共同剧情层；区域差异与黑核回收事实继续保留来源分集和时间码。
