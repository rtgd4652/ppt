# 后续开发优先级

## Phase 1（当前）

### v0.1 稳定版本

目标：

- 冻结当前版本。
- 不新增大型玩法。
- 修复影响启动、进游戏、白夜馆使用和核心系统体验的问题。
- 统一归档文档、测试结果和知识库状态。

完成标准：

- v0.1 核心测试全部通过。
- `error.log` 无本 MOD 的关键阻断错误。
- release notes、测试报告、总设计文档和知识库路线图完成。

## Phase 2

### 神器使文明深化

目标：

- 在 v0.1 稳定底座上扩展神器使文明体验。

内容：

- 更多神器使。
- 更多招募。
- 神器使事件。
- 白夜馆深化。
- 角色通讯与回忆扩展。
- 神器使 trait 模板标准化。

边界：

- 不直接进入完整爱缪莎终局线。
- 不同时展开大型银河危机。

## Phase 3

### 爱缪莎主线

目标：

- 将爱缪莎从首批神器使成员提升为主角路线核心。

内容：

- 三职业切换。
- 30级觉醒。
- 成神立绘。
- 专属飞升。
- 专属舰船。
- 专属巨构。
- 命运路线。

边界：

- 需要先完成世界观圣经、玩法总设计和原版主线摘要。
- 专属舰船与巨构必须先解决模型、图标、UI 和组件保存问题。

## Phase 4

### 银河时代扩展

目标：

- 把黑门、神器、中央庭与白夜馆扩展到银河尺度。

内容：

- 黑门危机。
- 银河文明互动。
- 大型考古。
- 终局危机。
- 多组织政治与外交。
- 银河级神器研究与命运干涉。

边界：

- 只有在 Phase 2 和 Phase 3 的核心系统稳定后再展开。
- 所有大型系统必须先进入设计文档，再进入脚本实现。

## 开发原则

1. 当前阶段不新增大型玩法。
2. 当前阶段只整理、归档、固化。
3. 不修改已经通过测试的核心系统。
4. 所有未来设想进入 roadmap。
5. 保持代码、文档、知识库同步。
