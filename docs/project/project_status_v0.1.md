# 《神器使》Stellaris Mod 项目状态 v0.1.0

> 更新时间：2026-07-11
> 状态：封版候选，等待游戏内复测
> 当前开发分支：`parallel/v1-integration`

## 1. 版本定位

v0.1.0 是“神器使文明基础系统 + 白夜馆首批角色 + 第一版终局内容”的稳定基线。

本版本的目标是证明以下闭环能够稳定运行：

1. 玩家可以使用神器使物种、起源和预设帝国开始游戏。
2. 玩家可以通过白夜馆招募首批神器使领袖。
3. 神器使科技、传统、飞升、建筑、岗位和区划能够共同工作。
4. 专属星球不会因科技、月结、读档或重复事件而反复生成。
5. 命运观测塔和命运之主能够以当前冻结范围进入游戏。

v0.1.0 不追求完整复刻原作，也不继续扩展角色和剧情。

## 2. 已实现范围

### 文明基础

- 神器使物种、肖像与种族特质。
- 神器使起源、专属初始星球和预设帝国。
- 专属科技、传统、飞升、建筑、岗位与区划。
- 专属星球国家 flag 防重复逻辑。

### 白夜馆与领袖

- 白夜馆是神器使招募、联络、档案展示与管理入口，不属于中央庭，也不是世界观势力。
- 已实装爱缪莎、赛斯、幽桐和拉比。
- 已接入唯一招募判断、专属 trait、职业定位和 30 级上限。
- 爱缪莎保留职业切换与等级立绘基础。

### 命运观测塔

- 已有四阶段巨构脚本与政策模式。
- 正式三维模型、阶段外观和正式 outliner 图标延后。

### 命运之主

- 已有专属舰体、模型、三个区段、核心组件、双光环、跃迁核心与重构事件。
- 使用 `use_shipnames_from = titan` 兼容任意玩家名称表。
- 因模型缺少武器 locator，v0.1 暂时关闭 T、X、L 武器槽。
- 完整武器布局、攻击动画和战斗平衡延后。

### 知识库与设计

- 已完成七名角色的 Raw、Clean、图片索引和 Mod Ready 摘要。
- 已完成爱缪莎、安托涅瓦、晏华标准角色档案。
- 已完成世界观、神器、组织、时间线、剧情和角色关系圣经。
- 安托涅瓦被确定为中央庭核心领袖，晏华与爱缪莎是重要辅助者。

## 3. 本轮封版修复

- `mod/descriptor.mod` 版本统一为 `0.1.0`。
- 建筑和岗位中的无效资源键 `trade_value` 已改为 Stellaris 4.4.3 使用的 `trade`。
- `mod/interface/aemusa_generated_icons.gfx` 已转换为 UTF-8 无 BOM。
- 命运之主已复用泰坦名称表，避免 `HUMAN1` 等名称表无法生成自定义舰级名称。
- 没有恢复尚无模型 locator 支持的武器槽。
- 没有制作缺失图标，等待后续统一美术规范。

## 4. v0.1.0 发布门槛

以下项目必须由只启用本 Mod 的新开局验证：

1. 白夜馆入口稳定。
2. 四名领袖均可招募。
3. 已招募角色不会重复出现。
4. 领袖职业正确。
5. 专属 trait 正确挂载。
6. 神器使领袖等级上限 30 生效。
7. 专属飞升可选择。
8. 专属传统可打开。
9. 科技线可抽取并正确解锁。
10. 专属星球、区划、建筑和岗位正常工作。
11. 中文本地化不存在阻断性缺失。
12. 新生成的 `error.log` 不包含本 Mod 的脚本解析、无效对象或事件崩溃错误。

缺失的正式图标属于已知美术问题，不作为本次封版阻断项，但必须在报告中保留。
