# 神器使与爱缪莎 · 本地候选版安装与存档

ZIP 文件名中的 `candidate` 表示开发候选。启动器沿用项目原有的显示名「神器使与爱缪莎」和版本 `0.1.0`。描述符声明 `4.4.*`，因此 4.5 版启动器可能显示版本提示。项目已有《群星》4.5.3 的旗舰实战记录，完整 1.0 的全线与多模组兼容验收仍在进行。

## Windows 安装

1. 关闭游戏与 Paradox 启动器，将整个 ZIP 解压到一个新文件夹。打开解压后的 `mod` 文件夹，应看到 `aemusa_artifact_user.mod` 和 `aemusa_artifact_user` 两项。
2. 在文件资源管理器打开当前用户的「文档」，进入 `Paradox Interactive\Stellaris\mod`。若「文档」已迁移至 OneDrive 或其他盘符，使用实际存放该游戏 `save games` 的用户资料目录。在首次安装时可新建 `mod` 文件夹。
3. 将第 1 步的两项一起复制到游戏的 `mod` 文件夹。最终应有以下结构。

   ```text
   Stellaris/
     mod/
       aemusa_artifact_user.mod
       aemusa_artifact_user/
         descriptor.mod
         common/
         events/
         gfx/
         interface/
         localisation/
         prescripted_countries/
   ```

4. 打开启动器，在「所有已安装的 Mod」中找到「神器使与爱缪莎」，加入要使用的播放集并启用。首次体验可只启用这一份，进入新游戏。外层 `.mod` 的 `path="mod/aemusa_artifact_user"` 会指向刚复制的内容目录，用户名和上层文件夹可使用中文。

## 更新、接续与回退

已有同名安装时，先在游戏外保留一份升级前的 `.sav`。游戏和启动器关闭后，将旧的 `aemusa_artifact_user.mod` 和对应内容文件夹备份到 `mod` 目录之外，再放入新包的两项。整目录替换可清除旧版本已移除的脚本。若旧注册文件的 `path` 指向开发仓库，仅备份注册文件，原仓库原地保留。播放集使用一份同名 Mod。读回旧档时沿用它原有的其他 Mod 和 DLC 组合，确认后另存新档。

| 读回以前的存档 | 可期待的表现 |
| --- | --- |
| 已有现实恒定旗舰 | 六 L 旧舰保留原来的舰体和配装。旗舰战斗瘫痪时在原地立即复原。若被脚本彻底移除，打开「联络爱缪莎」，点击「在首都召回『未闭合的航路』」。新补的唯一旗舰使用 16T 设计，需要本国控制首都。 |
| 正在处理专属危机锚点 | 更新前已经公开预警或成锚的节点沿用原时限。新关联压力在确认下一处核心节点预警时启用，已记录的损失与战果继续保留。 |
| 已完成专属危机或任一正式结局 | 战后公共工程读取共同胜利记录。旧档缺少节点明细时显示胜利摘要。仅存个人结局的旧档可回看结局。个人正式转变有独立条件，另两种结局也能按共同战果发展公共工程。 |
| 首次向进行中的其他战役加入本 Mod | 新帝国可从建国时取得物种、起源与预设内容。已有战役中临时加入的全线回填尚未验证。 |

若需要回退，关闭游戏和启动器，恢复备份的注册文件、原内容目录以及**升级前保存的存档**。在新版本中另存的战役没有验证向旧版本降级读取。

## 从源码重建候选包

在仓库根目录运行 `python -B tools/build/package_local_mod.py`。构建使用 Python 标准库和 Git 的 `archive --mtime`，取当前已提交版本的整个 `mod/` 和本说明。输出位于 `temp/local_mod_candidates/`，文件名带提交短号。需要另存时，可传 `--output-dir "包含空格或中文的目录"`。
