# 知识库建设路线图

## 目标

知识库用于支撑《神器使》Stellaris Mod 的长期大型化开发。它负责沉淀世界观、原作剧情、组织设定、神器体系、时间线和美术规范，避免后续开发只靠临时记忆推进。

当前阶段只整理知识库方向，不把未来设想直接实现进 v0.1。

## 当前已完成

- `characters`：已建立角色基础知识条目。
- `mod_ready/characters`：已建立面向 MOD 实装的角色转译资料。
- `character reports`：已形成角色整理与接入报告。

## 建设原则

1. 先知识库，后玩法实现。
2. 先原作事实与 MOD 转译分层，再进入脚本开发。
3. 角色、世界观、玩法文档、脚本实现保持同步。
4. v0.1 收尾阶段只记录缺口，不新增大型玩法。
5. v0.2 开发前优先补齐世界观圣经与玩法设计总文档。
