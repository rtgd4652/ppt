# 3. 总体结论

1.0 的**背景底座已经完成**：世界观、历史阶段、组织体系、神器体系、宇宙论边界、十人最低时间连续性、角色职业与单一核心机制、爱缪莎主线总纲和终局叙事边界均已有可追溯文档与人工审核记录。

但项目尚未达到“可以直接全面实现 1.0”的准备程度。当前主要缺口已经从“世界观不知道怎么写”转变为三类生产前问题：

1. **十名角色基础视觉锚点已经闭合，但正式资产尚未生产**：十人的基础形态、觉醒辅助边界、神器器物、外貌和固有色已经人工批准；爱缪莎命运主宰终局形态仍作为主线专项待审。
2. **爱缪莎主线仍缺制作级叙事拆分**：章节总纲与危机职责已经批准，但具体场景节拍、参与角色、信息证据、对话目标、资产需求和章节验收条件尚未形成统一制作表。
3. **正式资产方向尚未闭合**：中央庭公共材质和黑门／异界分层规则已经人工批准，但新版爱缪莎专属舰、命运类巨构、终局形态和 UI 技术规格仍未闭合；批准的公共规则也尚未经过代表性游戏资产曝光复测。

因此，当前阶段应继续称为**1.0 生产前准备阶段**，而不是技术原型阶段或正式实现阶段。

# 5. 已完成且不应重复工作的内容

## 5.1 背景与正史

- 七日轮回已经结束，人类进入连续历史。
- 人类在黑门灾难中成长，没有因灾难被彻底毁灭。
- 中央庭是灾后文明治理核心，不是单纯军事组织。
- 神器是人类独有、可科学研究但尚未完全理解的现实异常。
- 白夜馆只是招募、联络、档案和管理功能入口，不是世界观组织。
- 人类在 Stellaris 开局时仍是刚进入银河的年轻文明。

这些结论已经足以支撑 1.0，不应为了“补完整”而擅自解释所有宇宙谜团。

## 5.2 十名神器使

锁定名单为：安托涅瓦、爱缪莎、晏华、安、赛斯、幽桐、拉比、格蕾莎、雯梓、丽。

- 十人的资料、Mod Ready 摘要、标准角色档案与最低时间连续性已经达到当前范围要求。
- 十人的领袖职业与一个角色核心机制已经获得人工批准。
- 里见茜不进入 1.0 十人名单；塞拉菲姆只保留为过去历史人物。
- 司篁不进入 1.0 十人名单。
- 埃索林不是神器使，只承担爱缪莎主线后期的有限见证者／顾问职责。

## 5.3 爱缪莎主线

- “序幕 + 六幕；序章 + 十六章”的结构已批准。
- 失落帝国战争固定在玩家选择的原版天灾之前。
- 原版天灾由玩家选择一种，每局只进入一次对应主线模块。
- 命运没有人格或意志，是对不和谐与超脱倾向进行修正的运行规律。
- 爱缪莎在原版天灾阶段开始主动干涉命运。
- 专属终局天灾是无尽七日轮回中“注定毁灭的命运”在当前宇宙中的收敛显现。
- 战胜专属危机后，爱缪莎才确认旧世界与当前世界并非同一世界，并在玩家授权与本人自主接受后成为命运主宰。

# 6. 真正缺失的准备材料

## P0：进入正式内容生产前必须完成

### GAP-P0-01：十名角色视觉锚点完成矩阵

**状态：已完成。** 十人的基础立绘、觉醒辅助边界、神器、服装、发型、固有色、关键配饰、禁止误读和来源边界已经完成逐人审核；爱缪莎命运主宰终局形态不包含在本项中，继续作为主线专项单独审核。

需要为十名角色逐一记录：

- 基础立绘、觉醒立绘、神器、服装、发型、固有色和关键配饰的来源；
- 不可改变的角色识别元素；
- 可用于星海时代升级的结构；
- 只属于特定皮肤或剧情状态、不能当作基础形态的元素；
- 禁止误读方向；
- 来源与版权状态。

爱缪莎与安托涅瓦应先完成“部分”到“批准”的收尾，然后处理晏华、安、赛斯、幽桐、拉比、格蕾莎、雯梓和丽。没有通过视觉锚点审核前，不制作正式立绘和个人图标。

### GAP-P0-02：爱缪莎主线制作级剧情矩阵

在不写事件代码的前提下，把十六章逐章拆成：

- 章节目标与进入条件；
- 场景序列与节拍；
- 出场角色及每人的叙事职责；
- 玩家需要理解的事实、角色主张和仍保持开放的谜团；
- 选择点、暂停点、修复点与不可逆后果；
- 对话目标和情绪变化，不提前写完整台词；
- 所需立绘、事件图、UI、舰船、巨构、音效和特效；
- 章节完成与一致性验收条件。

这份矩阵必须继续遵守 AMR、JCR、命运主宰能力边界和真相揭示矩阵，不得通过演出提前泄露终局真相。

建立面向发布范围的资产总表，至少覆盖：

- 十名角色的基础立绘、必要阶段立绘、头像与通讯表现；
- 白夜馆公共界面；
- 爱缪莎主线必要事件图和阶段表现；
- 新专属舰、新命运类巨构和专属危机载体；
- 中央庭公共舰船／建筑／区划／科技／传统／飞升／遗珍／特质；
- 黑门、终局锚点、命运干涉和危机阶段特效。

每项记录“是否 1.0 必需、来源、版权、设计状态、制作状态、游戏规格、审核人和验收条件”。参考图不得直接当作正式资产。

`docs/ROADMAP.md` 与 `docs/TODO.md` 仍以旧 `v0.x` 原型为主体，并保留“继续精修命运之主”“制作命运观测塔”等已失效任务。应在准备阶段另行更新为 1.0 内部里程碑，并明确：

- 旧 Stage 9 舰体不是爱缪莎正式专属舰；
- 旧命运观测塔已废弃；
- 图标缺失按用户决定等待美术风格与技术表最终确认；
- 当前不进入代码或技术原型；
- 十人视觉锚点、主线制作矩阵和资产登记表是当前优先项。

## P1：资产批量制作前必须完成

### GAP-P1-01：中央庭公共材质代表性校准

**规则状态：已批准。** `CCM-001～003` 已于 2026-08-16 人工批准，公共颜色、材料职责、维护状态和发光边界已经锁定。以下代表性游戏环境测试仍属于正式资产批量生产前的验证任务，不反向重开已批准的公共风格。

使用一个普通舰船、一个公共建筑和一组小尺寸图标作为校准载体，在不同星系背景和 UI 尺寸下确认：

- 深色陶瓷／复合装甲、涂层金属、雾银结构件、强化玻璃和受控神器接口的比例；
- 发光强度、曝光、边缘可读性和远景剪影；
- 日常、公共、神器、英雄和终局五级视觉强度不会混淆。

此处只做校准方案与审核记录；实际样例制作需要后续单独授权。

### GAP-P1-02：黑门与异界视觉证据补足

**结构状态：已批准。** `BGV-001～002` 已于 2026-08-16 人工批准，黑门、黑核、黑雾、异界生态和中央庭工程响应的分层规则已经锁定。不同规模门体、开合状态与独立异界生态仍需随实际剧情资产继续补证和校色。

第一版对照已存在，但仍需补足不同规模门体、开合状态、黑核、黑雾、空间折叠和不同异界生态的来源证据与校色记录，避免把所有异常统一成紫色虚境或水晶魔法。

### GAP-P1-03：爱缪莎专属舰与命运类巨构重新立项

正式立项顺序必须是：

1. 锁定叙事职责和使用场景；
2. 决定正式名称；
3. 建立形状、材质、光效和性能边界；
4. 形成多方案概念草案；
5. 人工审核后再进入灰模。

旧 Stage 9 舰体只可作为技术经验；旧命运观测塔只可作为反面参考，二者都不能反向决定新方案。

### GAP-P1-04：十人关系与主线参与矩阵

现有关系圣经主要锁定安托涅瓦—晏华—爱缪莎核心结构。还需要明确其余七人在 1.0 中：

- 与中央庭及安托涅瓦的工作关系；
- 是否参与爱缪莎主线，参与到哪一幕；
- 能提供什么有限证据或行动能力；
- 哪些章节不得强行出现；
- 如何避免十人沦为同时发言的背景群像。

该矩阵只决定叙事职责，不设计玩法收益。

# 7. 文档一致性问题

当前部分状态文件仍写着“下一步进入隔离技术原型”或 `approved_for_isolated_prototype`。这些字段只记录此前已经批准的可行性边界，不代表当前立即执行顺序。以后统一解释为：

- 责任卡已经审核完成；
- 技术原型授权暂时冻结；
- 只有用户明确宣布进入技术原型阶段后，才允许执行；
- 在此之前继续完成本审计列出的准备材料。

此外，旧 `ROADMAP.md`、`TODO.md` 和部分 v0.1 状态记录属于历史里程碑，不得作为 1.0 当前路线的直接指令。
